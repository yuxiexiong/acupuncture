按青蒿素原则，已有工作是起点和比较对象：缓存线重点承接混合模型状态分工、缓存移植及 WriteSAE；控制线把 DSI、CNA、COAST 等纳入方法参照，并复用成熟评价。没有必要为了避开近邻缩小问题。两份查重报告区分已核对的文献、项目已有结果与尚未运行的 baseline；不把定向查重当“无人做过”的证明。

共同解释边界：停止优势增加不等于实际停止；事实敏感度下降不等于事实利用失败；任务答错不等于知识被删除。缓存指具体实现中的持久推理状态，不是永久权重记忆。历史方案、冻结设置、失败和收据保留原样；历史方向以当时语境阅读，当前项目定位以上述两条线为准。
