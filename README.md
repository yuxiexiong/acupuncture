# Acupuncture｜少数通道干预：缓存机制与稳定副作用控制

研究训练完成、权重冻结的语言模型中，少数通道的激活干预为什么能显著影响回答，以及怎样理解和利用这种影响。当前项目以 **缓存机制线** 与 **稳定副作用控制线** 分别立项。当前“插针”主要指 MLP 中间激活的运行时修改，不等于已经进行了静态权重编辑；少数坐标也不等于小幅有效扰动。

## 当前两条研究线

统一口径日期：2026-10-30。以下是研究定位和立项草案，不是已经成立的完整机制或方法贡献，也不是新实验运行授权。

| 研究线 | 分别做什么、解决什么痛点 | 已有什么 | 价值与当前证据位置 | 立项及查重 |
| --- | --- | --- | --- | --- |
| **缓存机制线** | 解释少数通道干预怎样写入历史状态、跨层传播，并在撤针后继续影响回答；解决只看输出或当前干预开关无法解释持续效应的问题 | 同文字有针/无针状态对照，KV、递推、短卷积三类状态拆分，层组清理与反向污染，以及部分回答交付恢复 | 已有指定状态的因果作用证据，尚未完成内部计算解释；机制认识可以独立有价值，不要求必须产出更好算法 | [Proposal](docs/cache-mechanism-proposal-2026-10-30.zh-CN.md) · [查重报告](docs/literature/cache-mechanism-prior-art-2026-10-30.zh-CN.md) |
| **稳定副作用控制线** | 研究怎样选通道和校准干预，在达到目标行为效果时减少错答、交付失败等代价，并保持对新输入的可靠性 | 跨模型、层、方向和剂量的观察；行为/任务联合测量；固定随机参照；已有实际副作用与反例 | 应用目标更直接，已有问题证据但尚无相对强方法的改进证据；不等于让副作用稳定出现，也不要求绝对零损失 | [Proposal](docs/stable-control-proposal-2026-10-30.zh-CN.md) · [查重报告](docs/literature/stable-control-prior-art-2026-10-30.zh-CN.md) |

**当前缓存机制线的直接证据更完整，具备优先推进依据；两条线各自保留立项目标和成果标准。** 它们可以共享工具、数据和解释，但不是一个无边界大实验：缓存恢复不等于控制方法可用，控制改善也不自动证明机制。后续不同补充问题应分别形成实验与合同，可以串联。

按青蒿素原则，已有工作是起点和比较对象：缓存线重点承接混合模型状态分工、缓存移植及 WriteSAE；控制线把 DSI、CNA、COAST 等纳入方法参照，并复用成熟评价。没有必要为了避开近邻缩小问题。两份查重报告区分已核对的文献、项目已有结果与尚未运行的 baseline；不把定向查重当“无人做过”的证明。

共同解释边界：停止优势增加不等于实际停止；事实敏感度下降不等于事实利用失败；任务答错不等于知识被删除。缓存指具体实现中的持久推理状态，不是永久权重记忆。历史方案、冻结设置、失败和收据保留原样；历史方向以当时语境阅读，当前项目定位以上述两条线为准。
