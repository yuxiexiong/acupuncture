# NVB-01 决策日志（冻结前）

- N1 主比较按两轮讨论移到原生一侧（B010/B011 对 B000/B001），恢复侧与输出侧比较保留；不称“内容×读取语境”析因（c 也改深层写入输入）。
- N2 随机族只在 c=0、只跑 C 路线：主问题是“原生输出下只改留存”；c=0 自然轨迹 t1 停止是结构必然（LVK L00 166/192），自然路线无信息。
- N3 K=19：单侧最小可得 p=1/20；K=9 只到 0.1。增量约 1.46 万次前向（估约 0.32 设备小时，未实测），总上限仍 1.5 GPUh。
- N4 ρ 用 FP32 加到 v0 上（v_r 不经 BF16 舍入），以保证每头范数精确匹配；v1 本身是 BF16 卷积输出。差异在 BF16 舍入量级，记为可接受边界。
- N5 每个随机格独立前向（不在缓存里直接替换 S），让“只有 S 不同”在真实前向上实测，而不是构造假定。
- N6 对角四格除与 LVK 记录比对外，再用参考实现重建完整缓存（000 对原生 t1；001/110/111 对 LVK LHook），共 768 次参照 t1。
- N7 t2 q/k 只读捕获沿用 SRU 的 RHook('capture')（调用原核，不改输出）；对 000 的 C 路线输出另与 LVK 逐位比对，可检出捕获是否扰动。
- N8 CPU 就绪检查实测：LVK 新面板 L00 t1 停止 166/192、L01 174/192、L10/L11 0。
