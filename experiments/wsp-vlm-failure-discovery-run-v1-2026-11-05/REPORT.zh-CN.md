## 2. B：确有条件计数缺口，不能简单归为“忽略条件”

D普通提示T0：全数47/58、子集31/58，差27.59pp；H差14.77pp，开发表现差在留出上减弱。H有22组全数对/子集错，9组反向。等义改写T1差15.91pp，方向保持。

H全数与子集标签不同的59组中，仅2组满足“全数答对，子集错答成全数”。D对应4/45组。该模式远不足以解释全部失败；不要把后续操作预设成统一压低答案数或“开启空间条件神经元”。

规则提示B1在H的T0子集上修对6、改错6，子集正确率仍68.18%；总数正确率反而从82.95%到80.68%。T1子集也没有净改善。这里的结果是该固定提示效果有限，不是所有提示都无效，更不是WSP有优势的证据。

B保留为后续比较或诊断备选；不自动加题、改模型或扩大搜索。

## 3. C：反事实图影响常识回答，且伴随问法敏感性

H普通提示T0、固定primary顺序的五条件为：

| 条件 | 正确率 |
|---|---:|
| 无图通常 | 85/96，88.54% |
| 原图通常 | 94/96，97.92% |
| 反事实图通常 | 74/96，77.08% |
| 原图视觉 | 96/96，100% |
| 反事实图视觉 | 90/96，93.75% |
| 五条件全部答对 | 64/96，66.67% |

20组原图通常对而反事实通常错，反向为0。**15/96组满足严格行为模式：无图通常对、原图通常对、反事实视觉对，但反事实通常错成视觉答案。** D对应7/64，低于原先8组线索强度参考；H达到12组参考。两者均完整报告，不把开发集参考计数偷换成主检验通过条件。

例如C-093问瓶子与木筏、C-420问微波炉与帆船：这两组无图/原图的通常题答对，反事实视觉题也答对，但反事实图上的通常题分别错答瓶子、微波炉。完整15组及图片指针见 `descriptive_followup.json`；所有正确/错误均在证据包中，不仅保存这些例子。

普通提示在T0/T1及两种名称顺序的四个固定面板中，通常题主差均为正（15.63–23.96pp）；C通过既定稳健性要求。对象顺序、模板仍影响幅度，不能称提示无关能力缺陷。

**新模式的探索性复核：** D已在H之前登记视觉问法敏感性。H中，同一primary顺序，反事实视觉从T0的90/96降到T1的59/96；31组由对变错，反向0组。这是D发现后的描述性复核，没有新增确认性p值。它提醒后续修复同时检查图像与常识问法，不能把痛点简化为永久降低视觉影响。

固定规则提示也不是稳定修法：H的T0反事实通常从74/96降为66/96，修对1组、改错9组；T1则从70/96升到75/96。其效果依赖问法。本轮只比较预定这一个规则提示，不宣称穷尽提示优化。
