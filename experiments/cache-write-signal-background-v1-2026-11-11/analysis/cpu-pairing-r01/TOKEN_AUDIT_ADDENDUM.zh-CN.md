# 输出分叉位置核对：CPU 补充设计

在读取一份原始记录核对字段后追加；此时张量分析正在运行，尚未读取其汇总结果。原始自然生成函数确认 N.ids 从 t1 输出开始，含终止token；已保存t2 logits的hash而非数值。

本项只为定位缺测时刻：全348配对逐格与CC比较完整token串的第一个不同位置；并列CH/HC/HH，相同列为same。再列四格t1完整logit hash和t2 logit hash相同数量。它能说明可见答案何时分叉、缺哪一步的数值，不能说内部作用只从该token开始，也不能把hash不同当作任务相关差异大。

全配对保留，不挑变答成功子集，不设阈值、不新增模型调用。C01/C02通过：服务写入后何时影响选择及缺测定位；C08/C10通过：token分叉不冒充因果起点，hash不冒充数值；C13通过：明确追加时间和已查看一条记录，仍为探索；C14通过：结束于缺测表，不触发GPU。其余C项沿原只读设计，操作范围未变。

反方：首token相同不等于中间状态相同，t2首次分叉不等于t2唯一成因；保留该边界，不把顺序关联升级为机制。作者自查通过，用户CPU授权覆盖，新增GPU小时0。
