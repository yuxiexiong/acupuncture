如何理解这些对照

原版自由回答是未干预模型独立生成的回答，用于比较最终文本。图中的无针参照则从提示开始全程不加针，保留独立缓存，并强制读取干预分支已经选择的 token；两边在每一步看到相同文字历史。

因此，图中比较的是相同前缀下的状态与预测。它不等于中途拔针，也不能单凭某层最亮或某个 token 最先不同，就断定该层负责语句完整性。

停止优势为最高停止 token 分数减去最高非停止 token 分数；正值表示停止更占优。候选 token 的并列最高分需要保留，不能把并列选择自动算作行为异常。

每题最多生成 128 个新 token，遇到 EOS 则保留原长。到达长度上限、空正文和第一次预测不同本身都不是自动判定的失败。页面不附加语义评分或人格标签。

没有采集轨迹的条件显示“未采集”，不画成零。Attention / GatedDeltaNet、MLP 与层末残差分别保留各自读数；GatedDeltaNet 的读数不是注意力权重矩阵。
