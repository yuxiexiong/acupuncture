# SRU-01 合同 r01：t1 形成的状态差怎样在 t2 变成目标优势

依据计划 `docs/cache-state-read-use-plan-v1-2026-11-03.zh-CN.md`（4e4fdfe），加上我审阅时提的三点补充（§4 编号 token 与选择步、§5 未搬运差异清单、§5 与 KHC 的对照读法）。授权：2026-11-03 用户“开始”。冻结后不改本文件；偏离记入 `DEVIATIONS.zh-CN.md`。

## 1. 问题

LVK 的两个写入端点 L10（只换局部 v）与 L11（局部 v + 写入项 k1）之间已有完整回答差异。本轮问：t1 形成的递推状态差，在 t2 通过哪一种旧状态使用方式（直接读取 D，或旧预测修正 E），足以获得或撤回目标优势与完整交付。不是证明“S 能被读到”，也不承诺识别完整原生机制。

## 2. 固定条件

只用 LVK 的新面板 48 条（本轮已见过其结果，称“既有新文本面板上的机制后续检验”）；其余全部继承 LVK 合同。G 为固定 14 层，不选头不扫层。

## 3. 操作

- 每输入重建 C 与四个 T；每方向重建 L10、L11 的 t1（LVK 影子钩子），取各 G 层 t1 后的递推状态 S1 作只读来源。
- t2 原核输出的分解（已对照原核核实）：o₂ = D(S₁) + E(S₁) + W，D = αS₁ᵀq，E = −αβ(kᵀq)S₁ᵀk，W = β(kᵀq)v。
- 有序配对：gain（接收者 L10，供体 L11）、withdraw（接收者 L11，供体 L10）。格 ab：o₂_ab = o₂ + a·α(S_d−S_r)ᵀq − b·αβ(kᵀq)(S_d−S_r)ᵀk，在 FP32、转 BF16 之前相加；返回并写入缓存的 S₂ 是接收者原生更新。q/k/v/α/β 都取当前分支自己的值。只在 t2、14 个 G 层；t1 只有 LVK 的写入钩子，t3 起无钩子。
- C 路线：t2 输入冻结共同首 token fF；N 路线：t2 输入接收者自己的 t1 首 token，贪心续写到停止或共 32 token。

## 4. 读数

- M（目标区别 token − 首列；目标首列时减第二列）、M_all；Y_full（原解析器）。M 用目标非首列 32 条场景等权，Y 用全 48 条。
- **编号 token 结构（审阅补充，已用真实分词器核实）**：所有编号都是 3 个 token（共享首 token + 互不相同的第二 token + 第三 token）。所以“选哪条记录”由 t2 的输出决定，本轮操作正好作用在这一步；但第三个 token 在 t3 输出，那时状态里是接收者原生的 S₂，供体信息已不在。为把“选择”与“补全”分开，增加描述性读数“t2 选择正确”＝自然轨迹 t2 输出等于目标编号的第二 token；Y_full 仍是主行为终点。
- L10/L11 共 384 个首 token 中有 6 个不等于 fF；这些输入的 t2 不是选择步，单独列出，不筛掉。

## 5. 冻结判读（操作性标签，非显著性）

- 获得侧预期为正，撤回侧为负。M 定向支持：sign·eq ≥0.25 且 ≥4/6 场景同号；Y 支持：净变化 ≥2/48 且 ≥2 个场景有预期方向变化；联合支持＝两者都满足。
- 标签（取第一个满足的）：opposite（任一格 M 反向）；direct_dominant（11、10 都有联合支持，|ΔM11| ≥0.5，ΔM10/ΔM11 ≥0.75，|ΔM01/ΔM11| ≤0.25）；correction_dominant（对称）；both_single；joint_only；diag_only（11 只有 M）；weak。
- 两侧都 direct_dominant 才称双向支持；三个缺口方向至少 2 个才称多数方向。C1343 只作诊断。
- **工作预测（推测档）**：D 单项能双向搬运相当部分目标优势并改变完整交付，E 单项较弱。依据是 QKD 的描述性分账与 KHC 的载体线索，都不保证成立。
- 描述：背景缺口 g＝M(供体 00)−M(接收者 00)、ΔM11/g、交互 I、每层 D/E 校正范数与夹角、每层 t2 时两端点 q、k 的余弦。比值都不是机制份额。
- **未搬运差异（审阅补充）**：L10 与 L11 在 t2 之前除 S₁ 外还有差异：更深层卷积缓冲的 t1 新槽（上游 t1 输出不同）、A 层 t1 位置的 KV、以及 t2 当步的 q/k/v。11 格只换 S 在 t2 这次输出里的两种用途，这些都保留接收者的。11 格若偏弱，这些差异要和“后续更新/多步使用”一起列为候选，不能只归到其中一项。
- **与 KHC 的对照读法（审阅补充，看数据前写定）**：KHC 在 Q 固定为供体、并把 S 写进缓存时，S 几乎搬运了全部 H 效应。本轮 11 格用接收者自己的 q、不把 S 写进缓存。11 格强 → 在自由 q 下，t2 一次读取就够；11 格弱 → 差距候选为 q 的条件（KHC 用供体 q）与 S₂ 的持续存储。KHC 用的是另一组端点（Rk/V），只作定性锚点。
- E 在 t2 有效不与 KUC 中 t1 擦除项弱矛盾（时刻与操作对象不同）。M 动而 Y 不跟，只是条件竞争层面的约束。11 也弱时，不推出 S 无作用或剩余在 KV/q，也不自动加钳制、扩 t3 或扫层。

## 6. 工程闸门（运行中断言，任一失败即停）

1. 形成哈希等于 LVK 记录；L10/L11 的 t1 bf16 logits、首 token 与 LVK 一致；00 格的 C t2 bf16 全词表与自然完整 token 与 LVK 逐位一致。
2. 复刻原核顺序的 t2 钩子在 a=b=0 时与原生 t2 逐位相同（C 路线与 N 路线各一次工程参照）。
3. 返回的 S₂ 是接收者原生更新（同一实现内恒成立，CPU 测试验证）；供体 S₁ 只读，KV/卷积不移植。
4. 校正在转 BF16 之前加；10/01/11 每层局部输出对 FP64 公式相对误差 ≤1e−5；11 格另与“同顺序原核喂 S_d”的局部输出比较，相对误差 ≤1e−5。容差不用于放宽控制重放。
5. t2 每次前向 14 个 G 层各触发一次；t3 起零钩子；C/N 分别深拷贝；源缓存不变。有符号零沿用 KUC 规则。
- 预检（LVK 新面板 NQ01-ABC-A、NQ02-ABC-B 两条，全方向全格）失败即停，允许一次有记录的修复重试；正式开始后不改实现、阈值、数据。
