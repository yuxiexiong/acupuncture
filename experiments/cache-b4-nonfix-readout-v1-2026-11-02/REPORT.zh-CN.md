# B4（非 FIX G 层值头读出对 FIX 主效应的条件性依赖）结果报告

日期：2026-11-02。[合同 r01](CONTRACT.zh-CN.md)；[决策 D1–D5](DECISIONS.zh-CN.md)；方案 [v2](../../docs/cache-b4-nonfix-readout-dependence-plan-v2-2026-11-02.zh-CN.md) + [v3](../../docs/cache-b4-nonfix-readout-dependence-plan-v3-2026-11-02.zh-CN.md)。代码 `d25d3f1`，freeze-r01 `dee9d345…3d43`。输入已见，操作结果未见。同一助手实现、运行与撰写。

## 1. 结论（不利的先说）

1. **P1 不成立：钳回非 FIX G 层值头的读出后，停止侧主效应基本不降。** ρ_K 的方向均值为 0.88（N4146）、0.94（N1210）、0.96（R0）、0.90（R1），逐输入 0.82–1.14；24/24 个情景在两个事实上都是“未降低”（ρ_K > 0.8），四档标签全部为“未达改变门槛”。轴 A 的跨方向结论为**未降低**。
2. **按合同出口：未达门槛，不能据此把机制定位回 FIX。** 钳回只覆盖 403 个非 FIX 的 G 层值头；五个全注意力层和所有 MLP 照常响应，可能承载了替代路径或补偿。
3. **轴 B 是条件依赖**：R0、R1 判为“与两参照接近”（各 5/6 情景），N4146、N1210 没有形成方向标签。K 比参照多降的幅度不足 0.2。联合结论（强降低且超过两个参照）不成立。
4. **P2 成立：冻结下游的影子预测相当准确。** |ρ_K − ρ_shadow| ≤ 0.25 在 24/24 情景成立，逐输入最大差分别为 0.24、0.13、0.11、0.08。上卡前冻结的影子值是 0.93–1.00。在这个操作下，下游没有把非 FIX 头的读出变化放大成停止效应。
5. **两条预测指向相反，P2 胜出。** P1 的依据是 B3-P1 账目里的“跨组表达”（它解释的是两组主效应之间的**对齐能量**）；这次直接干预表明，这部分跨组表达对**停止侧主效应**几乎不承重。之前把描述性账目当作承重线索，这一推断被否定了。

## 3. 次要读数（描述，无预注册门槛）

- **答案侧变化比停止侧大得多**：FIX 让干净首词的去均值 logit 下降 3.3–3.9；K 之后只下降 2.0–2.3，即约四成的答案侧压低依赖非 FIX 读出。但 **M_nat 也有相近的作用**（下降 2.2–2.7），M_rand 几乎没有（3.3–4.0）。所以这里不能区分“依赖这份响应”和“对跨输入移植的自然方向敏感”。这与 C2 的“答案侧不由固定名单承载”一致，只作描述。

## 5. 对课题的含义与下一步（未设计、未授权）

- 固定45头的停止侧主效应，**不靠非 FIX G 层值头的后续读出来维持**（在本操作下最多 4–12%）。结合影子预测，非 FIX 头读出变化的直接贡献本来就小，下游也没有放大它。
- 剩下的承载候选是：FIX 头自己在各层的读出，以及全注意力/MLP 对这些读出的响应。其中最便宜的一步是互补的影子估计：在 B3 记录上从最终 h 减去 **FIX 头块**的直接贡献，看 X 还剩多少（零 GPU）。如果大部分 X 就是 FIX 头的直接写入，那么下一项因果检验的对象就很明确了；如果不是，承载者就在 MLP/注意力的响应里。
- 答案侧对非 FIX 读出更敏感，但 M_nat 混淆了它，需要单独设计，不并入停止侧主线。
