## 4. 记号与分析量（计划 §4–§5、§7）

S_t = A_t S_{t−1} + B_t，A = α(I − βkkᵀ)，B = βkvᵀ（k、q 为内核约定的归一化，q 乘 d_k^{−1/2}）。配对 X/Y：01v00、11v10（同起点），10v00（不同起点）。

- **第一步**（预先固定为 b+1，不挑点）：ĀΔS_b、ΔA·S_b（= 该步 u_H）、ΔB、二者内积，以及算子差 ‖ΔA‖ 本身；单列"ΔA 可分辨而 ΔA·S_b 未分辨"（零空间情形）。
- **H/N 追踪**（从 b 开始）：H_b = S_b，N_b = 0；u_B、u_H、u_N、ΔH、ΔN 逐步记录，并核验 S = H + N、ΔH 与 ΔN 的递推恒等式、u_H + u_N = ΔA·S̄。
- **10v00**：b 之后逐步的 ΔB、‖ΔA‖、ΔA·S̄，覆盖 τ、t_L 与全部候选位置；按段统计可分辨位置数。
- **辅助累计账**：D/W/R 从 c = b 与 c = τ 起，按对称、X 背景、Y 背景三种算子各算一遍，D + W + R = ΔS 须成立。
- **读出**：Δo = ΔSᵀq̄ + S̄ᵀΔq，状态项再拆成 ΔHᵀq̄ 与 ΔNᵀq̄；另报告 u_B、u_H、u_N 的读出投影。
- 层、头、token、事实版本都不当独立样本；逐情景、逐事实、逐层全部列出，不设"多数通过即成立"。

## 5. 误差界与可分辨性（计划 §8；离线预演前冻结，`formation.py` 常量）

1. **先验状态界**：e_S(t) = Σ_{s≤t} c·u·(‖S_s‖ + ‖B_s‖)，u = 2⁻²⁴（fp32 单位舍入），c = 16；沿主路径与候选分支各自累积。
2. **界的有效性（闸门）**：在每个暴露状态（τ、t_L、每条候选末）上，离线 fp64 重建与内核状态的实测绝对误差必须 ≤ e_S。有任一处不满足 → 分析停在工程验收（`stopped_engineering`），不出排除判决。
3. **分项界**：e(ΔS) = e_S^X + e_S^Y；e(ΔH) = e_S^X(b) + e_S^Y(b)；e(ΔN) = e(ΔS) + e(ΔH)；e(u_B) = c·u·(‖B^X‖ + ‖B^Y‖)；e(‖ΔA‖) = c·u·(‖A^X‖ + ‖A^Y‖)；对形如 ΔA·Z̄ 的源项，e = max_h‖ΔA_h‖_F·ē_Z + c·u·max_h‖ΔA_h‖_F·‖Z̄‖；读出界 = 状态界 × max‖q‖。
4. **可分辨**：量 > **10 ×** 其界。低于门槛记"未分辨"，不当作零效应或等效性证明；高于门槛也不是统计显著性或泛化声明。
5. 恒等式检查（S=H+N、ΔH/ΔN 递推、u_H+u_N、D+W+R、Δo 两项）的相对残差 ≤ 1e−8，否则工程停止。

零值说明（研究准则 6.3）：本阶段的待排除解释都是"某项严格相同"，在确定性前向里对应的零就是数值舍入，所以零分布由 1–2 的数值界给出，并在第 2 条用实测误差校验。S1 那种描述性切点（抵消比等）本阶段**不用作任何判据**。

## 7. 次要时序预测（计划 §7；S1 与 v2 事前登记，阈值不改）

t_L 处用内核自己的状态，按"两事实 × 三层"等权堆叠成向量：

- r10 = ‖S10 − S00‖ / ‖S11 − S00‖，预测 **r10 < 0.5**（两锚点、逐情景）。
- a01 = ⟨ΔS01, ΔS11⟩ / ‖ΔS11‖²，e01 = ‖ΔS01 − ΔS11‖ / ‖ΔS11‖；a01 ≥ 0.5 且 e01 ≤ 0.5 记为"目标状态近似重现"。
- 逐情景 **L0 的 r10 高于 L12**。

失败或异质照实报告；任何一条都不单独判定过程机制。分母不可分辨时不算比例。另报分层、分事实值。

## 8. 失败类型与停止条件

- G1–G6 或 §5.2、§5.5 不过：**合同执行失败**，信息量为零，不当负面证据。
- 判决全部为"未分辨"：没拿到结果（在所测精度下未发现偏离），不是零效应证明。
- 预测失败：科学失败，照实报告。
- 停止：preflight 任一闸门不过即不进 formal；formal 任一记录不过即整轮停止，保留部分记录；分析工程检查不过即不出判决；规模超 §2 上限即停。
