日期：2026-10-31（UTC）。计划 `CFM-S2-v3-20261031`；合同 r01；冻结 freeze-r02（提交 18cc5b6，sha `ad542329…`）；运行 preflight-r02、formal-r01；分析 `analysis/formation-r01.json`。

## 0. 先说不利的部分

1. **计划 §6 的排除表区分度很低：每个锚点、每个配对的 36 个格子，所有待检验解释全部被反驳**（E1–E5 均为 36/36，没有"未分辨"格，也没有 E6 格）。这在设计上几乎是注定的：这些解释都是"某项严格相同"，而 01、11 臂在窗口内直接开着针，驱动量当然会变。表本身成立，但它只排除了严格相等的解释，**本阶段真正的信息在第 3–5 节的幅度与方向上**，那些都是描述，不是判决。
2. **S1 报告登记的次要预测 r10 < 0.5，在 L0 的 6 个情景里全部失败**（0.57–0.64），L12 有 5/6 成立（VAR01 为 0.54，不成立）。这是科学失败，照实记录。"L0 的 r10 高于 L12" 6/6 成立。
3. **第一次 preflight（r01）是合同执行失败**：收尾的规模检查有代码错误，KeyError 崩溃。已修正，补测试后重新冻结为 r02；判据和设计没改（决策日志第 8 条）。
4. 本阶段不识别写入与处理各自的独立因果贡献、原发原因、跨层路径，也不识别对回答的必要性（计划 §6 末段）。

## 3. 共同起点后的第一步（b+1）

| 配对 | u_H / u_B（范围，中位） | cos(u_B, u_H)（中位） | u_B / ‖S_b‖（中位） |
|---|---|---|---|
| L0 01v00 | 0.30–0.69（0.46） | −0.44 | 0.16 |
| L0 11v10 | 0.44–0.91（0.60） | −0.52 | 0.30 |
| L12 01v00 | 0.40–0.78（0.50） | −0.54 | 0.21 |
| L12 11v10 | 0.34–0.70（0.44） | −0.58 | 0.24 |

- 从**同一份旧状态**出发，第一步就同时出现写入差异和处理差异。处理项约为写入项的一半，方向与写入**部分相反**（余弦 −0.24 到 −0.73）。
- S1 观察到的写入与处理反向抵消，因此**不是两条轨迹历史不同造成的**：同起点时它在第一步就出现（推导：delta rule 修正项 −αβk kᵀS 与写入项 βk vᵀ 共享 β、k，同一次更新内部即可部分抵消；这里是在共同 S_b 上实测到的）。
- 同起点格里没有出现零空间情形：只要算子变了，它对这份旧状态的作用就可分辨。

## 4. t_L 处的状态与读出由什么构成

对 ΔS 的投影份额与读出份额（两事实 × 三层 × 六情景合并）：

| 配对 | ΔH 份额 | ΔN 份额 | 读出：ΔHᵀq̄ / ΔNᵀq̄ / 查询项 | 平均 ‖ΔH‖ / ‖ΔN‖ / ‖ΔS‖ |
|---|---|---|---|---|
| L0 01v00 | −0.01 | 1.01 | −0.09 / 0.69 / 0.40 | 1.09 / 3.15 / 2.91 |
| L0 11v10 | −0.03 | 1.03 | −0.15 / 0.93 / 0.22 | 1.06 / 3.16 / 2.89 |
| L0 10v00（不同起点） | 0.12 | 0.88 | 0.05 / 0.56 / 0.39 | 0.92 / 1.91 / 1.92 |
| L12 01v00 | −0.00 | 1.00 | −0.04 / 0.91 / 0.13 | 0.64 / 2.52 / 2.42 |
| L12 11v10 | −0.01 | 1.01 | −0.01 / 0.90 / 0.11 | 0.62 / 2.53 / 2.42 |
| L12 10v00（不同起点） | 0.43 | 0.57 | 0.21 / 0.64 / 0.15 | 0.73 / 0.83 / 1.10 |

- **共同旧来源确实被不同地处理了**：‖ΔH‖ 在 t_L 达到 0.6–1.1，不小（E2 被反驳）。但它与总差异 ΔS **几乎正交**（份额 −0.03 至 0），在读出上还略为负（−0.15 至 −0.01）。t_L 的状态差异和读出差异几乎全部来自 b 之后写入的来源 N。
- 10v00（不同起点，ΔH 含早段针直接留下的差异）：L12 有 43% 的 ΔS 来自 b 时已有的来源，L0 只有 12%。L12 的早段针差异更多以"被带下来的旧差异"形式存在；L0 的早段针在撤针后靠新的写入差异维持。
- 查询项在 L0 占读出差的 22–40%，在 L12 只占 11–15%。

| 臂 | L0：首步 EOS / D 范围 / S_fact 范围 | L12：首步 EOS / D 范围 / S_fact 范围 |

- L0 出现分离：**停嘴需要后段针**（01 的 EOS 10/12，10 为 0/12，D 接近干净）；**事实使用的破坏主要来自早段针**（10 的 S_fact 降到 −0.1–5.3，而 01 还保留到 0–10.9）。这与 2026-10-29 早层失效定位第一阶段"前半段污染导致作答但答错，后半段污染导致不交付"的结论一致（类比档：那次是拼缓存，这次是原生时序开关）。
- L16–18 状态差异的大小与这一分离对不上：L0-10 的 r10 约 0.6，却完全不停嘴。停止不由这一窗口的状态差异范数决定，与 S1 一致。
