## 1. 结论（含限制）

1. **等价前提成立**：48/48 个单元上，010 = EH-XC XH11，011 = EH-XC X10，110 = EH-XC H01（logits 逐位相同）。单步评分时，浅层缓存只通过第13层入口影响深层（只限本轮固定 token 的单步读出）。
2. **没有任何单一因素能撤回大部分原生变化，也没有任何单一因素单独保留就能维持大部分。** 单因素恢复占 N 的比例（方向均值）：入口 X 0.10–0.20，深层卷积 F 0.33–0.48（已知值复核；C1343 有 4/12 个输入 ≥0.5），深层历史 H 0.21–0.29（已知值复核）。单因素保留：只保留入口 L_X 0.08–0.13，只保留卷积 L_F 0.33–0.42，只保留深层历史 L_H 0.33–0.40；48 个单元中没有一个达到 0.5。
3. **预注册**：P_X（只撤入口回退 <0.5N）4/4 方向支持（每方向 6/6 情景）。P_XH（入口与深层历史的二阶交互 ≥τ）3/4 支持：N4146、N1210、R0 都是 12/12 为正；C1343 只有 6/12，判为未支持。
4. **组合明显不可加，且形状一致：两两恢复超加和，三者一起恢复则大幅次加和。** 二阶项 i_XH（+1.4 到 +4.1）与 i_FH（+2.2 到 +4.1）在几乎所有单元为正，i_XF 在 N1210/R0 多为正、在 N4146/C1343 为小；三阶项 i_XFH 在四个方向 48/48 个单元都为明显负值（−3.0 到 −6.2）。可加相容只有 2/48。读法：恢复任意两类时，回退超过单独之和；但第三类再恢复时，增量远小于两两预测（条件二阶项 i_ij + i_XFH 多为负或接近 0），呈饱和形状。这是恢复效应的代数描述，不证明同一信息被多处存储，也不证明发生了动态补偿。
5. **D 上的形状大部分不在固定候选 Q 上重现**：Q 上，单因素恢复的和（约 26–29）**超过** Q 的总变化（约 19–20），三元可加残差 E 为 −4.9 到 −7.7（D 上为 +0.6 到 +4.1），多数交互项为负。也就是说，在“停止词 vs 干净首词”这个固定候选差上，三类状态各自都能恢复很大一部分（彼此冗余）；而在“停止 vs 当前最强非停止词”的竞争差 D 上，需要组合恢复才能扳回，因为另一个非停止词会顶上来。D 上的非加和相当一部分来自竞争者更替（每方向有 4–8 个单元的 i_XH、i_XFH 在 D 上明显、在 Q 上为小）。

## 4. 出口与含义

- 对应出口“三阶仍明显且 Q 上同向”（Q 上的三阶项在三个方向为负，C1343 为 +0.3）与“三类单独都弱、组合不可加”的组合：原生干预造成的竞争变化，由入口、深层卷积、深层历史**共同**维持，任何一类单独都既撤不掉、也保不住大部分；成对恢复超加和、三者一起时饱和。按合同，没有可失败的计算预测就到此止步，不继续把因素切得更细。
- 课题层面最重要的两点：(1) 原生行为离停止门槛很近，任何一类状态的恢复都能翻转首步，但分数变化是分布式、强非加和地维持的；(2) 在固定的“停止词 vs 干净首词”读数上，三类状态彼此冗余（单独恢复之和超过总变化），而在实际竞争差上则表现为需要组合，差别来自非停止竞争者的更替。后续如果要研究“回答为什么改变”，竞争者更替（哪个非停止词顶上来、为什么）是一个比继续拆状态更直接的对象。

## 5. 可以说 / 不可以说

| 可以说 | 不可以说 |
|---|---|
| 单步评分时浅层只经第13层入口影响深层（48/48 逐位） | 这一等价对自由生成成立 |
| 单独撤回任一类状态回退 ≤ 约一半原生变化；单独保留任一类维持 ≤ 约四成 | 原生变化“储存在”某一类状态 |
| 两两恢复超加和、三者恢复次加和（48/48 三阶为负） | 证明了冗余存储或动态补偿 |
| 只撤入口就让首步停止消失，但入口只占 10–20% 的分数变化 | 入口是原生停止的主因 |
| 固定候选上三类状态彼此冗余，竞争差上需要组合 | 原生行为变化是事实丢失 |
