## 1. 操作

沿用 SK-01 的模型、revision、BF16、内核、token、晚段窗口、L0 剂量 −1、四方向（N4146、N1210、R0、C1343）、12 条输入、worker/GPU 分配、进程内校准。每输入形成 C、评分 C_native；每方向形成 T，然后从完整 T 缓存出发，把以下因素的任意子集恢复为同输入的 C 供体，共 8 格（位 = X F H，1 = 恢复）：X = 第0–12层全部缓存分量；F = 深层 G 层的卷积缓冲（q/k/v 全部通道）；H = 深层 G 层递推 S + 深层全注意力 keys 与 values。全部格自然入口、不挂任何入口 hook；000 即 T_native。

校准、GPU 分配等于 B3；L0 写入 ≤1%；层列表与固定配置一致；**重放**：000 = EH-XC T_native，001 = SK P_SK0，111 = C_native（= EH-XC C_native）；**等价前提**：010 = EH-XC XH11，011 = EH-XC X10，110 = EH-XC H01（logits 逐位）；自然入口：X 恢复时等于 x_C，否则等于 x_T（逐位）；每格 X、F、S、KV 四类分量分别哈希并与来源表一致；供体前后哈希不变；每格 14 个 G 内核各一次、chunk 为 0、评分时无形成 hook；首输入记录器开/关逐位一致。

## 4. 读数与判读（`nr_core.RULE`）

D = 停止最大 − 非停止最大；同时算固定候选 Q/A/B 版本。N = D(P) − D(C_native)；R(A) = D(P) − D(恢复 A)；r_i、i_ij、i_XFH 按标准 2³ 分解，N = Σr + Σi_ij + i_XFH；条件二阶项 i_ij + i_XFH；保留 L(i) = N − R(其余两类)；三元可加残差 E = N − Σr。只在 N ≥ 1 的输入上形成比例与标签；所有格照常执行。

- **预注册（推测档，仅未见量）**：P_X：R(X) < 0.5N；P_XH：i_XH ≥ τ，τ = max(0.5, 0.1N)。方向内两事实都满足、≥5/6 情景记支持；≥5 个情景两事实适用但支持不足记未支持；否则适用不足。跨方向报告 k/4。
- **描述（分别报告，可同时成立）**：单因素强恢复 R(i) ≥ 0.5N；单因素保留占多数 L(i) ≥ 0.5N；各交互项按 ≥τ 正、≤−τ 负、其余为小；可加相容 = 三个 i_ij 与 E 的绝对值都 <τ；反向或过度恢复原值报告。R(F)、R(H)、R(XF)、R(FH) 及由它们决定的量标为**已知值复核**（冻结前已见）。
- D 上明显而 Q 上为小的交互，只说竞争集合层面的非加和。距判据边界 ≤0.125 的单元单列为精度敏感。
- 措辞：联合恢复强不等于三阶交互强；“恢复效应超加和”与冗余/替代相容，但不证明同一信息或动态补偿；浅层/入口等价只限本轮固定 token 的单步读出。

## 5. 出口

见计划 v1 §9：某类单独保留仍维持 ≥ 半数 N → 该反事实背景下的幅度充分性；三类单独恢复都弱且组合近可加 → 多个中等作用叠加，结束分账分支；二阶明显而三阶小 → 成对项描述；三阶明显且 Q 同向 → 条件性约束；方向差异 → 保留异质性；全恢复或等价闸门不闭合 → 工程或因素完整性失败，不解释为未知机制。
