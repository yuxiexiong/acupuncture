# QCO-01（跨记录共同 q/k 偏移能否双向搬运回答效应）结果报告

日期：2026-11-02。[合同 r01](CONTRACT.zh-CN.md)；[决策 D1–D4](DECISIONS.zh-CN.md)；计划 v1（905a6d19，评审撰写）。代码 `3fcb81d`，freeze-r01 `a607db70…1060`。R/A/R_rand/A_rand 运行前无输出。同一助手实现、运行与撰写。

## 1. 结论（限制先说）

1. **限制一：等范数随机方向本身也有不小作用，尤其在 N4146。** 把同范数（约 530–560）的随机向量加到干净 q/k 上（A_rand），也会逐 token 复现 V 的错误：N4146 35/48（B_rand = 0.64）、N1210 31/48（0.32）、R0 38/48（0.18）；从受针 q/k 减随机向量（R_rand）则通常更差（P_rand = −0.06 / −0.34 / −1.05，并把 2 / 7 / 11 个原本答对的格改坏）。所以“q/k 被大幅扰动 → 首列错误”有相当一部分不依赖方向；共同偏移的方向特异性体现在它比随机好得多，而不是随机无效。
2. **限制二：这是混合状态下的操作效果**（V 取 C(i)，S/KV/浅层取 T(i,d)），在已见开发面板、六个场景、NA 原布局宽窗口上；六折不是六次独立实验。
3. **预注册的“双向搬运”在全部 3 个适用方向成立（C1343 无缺口、不适用）。**
   - 去除（R = 受针 q/k − 共同偏移）：N4146 16 → 47/48，N1210 28 → 48/48，R0 38 → 48/48；P = 0.97 / 1.00 / 1.00；6/6、6/6、4/4 个有缺口的场景净改善为正；没有改坏任何格。
   - 加入（A = 干净 q/k + 共同偏移）：逐 token 复现 V 的自然输出 48/48、47/48、46/48；在原错误格上 B = 1.00 / 0.93 / 0.77；6/6、6/6、4/4 场景出现复现。
   - 与随机参照的差：P − P_rand = 1.03 / 1.34 / 2.05；B − B_rand = 0.36 / 0.61 / 0.59，都超过 0.25 的门槛。实际编辑范数与随机参照逐输入相同（相对差 ≤5% 全部通过）。
4. **几何（描述）**：每个输入的受针 q/k 改变与“用其他 5 个场景估计的共同偏移”几乎同向——cos 均值 0.97–0.99（最小 0.90），减去共同偏移后只剩 3–7% 的平方范数。受针造成的末端 q/k 改变几乎是一个跨记录共享的加性偏移。
5. 按计划 §7 第 1 行：**支持“用其他场景估计的共同差分可部分（在这里几乎全部）解释该背景中 V-only 的行为变化”**；下一个问题才是这个偏移通过什么更新/读取计算起作用。不能说原生机制已闭合、所有针共享一个方向，或查询信息被删除。
6. 工程全部通过：base/C/T 哈希 = QCD G；624 条参照与 QST 逐位相同；预检零偏移无操作逐位复现 V/F；采集张量哈希经偏移脚本复核。

## 4. 可以说 / 不可以说

| 可以说 | 不可以说 |
|---|---|
| 受针造成的末端 q/k 改变几乎是跨记录共享的加性偏移（cos 0.97–0.99） | 所有针共享一个方向（四个方向各自估计） |
| 去掉这个由其他场景估计的偏移，V-only 的错误几乎全部消失；加上它，干净 q/k 逐 token 重现原错误（3 个适用方向） | 原生运行中针只通过这一偏移起作用；机制已闭合 |
| 同范数随机方向也有可观作用（A_rand 复现 18–64%），共同偏移明显优于随机 | 方向完全特异；大幅扰动无关 |
