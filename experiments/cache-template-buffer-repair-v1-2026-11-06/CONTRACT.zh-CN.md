# FBR-01 合同 r01：不看答案的模板缓冲修复

**状态：阶段 A 已冻结（`freeze-A-r01.json`），未获运行授权、未运行。** 2026-11-06，用户"推进吧"之后完成运行器、CPU 测试、就绪检查与冻结，全部零 GPU，没有任何模型输出。上卡以用户"开始"为准。阶段 B 的面板与参照文件在阶段 A 之后生成并另行冻结。规划与设计自查见[规划文档](../../docs/experiment-plan-template-buffer-repair-2026-11-06.zh-CN.md)与 [DESIGN.zh-CN.md](DESIGN.zh-CN.md)。冻结后不改本文件；偏离记入 `DEVIATIONS.zh-CN.md`。同一助手撰写与实现，不是独立审查。

## 1. 问题
LVK-01 的 F 臂已显示：只在 t1 之前把 14 个递推层的卷积缓冲换成本输入干净运行的值，原生受针运行在 48 条新输入、四个方向上都是 48/48 答对（原生 0 到 1），递推状态与 KV 不动。本合同问：**不运行本输入的干净版本，只用其他输入的干净卷积缓冲，原生受针运行能修回多少；这种修复是否超过同幅度的任意改动。**

承诺的只是"在这些输入上，这种缓冲替换足以修复完整回答"。不承诺缓冲是唯一受损处，不承诺递推状态与 KV 未受损，不承诺这是模型自然的失败路径。

## 2. 固定条件
Qwen3.5-4B revision `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`，BF16/eager/batch 1/torch 原核。L0 形成干预、NA 布局、B1 窗口、−1 强度、冻结校准、G={13,14,16,17,18,20,21,22,24,25,26,28,29,30}、解析器与停止 ID 全部继承 LVK/NWR。方向：N4146、N1210 为主要；R0（随机施针）与 C1343 为诊断。

## 3. 操作
每输入重建干净缓存 C 与各方向的原生受针缓存 T（边界在最后一个提示 token 之前）。**只改 T 在 14 个 G 层的卷积缓冲状态（`conv_states`，q/k 通道 0–4095、V 通道 4096 起，全部槽），其余张量逐字节不动。** 之后做 t1 前向与贪心续写到停止或共 32 token。全程不挂任何钩子。

| 臂 | G 层卷积缓冲的来源 | 用途 |
|---|---|---|
| T | 原生受针，不改 | 下限 |
| F_own | 本输入的 C | 上限，看答案；阶段 A 须与 LVK 的 F 臂逐位一致 |
| **F_mean** | 参照集里其他结构族全部输入的 C 缓冲，逐层逐元素取平均（FP32 平均后转回缓存精度） | **主臂** |
| F_one_s / F_one_o | 一条参照输入的 C 缓冲：同族下一条 / 下一个结构族的第一条 | 单条参照够不够 |
| VmK | V 通道取 F_mean 的 V 通道；q/k 通道取原生值并按已冻结的共同 k 偏移向量做去偏移（QCO 的编辑，向量来自其他五个场景） | 两向量版本，与写入—读取链对接 |
| F_dmean | 参照集里其他结构族全部输入的**原生受针**缓冲的平均（同方向） | 对照："平均"本身是否足够 |
| F_zero | 全零 | 对照：抹掉受损缓冲是否足够 |
| R1…R20 | 原生缓冲加随机改动：逐层，改动的 Frobenius 范数等于该层（F_mean − 原生）的范数，方向为（种子，层）固定的随机张量；种子 202611201…220 | 对照：同幅度的任意改动是否足够 |

**参照集。**
- 阶段 A：LVK 新面板自身，留场景法。先跑一个**标定阶段**：对 48 条输入各形成一次 C 与四个方向的 T，只读出 G 层卷积缓冲并存档，不做任何生成；再由 CPU 把它们汇成一份参照文件（哈希写入后续授权）。某输入的 F_mean、F_dmean 取其他五个场景全部输入的平均（场景大小 6 到 9 条不等，所以参照集是 39 到 42 条），不含它所在场景的任何输入。F_one_s 取同场景账本顺序的下一条，F_one_o 取下一个场景的第一条。
- 阶段 B：**阶段 A 结束后把 LVK 新面板 48 条的干净缓冲按"留出目标输入所在结构族"算好六份平均，写成固定文件并冻结哈希。** 阶段 B 的新输入只读这份文件，不用新面板自己的任何干净运行来构造 F_mean、F_one、F_dmean。F_own 仍用新输入自己的 C，只作上限。

## 5. 冻结判读（看任何新输出前写定；实现在 `fbr_core.py`；每个标签与结局已在合成数据上出现过，见 `analysis/rehearsal_output.txt`）
主终点 Y：自然完整回答正确（FC-01 分类器原规则）。比率按族等权；阶段 A 只有一个族，比率即 48 条输入的合并比例。区间：族内对聚类单位有放回重抽 10000 次，种子 20261106，取 95% 百分位下界。阶段 A 的聚类单位是场景（6 个），阶段 B 是基础情境（24 个）。每个方向分别判读。记 g_X = Y(X) − Y(T)。

| 标签 | 成立的条件 | 不可判 | 成立时允许写的句子 | 不允许写的句子 |
|---|---|---|---|---|
| DMG | Y(T) ≤ 0.25 | — | 这块面板上原生受针运行确实坏了 | — |
| UP | Y(F_own) ≥ 0.75 | DMG 不成立 | 换回本输入自己的干净缓冲足以修复 | 缓冲是唯一受损处；其余状态未受损 |
| **PA** | Y(F_mean) ≥ 0.90·Y(F_own)，且 g_mean 的下界 ≥ 0.50 | DMG 或 UP 不成立 | 不运行本输入的干净版本，用其他结构族输入的平均干净缓冲，即可把原生受针运行修回到接近上限 | 对任何提示模板都成立；对任何干预都成立；这是自然失败路径 |
| **PB** | 20 个同范数随机改动里，g ≥ 0.5·g_mean 的至多 1 个 | g_mean < 0.25 | 抽到的 20 个同幅度随机改动里至多 c 个达到修复增益的一半，总体比例 95% 上界为 x | 任何同幅度改动都无效；修复依赖特定方向已被证明 |
| PC | g_zero < 0.5·g_mean | g_mean < 0.25 | 把缓冲清零达不到修复增益的一半 | — |
| PD_s、PD_o | Y(F_one) ≥ 0.90·Y(F_mean) | Y(F_mean) < 0.25 | 一条同族（或异族）参照输入的干净缓冲与平均缓冲效果相近 | 任意一条输入都可作参照 |
| PE | Y(VmK) ≥ 0.75·Y(F_own) | DMG 或 UP 不成立 | 只换 V 通道的平均值并减去共同 k 偏移，可达到上限的大部分 | q 通道无关；修复可分解为两个独立向量的贡献 |
| PF | g_dmean < 0.5·g_mean | g_mean < 0.25 | 用其他输入的受针缓冲的平均达不到修复增益的一半 | — |

计数的总体上界（两侧 95% Clopper–Pearson）：0/20 为 16.8%，1/20 为 24.9%，2/20 为 31.7%。PB 是有限样本的操作门槛。

**每个方向的结局（取第一个满足的）。**
1. **无损伤可修**：DMG 不成立。全部不可判。
2. **上限不迁移**：UP 不成立。本线在该方向停止。
3. **修复成立且超过随机改动**：PA、PB 都成立。
4. **修复成立但不超过随机改动**：PA 成立，PB 不成立或不可判。修复仍可写，"恢复了干净内容"不写。
5. **缓冲带输入特有信息**：UP 成立而 PA 不成立。报告 F_one 同族与异族的差别，不追加定位。

**总读法。** 阶段 B 上 N4146 与 N1210 的结局都是 3 或 4：修复在既有结构族内、同一指令尾巴的新输入上得到确认。只有一个方向如此：写该方向的局部结论。R0 与 C1343 同口径报告，不替代主要方向。

**看数据前登记的预期（推测档）。** UP 在四个方向都成立（LVK 已见 48/48）。PA 多半成立：旁证是干净 q/k 在模板位上几乎相同（QST-01）和损伤补丁跨输入余弦 0.91 到 0.96（NWC-01）；V 通道没有直接数据，这是主要风险。PB 没有把握：NWC 显示读取处同幅度随机扰动经常有效，缓冲处是否如此未知。PF 多半成立。PE 在 C1343 上应成立，其余方向没有把握。

**只作描述、不设门槛。** 各臂的错答类型与首步是否开口；干净缓冲与"受针减干净"之差的跨输入余弦（分 q/k 与 V、分层）；阶段 B 按目标位置分层的各臂正确数。

**退出。** 阶段 A 任一主要方向的结局是 1、2 或 5：不进阶段 B，回到规划文档的取舍。阶段 B 结束即结束本卡，任何结局都不追加层、头、通道定位。结局 3 或 4 才展开下一张卡（适用边界）。

## 6. 工程闸门（任一失败即停，记为合同执行失败，不是科学阴性）
1. 面板：输入文件与分词账本哈希；运行中 token 等于账本。
2. 桥接（阶段 A）：T 与 F_own 的 t1 bf16 logits、首 token、自然 token 序列分别与 LVK 记录的 L00 与 F 臂逐位一致。
3. 编辑范围：每个臂的缓存与 T 相比，只有 14 个 G 层的卷积缓冲不同，其余全部张量逐字节相同；F_own 的缓冲逐位等于 C 的；VmK 的 q/k 通道槽 0 不变。
4. 参照缓冲：正式运行里重新形成的 C 与 T 缓冲逐位等于标定阶段存档的同一输入的缓冲；单条缓冲的平均等于它自己；参照集不含目标输入所在场景（断言，CPU 测试在真实账本上验过）。
5. 随机改动：逐层范数相对误差 ≤ 1e−5；目标范数为 0 的层不改；种子与层固定方向，跨输入不变。
6. 全程无钩子；核函数未被替换；源缓存哈希不变。
7. 阶段 B 的参照文件：哈希等于冻结值；构造时不读任何阶段 B 输入。
8. 预检：阶段 A 取 NQ01-ABC-A 与 NQ02-ABC-B 两条、全方向全臂；阶段 B 取两条新输入。失败即停，每阶段允许一次有记录的修复重试。阶段 B 的预检输出在预检时即被看到，如实登记。
9. 闸门只写对被检对象本身成立的关系。本卡的全部操作都在 t1 之前的缓存上，不涉及跨层前向依赖；这是 NWC-01 偏离 D1 的教训。
