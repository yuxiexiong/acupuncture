# NFC-01（原生首步竞争：逐段链条与 B4 分支）结果报告

日期：2026-11-02。[合同 r01](CONTRACT.zh-CN.md)；[决策 D1–D4](DECISIONS.zh-CN.md)；计划 [v1](../../docs/cache-native-first-token-competition-plan-v1-2026-11-02.zh-CN.md) + [v2](../../docs/cache-native-first-token-competition-plan-v2-2026-11-02.zh-CN.md)。代码 `9261f90`，freeze-r01 `c824bc57…5260`。零模型调用、零 GPU（CPU 12 秒）。已见数据上的探索性再分析；同一助手实现、运行与撰写。

## 1. 结论（不利与限制先说）

1. **固定45头那一段只承担原生竞争变化的三到四成；更大的一段在进入 N 背景时就已经发生。** 原生 ΔD（停止最大 − 非停止最大，原始 logit）为 12.6–14.2。逐段均值：e1（C_native→N:CC）7.9–8.4，e2（固定45头的 V 历史）4.5–6.3，e3（其余头的 V 历史）−0.4 到 +0.5，e4（CC→TT 的剩余卷积历史）−0.2 到 +0.2。绝对集中度：e1 0.54–0.63，e2 0.33–0.43。预注册的 P1（最大段为 e1）成立：4/4 方向、每方向 6/6 情景。
2. **e1 是复合转换，不能归因于单个变量。** N:CC 相对 C_native 同时改变了深层（第13–31层）的递推状态 S、深层全注意力 KV，以及第13层入口残差 x_T（它携带了浅层在当前 token 上受到的影响）；卷积缓冲（q/k/v）仍是 C。本轮没有把 e1 拆开。
3. **辅助对应表（v1 分档）24/24 判为“同向但幅度不同”**：e2 约为原生变化的 35–45%。按 v2，这一条不再用来否定 45 头与原生的对应；它是因为 N:CC 已经吸收了 e1。
4. **首步翻转在这条链上都发生在 e2，但这是顺序造成的。** N:CC 的 D 仍为负（N4146：−5.8 到 −3.4；R0：−5.1 到 −3.4），也就是说，仅靠 e1 不足以翻转首步；再加上 FIX 的 V 历史后，D 越过 0（N4146 的 N:CFIX：0.4 到 1.4）。在 N4146、N1210、R1 中，12/12 的翻转都落在 e2；R0 原生几乎不停止（11/12 两端都不停止），它的 N:CFIX 也正好贴着零点（−0.4 到 0.3）。换一种顺序，翻转可能落在别的段，所以这只是这条链上的条件描述。
5. **e3 ≈ 0 是两项大量相消**：在 D 读数上，R_D（其余头单独）+2.7 到 +5.1，I_D（交互）−3.2 到 −4.6。不能把 e3 称为负交互。

## 2. 原生变化在两侧的构成（描述）

- 停止赢家始终是 248046（A = 0）。原生 ΔF（248046 对干净首词 q0 的差）为 18.4–19.9，其中 4.4–6.4 被另一个非停止词顶替 q0 成为新的最强竞争者吸收（ΔB），所以 ΔD 比 ΔF 小。
- 以词表均值为参照：248046 相对上升 6.5–7.2，q0 相对下降 11.7–12.7；以中位数为参照符号相同（各段、原生均 12/12 一致；只有 R1 的 e4 是 9/12）。在两种参照下，**干净首词被压低的幅度都大于停止词被抬高的幅度**，但两侧都显著。这是相对位置的描述，不是“通路份额”，也不等于事实丢失。
- 各段的构成：e1 几乎全部是 F（赢家不变）；e2 是 F 5.7–7.2，其中 0.6–2.0 由非停止赢家更替吸收；e3 是 F 3.1–5.0，但几乎全部被赢家更替吸收（B 2.8–5.1），所以对 D 的净作用约为 0。

## 4. 执行

闸门全部通过：B3、B4 记录按 receipt 核对哈希；48/48 个 N:TT 与 T_native 逐位相同；B3/B4 接头（C_native、T_native、CC、CFIX）逐条相同；q0 = a_token；存储的全词表 logits 与记录逐值一致（D 误差 0）；D 与记录的 stop_advantage 一致（误差 0）；伸缩恒等式误差 0。有 12 个单元 D 恰好为 0（BF16 logits 在约 20 的量级上间隔 0.125，平局并不罕见），出现在 N:CFIX ×3、M_nat ×4、K ×2、T_native/N:TT ×1、N:CREST ×1。这些单元按记录的首步选择报告，不计入符号一致性检查。

## 5. 对课题的含义与出口（合同 §5）

- 按出口规则：撤回“δ_FIX 不接近 δ_native 就否定对应”的判法。**原生首步变化在这条链上分成两块相当的部分**：一块在进入 N 背景时发生（深层 S、深层 KV、入口 x_T 的复合，约 55–63%），一块是固定45头的 V 卷积历史（约 33–43%）。其余头的 V 历史和剩余卷积历史净作用约为零。
- 这说明此前几轮在 N 背景里研究的 45 头机制，对应的是原生变化中真实存在、但不是最大的那一块。“稀疏干预为什么造成回答变化”这条机制链，现在缺的主要是 e1。
- 下一步（未设计、未授权）：如果要继续，最有信息量的一步是把 e1 拆成三个变量（深层 S、深层 KV、入口 x_T），在原生背景附近做逐项替换，看哪一个承载了这约 8 logit。这需要重新形成缓存，要上 GPU，而且要先确认它能给出可被推翻的预测。之前的 CFM-COMBO 发现单步评分时深层效应主要在卷积缓冲、KV 小，可以作为先验；但那一轮的分解方式与这条链不同，不能直接搬用。
- 答案侧：两种参照都显示，干净首词被压低的幅度大于停止词被抬高的幅度；K 与 M_nat 也主要作用在这一侧。答案侧值得单独立题，但必须先解决 M_nat 的混淆。
