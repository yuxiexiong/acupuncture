## 1. 要回答的问题

在**同一运行条件**下，模型对两种事实（f0 与 f1）的区别，在以下各处怎样变化：

1. 撤针时（τ）的全层缓存，包括 32 层的递推状态与全注意力 KV；
2. L16–18 每一步的新 value v、旧记忆预测 m = (αS_{t−1})ᵀk̂、实际修正量 e = v − m，以及读出 o = S_tᵀq̂。

并据此在三种情况之间作**约束性**判断：

- 情况 I：value 里的事实区别已经变弱；
- 情况 II：value 里还在，但在减去旧记忆预测后、实际修正中变弱，即"匹配关系"假说；
- 情况 III：局部读出里事实区别仍在，但候选分数对事实不敏感。

本分析是约束，不是因果证明。所有结果都是在原生轨迹上的描述，不改动任何前向计算。

## 2. 记号与量

- 条件 X：00（干净）、10、01、11，两个锚点 L0/C4146/−1、L12/C3621/−1。情景：VAR01、VAR02、VRD01、VRD02、VRL01、VRL02，f0 与 f1 位置对齐。
- 事实区别：D_X(·) = 量(f0 运行) − 量(f1 运行)，同一条件、同一位置、同一层与头。
- **参照方向**：干净运行的事实区别 D_C。理由：干净模型用这份区别答对了题。
- 对任一量，把位置、头（以及适用时的矩阵元素）合并后，报告三项：
  - **保留系数** ρ = Σ⟨D_X, D_C⟩ / Σ‖D_C‖²，即沿干净方向保留了多少；
  - **方向余弦** cos = Σ⟨D_X, D_C⟩ / √(Σ‖D_X‖² · Σ‖D_C‖²)；
  - **范数比** r = √(Σ‖D_X‖² / Σ‖D_C‖²)。
- 位置类：
  - F = 第一个 f0/f1 不同 token 到 b（事实段末）；
  - post = b+1..n−2（问句、指令、模板尾）；
  - last = 末提示 token；
  - cand = 候选位置。

  第一个不同 token 之前的位置，事实区别恒为 0，不计入。

## 3. 分析一：撤针时全层的事实区别（Mτ）

- 递推状态：对每个线性层 ℓ，D_X = S_ℓ(f0) − S_ℓ(f1)（32 头 × 128 × 128），在 τ 处计算 ρ、cos、r。
- KV：对每个全注意力层，F 位置的 K、V 与 post 位置的 K、V 分开计算 ρ、cos、r。
- 卷积缓冲（最后 3 个 post 位置）只作报告，不入判读。
- 产出：两锚点 × 三个带针条件 × 6 情景的"事实区别随深度"曲线。

判读规则（事先写死）：

- 对每个（锚点、条件、情景），**首个弱化层**定义为从 L1 起、递推状态 ρ ≤ 0.5 的第一层；若没有，记"未弱化"。
- KV 在 F 位置的 ρ 单独报告。KV 写入后不衰减、不擦除，所以 F 位置 KV 的 ρ 低，只能来自 F 写入时的差别，不能来自后续保留或擦除（推导档）。

## 4. 分析二：L16–18 每一步的 v、m、e、o

- 由 S2 记录的驱动量，用 S1 的 float64 递推重建每步状态（S2 已验证：与内核暴露状态的误差 ≤ 界的 1.25%）。按源码约定：k̂、q̂ 经 l2 归一化，q 乘 d_k^{−1/2}；α = exp(g)。
- 每步计算 v、m = (α_t S_{t−1})ᵀk̂_t、e = v − m、o = S_tᵀq̂_t（按头），对每个量求 D_X 及 ρ、cos、r。
- 位置类分开报告 F、post、last、cand；判读用"post + last"合并（事实必须经这些位置才能到达答案）。三层分开报告，判读用三层合并。

判读规则（事先写死；条件 X ∈ {10, 01, 11}，与 00 比较）：

| 情况 | 条件 |
|---|---|
| I value 已弱 | ρ_v ≤ 0.5 |
| II value 仍在，修正中变弱 | ρ_v > 0.5，且 ρ_e ≤ 0.5 · ρ_v |
| II′ 写入仍在，读出中变弱 | ρ_v > 0.5、ρ_e > 0.5 · ρ_v，且 ρ_o ≤ 0.5 |
| III 局部读出仍在，候选不敏感 | ρ_o > 0.5，且候选事实敏感度比 S_fact(X)/S_fact(00) ≤ 0.5 |
| 未分类 | 其余 |

- 0.5 是描述性切点，所有连续值同时报告。cos 与 r 用于说明 ρ 的变化是方向偏转还是幅度缩小，不进判读。
- 若分析一显示事实区别在 L16 之前已经弱化（首个弱化层 < 16），则 L16–18 的情况 I 只读作"进入本窗口时已弱"，**不**判为"形成端问题"。这是用户补充第 1 点。

## 6. 不能回答的

- 任何因果结论：差异在哪里变弱，不等于那里是损失的原因。
- L16–18 之外各层每一步的 v、m、e：只有 Mτ 状态，没有逐步驱动量。
- 以干净方向为参照，可能漏掉带针条件下以新方向编码、但模型仍可用的事实信息；正交残差 r 与 cos 会报告，但无法判断其是否可用。
