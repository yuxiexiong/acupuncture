# A022 结果及最小缺测关系独立审查

2026-11-16，同一独立 Advisor。读取作者结果草案、修订 PLAN、result-r01/receipt-r01、analyse.py 及被导入的本地辅助脚本；不运行模型、新实验、统计检验或递归委派。先判断已得到什么，再讨论尚未设计的测量候选。

## 一、结果值得保留，但不能折算 GH/GC 份额

**本轮提供了有内容的局部解释：两方向并非等强的正负扰动；净读取幅度与向量对同一门差的适配可以区别。** 它不是完整任务解释，也不是又一句泛泛“背景重要”。

原生同一门差的计算先于实际 X 轨迹漂移，单位化与两个共同尺度参照能显示：某些层不只是 H 有更大的读取向量，同样总幅度的向量也更适配该门差。L21/L24 的原生读取幅度 H 较小、实际补丁反而较大，L29 读取幅度接近而补丁约两倍，是“各层只是 H 读得更多”这个简单版本的具体反例。L22/L24/L28 的共同尺度适配差不是靠整门 H/C 比替代；L26 的旧整门约四倍也不能继续充当此次门差适配的证据。

GPU 已存 patch−native 的每层加权范数均在 H 较大，直接说明实际作用量不等；L13 当前端点与原生一致，又排除了把首层不等全部归于此前 NGU 传播。W_o 对这些向量的范数映射没有显示一个统一、额外的大幅 C 侧压制；这是对一个具体后续环节的约束，不是“后续计算不重要”。

**这些结果无法量化解释 GH=1.404 与 GC=.238 的多少。** 局部向量可很大却沿任务无关方向；不同层的有符号任务作用可能相消。每层范数 H/C 大于一，也不能推出任务作用之比，更不能用 GC 点估计作稳定分母，宣称已经解释了约六倍差距。缺少任务方向响应确实是当前定量连接中的关键缺口，不是为了延长工作人为增加的要求；但未知不自动要求新模型测量。

## 二、需要明确的数值与汇总边界

1. **cast 前后读取分开。** 作者原表第一列实际是 raw1−raw0；单位化适配使用的是已 cast 的 x1−x0。L13 两者的 H/C 均值范数比为 1.4075 和 1.3140，L14 为 1.6611 和 1.5707。应补 cast d 列或同等明确的定义，不能把 raw 比与 fit 当同一代数分解的因子。作者已表示采纳。raw 证据仍有价值，但只能作为独立的门前读取描述。
2. **统计汇总不混用。** 两边加权范数均值之比与逐对比率再接收者等权的均值是不同对象。作者已正确标注；即使每对存在理想代数分解，也不能乘表内汇总值计算贡献。L26 的“跟随幅度”宜表述为共同尺度单位适配接近一、局部幅度模式一致，不能升级为已经定量排除了其他因素。
3. **实数、有限端点与最终补丁分开。** L13 的理想/有限端点相对差约 .434/.364、最终补丁/意图差约 .189/.141，说明有限精度不可忽略。原生 CPU x1 的小平台误差不界住所有 x0 跨门端点。L22/24/28 固定场与实际补丁的范数比相近，是描述关系；同样范数比不保证逐向量相等，更不提供所有坐标的误差界。
4. **小基底漂移与大差分漂移可同时成立。** 已 cast d 是两个近端点相减，较小 x0/x1 改变可使相对 d 漂移很大；不能把 .704 直接命名为净读取系数发生同量级改变。实际高层门场、尺度、输入及 cast 均参与，不将原生固定算子结果移植为所有实际 X 层的同一算子。
5. **向量反向不等于任务抵消。** norm 比约 .7 可能只是正交；当前 cosine 诊断避免了这一误读。观察到 H 某些层反向，也不能以净结果反推 C 有更强任务补偿。W_o 后的方向仍未与 D−Y 对齐。

上述限制不抹去局部认识，也不要求补更多范数、热点或相关性分析。

## 三、下一最小测量：有条件推荐任务 VJP 卡，而非直接交叉加数实验

**明确建议：可以先写一个有退出条件的 VJP 测量设计卡，科学承诺仅为检验并使用一阶任务方向近似；尚不能标记方案通过，更不运行。** 相比继续加局部几何或立即跨背景重放固定加数，它直指现有缺口：相同有符号方向对两背景 D−Y 的线性任务映射是否不同。

这里有一个可交付、但必须讲清的对象。令每个 tap 的 P_l 为实际 GPU 保存的 patch−native，在 FP64 中取差。把 P_l 冻结，按原顺序构造加数路径。原背景的 λ=1 端点可通过“前层匹配→当前 native 匹配→加回 P 恢复原 patch”按层归纳连接到已有 NGU 轨迹；首先应核每个已存端点的实际重组/cast 身份，不能只凭实数等式。原生 VJP 的多 tap 内积和，才可作为这个**端点锚定的冻结加数路径的连续 autograd surrogate** 在 λ=0 的一阶预测。

它不是自适应 NGU 门政策的导数，也不是离散 BF16 函数的数学导数。函数身份不同并不使测量无价值：关键是该受限近似能否预先、无拟合地预测已经观测的有限任务差。

最危险的失败方式须在设计中处理：

- 只拟合两个均值、相关性或乘一个事后比例就宣布预测成功。需保留逐对/接收者及两背景的有符号误差，不能用大的 H 效应掩盖小的 C 效应失配；也不能因 C 接近零只报告不稳定相对误差。
- 对 `patch−native11` 的总漂移做多 tap 内积相加。这会重复计入上游传播；候选应使用各 tap 新增的直接 P，完整图中原生梯度仍允许后续自然传播。
- 自身方向预测不成立仍解释交叉梯度为有限 NGU 原因。只有一阶近似在既有端点上有用，固定同一 signed/normalized 方向的交叉内积才值得用于任务映射诊断；即使成立，也不是自然中介份额、各层独立贡献或完整回答恢复保证。
- 用 BF16 autograd 的 surrogate 隐去 forward 不匹配。原生 forward/tap/logit 身份、缓存语义、梯度流和数值实现是待设计的工程门槛，不应预先宣称已具备。

若预测失败，应退出这一阶解释，仍交付 A022 的局部结果；不自动转积分梯度、剂量扫描或更多背景。以上是测量候选判断，不替代作者完整 C01–C14、代价/停止条件与同人设计复核。

**不优先简单固定加数跨背景重放。** 同一 pre-cast 加数在两种基底上未必产生同一实际 BF16 改变量，且逐层传播后的轨迹也不同。它并非原则上不能定义，但在没有精确实现身份与明确估计对象前，不解决“同一实际方向”的问题。VJP 诊断可先问受限的任务线性映射；不能因此声称已执行了跨背景有限因果测试。
