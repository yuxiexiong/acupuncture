# A021 / NGU-01 同一独立 Advisor 结果解释审查

2026-11-16。先读作者结果草案与自查，再核正式 analysis、receipt/exit、冻结 PLAN/分析源码及本地和远程审计记录。没有运行模型、新实验、新统计检验或递归委派。以下为原始审查意见，不以维护作者草案为目标。

## 结论：可收束，保留有内容的局部因果认识

**可以保留“条件性的部分机制解释”，不能说双向强移植预测成功。** 本轮增加的不是“门能影响模型”这一架构常识，而是在原指定 J、G14/t2 和原面板上，只替换新增分子用途所用门场，就降低了 H 中的任务响应，并伴随完整来源选择减少。这个干预把 A020 的局部算子差连接到了已对齐的分子用途任务对比，越过了仅凭局部范数猜原因的证据界限。

同时，这项认识没有解释 H 为什么最初形成该门场，也没有证明门是唯一或必要的增强通道。换门后 H 的分子用途仍有明显正的描述性均值，不能说切掉了唯一瓶颈。门字段可含处理后的来源信息；这里的调节不等于无语义控制。结果仍限定于 ΔH 这一列，不补全 ΔC/HC 的弱作用解释。

## 主要结果与预定规则

- G_H=1.403646，95%同时区间 [0.864236,1.943056]：支持削弱 H 响应的方向，预定 +1 量级下界未达，不能叫预定大阳性。
- G_C=0.237630，区间 [−0.301780,0.777040]：正方向未获预定推断支持，且上界低于 +1，限制了该方向的关注量级版本；不是零效应或近零等效结论。
- 双向关注量级合取为 false。不能以 H 单向结果替换原成功标准，也不能另借六场景点均值皆正来重选推断。
- H 的完整 D_tr 从 .881944 降至 .590278；冲突对自身/供体/第三行由 24/128/16 变为 55/96/17。有效编号仍为 100%，没有停止/无效增加，因此连续结果有来源选择行为联系，未呈现广泛交付损伤。D_tr 的 .291667 差是描述性行为证据，不是已建立另一个显著性族。
- C 的 D_tr 仍为 0。不能仅凭未翻转推断门无任务作用；但本轮也有 G_C 的连续量级限制，故不能把未获得强移植全部解释为答案余量掩盖。

“不对称”宜沿作者补充限定为两方向的观测与各自预定判读模式，不另宣称已完成 G_H−G_C 的专门差异检验。本轮无需追加该检验来成立上述结论。

## 对“部分解释”和剩余差的具体纠正

1. **把部分解释绑定操作。** 最稳妥表达是：“在这套逐层增量门场替换政策下，H 的用途响应平均降低 1.404 logits，完整 D_tr 同向下降；原用途背景差也随之缩小。”这是有干预依据的条件贡献。它包含前面替换对后续当前驱动、净读数、分母和后续计算的响应，不能改写成所有原生 d/r/未来轨迹保持不动时，孤立门乘法贡献了 1.404。
2. **强开关说法须限定版本。** 建议写为“本固定 G14/t2/ΔH 条件下，预定 +1 logit 量级的双向可移植门场解释未成立”。不要泛称门不是增益机制或任何背景下都不能移植。结果支持 H 中这一门场使用方式的条件参与，同时限制 C 中的强获得效应；向量—门适配、上下文敏感性与上游读取仍可并存。
3. **4.026 和 3.789 是新的混合系统差距。** 仅 H 换 C 门后，原差 5.430 减 G_H 得 4.026；两方向都换后为 3.789。这些端点代数有用：它们显示本操作没有把两背景响应拉近到相同。但前者只统一指定增量的参照门场，后者更是交换门场而非统一所有中间量。没有为这些剩余差建立新的区间，也没有自然机制的可加分账，故不报解释百分比、不将两 G 当独立原因相加，不把余数分配给净 w、W_o 或“剩余门机制”。
4. **降级正确的旧解释，而非改写历史成功。** A016 强分母版本仍未得到支持，分母不等于零；A020 的固定向量算子差有描述价值，本轮只为其中具体门用途增加任务因果证据。不能以门的这次单向作用把原分母假说包装成成功，也不能把门后范数大改说成跨背景强移植已证实。

作者草案已经覆盖多数边界；以上前两项建议在最终主结论邻近明示，避免读者从标题“部分解释/不是强开关”读出超出正文的结论。

## 本轮决策

**建议收束并交付，不追加实验。** 正面结果是具体门场用途对 H 任务响应及来源行为的条件贡献；负面结果是双向预定量级未成立，尤其 C 的强获得版本受限。二者共同把“局部幅度放大可直接移植成强任务响应”的简单故事改为需要背景配合的受限操作关系，但尚未识别这种配合具体由什么产生。缺口可以诚实保留，不自动恢复 BRC、追加热点、剂量或模型，也不据此上调整篇论文判断。
