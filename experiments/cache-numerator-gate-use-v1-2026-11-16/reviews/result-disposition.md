# A021 / NGU-01 结果审查采纳与本轮决定

2026-11-16。原始独立上下文意见见[result-review.md](result-review.md)，作者审查前草案与自查见[author-result-interpretation.md](author-result-interpretation.md)。Advisor未独立运行模型；其核398个分析来源文件哈希及数字，不冒充作者全量审计的独立复现。

1. **采纳：部分解释绑定替换政策。** 主报告在结论和差距段落明确1.404为G14逐层用途替换及后续响应的效果，不是固定全部原生d/r/未来轨迹的孤立门乘法份额。理由是每层保留当前端点不阻止更高层响应前序补丁。
2. **采纳：限制被否定的强开关版本。** 改为“本固定G14/t2/ΔH下，预定+1 logit量级的双向可移植解释未成立”，不说所有门机制无效。H只达方向支持，+1下界未达；C正方向未获同时区间支持，上界<1，非精确零。保留双向合取失败，未换统计。
3. **采纳：残差是新混合系统端点差。** 4.026/5.192/3.789只作描述性代数，无新增区间，不做自然百分比，不将两G看成独立原因，不把余数归给净w/输出投影/剩余门机制。
4. **采纳：保留旧解释的正确身份。** 分母强版本未获支持不改写为零或借门阳性复活；局部范数不等于任务因果；新增只连接具体门用途与H响应/完整来源。C没翻转不能单独否定门作用，但连续上界也限制强获得版本，不能全归余量。结果仍是ΔH列，不补全ΔC/HC或门场最初形成原因。
5. **采纳双方补充：不对称仅指观察与各自预定判读模式。** 未进行G_H−G_C专门推断，不借两个标签不同宣布已证明统计差异；无需补一项检验。

本轮决定：实现、32项CPU测试、两个工程及一个正式运行、冻结评分、来源/数值/预算审计和解释审查全部完成，交付后收束。没有未解决的解释分歧或实现阻断；仍有机制未知但不把它变成自动实验队列。没有追加层/剂量/模型/BRC、没有提高整体成文判断。原方案和旧失败/预算阻断原样保留。
