# QCD-01（形成期注入覆盖 × 剂量）合同 r01：设计 v2

日期：2026-11-02。设计依据：[计划 v1](../../docs/cache-coverage-dose-plan-v1-2026-11-02.zh-CN.md)（评审撰写，c030d28）+ 评审与助手两轮往返后的修订（本节即设计 v2，取代 v1 中被修订的部分）。授权：用户 2026-11-02「你直接按照这个设计，然后写合同代码，测试上卡」。QC-01 的 NA/LA 文本与结果已见；新政策与交叉来源条件此前无输出。

## 0. 相对计划 v1 的修订（v2）

1. **阶段 G 闸门不再要求逐对零翻转**（v1 §3.3 第 2、3 条作废）：BF16 级供体差异下，宽窗口已有 21–41/216 格 |M| ≤ 0.375，逐格零翻转不是测量能支持的必要条件。改为挂在本轮结论上的阻断判据（§4.1），逐格翻转全部公开不阻断。
2. **阶段 G 缩小**：全部 108 文本都做交叉来源，但只跑必需的臂（T_b、T_s 各换入 C_b / C_s 的 V；统一切分窄窗 T_u 只用 C_b，与阶段 S 的 N1 合一）；不跑 T_s 的 F。
3. **剂量阻断只卡 A、Q**（v1 §5 的逐步 1% 改为只报告）；P 与逐步差异实测报告，并限定措辞：只说“范数和 / 平方和近似匹配”，P 差异大时写明单步幅度不同。
4. **不持久化快照**：阶段 S 重算宽切分预填与 C_b，并与阶段 G 记录的哈希逐位比对；新增成本计入预算。
5. 阶段 S 另重新形成 B1、N1 缓存（不生成），供单元内剂量比较，并核对与阶段 G 哈希相同。

## 2. 形成、恢复与生成

模型、方向（N4146、N1210、R0、C1343，L0）、深层 G 层、恢复与生成规则沿用 QC/NQ；校准用六份 NQ-01 场景原值。

- 阶段 G（每文本）：C_b（宽切分：预填至 b_b，逐 token 形成 B）；C_s（窄切分：预填至 b_s，逐 token 形成 N）；每方向 T_b（宽切分，B 全注入，剂量 −1）、T_s（窄切分，N 全注入）、T_u（宽切分，B 逐 token 但只在 N 注入）。臂：C_b、C_s 自然；T_b 的 nat / V←C_b / V←C_s / F←C_b；T_s 的 nat / V←C_s / V←C_b；T_u 的 nat / V←C_b / F←C_b。共 14 形成、42 条轨迹。
- 阶段 S（每文本，宽切分，供体统一 C_b）：五项新政策 × 四方向，各 nat 与 V←C_b：

| 政策 | 窗口 | 正倍率 a（剂量 −a） | 用途 |
|---|---|---|---|
| B1 / N1 | B / N | 1 | 来自阶段 G（T_b / T_u） |
| E1 | E20 | 1 | 主比较 E1 vs N1：等长、同单步幅度、不同位置 |
| N-A / N-Q | N | L/20 / √(L/20) | 范数和 / 平方和配平 B1 |
| B-A / B-Q | B | 20/L / √(20/L) | 范数和 / 平方和配平 N1 |

V 恢复 = 14 层卷积 V 通道 [4096, 8192) 取供体，q/k、S、KV、浅层取接收者；F = 整个深层卷积取供体。恢复只在读出前一次；贪心、停止 {248044, 248046}、32 新 token，不强制不屏蔽；同前缀诊断分叉照旧。

## 3. 实际剂量（只读审计）

每个注入位置在冻结注入 hook 前后各挂一个只读 hook：原生通道记录该通道实际 BF16 激活改变 δa（及其余通道未变、局部 down_proj 输出差的影子 GEMV，不写回）；R0 记录 MLP 输出的实际改变向量 u。单步实际范数 ||u_t||（原生 = |δa|·||W[:,c]||）；A = Σ||u_t||，Q = Σ||u_t||²，P = max||u_t||。

## 4. 判据（冻结，qcd_core.py）

### 4.1 阶段 G 闸门（阻断）
对比（左 → 右）的逐格差 d = Y_V(右) − Y_V(左)，场景净差 = 9 格之和。稳定类别：≥5/6 场景净差 > 0 且总净差 ≥6/54 → 右优；对称为左优；否则无。每个模板 × 方向，B 对 N 的稳定类别在以下五种组合下必须**完全相同**：K1 T_b←C_b 对 T_s←C_s（QC 原样）；K2 T_b←C_s 对 T_s←C_s；K3 T_b←C_b 对 T_s←C_b；K4 T_b←C_s 对 T_s←C_b；K5 T_b←C_b 对 T_u←C_b（统一切分 = 阶段 S 的 B1 对 N1）。任一不同 → 闸门失败，阶段 S 不开跑，只交付数值敏感性报告。同时公开（不阻断）：每对逐格翻转（按场景、目标位置、方向分组）、ΔM、ΔE 分布、M 在两边 |M| ≤ 0.5 内的符号翻转数。

### 4.2 阶段 S
- 适用性（NQ 规则）：C_b 面板合格（每模板 ≥5/6 场景各 ≥8/9）；每政策 × 方向损伤迁移（≥4/6 场景各 ≥6/9 为 C 对且 nat 错）。比较两边都适用才判。
- 剂量阻断：E1/N1 要求每文本 A、Q 相对差 ≤1%；B1/N-A 与 B-A/N1 卡 A；B1/N-Q 与 B-Q/N1 卡 Q。不过 → 该比较“剂量未配平”，不下科学结论（工程未达目的，不当阴性）。P 与 E1/N1 逐步差只报告。
- 六个预定比较：B1/N1、E1/N1（主位置比较）、B1/N-A、B1/N-Q、B-A/N1、B-Q/N1；每模板 × 方向给稳定类别、配对四格、Y_V、Y_nat、恢复增量差 ΔR。跨方向模式：某非“无”类别在固定 4 方向中 ≥3 个。
- 剂量优先解释（按方向，仅在 B1/N1 稳定的方向）：N-A、N-Q 向 B1 靠近且 B-A、B-Q 向 N1 靠近，四个配平差的绝对值都 ≤ 原 B1/N1 差的 25%，且 E1/N1 不稳定 → 剂量优先；前两条成立但 E1/N1 稳定 → 位置与剂量共同影响；否则非剂量解释。
- 结论措辞按计划 v1 §6.3；稳定类别是最小可报告一致模式，不是显著性。若改善主要来自 Y_nat 上升，先报告损伤减轻。
