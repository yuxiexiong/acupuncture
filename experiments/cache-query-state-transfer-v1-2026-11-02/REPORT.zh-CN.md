# QST-01（查询相关卷积 q/k 历史能否定向改变完整答案）结果报告

日期：2026-11-02。[合同 r01](CONTRACT.zh-CN.md)；[决策 D1–D5](DECISIONS.zh-CN.md)；[冻结后偏离](DEVIATIONS.zh-CN.md)；计划 v1（d4cc83c，评审撰写）。代码 `ccefeac`，freeze-r01 `ae35e8f6…d6e`。外来供体轨迹运行前无输出。同一助手实现、运行与撰写。

## 1. 结论（阴性先说）

1. **没有任何定向转移。** 换入另一个查询形成的 q/k 历史后，干净接收者（U）和“受针背景 + 干净 q/k”（H_C）在四个方向都 **84/84 仍然交付接收者自己的答案**；36 个主接收者的 J、W 全部为 0。九种臂类型（U；四方向 H_C、H_T）都没有达到稳定正向或反向标准；受针削弱判据的前提（H_C 稳定正向）不成立。
2. **原因很直接：在读出前的四个模板位置上，不同查询留下的干净 q/k 历史几乎相同。** 把 q/k 换成同组另一个查询的，首步共同首字母分数的变化中位数 0、最大 0.125–0.25 logit，诊断三候选分数最大变化 0.125–0.25 logit（1–2 个 BF16 间距），所有臂与方向都如此。也就是说，查询身份在这块状态里几乎没有留下能影响输出的差异。
3. **但“干净 vs 受针”在这块状态里差别很大。** 自供体时，干净 q/k（H_C(a,a) = 旧 T_F）四方向 48/48 交付原题；受针 q/k（H_T(a,a) = 旧 T_V）只有 16/48（N4146）、28/48（N1210）、38/48（R0）、48/48（C1343）。外来受针 q/k（H_T）在 N4146 的 36 个主接收者上两个供体都输出首列编号（36/36），即旧的“首列”偏好，与供体身份无关。
4. 按计划出口（§7 第 5 行）：**一般恢复成立，查询定向候选未获支持；本候选结束。** 能说的是：深层卷积 q/k 历史对“选对目标”的作用，在这个面板上与“是哪个查询”基本无关，而与“是否在受针条件下形成”有关。
5. 限制：只测了 NA 原布局、宽窗口 B1、读出前四个模板位置的 q/k 投影；阴性不证明模型没有查询信息（递推 S 与全注意力 KV 里显然有，接收者始终答自己的题），只说明这块状态不携带足以改答案的查询身份。
6. 工程全部通过：base、C、T 哈希等于 QCD 阶段 G；624 条自供体臂与 QCD 逐位重放（T_nat 192、U(a,a) 48、H_C(a,a) 192、H_T(a,a) 192）；预检中未替换 C = U(a,a)、两文本重建一致、卷积 4 槽滑窗在形成逐 token 与首读一步都核对通过。

## 4. 对主线的含义

- 前几轮里“q/k 与 V 一起恢复才能选对”这件事，现在可以更准确地读：所需要的是**干净形成的** q/k 历史，而不是**带着正确查询的** q/k 历史——同组任一查询的干净 q/k 都一样有效。
- 所以“受针改变了哪一部分历史、怎样导致选错/复述”，答案不在“查询身份被写进 q/k”这条路上；更可能在 q/k 历史的一般状态（受针形成后整体偏离）如何与读取交互。下一步若继续，应先问：受针形成的 q/k 历史与干净的差在哪些层、哪个方向，这种差能否用一个与查询无关的方向描述——这需要新的计划，本轮不自动展开。
