# SVQ-01（共享首字母面板上的 V 与 q/k 卷积恢复）合同 r01

日期：2026-11-02。设计：[计划 v1](../../docs/cache-sp-v-qk-delivery-plan-v1-2026-11-02.zh-CN.md)（评审撰写，5b6127c）+ [修订 v2](../../docs/cache-v-followup-amendments-v2-2026-11-02.zh-CN.md)（032a17c：A1 诊断分叉的历史重放验收；A2 T_F 是参照不是上限、逐输入配对表）+ [共同自查](../../docs/cache-v-followup-self-check-v1-2026-11-02.zh-CN.md)。授权：用户 2026-11-02「开始」。SP 面板与 SP-01 结果已见（不是未见输入或独立确认）；新测的是 T_V 与 T_QK。与 FXS-01 独立立项、记账，互不设科学门槛。

## 1. 操作

12 条 SP 输入（6 情景 × f0/f1）、四方向 N4146/N1210/R0/C1343、模型/分词器/内核、L0 剂量 −1、形成窗口、worker/GPU 分配全部沿用 SP-01；进程内校准须逐值等于 SP-01 正式校准。每输入共享 C_nat；每方向四个自然续写臂：

| 臂 | 深层 q/k 卷积（通道 0–4095） | 深层 V 卷积（通道 4096–8191，全部 32 个值头） | 其他（浅层、递推 S、全注意力 KV） |
|---|---|---|---|
| T_nat | T | T | T |
| T_V | T | C | T |
| T_QK | C | T | T |
| T_F | C | C | T |

14 个深层 G 层 13,14,16,17,18,20,21,22,24,25,26,28,29,30。q/k 指短卷积缓冲，不是全注意力 KV。恢复只在起点做一次，之后所有缓存沿真实输出正常更新。贪心（argmax）、停止 {248044, 248046}、最多 32 个新 token；不强制、不屏蔽、生成期不注入。混合状态不是原生轨迹，供体可重新带入事实信息。

**同前缀诊断分叉**：每条轨迹做完首步评分后，克隆更新后的缓存，喂入 SP-01 冻结的共同首 token q_shared，恰好一次前向，读取目标第二 token 与两个干扰第二 token 的分数及全词表 logits；分叉不继续生成、不混入自然交付；首步自然停止也照做。M = 目标第二 token − 最大干扰第二 token。共同前缀是格式提示，M 只说明该提示下的选择倾向。

## 2. 判据（无方向性预测）

- 主终点：FC/SP 冻结解析器的 Y_delivery（完整目标、无其他不同编号），同报 Y_strict 与互斥分类。
- 前提：C 基线 ≥5/6 情景两事实都正确；T_nat 损伤 ≥4/6 情景两事实都未交付；不满足分别记“基线不足”“效应未迁移”。
- **恢复支持**：≥5/6 情景两事实都满足“C 正确、T_nat 未交付、该臂正确”；整体 ≥3/4 方向（固定分母）。**P_SV**＝T_V，**P_SQK**＝T_QK。T_F 用同一规则报告，只作参照。
- **T_F 是参照不是上限**（修订 A2）：不降门槛、不排除 R0（SP-01 中 R0 的 T_F 在 SP03-f0、SP06-f1 未交付）；V 或 QK 优于 F 如实报告，不当异常。每方向逐输入配对表：F 对 V、F 对 QK、V 对 QK，各分“仅前者对 / 仅后者对 / 都对 / 都错”。
- **目标选择**：只在目标不在首列的 4 情景 8 输入（SP02/03/05/06）上数“输出 = 目标”与“输出 = 首列编号”；目标在首列时两者不可分，不计入。全样本主终点不变。
- 首步：共同首 token 相对固定停止 s0 = 248046 的分差、相对全部其他 token 最大值的优势；停止集合最大值单列。
- 出口（计划 §4）：V 支持而 QK 不支持 → 本条件下恢复 V 足以交付（不说 q/k 无用或 V 唯一必要）；QK 支持而 V 不支持 → 撤回把 P 面板 V 充分性推广到 SP；两者都支持 → 两种操作各可恢复；两者都不支持而 F 支持 → 所测组合优于单独恢复（二元交付不证内部协同）；F 混合 → 逐方向如实报告。M 与交付不一致时以交付为主判。V 只在目标首列时成功，不称恢复了可靠目标选择。无论结果如何本轮结束，不自动扫层、不重启固定 45 头。

## 4. 工程闸门（任一不过即停止）

校准逐值等于 SP-01；worker 分配等于 SP-01；q_shared 与第二 token 由真实分词器重算且等于 SP-01 记录；L0 写入 ≤1%；**重放**：C_nat、T_nat、T_F 与 SP-01 逐 token 相同（首步 logits 哈希、首步后与最终缓存哈希、自然第二步三候选分数）；**诊断重放（修订 A1）**：每方向 T_nat 分叉三候选分数与 SP-01 T_shared 第二步逐位相同，C 与 T_F 在 SP-01 首 token 为 q_shared 的单元上与 SP-01 自然第二步逐位相同，任何首 token 为 q_shared 的臂其分叉与自身自然第二步逐位相同（含全词表哈希）；**组装**：T_V、T_QK、T_F 的 q/k 与 V 通道块逐位来自规定供体，S/KV/浅层哈希 = T，且每层 C 与 T 的 q/k 块、V 块都不相同（恢复不空）；供体不变；生成前无 hook；预检重建一致（轨迹、最终缓存、诊断）。
