# A024 最小缺测候选：固定末端任务种子，比较反向传递

2026-11-16；**未实现、未运行；作者自查与同一Advisor逻辑审查通过，工程未验收，不是GPU排程。** 用户本轮只授权旧数据/理论分析，未授权此测量。保留原TGA与旧队列停止状态。

## 为什么不能只多存各层梯度

已存tap梯度只有a_B=J_B^T b_B。b_B是最终RMS前残差h_B的任务梯度，J_B是14个控制点到h_B的映射；二者没有分开保存。已有局部q/k/v/z/x0不能恢复它们。

作者原考虑各残差子层b_in−b_out的望远镜分账。Advisor给出反例：即使所有子层J_f不变，单独末端b变化也会改变全部J_f^T b_out，让差异显示在许多MLP/attention项。故**撤回此方案作为来源判别的优先测量**。只记录h或b也不足；必须固定同一个b再比较J的作用。

## 设计卡

1. 主线：解释针影响读取后为何形成不同任务响应。本轮唯一新增关系：终端RMS/readout种子变化与进入末端的映射变化，对已测指定方向的作用分别怎样？不追求模块唯一定位，不重跑NQ03/04误差路径。
2. 固定原48接收者/168冲突对/G14、同一模型revision和TGA native C/H、相同prefix/候选及t2原始L=zD−zY。使用全部原面板，避免按大误差选择样本；工程复用原6接收者/20对。C/H均为原条件，H仍混合背景，不改历史来源。
3. 每背景只做原native t2，非修改hook捕获**最终RMS输入h**，同一loss反向得到native a及b=∂L/∂h，图保留。两背景都完成后，各自图再以另一背景的已detach b为grad_outputs计算∂h/∂e的VJP。权重冻结、cache历史固定、t2继续正常计算；不把b作为前向激活，不改logits、不生成新自然回答。
4. 理论四格a_{B←s}=J_B^T b_s，B为C/H前向图，s为C/H任务种子。**实际估计对象定义为机器VJP操作P_B(b_s)**：BF16 backward对grad_outputs未必严格线性，不能将实际四格冒充某个精确实数J矩阵的乘法。固定seed的映射差包括该图的数值传播，不直接命名某模块。b的两者必须具有相同h坐标、dtype、候选与位置；异背景seed作为常数，不能让梯度流到来源背景。原生对角须逐tap桥接原a；两交叉新增反向测量。
5. 对旧U_C、U_H分别计算S_{B,s}=Σ_l<a_{B←s,l},U_l>。保留有符号逐层项和全场值，按原接收者单位汇总。固定s的行差识别给定种子下J变化的作用；固定B的列差识别给定J下种子变化的作用。报告两种参照的条件差及I=S_HH−S_HC−S_CH+S_CC；不把其中某一顺序或平均分成自然机制份额。
6. 若两固定种子行差均小、列差足以近似原对角差，则削弱“必须由前端映射差产生”的解释；反之则削弱“仅末端种子变化”解释。若两者均有较大作用或I大，则保留共同依赖；不能把模糊结果自动转为更多层/剂量/积分。这里“小/大”须交付连续读数与原对角差对照，不预设统计通过、场景小样本不作确认。
7. 保存h/b/native及cross a、旧U来源SHA、每次反向计数、完整logits与hook/cache桥接、失败现场。可CPU核γ=1+weight与head行差的RMS理论seed（逆尺度+径向），但BF16机器b与实数公式的差另报；不凭seed几何认定两个内部项的任务份额。
8. 完成即可收束。它分辨的是**末端局部任务梯度与此前映射**，不是RMS的自然中介份额，也不区分MLP、GDN、fullattention；不承诺解释NQ03/04有限误差。原幅度端点校准身份不自动覆盖新cross，所有cross仍是机器autograd surrogate。

## 工程门与最小预算（均未验收）

复用TGA控制、已核原地cache保存副本、原t1构造与计费。所有反向在既有allow_mutation_on_saved_tensors语义内；不得为方便而detach native链、改kernel/dtype或重建成另一模型。

- CPU合成图检查：末RMS前定位、seed detach、四格VJP方向与恒等、权重无梯度、反向次数及失败留存。
- 工程6/20：新native完整logits与已存a逐值桥接；另以各自native b再拉回一次，确认链式分割**逐tap逐值**重现native a（不是只对均值）；正式仍核每对native logits与a吻合旧记录。失败属于工程问题，停止，不自动放宽门槛或以科学阴性解释。cross无前向端点，不能假装做过有限校准。
- 正式48/168：只有上述门通过后才可按未来明确授权执行；当前不执行。每对2 native t2、2 native backward+2 cross VJP；工程另2 native-seed重现VJP。合计梯度遍历120工程＋672正式=792，0自然回答。
- 形成、prefix、t1必须重建，旧快照不是完整可直接续跑cache。沿TGA上界：工程57×6+4×20=422次forward，正式57×48+4×168=3408，总3830；形成长度实际不足上界时按真实ledger计，不把上界当完成数。去掉TGA frozen-P t2，不新增前向条件。预计成本不能仅算交叉VJP。
- 资源仅作未授权硬上限候选：工程900秒、正式5400秒、含失败总7200秒、单worker/单卡、产物2GiB。必须工程最慢单位×1.25外推包含全部重建及反向，超限停止；没有实测时长，不宣称已GPU-ready。CPU额外验收上限120秒，源校验另记。
