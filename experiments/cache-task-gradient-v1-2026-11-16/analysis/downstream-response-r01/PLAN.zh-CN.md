# A024：已有梯度的后续响应分析卡

2026-11-16；探索性、已见面板；先作者自查再同一独立Advisor审查。当前仅CPU旧数据分析与理论，0模型forward/0 GPU。来源：A023正式48接收者/168冲突对/G14、已存336梯度与projection，A022同168对2352行局部记录。旧实验身份和判据不改。

## 设计卡

1. 主线仍是针如何经写入、历史处理、读取影响回答。本轮问：同一指定方向在H的较强任务内积，是梯度整体变大、方向重排、还是层间抵消减少？NQ03/04的一阶误差能排除什么？
2. 增量：将“后续敏感性”拆为可核算的竞争限制，拒绝把梯度差直接命名为MLP或attention机制。不重复A023校准。
3. 沿用原P与Q_C=P_C、Q_H=-P_H及逐层共同幅度U；原幅度对角有限校准，交叉/U仅surrogate。最不利证据为H五接收者大误差、NQ03/04局部门槛未过、无中间残差/模块梯度。
4. 不改变模型、数据或干预：从旧张量读取a_C,a_H，重现全部原投影；核SHA。全场拼接及逐层分别计算范数比、cos和最佳标量k=<aH,aC>/||aC||²、剩余r=aH-k aC。对U_C/U_H精确分解响应差为(k-1)<aC,U>+<r,U>。k是描述性正交投影，不是拟合新的任务预测；不把r命名特定模块。分层k仅描述，不能将不同tap坐标的梯度范数比当跨模块增益。
5. 对同方向逐层内积取Σmax(t,0)、Σmin(t,0)，解释均值差由正项增加还是负项减弱构成。这是同一一阶和的代数分解，不是独立层干预效应。全场与分层结果并报，防止层幅度分配伪装成局部旋转。
6. NQ03/04与其余四场景并报原MAE、bias、MAE/mean|G|、误差符号、接收者行；不用逐对近零分母。连接A022各层rounding_relative、d/x0/inv漂移及P范数作描述性比较，相关不作因果证明；不做显著性筛选/删样本/重定阈值。大误差与效应尺度一致也只提供线索。检查末端量化是否足以单独解释误差，仅在源码与保存dtype足以确定时作保守界。
7. 理论对照实际冻结源码：固定lm_head两行；最终RMSNorm的逆尺度及径向项；本层MLP、后续attention/GDN的Jacobian链。证明可发生不当实证已发生。原tap之后才有因果作用，不归因同层已提交cache。查公开一手来源，不上传私有记录。
8. 结果允许整体增幅、方向变化、抵消共存，或现有量无法区分。若纯比例近似差，可拒绝纯统一缩放，但不能拒绝最终RMSNorm的径向作用；若误差仍多解，不强行选曲率或舍入。完成即停止CPU分析，不自动上卡。若提出补测，只对确缺的模块pullback给最小未运行方案，另作自查。

汇总以供体在接收者内均值、48接收者等权；场景按实际接收者等权（NQ01/03/05/06各9，NQ02/04各6）。张量元素或2352行不当独立样本；原168不是外部确认。只报指定方向、已见面板、surrogate。

Advisor初步修正已纳入：全场k在每配对14×4096拼接后计算，先逐对分解再汇总，绝不用均值相乘；k≤0只称标量分量、不称增幅，零梯度标未定义并停止几何分解。正负项先逐对逐层取max/min再汇总。CPU单线程，上限120秒分析+120秒合成验收，输出30MiB；超限停止，不扩大预算。末端四logit舍入界只约束最后输出舍入，不约束整个BF16计算或反向数值误差。
