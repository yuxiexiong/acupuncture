### 2.2 评价字段

- 程序字段：首 token 是否属于原 EOS 集合；实际首 EOS 位置；生成长度；结束原因；是否达到 128 token 上限。
- `delivered`：是否给出可判定的题目核心答案；拒答、仅复述问题、泛泛说明、尚无答案均为 0。
- `correct_core`：最终明确核心答案是否满足预定答案规则。先错后明确更正可按最终结论评价，另记 `self_correction`；未解决的相互矛盾结论不能算正确完成。
- `contradiction`：是否存在未明确撤回的核心矛盾；非核心附语另列，不静默丢弃。
- `repeat`：同一完整子句非任务要求地重复至少三次，或连续相同 token 子串（长度至少四）重复至少三次，记录对应跨度；复杂语义循环保留人工判断与引文。重复与正确可以共存。
- `unjudgeable`：答案含糊或评分规则不能覆盖；不能强迫读者猜。主指标保守记 0，另报告把所有此类视为成功时的上界。

截断不自动判事实错误：若已完整给出正确核心答案且无未解决矛盾，可算核心成功，但必须单列截断；另报“正确且无截断、无重复”的严格完成率。各标签不是互斥桶。

## 3. 被测条件及唯一新增操作

只研究 Qwen3.5-4B、L0/C4146、dose=−1。干预仍为 MLP 中间激活进入 down_proj 前的加法；校准公式、参考提示关系及 BF16 沿用源冻结实现。前缀 prompt[:-1] 受干预；最后提示 token 和全部解码无插件。greedy、原 EOS 集合、128 新 token 上限不变。不重新校准为“更有效”的剂量。

缓存代码顺序为 KV、递推、卷积；T=受干预运行，C=同输入的干净运行。

| 臂 | 精确替换 |
|---|---|
| CCC | 三类全部干净，正常参照 |
| TTT | 三类全部受干预，失效参照 |
| CTT | 只清理 L3/7/11/15/19/23/27/31 的 K 和 V |
| TCT | 只清理所有线性层递推状态 |
| TTC | 只清理所有线性层卷积状态 |
| TCC | 同时清理所有线性层递推与卷积状态 |

线性层为 L0–31 中除上述八个完整注意力层以外的 24 层。L0 干预位置同层注意力已计算，L0 缓存 T=C；仍保留完整设计身份。缓存管理字段和前缀位置必须一致。不能混用其他题、其他事实版本或不同生成历史的缓存。

两种生成方式与六臂完全交叉：

- N：原始 greedy。
- E：只在生成 step=0，把原 EOS 集合的选择分数置为负无穷；step≥1 恢复原分数和停止规则。除 EOS 外所有 logits 保持不变，不使用 min_new_tokens、强制答案前缀、额外指令或延长上限。

每个分支从混合缓存独立深拷贝开始。E 的 step=0 原始 D 在屏蔽前保存，另存实际选择；不得将屏蔽后的 D=−∞ 纳入效果统计。E 首步 EOS=0 是强制操作，不作显著性发现；单列 step=1 立即结束情况。E 失败不能证明信息已丢失。

## 4. 题集与冻结顺序

A 完成来源和标签评估、B 工程预检通过后，C 用全新 96 个基础情景、每情景两事实版本，共 192 输入。reading、arithmetic、relation 三族各 32 情景。每对只改变决定答案的事实，两个版本正确答案必须不同；候选对、题面、真值、自然答案允许表达、否定与单位规则预先固定。

新增题不能只是旧题换实体名或数值；记录模板与语义去重审查。每个基础情景独立，不用同一模板几十次改词冒充独立样本；模板来源相近者标簇并报告按模板聚合的敏感性分析。题面长度按两版本分别记录，版本间缓存不互换。

题目由程序可验证的关系/算术规则和人工语义审核共同确定；不得使用干预输出筛题。96 对在任何 C 模型输出（含干净）打开前锁定。干净自然错误留在总体分母，不按 clean S 或干净正确率删题。

新题固定后，先完成 CCC/N 全部输出并盲评：若完整事实对正确数少于 87/96，记录“任务适配不足”，终止其余 C 采集，不能替换失败题续跑；另立版本才可换题。87/96 是本合同选定的 90% 适配门槛，非既有领域标准。通过后复用全部 CCC/N 记录，正式总体仍为原 96 对。

旧题仅用于 B 的工程检查；本合同不设从新题表现选择最优缓存臂的步骤。人工题面审核、代码/分析哈希、全部主比较和预算须在 C 启动前冻结。缺少实际权重哈希或题文件不是可自动填空的细节，当前 draft 不等于已冻结可运行合同。

## 5. 主指标与辅助指标

每输入核心成功 y=1，当且仅当 delivered=1、correct_core=1、contradiction=0、unjudgeable=0。其他情况 y=0。未交付计任务失败，但不能在语义错误类别中算作错误答案。

**唯一主要行为指标 P：** 每基础情景两个事实版本 y 都为 1 则 z=1，否则 z=0；P=96 个 z 的平均。两版本不能作为 192 个独立样本。报告各族分层结果，但不将族内检验追加为确认发现。

必报次指标：每输入成功率、交付率、交付后正确率（无交付时 NA）、首步 EOS、step=1 EOS、截断/重复/矛盾比例、严格完成率（核心成功且不截断不重复）、两事实对候选排序均正确率。所有分母明确；条件正确率不替代无条件 P。

辅助 D=max(EOS logits)−max(非 EOS logits)；S=[ll(A)−ll(B)]事实A−[ll(A)−ll(B)]事实B。ll 为固定候选逐 token 自然对数概率之和，不除长度；两版本共用候选且正确项互换，先据真值定向而非默认 choices[0] 总是事实 A。S 不是正确率，不设“降低多少即信息损坏”的阈值。候选评分不经过 EOS 屏蔽、不受某一自由生成分支历史影响，各缓存臂只评一次并共享 N/E 的辅助读数。概率和行为差异不能换算成“知识恢复百分比”。

## 6. 预注册比较、实用门槛与统计

### 6.1 七个改善比较：唯一确认性优效家族

全部以 P 的配对差为终点，备择为前者较高：

1. TTT/E − TTT/N：简单首步解除是否改善真实作答。
2–4. TCT/N、TTC/N、TCC/N 分别 − TTT/N：三种线性缓存清理是否改善真实作答。
5–7. TCT/E、TTC/E、TCC/E 分别 − TTT/E：在同样解除首步 EOS 的条件下，清理是否仍有额外收益。

CTT 是预定缓存类型参照，所有结果报告，但不追加主检验以降低多重检验成本；其对比属于探索性。N/E 的交互差分也只描述，未证实交互不能声称两个独立机制。

每比较用事实对 z 的不一致配对计数，精确单侧 McNemar（条件二项，无不一致配对时 p=1；有不一致时按实际获益与受损对数计算），七项 Holm 控制家族 α=0.05。报告成功/失败配对四格表、百分点差、原始及校正 p、按基础情景配对 bootstrap 95% 描述区间（10,000 次，种子 20261030；三族内各重采样 32，所有臂共用索引）。区间不是家族同时区间。

“检测到改善”需 Holm p<0.05；“有实用幅度的改善”还需 P 差≥10 个百分点（96 对至少净增 10 对）。10 pp 是本次预先选定的实用门槛，不是自然界限；不足时如实报告小效应，不改门槛。该样本量并非对 10 pp 效应的高功效保证；不一致率决定精度，不允许见结果后补到显著。

### 6.2 接近干净水平：独立、保守的三项保留检验

不能用“差异不显著”宣布无损。预定三对：CCC/E 相对 CCC/N；TTT/E 相对 CCC/E；TCC/E 相对 CCC/E。

每对定义有害不一致 h=参照 z=1 而待检 z=0 的基础情景数；以全部 96 对为分母，计算 h/96 的精确 Clopper–Pearson 单侧上界，单项置信度 1−0.05/3，三项 Bonferroni。只有该上界≤5% 才支持“在本题分布上，新增事实对失败率不超过 5 pp”。这是对净损失的保守上界，忽略待检的改善收益，不宣称所有能力等效。96 对零有害不一致时仍需按精确公式报告，不能写绝对无损。

CCC/E 若不能通过，E 对正常作答的影响尚未排除；可继续如实测量，但不得据此作“单纯输出门控”强解释。以上保留家族与优效家族分别解释，不把多个家族任一显著拼成同一个成功声明。

### 6.3 适用范围

固定任务集给出条件内证据；统计概括依赖基础情景可作为目标题分布样本的假设。模板簇和人工选题限制写入结论。多种缓存臂、token、重复角色和同一确定性运行的重复次数都不增加独立样本量。

## 7. 竞争解释与判定规则

首先检查 CCC/N−TTT/N 的 P 差：若不足 20 pp，或 TTT/N 首步 EOS 输入比例不足 80%，标“原严重停嘴情景未充分复现”，仍保留完整已授权矩阵并报告，禁止据此调剂量；不以本轮宣称解释了历史全面停嘴。两个门槛为本合同的适用性标准，不作新的定律。

| 结果组合 | 允许的判读与下一步 |
|---|---|
| 原异常复现；CCC/E 保留门槛通过；TTT/E 有实用改善且相对 CCC/E 保留门槛通过 | 支持首步输出压制对该任务失效有主要解释力；不能外推其他能力，暂缓细拆层 |
| TCT/E、TTC/E 或 TCC/E 相对 TTT/E 有实用改善 | 指定清理存在超出首步 EOS 解除的行为收益；不自动称其为事实存储修复 |
| 上一行且改善主要由未交付/循环转为正确完成 | 优先研究生成过程，事实信息损坏仍未证实 |
| 能稳定交付但两事实版本不随真值翻转，且清理恢复 | 支持任务层面的事实利用失败与恢复；必须列出配对原文，条件正确率仅辅助，不证明信息被擦除 |
| 只有 D/S 或候选排序改善，P 无确认改善 | 内部读数作用；不能写“能力恢复”，不因 S 峰值自动追层 |
| 未显著、保留上界>5%、读出方式冲突 | 证据不足；不等于没有效应，也不等于能力保持 |

表中生成障碍和事实错误的归类是描述性机制诊断，不另授确认性身份。“稳定交付”固定为该臂至少 90% 输入 delivered=1；“主要由未交付/循环转为正确完成”固定为所有失败→成功的事实对中超过一半此前至少一个版本存在未交付或重复。两类可以重叠，完整交叉表必须保留，不按选中的子集重新检验来宣布机制成立。若 S 降低但 P 保持、或错误缺少一致模式，均不升级为事实利用机制。

无候选排名后追加实验。反向移植能否重现真实行为、新通道、新模型、剂量与时段扫描都须另立合同。干净供体的恢复可能含补偿，不能从恢复一项直接推出自然路径唯一根因。

## 8. 工程与评分门槛

B 只用旧开发题，最多 12 输入×6 臂×2 生成=144 次生成，候选评分最多 144 条；不筛通道和剂量。必须核验：N 与冻结旧实现同输入同臂 token/首步 logits/候选分数逐字节一致；E 屏蔽前 logits 与 N 一致，非 EOS 分数未改；step≥1 关闭屏蔽；不改变缓存来源、位置、dtype、hook 时段、权重；深拷贝不串扰；全部缓存 T=C 的恒等条件；固定候选评分索引。E 后续历史不同，不要求其 logits 与 N 相同，而验证其计算规则恢复原样。
