## 1. 问题与主线

主线不变：稀疏激活干预怎样改变历史状态及后续计算，最后产生显著回答效应。A提供材料关系，C1-P/C2提供有边界的预测验证，B仍缺计算连接。停止词分数是当前诊断窗口，不是整个课题目标。

本轮问：**FIX/其余历史同时存在时，最终 RMS 的超加和增长，在平方范数账目上由哪些分支及其与输入的对齐关系承担；是否能据此提出一个改变分支计算后会减弱该增长的可失败预测？**

这不是重新检验“FIX特殊”。报告更正发现 FIX 与两个随机切分的交互大小虽都为负，尺度承载方式却不同：FIX 的 r 交互均值约0.07–0.13，U1/U2约0.003–0.039。该差异是已见数据上的探索线索，P2原判定不变，不能推成所有随机切分或一般机制。

Related Work已有归一化、几何和状态读写解释；缺的是这些运算与本项目同条件历史效应的实证连接。使用已知范数公式不是新机制；本轮价值仅在于把一个新观察变成具体干预对象和预测，或明确无法做到。详见[文献边界](literature/merged-prior-art-artemisinin-2026-11-01.zh-CN.md)§4–5、[基础审计](cache-mechanism-known-basics-audit-2026-10-31.zh-CN.md)。

## 2. 本轮边界与对上一思路的修正

- 撤回“优先干预31层”的口头设想。停止方向投影最负不等于最能解释平方范数增长；28/30/31都不预设为胜者。
- 只做一次已有数据 CPU 分析，不调用任何模型模块，不重建前缀、不加载权重；最终读出向量使用已存 FP64 向量。
- 复用四方向、六情景各两事实、FIX/U1/U2三种冻结切分。12输入是六个配对情景；同一输入跨方向不独立。
- 不新增随机切分、不追加留出题。本轮不作特异性确认；更多随机切分属于后续独立预测检验，不能混入本轮再算“事前”。
- 新增的是**平方范数及内积账目**，不是第五轮停止方向投影筛选。选点依据必须来自尺度目标；投影只用来检查候选是否主要直接改分子。

## 3. 数据与四格

各输入、各方向内部固定同一 N 背景与 decoder-13 入口 x_T。以每个切分的45头为 A，其余为 B：00=N:CC，10=FIX或Uk，01=REST或Uk补集，11=N:CT。定义线性四格算子 K(y)=y11−y10−y01+y00。

使用 B3 每格第13–31层的输入、mixer输出、MLP输出、decoder输出、最终h及normed、全词表logits/原读数、停止及答案读出向量。C/T缓存快照没有保存（B3 D2）；任何未来模型干预必须重新形成，不能假定可直接续跑。

所有资产核对 receipt 中哈希、dtype/shape、位置、方向、切分和模型身份；不完整即停止，禁止用另一输入或方向补齐。

## 4. 精确账目：分清平方范数、RMS与读数

### 4.1 残差加法顺序

第 l 层记输入 h、mixer输出 m、MLP输出 f。先按原 BF16 路径重建 a=BF16(h+m)，核对 out=BF16(a+f) 与记录逐位一致。a不是凭空新增观测，标记为已验收加法重建。

转FP64后，使用实际残差增量 Δm=a−h、Δf=out−a，分别计算：

`E_m = 2<h,Δm> + ||Δm||² = ||a||²−||h||²`

`E_f = 2<a,Δf> + ||Δf||² = ||out||²−||a||²`

各分支保留“与输入的内积项”和“增量自身平方项”，再分别应用K。完整账目为：

`K(||h_final||²) = K(||h_13,in||²) + Σ_l [K(E_m,l)+K(E_f,l)]`。

入口四格相同，入口交互应为0；仍实际验证。记录 Δm−m、Δf−f 的舍入差，不把它们藏入科学分量。不能只算各分支自身范数，也不能漏掉跨分支影响：这些影响通过当时的输入向量进入内积项。该顺序分账是模型实际加法顺序的一种精确账目，**不是唯一因果贡献**。

### 4.2 从平方范数到RMS

每格分别重算 `r=sqrt(||h_final||²/d+eps)`，由四格r求K(r)。`K(r²)=K(||h||²)/d`，但 `K(r)` 不是分支平方范数交互简单相加或开根号；禁止把两者等同。若K(r)明显而K(r²)弱，必须报告平方根变换的作用，不能强行找“大能量分支”。

### 4.3 方向与尺度

令已存去均值停止读出向量为 u，`p=u·h`，`z=p/r`。分别核对K(p)、K(r)、K(z)。另用单位方向 e=u/||u|| 计算 `||h||²=(e·h)²+||h−e(e·h)||²`，检查尺度增长是否确实包含非停止方向部分，不从RMS变大直接断言“无关信息变多”。答案侧只报告相同账目，不据此认定独立电路。

## 5. 固定选点规则与离线预测

本轮是探索选点，无p值、无“随机零分布”、无将12输入当12独立样本。U1/U2只作同输入参照，全量列出，不再合并输入尺度后用极值带宣布等效。

候选域固定为第13–31层的38个单独分支（每层mixer、MLP）。不任意拼层组、不看完结果后加入组合。最多交付一个候选，也允许零个。

先判终点平方范数交互是否可分解：每输入 K(E_final) 须为正且大于 `1e-6×max(E_final四格)` 才计算其占比，否则保留原值、标为不可比。此门槛只防小分母，不是科学显著性阈值。

一个分支须在至少3/4方向中，各至少5/6情景同时满足：两事实K(E_branch)>0，且情景均值K(E_branch)≥0.25×K(E_final)情景均值、两事实分母可比，才进入离线干预检查。0.25是本轮有限预算的实用候选门槛，不是自然常数；超过100%允许，其他项可能反向抵消。多个候选时，按四方向的“情景占比中位数”的中位数排序；并列按层号、mixer先于MLP，取一名。所有落选原因保存。

对这个分支，只在11格构造供体替换的**冻结后续响应预测**：将该分支原输出改为同输入/同方向10格的输出，保留其他已记录分支增量，按原加法顺序重算最终向量及p/r。这是一个离线影子结果，下游模块没有重新响应；不是新模型运行，也不是因果效应。FIX与U1/U2都使用各自10格，不能把FIX供体用于随机切分。

进入下一份因果合同的预测卡必须包含：

1. 分支、hook边界、11接收者和10供体；干预的是当前分支输出，不是历史形成过程或整个层。
2. 离线预测的K(r)、K(p)、K(z)及其逐情景变化，明确后续真实响应可能推翻。
3. FIX中至少3/4方向各5/6情景，两事实均使K(r)降低，情景均值降低≥25%；同时分子变化换算为共同原r尺度的绝对logit变化≤0.1（两事实均须满足）。这筛选的是“主要影响尺度”的具体预测，而非任何能改变停止分数的操作。
4. U1/U2接受同样计算并完整报告；不要求随机切分必须阴性，也不根据其结果更换候选。

如果前述候选没有通过离线检查，不取第二名补救；报告“没有得到本轮定义的尺度干预预测”。这些门槛只筛下一轮成本，不证明分支必要性或完整机制。

## 6. 出口：不把准备分析无限延长

- **有候选且有尺度预测**：另写B3-P1单分支因果合同，让真实下游正常响应，检验预测兑现程度；FIX与随机切分相同操作。需要模块级等幅、等即时停止投影参照以区别泛化几何改变，具体可实现性与预算在该合同中验收。
- **账目集中但离线预测失败**：说明顺序分账不能支持该恢复操作；不把占比称因果份额，也不按排序自动换下一个分支。
- **分散、平方根效应主导或数值不可判**：如实退出此选点路线。若未来提出生成假设的有限干预，须另有明确问题；本计划不自动启动扫层。

后续“更多随机切分检验RMS差异”是另一独立问题，须另定样本数、种子、情景内比较和预算；每个切分新增两格仅是端点成本，不包含其因果干预、校准与重建成本。无需为了本轮选点先扩随机面板。

## 7. 实现验收、成本和交付

成本：新增模型前向/形成/评分/校准/生成/GPU均0；CPU累计≤4核小时；已有张量按清单读取，新增小表与报告≤100MiB；不复制权重或批量生成新大张量。只有原B3张量的必要传输，不宣称其已在本地。

验收顺序：哈希和四格身份→BF16逐层闭合→FP64能量恒等式→四格和逐层总账闭合→p/r与既有读数对照→选点及退出分支测试。FP64恒等式绝对误差须≤`1e-9×max(1,相关能量绝对值之和)`；与BF16 logits的差沿用B3的0.15 logit验收线并报告实际最大值，该误差不用于判断影子预测的0.1门槛（后者在同一FP64公式内比较）。真实模型实验届时需单独处理数值误差。

测试用人工四格检查：完全相同、纯加法却因范数产生交叉项、正负分支抵消、小分母、影子替换无变化、所有候选失败与唯一候选通过。测试不加载模型。若记录不全或恒等式失败，停止，区分工程失败与无候选；不自动补GPU。

反方复查及修订：

1. “平方范数可加账就是因果贡献？”不是；已保留内积耦合和顺序依赖，只生成预测。
2. “K(r²)大就等于K(r)大？”不是；已逐格开根并单列，不能从一个强推另一个。
3. “恢复分支必然降停止？”不是；所选操作来自已见供体，真实MLP/后续响应未知；预测还要求分子近似不变，不能用任意压低读数过关。
4. “这是另一轮热点筛选？”这是一次围绕新尺度观察的能量选点，仍属探索；因此设置单轮、单候选、失败不递补，并必须给出干预预测。不能持续用本方法无限细拆。
5. “随机分母小会夸大FIX优势？”本轮不以随机比值判特异性，所有原量公开，更多随机留给独立验证。
6. “0.1门槛小于旧logits重算误差0.15？”离线同公式差与跨实现误差分开；候选只供后续验证，不能宣称0.1以内的原模型变化已经测得。
