## 1. 重新定义对象：前文如何通过持久状态影响当前回答

建议首篇正式研究的问题是：

> **混合语言模型中，前文内容的提取与前文规则的执行，分别怎样依赖 KV、递推和短卷积状态；这种依赖在延迟和干扰下是否稳定，又由哪些写入、保留和读取运算产生？**

这是自然前文形成的推理状态机制。主实验不先往模型插针制造故障，也不要求正常模型必须答错。内容提取、规则执行与生成稳定性分开测量。权重知识、外部检索数据库和跨会话产品记忆不在本研究定义内。

首要结论范围是被测混合模型，涉及两个架构族和一个族内规模对照；不先许诺“所有 LLM 的机制”。纯注意力模型可作边界参照，其 KV 内部如何分工是不同层级的问题，不存在的递推状态不能填零后当作同一消融臂。

这相较原 Proposal 是实质性转向：先研究自然缓存的功能与动态依赖，再问稀疏激活干预如何利用或扰动该依赖。旧实验保留三种用途：实现经验、工程回归案例、后续扰动扩展；不参与正式面板选点，不作为确认集或现象普遍性的证据。

## 2. 以友军工作为起点，而不是重新发现缓存有用

## 3. HanLab 的广谱实验到底值得学什么

没有所有论文共用的“第一个广谱实验”。可以区分三种证据结构：

1. **广度与边界：** StreamingLLM §4.1 在多个模型族和尺度上使用统一的语言建模终点，与 dense、window、recompute 比较；它另测问答边界。长序列生成稳定不能等同于保留全部远处事实。[原文 §4.1、附录 C–D](https://arxiv.org/html/2309.17453v4)
2. **同预算的因果选择：** DuoAttention Fig.1 按不同顺序限制相同比例的头，包括随机顺序，观察同一检索终点的变化；随后扩展模型、任务和缓存预算。不是凭某个头的注意力图宣布其代表全部模型。[原文 Fig.1、§3](https://proceedings.iclr.cc/paper_files/paper/2025/file/5c1ddd2e59df46fd2aa85c833b1b36ed-Paper-Conference.pdf)
3. **选择依据与选择数量分离：** AWQ Table 1 对比相同保护比例下的不同选择规则，包括随机选择。可迁移的是控制预算的逻辑，量化结论不能直接搬到缓存状态。[原文 Table 1](https://arxiv.org/html/2306.00978v4)

本研究据此采用：**统一问题与终点的广谱面板 → 独立开发的定位规则 → 等预算反事实 → 新条件预测。** 不把“广谱”等同于先扫所有神经元，也不照搬缺少不确定性报告的做法。纯机制研究不需要先做硬件排行榜。

## 4. 第一项正式实验 G：状态功能与时间依赖的广谱诊断

### 4.1 要区分的解释

| 待检验解释 | 事前可观察预测 | 哪种结果会限制该解释 |
| --- | --- | --- |
| 功能分工在所测范围相对稳定 | 不同任务对各状态的来源依赖，在长度、延迟和干扰条件间大体保持排序 | 排序随任务或间隔系统反转；只能提出条件化分工 |
| 延迟/干扰改变状态的可用性 | 同一任务的来源依赖随匹配的间隔/干扰变化 | 在精度足够时仍无有意义变化；不能把未显著直接写成不变 |
| 前文可报告与实际执行是不同计算 | 对同一规则，“说出规则”和“执行规则”对状态的依赖不同 | 两者持续同步变化，或差异完全来自基线难度 |
| 混合操作造成非特异破坏 | 多属性一起退化，难以跟随任何供体；同内容换表述也引起类似异常 | 来源选择性在双向与替代表述下复现，会削弱这种解释，但不能完全排除分布外问题 |

这些解释可以部分并存，不强迫实验选出唯一胜者。第一轮定位的是功能依赖和边界，还不是完整写入—读取机制。

### 4.2 模型面板：按比较目的选，不按 toy 效果选

建议核心面板为：Qwen3.5-4B（与 C1 衔接）、Falcon-H1-3B-Instruct（第二混合架构族、与 C1 衔接）、Qwen3.5-9B（同族规模对照）。这是候选清单；精确 revision、可用实现、许可与资源在合同冻结前核验，不据名称推定配置或本机已有权重。

两个族的差异同时包含训练数据、规模、训练配方等因素，因此只能称跨模型复现/边界，不能把结果差异唯一归因于架构。一个族内的两个规模也不建立缩放定律。若先做单模型工程预检，只能称预检，不能提前报告广谱结论。

纯注意力参考可作为独立扩展，在相同任务上验证现象是否依赖混合架构；不让它承担无法定义的 KV/递推三因素比较。首轮优先保证核心面板测量有效，而非堆模型数量。

### 4.3 任务面板：相同前文，拆开“记住什么”和“怎样使用”

**桥接面板：** 按 C1 原设置复现其四类诊断任务，保留原评分规则；目的为测量对齐，不将复现当新发现。若实现或基线不符，先解释差异，不在不可比的基础上画增量结论。

**机制主面板：** 使用可控制、可程序判真的前文，每个基础情景包含可独立改变的两类属性：

- 内容 F：例如一个实体的值或一组关系，版本 F0/F1 各有明确真值。
- 规则 P：例如值到标签的映射或有明确判据的输出约定，版本 P0/P1 各有明确真值。
- 生成四个完整前文 H00、H01、H10、H11，避免把“事实 A 永远绑定规则 A”变成设计混淆。
- 对同一前文分开问：检索值、报告规则、按规则处理该值。执行题应使四个 F×P 组合产生可区分的有效答案，防止从一个答案无法识别其来源。
- 同一比较中的后续查询、模板、输出上限和解码一致；报告规则与执行规则两类查询是不同任务，不能据绝对准确率差直接推断内部功能。

至少覆盖任意键值检索、关系/组合使用、规则执行三类任务，每类使用不同模板簇而非只替换名字；语言跟随作为与 C1 衔接的终点，开放人格评分不作为唯一主指标。

人工或程序可验证主任务用于识别因素；自然文本/真实指令材料另设外部验证面板，复用合适的公开任务及评分，不把所有维度塞进综合榜单均分。语料难度在独立开发集调整，不能按正式干净输出逐题筛掉难题。

### 4.4 长度、延迟和干扰：避免三个因素混在一起

首轮广度围绕问题所需的轴，不做全模型×全任务×所有层×所有 token 的笛卡尔积。

- **固定总长度改变信息到查询的距离。** 调整无关文本在信息前后的分配，覆盖近/中/远三个位置；报告这同时涉及绝对位置变化，不能称纯时间因果。
- **固定信息到查询距离改变总长度。** 通过信息之前的前缀改变总长度，设至少两个长度档，作为独立对照，避免把长上下文效应当成遗忘。
- **固定长度和信息位置改变干扰内容。** 无关填充与匹配长度的任务相关干扰配对；干扰涉及不同实体，或明确标注为无效旧记录，真值不能含糊。合法修订指令会改变正确答案，应单独做更新任务，不能记作遗忘错误。
- 同一模型内做精确 token 位置匹配；跨 tokenizer 共享语义情景并报告实际 token 长度。不能同时假装语义文本和每个 token 边界都跨模型完全相同。

主配置和可行的交叉单元在冻结表中逐格列出；未运行单元标缺测。核心长度不超出各模型声明支持范围，超长外推另立问题。短卷积动态后续需另加围绕其实际窗口长度的近距离采样；不能只测很长间隔后宣布卷积无用。

### 4.5 状态操作：先全局功能，后局部位置

对每一对匹配的自然前文 A/B，分别正常处理到查询前的同一边界，获得完整状态。主因果面板使用同形状、等位置的自然供体替换，不先做异常通道加法。

在确有三种状态的模型上，记 K=KV、R=递推、C=短卷积，组合为 {A,B}³，共八种来源组合，包括全 A、全 B 与六种混合状态。每种状态类型先覆盖其全部对应层，避免预选 L12；只改变事实、只改变规则的供体对为主，事实和规则均改变的供体对用于检验组合与交互。四种自然完整历史提供相应语义参照。

八组合支持在指定背景中的来源效应及交互分析，不等于信息在三种缓存里被独占存储。K/V 初期一起替换，是否细分由后续问题决定。随机不同题供体会同时改变太多因素，不能替代配对自然供体的主对照。

**分两种时间干预，不混算：**

1. 广谱主测量：正常处理到查询前再交换状态，测当时的可用状态对回答的作用。
2. 在预先平衡抽取的子面板：信息写入后立即交换，随后馈入完全相同的间隔文本与查询，测这段状态变化如何继续传播。它回答保持/传播，不能与第一种直接合并为一个“贡献率”。

两类比较均不删除其他状态，不改变查询 token 和位置。零化/删除臂保留在 C1 桥接与必要的诊断对照中，不能自动解释为正常运行的信息专属载体。

### 4.6 工程与可比较性门槛

必须核对实际持久字段、聊天模板切分、RoPE/位置、缓存长度、递推初始化标志、短卷积布局，以及候选评分/生成是否复制状态。常规一次前向与分段前向对齐；同源组装与不组装对齐；直接验证恢复的递推状态在实际查询执行路径中被读取。容差按精度和内核预先校准，不把所有内核差异都要求为逐字节一致。

**原文中一个值得单独控制的细节：** C1 的 rec-only 删除 KV 后将查询位置设为 0，而 full/kv-only 从上下文长度处开始；其短卷积随递推一起操作。因此必须分别交付：忠实原协议的桥接结果，以及本研究等长度/等位置自然供体的比较。不能默默改原协议再称严格复现；也不能把原删除臂差异不加限制地解释为纯内容作用。该差异本身尚不能推翻原结论。[C1 附录 B](https://arxiv.org/html/2609.04434#A2)

### 4.7 读数、统计和第一张主图

**主行为读数：** 内容提取正确率、规则报告正确率、规则执行正确率、联合正确率；混合状态下另分答案跟随哪一供体，以及无效/未交付/矛盾。某个臂不应执行某供体规则时，用其预定义反事实目标解释，不能统一按原 A 答案计“错误”。

**次读数：** 固定候选的定向对数概率差、EOS 与生成稳定性。全词表最大非 EOS 的身份会变化，若后续分析停止机制应保留实际竞争 token；第一轮不把停止预设为核心故障。

按基础情景配对，事实/规则版本、查询和状态臂均为情景内重复，不把生成条数当样本数。按模板簇作敏感性分析；确定性 greedy 重复相同输入不增加独立证据，随机性来自情景抽样、填充材料和后续随机子集。不同模型分别报告，跨模型均值不冒充模型总体推断。

首先冻结少量主效应/交互对比和多重比较家族，其余完整图为探索性。样本量依据独立开发面板上的不一致率、目标置信区间宽度及最低有意义效应规划；当前不凭惯例写一个“96 题足够”。干净表现处于地板的单元仍报告，标注不适合机制比较，不在观察干预效果后替换。

第一张主图应展示：**模型 × 功能终点 × 延迟/干扰下的状态来源依赖曲线**，附正常状态表现和不确定性。它回答“功能关系稳定还是条件依赖”，不首先画层热点。另给混合状态无效输出率，避免只统计成功输出中的漂亮来源分离。

### 4.8 G 怎样算有效、下一步如何决策

| 结果 | 科学解释与下一步 |
| --- | --- |
| 基本复现 C1 且跨所测条件稳定 | 稳健性证据成立；继续问具体运算能否解释，不能只靠扩题扩模型宣称新机制 |
| 依赖随延迟/干扰系统变化 | 冻结候选交互，用新题确认，再针对保留或读取过程定位 |
| 主要是无效生成和混合破坏，没有属性选择性 | 优先检查拼接适用性；换用局部写入或自然路径重算对照，不强行命名功能 |
| 模型间关系不同 | 明确条件边界，检查实现和任务地板；不选择性删模型 |
| 工程门槛或原协议复现失败 | 交付失败定位与差异，不进入建立在该操作上的机制主张 |

有效实验的验收是：问题可区分、操作有效、结果来源完整、能收窄下一步，而不是必须显著或必须发现反直觉现象。

## 5. 后续三项实验：由广谱证据决定定位，不由旧热点决定

### L：功能作用分布在什么范围

在 G 已确认、非地板的功能关系上按预定规则取案例，同时保留随机案例和无效案例。跨全深度作等大小层组调查，在开发集形成排序；在留出题上比较“高作用组优先、低作用组优先、多次随机顺序”与状态替换比例的曲线。各比较在同一模型、同一状态类型内匹配组数/张量规模并报告差分幅度；不同类型不因同样 10% 就视为等能量。

做双向替换及必要的联合组对照，评估背景依赖和交互。若高/低/随机差异不复现，就不建立固定关键区主张。L12 若再次出现是新面板结果，而不是设计前提。

### M：具体写入、保留和读取为何产生这种关系

在 L 的开发案例上审计实际更新方程，记录必要的写入、门控、查询和读出量；分别改变写入项、保留过程和读取项，重新沿下游计算。利用 WriteSAE 等已有计算分析时，单独检查其前提，不把简单 logit 公式直接外推到长自由生成。

要求解释对独立题给出方向或幅度预测，并与状态差范数、延迟、深度等简单基线比较。只有可视化或 probe 可解码不证明模型实际使用；局部干预有效也不证明唯一自然路径。

### V：对下一步有用的前瞻性检验

机制模型冻结后，预测未见情景/干扰条件中的来源选择与失败，以及哪种有限状态操作能改变目标属性、保留另一属性。与同规模随机操作和简单状态规则比较，同时报告内容、规则、稳定性与计算开销。

这一验证可以证实机制具有操作价值，即使还没有优于强方法的部署算法。稀疏插针只在此后作为独立外部扰动检验：它是否沿已识别路径写入和持续；不反过来要求自然机制必须解释旧 toy 的所有异常。

## 6. 执行顺序、成本与文件状态

顺序为：**工程与原协议桥接 → G 广谱诊断 → 留出确认候选关系 → L 因果定位 → M 计算拆解 → V 前瞻检验。** 各问题独立合同、独立结果，可在负结果或证据不足处正常结题，不自动开车队。

冻结前需补齐模型 revision、各模型状态映射、语料许可与版本、题目/模板簇、长度与位置表、供体组合表、统计家族、样本量依据和资源上限。预算按“基础情景×时间配置×供体对×状态臂×查询”显式展开并去重；内部前向、自由生成、阅读与失败成本分列。多查询可共享只读 prefill，但每条执行独立复制缓存。

当前尚未获得新实现吞吐与正式样本量，不报虚构卡时。控制成本首先减少不必要的轴交叉、复用同源 prefill，不能只剩一个强效点却仍称广谱。
