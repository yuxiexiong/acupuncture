两端之间还缺这个解释

写入差异 → 实际净读数的任务作用 → 来源选择

哪些差异在读取时保留下来、被扣除或转成不同读数？是否还必须包含背景相关的后续转换，才能解释强弱组合？

读取与后续计算可以共同决定结果。当前选择了要补的关系，尚未选中真实原因。

已经接上的部分：ΔH列的分子用途有强作用；其C/H任务作用约0.481/5.911，不能只靠答案余量解释。不能越过的缺口：HC的来源选择弱，不等于已证明它的内部任务响应也弱；这一列不能借用ΔH列的排除结论。
补上有什么价值：一个解释要同时说明“HH为什么强”以及“HC、CH为什么弱”。只多出一个向量范数，或再证明某个系数有效，都不算把这处连接补上。此处优先不代表其他缺口消失，也不代表已经解释整个课题。
为什么它排在其他连接前面？

它的写入端、完整答案端和部分用途证据可直接对齐，且两个弱组合能约束解释。最近备选是SPF中受针q/k使供体V失去来源选择，但部分写入链已由LVK完成，剩余条件更混杂。自然V到停答更贴近原针，却还缺明确的中间计算候选；继续细拆门交换误差主要完善局部操作。详见已审查的A032，无新实验方案。

完整比较与Advisor处理

图中几个词，用白话读

针：对指定少数激活坐标的修改规则，可以在多个位置重复施加。

内部历史：模型留下的状态，不只是聊天里看得见的文字。

V / KV：这里是模型里的计算量或缓存名，不能直接等同于某种语义内容。

C / T / H：干净 / 原生受针 / 指定恢复后的混合背景。H不能当成T。

ΔC / ΔH：在C或H来源轨迹上形成并保存的写入改动，不是两条轨迹总差。

条件因果链：在特定条件下，改变或撤回某项用途确实影响行为；范围不能自动扩大。
