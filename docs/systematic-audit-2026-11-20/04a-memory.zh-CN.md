# 递推记忆、混合模型与来源选择的十篇全文比对

阅读截至 2026-11-20。以下逐篇核对 arXiv 正文从引言、方法、实验到讨论或局限，并回查文中注明的附录。数据均为论文作者报告。Acupuncture 的 C 为干净背景，T 为原生受针背景，H 为受针后将指定卷积历史恢复为本题干净值的混合背景。对照中的“同一写入”指固定并重放保存的写入差值；接收状态、下一步的读取和之后的计算可以变化。

### How Linear Attention Remembers — Kichang Lee、JaeYeon Park、Songkuk Kim、JeongGil Ko

**直接覆盖“某条来源的写入如何通过后续读取影响答案”。** 在维基文本中嵌入键值事实，供体和接收者对同一个键给出不同值。作者先在开发文本逐头筛选，冻结候选，在来源不重叠的文本上依次干预事实段的写入、提问前的状态、提问时头的输出，再做反向恢复。三个纯递推模型 GLA-340M、GDN-340M、GDN-1.3B 中，阻断选定头写入使四选一正确率降低 36–79 个百分点，换供体写入使 68–90% 的选择转向供体。把供体状态换入再恢复接收者的读出会大幅消除供体作用。四事实条件下，选中事实可转移 61–89%，其他原本正确的事实受损 0.4–1.4%。写入与读取已经有因果证据，文中还测试了事实竞争和同范数写入方向。见 §§2–4、图 2–8。[论文全文](https://arxiv.org/html/2609.33093)

换到混合架构后，作者发现另一种结果。Qwen3.5-4B 三项任务中，只换提问前的递推/本地状态仅恢复联合供体余量效应的 0.2–3.6%，只换 KV 恢复 96–100%。附录 E.1 在 WikiText、PG19 上的实体更新及约 4K 的 RULER 检索中，单换递推产生的供体答案率都是 0。它约束了把我们的结果概括成“Qwen3.5 通常用递推矩阵保存正确事实”的说法。我们在 KVC 同样发现事实身份可由 KV 搬运。DWC 增加了施针和指定写入、读取操作下对完整编号的获得及撤回；WSB/RCS 增加了干净与修复后受针背景配合的四格行为证据。上述论文并未测试这两种背景的写入差交叉和分子/分母用途。因此对 DWC 的概念重合度很高，对 WSB/RCS 的特定条件结论仍有可说明的距离。[混合模型稳健性检验](https://arxiv.org/html/2609.33093#A5)

### The Key Handoff: Retrieval in Hybrid Language Models — Kaan Kale、Oguzhan Baser、Sriram Vishwanath

作者让模型做两跳查询，改变供体和接收者中的实体绑定及记录顺序，使“跟随供体答案”“跟随同实体在新表里的值”“跟随同一行”产生三个不同预测，并设置第四个参考答案。在 12 个模型的 23 个深度剖面中，转移末提示位置的残差，区分可解码的中间键、仍能驱动查询的键及已形成的答案。进一步在 4 个混合模型换递推层输出，在 3 个模型查读者头。Nemotron-H 在选定的八个头上可复现约全部的键效应，Granite-H 为 69–75%，Nano 为 93–96%。附录 F.3 保持进入末段的残差及卷积历史来自接收者，只换最后注意力之后的递推矩阵，并旋转行以排除位置解释。7 个候选混合模型仅 4 个出现所测读取；普通执行中赔率提高约 1.3–2.7 倍，排名保持。去掉最后注意力的指定更新后，Nemotron-H 中改为记忆供体首选的比例额外上升 22 个百分点。见 §§2–6、表 1–3、附录 F。[论文全文](https://arxiv.org/html/2609.32942)

**直接影响 DWC 的三路判别，也影响 WSB 的背景解释。** 分离位置、绑定、答案复制已有受控先例；同样的记忆替换在两个入口状态中能有不同的首选后果，也有明确先例。它检验末段递推矩阵及注意力更新，标志性终点是候选余量/相对赔率及排名。我们实测的是因稀疏干预形成的背景，并在恢复原题交付后重放保存的写入差，再操纵第二步的特定用途。二者在“背景影响来源证据能否跨过选择边界”上已经重合。在“同一新增分子用途的连续响应在 C/H 本身差约 5.430 logits”上，本文没有对应对照。[状态交叉与阴性模型](https://arxiv.org/html/2609.32942#S5)

**它直接占据“递推信息可决定混合模型选择哪条记录”，并提供比我们更广的模型覆盖。** 本项目在 QST 中异查询供体的指定卷积 q/k 移植失败，在 SPF 中则发现某些背景下换缓冲能强烈驱动供体选择；这些结果的时窗、变量和终点不同。不能用 QST 否定文中的地址块，也不能由本文认定我们已定位到同一读者。论文的成功移植与移除后的准确率可以并存，为我们解释“原题答对，但写入使用方式已经不同”提供既有参照；它没有施针后的 H、差值双交叉或 RCS 分子/分母端点。[同模型与跨架构对照](https://arxiv.org/html/2611.01909#S6)

### WriteSAE: Sparse Autoencoders for Recurrent State — Jack Young

作者训练与原生缓存写入形状匹配的稀疏字典，在某个原子自然激活的位置，用学到的矩阵替代当步原生写入，与删除写入及随机原子比较，用后续词分布的 KL 评价。Qwen3.5-0.8B 三层同头合计 4,851 个位置，替换优于删除为 92.4%；这是位置汇总，不能全部归给代表性 L9H4。文中用遗忘门、读查询和输出投影近似预测词分数。附录 A 审计在主导 logit 的原子/剂量格中得到中位 R²=.983，在排名约 50 的尾部降至约 .05；独立单位置定向试验 2,000 次中符号正确 84.6%，汇总幅度 R²=−.06。4B 的 L12H8 单写入替换仅 48%（600 次），跨到 Mamba-2 的同式预测 R²=−.07。生成终点是目标词在 20 个词内至少出现一次，4B 另有换行/大小写试验，不能当作问题的完整正确回答。见 §§2–6、表 2–4、附录 A/F/I。[论文全文](https://arxiv.org/html/2605.12770)

**它已覆盖 Qwen3.5 的运行时写入替换、读者依赖、基于门和查询的词分数预测，以及部分生成行为。** 我们不能将写入可干预、读者方向重要或一阶预测可成功作为方法首创。论文的遗忘门是写入后跨位置保留的一个因素；NGU 改的是同一新增分子读数的输出门用途，比较 H→C 与 C→H 两个方向并对照完整来源选择。TGA 对已有 168 冲突配对做端点校准。其适用域及误差度量都异于 WriteSAE，不能拿两项拟合数字判断谁“解释了更多机制”。[公式的限制与实测失败](https://arxiv.org/html/2605.12770#S6)

### Reading Is Not Using: Retrieval, Judgment, and the Design of AI Financial Research Workflows — Miao Liu、Zhizhe Liu

作者在 12 家公司的年报中插入有可核查数值的风险段落，与五种等长中性替换比较，增加与公司无关的背景至 2K–128K tokens。分别询问披露事实与投资判断，用实测中性插入波动校准决策影响。在 Qwen3.5-9B-Base 的前置填充条件，目标对卖出概率的平均影响从 +.032 降至 +.004；四档长度直接提问均 12/12 正确。§5.4 在同一披露边界交叉整组卷积与递推状态、保留另一段的 KV，再继续处理文本。换中性运行状态，原披露影响减约 65%；反向换入产生约 44%；全注意力屏蔽扣中性槽位后为 44–48%。两种操作的移除效应之差未分开（配对 p=.54）。附录 D.2 说明移植只用一个中性对照、边界可差 −9 到 +11 tokens、渠道不能相加。§6 用工作流比较确认，针对披露的结构化重述能增加决策影响，泛化摘要经常遗漏披露。见 §§3–7、表 2/3/6–9。[论文全文](https://arxiv.org/html/2608.24842)

**它是真实文档上“能取回但未必有效使用”的近邻，并有整类 GDN 历史状态获得/撤回对照。** 这个一般性论点和用反事实终点检验的思路已有实证。这里跨的是信息内容或背景长度，依变量是决策概率。Acupuncture 以相同问题、经施针或指定修复的历史和任务内供体编号为条件，定位用途到下一步的分子、分母与输出门。真实年报证据提高了邻域工作的任务广度，却没有给我们单模型机制补上外部效度。[因果渠道比较](https://arxiv.org/html/2608.24842#S5)

### LatentPort: Beyond KV Cache – Cross-Model Transfer of Recurrent Memory in Hybrid Language Models — Simon P. Villani

Qwen3.5-4B-Base 读 4,096 个前缀 token 后，把 KV、递推矩阵与卷积状态交给几何匹配的 9B-Base。作者比较直接复制和学习映射，以教师强制的后续 64 个 token 的负对数似然衡量交接。在 64 本 PG19 文档上，固定经映射的 KV，加入 GDN 状态包后，平均改善 .7473 nats/token [ .6921,.8047 ]，64/64 同向；包同时含矩阵、卷积和初始化语义。另一组新文档上，小型残差校正使 NLL 为 1.989，相对 9B 原生的超额 .076，首选一致率 .864；三个近原生门槛均未过，16K 阶段未运行。附录 F 的直接/映射八格显示，KV×递推的交互在验证上 .0284、留出测试 .0151，低于事前指定 .02。全状态错供体则明显退化，但不能定位来源特异性属于哪个子成分。见 §§2–8、表 3/4、附录 F。[论文全文](https://arxiv.org/html/2609.25053)

**跨 4B→9B 使用递推/卷积缓存，并用状态组合和行为来判断兼容性，已有工程实证。** 这个结果削弱“不同规模能交换历史状态”作为独立贡献。它运行的是不同模型的完整前缀状态交接，没有比较一个模型在 C 与 T/H 中对同一写入差值的响应，也没有推理自由生成是否回答供体对应的记录。作者报告的 .918 是空缓存至原生 9B 的续写损失改善恢复比例，无法替代 WUS 尚无的跨尺度完整答案结果。[组合与结果界线](https://arxiv.org/html/2609.25053#S4)

作者在约 5,000 tokens 的检索上下文中改动一段等长事实记录，要求直接读取新值，或经过修改后的别名选择下游未修改表中的答案。在 Llama-3.1-8B、Qwen3-8B、Mistral-7B 上比较两个可逐位置对应的操作：从完全重新预填的正确缓存复制 KV，或在含旧状态的接收上下文重算相同位置。在留出两跳题中，三模型分别保留 34/75/58 个正确参照可答样本。按移植时的因果作用选 8 个位置，直接移植可恢复 .918/.952/.969 的新旧答案余量，但是原位重算仅 .209/.011/.008。167 个留出位置集合逐一相同。改成连续重算紧邻编辑的 32 个位置时，三模型余量恢复 .993/1.007/.937；把真正需要的下游记录移开 250 tokens 后，仅 .09/.01/.01。表 2–3 同时给出余量和新旧答案翻转率。正文承认 16-token 贪心输出、只保留正确参照可解题及移动位置伴随新近性改变。正文提及另行提供的补充附录，但公开 HTML 和 arXiv 源包仅见主文、参考文献、模板与三幅图，附录未取得。[公开正文](https://arxiv.org/html/2609.17983) · [arXiv 源包](https://arxiv.org/src/2609.17983)

**它直接限制“换回某块有效就找到了原故障的生成原因”的推理。** 外来干净状态可能携带该部件之外上游已算好的信息。相同位置原位生成时，会继承周围的受损历史；作者把这两个操作放在完全同一组位置上做了较强反例。Acupuncture 的分层移植、WIN 的窗口修复及 DWB/DWR 的定向搬运应按实际操作描述。原文考察文档改动后过期的全注意力 KV；项目在同文本上施加激活干预，以 T 或混合 H 在 GDN 的指定写读位置继续运行，数据和操作无法直接互证。尤其不能将 WSB 四格搬运成功视作在原生受针模型中已经重建同一条自然因果路径。[正文对照与适用边界](https://arxiv.org/html/2609.17983)

### Tail-Replay: Escaping the Curse of Linear Attention in Prefix Caching for Hybrid LLMs — Yirui Liu 等

作者考察同一模型的前缀复用：完全保留全注意力 KV 和相应层的输出隐藏向量，只在每组递推层的最近一段重放已经保存的隐藏向量，以近似重建递推状态。比较完整预填、只保留全注意力 KV 而把递推状态清零、重放最后 5% 或 10%。三种 Gated DeltaNet 混合模型为 OLMo-Hybrid-7B、Qwen3.5-4B 和 Qwen3.6-27B。Qwen3.5-4B 在 LongBench 的完整/清零/5%/10% 分别得 .374/.271/.369/.367，RULER 得 .960/.415/.959/.958。附录 A 表 3 可见 Qasper@16K 为 .487/.355/.482/.461，增加重放量未使每项成绩单调提高。表 2 的 Qwen3.5-4B 在约 32K 命中前缀上，预填至首词耗时 786.4 ms，5% 优化重放为 86.2 ms。见 §§2–5、附录 A。[版本 v2 全文](https://arxiv.org/html/2608.30310v2)

**这项工作直接覆盖“在精确全注意力信息仍可用时，局部重建递推状态能恢复模型的任务表现”。** 它在真实任务集上验证近似重建的平均行为质量，说明恢复得分可以容许状态差。起点是正常输入前缀；每组还读入原预填保存的全注意力隐藏向量，其中已带有早期上下文。不能从中断言稀疏针的早期历史已遗忘，也不能把其 98.9% 相对 LongBench 分数与我们的状态差搬运比例相比较。对 Acupuncture 而言，恢复后的原题得分与恢复后的供体写入用途应继续作为两个实测量；WSB/RCS 比较的是后一问题。[实验与任务分解](https://arxiv.org/html/2608.30310v2#A1)

### Aborted but Not Forgotten: KV-Cache Retention Breaks Rollback Consistency in Language Agents — Guijia Zhang、Harry Yang

论文检验应用可见记录已回滚后，推理状态是否也与已提交记录一致。作者在受控环境固定决策步骤输入，比较不同历史形成的 KV。在七个开放权重模型的固定 63 个条件中，最终送入的决策 token 逐条件相同；保留分支状态时 25/63 出现受保护决策变化，从已提交记录重建缓存时为 0/63。附录 A 分开定义状态能否从已提交记录重建、有限输入面板上输出是否一致。即使内部状态不一致，一些模型在全部九个已测条件上仍给出相同决策。这是固定条件下的确定性计数，不能解为总体发生概率。作者的事务级状态恢复解决的是逻辑回滚与推理状态的一致性，相关输出仅来自实验环境。见 §§2–4、§6、附录 A。[版本 v1 全文](https://arxiv.org/html/2608.15939v1)

**“固定当前 token、仅变历史状态，就能改变真实行为终点”已有直接的实验方法先例。** 该文的历史差来自先前文本分支，当前决策 token 相同；Acupuncture 从同一段前缀文字出发，改变形成历史时的少通道激活，还能把递推/卷积/全注意力成分和后续读取用途拆开。该文中有限测试行为正常不保证状态相同，与我们在 C 和 H 都能答原题时仍观察到差异相容；它没有测量对同一来源写入的条件响应，也没有证明我们在原生 T 中已定位到完整的答案故障原因。[状态和行为的定义](https://arxiv.org/html/2608.15939v1#A1)

## 这组比较留下的实质区别

已有论文分别实现了来源写入、读取获得与撤回、同一供体在不同接收状态产生不同后果、混合缓存交叉、在同系列模型上把递推写入作用与任务响应连接起来。“来源信息能在历史状态中延续并影响答案”与“模型答对时，读取过程仍可不同”两种宽泛表述均有直接先例。本项目较有辨识度的证据集中在同一正常作答面板里的联合比较：保存的 ΔH 只有配合修复后的受针背景 H 才强烈改变完整来源选择；分离新增读数的两种归一化用途后，强效落在分子用途；换门可减弱 H 的实际连续响应和完整来源选择，反向换门未在 C 中取得对应强效。十篇正文没有报告这一组相同对象、干预和端点的结果。该判断仅限实际阅读范围，不能用来宣告全领域首创。DWC 在独立材料上的确认属于另一套操作，未替代这组四格证据的跨任务或跨模型确认。[Acupuncture 实验分册](02-cache.zh-CN.md)
