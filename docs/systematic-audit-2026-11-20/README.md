# Acupuncture 的实验结果与系统查重

**截至 2026 年 11 月 20 日，最有辨识力的发现是：同一个模型在两种内部历史下都能正确回答同一题，但同一份额外写入对后续答案可以有截然不同的作用。** 这项比较有完整编号答案和具体读取操作支撑。前人已经证明少数通道可严重损伤生成、供体写入可改变后续答案，也已在相同的 Qwen3.5-4B 上定位过来源键。本项目的区别集中在**怎样形成写入、什么背景接收它、同一读数进入哪项计算**这三者的交叉。现有实验只在一部分条件下接通了这条链。[缓存实验](02-cache.zh-CN.md) · [最直接的记忆研究](04a-memory.zh-CN.md) · [同模型来源键及因果对照](04d-causal.zh-CN.md)

## 从稀疏干预到完整回答，项目实测了什么

**最初的异常同时包含能力损失、格式损失和截断。** 首批中文开放题按用户要求停于 Q24。另在每项 100 题的快速基准中，持续双通道干预使阅读、数学、逻辑三个严格格式分全降到 0；用相同的显式答案提取器重判干预输出，三项为 11、0、15 题正确。即使把阅读和逻辑都变成强制四选一，正确率也分别从 89% 降到 30%、70% 降到 23%。独立的 1,400 题固定能力面板还可逐题区分“原对改错”和“原错改对”。同族 Qwen 的迁移先学习源到目标表示映射，再投影为目标单坐标；跨族 Llama 只完成稠密映射主比较。两者都有能力损失，随机对照也可造成损伤。证据到达了具体配方在目标模型上的后果，尚不能识别跨模型同源的功能单元。Laya 的结果停在源码和合成 CPU 接口核验。[实验 001–007、013–025 及 Laya](01-early-transfer.zh-CN.md)

**同一段文字可以留下不同的内部历史，而继续生成与答回原题之间还有一步。** 在提示期间施针、之后撤针，固定已见文字，再替换不同层或不同类别的历史状态，可以检验早先的干预是否仍影响后面的生成。一组 24 题中，换回指定层组状态使首步停止从 24/24 降到 0/24；按旧口径只有 7 条命中核心，逐条复查其中 6 条还改动了问题前提。在另一组原生受针条件，恢复晚段的一个值输入，首步停止从 12/12 降到 0/12，只保留那段值的变化则回到 12/12。后者已把一个局部计算接到停止行为，但其终点仍是第一步。换成完整编号任务后，能保留几乎全部停止分差的一组头，四方向 48 题的严格格式交付为 0，而全值恢复为 48/48。[缓存分册，026–053 与原生首停](02-cache.zh-CN.md) · [原生和混合历史的区别](06-review.zh-CN.md)

**在新题上，写入与紧随其后的读取确有来源特异作用，但两支针的量级不同。** DWC 把六类题各留出 16 个新情境，预先规定用哪些供体记录、何时换写入、何时给回或撤去指定读取，再按模型最终交付的编号检查来源。96 个新情境是推广比较的单位。主方向的写入净转移、读取获得、读取撤回为 .588、.311、.473，按预定的等族权平均均越过 .25。另一方向相应为 .309、.213、.294；中间一项的 95% 区间 [.192, .234] 完全低于 .25。论文表述应保留这个量级预测失败。两方向都存在正向读取作用，所有类别都等强则缺少支持。[逐项设计与冻结判据，166–168](02-cache.zh-CN.md) · [DWC 独立核查](06-review.zh-CN.md)

**两个都能答对的背景，为什么仍可能不同？** 题目要求从多条记录中选出指定编号。C 是正常历史，T 是原生受针历史；H 由 T 出发，把指定 14 层的卷积历史换回本题自身的干净值。没有额外供体写入时，C、H 各答对 48/48。研究者分别在 C、H 中保存“另一条记录相对自身记录引起的实际写入差”，再把每份保存的差分别放入 C、H。这样，比较同一列时放进去的东西完全相同。

| 接收背景 | 放入 C 产生的写入差 | 放入 H 产生的写入差 |
|---|---:|---:|
| C | 0 | 0 |
| H | .00347 | .88194 |

每格均得到 348/348 个有效完整编号。表中数值是按接收者加权、扣除对照来源后的**净来源分数**；右下格仍有 121/348 保持自身正确，不能把 .88194 读成供体跟随率。每行的配对重复使用来自六个已见场景的 48 个输入，这里的背景差距也不能自动推广到 DWC 的 96 个新情境。这个交叉同时否定了两个简单解释：只由写入差的来源决定、或只由接收背景决定。[WSB 原件与四格解释](02-cache.zh-CN.md) · [各格分母与有效性复核](06-review.zh-CN.md)

**沿右下格继续分解，新增读数进入输出分子的作用最大。** 限定同一份 H 写入差，在 H 中让新增读数分别进入输出分子、归一化分母、两者或均不进入。仅分子为 .89236，仅分母为 .02431，两者都用为 .88194，均不用为 .01736。分母效应的区间排除了预先关心的 +.10 正增益，精确的 ±.05 等效判据没有通过。换用 C 的输出门后，H 的完整净来源分数从 .882 降到 .590；反向把 H 的门给 C 后仍为 0。两方向的连续效应各自接受了检验，两者之间的差未直接检验。一阶梯度在 336 个已测背景–配对上可较好预测连续分差，但该分析没有生成新回答。至此仍未证明针怎样在原生历史 T 中形成这里关键的 H 背景性质，也未解释 C 产生的写入差为何在 H 中仍弱。[RCS、NGU、TGA 的方案、反例和数值](02-cache.zh-CN.md)

## 权重修补得到的结果

- **数学与编程。** Qwen 4B 数学固定候选在 2,048 题上修对 31、改错 34，总正确 1,956→1,953，最终回滚。0.8B 的最好结果来自开发集，固定候选验证中断。编程线保留了原版运行和预检，缺少完整干预与独立终验比较。[数学与编程分册](03-wsp.zh-CN.md)
- **视觉与常识冲突。** 同一张反事实图有时要按图回答，有时要按通常世界知识回答，两个问法都对才得联合分。Qwen v8 在 256 个开发配对上从 149 增至 181，净增的 32 对按模板拆开，原问法净增 3 对、改写问法净增 29 对。对满足保护条件、在两种名称顺序下都稳定失败的来源，要求同一补丁把该来源的四条冲突回答全部修好。已测候选达到这一标准的为 Qwen 0/4、Gemma 0/16。开发中的局部改善与严格标准下的零新增修复同时成立；独立终验材料已冻结但未运行。[八组开发结果、逐题重计及严格分母](03-wsp.zh-CN.md)

## 复核与范围

三位子 agent 分别复核早期与迁移、缓存机制、权重修补；另由独立上下文的辅导师专门复核解释。三份实验分册分别说明证据深度。早期从原始 JSON 清点 18,272 份输出、重计固定能力面板的 1,400 对答题转移。缓存分册对 104 个历史目录的 470 处原文引用核验哈希，打开 79 个目录的机器表、62 个目录的正式回执或分析，并从逐对数据重算 336 个梯度预测。视觉分册按原口径逐条重计了四组共 368,640 条保存回答。其余条目按已有协议、正式回执、原报告和历史全章注明来源。一次运行产生的多个回答、重试、多个目录都不能当独立实验。本次只读旧数据并作离线重计，未启动模型或 GPU。

独立核查指出的三项更正已反映在正文：同族和跨族用了不同迁移操作；两个方向换门的估计不能写成已经检验了方向间差异；VLM 预印本晚于本项目实验。本轮 40 篇逐篇报告均查阅全文，另核作者博客；历史候选仅凭题名或简介的记录不用于断言项目新颖。已核范围内，尚未看到与“实际写入差跨两个可答对背景的完整选择四格，再在固定差上分解其用途”完全对应的实验。这个判断随检索范围、模型、任务和终点而定。[独立核查](06-review.zh-CN.md) · [查重范围与限制](04-literature.zh-CN.md)
