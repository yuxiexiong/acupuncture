# WSP-VL-SCREEN-01：设计自查与反方复查

日期：2026-11-05。对象：[行为筛查与WSP衔接方案](wsp-vlm-behavior-screen-v1-2026-11-05.zh-CN.md)。规范：[experiment-design-self-check v1](experiment-design-self-check.zh-CN.md)。

身份：同一设计助手的自查，不是独立审查。按用户要求只交付文档；本次仅进行了文献/数据卡读取、CPU预算与概率枚举，没有模型/GPU实验。

## 1. 设计卡

| 项目 | 决定与理由 |
|---|---|
| 主线 | 研究者AI通过反馈诊断并发现后训练稀疏权重修补，修复具体VLM失败；不将一般低分或探针读出替代修复目标 |
| 本轮问题 | Qwen3-VL-4B-Instruct在混合计数、空间条件计数、反事实图下通常大小三任务上，是否有稳定的大缺口值得进入WSP诊断 |
| 增量 | 不复用旧Qwen2/纯文本结果当基线；得到目标模型具体失败、同源成功对照、提示响应、确认结果和下一步选择，避免继续凭类比指定层号 |
| 依据 | 模型卡/固定processor、VLMCountBench论文、SPHERE明确对应题字段、PvP与Visual CounterFact；旧WSP工程仅作接口资产 |
| 反例 | 强提示可能足够；正常和挑战都差；合成风格可能主导；相似错误可能分散在许多权重，不能稀疏修；Jev事实翻转负例说明涨分不等于能力修复 |
| 操作 | 原权重BF16固定；本轮仅改图像条件/问题范围/规则提示/同义模板。无层、供体、hook、梯度、探针或ΔW；权重预算为0。目标输入与所有下游正常计算一同变化 |
| 估计对象 | 固定推理协议下配对题的生成正确率差；A布局/总数受控，B是同图两类任务的描述性差异，C测图片语境对常识作答的总影响；均非内部路径归因 |
| 判读 | 优先/暂不优先/未决，三项主检验固定；提示成功、失败均可提供后续线索但不证明WSP价值；反向分差不算支持预设失败 |
| 范围成本 | 每候选D64/H96；不同模板不能扩n；最多10,560回答、12GPU小时停止线、准备2工作日；本次实际0模型请求/0GPU |
| 退出 | 缺数据为不可判，缺口小为暂不优先，筛查未决不自动扩样；后续只择一个候选另立WSP合同；全无候选可结束 |

## 4. E01–E26历史错误处理

- E01：总体目标为WSP修复；本轮筛查承担必要入口，不替代总目标（§1/§5）。
- E02：不固定原作者两层、原Acupuncture层号；内部位置由以后诊断决定。
- E03：未来支持标量、结构单元、范数分别记；本轮权重变动为零。
- E04：ΔW公式与已知算子是工具，不作为科学新发现。
- E05/E06/E08/E13/E17/E19/E26：本轮不修改共享缓存、不设供体、不做状态减法或形成/读取隔离，具体错误不适用；后续临时干预须另给来源和操作合同，§5不提前认领这些结论。
- E07/E14/E15：当前不从配对/未来局部干预拼成原生机制链；静态补丁与内部临时恢复是不同操作。
- E09/E10/E11：只看真实回答；probe、attention与信息完整性分开；自然回答与teacher forcing分开。
- E12：不把配对自动当去混杂，B的目标集合变化明确；不拿bootstrap或反号补丁冒充零假设分布。
- E16/E18：异号与未决不当实现错误或其余解释胜出；只在独立工程验收失败时停测量。
- E20：计数、空间筛选和证据取舍可以交叠；位置集中和稀疏解不是被强制的互斥假设。
- E21：未做完全部近邻查重，不声称首次；正式贡献阶段要按实际入选任务补齐比较。
- E22：每来源组为单位，模板/顺序/提示不扩n；H看过后不复用为补丁终验；公共基准预训练暴露未知。
- E23：本记录同助手自查；逻辑设计、工程、授权、结果四种身份分开。
- E24：行为具体化本身有阶段增量；不要求此步证明全部机制或稀疏解。
- E25：不同步做探针、全面定位或三路补丁；保留必要成对与提示比较，不为完整感加大型基准。

## 5. 实质反方检查与修订

| 最强反例 | 是否使本轮承诺失效 | 修订/限定与复查 |
|---|---|---|
| A混合图更多对象，因此变差 | 若成立则配对假设错误 | 两图总数、中心布局固定；分类型题只作辅助，不能把其较小计数与总数的差归因组合。C05/C07/C08重查通过 |
| A类别轮廓/视觉复杂度变了，也可变差 | 不否定“混合条件失败”，否定已知内部合并机制 | 明确轮廓变化、只称条件效应；各类正确也不是总数运行内已有答案。后续AI需区分这些解释 |
| B配对仅凭行号／问题编号，实际上不同图片 | 会使配对无效 | 原数据卡有对应关系，仍必须来源ID＋语义/标注核验，实际清单未验收不标可跑 |
| B空间题更小数或更难图、来源不同导致差异 | 不同图已排除；答案/任务混杂仍存在 | 保留同图，报告计数与视角分层；不把差异归为纯空间推理。无需为了该有限结论再造整套数据 |
| C原图通常正确只是猜中了图，根本不知道常识 | 会削弱知识使用假设 | 增加无图通常参照；重点模式还需CF视觉正确，五条件全报，不以主差单独证明知道答案 |
| 全部候选筛得好，但没有任何稀疏可修位置 | 不影响行为筛查，但否定强WSP承诺 | §1明确只选入口；§5给下一步诊断/真实试改，局部不起效或分布式故障允许停止。不能将筛查入选叫WSP可行 |
| 提示已解决，补丁只复制提示 | 对筛查不致命，对高贡献有压力 | 不淘汰；未来须与提示及补丁＋提示比较。仅省提示不足，但也不先设提示为性能上界 |
| 正常/挑战都很差却有小分差 | 弱化条件性痛点，不适合声称“本会做但被触发” | 控制≥70%仅为资源优先级；未满足标非特异失败，不宣布所有WSP方法无效 |
| 选最好模板、最好错误模式、最好任务，H被反复看 | 会制造选择偏差 | 主T0/顺序由hash固定、三候选Holm、D模式登记后H一次揭示；未来新终验。H排序不当可修性排名 |
| 模板变体使有效样本数虚增 | 会虚增统计置信度 | 主检验每组一对；稳健性变体只作相关测量，来源图/对象对不拆 |
| H96检不出15pp，阴性就停研究是否错误 | 若称无缺口则错误 | 附精确功效；多数未显著进入未决。暂不优先需区间支持小缺口或高准确率，不靠p>.05证明无效 |
| 判据无论什么数据都能过或根本不可达 | 会使筛查失去决策价值 | 用手造二元计数核算通过/失败例，见§6；完整多条件门可通过但不保证实际模型通过 |
| 参数表貌似完整，但数据组数/版本未知 | 会影响实施，不自动破坏有条件设计 | 将P0明确列工程门；不足时不运行该候选，不拆组补数。当前未声称ready-to-run |
| 分辨率/截断或评分错误制造能力缺口 | 会破坏目标解释 | 固定输入与输出，P0检查缩放后可辨性，失败率过高审协议；保留raw，不由标签裁判输出 |
| 少量patch列损伤了所有图像token | 是未来编辑的真实风险 | §5要求拟合覆盖实际生效位置与保护反馈；诊断hook效果不能直接等同静态补丁效果 |
| 最后只是提出“继续诊断”，没有WSP怎么做 | 会脱离用户核心目的 | §5列三个任务→竞争解释→定位→三类权重算子→反馈→冻结重载→新终验；不预写不存在的层号和有效系数 |

复查结果：修订后 C01/C02/C05/C07/C08/C10/C11/C12/C13/C14 均仍回答同一本轮问题。余下不确定性是明示的工程/经验缺口，未用免责声明掩盖配对或归因硬伤。

## 6. 本次CPU核算及可重复公式

预算：A=160×4×2×2=2,560；B=160×2×2×2=1,280；C=160×5×2×2×2=6,400；科学回答10,240；工程64＋恢复预留256，总10,560；输出上限10,560×128=1,351,680token。D占64/160，所以4,096；H为6,144。图片/输入token另计，不能据此声称吞吐已知。

对于n=96、主差δ、不一致概率q：m~Binomial(n,q)，在m个不一致组中 b~Binomial(m,(q+δ)/(2q))；枚举每个m、b，以条件零分布右尾≤.05/3计拒绝概率。方案§4.3是其数值。它假设不同来源组独立同分布，仅用于样本量尺度估计。

手造统计fixture（不运行模型，也不是实测证据）：

- **可通过例**：两边对45组、控制对挑战错30组、控制错挑战对5组、两边错16组。n96，控制75/96，挑战50/96，Δ26.04pp；精确单侧p=0.00001118076，最保守×3后0.00003354228。若D差为正、其他模板同号且数据有效，能够通过主门。C还需无图条件≥70%；模式计数可单独不足，不能自动伪造。
- **不可通过例**：b19、c17时Δ2.08pp，p=.4339697；即使挑战总体很差，也不能通过明显条件差门。
- **相同答案例**：b=c=0，p=1，无差异，不能用多次greedy重放“积累显著性”。

因此通过例、失败例、统计不确定例具有不同出口；没有拿3个随机编辑种子冒充零分布，也没有把一次P0正确当科学结果。

## 7. 最终状态

- **设计逻辑：通过本次设计者自查。** 通过的是“在明确数据准入条件下筛查明显行为缺口，并为WSP交付诊断入口”的设计，不是完整WSP修复合同、独立评审或可修性证明。
- **工程验收：未完成。** 数据生成/对应关系/分组量、目标模型、评分器、软件版本和吞吐全部还需实施；不掩盖SPHERE/CF版本及样本量待核项。
- **执行授权：本轮仅文档与CPU设计核算。** 无模型/GPU授权；后续修补也未授权。
- **实际科学结果：没有。** 本次只交付方案、自查、来源链接与已核对的设计算术。

最后复查：如果三个候选都失败或未决，允许结束筛查；如果一个入选，唯一自动产出是该候选的证据卡与诊断建议，不自动启动编辑。总目标仍是AI发现有留出收益的稀疏修补，行为筛查没有被包装成最终贡献。
