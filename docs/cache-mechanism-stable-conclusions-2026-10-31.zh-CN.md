# 缓存机制线：已有证据的稳定结论与推进判断

日期：2026-10-31。性质：截至当前证据的结论基线，不是实验方案或运行授权。依据已完成的S1–S3、两份旧数据分析及其勘误；本次只核对已有文档、合同、收据和汇总，没有新增模型运行、GPU或预测模型复算。由同一助手整理，不称独立复现。

**当前判断：保留缓存机制线的研究方向；本轮探索与因果定位结果可以结案，但原生机制解释尚未完成。停止把近期草案作为默认下一步，不继续追加设计或计算。** 这不是认定课题无价值，而是承认现有证据还不足以选定一个值得投入的具体机制分支。不能用“已经三个阶段”宣布成功，也不能再用“只差补一个对照”推进。

## 1. 核心问题与目前答到的位置

**局部激活干预进入模型后，怎样改变写入、旧状态处理及后续读取，为什么最终造成显著的回答变化？** 缓存机制线解释历史形成与使用在其中的作用。撤针是诊断条件，停止和事实评分是具体终点，都不替代总问题。

目前可以稳定陈述：

> 在已测试条件下，针是坐标稀疏、但校准有效幅度约为参考残差尺度、且在多个token重复施加的干预。它改变原生更新和历史形成；先前历史又改变后来同一针设置的局部反应。指定卷积前V替换能显著改变停止输出。但尚未识别：原生变化中的哪部分经什么读取和下游计算，造成了特定答案竞争的大幅偏移。

因此，“只动一个坐标为什么也可能影响很大”的一个错误前提已澄清：它并非一次微小有效扰动。**“为什么这根针、这个时段和历史造成这种行为，而另一些条件没有”仍未解释清楚。** 大剂量不等于全部答案；不能据此认定只是一般损伤，也不能继续预设特殊放大。

## 2. 适用范围与名词

- 机制面板：Qwen3.5-4B，L0/C4146/−1与L12/C3621/−1，六个基础情景各两个事实版本。不是12个独立情景，不代表所有模型、层或针。
- 00无针，10仅早段，01仅晚段，11两段。末提示及候选评分位置无针；这些结果不能覆盖回答位置持续开针的全部效应。
- S3的V是卷积前value通道，操作覆盖针之后相关线性层；S2细轨迹为L16–18，公式中的v在卷积后。二者不能视为同一范围的中介。
- R是形成α的投影输出；K含卷积前key及形成β的投影输出。k、β共享参与旧状态修正和新写入；单独R效果弱不等于旧状态处理不重要。
- D为停止优势，情景表可对两事实取均值；EOS为逐输入首步选择。S_fact是候选分数对事实版本的响应，不是准确率或信息存量。

## 3. 已被反例否定的具体解释

以下否定均保留其条件和量的定义，不推广为整个机制类别已被排除。

| 编号 | 被否定的说法 | 决定性依据 | 否定到哪里为止 |
|---|---|---|---|
| N1 | 只改一个通道，因此是一次微小有效扰动，必须靠异常放大才有大效应 | 冻结校准与权重核对：注入常数映射的输出范数约为参考残差尺度1倍；早段16–28、晚段27–33个注入位置 | 撤回“小扰动”前提；逐token实际差分未保存，不排除后续增益 |
| N2 | 后段出现的新写入差异，必须由后段仍在插针造成；早段针只留下被动残余 | S2的10/00在后段不开针时，仍存在后续更新及投影差异 | 证明早段操作能影响后段形成；不证明目标层局部自反馈、无限持续或唯一缓存来源 |
| N3 | 共同起点首步只有新写入变化，对旧状态的处理不变 | 同起点认证成立，首步处理作用与写入变化均存在，方向部分相反 | 否定该首步的“处理不变”；不提供独立行为份额 |
| N4 | 此观测窗口中，写入与旧状态处理同向叠加，靠它们共同放大解释大效应 | 连接分析首步净状态差/单独写入差为0.800–0.951，处理作用部分抵消 | 否定该窗口的同向放大解释；不排除别处增益，也不证明抵消保护回答 |
| N5 | 用当前局部变化范数就能单调解释停止强弱 | 干净前史下，L12首步v相对变化在六情景均大于L0，D增量却均更小；L0更大的首步变化也不稳定对应更大终点效应 | 否定这些局部幅度指标的充分解释力；不否定全部状态或幅度作用 |
| N6 | 停止只是极小连续分数变化碰巧跨阈值 | L0原生11相对10的D增加15.70–17.64，EOS由0/12至12/12 | 本比较不是“只有微小分数变化”；阈值化仍决定是否停止 |
| N7 | 所有晚段行为变化都必须先改坏此前事实位置的KV | 01在事实位置KV已形成后才开针，先前条目不变，输出仍可明显变化 | 旧事实KV改写不是此条件的必要前提；递推状态、读取及后续KV作用未被排除 |
| N8 | 不首步停止就表示事实响应正常；保留一半停止分数就表示仍停嘴 | 10不首步停止但S_fact显著低于干净；S3后续写更新与读取都换回后仍保留52%–62%分数偏移，EOS却为0/12 | 否定指标等同；不把候选分数下降升级为实际答错 |

N1、N3–N6来源[A]；N2、N8来源[B][C][D]；N7结合源运行时序、KV实现约束及[E]。架构事实不是本项目新发现。

## 4. 有实质证据支持的结论

| 编号 | 稳定结论 | 证据 | 结论边界 |
|---|---|---|---|
| S1 | 原针改变了真实历史形成和后续更新，不只是最后输出读数 | 原生时序对照、同起点认证；S1/S2与旧数据重建相互对应 | 没有完整识别所有中介路径 |
| S2 | 模型对后来同一针设置的反应依赖先前历史 | L0中11/10首步v绝对差异为01/00的1.68–2.70倍，m差异为2.66–4.51倍 | 是有限差分的背景依赖，不是旧历史独立贡献或一般非线性证明 |
| S3 | 旧状态处理在所测原生更新中实际发生，并部分抵消写入差异 | 同起点首步及累计方向记录；不只检出非零 | 尚不知道它对最终回答保护、加害或条件性改变多少 |
| S4 | 在指定S3条件下，晚段卷积前V与L0停止有强干预联系 | 晚段撤除V后EOS 0/12，D恢复量0.617–0.765；只留V时EOS 12/12，保留量1.057–1.109 | 供体/参照为10，覆盖全相关层；这是条件性效果，不是V原发原因或自然贡献百分比 |
| S5 | 针改变了两种事实输入在内部的数值区分方式 | L0早段针下，L16–18合并后段/末提示的v事实差cos为−0.0273至0.0306，范数比0.409–1.955 | 证明数值对比偏离干净方向，不证明语义已删除或完整换码 |
| S6 | 停止、候选事实响应、状态距离必须分别解释 | 原生时序、两锚点及S3条件存在跨指标反例 | 不等于已证明三个独立功能模块 |

来源[A]–[E]。S4的描述范围不覆盖原零对照、分辨率限制和事实格中的“证据不足”。恢复比例不作为确定的自然机制份额。

**这些已经超过“只观察到输出变了”，但尚未构成原生机制闭合。** 最强成果是：历史形成的实际过程证据、受前史影响的计算反应、以及特定变量组到行为的条件性因果联系。

## 5. 仍无法判断的解释

| 待判断问题 | 为什么现在不能裁决 |
|---|---|
| 大效应主要来自参考尺度量级扰动的一般损伤，还是特定方向/位置的作用 | 已核实剂量，但这条机制证据链没有完成同条件的特异性判断；其他广谱调查不能未经对齐直接代替 |
| 写入内容变化是否足以解释原生读出；处理规则变化是否不可忽略 | 两者在真实计算中共享变量并共同变化；新增的内容/规则预测模型尚未运行，也不能把旧账目当其验证 |
| 新内容与旧记忆预测的“有害错配”是不是关键 | 事实分类36格中28格因ρ_v低提前分类，只有8格进入相关判据；零命中不能排除其他层、时刻或条件 |
| 是否存在跨输入共享的行为相关低维方向；是否主要集中在模板尾 | 目前为未验证候选；位置集中与方向集中可以同时成立。候选写得具体不等于已有证据支持其属性 |
| 事实被擦除、改写为不可用编码，还是读取/答案竞争改变 | 几何投影与S_fact均非信息存量；旧KV不变不保证其功能正常 |
| V恢复是否沿着原针的实际作用路径逆转，还是利用了补偿 | S3是混合反事实；双向有效或全量恢复正确都不独自认证自然路径 |
| 读取条件在形成期及答案期分别有多重要 | “指定撤针后读取替换未解除停止”不能排除形成期读取、其他读取量或与状态的相互作用 |
| 具体为什么L0强、L12弱，为什么前史改变局部反应却不同比例改变输出 | 目前只有约束和反例，没有同范围的计算解释；不赋予L12天然特殊性 |
| 完整带针自由回答及跨模型机制 | CFM评分位置无针，且机制面板为一模型两锚点；没有证成通用机制 |

**未证实不等于已否定。** 同样，因统计/对照分辨率不足而“未检出”，不能写成机制无作用。

另有几条属于应撤回的推断，而非对应机制已被实验证伪：

- V恢复后事实没回00，不能证明V只管停止：其实际供体10本来事实评分就低。
- 稳定残余分数不等于稳定残余行为；单组R弱不等于全部旧状态处理弱。
- 全量替换重现参照属于工程验证；同源数据做两种分析不算两次独立确认。
- 找到最早偏离层、有效恢复点或共享子空间，不自动证明最初病因或完整原生路径。

## 6. 前三阶段是否完成了最初目标

| 阶段 | 已完成 | 没有完成 |
|---|---|---|
| S1 | 原生过程记录、更新/处理分账、局部读出；保留自然对照也触发coupled标签的反例 | 未识别针特有耦合机制；未连接行为因果 |
| S2 | 原生时序与共同起点证据；区分后段形成与后段针必须在场；报告预登记预测失败 | 多个判据区分度低；未分出写入/处理的独立回答作用 |
| S3 | 验证既定替换条件对停止及候选评分的效果，V联系较强；工程参照复现 | 未拆清原生写入—处理—读取如何导致回答变化；多数事实机制判定不足 |

**执行上的三个阶段已完成，最初想达到的机制拆解目标没有完成。** 不是所有阶段白做，也不是最后补一格即可保证完成。现有合同范围本身已限定S3只主张替换条件下的效果；不能事后把它升级为原生机制证明。

## 7. 明确的课题推进判断

1. **保留研究方向，停止本轮设计扩展。** 历史形成与变量到输出的证据足以说明问题值得研究，但不足以让近期任一候选自动获得下一轮优先权。
2. **把本轮结果按实际证据结案：** “原生历史形成与背景依赖已获支持；部分变量有条件性行为作用；大行为效应的自然计算解释未完成。” 不继续把局部预测、停止子空间或事实恢复点改称总问题答案。
3. **近期方案均保持未验证草案身份，不进入默认执行序列。** 包括内容/规则预测草案、共享方向/近因位置候选、浅层事实恢复及S4扩展。保留历史，不重写为失败实验；本文件不提出替代实验。
4. **不宣称已有可成立的完整机制贡献。** 相比已有查重近邻，我们增加了上游激活干预的形成轨迹、同起点/时序约束和指定变量的行为证据；尚未交付新的完整计算解释或独立验证的行为预测。这是研究增量判断，不等于领域首次、已优于近邻或整项目不可发表。

当前最关键的未解决关系只有一句话：**原针造成的哪部分计算变化，以何种方式影响实际答案竞争，才能同时说明强效、弱效和恢复条件？** 本句是现状判断，不是新的补测任务清单。

所谓“稳定”，是以后讨论沿用这些已核对的事实与边界。只有新增证据或明确数值/实现勘误才修改相应结论；不能因为又想到一个候选，就重新把全部证据讲成支持它。当前既不结束整个课题，也不承诺后续一定能得到原生机制。
