### 已知注入地址，不等于已知功能部位

已执行的改动是零起始索引 L13/N7956 负向、L14/N8949 正向的动态激活加法；位置是各层 MLP 的 `down_proj` 输入。模型权重保持不变。结构及固定版本来源见[定位方向记录](acupuncture-localization-direction-2026-10-26.json)，实际实现见 [probe.py](../experiments/qwen35-neuron-steering-2026-10-25/probe.py) 与 [collect_raw.py](../experiments/qwen35-neuron-steering-2026-10-25/collect_raw.py)。

令自然通道激活为 a、对应 down-projection 权重列为 d。原本该通道写入 a·d；现在写入 (a+c)·d，局部额外贡献为 c·d。c 不随当前 token 的自然激活变化，因此干预有效不能单独证明该通道在自然计算中承担同名功能。B=L13 先于 A=L14 执行；两点分处相邻层也不证明 B 必须通过 A 传播。

当前 c=dose×m/||d||，m 是原版该层输出残差在提示位置 1: 上的范数中位数。因此在理想实数运算下，单点额外写入的范数是 |dose|×m；dose=±1 对应一个参考残差尺度，不是 1% 微扰。实际 BF16 舍入、逐 token 残差比例及两点联合后的总差分仍须测量。当前在提示处理与生成全程逐位置注入，不能把两点数目少等同扰动小。

### 要区分的解释

1. 原生计算中已有相关功能路径，干预改变了它的工作状态。
2. 这些权重列提供了可被强行写入的特定方向，随后由残差直通、下游计算或生成文本反馈放大；自然通道未必平时负责这种行为。
3. 大幅持续扰动造成普遍任务损伤，其中部分输出被误当成一个专门功能的改变。

三者可能并存。主动有害建议、敌意措辞、任务失遵循和重复须分开作为结果；目前没有全体回答的恶意发生率，不能预设“evil”是单一机制。已有语料用于提出解释和开发测量，独立确认材料及判据需在新实验前冻结。

### 按因果问题推进，不先铺开全部组合

| 顺序 | 具体操作 | 要获得的证据与限制 |
| --- | --- | --- |
| 1. 分解起点 | 固定相同输入与校准尺度，比较原版、仅 A、仅 B、A+B；记录实际局部写入、自然激活及其范围。加入多组同层、同逐层注入范数和时机的随机通道对及反向对照 | 区分单点主导、联合效应和一般扰动；随机对照保留全部结果。数值读数的交互不等于已找到 B→A 路径；真实回答不能直接作文本减法。能力损伤是并列结果，不作为删题依据 |
| 2. 找到传播环节 | 在相同固定 token 前缀上比较各下游模块的输入/输出、残差与最终词概率；先追踪两个入口后的计算，不逐个扫描所有神经元。用“保留注入但固定后续模块写入”的诊断反事实，区分残差直接读出与下游重新计算的贡献 | 差分大、词表投影或相关性只产生候选；固定整批模块构成混合计算，只能约束解释，不能直接证明一个自然功能区 |
| 3. 验证候选路径 | 保持 A/B 干预开启，只将候选下游模块的有限贡献、通道集合或子空间替换为同前缀原版值；反向测试在无 A/B 时注入候选中间变化。逐步缩小有效替换范围，并设同大小、同幅度无关替换对照 | 检查有害内容、任务表现等各指标是否被分别恢复/重现。不能把整层残差全部换回原版或直接抵消源注入当作机制发现；双向替换支持限定条件下的因果作用，不保证唯一机制或全局最小回路 |
| 4. 区分自然作用与强制驱动 | 对候选路径，在未经额外注入的相关正常情境下做有限消融和恢复；另外比较提示期/生成期干预，及原版/干预版前缀在有/无干预下的重放 | 自然活动的因果作用与外加强推分开。自由生成分叉后的内部差异混入上下文变化；关闭钩子不会清除历史 KV 或递归状态，涉及恢复时须重新计算相同前缀并明确状态来源。阶段开关同时改变次数与总量，不能只凭它声称时间特异性 |

步骤 1 是排除基本混淆的入口，步骤 2–3 才是本轮要解决的机制定位核心。所有候选先在开发材料上提出，再冻结并在独立材料确认；不要根据确认输出不断改候选。必要性与充分性可能受冗余、上下文和分布外替换影响，失败也必须报告，不能承诺一定找到一个独立、连续的“部位”。

### 本阶段交付标准与迁移边界

目标是得到带反事实证据的描述：在明确输入条件下，A/B 的写入改变了什么中间计算，经哪些受验证的环节影响输出；只修复候选中间变化时哪些现象消失、哪些仍在；只重放该变化时哪些现象重现。若仅能确认直接写入偏置加生成反馈，或一般损伤，也应如实作为机制结论。不能以“两个点附近存在功能区”填补缺失证据。

MLP、残差等结构在许多模型中存在，不代表这两个通道的自然功能或整条因果路径共有。源模型定位后，才将已验证的计算关系转为其他 Qwen 模型的预测与反事实检验，再到其他家族。判断对应机制的依据应是相同功能关系及干预/恢复效果，而不是同编号、同相对层深或相似措辞；有限模型面板也不能证明所有大模型都有统一“前额叶”。

本修订应用 [HanLab 总结](HanLab经验总结.md) 中“机制主张配反事实、修复同一个被解释量、匹配随机对照”的经验；它不是该总结或已有 Acupuncture 实验已经提供了机制证明。本轮仅核对源码、协议与收据，并修订研究顺序，没有运行模型。

## 三类新增材料的联合判断（2026-10-26）

本节综合上述三项 Benchmark、[26 篇相关工作核查](literature/mechanistic-interventions-2026-10-26.json)及[原帖讨论档案](literature/lyra-x-thread-2026-10-26.zh-CN.md)。基准原文文件与评分清单的 300 个 SHA-256 已逐一复核；这属于记录审计，不是重新运行模型。X 讨论依据已归档的登录后调查，本次重访关键直链遇到访问限制，未声称再次完整查看评论区。以下实验均未启动。

### 证据怎样改变方向

1. **先区分特定行为改变与正常任务损伤。** 严格零分受格式影响，但统一放宽显式答案提取后，EVO 的 RACE / GSM8K / LogiQA 仍只有 11 / 0 / 15 分，原版为 89 / 83 / 70 分。选择题首次 forward 的 A–D 排序也已变化，修正 EOS 后仍有 295/300 份回答达到上限。因此不能把全部差异归因于输出格式、旧停止标记或生成末尾循环；也不能由此推断模型所有知识消失或故意答错。现有数据没有给出 300 题的全量有害内容发生率。

2. **作者已经有明确定位流程。** 作者描述的是预计算影响图谱，结合词语搜索和输入激活筛候选，再实际干预。自述的 2–5 分钟是使用已有工具的一次搜索，不是完整发现成本。其他风格配方可提供多行为验证线索，但未经本项目复现，不能直接当功能真值。[作者方法回复](https://x.com/_lyraaaa_/status/2114188408084185377)

3. **剂量区间是线索，不是已经找到的解法。** 评论者 Alex 报告剂量 0.5 的开放题与日常题反应不同，剂量 2 则 40/40 循环或乱码。缺少完整题集和判据，不能合并到本项目结果，也不能把“没有循环”当能力保持。它支持优先检验剂量与输入类型的交互。[第三方附图](https://x.com/alexisaev/status/2114411936637128720)

4. **干预持续时间有直接文献依据。** [Activation Steering Induces Emergent Misalignment，v2](https://arxiv.org/html/2606.08682v2) 已含 Qwen3.5-4B/9B/27B；Appendix B.3 / Table 5 写明只在 prefill 与随后 3 个 decode 步注入。我们目前在 prefill 和整个生成期间持续注入。两者还存在方向构造等差别，不能据此断言缩短干预就会恢复能力；这是值得单独验证的变量。该论文构造方向依赖微调参考模型，不能把整套发现流程称为无训练。

### 查重后不能独占的主张

| 原始研究 | 已覆盖的内容 | 我们应怎样使用 |
| --- | --- | --- |
| [CNA：Targeted Neuron Modulation via Contrastive Pair Search](https://arxiv.org/html/2605.12290v1)，原作者直接推荐 | 对比提示的原生 MLP 激活差异选取少量通道，再施加干预 | 作为定位基线。其乘法调制/消融与我们的逐题校准加法不同，须比较实际扰动和能力代价，不能只比较点数 |
| [Persona Vectors，v3](https://arxiv.org/html/2507.21509v3) | 对比提示构造行为方向；Appendix M 已拆分 evil 的内容与风格，并测试 SAE 特征 | “evil 有多个成分”本身不构成新方法；SAE 特征也不能等同原生 MLP 通道 |
| [CircuitBreak](https://arxiv.org/html/2610.16470v1) | 梯度与激活筛候选、能力约束下联合搜索少量原生 FFN 通道 | 少点、联合选点、加入能力约束本身已有先例，须直接比较 |
| [Convergent Linear Representations of Emergent Misalignment](https://arxiv.org/html/2506.11618v2) | 相关微调模型之间存在共享行为方向 | 同一基础模型的微调派生物不能替代不同规模、独立训练家族的原生位置预测验证 |

这里是针对近邻论文的主张核查，不是穷尽性查重，也未独立复现实验。尚不能宣称“跨模型功能定位无人研究”。

另一个比较约束：对线性 down-projection，单通道加法在注入处等价于沿该权重列添加输出向量。我们的加法幅度由每条提示校准，在该次生成中固定，不随当前 token 的自然通道激活变化；CNA 的乘法调制则直接依赖当前通道激活。因此须比较候选空间、位置选择规则、干预时机和实际扰动；“神经元”和“向量”两个名称本身不能证明机制不同。

### 建议的研究顺序：先证明可用，再证明可定位，最后证明可迁移

**第一步：源模型的小规模因果分解。** 事前固定少量剂量，分别测试 A=L14/N8949、B=L13/N7956 与 A+B；比较 prefill、prefill＋3 步和全程干预，并设置不干预及同层、同有效扰动强度的随机对照。时间窗口变短也减少了注入次数，须包含低剂量全程对照并记录实际注入范数，避免把总量差解释成时间机制。分别观察任务完成、风格、拒答、主动引入有害内容与重复；不将它们合成一个 evil 分数。旧题用于开发，结论需要独立固定题确认。

此阶段的问题是：能否找到可复现的行为改变区间，其正常任务代价显著小于当前配方及匹配随机干预？不存在这样的区间也是有效结果；不能通过删掉失败题、改解析或只展示有趣案例制造分离。

**第二步：把有效位置描述成可比较的功能特征。** 在同一组探针上记录自然激活响应与因果影响，明确哪些特征在不知道目标模型行为结果时就可计算。不同模型的隐藏空间没有天然共享坐标，不能直接拿原始权重余弦充当功能对应。已知两点只是起始线索，需用独立行为或位置检查规则是否过拟合；允许一个点、多点或方向，不能预设所有模型都有单个“前额叶”。从已知两点出发的方案应称种子引导定位，不能冒充从零发现。

**第三步：冻结规则后预测新模型的位置。** 在未参与方法开发的模型上，先保存候选及排序，再查看独立行为测试。目标模型允许使用的数据和计算须事前写清并计入成本；无目标行为标签不等于零目标计算。与同编号/相对层深、等预算随机、每个模型重新做 CNA 式搜索，以及稠密方向基线比较。在相近能力损伤下比较行为效果，或在相近效果下比较损伤，并核算完整发现成本。

候选贡献是“可预测的功能定位与对应规则”，尚非已成立结论。若必须看目标测试输出后反复改位置，支持的是目标内重新搜索；若随机点同样有效，缺少定位特异性；若只迁移语气或粗口，不能宣称迁移了广泛行为控制。方法确定后还需围绕该具体主张补充查重。

### 全量扫描预算的含义

32 × 9216 = 294,912 个通道；单点正负两方向共 589,824 个条件。一次正常 forward 可以同时记录所有通道的自然激活；这与对每个通道分别进行因果干预是两种工作量。单点扫描也不涵盖两点交互。

依据正式数学运行的 batch-16 生成计时，当前实现的 EVO 吞吐约为每卡 219 个输出 token/秒。若每个条件 4 题、每题生成满 128 token，两张同速卡理想并行的生成时间约 8 天；24 题 × 256 token 约 96 天；40 题 × 512 token 约 319 天。这是将既有工作负载外推到新扫描的条件预算，不是完整工程或评分 ETA，亦不是已经运行的结果。提示长度、批量、早停、层位置、内核与多条件批处理均会改变吞吐。

公式、来源与评分吞吐敏感性场景见 [扫描预算记录](scan-budget-2026-10-26.json)。建议先用小规模分解确定有效观察指标，再把局部较完整扫描用于检查低成本定位方法会漏掉多少有效位置；暂不把 59 万条件的长回答全扫作为默认下一步。

### 最小起步：先用 4B→9B 检验定位是否提供有效信息

建议把 v1 的 2B 首站调整为 9B。理由来自现有配置记录：4B与9B均为32层，两个源编号在9B合法，能够直接加入最简单的原坐标迁移基线。结构相近利于定位失败原因，但不能预设同坐标功能相同；较低计算成本则是2B首站的优势。本次选择更便于判别方法贡献的9B，之后仍按2B、Qwen3-4B、Gemma、Llama推进。目标精确revision仍须在执行前核验冻结。

源模型只做已有A、B的自然响应及原版/A/B/A+B标定。目标端沿用v1的限定层、每源点最多三个候选、固定短探针校准和独立确认。跨层恢复实验后置，仅当源局部关系已有证据、目标顺序也相符时做；不把完整机制图作为开始迁移的前提。

首张判别表使用独立短探针的因果指纹作为终点：

| 候选来源 | 不使用目标因果校准 | 使用同预算目标因果校准 |
| --- | --- | --- |
| 源通道自然响应匹配 | 使用第一名及事前固定的符号预测规则 | 每源点最多三候选，按固定短探针选点与方向 |
| 同层随机候选 | 使用预定随机首选及同一符号预测规则 | 相同候选数、正负条件、探针和选点规则 |

随机候选必须来自与方法相同的层窗、方差及可靠性筛选后的集合，不能混入大量近零响应来削弱基线。右列两行之差衡量定位信息的增量，同一行两列之差衡量目标校准的增量；未校准的符号是预测，若失败不能直接归因为位置不存在。原版与原编号/原符号另作参照，原编号臂不承担等预算组件归因。

随机池应事前固定多组。一个可控的预算草案是：20组用于短探针对照，其中事前指定3组进入与方法相同的完整行为评测，不能按短探针结果选最差的三组。20组只提供有限的经验参照，不自动意味着统计显著；3组完整生成也不能代表充分刻画行为零分布。若要主张稳定的完整行为优势，需要追加独立、同等覆盖的确认，不能拿短指纹分布代替。实际池数、主要比较、阈值与算力预算须在执行前固定，本轮尚未执行。

### 先写下允许失败的预言

1. **定位信息预测：** 经过相同目标校准后，功能匹配候选在未见短探针上的因果作用应比同层随机候选更接近源点。若没有显示增量，先报告当前定位规则无优势，不通过扩层、加候选补救原轮结果。
2. **代理有效性预测：** 短探针上的作用对应应能在独立完整回答中复现预定的行为变化。若只出现局部概率偏移或粗口，不把它升级成广泛行为迁移。
3. **校准贡献预测：** 若随机候选经相同校准已能达到相似结果，当前成功主要支持目标端有限搜索，而不能归因于源功能定位。
4. **朴素基线预测：** 若9B原编号移植同样有效，承认9B上复杂定位尚未显示必要性；2B仍可检验编号不可直接复用时的价值。

正式确认沿用新行为题与正常能力题两条结果轴；能力题优先从标准基准未用于开发的固定样本中取，不能凭少量自建题宣称广泛能力保持。所有条件相对该模型自身原版比较，保留能力下降、截断和失败。每模型独立报告，不能把少数目标模型汇总成全家族普遍性。

### 不机械照搬总结中的规则

- 文档“核心对比至少3个seed”在本项目应落实到随机候选、输入场景或确有采样的解码变异。把相同greedy推理重复三次不产生三个独立实验；同源改写、token和评委重复也不是独立场景。
- 文档“二值事实不需要统计”不能用于从有限题目未出现某行为，推断该行为永远不存在。零次观察仍有样本范围与不确定性。
- 文档中的规模扫描与查重建议不覆盖用户当前禁止扫描的指示；本次没有新增文献检索或全模型逐点干预。

确认集在候选、符号、剂量与判据冻结后才打开；若看完9B结果再修改方法，9B归入开发证据，新规则由2B或后续未见模型确认。实现上复用现有动态hook，在新的版本化实验目录内完成探针记录、有限候选匹配和独立确认，保留旧实验与v1方案。下一份可执行交付应是这一个迁移实验的固定输入、明确对照和运行预算；当前记录只完成建议与归档，不启动算力任务。
