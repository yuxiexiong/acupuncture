# NVB-01：从原生 T 出发，拆分局部 v 的当前输出与留存状态用途

2026-11-03；v1；来源快照 `105e6832`；对应[To-do 第 1 项](cache-mechanism-todo.zh-CN.md)。**作者逻辑自查通过，非独立评审；实现与真实模型数值验收未完成；本轮未运行、无新 GPU 授权。** 本文件含设计与自查，不另起一组推广工作。

## 1. 问题与新增认识

主线：稀疏干预怎样经写入、历史处理与读取改变回答。本轮问：**从原生受干预状态 T 出发，LVK 的局部 v 恢复，是通过改变 t1 当步输出及其下游上下文，还是还需要改变留给 t2 以后的递推状态，才能增强 k 操作对目标选择和完整回答的作用？** 两种用途可以共同起作用，不预设互斥机制。

已有证据：[NVW](../experiments/cache-native-v-write-interaction-v1-2026-11-03/REPORT.zh-CN.md)表明未恢复 V 时，强制共同前缀后的 k 效应也小；因此“只是原生停在第一步，潜在目标竞争完全没变”不足以解释已有结果。[LVK](../experiments/cache-local-v-k-v1-2026-11-03/REPORT.zh-CN.md)将 V 条件落实到 t1 局部 v，但该操作同时改变当前输出与持久状态。[SRU](../experiments/cache-state-read-use-v1-2026-11-03/REPORT.zh-CN.md)检验的是 LVK 两个已恢复端点的状态使用，没有拆开局部 v 恢复的上述两种用途。

本轮补的是**原生 T→LVK 修复过程内部的用途连接**。即使阳性，也不宣称原生针只通过该路径起作用，不称完整自然中介识别。一次有边界的连接检验能推进 To-do 1，但不预先宣布整个问题关闭。

## 2. 固定范围与供体

- 只用 LVK 新面板已有 48 条文本、六场景；现在是已见机制开发面板。四方向 N4146/N1210/R0/C1343 不变，C1343 单列。旧面板不重跑。
- 模型 Qwen3.5-4B、revision `851bf6e8…`、BF16/eager/batch1、torch 原核、L0 形成干预、NA/B1、−1 强度、μ 与校准全部继承 [LVK 合同](../experiments/cache-local-v-k-v1-2026-11-03/CONTRACT.zh-CN.md)。不新增模型、针、文本、层或剂量。
- 每输入重建 C 与四个 T，所有实验格都从同一 T 边界开始。固定 G=[13,14,16,17,18,20,21,22,24,25,26,28,29,30]。
- v0/k0 是本分支当前卷积输出；v1/k1 按 LVK 的两种影子克隆方式产生：用**本分支当前输入**，v1 只恢复同输入 C 的 V 历史，k1 只按冻结 μ 去除 k 历史偏移。两影子独立构造、都不写回卷积缓冲。v1 仍不是完整干净 C 的 v。

## 3. 操作：同一局部驱动下，分别决定输出与保存什么状态

沿用 LVK 的状态更新，记 b 为 k 操作，j 为局部 v 来源：

\[
\widehat S_1(j,b)=\alpha S_0-\alpha\beta k_0(k_0^\top S_0)+\beta k_bv_j^\top.
\]

新格 B(c,a,b) 的局部递推核返回：

\[
o_1=\widehat S_1(c,b)^\top q,\qquad S_{\mathrm{return}}=\widehat S_1(a,b).
\]

三个二值开关：c 控制**当前输出计算**使用哪种 v；a 控制**留存递推状态**使用哪种 v；b 控制两者的写入 k 是否去偏移。旧预测修正的 k 始终为 k0。每个格都使用自己的当前 q/k/v/α/β 和 S0；不搬入另一完整轨迹的输出或全部状态。

| c：输出用 v | a：存下的状态用 v | b=0 / b=1 | 身份 |
|---|---|---|---|
| 0 原生 | 0 原生 | B000 / B001 | LVK L00 / L01 旧参照 |
| 1 影子 | 0 原生 | B100 / B101 | 新：只在输出用途恢复 v |
| 0 原生 | 1 影子 | B010 / B011 | 新：只在留存状态用途恢复 v |
| 1 影子 | 1 影子 | B110 / B111 | LVK L10 / L11 旧参照 |

共 8 格/输入/方向，其中 **4 个新科学条件、4 个旧参照重放**。只在 t1 的 14 个 G 层操作；t2 起完全卸载钩子，正常更新、读取和生成。实现复用 `lvk_run.py::LHook` 与 `kuc_run.py::custom_update`；非对角格在相同局部输入上计算两次，取一个输出和另一个返回状态；对角格只算一次。保留原核运算顺序与 cast 路径，不在已舍入的输出后近似补项。

### 必须保留的操作解释

1. 非对角格打破原生“输出从被保存的新状态读取”的一致性，是人工用途反事实，不是模型天然有两套状态。
2. c 的变化不只是“让模型开口”：它改变 t1 深层输入、归一化、KV 和卷积新槽等。因此本轮叫**当前输出支路恢复**，不能叫纯停止控制或纯首 token 控制。
3. **固定 c、b，改变 a：t1 输出、首 token、全部非 S 缓存应相同，只有指定 G 层的 S 不同。** 因为每层当前输出不依赖 a，浅层到深层可归纳。这是结构事实和工程闸门，不是科学发现。
4. 固定 c、b 时，局部 S 差在实数公式下为 βk_b(v1−v0)ᵀ。t2 后 q、状态、KV 和生成允许响应；此后不再要求非 S 缓存相同。
5. 固定 a 比较 c 时，没有上述非 S 相等要求；比较 b 时 k 同时影响 t1 输出和留存状态，下游也会变化。本轮不把 k 总效果冒称纯持久写入的局部效应。
6. c=0 的自然首 token 与 LVK 对应原生 v 臂相同；已停止的输入不可能因只改 a 而在 t1 自然继续。这个“不能开口”不是新发现，新增信息在条件 t2 与实际继续的自然轨迹、以及 c=1 时后续回答的变化。

## 4. 比较与读数

令 z 为 M 或 Y，e(c,a)=z(c,a,1)−z(c,a,0) 是对应用途背景下的 k 效应。报告八格原值和全部改对/改坏；重点报告：

- **固定输出恢复时的状态用途影响**：s_b=z(1,1,b)−z(1,0,b)，以及 J_S=e(1,1)−e(1,0)。这回答：同一 t1 输出和非 S 历史下，把 v1 留存在 S 是否改变后续行为、是否增强 k 效果。
- **固定留存状态设置时的输出用途影响**：o_b=z(1,1,b)−z(0,1,b)，以及 J_O=e(1,1)−e(0,1)。这是输出支路及其后果的总效果，不是纯输出 token 的贡献。
- 其余配对 e(0,0)、e(0,1)、e(1,0)、e(1,1) 全报。J_S/J_O 有不同条件，不能相加分配为两份机制贡献，不设解释百分比。

**自然路线 N 为行为终点：** 各格自身 t1 首 token，贪心继续到停止或含首 token 共 32 token；完整正确 Y、改对/改坏、停止步、错误类型和原文全部保留，48 条进分母。不屏蔽 EOS，不强迫首 token，不按已开口筛样本。

**C 路线为条件竞争读数：** t1 后复制本格缓存，消费 LVK 冻结 fF，测 t2 M；主32条目标非首列输入逐例配对后六场景等权，首列16条辅助。六条已知自然首 token 例外以及任何新例外按真实结果单列。C/N 输入不同时分开前向，不能把强制前缀输出算作自然答案。

原生首步 G 和实际停止描述性报告，用于桥接和解释可达性；固定 c,b 时的 G 相等不作为新科学终点。M 支持沿用 ≥0.25 logit 且 ≥4/6 场景同向；Y 改善/恶化支持沿用净变化 ≥2/48 且 ≥2 场景，始终报告反向个例。这些是预设实用幅度标签，不是显著性或等价性检验。

## 5. 工作预测、可能结果和退出

**工作预测（未测）：** 在 c=1 的共同输出条件下，保存 v1 而非 v0 仍能增强 k 的后续作用，即 J_S(M)>0，并有自然完整交付证据。依据是 LVK 的写入效应与 SRU 的状态读取作用；它们不保证此新反事实成立。

| 结果 | 新增认识及限制 |
|---|---|
| c=1 下 s_b 或 J_S 有 M/Y 联合支持 | 局部 v 恢复不只通过 t1 当前输出支路起作用，留存 S 的差异对后续选择/回答有条件性作用；结合 SRU 是相容证据，但不宣称 SRU 的 D 已被证明中介了本轮全部效应 |
| e(1,0) 已有 M/Y 支持，而 J_S 未达支持 | k 的作用可以在未直接恢复留存 v 的情况下出现，当前输出支路及其形成的后续上下文已提供重要条件；撤回“必须恢复该留存 v 才能增强”的工作判断。弱差异不证明严格等价或零作用 |
| c=0,a=1 的 C-M 改善，但自然仍停止 | 将潜在选择能力与原生可达性分开；只能解释条件竞争，不能称原生完整修复 |
| s_b 改变 Y，但 J_S 不支持 | 留存 v 有后续主效应，不能声称它特异增强 k；主效应和交互分开 |
| M 支持、Y 不跟，反向、仅个别方向支持 | 分别保留诊断、反向或条件局限；不包装为统一机制 |
| 新交叉格均弱/不稳定 | 当前用途拆分不足以提供预期桥接；本轮完整报告后停止该候选，不自动加 t2 钳制、扩层、改剂量 |

三个缺口方向逐一报告，至少2/3方向符合才称“多数方向”，C1343 不并入该成功率。对角旧端点应重现是工程要求；新格必须改善不是工程要求。无论结果如何，这轮只评价修复过程中的两种用途，不把第 1 项整体标成完成。

## 6. 工程验收与成本

已有代码审读确认 `custom_update` 返回 `(out,S,err)`，更新中不原地覆盖传入 initial_state；同一局部输入可计算两份候选，再分别返回。本次只审读，真实模型接线尚未验证。来源清单、冻结 μ、输入账本、校准和模型 revision 继续核验；LVK 的日志/张量没有本轮四个交叉格的回答，不能仅靠旧 logits 在 CPU 上推算。

固定预检2条：`LVK-H-NA-NQ01-ABC-A`、`LVK-H-NA-NQ02-ABC-B`，全四方向全八格。最多一次有记录的工程修复重试；正式开始后不改定义或筛题。

1. 对角四格 t1、C-t2 全词表和自然完整 token 与 LVK 逐位一致；每单元另用原 LVK 实现重建四个 t1 参考，核对完整缓存。不能拿终点相近替代接线。
2. 固定 c,b 改 a 时，t1 logits/首 token 及所有非 S 缓存逐位相同；只允许14个G层S不同。浅层S也必须相同。FP64核对状态差公式，归一化误差≤1e−5；数值容差不放宽输出/非S精确桥接。
3. 每个候选输出/状态用同一 q/k/v/门/旧 S，FP64 oracle≤1e−5；返回对象等于所选候选，影子初始状态/源缓存前后不变。±0沿用旧规则，记录次数。
4. 每个 t1 的14层各触发一次；t2起零hook；C/N缓存独立；解析器和停止集合不变。精确重放失败先停，不能当科学阴性。

### 反方检查与修正

1. **是不是把“开口”与“记忆”干净分开？** 不是。c会改变深层输入、KV、新卷积槽等；已改名当前输出支路，拒绝纯开口解释。固定c,b时改变a的非S一致性才是可验收的窄控制。
2. **输出来自另一个S但存下本S，是否不自然？** 是人工反事实；承诺仅为用途干预及修复依赖，不能识别自然唯一中介。边界内能区分同一t1输出下后续S作用，具有实际增量。
3. **c=0只改a仍停止是必然，岂不空实验？** 首步不变仅工程；科学终点是其条件t2，以及c=1共同输出下的自然完整回答。原生可继续的少数输入也保留。不给结构不变计成功。
4. **b也改了输出，J_S怎能叫纯k写入状态效应？** 不能。每个b内的a比较控制同输出；跨b交互仍是该背景下k操作总效果的条件差。已明确不作纯路径归因。
5. **若只改输出就有效，是否证明S无用？** 否。被保存的S仍使用因输出改变而变化的深层输入；只说明直接把v1用于留存更新不是出现该效应的必需操作。弱差异不作等价性证明。
6. **如果状态用途有作用，就已经证明它经SRU的D传递？** 否。本轮无t2用途替换；只支持后续S使用的总效果，与SRU相容但不将新格直接套用旧D归因。
7. **是不是又构造了一个背景，仍没接回原生？** 四对角包含原生T与原LVK修复，所有分支从同一T出发，比较直接解释这次恢复操作的两用途；这补一个接口，不宣称原生自然路径已闭合。第1项保持进行中。

与上一轮区别：SRU在已恢复端点上拆t2的D/E；本轮回到原生起点与原LVK四格，拆t1的v输出/留存用途。不追加SRU层头定位。最终复查C01/C02/C05–C10/C14通过；实现、真实模型数值与运行授权仍待完成。
