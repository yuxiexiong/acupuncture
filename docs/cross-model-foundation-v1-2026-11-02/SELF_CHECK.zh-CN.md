# 跨模型基础实验 v1 / 修订r3：设计自查

2026-11-02（Asia/Shanghai）。规范：experiment-design-self-check v1。检查者：本次设计助手；是自查，不是独立评审。计划见[PLAN](PLAN.zh-CN.md)。旧版本保留在e513f30，本文替代其自查结论。

## 设计卡和修订范围

主线保持：在四个具体模型中测量局部激活干预的当前与历史条件效应，建立可比、可重放证据。独立A固定文字四格与B自然生成三臂不变；跨模型线不裁决原机制线。

新增认识：在共同入口量程、多针/深度、固定任务与留出面板中，给出条件效应、模型配对差和其精度范围；不将代数、状态存在或存得多当科学发现。

操作及估计对象：PLAN §§4–6。A有符号H/C/J和主要平均绝对历史效应/交互的模型差；B可达条件内W−R正确交付差、可达性和共同可达的探索模型差。不做架构因果归因。

本次r3的实质修改（r2的剂量校准、判读和完整小批次规则继续有效）：

1. 核对F0已提交收据及下载JSON，将模型身份与工程数值验收分开；Llama仅有镜像哈希身份，不冒称官方核验。
2. 取消外部归档要求，全部新增落盘峰值≤200 GB且受实际Q约束；持久分片累计、轻记录、临时文件、他人预留均计入。
3. 深A从1,536格改为384格：2情景、一个平衡事实版本、所有模型/层、原生与随机两方向、正负、完整四格；深B仍96源。A最多5位置、B前8步，减少全层重复和内部字段；完整边界缓存保留。
4. Q不足时事前仅降时间点密度（A仅q、B仅首步），不删除对照。最低完整方案仍超限则报告深记录阻塞，不暗中换目标。
5. 增加离线能力表和Q-dose有限行为描述；不承诺任意CPU机制分析、不由校准读数推断ΔV趋同、不恢复P1–P3或P-conv。

B正式仍12情景；先前讨论的24情景是未落实的建议，本次没有借存储修订扩行为规模。两情景深记录的任务覆盖有限，不能代替全量轻面板或独立机制确认。

另外修复原计划自然CONT观察长度缺口：最大k=16、各臂续写64，CONT源需最多80token；按每个k截取k+64。原来源总长64与派生分支续写64并不等长。源运行数不变，生成token预算更新。

证据与限制：沿用已核对官方模型配置/卡、项目旧报告和撤针审计；本轮读取F0仓库收据、没有重新登录服务器测容量或重跑历史实验。四模型不能排除训练与架构混淆，随机针有限，B可达性有选择性。所有新实验未运行。

## 历史错误逐组核对

- E01/E24：独立跨模型线，保留有边界增量，不要求一次完整机制。
- E02/E03：相对层非功能同源；包含有效投影乘子，开发量程与正式尺度不混同。
- E04/E09：数学账与行为交互不自动成为机制；A/B交叉表非预测。
- E05/E06/E08：本轮不做共享门/键拆分，供体完整同文字无针状态，未穷尽每类写入因素。
- E07/E14/E19：重放为工程，不当必要性/充分性/结构恒等式发现。
- E10/E11：停止倾向≠停止、候选概率≠事实完整保存、重建读文字≠恢复原记忆。
- E12：两随机方向不是零分布；尺度配平不消除一般损伤；地板不当机制等效。
- E13/E15/E17/E26：形成/读出时段分开，旧运行与新合同不拼链，生成中形成的状态也是历史。

- E21：不以多模型和更多张量作为新颖性；§12已列直接近邻，最终主张须再查重。
- E22：两个事实/多针/多token非独立n；确认只开一次，不按阳性扩样。
- E23：设计自查、数值验收、执行授权、实际结果分开。

## 反方检查及修正

**“没有方向预测就不是科学。”** 不接受；本轮是预定估计对象与判读规则的探索基础研究。但必须冻结估计对象、阈值、统计单位和扩容规则，已写§9/11；不能任何结果都叫支持。

**“δ由数据波动决定，就能随意宣布等效。”** 接受此风险；δ_A=0.05、δ_B=0.10现在固定，说明为研究决策选择，不是领域标准；MDE由开发方差另算。开发或正式精度不足不改变δ。

**“六个确认情景的B全相同，bootstrap区间会为0。”** 接受；§9.3退化时用保守有界区间/完整范围，禁止零宽等效。小n很可能不确定，这不是实现失败。所有区间推广仅限任务生成方案。

**“选非饱和剂量就是选结果。”** 开发阶段按统一判据选量程确实使用响应，但不选期待模型差异或强针；正负方向均测、原始选择记录全存、所有模型共享正式尺度，正式独立留出。该边界明确，不能声称完全无选择的原始剂量研究。

**“校准耗时没有计算。”** 已补A最多27,648逻辑校准格、B最多1,728开发源，另计工程预检和历史回放。未测GPUh，不伪造耗时。

**“存储数字过时或别人同时写盘。”** 收据354G不当现值；F1字节级df与各任务预留复核，实时剩余量触发限流/停新任务。200 GB与安全余量共同约束，且持久累计不作为可回收热缓存。实际路径、容量、吞吐仍须工程验收。

**“旧针不阳性就不停修。”** 明确禁止；只在完全相同资产/条件的回放不一致时查工程；新条件不复现属于科学边界。历史回放不进入主结果、不要求阳性。

**“B终点长度不配对。”** 原稿的实际缺陷；源80token、各k的CONT截取k+64已修，所有分支按共同64续写窗口，EOS自然提前停止。

**“多针加总掩盖异号。”** 主要M使用绝对值只为测响应幅度，H/J有符号分层同时保留；不能把|H|共同为正解读为相同功能方向。跨深度稳定要求指定符号条件。

**“等入口强度仍不能证明架构。”** 仍成立，是可接受范围边界；只给具体模型条件差异，不给架构因果。四模型不是完整因子设计。

### r3最强反例和修正后复查

- **只把97改为200会破坏磁盘保护。** 接受；200 GB为意愿上限，实际Q仍扣其他任务/新增依赖/原安全余量，按文件系统分别计算，不保证能用满。C12/C13复查通过。
- **少存一部分导致后续无法算两事实内部差分。** 接受并缩小深记录能力承诺：A深子面板每情景仅一个事实，主轻矩阵不变；明确此内部差分需重跑，不能把两个不同情景当事实对。C02/C10复查通过，有界几何与边界重放仍有用。
- **384格仍可能很大。** 接受；改为选择时间点、残差级字段与完整缓存，按模型最大形状逐字段计字节并乘1.25；没有实测前不承诺能装下。最低档不合容量则深采集阻塞，允许完成有身份标注的F1，不冒称正式基础数据已完成。C11/C12复查通过。
- **单副本损坏后无从恢复。** 是用户不外归档约束下的真实边界；Git索引/哈希不是张量备份。本地重读/重放能验证文件当时有效，不能保证灾难恢复，不将其表述成双备份。C13通过但风险保留。
- **校准探索被包装为预注册机制阈值。** 不接受该包装；Q-dose只描述行为响应、饱和和有限方向极差。新阈值另需留出确认，无新增调用。C04/C08/C09/C10复查通过。
- **减少记录把研究变成一般行为评测。** 主A/B的干预时段与同文本内部历史比较没有改，完整cache与固定轨迹支持有限后续机制分析；删去的是未经容量支持的全字段承诺，非改估计对象。C01/C02/C08/C14复查通过。

C05–C07操作/路径不变；C03补入F0收据；C06另明确文本分叉后的轨迹不可严格配对；其余C项沿用上表理由并对r3 §§2.1、4.2、7、10.1重新核对。E03/E09/E12防范饱和和方向无关混同，E22锁定深面板不按阳性选择，E23本次自查不是外部独立审查，E25记录降档不加矩阵；其余E项按上述逐组理由无新增适用操作。
