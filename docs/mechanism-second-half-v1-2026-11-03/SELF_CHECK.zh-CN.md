# 下半场 Proposal v1 自查

2026-11-03。规范：experiment-design-self-check v1。对象：[Proposal](PROPOSAL.zh-CN.md)。这是同一设计者自查，不是独立评审。

**结论：研究路线层面的设计通过，可作为讨论稿交付；具体实验尚未设计冻结，不能据此直接运行。** 此次只交付两份文档。未计算候选量、未重算实验、未加载模型或启动 GPU。

## 设计卡

1. 主线／本轮问题：解释稀疏干预经写入、历史状态处理和后续读取改变答案；本稿安排如何把已有条件性链条接到原生入口并研究分叉。
2. 增量：从局部修复证据走向形成连接与跨条件比较，不把架构恒等式或相关预测当机制。
3. 依据／反例：SIT 的跨背景增量作用与原生停止未修复；CGV 的 L12 反向 k 作用和新任务行为收益有限；三份零 GPU 文档的数据及缺失清单。来源在 Proposal 末尾。
4. 操作：本稿只有文档组织；后续先对齐 L0/L12 条件和已有记录，不冻结供体、hook、剂量、模型运行或新增矩阵。
5. 估计对象：后续区分原生操作效果、恢复背景条件作用、状态转移和实际答案。具体比较须在唯一下一包实验卡中写定。
6. 判读：支持共同过程、支持条件分叉、只有局部代理变化、反向或不可判分别保留；没有统一成功／失败标签，也没有机制份额承诺。
7. 范围／成本：只用已有资产制定路线；知道历史轨迹缺完整向量和调查条件的缓存。新增测量和所有验收成本由下一实验卡按缺口提出，不宣称零 GPU 可完成因果连接。
8. 退出：分支无法形成可区分的比较，或只有一般破坏而不能支持承诺时停止；不自动扩层、换题、加剂量。

## 历史错误与相对前案的修正

- E01/E24/E25：恢复主线，保留局部成果；不把修复停止或局部全拆完设成总任务，不铺矩阵。
- E02/E03/E18/E20：L12 是已有反例而非天然特殊层；区分输入范数、传播变化、状态作用；形成与使用可共同变化，不以排除法给剩余机制命名。
- E04/E09/E11/E14/E15：公式、状态距离和投影不等于因果发现；条件性链条不能跨不匹配背景直接拼接；效应比不作完成度。
- E07/E10/E13/E22/E23：混合背景不作原生证明，来源与终点分开；旧数据不称未见；自查不称独立审查。
- E16/E21/E26：允许科学阴性；不承诺首创或录用；以后若形成期操作同时影响直接读取，只能按真实操作报告总效果。
- E05/E06/E08/E12/E17/E19：本稿未提出对应变量拼换、补偿、零分布或重放操作，暂无可审核实现；具体实验不能继承“通过”，须按对象逐项检查。

与旧 cross-condition-predictor 草稿相比：保留资产盘点与探索／验证分离；取消以 EOS 排序竞赛作为下半场中心，改为原生形成连接与跨条件机制比较。保留 H3/H4 作为未证实线索，不接受其“信息丢失／默认输出”的提前归因。原文件保持历史原样。

## 同作者反方检查

1. **共同轨迹可能只是一般破坏。** 处理：相关扫描只提名缺口；要通过针对连接的操作及实际输出检验增加因果证据。只有一般破坏则停止该解释。
2. **L0/L12 可能因任务、剂量或来源不同而不可比。** 处理：先列条件，不能直接拿不同实验平均数归因于层；缺少可比测量就提出最小缺口，不臆造对齐。
3. **恢复操作有效仍可能绕过原生机制。** 处理：第一段明确要求在原生干预背景中检验连接；恢复背景阳性保留原身份，不升级为原生路径。
4. **“共同机制”可能成为强行统一的要求。** 处理：允许共享部分加分叉，允许有关联的不同路径；没有共同证据就不合并。
5. **历史标量轨迹不足以研究写入。** 处理：已列出完整向量与缓存缺失；首轮交付是连接表及一个实验卡，不声称旧数据足以闭环。

最后复查：研究目标没有改成 EOS 预测；已有机制保留；下一步有限且接续已有资产。实现／数值验收未开展，运行未授权。下一轮用户打磨的是研究路线，尚非批准实验执行。
