## 1. 我们接下来要做什么

我们以已有的原生链证据和条件性“写入—状态—读取—回答”机制为基础，解释恢复背景与原生背景中的作用为何不同，再横向比较不同针、层和任务下的共同过程与条件差异。中心问题是：**稀疏干预怎样经传播、写入、历史状态处理和读取改变回答；其中哪些过程是等强度扰动共有的，哪些由方向、位置和任务背景决定？** 预测用于检验这种解释，停止只是回答变化的一种表现。已有机制是下半场的因果证据和实验工具，不丢弃，也不预设它能覆盖所有情况。

拟检验的中心命题是：**稀疏干预的效应取决于它如何被后续计算转化为可留存、可使用的状态变化；不同条件可能共享形成过程，却在写入内容、旧状态处理或读取使用上分叉。** 这是研究假设，尚不是跨条件成立的结论。

**随机方向复现已有关系，是需要解释的正面证据，不是附带限制。** 要检验共同作用与方向依赖，不能预设必须找到“超越随机扰动”的效应。若同幅随机方向也经同一计算过程改变回答，且能说明其条件与因果作用，这可以构成更宽的机制。随机方向是主动比较对象，不是无效应零分布；“不特异”也不等于“没有机制”。

87–97%、73–86% 等既有数字是指定对照下的效应比，不是机制完成度。**原生链并非空白。近期缺口是：以 NVB 的原生背景弱效应为起点，解释为什么恢复背景中明显的写入—读取作用，在原生背景中没有同等表现。** 这限定了已有操作的作用，不代表原生写入与读取不参与，也不表示其余机制都已闭合。

## 3. 三份零 GPU 工作怎样接回主线

保留原文，重新安排用途，不直接执行原来的 EOS 预测方案。

- **盘点**提供关键比较入口：同层、同题、同剂量且实际写入范数匹配时，不同通道仍可产生不同后果，因此单靠输入幅度不足以解释这些层内差异。要把方向差异连接到传播、状态形成和使用，而不是只做输出排序。实际输入范数相同不保证下游状态变化同幅；不同任务或模板的数据不能直接拼为配对证据。
- **候选解释**用于提出形成过程的假设：扰动怎样传播、任务相关差异是否受到影响、这些变化怎样进入写入和历史状态。H3“传播”与 H4“表示变化”只是线索；余弦变化不等于信息丢失，也不能直接命名为“默认输出机制”。H1 提供强度参照，H2 的停止对齐保留为特定输出的辅助解释。
- **预注册草稿**只复用“探索、未见条件检验、因果操作分开”的原则。旧数据多数结局已看过，只能用于回顾性探索。原草稿的 EOS 排序、候选胜出门槛和统一停止规则不作为本 proposal 的主线。

## 4. 推进顺序：先解释背景差异，再拓宽共同关系

### 第一段：解释已有写入—读取操作的背景依赖

从 NVB 的原生背景弱效应与 SIT 的增量转移结果出发：恢复背景可能改变了产生的状态增量，也可能改变了接收者使用它的方式，两者可以同时起作用。下一轮围绕这个具体差异选操作，不从头重新寻找针进入了哪个缓存。

SIT 的幅度／方向分离是已有候选，具体设计时应优先评估其能增加什么认识：等幅比较若仍有差异，支持超出幅度的作用；若缩放能复现，则支持该操作范围内的幅度解释，不推出所有方向等效。随机方向对照按其能区分的假设安排，不机械要求每张卡都新增随机臂。连接表仅作已有证据与缺失测量的简短附录，不设为新的研究阶段或开工门槛。

只设计一个能区分当前解释的最小实验包，明确被操作对象、输出背景和对应终点。尤其不能用 t1 之后的状态替换解释已经发生的 t1 首步选择；强制前缀下的目标竞争作用与原生首步、自然完整回答分别解释。旧标量轨迹不能重建完整 q/k/v 或状态，必要缺失测量单列，不臆造已有数据。

这一段要新增的是：**背景差异怎样改变写入—状态—读取关系的实际作用，以及这些变化能解释哪一部分回答差异。** 如果候选操作只在恢复背景有效，就保留其条件性身份，不称为原生机制。

### 第二段：围绕分叉拓宽，而非逐个复制案例

优先检验两类已有线索：L0/L12 的写入作用不同；新任务中目标分差与完整回答变化不同。它们是待解释的条件差异，尚不是已确定的共同分叉规律。先解决能由第一段直接检验的一类，另一类保留；L0/L12 比较必须对齐题目、强度定义、输出背景和时段，剩余传播路径不同也须明确，不能直接归因于层号。

再从零 GPU 盘点中选少量条件匹配、内部传播或输出明显不同的通道，检验第一段得到的关系。选择规则在新干预结果之前写定；旧数据选出的对照不冒充独立确认。

每个比较都问同一件事：差别来自进入状态之前的形成过程、写入／旧状态处理，还是后续使用？只有与数据一致的候选才做对应操作。允许共同过程带有分支，也允许发现另一条相连的路径；**不能仅因两个案例都“改变答案”就把它们捆成同一机制。**

这一段的产出是一张带条件的机制图：共同部分、已证实分叉和未连接部分分别标清。新增层或通道必须帮助区分解释，不做普查式扩展。

### 第三段：用真正的新条件检验解释

当形成了可操作的关系，再选择最能挑战它的新输入、针或任务，提前说明预计哪一段变化、哪一段保持，以及会怎样影响答案。先做一个有区分力的检验包，不同时铺开跨层、跨任务、跨模型、跨规模网格。

跨模型研究在具有可比计算对象时加入。相似输出不证明相同内部机制，模型间差异也不自动归因于架构。预测不符时，检查原有解释在哪个条件不成立；有具体分叉问题才回到局部深入。

## 5. 怎样看结果，才服务于中心问题

每轮同时保留三层证据：被操作的计算对象、状态及其后续使用、实际回答。能评分的任务报告正确性和原始输出；没有正确性标签的历史题目，仅报告可核验的输出差异与明确的异常类型，不把不同首 token 数当作能力或语义损伤。停止、重复、模板化输出与选错记录分开记录。

条件性强制前缀读数与自然生成分别分析。原生轨迹已经停止时，不把强制继续后的行为叫作原生恢复。无行为翻转而分差变化，说明影响到了竞争过程，但还未证明解释了完整回答。

我们期待得到的较强贡献是：**一套能接上原生干预、解释多个条件中共同过程与分叉、并经针对性操作和新条件检验支持的计算机制。** 若只得到有边界的多条路径，也应如实保留，不能为了统一叙事强行合并。论文档次和录用结果不是本 proposal 可以保证的结论。

最终产物是一张机制图及配套证据表：每条关键连接标明原生背景证据、恢复背景证据、与匹配随机方向的比较及未测部分。共同过程与条件分叉分别呈现；缺失证据明确留空，不把每一条边都强制扩成完整实验矩阵。

## 6. 近期工作与收束

下一步直接围绕第一段的背景依赖问题交付**一个**最小实验卡，以已有 NVB/SIT 和原生链证据为起点；该卡明确缺失测量、操作、估计对象、不同结果的含义，以及包含重放和验收的成本。当前不运行旧预注册，不新增 GPU 工作。

范数匹配、β/k/v 因子交换、层组定位等已有候选不会自动全部追加。只有当它们能区分当前连接问题的竞争解释时才进入实验卡。

一个分支若没有可区分的解释，或只显示输出受破坏而无法连接到承诺的计算过程，就停止该分支，留下负面结果。随机方向与针产生相似作用本身不触发停止，而用于检验共同机制；不靠加剂量、换题或扩大搜索救结论。每轮应交付一条新增连接、一个被支持的分叉，或对某种解释的明确约束。

本稿研究方向已 Ready。后续进入具体实验设计，解决操作时点、可比条件、能够兑现的行为解释及预算；不再把方向稿展开成所有分支的运行合同。
