## 0. 现状判断

不是"基本确定能成，只剩提高上限"。现象、局部计算证据与反例已经降低了从零开始的风险，但**尚未把它们组织成一个值得检验、能够站稳的贡献**。最容易犯的错是：在核心主张没站稳时，通过加层、加模型、加实验把投入做大。

| 问题 | 性质 | 当前状态 |
|---|---|---|
| 能否提出已有知识未充分回答的重要结论 | **决定核心贡献** | H1仅是研究方向；具体可迁移规则仍未识别，一般背景依赖/缓存污染已有先行工作 |
| 解释与实际回答变化是否有可信因果连接 | **决定核心贡献** | 指定恢复背景有计算与完整回答作用；原生连接和跨条件解释尚不充分，不把停止/错误直接拆成独立机制分量 |
| 解释能否接受独立条件检验 | **决定核心贡献** | 0 份独立材料；所有面板已见 |
| 覆盖更多模型、任务、深度 | 取决于主张 | 独立条件确认影响核心可信度；若声称跨模型/架构，相应证据必需。没有普适数量门槛 |
| 定位更多层、头、位置 | 影响解释精度 | 只在能区分 §3 的替代解释时才做 |
| 可用的诊断/干预方法 | 可能提高价值 | 不主张实用性，不兑现 |
| 解释全部残余、证明唯一通路 | 非必要 | 不做 |

## 1. 总问题（不变）

> 稀疏激活干预怎样改变写入、历史状态处理和后续读取，最终造成回答变化；哪些关系可以跨条件复用，哪些受到明确条件限制？

**预测是检验机制解释的手段，不是把课题改成预测器项目。** 不强求标量公式或统一所有条件。随机方向复现关系是需要解释的正面证据，不是附带限制；但效应相似、操作响应相似、计算过程相同必须分开检验。

## 2. 我们希望多知道什么

**优先研究方向H1（尚无核心主张）：稀疏干预所形成的状态变化，其写入/读取作用能否影响完整答案，受到形成历史与接收/使用背景的条件性约束；这些约束能否形成跨条件保持或有明确失效边界的规律？**

这是寻找具体规律的研究方向，当前不能称为已经提出的可推翻核心主张。现有证据支持具体背景差异，尚未识别能事前限定保持/失效的规则；“背景重要”“KV带事实”“停止不是全部损伤”本身不足以承担核心。下一项比较必须提出有限的适用条件和失败预期，不能用“每个条件各有机制”容纳所有结果。

[审计§2](CORE_CLAIMS.zh-CN.md)比较六类候选：H1优先；旧局部写入—状态—读取链H2作为计算骨架和竞争解释，不丢弃、不预设普遍；KVC事实定向H3作桥接，不默认追加读取定位；状态类型地图H4作覆盖工具，不独立启动扫描；特殊通道叙事H5不作前提；v5的形式/内容双分量H6不足以识别，不能用作执行基线。

优先压力测试是WIN已暴露的恢复关系分叉：同为记录句后受针，L0事实的深层S恢复仅16/48、全层递推47/48，而编号任务深层S为48/48。**这提示同一操作关系可能有边界，却尚不能命名为不同“内容承载”。** 旧数据审计已完成，下一项已选为[WPC-01](WINDOW_COMPARISON.zh-CN.md)：一个方向、两块已见面板、C/T/深层递推/全递推四臂，共同逐token形成、固定bf16幅度−5.96875、W_post尾部25位置、128-token生成。它检验分叉的共同协议稳健性；不把所有状态、深度、针、窗口一次交叉。SRU是可用的具体计算工具，不是必须重新拆完整条链的起点。

### 2.1 已完成审计与待测预测

旧WIN的384个相关输出重算：事实S_deep 16/48、R_all 47/48；编号两臂均48/48。编号C/T/S_deep/R_all全部在17 token内自然停止；提高旧编号上限到128不会改变这些已终止轨迹。事实S_deep有32/48达到128上限且未交付正确结论，不能称内容丢失。事实/编号名义单次写入范数均值为2.7875/2.6265，施针次数25–33/26–27；旧协议差异尚未排净。

**P-WPC（有限操作预测，不是论文核心主张）：** 可检验余量满足时，共同协议下D_fact−D_code至少0.20，其中D为同输入Y_R_all−Y_S_deep的情景等权平均。它可能支持、近零、反向或不可判；固定判据见[设计§4](WINDOW_COMPARISON.zh-CN.md#4-哪些结果改变什么判断)。看过旧结果后提出此预测，只登记在未来测量之前，不追认旧结果为事前预测。

**价值与出口：** 阳性使这一有限关系值得进入新输入/非L0/随机方向的横向边界检查；近零、反向、余量不足或不可判均结束这张卡，不自动加层、加预算、延长输出或继续拆浅层。先停止局部续卡，不要求为保住H1再找一个窄机制。多个协议项同时标准化只能判断共同策略稳健性，不能唯一归因旧差异的原因。

完整数字、固定报告链接和文献边界见[审计§3–4](CORE_CLAIMS.zh-CN.md)。覆盖按关系分账：XCHAN是L0的10原生通道+4随机方向的粗关系；SRU细读取行为主要为L0/N4146、N1210、R0；KVC为L0/N4146、L0/R0、L3/C7666，即两原生通道、一随机方向、两个施针层位、一类已见事实任务（22对/44接收者）。不能累加成十几针共同完整机制。

87–97%、73–86% 等数字是指定对照下的效应比，不是机制完成度。

## 4. 最强的替代解释（不预先排除）

以下解释可能共同存在，横向比较须逐项说明它实际能区分什么：

1. **干预尺度/位置数**：W_pre 与 W_post 位置数逐题差 −14…+13，"段"可能是累计剂量的代理。
2. **天花板**：损伤轻的格救回余量小，恢复偏好不可判。
3. **可受影响下游范围**：注入层决定哪些 KV 层受损（L3/L5 注入时第 3 层 KV 干净），非 L0 针"偏递推"可能是结构后果。
4. **任务协议差异**：生成长度 128/32、校准文本与尺度、形成实现、判读方式全部不同。
5. **操作背景与一般作答损伤**：供体重新带入信息、混合状态补偿或一般作答改善，都可能参与恢复；KVC的定向性不自动排除这些作用。

## 5. 什么结果使核心主张获得支持、修改或暂停

| 结果身份 | 处置 |
|---|---|
| 一条事前限定的状态/计算关系跨可比条件保持或出现预言的边界，并连接自然回答 | 支持该有限关系；接受未参与构建规则的材料确认，不把一次阳性升级为完整机制 |
| 差异主要由实际尺度、原始损伤/余量或输出阈值解释 | 收缩对应的新机制主张；不把窗口效应消失直接等同于已经证明累计剂量机制 |
| 效应只在人工恢复组合成立，原生回答连接不足 | 保留恢复操作规律，撤回超出证据的原生致错归因 |
| 计算读数变化但完整回答未呈相应变化 | 保留计算作用，不能声称行为推广；优先判定阈值/任务边界，不自动细拆 |
| 阴性、不可判或不能形成区别于已有工作的具体规则 | 限制或暂停该候选；不自动扩层、换题、加剂量或转押其他分量 |

同一状态恢复在两任务的效果不同，最多先支持条件性操作差异；不能直接叫“内容载体不同”。两任务相同也不证明其他差异全是协议产物。一个配对窗口的阴性不唯一证明剂量机制。原v5的这些自动推论不再作为判读规则。

## 6. 推进顺序（按消除关键不确定性，见 Roadmap v7）

| 阶段 | 要得到的认识 | 现状 |
|---|---|---|
| 确定核心候选主张 | 现有支持、最强反例、直接近邻与缺失 | **方向审计已完成**；H1是方向，未形成核心主张；新增P-WPC为有限诊断预测 |
| 关键横向比较 | 现成关系在可比条件保持还是失效，能否区别强度/阈值与操作背景解释 | **已选WPC-01**：旧384输出审计完成；缺共同策略384输出及16条旧桥接；设计含自查，未运行。上限1 GPUh含验收；不是已授权运行 |
| 必要的计算检验 | 对关键共同点或分叉给出因果约束 | 只在横向结果指出影响整体解释的分叉时做；不追求完整回路 |
| 独立确认与边界 | 固定关系面对未参与构建它的材料 | 当前候选所用面板已见；对象可比时按主张需要接入新任务/模型，不等局部全图完成 |
| 价值兑现 | 是否支持更好的诊断/控制，或构成足够重要的机制结论 | 决定论文形态；现在不承诺 |

横向比较从一开始承担**区分解释**的职责，不是"先扫全层，再挑一点深挖"。

**v4 队列的修正**：
- **取消"再做一轮 KV 读取"作为默认下一步。** 它与已有KV研究高度重合，当前不足以支撑主贡献。"最多一轮"的上限保留，但上限不是配额，也不是这一轮值得做的理由。以后因横向分叉开启的局部检验，最多一轮事前有界比较；任何结果后回横向，不得拆卡重置或无界打包。
- 局部深入重新开启的条件：横向结果出现影响 §5 处置的分叉，且能说出它解决哪个跨条件问题。
- **SDM 全层图谱草稿不自动成为主线。** 它有两处影响科学结论的问题：(a) 从"干净上下文中 KV 与递推的分工"推到"内部干预致错时恢复 KV 应充分、恢复递推应不足"不是自动成立的推论，基线推得过强时测到偏离也未必是发现；(b) 单类恢复与留一恢复不能把结果直接归为"唯一承载/分布式/冗余"，超出这些反事实操作的识别范围。它可以提供数据，但扩大运行前必须说明这些数据检验什么解释。已在[该稿](../cache-state-type-damage-map-plan-v1-2026-11-05.zh-CN.md)顶部登记。
