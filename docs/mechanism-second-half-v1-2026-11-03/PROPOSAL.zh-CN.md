# 从局部链条到共同机制

**Acupuncture 课题下半场 Proposal · 讨论稿 v1 · 2026-11-03**

状态：研究路线提案，供下一轮打磨；不是运行合同，不启动模型或 GPU 实验。[自查记录](SELF_CHECK.zh-CN.md)。

## 1. 我们接下来要做什么

我们要以已经建立的条件性“写入—状态—读取—回答”链条为基础，向上连接真实的稀疏干预入口，横向比较不同针、层和任务下的计算路径，找出哪些过程共同存在、哪些条件使路径分叉。最终要解释：**为什么少数通道上的干预，会经过模型的写入、历史状态处理与后续读取，产生不同类型的大幅回答变化。** 预测用于检验这种解释，停止只是回答变化的一种表现。已有机制是下半场的因果证据和实验工具，不丢弃，也不预设它能覆盖所有情况。

拟检验的中心命题是：**稀疏干预的效应取决于它如何被后续计算转化为可留存、可使用的状态变化；不同条件可能共享形成过程，却在写入内容、旧状态处理或读取使用上分叉。** 这是研究假设，尚不是跨条件成立的结论。

## 2. 上半场留下了什么

| 资产 | 已有价值 | 仍缺的连接 |
|---|---|---|
| LVK / SRU 的局部写入与读取干预 | 在指定背景下，局部 v 与 k 的写入关系能改变目标竞争和完整回答；一次直接读取替换有行为作用 | 还不能把这些混合背景拼成唯一的原生损伤路径 |
| NVB / NBR / SIT 的输出背景与状态增量研究 | 状态增量的来源与接收背景都影响其作用；实际增量可以跨背景转移 | 增量幅度与方向尚未分开；原生停止并未因此普遍修复 |
| CGV 的跨针、跨任务、干净背景比较 | 提供了有价值的分叉：L12 局部 v 恢复有效，指定 k 修正没有同样收益；新结构中分差变化不总转成正确回答 | 需要解释分叉发生在哪个计算关系，不能概括成“L12 与 k 无关” |
| 三份零 GPU 文档 | 已盘点跨模型、层、通道和剂量的行为及轨迹，并整理候选解释与验证思路 | 是资产盘点、假设和草稿，不是三个新结果；历史轨迹不含调查条件的完整状态向量 |

87–97%、73–86% 等既有数字是指定对照下的效应比，不是机制完成度。当前最强成果是有边界的计算因果关系；下半场要增加其原生连接和适用范围。

## 3. 三份零 GPU 工作怎样接回主线

保留原文，重新安排用途，不直接执行原来的 EOS 预测方案。

- **盘点**用于找可比条件和缺失测量。同层、同题、同剂量且实际写入范数匹配的通道，可用来比较方向不同为什么造成不同后果。不同任务或模板的数据不能直接拼为配对证据。
- **候选解释**用于提出形成过程的假设：扰动怎样传播、任务相关差异是否受到影响、这些变化怎样进入写入和历史状态。H3“传播”与 H4“表示变化”只是线索；余弦变化不等于信息丢失，也不能直接命名为“默认输出机制”。H1 提供强度参照，H2 的停止对齐保留为特定输出的辅助解释。
- **预注册草稿**只复用“探索、未见条件检验、因果操作分开”的原则。旧数据多数结局已看过，只能用于回顾性探索。原草稿的 EOS 排序、候选胜出门槛和统一停止规则不作为本 proposal 的主线。

## 4. 推进顺序：先接一条，再找共同关系

### 第一段：把原生入口接到已有机制

以已有 L0 机制条件为锚点，以 CGV 的 L12 条件为对照，先整理各自真实干预下的计算过程：针写入了什么，下游哪些变化先出现，哪些变化进入卷积历史或递推状态，后续怎样被使用。比较必须标明输入、针、强度、时段、状态来源和输出背景；不能把不同任务的旧统计当作同一条轨迹。

**第一份产出是一张“机制连接表”**：每条连接标为已有因果证据、只有伴随变化、或缺失测量。只查与 L0/L12 分叉直接相关的资产，不重新盘点整个仓库。旧标量轨迹不能重建完整 q/k/v 或状态；缺什么就明确写什么。

随后只选择一个最有判别力的缺口做最小因果实验：在原生干预背景中，操纵候选连接，检查它是否按预期改变已知写入／状态效应，以及对应的实际输出。具体替换对象与时段由连接表决定，单独形成短实验卡；不预先展开所有部件矩阵。

这一段要新增的是：**已有的条件性修复关系，哪些部分实际参与了针造成的变化。** 如果候选操作只在恢复背景有效，就保留其条件性身份，不称为原生机制。

### 第二段：围绕分叉拓宽，而非逐个复制案例

优先解释已经出现的两类差异：L0/L12 的写入作用不同；新任务中目标分差与完整回答变化不同。先解决能由第一段直接检验的一类，另一类保留。

再从零 GPU 盘点中选少量条件匹配、内部传播或输出明显不同的通道，检验第一段得到的关系。选择规则在新干预结果之前写定；旧数据选出的对照不冒充独立确认。

每个比较都问同一件事：差别来自进入状态之前的形成过程、写入／旧状态处理，还是后续使用？只有与数据一致的候选才做对应操作。允许共同过程带有分支，也允许发现另一条相连的路径；**不能仅因两个案例都“改变答案”就把它们捆成同一机制。**

这一段的产出是一张带条件的机制图：共同部分、已证实分叉和未连接部分分别标清。新增层或通道必须帮助区分解释，不做普查式扩展。

### 第三段：用真正的新条件检验解释

当形成了可操作的关系，再选择最能挑战它的新输入、针或任务，提前说明预计哪一段变化、哪一段保持，以及会怎样影响答案。先做一个有区分力的检验包，不同时铺开跨层、跨任务、跨模型、跨规模网格。

跨模型研究在具有可比计算对象时加入。相似输出不证明相同内部机制，模型间差异也不自动归因于架构。预测不符时，检查原有解释在哪个条件不成立；有具体分叉问题才回到局部深入。

## 5. 怎样看结果，才服务于中心问题

每轮同时保留三层证据：被操作的计算对象、状态及其后续使用、实际回答。能评分的任务报告正确性和原始输出；没有正确性标签的历史题目，仅报告可核验的输出差异与明确的异常类型，不把不同首 token 数当作能力或语义损伤。停止、重复、模板化输出与选错记录分开记录。

条件性强制前缀读数与自然生成分别分析。原生轨迹已经停止时，不把强制继续后的行为叫作原生恢复。无行为翻转而分差变化，说明影响到了竞争过程，但还未证明解释了完整回答。

我们期待得到的较强贡献是：**一套能接上原生干预、解释多个条件中共同过程与分叉、并经针对性操作和新条件检验支持的计算机制。** 若只得到有边界的多条路径，也应如实保留，不能为了统一叙事强行合并。论文档次和录用结果不是本 proposal 可以保证的结论。

## 6. 近期工作与收束

下一步先完成第一段的机制连接表，并据此交付**一个**最小实验卡；该卡明确缺失测量、操作、估计对象、不同结果的含义，以及包含重放和验收的成本。当前不运行旧预注册，不新增 GPU 工作。

范数匹配、β/k/v 因子交换、层组定位等已有候选不会自动全部追加。只有当它们能区分当前连接问题的竞争解释时才进入实验卡。

一个分支若没有可区分的解释，或操作只有一般破坏而无法连接到承诺的机制，就停止该分支，留下负面结果；不靠加剂量、换题或扩大搜索救结论。每轮应交付一条新增连接、一个被支持的分叉，或对某种解释的明确约束。
