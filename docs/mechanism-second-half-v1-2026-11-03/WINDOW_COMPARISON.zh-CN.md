# WPC-01：WIN 恢复分叉的统一协议比较

2026-11-05；设计 v1。状态：**已有数据离线审计已完成；具体比较的作者逻辑自查通过；未实现、未做模型验收、未运行、无新模型/GPU授权。** 本文与 Proposal v7 / Roadmap v7 配套。H1 仍是研究方向，不是已有核心主张。本轮只决定一个已有分叉是否值得带到更宽条件，不承诺由此发现通用机制。

## 1. 主线、本轮问题与可失败的句子

总问题：稀疏干预如何改变写入、历史状态处理与后续读取，进而改变回答；哪些关系能跨条件复用？

本轮问题：WIN-01 的“全递推相对深层递推的回答恢复优势，在事实面板明显大于编号面板”，在共同生成上限、形成流程、单次施针幅度及次数下是否保留？

**待测操作性预测 P-WPC：** 在下面固定的共同协议和原有两块已见面板上，若干净基线与损伤/恢复余量达到可检验条件，全递推相对深层递推的正确结论率增益，事实面板比编号面板至少高 0.20。定义为 D_fact − D_code ≥ 0.20，D_task = mean(Y_R_all − Y_S_deep)。这个数是沿用 WIN 的实质变化尺度制定的研究决策阈值，不是自然常数、统计显著性或看过新结果后的拟合。

预测来源是旧数据，因此旧 WIN 结果不算兑现预测；两块面板已见，新协议测量也不叫外部确认。即使兑现，得到的只是**固定操作与预算下可复用的任务面板分叉**，尚未得到形成历史/使用背景的通用条件规律。不能用“当且仅当背景合适”填空制造核心主张。

## 3. 选定的最小比较：一个方向、两个任务、两个恢复臂

### 3.1 固定项与操作

- 模型、权重、tokenizer、模板沿 WIN-01：Qwen3.5-4B revision `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`；torch 2.6.0+cu124、transformers 5.20.2、bf16、eager、batch=1、enable_thinking=false、确定性设置及权重哈希按原 metadata/freeze 核验。不换模型、改输入或重新选题。
- 唯一方向为原 L0/C4146 的负向单通道，hook 仍在 MLP down_proj 输入。**改用固定 bf16 激活加量 −5.96875，不再称逐题 dose=−1。** 选择是旧编号 48 条记录的中位幅度，只依据已有校准数值确定；不根据新恢复表现调参。该列范数 0.44003573060035706，对应名义单次投影扰动 2.626463267020881。
- 两任务都只干预末提示 token 之前的最后 **25** 个位置：0-based `n−26 .. n−2`，均在原 W_post 内；旧最短 W_post 为 25，因此不丢弃输入。新窗口命名 **W_post_tail25**，不能继续冒充原完整 W_post。固定次数用于移除旧次数不匹配；不声称相同语义位置、相同下游状态损伤或相同相对扰动。
- 共同形成流程：0..b 一次干净 prefill，b+1..n−2 按位置逐 token 前向；进入 tail25 才施针。C 也使用同一分段/逐 token流程但不施针。τ 为读入最后提示 token 前；此后不施针、不强制前缀、不屏蔽EOS。
- 每个输入得到同输入 C 和 T；独立深拷贝 T 构造恢复臂。所有非替换状态保持 τ 时的 T，之后正常更新、读取和生成。不是固定未来 q/k 或整条后续路径。
- 共同 greedy 解码：最多 128 新 token，stop IDs 248044/248046；最后提示 token 先正常读入。统一一个 decoder，不因任务换生成代码。只用于评估完整任务结论；记录自然停止/截断，32-token前缀仅可作为离线辅助读数，不作为主判据。
- 实际 down_proj 输出舍入差不能由固定幅度保证严格相等。预检及正式形成 forward 内记录每次注入的位置、bf16 delta、名义范数；记录同一投影输入注入前/后的输出差范数作数值审计，不新增反事实模型轨迹。若名义写入目标偏离 >1% 或 hook次数不符，属于工程失败；实际舍入差分布如实报告，不据其微差事后重新调剂量。

| 臂 | τ 时状态来源 | 唯一用途 |
|---|---|---|
| C | 全部来自共同流程的干净同输入 | 干净作答基线与恢复供体 |
| T | 全部来自共同流程的 tail25 受针同输入 | 原始损伤、停止/错误/截断及可救余量 |
| S_deep | T 中只将 G14 的 recurrent_states 换为 C | 原深层恢复操作 |
| R_all | T 中只将全部线性层的 recurrent_states 换为 C | 与 S_deep 配对，测补其余递推的总行为增益 |

G14=`13,14,16,17,18,20,21,22,24,25,26,28,29,30`。全部线性层=`0,1,2,4,5,6,8,9,10,12` 加 G14；conv_states 与全部 KV 均不替换。L0 的同层递推结构上应 C=T，列入替换不创造新损伤。不存在“恢复十四层就是十四根针”的计数：**本卡一根针、一个注入层、一个模型、两类已见任务。**

这是一项**共同协议稳健性检验**：幅度、次数、形成流程同时标准化，不能将前后差异唯一归因其中某项。保留原完整 W_post / 逐题相对剂量结果为历史证据，不覆盖或否定它。共同输入策略仍不等于任务随机化；任务内容、模板和难度仍不同，不能把剩余分叉命名为任务语义的纯因果效应。

### 3.2 样本、终点与估计对象

固定原 48 事实输入（24 base×2）和 48 编号输入（6 情景）；不按旧恢复成败筛题。事实统一 v4 的明确最终事实结论标准，编号使用原 y_full 的完整正确编号标准；两者都排除只在思考中提到正确词、同时给出互相矛盾答案、未交付。评分规则必须在新增文本出现前写入合同，保留任务定义的合理差异，不能把两个语义任务强行变成同一正则匹配。

主读数 Y128：128-token预算内交付明确正确的任务结论；同时报告“Y128且自然终止”、首步stop、其他事实/编号、其他错误、未交付、截断。Y128 不等于无穷预算能力。新文本盲读，隐藏任务之外的针/臂身份；相同 item+完整文本哈希才复用既有标签，冲突按已有盲读规则处理。作者或模型辅助判读的来源照实标注。

主估计先在每个输入算 Y_R_all−Y_S_deep，再在 base/情景内平均，再对各 base/情景等权，得到 D_fact、D_code 与 Δ。同时给原 48 输入等权计数，避免编号情景 6/9 变体数改变权重而不说明。两任务分别重采样完整 base/情景；不得把 96 条当独立或跨任务配对。

沿用 WIN 的固定 seed 20261103、2000 次重采样框架，输出 Δ 的 95% percentile区间、各情景差及逐一删除一个 base/情景的敏感性。这是有限已见面板的探索性稳定性读数；只有6个编号情景、模板共享会限制外推，零样本方差不等于总体等效。不是新任务/新针确认，也不把区间当领域普适概率。

可检验余量：每任务 C 正确至少46/48，T 至少12/48错误，R_all 正确至少36/48。阈值分别用于排除明显基线失效、沿用WIN最小可救余量、确认“全递推可作为强恢复参照”；都是决策门槛。任何一项不满足，仍完整报告四臂，不把不利输入删掉重算“可检验子集”。

## 4. 哪些结果改变什么判断

先检查实现验收，再检查可检验余量；不以科学预期作为工程验收标准。

| 结果 | 得到/撤回的判断 | 收尾与后续 |
|---|---|---|
| 余量满足，Δ≥0.20且95%区间下界>0.10 | P-WPC在已见面板的共同策略下得到支持；简单旧协议不匹配不足以抹去此分叉 | 固定操作关系，下一科学比较转向新输入及非L0/随机方向的横向边界；不先切浅层/头/位置 |
| 余量满足，区间完全落在[-0.10,0.10] | 未保留有实际意义的任务面板增益差；不再以旧31/48差作为新机制的主理由 | 结束这条分叉优先级；回已有横向关系/核心主张审计，不说已证明某一校准因素导致旧差异 |
| 余量满足，Δ≤−0.20且区间上界<−0.10 | 方向性预测被反向结果推翻 | 撤回P-WPC；保留反例，不把“也依赖背景”当成功 |
| 其余余量满足情况，包括点差≥0.20但区间不够明确 | 小/部分差异或不可判；不得写“等效”或“已支持” | 本轮结束、暂停该候选；不自动加样本、增生成长度或换阈值追判定 |
| C低于门槛，或T损伤不足 | 当前共同策略下缺少可靠基线或可救空间，无法检验既定分叉 | 有效的适用边界；不加剂量、不换题凑阳性；不拿工程通过冒充科学支持 |
| R_all低于门槛 | “全递推是强恢复参照”的前提在此策略下失败 | 记录新边界，停止既定分叉归因，不直接推断改由KV/浅层承载 |
| 工程桥接、对象/位置/数值审计失败，或算力上限用尽 | 实现/预算未完成，不是科学阴性 | 保存失败，停止；修复与是否继续另议，不自动重跑或扩大范围 |

若阳性主要来自 S_deep 的长度截断，它仍可支持**预算内交付的操作差异**，不能支持“内容已丢失”。不另开延长到256/512的循环。两任务都强恢复也不证明同一读取机制；全递推胜深层不证明浅层独立充分或唯一携带内容。

**硬出口：** 本卡最多一轮有界共同协议测量；科学判读只在固定面板完成后进行，不按中途显著、低效果或边界值追加/提前截停样本；工程失败及资源上限按下面规则止损。所有结果交付后即结束。任何后继科学工作先回横向适用范围/反例比较或撤回候选，不自动续局部深挖。当前取消KVC读取、浅层逐组、KV/conv组合、其他窗口和剂量扫描的默认队列。重新开启局部计算必须由后继横向证据提出一个能改变整体解释的问题，不能因本卡还剩残差而启动。

## 5. 真正缺失的测量、复用与成本

1. **缺96输入在共同形成/施针策略下的四臂自然输出。** 384条生成；C/T同输入各形成一次，恢复从它们深拷贝，无候选强制评分、无新校准forward、无层/头扫描。旧tokens/文本/供体身份/模板全部复用，旧状态不能冒充新共同策略形成的状态。
2. **缺共同实现的数值验收。** 预检固定事实 AR01-f0-required、CRL01-f0-required及编号 LVK-H-NA-NQ01-ABC-A、LVK-H-NA-NQ02-ABC-B；这些是已见工程输入，不作额外确认集。四输入四臂的新协议16轨迹是384条中的一部分，配置/代码不变且验收通过时复用。
3. **旧协议重放仅4输入×4臂=16条额外生成。** 使用冻结旧形成策略及旧逐题尺度，核对原token序列/首步logits或记录的bf16量/停止；事实旧参考按原来源重建，最多2次旧校准。该桥接检验加载环境，不能要求新共同策略逐位重放旧T。新协议比较器需无操作深拷贝一致、替换字段/供体/非目标逐位正确、上游边界及位置/次数验收；在同次生成/形成中记录，不另铺参照网格。
4. 总上限400条生成（384新协议+16旧桥接），最多51200个生成token及对应前向；96×2新形成+4×2旧桥接形成，旧事实最多2校准，所有prefill/逐token形成、投影审计、载入/验收成本入回执。预算规划上限**1 GPUh**，含预检与桥接，不能把正式run计时单列绕过上限；这是资源止损上限，不是已测耗时保证。若实现预估无法在上限内完成，先返回设计状态，不削样本后声称完成。
5. 本次只审计旧记录；上述模型测量**均未运行**。逻辑设计通过不是实现通过，也不是运行授权。新合同/代码冻结、输入和统计判据锁定、工程验收以及明确运行授权仍分开。

旧数据已解决：计数重算、长度/停止审计、名义尺度/次数范围、现有操作定义与缺臂身份。旧数据不能解决：共同策略的反事实输出、实际数值桥接、128之后能否恢复、任务语义的纯因果效应、跨针跨层通用性。后四项并非本卡必须全部补齐；只新增前两类所需测量。

## 6. 与v6及截图建议相比

- v6只有“核协议后选最小比较”，现在已有逐项审计、固定比较、阈值、结果处置与退出，不再将H1称核心候选主张。
- 保留L0/N4146、两任务、W_post区域、深/全递推比较；删除浅层单独臂，避免多问一个无法帮助主差的识别问题。
- 不采纳事实32-token硬上限：旧记录已显示大量长回答；统一128并把截断单列，避免把缩短预算当机制阴性。
- 不只写“同校准尺度”：指定一个固定幅度和25次明确操作；同时承认新tail25不是旧全W_post，也不声称总体任务语义已匹配。
- 不要求本卡给出通用 iff 机制规则；它只负责决定一个具体分叉是否值得横向投入。若不能形成有新增意义的跨条件解释，H1方向仍可能停止。
