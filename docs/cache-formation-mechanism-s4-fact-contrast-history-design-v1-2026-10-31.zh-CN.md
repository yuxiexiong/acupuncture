## 1. 基本记号

- 锚点 L0、L12；背景 C = 00，T = 10（只有早段针）。L12 另做 T = 11 的核心格。开发情景 6 个，f0、f1 位置对齐。
- F：事实段内从第一个 f0/f1 不同的 token 到 b。Q：b+1..n−2。τ：Q 末，即撤针边界。答案位置：末提示与候选。
- 事实段身份 a：用 f_a 提示原生写入 F。后续供体身份 c：Q 上的写缓存变量取同一背景下 f_c 运行的原生值；c = a 时即原生运行。
- m：f0 正确候选与 f1 正确候选的对数似然差。S = m(f0,f0) − m(f1,f1) 即原生事实对比。

## 2. 实验 A：事实丢失的机制区分

### 2.1 A1　路径特定效应（定位，不判损伤）

在 C、T 各跑 2×2 身份格，得到：

- E = 后续供体固定时答案对事实段身份的依赖，即**不经 Q 重写**、由 F 上存下的信息被答案直接读到的部分；
- Lp = 经 Q 重写传给答案的部分；
- E + Lp = S 是定义上的恒等式，不是发现。

用途只有一个：知道带针后 S 的下降落在哪条路径上，即 E_T 对 E_C、Lp_T 对 Lp_C。E 小只说明"事实主要经 Q 重写传递"，**不说明存储受损**。

### 2.2 A2　存储信号：直接测"由事实段身份造成的缓存差异"

在后续供体身份固定（c 相同）的两个运行 (f0, c) 与 (f1, c) 之间，它们唯一的差别是 F 的身份。定义**事实段信号**：

- D_F,rec(t)：各线性层递推状态在 t 时刻的差，取 t = b（刚写完）与 t = τ（撤针时）。b 处状态用 S1 的记录器离线重建，S1 已验证误差 ≤ 10⁻⁶；τ 处直接取缓存。
- D_F,KV：F 位置上全注意力层 K、V 的差（KV 写入后不衰减、不擦除）。

每层、每头报告 ‖D_F‖、留存比 ‖D_F,rec(τ)‖ / ‖D_F,rec(b)‖，以及 T 与 C 之间 D_F 的方向余弦。

### 2.3 A3　存储中介：答案经哪类存储读到事实

在 (f0, c) 运行中，于 τ 把某类存储换成 (f1, c) 的值：两个运行只差事实身份，这是失配最小的拼接。看 E 下降多少：

- 换递推状态（全部线性层）→ 经递推存储的份额 E_rec；
- 换 F 位置的 KV → 经注意力存储的份额 E_KV。

在 C 中：干净模型靠哪类存储送达事实。在 T 中：带针后哪类存储的送达下降了。

**由架构推出的约束（推导档）**：KV 写入后既不衰减也不擦除。若 T 的损失全落在 E_KV，候选机制只剩"读取失败"与"F 写坏"，保留与擦除被排除。

### 2.4 A4　候选机制的区分对照

对每个候选组 g，做四项检验。g ∈ {R = α，K = k/β，R+K，V，Read = 答案位置的查询与门；F-写 = F 上的写缓存变量}。g 在 Q 上替换，F-写在 F 上，Read 在答案位置；供体身份都固定为 c（F-写取 a），因此不会重新注入事实。

| 检验 | 操作 | 修复原过程的预测 | 补偿的预测 |
|---|---|---|---|
| ① 恢复 | T 中把 g 换成 C 背景值 | E（或 S）恢复 | 也可能恢复 |
| ② 移植 | C 中把 g 换成 T 背景值，其余保持 C | **在同一路径上制造出与 T 相近的损失** | 不制造损失，或损失落在别的路径 |
| ③ 信号 | ① 与 ② 中测 D_F（§2.2） | ① 使 D_F 向 C 恢复，② 使 D_F 向 T 退化，且形状符合下表 | ① 中 D_F 仍退化，答案却恢复 |
| ④ 中和 | 在 ① 的恢复运行中，于 τ 把 g 对应的存储（递推或 KV）换成另一身份的值 | 恢复出来的 E 随之消失 | 恢复不依赖该存储，E 基本不变 |

**各机制在 D_F 上的预测**（由更新规则推出，推导档）。形状判据用于 **② 移植格**：那里只有 g 与 C 不同。若只有 α 不同，D_F(t) = A_t D_F(t−1) 中 k/β 部分相同，每个头只差标量倍数；若 k/β 不同，投影算子不同，方向随之改变。T 原运行里所有变量一起变化，不能直接拿 T 和 C 比形状；① 恢复格只看 D_F 是否向 C 恢复。表中"T 与 C"在移植格中读作"移植格与 C"：

| 机制 | g | D_F,rec(b) | 留存比 ‖D_F(τ)‖/‖D_F(b)‖ | T 与 C 的 D_F 逐头方向余弦 | D_F,KV |
|---|---|---|---|---|---|
| M1 保留衰减 | R | ≈ C | **低于 C** | **≈ 1**（α 对每个头整体缩放） | ≈ C |
| M2 定向擦除或覆写 | K、R+K | ≈ C | 低于 C | **明显 < 1**（沿特定 key 方向删除） | ≈ C |
| M3 后续写入干扰 | V | ≈ C | ≈ C | ≈ 1 | ≈ C |
| M4 读取失败 | Read | ≈ C | ≈ C | ≈ 1 | ≈ C |
| M5 事实段写坏 | F-写 | **低于 C 或方向偏离** | —— | —— | 可能偏离 |

一个机制只有在 ①–④ 与 D_F 形状**同时**符合时才判"支持"。只有 ① 成立而 ②、③、④ 不符，判为"补偿或冗余通道，未识别为原因"。M3 与 M4 在 D_F 上的预测相同，靠 ② 移植区分：移植 V 能否在干净背景中制造损失，移植 Read 能否制造损失。

### 2.5 零对照与可分辨性

- 一般损伤参照：在 C 的 Q 上，对五组加与 T−C 同幅的随机方向扰动（2 次），报告 E、Lp、D_F 的变化，仅作解读，不作分界。
- 区间：≥ 0.8 接近完整，0.2–0.8 部分，≤ 0.2 很少，逐情景报告。D_F 的余弦以 0.9 为"方向保持"。这些阈值事先写死，但都是描述性切点，所以同时报告连续值。
- 闸门：c = a 的格逐位等于原生；同背景 F、Q 都为 f1 时逐位等于 f1 原生；离线重建的 S_b 在 τ 处与缓存的误差 ≤ 10⁻⁶。

## 3. 实验 B：历史 × 晚段变量（停嘴）

在 01（早段干净、晚段带针，供体 00）上重做 S3 的晚段格：完备；撤除与只留 V、R、K、{R,K}、{V,R,K}；V 与 {R,K} 各配 2 次随机零对照。与 S3 在 11 上的同名格比较 N、S 与首步 EOS。

- 读法：差值的绝对值都 ≤ 0.2 且 EOS 结论相同 → "本次比较未显示历史依赖"。任一 ≥ 0.4 或 EOS 结论翻转 → "替换效果依赖早段干预造成的历史背景"。
- 两个背景不同的不只是递推旧状态，还有多层缓存、后续投影、读取条件，供体与分母也不同。所以 B **不能**据此认定旧记忆预测 m = Sᵀk 在起作用；反过来，"未显示差别"也不证明不依赖历史。
- 同时检验 S3 中"撤除 K 使停止分数更高"在 01 上是否仍然出现。

## 4. 实验 C：自由生成验证

- 生成对象：四个原生条件；S3 中只在前缀介入的关键格（晚段撤除 V、只留 V、只留 {R,K}、撤除 {V,R,K}）；B 的对应格；A4 中被判为"支持"的机制的 ① 恢复格与 ② 移植格，取 c = a（介入只在撤针前，生成时无需供体）。
- **撤针后族不做自由生成**：一旦生成文字分叉，就没有对应位置的干净供体。
- 评分：首步 EOS、交付是否为空、关键串**命中**（两候选去掉公共前后缀后的差异部分）。另由不知道条件的阅读者按事先写死的规则标注语义是否正确：正确、错误、未作答、自相矛盾。"命中"不等于答对，例如"不是 14"也命中 14。
- 首步 EOS、停止分数、交付、命中、语义正确分别报告。
