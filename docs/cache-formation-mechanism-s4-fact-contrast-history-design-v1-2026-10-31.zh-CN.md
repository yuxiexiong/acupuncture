## 1. 对 r1 两个错误前提的修正

1. **对比不能抵消一般损伤。** 差值只消掉两运行相同的加性偏移，乘性压缩（例如两事实的分数一起被压到十分之一）照样让对比下降。r2 不再用单一对比的大小判断"事实丢了"。改为在同一背景里比较两条路径：一条是早存事实经保留到达答案，一条是晚写身份经短路径到达答案。见 §2.3。
2. **下游供体会重新注入事实。** r1 的下游恢复用"与事实段同身份"的干净供体，供体本身可能把事实带回来。r2 让**事实段身份与后续供体身份独立**，且所有后续供体在事实段对比的两端**取同一身份**。这样答案对事实段身份的依赖，不可能来自后续供体的重新注入。见 §2.2。

## 2. 实验 A：事实身份的来源分离（主实验）

### 2.1 位置与身份

- 锚点 L0、L12；背景 X ∈ {C = 00, T = 10}（只有早段针；L0 事实丢失最清楚且不停嘴）。次背景 T = 11 只做核心格。开发情景 6 个，f0 与 f1 位置对齐（已核对）。
- **F**：事实段内，从第一个 f0/f1 不同的 token 到 b。**Q**：b+1..n−2（问句、指令、模板尾；撤针前）。答案位置：末提示 token 与候选。
- 事实段身份 a ∈ {f0, f1}：直接用 f_a 的提示在 F 上原生写入，不做替换。
- 后续身份 c ∈ {f0, f1}：Q 上的全部写缓存变量（S3 的五组，所有层）替换为**同一背景**下 f_c 运行的原生值。c = a 时就是原生运行，可作逐位核对。
- 读数 m：f0 正确候选与 f1 正确候选的对数似然之差（两事实的候选文字相同）。

### 2.2 2×2 身份设计与两条路径

每个背景、每种处理条件 P 下跑 4 个格 m(a, c)：

- **早存路径效应** E = ½[(m(f0,f0) − m(f1,f0)) + (m(f0,f1) − m(f1,f1))]：后续身份固定时，答案跟随事实段身份的程度。事实段身份只能经 F 上写入、且在 Q 的处理下存续的状态（递推状态的保留、F 上的 KV）到达答案。由于 Q 的供体在比较两端相同，E **不包含**后续供体重新注入的事实。
- **晚写路径效应** Lp = ½[(m(f0,f0) − m(f0,f1)) + (m(f1,f0) − m(f1,f1))]：事实段身份固定时，答案跟随后续供体身份的程度。
- **交互** I = m(f0,f0) − m(f1,f0) − m(f0,f1) + m(f1,f1)：两条路径是否可加。

**闸门**：c = a 的格必须逐位等于原生运行；同背景下，F 与 Q 两处都用 f1 时必须逐位等于 f1 原生运行。

### 2.3 怎样避免把一般压缩当成事实丢失

一般性的读出压缩，会同时压低 E 与 Lp；保留、擦除类损失主要压低 E，因为 E 依赖跨过 Q 的存续。所以"早存事实在带针背景中丢失"这一判断，要求两条同时成立：

1. E_T / E_C ≤ 0.5；
2. 相对路径比 (E/Lp)_T ≤ 0.5 × (E/Lp)_C。

只满足第 1 条时，只说"带针背景下事实对比整体变小"，不归因于存储。Lp 也经过部分处理，所以这一比较区分的是"依赖存续时长的损失"与"两路径共有的损失"，并不排除一切一般损伤。Lp_T 本身不可分辨时（< 0.2 × Lp_C），相对比较记为不可用。

另配一般损伤参照：在 C 背景的 Q 上，对五组加与 T−C 同幅的随机方向扰动（2 次），报告它造成的 E、Lp 与 E/Lp 变化，供解读，不作分界。

### 2.4 处理条件：哪类后续处理是早存事实丢失的必要条件

在 T 背景上，把 **Q 上的某一组**改为 **C 背景**中身份为 c 的供体值；其余组仍为 T 背景中身份为 c 的值。每个条件都跑完整的 2×2，计算 E。

| 条件 | Q 上取 C 背景供体的变量 | 若 E 向 E_C 恢复，指向 |
|---|---|---|
| P0 | 无（全部 T 背景） | 基线 E_T |
| P-ALL | 五组全部 | 存续失败发生在 Q 的处理里（而非 F 写入或答案读取） |
| P-R | α | 带针历史改变了**保留**，导致早存事实衰减 |
| P-K | k、β | 带针历史改变了**定向修正与寻址**，即擦除或覆写了早存关联 |
| P-V | v | 后续**写入内容**干扰了早存事实的读出 |
| P-R+K | α、k、β | 保留与擦除需要共同恢复 |
| P-KV、P-Qc | 注意力 K/V；q 通道 | 注意力通道 / 卷积携带的查询 |
| P-Read | Q 仍全部为 T；答案位置的 q、z、注意力查询与门取 C 背景中身份为 c 的值 | 早存事实还在，但读取条件读不到 |
| P-F | Q 仍为 T；F 上的五组取 C 背景中**身份为 a** 的值（与 F 自身身份一致） | 事实段在针下的写入本身参与了丢失 |

所有供体都取 c 或 a 的固定身份，比较的两端用同一套后续供体，所以 E 的恢复不能来自供体把 F 的事实重新带回。

### 2.5 读法（逐情景报告；事先写死）

恢复量 ρ_P = (E_P − E_T) / (E_C − E_T)；区间 ≥ 0.8 接近完整、0.2–0.8 部分、≤ 0.2 很少。

| 结果 | 支持 | 排除或削弱 | 仍分不开 |
|---|---|---|---|
| §2.3 两条都满足 | 带针背景下早存事实无法到达答案，且不只是整体压缩 | "只是一般辨别能力下降" | 丢失发生在哪一步 |
| ρ_P-ALL 接近完整，ρ_P-Read、ρ_P-F 很少 | 失败在 Q 位置的处理 | "答案读取条件读不到"；"事实段被写坏" | Q 上是哪一组 |
| ρ_P-R 接近完整，其余单组很少 | 保留改变是必要条件 | 擦除、后续写入作为必要条件 | α 改变是原发还是上游后果 |
| ρ_P-K 接近完整 | 定向修正与寻址改变是必要条件（擦除或覆写） | 只靠衰减 | k 中"写在哪"与"擦什么"各占多少 |
| 单组都只部分、ρ_P-R+K 接近完整 | 保留与擦除需要共同改变 | 任一单独充分 | —— |
| ρ_P-F 接近完整 | 针下写入的事实段内容是必要条件 | 纯后续处理解释 | 写入内容与 F 位置自身的处理 |
| ρ_P-Read 接近完整 | 事实仍存，读取条件改变是必要条件 | 存储丢失 | —— |

每条结论都是"在把该组替换为 C 背景值的条件下"的必要性，不是自然路径的唯一原因。供体来自 C 背景、接收方是 T 背景，这一兼容性限制在每一格都存在，报告失配诊断。

## 3. 实验 B：历史 × 晚段变量（停嘴）

在 01（早段干净、晚段带针，供体 00）上重做 S3 的晚段格：完备；撤除与只留 V、R、K、{R,K}、{V,R,K}；V 与 {R,K} 各配 2 次随机零对照。与 S3 在 11 上的同名格比较 N、S 与首步 EOS。

- 读法：差值的绝对值都 ≤ 0.2 且 EOS 结论相同 → "本次比较未显示历史依赖"。任一 ≥ 0.4 或 EOS 结论翻转 → "替换效果依赖早段干预造成的历史背景"。
- 两个背景不同的不只是递推旧状态，还有多层缓存、后续投影、读取条件，供体与分母也不同。所以 B **不能**据此认定旧记忆预测 m = Sᵀk 在起作用；反过来，"未显示差别"也不证明不依赖历史。
- 同时检验 S3 中"撤除 K 使停止分数更高"在 01 上是否仍然出现。

## 4. 实验 C：自由生成验证

- 生成对象：四个原生条件；S3 中只在前缀介入的关键格（晚段撤除 V、只留 V、只留 {R,K}、撤除 {V,R,K}）；B 的对应格；A 的 P0、P-ALL、P-R、P-K、P-F 中 c = a 的格（这些介入只在撤针前，生成时无需供体）。
- **撤针后族不做自由生成**：一旦生成文字分叉，就没有对应位置的干净供体。
- 评分：首步 EOS、交付是否为空、关键串**命中**（两候选去掉公共前后缀后的差异部分）。另由不知道条件的阅读者按事先写死的规则标注语义是否正确：正确、错误、未作答、自相矛盾。"命中"不等于答对，例如"不是 14"也命中 14。
- 首步 EOS、停止分数、交付、命中、语义正确分别报告。
