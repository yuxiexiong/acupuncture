## 1. 为什么 S3 拆不开事实使用，A 怎样避开

S3 的事实读数 S_fact 是"两事实下答案差距之差"。任何一般性损伤都会把它向 0 压缩，所以同幅随机零对照本身就能造成很大变化，替换效应和损伤分不开。

A 的读数换成**对比**：两个混合运行的背景完全相同，只在"事实段写进去的是 f0 还是 f1 的内容"上不同。一般性损伤对两个运行相同，在差值里抵消；差值只度量"事实身份能否被送到答案"。这是交换介入的标准用法，借用而非新发明。

## 2. 实验 A：事实内容对比交换（主实验）

### 2.1 对象与记号

- 锚点：L0、L12。主背景 T = **10**（只有早段针，S2 中 L0 事实丢失最清楚、且不停嘴）；次背景 T = 11（只做核心格）。C = 00。
- 情景：开发 6 个（同 S1–S3）；f0 与 f1 token 数相同、位置对齐（已核对）。
- **F**：事实段内从第一个 f0/f1 不同的 token 到 b（事实段末）的位置。事实身份只能在 F 内写入；F 之前两事实逐 token 相同。
- 分组：沿用 S3 的 V、R、K、Qc、KV，以及五组合并的 ALL；在所有层上交换（L0 针所在层自身的注意力部分在 F 上与 C 相同，交换不改变它）。
- 读数：m = ll(f0 的正确候选) − ll(f1 的正确候选)，在 f0 背景下为正。

### 2.2 核心 2×2：谁写、谁送

对每个背景 X ∈ {C, T}、事实内容来源 Y ∈ {C, T}、组 G：

> 混合运行 H(X, Y→f′, G)：跑 X 条件下的 f0 输入，在 F 上把 G 换成 Y 条件下 f′ 输入的原生值，其余照常计算。

**对比量** κ_XY(G) = m[H(X, Y→f0, G)] − m[H(X, Y→f1, G)]；与 f1 背景的镜像对比取平均。归一化 κ̂ = κ / S_C，其中 S_C 是干净运行的事实敏感度。

| 格 | 含义 |
|---|---|
| κ̂_CC(G) | 干净模型中，事实身份经 G 在 F 上的送达份额（经典交换介入） |
| κ̂_CT(G) | **针写下的** F 内容，在干净下游里还能送达多少：写坏检验 |
| κ̂_TC(G) | **干净写下的** F 内容，在带针下游里还能送达多少：下游失效检验 |
| κ̂_TT(G) | 带针运行自身经 G 的送达份额（ALL 时 = S_T / S_C，即原事实丢失程度） |

**完备性闸门**：H(C, C→f1, ALL) 必须逐位等于干净 f1 运行；H(T, T→f1, ALL) 必须逐位等于 T 的 f1 运行（F 之后各位置只经缓存读 F，F 之前两事实相同）。不过即停。

### 2.3 下游分解：送不到时，是哪种处理

在"F 已写入干净内容"的带针背景 H(T, C→f′, ALL) 上，再把 **F 之后**各位置的某一组恢复为对应干净运行的值，测对比量向 κ_CC(ALL) 恢复了多少：

| 格 | 恢复的变量（F 之后、介入层） | 对应的核心问题 |
|---|---|---|
| 后续 R | α | 已存事实的**保留与衰减**被改变 |
| 后续 K | k、β | 已存事实被**定向修正或擦除** |
| 后续 V | v | 后续**写入**覆盖了事实 |
| 后续 Qc、KV | q 通道；注意力 K/V | 后续查询条件 / 注意力通道 |
| 答案读取 | 撤针后位置的 q、z、注意力查询与门 | **读取条件** |
| 后续全部 | 以上全部 | 若仍不恢复，说明 F 之前带针的上下文本身起作用 |

恢复量 ρ_g = (κ_格 − κ_TC) / (κ_CC − κ_TC)。另配随机零对照：在**干净背景**的 F 之后，对全部五组加与 T−C 同幅的随机方向扰动，测 κ 被一般损伤压低多少。若随机损伤就把 κ 压到与 T 背景相同，"下游失效"就可能只是一般损伤，相关判断记为证据不足。

### 2.4 读法（逐情景，事先写死）

| 结果 | 结论（在本替换条件下） |
|---|---|
| κ̂_CT(ALL) ≥ 0.8，κ̂_TC(ALL) ≤ 0.5 | 事实写对了，丢在下游：**处理或读取**问题 |
| κ̂_CT(ALL) ≤ 0.5，κ̂_TC(ALL) ≥ 0.8 | 下游能送，事实被**写坏**了 |
| 两者都 ≤ 0.5 | 写入与下游都受损；看 κ̂_TT 与两者乘积是否相符，判断两段是否串联 |
| 两者都 ≥ 0.8 但 κ̂_TT 低 | 单独看任一段都不坏，只有两段同时带针才丢：**联合机制**，写入与下游必须同时改变 |
| 某组 G 的 κ̂_CC(G) ≥ 0.2 时，再比较该组的 κ̂_CT(G) / κ̂_CC(G) | 事实身份由哪组变量承载，以及这一组的内容是否被针写坏 |
| 下游分解中 ρ_R、ρ_K、ρ_V 或读取格接近完整（≥ 0.8） | 分别指向保留、擦除修正、后续覆盖、读取条件；多组都只部分时报告组合 |

最后一行就是事实那一半里"写入 vs 旧信号保留、衰减、修正"的直接答案。

## 3. 实验 B：历史 × 晚段变量（停嘴）

S3 的晚段介入都在 11 上做，早段历史带针。B 在 **01**（早段干净、晚段带针，S2 中 L0 首步 EOS 10/12）上重做同一组晚段格，供体为 00：

- 格：完备；撤除 / 只留 V、R、K、{R,K}、{V,R,K}；V 与 {R,K} 的撤除、只留各配 2 次随机零对照。
- 对照：同一格在 11（早段带针）与 01（早段干净）上的 N、S 与首步 EOS。
- 读法：|ΔN_V|、|ΔS_V| 都 ≤ 0.2 且 EOS 结论相同 → 晚段 v 的作用不依赖旧状态历史。任一 ≥ 0.4 或 EOS 结论翻转 → v 改变的作用取决于它写入时面对的旧状态，即经 m = Sᵀk 的预测与修正起作用，旧状态处理参与了停嘴机制。介于两者之间记为不确定。
- 同时检验 S3 中"撤除 K 使停嘴更强"在干净历史下是否仍然出现。

## 4. 实验 C：自由生成验证

对下列运行做贪心自由生成（≤ 128 token）：四个原生条件；S3 的关键格（晚段撤除 V、只留 V、只留 {R,K}、撤除 {V,R,K}、撤针后三格）；B 的关键格；A 中带针背景"F 写入干净内容"与"F 之后全部恢复"两格（各用自身事实内容，不做对比）。

- 行为分类（规则事先写死）：首步 EOS；交付是否为空；答案是否含正确关键串、错误关键串、两者都含或都不含。关键串取两个候选去掉公共前后缀后的差异部分，例如 14 对 16、C 架对 B 架、宋对罗。
- 首步 EOS、停止分数、交付、答对四项分别报告，不互相替代。S3 已经出现"分数偏移仍在但不再停嘴"的情况。
- 局限：一旦生成的文字分叉，就多了文本反馈路径，自由生成只作行为总效应核对，不作归因。
