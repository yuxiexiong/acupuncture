# NVW-01 作者自查

日期：2026-11-03；计划v1；规范：[experiment-design-self-check v1](experiment-design-self-check.zh-CN.md)。对象：[NVW计划](cache-native-v-write-interaction-plan-v1-2026-11-03.zh-CN.md)。同一助手设计与反方自查，不是独立评审。依据KUC计划/合同/报告/正式验收、SVQ报告、资产盘点及源码审计；本次不运行模型。

## 1. 八项设计卡

| 项 | 本轮决定 |
|---|---|
| 主线与问题 | 稀疏干预如何通过写入和历史改变回答；检验t1 W-k作用是否依赖卷积V恢复 |
| 新增认识 | KUC只在V已恢复背景检验更新项；NVW新增相同干预在V未恢复背景下的作用及同端点交互 |
| 依据与反例 | KUC写入项强、随机也强、C1343分差变但回答不翻；SVQ整体q/k修复无完整交付，但不能推出选择性W失败 |
| 操作 | 同C/T构造T/V/Q/F；G层t1影子k，仅W或完整K；固定输入与来源，下游自由响应 |
| 估计对象 | 每背景W−0、K−0以及V背景差分中的差分；是操作总效应的条件依赖，不是原生中介份额 |
| 判读 | G、M、Y分别判断；支持、部分、反向、全零及小分母都有出口；停止修复与完整交付不互换 |
| 范围成本 | 旧48输入/6场景/4方向；正式3072自然轨迹，含预检重试最多3328；总硬上限2.4 GPUh，尚未授权 |
| 退出 | 工程失败停止；科学结果无论何种均交付；不临时加E、层、剂量或新题；下一轮优先留出验证 |

## 4. 与上一设计及截图建议比较

| 保留/修改 | 原因 |
|---|---|
| 保留V×W的2×2、t1停止竞争、C路线t2 M及自然Y | 直接检验混合背景关系如何接回原生 |
| 将加入侧明确为Q↔F，而非T↔F | 后者同时改变q/k和V，不能归因V背景；Q仅恢复q/k |
| R/A/Z各保留完整t1 K参照 | 在新背景不预设W仍代表K；不要求新的臂自动复现高V结果 |
| 不追加“很便宜”的擦除项 | 这轮问背景依赖，新增E非必要；K/W不同也可形成清晰边界结论 |
| 不采用“原生救回几乎可排除” | 整体q/k修复与选择性W不是同操作；旧SVQ/FX也非同一面板 |
| 对三个读数分别计算交互 | 避免地板正确率制造内部耦合结论，避免用G成功掩盖Y失败 |
| 辅助范数同运行记录 | 不另耗模型预算，也不把向量大小当行为因果证明 |
| 延续KUC数值路线与高V8臂桥接 | 使用已有可信实现，新增工程工作集中于背景构造与交互分析 |

## 5. 实质反方检查与修正

1. **全部预期出现，但V变化同时改变了k编辑幅度，是否仍能称V×k关系？** 可以称这套固定影子干预的条件总效应；不能称固定数值Δk的纯V调制。§4已固定同算法、记录实际Δk并改用前一表述；不增加幅度扫描。
2. **T和F比较变好了，其实是q/k来源不同。** 属于硬伤，已用T/V和Q/F两对背景修正，重查C05–08。
3. **原生G改善却仍停止，或强制t2 M改善而自然没有第二步。** 只能分别解释连续首步竞争或条件目标竞争；§5–6必须同时给自然token与Y，不能汇总为“救回”。
4. **V恢复后Y作用强只是0/1阈值，而内部变化相同。** §5对G/M做同尺度I，Y交互不证明内部耦合；保持各连续结果，即使I不成立也不硬判依赖。
5. **同输入多方向让一致性看起来很高。** §2/6明确已见面板、场景汇总和方向分别报告；本轮不宣称外部确认，下一轮才检验留出。
6. **原生中完整K有效而W失败，仍沿KUC称写入主导。** §6明确撤回推广，报告该背景的W不足；不按剩余给E命名。
7. **随机与共同偏移一样，或C1343移动但答案不翻。** 这不破坏条件干预关系；§6禁止特异性结论，保留原始余量/变化与行为，不能把余量来源归V。
8. **高V臂新旧不一致，但误以为是科学新发现。** §8正式48题逐token及全词表桥接；不一致为工程/来源阻塞。新臂不要求旧行为。
9. **终点“任一变好”形成选择性汇报。** §5–6指定R/T的G为原生主要连续量，M/Y独立列完整表；不定义跨读数OR成功，不选择最有利方向。
10. **后续跨架构主张能否直接成立？** 不能；§10只输出可迁移的功能预测，保留原生背景与留出验证的阶段，不要求他模型复刻更新式。

修正后复查C01/C02/C08/C14：问题仍是写入项作用的背景依赖，新增T/Q反事实确实缺测，结果能约束原生接回，未换成停止修复工程。逻辑设计通过。
