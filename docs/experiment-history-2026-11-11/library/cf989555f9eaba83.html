0. 相对计划 v1 的修订

  1. 写明 12 条主子集的结构：两个外来供体目标都不在首列，当且仅当接收者自身目标排在首列；所以该子集就是“接收者目标在首列”的 12 条。那里首列偏好推向接收者原答案而非供体，对“转移”是保守的。测试中逐条核对。
  2. 卷积槽核对用缓存比较，不在卷积模块内挂 hook：卷积缓冲是 4 槽滑窗，每处理一个 token，新缓冲前 3 槽 = 旧缓冲后 3 槽。预检中 (a) 在 NA-NQ01-ABC-A 的干净形成逐 token 比较；(b) 在一个混合臂的首个读出步比较（另计 1 次前向）。不向前向路径加任何 hook。
  3. 本轮不登记方向性预测：H_C、H_T、U 的定向转移都可能成立或不成立，判据只作读法，不作“预期”。

1. 被替换的对象

14 个深层 G 层（13,14,16,17,18,20,21,22,24,25,26,28,29,30）的卷积缓冲 [1, 8192, 4]：q/k = 通道 [0, 4096)，V = [4096, 8192)。模型配置核长 4、宽 8192（readiness 实测）。读出前缓冲存位置 n−5…n−2 的投影，在 NA 原布局中这四个 token 是 \n、<think>、\n\n、</think>，各组内逐字相同；读出位 n−1 是 \n\n。首个读出步用旧缓冲后 3 槽与当前投影。本轮检验“读出前末端 q/k 投影历史的查询相关差异能否在固定接收背景中定向改变完整答案”，测替换的总效果。

4. 判据（冻结，qst_core.py；阈值见 design-r01.json）

4.0 无方向性预测（§0.3）

4.1 主比较

36 个有两个外来供体的接收者（NQ01/03/05/06 各 9）；b、c 按 id 固定。每个臂类型（U；每方向 H_C、H_T）：J = [y_b(b) − y_b(c) + y_c(c) − y_c(b)]/2；W = 1[供体 b 交付 b 且供体 c 交付 c]；W_rev 对称。稳定正向：四场景等权，≥3 个场景 J 均值 > 0，等权 J ≥ 1/3，等权 W ≥ 1/3；在 12 条子集（两个外来目标都非首列 = 接收者目标在首列，§0.1）上三条同时满足。反向把 J 取负、W 换 W_rev。“>0”只作一致性计数，必须与效应量门槛同时满足。

4.2 受针供体削弱（每方向）

H_C 稳定正向；H_T 不是稳定反向；全 36 条 ≥3 场景 ΔJ 均值 > 0，等权 ΔJ ≥ 1/3、ΔW ≥ 1/3；12 条子集 ΔJ、ΔW 等权均值 > 0（ΔJ = J(H_C) − J(H_T)）。

4.3 描述（不进判据）

132 配对各臂的“原题 / 供体 / 其他单编号 / 多编号 / 无编号”计数；12 个单外来供体接收者与 28 个双方非首列有向配对；同前缀诊断 z_b − z_c；改坏格。四方向各自完整报告，不设跨方向多数门槛。出口按计划 §7。
