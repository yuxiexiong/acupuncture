1. 实验目的与新增认识

中心仍是：写入改变和旧状态处理改变怎样影响后续回答。S2表明共同旧来源H被不同处理，但末态差异更多沿N来源；N同时含加性写入及随后处理，不能推出写入主导输出。 本轮主要检验三种形成分量经目标递推末态进入同一固定候选输出Q时的方向与大小：

  • 加性写入项变化的累计分量；
  • 对b时已有来源的处理变化分量；
  • 对b后新写入来源的处理变化分量。

把其余完整缓存变化保留在同一输出解释中，并用实际自由回答检查Q所反映的变化有没有任务意义。新增认识必须是具体过程如何推动、抵消或未能解释输出，而非三项都非零。允许最终判为混合、归因不可靠或现有观测下不可区分。

2. 设计先对准S2的比较，不扩为新的定位调查

保持原模型、6基础情景×2事实、两针、校准、精度、token及b/τ/t_L定义。S2的84份完整Mτ和已见首步/候选分数作为端点资产；没有新层、模型、随机针或SAE训练。

取消v2下一轮的原全前缀统一强度路径，改为两种共同前史下的后段原针强度路径：

背景 b之前 b之后至τ 两端对应S2
干净前史 无针 λ×原校准加法 λ=0为00，λ=1为01
已受干预前史 原强度针 λ×原校准加法 λ=0为10，λ=1为11

τ后撤针。各点完整原生前向，自己的KV/conv/递推自然共变；共享β/k不拆开、不补偿value，不插值或拼接缓存。这些是原针强度操作，不是独立A/B操作。比较可检验后段作用是否依赖前史；不直接归因早段针本身的10−00行为效应，后者仍作为现成约束与生成比较。不能把两条后段路径的结论冒充全程针所有形成来源。

两条路径都保留，不能按S2哪个效果大只选哪条；所有6情景保留，特别包括L12-VAR01反例。路径选取依据已见S2结果，因此为后续解释设计，不是独立未见样本确认。

3. 把N拆清楚再接同一个输出，不能把它重命名为纯写入

对相邻λ轨迹，从共同b起点计算H/N。Δ和横线仍为两条真实轨迹差与均值，沿b后前缀递推：

Z_B,b = Z_H,b = Z_N,b = 0
Z_B,t = Ā_t Z_B,t−1 + ΔB_t
Z_H,t = Ā_t Z_H,t−1 + ΔA_t H̄_t−1
Z_N,t = Ā_t Z_N,t−1 + ΔA_t N̄_t−1
ΔS_t = Z_B,t + Z_H,t + Z_N,t

其中Z_H=ΔH，Z_B+Z_N=ΔN；这些关系是数学验收，不是发现。Z_B是加性写入差异经后续算子传播，Z_N是算子变化作用于后来写入来源的累计账，不是“新状态处理独立效应”。分量不送回模型。沿用S2的C/T背景敏感性复算；数值/方向明显依赖约定，直接报告，不选择有利账目。

主要输出F=Q：按原输入事实定义的正确候选总loglikelihood减另一候选，保留原共同前缀与逐token评分；两事实另按原定义组成S_fact。F从完整Mτ开始，末提示和候选后续更新正常响应。首步EOS/固定logit差继续作为并列观察，本轮不额外承诺对停止机制完成过程归因。

τ完整缓存分组沿用S=L16–18递推、O_KV、O_conv、O_R及实际需要的O_extra。别名去重，管理状态/位置/mask合法一致，不能漏掉影响输出的状态。只把τ缓存作叶节点，不反传训练或把每层每时刻的全导数重复相加。

在真实M_j上求F对各缓存的读取梯度G_j，用相邻梯形近似计算：

C_B = Σ_j <Ḡ_S,j, Z_B,j>
C_H = Σ_j <Ḡ_S,j, Z_H,j>
C_N = Σ_j <Ḡ_S,j, Z_N,j>
C_Og = Σ_j <Ḡ_Og,j, ΔO_g,j>
ΔQ_hat = C_B + C_H + C_N + Σ_g C_Og

这检验的是指定路径、分解及τ通道下的计算解释。前缀中目标层已影响其他缓存的后果进入O；O不能叫“与写入/处理无关”。梯度含τ后状态引起的后续直接/间接作用，不能据此把两者独立分开。H/N只标计算来源，不标语义事实知识。

4. 主要检验：预测输出变化，而非检出非零

原生路径固定λ=0、0.5、1作为粗网格，0.25、0.75作为预定细化点；共5点，失败不自动增加到9点。先保存0/0.5/1的F与梯度；两个细化点的F在数值预测写入不可覆盖文件后再打开，不拿它们调公式或阈值。

细化点预测采用预定规则：0→0.25的小段用0.75G_0+0.25G_0.5；0.5→0.75用0.75G_0.5+0.25G_1，分别与对应真实小段的形成分量/其余状态差内积，加已知左端F。随后再计算细化点梯度，核验逐段和全路径归因。新点的形成量已经用于预测，因此这是给定形成变化的输出预测检验，不是预测未见状态、输入泛化或独立自然机制确认。

每个细化位置保留四个不重新拟合的预测：完整三项+O；省略C_B；省略C_H；省略C_N。省略只是检查该项对这套计算预测的必要程度，不是把该过程从模型中删除。不能把省略预测错误直接命名为过程对行为具有因果必要性。

结果 本轮新增认识 不允许的升级
完整预测可靠，省略C_B后误差超界，而省略C_H/C_N仍可预测 在本条路径和目标末态通道，加性写入形成分量是解释该Q变化所需的主要候选 写入是唯一原发原因，或处理没有作用
完整预测可靠，省略C_N后失准 N来源占优中，对后来写入信号的处理变化不能忽略；“N占优=纯写入”被定量反例限制 获得了独立处理门的因果效应
C_H在状态投影小，但省略它导致Q预测失准 旧来源变化对当前指定输出敏感，状态投影大小不是输出重要性代理 所有旧记忆都重要，或已解释全部回答
两项相反，任意省略都预测错误 此计算解释需要抵消项共同解释实际Q；报告绝对量、方向及残差 将一项直接命名为损伤、另一项修复
O承担明显输出响应，目标S三项不足 目标递推末态局部解释不完整，保留缺口 O与之前的写入/处理无关，或随即扩层就算本轮成功
不同省略式都能预测，或分项不稳 在预定精度/路径下未区分两类过程的输出作用 “都检出非零所以机制成立”
完整预测或梯度验收失败 当前归因方法不能可靠连接过程到输出 改精度、挑点或事后解释到看似闭合

不以任意新的贡献占比切点给机制分类，也不把仅数值可分辨当重要效应。保留全部连续误差、方向与情景反例；配对同一个Q终点，不将不同指标上的成功拼成一条因果链。

5. 数值关口与成本：仍未验收，先有界检查

BF16阶梯、cast导数与缓存原地操作必须处理。沿用v2有限差分/函数化读取/精度代理的验收要求；FP32代理须明确标注，并验证实际Q偏差，不能无条件解释原BF16程序。

工程检查固定VAR01-f0五个完整状态：C、两针各干净前史λ=0.5、两针各受干预前史λ=1。每状态最多8组读取评估（每组两候选），总计40组。先核验原/函数化输出、副作用及固定方向差分；其中两个λ=0.5是新前缀，计入下方预算。方向/步长与误差规则在看新点输出前写入实施合同；不通过即不铺开科学面板。

近似标准保留计算精度含义：逐小段残差绝对值总和≤max(10×工程误差界, 0.05×真实小段变化绝对值总和)；2/4小段的分组归因差异≤分组绝对量总和5%。细化点的盲读数预测也按预先冻结的同单位误差规则判定，不能事后放宽。总量闭合不是分项真实性充分条件；有背景/符号不稳则降为不可定量区分。

全6情景、两针、两前史背景：144条新中间前缀（12×2×2×3），每条一次末提示、两候选；原84端点完整状态复用，共228唯一状态。F=Q每状态两候选图，最多456个基本读取前向/反向图；工程重复读取另计，不在本轮额外给EOS做梯度。实现若需图重算先列实际成本，不以隐藏重算超预算；不反传整个原前缀。

与v2不同：原168个全前缀中间点不再运行；新路径在两个前史背景上测后段作用，图数按单一Q终点计。已有Mτ在服务器且有哈希，不等于本地已可读；读取身份、梯度内存与实际成本未核验前，不能声称GPU-ready，也不自动跑满上限。

这种转译失败意味着原评分/局部机制不能解释所声称的任务现象；转译成功也只是过程解释与时序行为相容。文字分叉后的内部状态不再按相同输入配对。不屏蔽EOS、强制首token或延长生成救结论。

7. 三阶段结束时究竟能交付什么

可以争取交付：在固定模型/两针/旧情景下，实际形成轨迹、可反驳的形成预测、经指定末态通道到Q的有误差核验的过程解释，以及候选变化与实际回答是否一致。每一环分别结案，不把任何一环失败藏在总叙述里。

不能预先保证：写入与处理谁先引起谁、各自可独立施加的自然行为效应、整模型全部路径、所有回答现象或跨模型普遍机制。即使三模块均通过，最强结论仍是指定干预路径下的定量计算解释与行为一致性，不是完整独立因果识别。

本阶段若只能报告更多共变或归因不可靠，结案就是该识别目标未达到；不得因这是第三阶段而强行宣布完整回答，也不自动加第四阶段。此科学上限属于当前方法的限制，不能通过缩小中心问题或重新命名来掩盖。
