# KVC-01 合同 r01：在固定恢复背景中改变补入前段 KV 的供体事实

2026-11-05。依据：[设计稿 v2](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-mechanism-r3-kvpre-content-plan-v1-2026-11-05.zh-CN.md)及 11-05 评审。用户授权（2026-11-05）："同意，改成 v2 后直接推进到实验结束再汇报"。探索性，面板已接触过，作者执行，未经独立评审。

## 0. 要回答什么

在固定的接收背景中，改变补入前段 KV 的供体事实身份，能否定向改变完整答案？这种响应在三根针及干净背景之间是否不同？

本卡是连接"状态恢复"与"答案选择"的一步桥接，不检验原有的 v/k—写入—递推—读取链是否在新条件下复现。

## 1. 固定条件

模型、引擎、模板、停止集合、贪心解码、切点 τ、事实任务的形成实现（单次前缀前向加掩码）、生成（≤ 128 token）与候选打分，全部同 WIN-01/02。

## 2. 输入与针

- **输入**：阶段二两面板中位置对齐的 22 对事实题（WIN-01 prep：两版只在事实词处 1–2 个 token 不同，n、b 相同），两版各作一次接收者，共 44 个接收者、22 个情景。
- **针**（全部全前缀 W_all，剂量与校准同 WIN-01/02）：L3/C7666/−1（代表）、L0/N4146/−1、R0_L00/−1。

## 3. 格（v 为接收版本，o 为另一版本）

| 格 | 背景 | 递推 | 位置 0..b 的 KV | 其余 KV、卷积 |
|---|---|---|---|---|
| M_same | T(v) | C(v) | C(v) | T(v) |
| M_other | T(v) | C(v) | C(o) | T(v) |
| B_pre | C(v) | C(v) | C(o) | C(v) |
| C | C(v) | — | — | — |

C 与 M_same 逐位桥接旧记录（阶段二 CCC；WIN-01 N4146、WIN-02 L3/R0 的 R_all＋KV_pre）。每对 16 条生成，共 352 条。

## 4. 读数

- 事实盲读，流程同 WIN-02；读者说明沿用 WIN-02（含截断规则）。
- C 与 M_same 的回答与旧记录逐位相同，沿用旧标签（按来源：C 与 N4146 取 WIN-01，L3/R0 取 WIN-02）。
- 其余回答新读；同题同文本共用一个标签，但 WIN-01 与 WIN-02 标签冲突的文本一律新读（DECISIONS D3）。
- 每个回答归三类：
  - R（接收者事实，follows_fact）；
  - D（供体事实，other_fact）；
  - O（其他）。

## 5. 判据（数据前写死，经 6.2 合成演示）

场景分层 bootstrap 2000 次，种子 20261103，单位为接收者，22 个情景等权。

**M_other（每针）**，零点 D0 ＝ M_same 中 D 的比例：
- **定向转移**：D 比例区间下界 ≥ D0 ＋ 0.20；
- **恢复保留但未跟随**：D 比例上界 ≤ D0 ＋ 0.10，且 R 比例相对 M_same 的配对差区间下界 ≥ −0.10；
- **恢复减弱且未跟随**：D 比例上界 ≤ D0 ＋ 0.10，且 R 配对差区间上界 ≤ −0.20；
- **不可判**：其余。

**B_pre**，零点为同一批接收者 C 的 D 比例：
- **转移**：下界 ≥ 零点 ＋ 0.20；
- **未转移**：上界 ≤ 零点 ＋ 0.10；
- 其余为**不可判**。

**条件间差异**（同一批接收者"是否跟随供体"的配对差；比较 L3 对 N4146、L3 对 R0、N4146 对 R0，以及每针 M_other 对 B_pre）：
- **响应不同**：区间不含 0 且 |差| ≥ 0.20；
- **未检出差异**：区间在 ±0.10 内；
- 其余为**不可判**。

不凭"一组过阈值、另一组没过"宣布差异。

## 6. 预测（数据前登记，推测）

M_other 三针都判"定向转移"；B_pre 判"转移"。失败照实记为科学失败。

## 7. 读法限定（设计稿 v2 §5）

- **定向转移**：只说前段 KV 在该背景中具有与事实相关的答案影响；不说答案只由它携带，也不说它不恢复作答条件。
- **恢复保留但未跟随**：只说恢复与供体事实跟随可以分离；不说内容来自别处、路径不同。
- **恢复减弱且未跟随**：只说跨版本替换后恢复减弱且未转移；"不兼容"等只是候选解释。
- **B_pre 未转移**：只说前段单独替换不足、全部 KV 替换有效；不说载体在后段，不自动追加实验。
- **条件间响应不同**：只说响应不同，不说机制分叉。
- 结论只限这三根针、这 44 个接收者。

## 8. 工程闸门（任一失败即停，报告用户）

1. **桥接**：C 等于阶段二 CCC；M_same 等于 WIN-01/02 的 R_all＋KV_pre 记录。比对内容为生成 token、t1 logits sha、候选对数似然。
2. **结构**：
   - 两版 C 在位置 0..（第一个不同 token − 1）的 KV 逐位相同，且记录句部分存在差异；
   - M_other 与 M_same 只在 KV 的位置 [第一个不同 token, b] 上不同；
   - 第 0..L 层缓存等于 C。
3. **替换**：目标等于供体，其余逐位等于接收者；接收者、供体前后不变；预检自换不变。
4. **写入审计**：误差 ≤ 1%，掩码位置数为 n−1。

## 9. 预算与停止

- 预检：RD01 一对，单卡，上限 0.3 GPUh。
- 正式：双卡，上限 2 GPUh，存储 4 GiB。
- 工程闸门失败＝合同执行失败，停止并报告；预检允许一次有记录的修复，正式不修不重试。
- 结果弱或不可判时，不加针、不改剂量、不换题。
