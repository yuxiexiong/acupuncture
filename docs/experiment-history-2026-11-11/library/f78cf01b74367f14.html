NMT-01 实验卡：状态增量的幅度分布能否复现其作用

2026-11-03。设计稿，未冻结、未实现、未运行，无 GPU 授权。 依据：SIT-01 报告、下半场 Proposal v2 第一段、2026-11-03 讨论定稿。档位：推导＝有论证链；类比＝相邻证据支持；推测＝待验证。

1. 问题

固定接收背景，把原生来源的状态增量逐层逐头放大到恢复来源的大小，能否复现后者的作用？反过来，把恢复来源的增量缩小到原生来源的大小，作用是否随之减弱？

  • 测的是逐层逐头的幅度分布，不是一个总范数。总范数另设一个次要臂（§3.3）。
  • 双向两个端点不能证明"效应随幅度单调变化"。单调性不在本卡范围。
  • 本卡把"状态增量能改变回答"推进到"增量的什么性质使它有效"，并为跨条件比较选出有依据的变量。

2. 已知事实（数据前）

  • SIT（48 条已见面板）：三个缺口方向的 A0 = +0.76 / +0.53 / +0.55，A1 = +1.55 / +0.74 / +0.76，全部 6/6 场景同号；A1 − A0 = +0.79 / +0.21 / +0.21（接收背景有作用）。
  • 增量交互 ‖I_S(1)‖/‖I_S(0)‖ 的逐输入中位数：第 13–18 层约 1，第 20–30 层 1.5–3.2；余弦在第 13–18 层 ≥ 0.90，第 20–30 层 0.65–0.91（SIT increment_stats）。
  • 第 13 层两个来源的增量逐位相同（结构性）。
  • 留存增量是秩一结构：ΔS(s,b) = β·k_b·(v1−v0)ᵀ，NVB 恒等式误差 ≤1e−5（推导）。
  • C1343 的模式与缺口方向不同（G = −0.36），单列。

3. 操作

沿用 SIT 记号：接收者 r∈{0,1}（原生 / 恢复输出背景），增量来源 s，b∈{0,1}（写入键 k0/k1）；ΔS(s,b) = S(s,1,b) − S(s,0,b)，按层 l、头 h 分块，块的 Frobenius 范数记 n_s(l,h,b)。所有新格都在 t1 结束后、t2 之前，一次性把接收格 B(r,0,b) 的 14 个 G 层递推状态改成 S(r,0,b) + X，X 是下表中的某种增量；其余缓存、t1 logits 和 token 都来自接收者，t2 起不挂钩子。和 SIT 一样先用 FP64 求和，再一次 cast 回 float32。

3.1 主臂（8 格 / 输入 / 方向）

代号 X 的定义（逐 l,h,b） 接收者 对照的目标格
UP ΔS(0,b) × n_1/n_0 ：原生方向、恢复幅度 r=0、r=1 F(r,1,b)：恢复来源原样
DN ΔS(1,b) × n_0/n_1 ：恢复方向、原生幅度 r=0、r=1 F(r,0,b)：原生来源原样

每个臂 × 2 个接收者 × 2 个 b = 8 格。

3.2 方向对照（次要，只在 r=0、只走 C 路线）

RND_j（j=0…4）：X = n_1(l,h,b) · û(l,h,b) ρ̂_jᵀ，其中 û 是 ΔS(0,b) 块的首个左奇异向量（写入键方向），ρ̂_j 是固定种子的单位高斯方向（逐层逐头，b=0/1 共用）。含义是"写入位置和恢复幅度保留，写入内容随机"，构造方式与 NVB 随机族一致。它用来区分两种情况："原生方向配上恢复幅度就够"，还是"任何内容配上恢复幅度都够"。K=5 只作描述，不做秩检验。

3.3 总范数对照（次要，只在 r=0）

UPG：X = ΔS(0,b) × N_1(b)/N_0(b)，N_s(b) 为全部 14 层 ΔS(s,b) 的总范数，所有层头共用一个缩放系数。它把"总量够大"和"分布对"分开。

3.4 保护与边界

  • 若某块 n_0 或 n_1 < 1e−12 × 该层中位数，不缩放、保留原块，并计数报告。
  • 第 13 层两来源相同，缩放系数恰为 1，UP/DN 在第 13 层与原块逐位相同（闸门）。
  • 逐 b 分别匹配，这样每个被移植的对象都与对应的那份增量等幅。产生的 ‖I_S‖ 是否也随之匹配，作为描述量报告（I_S 是两块之差，范数不一定被匹配）。

4. 读数与估计对象

C 路线 M（目标第二 token 减竞争者）为主读数；主子集为目标不在首列的 32 条，六场景等权；全 48 条与首列 16 条作补充。N 路线完整回答 Y 分开报告，r=0 一侧 t1 几乎全停，Y 只读 r=1。

沿用 SIT 的 H(r, X) = [F(r,X,1) − Z(r,1)] − [F(r,X,0) − Z(r,0)]。在每个接收者 r 上，来源差 Δ_src(r) = H(r,1) − H(r,0)（r=0 时等于 A0，r=1 时等于 A1）。

  • Φ_up(r) = [H(r,UP) − H(r,0)] / Δ_src(r)：把原生增量放大后，补回了多少来源差。
  • Φ_dn(r) = [H(r,1) − H(r,DN)] / Δ_src(r)：把恢复增量缩小后，丢掉了多少来源差。
  • 次要：Φ_rnd(0)（RND_j 的均值与范围）、Φ_upg(0)。
  • 比例只在场景等权 Δ_src(r) ≥ 0.5 时计算（三个缺口方向都满足；C1343 不计）。

逐输入算，再六场景等权；报告场景均值与正负数、逐输入正负数、场景分层 bootstrap 区间（2000 次，固定种子）。同时报告每个 b 的直接效应，避免交互掩盖主效应。

一阶参照（冻结前离线计算并登记，带条件）：NBR 已存每头读出向量 XA（ΔS_a 在接收背景读者下的直接读出）、梯度 g，以及每头范数 nSa{c}_b{b}。按缩放系数加权求和，就得到 UP、DN 的单点一阶预测。计算条件和 SIT §4.3 相同：直接读出项、单一线性化点、q 不响应。已知同一构造在 SIT 上多数低估实测，所以它只作参照，不作判据。

5. 结果 → 下一步（冻结的读法）

阈值是人为选定、冻结后不改的读法分档，不是显著性检验。每个缺口方向、每个接收者分别判，然后看三个方向是否一致（≥2/3）。

读法 条件 下一步
幅度复现 Φ_up ≥ 0.75 且 Φ_dn ≥ 0.75，两者 bootstrap 下界 ≥ 0.5 检验这一幅度关系能否迁移到其他条件（其他针、层、任务），连接更宽的机制
幅度不足 Φ_up ≤ 0.5 或 Φ_dn ≤ 0.5，且对应上界 < 0.75 保留方向、结构、接收背景几个候选，选能区分它们的下一步；不自动展开 β/k/v 全拆
单侧 一个 ≥ 0.75、另一个 ≤ 0.5 两侧机制不对称（例如放大够用但缩小不失效），照实保留；下一步针对不对称的那一侧
背景依赖 同一 Φ 在 r=0 与 r=1 之差 ≥ 0.3，且差的 bootstrap 区间不含 0 背景依赖本身作为结果保留，不强行归给幅度或方向单独决定
其余 — 部分 / 不可判，报告连续值，不升级任何结论

次要臂的读法（只描述，不改变主读法）： - Φ_rnd 也接近 Φ_up：写入位置配上恢复幅度就足够，内容方向不重要（仅限 r=0 和这 5 次抽样）。 - Φ_rnd 明显低于 Φ_up：原生方向本身有作用。 - Φ_upg 接近 Φ_up：总量就能代表；明显更低：分布有作用。

措辞限制： - "幅度复现"只说明在该接收背景、该操作范围内，幅度分布足以复现，不推出所有方向等效，也不推出单调性； - 不把结果升级为整条线的中心命题； - 剩余差异不归因给未操作的部件。

6. 工程验收（运行中断言，任一失败即停）

  • 来源：NVB 八格 t1/C t2 与 NVB 正式记录逐位一致；SIT 四个交叉格的 C t2 与 SIT 正式记录逐位一致。
  • 缩放：每块 ‖X‖ 与目标范数的相对误差 ≤ 1e−6（FP64）；UP/DN 与源块余弦 = 1（误差 ≤ 1e−6）；第 13 层 UP/DN 与原块逐位相同；RND 的范数匹配误差 ≤ 1e−6，b=0/1 方向相同。
  • 移植：只有 G 层 S 改变，其余缓存逐位等于接收者；cast 误差 ≤ 1e−6；源状态、t1 缓存不被修改。
  • 6.2 离线演示：在合成数据上分别构造"幅度复现、幅度不足、单侧、背景依赖"四种情形，每种读法都要演示能被满足、也能不被满足；冻结前在真实模型上用一个预检输入跑完整闸门，看到 PASS（不写 M/Y）。

9. 自查（作者自查，非独立评审）

  1. 这是不是又回到局部深挖？ 本卡的出口直接决定跨条件比较用什么变量（幅度分布、总量，还是方向），不是为补全案例链。"幅度不足"时也不自动展开 β/k/v。
  2. 逐 b 匹配会不会混淆 k 交互？ 会改变 I_S 的范数，所以把 ‖I_S‖ 的匹配程度作为描述量报告，并在读法里只谈"被移植对象的幅度分布"。
  3. 随机内容只有 5 次。 只作描述，不作零分布，不进主读法。
  4. 已见面板、混合反事实、有限幅度。 结论只限这些条件，与 SIT 相同。
  5. 双向端点不证明单调性。 已写进 §1 和 §5 的措辞限制。
  6. 阈值 0.75 / 0.5 / 0.3 是人为的。 冻结后不改；附近值同时报告未舍入数。
  7. 两种接收背景结论不同时，按"背景依赖"如实报告，不合并。
