CFM-VQ-WRITE-L13-v1（阶段 B1）实验合同 r01

日期：2026-11-01。设计：方案 v1 r2；合同与方案冲突以方案为准，偏离记入 DECISIONS。运行授权：用户 2026-11-01 指令“如果没有大问题就小修后直接写合同代码测试上卡实验”。

1. 对象与来源

Qwen3.5-4B 851bf6e8，BF16、eager；12 输入（6 已见情景 × 2 事实），第13层为数据知情选点。缓存从 BRIDGE formal-r01 的 τ 缓存重建（CONV-FACTOR 的 build，浅层 C，深层 S=T、全注意力 KV=T、14 个 G 层 F 全部为 T）。I13 由 CONV-FACTOR formal-r01 的第13层四角驱动计算（M_T：M:TCC/TCT/TTC/TTT；N：N:CC/CT/TC/TT），全部按收据 sha256 校验。

2. 操作

每输入每背景 4 格，全在 TT 基底：R（无补丁）、DEL（第13层 recurrent 内核 core 输出边减 I13）、RAND0/RAND1（减逐头范数匹配 I13 的随机向量，种子 int(sha256('CFM-VQ-WRITE-L13-v1|item|j')[:16],16)，CPU FP32 正态、FP64 逐头单位化）。补丁：FP64 减法、一次转 BF16；s_new 原样返回；下游正常。N 背景第13层入口替换为归档 T_native 的 x_T。

预检（VAR03-f0、VRL04-f0）每背景另加：零补丁、FP64 减后加回；每输入另加 M_T、N 记录器关闭参考各 1 次。

4. 工程闸门（任一不过 → 中止，记合同执行失败）

  1. 来源：BRIDGE、CONV-FACTOR 记录与张量 sha256；提示 token 哈希三方一致；a_i 与 CONV 一致；停止集 {248044, 248046}。
  2. 代数（每输入每背景）：四角 g/β/z 相同、q/k 只随 Q 变、v 只随 V 变；四角 I13 与乘积式残差 ≤ 1e−12 + 1e−10‖I13‖；读取项交互同标准；四角 core 重构误差 ≤ 1.05×BF16 底噪。
  3. 落地精度（方案 §7.4 r2）：DEL 与两条 RAND 各自整体相对误差 ≤ 5%；每头实际误差 ≤ 1.05×该头 BF16 底噪；目标 < 20×底噪的头能量合计 ≤ 2%；零头不改。GPU 实际补丁后的 core 哈希必须等于 CPU 核验过的 core。
  4. 重放：R 的 logits 与 CONV 对应 TT（M:TTT / N:TT）逐位一致，14 个 G 层驱动逐位一致；N 每格第13层入口等于 x_T。
  5. 命中：每格 14 个 G 层 recurrent 内核各 1 次、chunk 0 次、第13层补丁 1 次、N 入口 1 次；DEL/RAND 的补丁前 core、第13层入口、s_new 与 R 相同。
  6. 预检：零补丁、加回、记录器关闭三类与 R 逐位一致。
  7. 冻结：freeze 清单哈希在授权、运行、验证时一致。

5. 估计量与判据（冻结，方案 §5–6）

对 Z∈{cz_s46, cz_a}（全词表去均值；a 为冻结干净候选），旧三角来自 CONV：I = Z_TT − Z_TC − Z_CT + Z_CC；I′ = Z_DEL − Z_TC − Z_CT + Z_CC；δ = Z_TT − Z_DEL；ρ = δ/I（|I| ≥ 1 才算）；κ = |1−ρ|。情景：两事实各量先取均值再作比；|mean I| ≥ 1 且两事实 I 同号才显示比例。

逐情景“支持传递”：比例可判、κ ≤ 0.75、两事实 δ 与 I 同号；且 E_i = sign(I_i)δ_i 都 > 0、mean(E_i) > max_j mean|δ_rand,j| + 0.1。≥5/6 情景支持才称“稳定支持”。N·cz_s46 为预定主判断；M_T·cz_s46、N·cz_a、M_T·cz_a 完整报告，不合并择优。逐情景标签：比例不可判 / 变化很小（|ρ| ≤ 0.1 且 |δ| ≤ 0.1）/ 减弱（0 ≤ ρ ≤ 1）/ 过冲但幅度减小（1 < ρ < 2）/ 等幅反号（ρ = 2）/ 反向或放大（ρ < 0 或 ρ > 2）。
