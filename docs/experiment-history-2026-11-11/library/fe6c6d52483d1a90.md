# NCC-01 合同 r01：L0/L12 原生首步与完整回答的深层缓存恢复比较

依据：[NCC-01 方案](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-native-carrier-comparison-v1-2026-11-03/PLAN.zh-CN.md)与[自查](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-native-carrier-comparison-v1-2026-11-03/SELF_CHECK.zh-CN.md)（main `97156673`），以及 2026-11-03 评审商定的四处修正（§0）。授权：2026-11-03 用户原话“同意你的意见，你直接推进吧。实验跑完再跟我说”。冻结后不改本文件；偏离记入 `DEVIATIONS.zh-CN.md`，合同未覆盖的判断记入 `DECISIONS.zh-CN.md`。

## 0. 相对方案的修正（评审商定）

1. **TJ 改为“全部深层缓存恢复”**：G 层的整个卷积缓冲（q/k/V）、G 层的递推 S、深层全注意力层的 KV，都来自 C；浅层 0–12 仍为 T。不另加 TQK 格。TJ 比单组多出的效果**不能叫“三组协同”**，因为其中还包含新增的卷积 q/k 恢复。
2. **完整回答 Y 是主读数**；首步分差 B 只描述首步前缀竞争。首 token 分为编号开头、引导语、停止、其他四类。“共享首 token 命中 6/48、完整答对 31/48”只说明共享首 token 不是回答正确性的可靠代理，不能据此认定 L12 主要只改变写法：仍有 17 条完整回答错误需要解释。
3. **浅层与当前输入仍受干预**：全部深层历史换成 C，也不保证得到 C 的回答。TJ 未恢复时，不能直接认定剩余全由入口造成；混合状态和后续响应也可能参与。
4. **逐针、逐臂的工作预测只写方向，不编造量级**（§5.3）。“V 历史”指 G 层卷积缓冲里**有限卷积窗口内**的值，不是长历史。

## 1. 问题

在同一批输入、同一时刻、同一替换协议下，恢复深层卷积 V 历史、递推 S、注意力 KV 或全部深层缓存，各自怎样改变 L0 与 L12 两种既有干预的原生首步和自然完整回答？两种条件的恢复响应有何共性与差异？

## 2. 范围

- 模型：Qwen3.5-4B，revision `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`；BF16、eager、batch 1、torch 原核。
- 输入：LVK 新面板全部 48 条（已见开发面板），六场景。
- 两个针：L0/N4146/−1（沿用 LVK/NVB 形成）与 L12/C3621/−1（沿用 CGV G1 形成）。两者均为 NQ 校准尺度、NA 布局 B1 窗口 [b+1, n−2]、a=1.0；不重估、不重新校准。
- 两针的物理剂量和上游传播长度不同。本轮比较的是两个既有干预条件，不把差异归因于“只改了层号”。

## 3. 操作

- **切点 τ**：处理最后一个提示 token 之前的缓存快照（`form_new` 返回的 C 与 T），由该 token 的前向产生第一个回答 token。
- **接收者与供体**：接收者为该针正常形成的 T（经 `edited_arm(T,T,T)`，并由 `check_bg` 核对与 T 逐位相同）；供体为同一输入的无针 C。
- **替换**：在 τ 一次性复制下表中的目标张量，其余缓存（浅层 0–12、未替换的深层张量、位置管理）全部保持 T。随后正常处理最后一个提示 token，贪心生成到停止或共 32 个 token。不加针、不挂钩子、不强制任何前缀。

| 格 | 来自 C 的内容 |
|---|---|
| T | 无（原生受干预端点） |
| TV | G 层卷积缓冲的 V 通道 [V_LO:]（全部已存槽位 = 有限卷积窗口），q/k 通道保持 T |
| TS | G 层全部 recurrent_states |
| TK | 深层全注意力层 {15,19,23,27,31} 的 keys/values |
| TJ | G 层整个卷积缓冲（q/k/V）＋ G 层 S ＋ 深层 KV |

G = {13,14,16,17,18,20,21,22,24,25,26,28,29,30}；V_LO = 4096（= 2 × key_dim，运行时断言）。每条输入共 11 条自然轨迹：C 一条，两针各 T/TV/TS/TK/TJ 五条。

**TV 是已知参照**：TV 与先前的“V 背景”是同一操作（bV = `edited_arm(T,T,C)`）。L0 的 TV 必须逐位等于 LVK 新面板的 V 臂，L12 的 TV 必须逐位等于 CGV 的 L10（CGV 已断言 L10 = t1(bV)）。两针 TV 的结果在本轮之前已经确定，不算新发现。新信息集中在 TS、TK、TJ 以及两针之间的对应关系。

## 4. 读数

- **主读数**：自然完整回答 Y（CGV/LVK 冻结解析器 `y_full`），全 48 条。每格报告正确数；相对 T 的改对、改坏、净变化及涉及场景数；相对 C 的剩余差距；场景等权比例。C 正确子集只作附加描述。
- **首步描述**：f_i 为账本冻结的共享首 token（`q_shared`）。B_i = z₁[f_i] − max_{j≠f_i} z₁[j]（全词表）。同时保留 z₁[f_i]、最高停止 logit、最高非停止竞争 logit（j≠f_i 且不在停止集合）、赢家、首 token 是否为 f_i、首步停止。
- **首 token 分类**：首 token 为 f_i 记“编号开头”；首 token 为停止记“停止”；非停止、非 f_i，且自然输出之后出现任一列出的编号，记“引导语”；其余记“其他”。
- **汇总**：ΔB_X = B_X − B_T，ΔY_X = Y_X − Y_T，逐输入求差后六场景等权；场景分层 bootstrap（2000 次，种子 20261103，所有格与两针共用同一组重抽索引）给出描述性 95% 区间；报告每场景符号。
- **两针比较**：用同输入的配对差（L0 的效应减 L12 的效应），不据此消除剂量、形成历史和基线差异。
- 不算机制比例，不对小分母相除，不按停止分组删题，不设“成立/失效”总标签。

## 5. 解释边界与预测

### 5.1 解释表（不是自动选下一轮的阈值）

| 观察 | 能得出的认识 | 对后续的约束 |
|---|---|---|
| 两针同一组恢复首步且改善完整回答 | 两个条件共享这一缓存替换的行为敏感性 | 后续有理由检验共同的更新/读取计算；不直接宣布同一机制 |
| 两针单组效应的排序、符号或改对/改坏明显不同 | 共同缓存解释受条件约束 | 保留具体差异，先对齐条件再定位分叉 |
| 单组有限、TJ 更强 | 本接收背景下全部深层恢复带来更多改善 | 差额不分配给某组，也不称三组协同（含卷积 q/k）；不自动扩成八格 |
| 首步前缀恢复、完整回答未恢复 | 开头改善不足以解释交付 | 下一问题转向自然轨迹中的后续错误 |
| 三个单组与 TJ 都弱或反向 | 本切点和来源下这组恢复操作不足 | 结束本轮；不把剩余原因直接命名为浅层、入口或方向 |
| C/T 没有答案差但连续量有差 | 没有可修复的完整答案缺口 | 保留结果，不换针加剂量制造缺口 |

### 5.2 措辞限制

任何阳性都是混合缓存干预的总效果，可能涉及补偿、事实重引入和后续共同响应。恢复足够不等于该缓存是唯一损伤来源；本轮不做必要性或因果份额主张。

### 5.3 工作预测（数据前登记，只写方向；不是预定结论）

- **TV**：两针都是已知参照（§3），不作预测。
- **TS、TK**（两针）：单独恢复效果较弱。依据：NR-01、SK-01 中单因素恢复多数回退有限。L0 的依据来自旧面板，本面板需实测。
- **TJ**（两针）：改善不弱于 TV。由于入口和浅层仍是 T，不预测达到 C。
- **两针共性**：若存在共同的深层承载，两针的单组排序应相近（含 V 的格高于 S、K）。这是待检验的工作假设。

## 6. 工程闸门（运行中断言，任一失败即停）

1. **来源**：C 的形成 hash 等于 LVK 与 CGV；L0 的 T 等于 LVK；L12 的 T 等于 CGV。C 的 t1 bf16 logits 与自然 token 等于 CGV G1 的 C。
2. **端点桥接**：T 的 t1 bf16 logits 与自然 token 等于 NVB 的 B000（L0）或 CGV 的 L00（L12）；TV 等于 LVK 的 V 臂（L0）或 CGV 的 L10（L12）。
3. **替换**：目标张量等于供体（V 只换 [V_LO:]，q/k 保持接收者）；其他所有张量和缓存簿记逐位等于接收者；形状和 dtype 一致；供体和接收者前后 hash 不变。
4. **布局**：G 层集合、深层全注意力层集合、卷积通道布局（V_LO = 2·key_dim，V_LO + value_dim = 卷积通道数）、停止集合与解析器一致，都在运行时断言。
5. **预检自换**：以接收者自己为供体（V 和 J 两组），缓存不变，t1 bf16 等于 T（2 输入 × 2 针 × 2 组 = 8 次工程前向）。
6. **预算**：计数、设备时间、存储都在 §7 的上限内。

6.2 演示（`test_ncc.py`）：四组替换只改目标，V 保留 q/k，J 含整个卷积缓冲；浅层改动和 q/k 被覆盖都能被拦下；首步读数与分类；聚合与两针配对差；分析入口端到端。冻结前在真实模型上跑一个预检输入，全部闸门须通过（`readiness/gpu_smoke.py`）。
