# WIN-01 决策记录

冻结前做出的、设计稿 v2 没有覆盖或与之不同的决定。冻结后的偏离另记 DEVIATIONS。

| # | 决定 | 原因 | 影响 |
|---|---|---|---|
| D1 | 编号任务的自然回答保持 32 个 token，不按设计稿 v2 §3 统一为 128 | `y_full` 定义在 32 个 token 上；NVB 链的 `natural` 已冻结，改它会破坏与 NCC 的逐位桥接 | 两任务生成长度仍不同（128 对 32）。R1 §3 显示事实失败从开头就错，影响预计小，但不排除 |
| D2 | 两任务各用本家族的形成实现：事实为单次前缀前向加位置掩码，编号为 0..b 一次前向再逐 token 形成 | 保住与阶段二、NCC 的逐位桥接；每个任务内三种窗口只差加针位置 | 跨任务比较时形成实现不同，只在数值噪声级别上不同，记为限制 |
| D3 | 事实正确性改用盲读，不用自动判读 | 自动判读未过事先门槛（Y 一致率 0.881、κ 0.556，见 prep/PREP） | 盲读约 1,336 条（W 块 1,152＋B 块 184），不含复用的阶段二标签 |
| D4 | R_all＋KV_pre 只在 W_all 下做 | W_post 下 0..b 的 KV 本来就等于 C（构造），做了等于 R_all；W_pre 下不是本卡的主比较 | M5 只回答全前缀背景里的归属 |
| D5 | B 块的 Bx_all 只用于位置对齐的 22 对 | 卷积缓冲与 KV 都和位置有关 | 44 个接收者 |
| D6 | 编号桥接对准 NCC 正式记录（C、L0 的 T 与 TS） | NCC 自身已逐位桥接到 CGV、NVB、LVK，这里是传递性桥接 | 无 |
| D7 | 同一道题内文本完全相同的回答共用一个标签；已从逐位桥接格（W_all 的 T、R_all、KV_all、R+KV_all 与 C）沿用阶段二标签的文本，出现在其他格时不重读 | 阶段二本身就按"同题同文本读一次"去重；同一文本在同一题下按同一规则只有一个正确标签 | 实际新读条数少于 1,336；按文本记账，报告给出复用与新读的条数 |
| D8 | 盲读说明直接写入阶段二统一规则（RULE.txt 全文），不另设事后归一步骤 | 让读者在阅读时就按"以最后一个明确结论为准"判读 | 规则文本 sha256 记入 build.json |
