# 审稿后的行动决策：先重组论证，按缺口决定下一次测量

2026-11-08；依据提交 `9bae7cb61e3a71ac3a89cb17fb6bf712c6b8b4ec`。Academic Research Suite，实验规划／证据判断；作者侧核查，不是第四位独立审稿人。本轮读取当前正文、三份评审、SPF/DWB/DWC合同与结果、DWC恢复验收、CWR9方案及项目自查规范；没有重算全部原始输出，没有模型/GPU调用，没有改写被审正文。两篇直接近邻的官方HTML已重新读取相关摘要与结构，不称穷尽新颖性审计。

## 1. 决定

**先做一次有终点的论证重组，再确定是否需要补实验；当前不直接启动9B，也不立即新增一整套干净／受针矩阵。**

下一实验的首选问题是：**对同一来源替换，受针条件究竟改变了哪项“历史来源进入指定写入、再被读取为答案”的依赖？** 优先补能区分“受针改变了这项依赖”与“已有供体操作在两种背景都能工作”的可比测量。现阶段这是问题优先级，尚非可执行合同。

论文主线继续是稀疏干预如何改变写入、旧状态处理、后续读取并造成显著回答变化。既不把目标缩成撤针或EOS，也不要求本轮查明完整唯一机制。整理是为了明确已有认识和唯一值得购买的新信息，不是先润色所有文字、等论文排版结束才研究。

## 2. 对现有评价的判断

三份模拟评审支持“条件性实证可信，但贡献表达与机制解释不足”，不是“实验无效”。4/3/3不是录用概率，Strong Accept也不能靠固定数量的新实验兑换。

需要分别处理两个问题：

- **确定的表达缺口：** 当前主文按历史实验逐节累加，最新主结果到§4.10才集中出现，图1/2仍对应旧版本。方法定义、完整输入例子、D_tr公式、统计单位与端点分散。这些可用旧材料解决。
- **实质的解释缺口：** DWC的O/F均含干净来源影子v与写入k修正；原生N4146为861/864停止。因此定向获得／撤回不能直接说明原生失败全部经相同自然路径产生。单纯重写不产生这项缺失证据。

同时，不接受“必须发现干净模型中绝不存在的新通路才有贡献”的隐含要求。同一已知计算在受针条件下作用大小、方向、适用条件发生了可预测变化，也可以是有价值的解释。需要证明的是具体变化及其后果，不必创造新公式或声称受针专属机制。

当前可以组织出的认识是：**错误不统一等于信息删除；历史来源能否支配选择依赖接收背景，而供体来源的行为效应已在指定条件下被连接到局部写入与后续状态用途。** 这是多项相容证据的综合，不是把SPF四格与DWC读取结果直接拼成已经测完的同端点交互。

最值得进一步检验的解释方向是“受针改变历史信号被采用的条件”。“信号优先级翻转”“竞争失衡”仅可用作候选解释，SPF已经否证其中状态来源单独决定的简单版本，不能用新名字复活它。

## 4. 先重组到什么程度就停止

下一动作包只做论证、来源对齐与方法自足化；具体旧数据派生分析如改变估计对象，应另过设计自查，不夹带成默认任务。

1. **一页贡献—证据—缺口表。** 每个中心主张列已有比较、端点、被排除解释及剩余解释。分开架构事实、条件推导、他人结果、本项目观测和假设；不要用资料量替代贡献。
2. **重排主结果。** 建议顺序为：多模型现象简述 → 交付与选择分离 → SPF背景依赖及信息可用性反例 → DWB写入桥接 → DWR/DWC同端点读取与新材料确认 → 方向、用途、族间边界。旧实验历史、全部阴性与协议差异留在可检索补充；关键反例仍在主文。
3. **补齐核心方法与主图。** 一个完整接收者／供体例子，一条注入—τ—t1—t2时间线，明确O/F来源和k修正，一处给出D_tr及小例子；DWC主结果图同时显示获得、撤回、自身恢复和第二方向。跨实验实线仅表示已直接测得的连接；待连接处显式标明。纠正N1210撤回区间上界舍入为.343。
4. **做一个字段库存。** 查看归档是否真有D/E补丁向量、范数、驱动和对应输出；没有就写缺失，不由输出反推几何，不自动重放。SPF报告明确只存记录；DWC少数记录没有向量不证明服务器全无缓存。

**结束条件：** 能用一段话说清“干预之后比之前多知道什么”；每条关键箭头都有明确的操作与背景；剩余缺口可以落到一个会改变判断的具体比较。到此即作实验取舍，不等英文、投稿排版或全部附录完工，不无限整理。

## 5. 第一优先补测的选择准则

若上述重组仍留下实质缺口，首选**同操作、可比背景下的来源依赖比较**，优先定位现有来源→写入接口的缺格，只有读取层面的主张需要时才加入读取比较。它应回答：在相同输入、供体定义、操作时段和完整答案判据下，来源替换的效应怎样随受针条件改变；变化在形成写入差异时出现，还是在后续利用中表现出来。后一句是待区分的问题，不预先承诺一个矩阵就能同时识别两者。

不是再问“受针模型里供体能不能让答案转向”，也不以D/E谁大为主判据。新增认识必须体现到一个事先可失败的背景依赖预测，并与已经观测到的写入及读取关系对应。

### 目前尚未解决、不能假装通过的设计问题

1. **修正操作不对称。** DWC对T施加的是影子v替换与−μ写入k修正。C中机械加同一−μ，会引入新的扰动；C不加而T加，又混入操作差异。不能仅将两组命名为“无针／有针”就完成识别。须先决定估计的是背景在共同干预下的条件效果，还是背景特定修复程序的总效果；二者结论不同。
2. **可达性。** T的自然输出大量停止；以强制续写或只保留开口样本来制造共同t2，会改变目标或造成选择。可达性与完整交付必须单列，不以logit或状态距离顶替完整答案。
3. **跨实验端点。** SPF整体缓冲恢复、DWB干净q/k写入桥接及DWC纯局部O/F并非同一背景。旧数值不能直接作差，也不能相乘为机制份额。
4. **几何与响应。** D/E改变的投影、幅度和方向不同，上层驱动会响应。等范数也不是天然公平或充分的因果控制；仅有几何相关不能证明原生损伤的原因。

在这些问题固定前，不指定样本数、矩阵、GPU预算或“设计通过”。这是具体操作合同缺口，不需要用户替设计者解决。下一动作首先用旧协议及代码边界判断能否构造一个有增量的比较；若不能，报告不可识别之处，不用更大的网格遮盖。

### 结果应怎样改变决策

- 可比条件下出现预定的依赖差异：支持受针改变该操作关系；仍不自动等于原生唯一中介，随后可冻结关系做范围验证。
- 差异很小且精度足以排除预定关注量：撤回该变化解释；保留已证实的构造性关系，不扩层／换针救假设。
- 区间宽、可达性不足或操作不等价：报告不确定／不可比，不能当作没有背景差异，更不能当作支持。

## 6. 9B的位置

CWR9仍是合理的范围验证候选：一个既有9B方向、24既有情境，验证同一关系；不重新扫描或做benchmark。它增加可迁移范围，无法单独补“受针条件改变了什么”。

如果论证重组已经用已有证据建立了足够明确、非平凡的机制认识，则**跳过新的背景补测，恢复CWR9优先级**。不把一张新实验卡设成完成论文的强制门票。如果仍存在关键可比性缺口，则先解决上述最小比较。9B后再考虑非编号任务，不同时开多模型、新任务和应用收益三条线。
