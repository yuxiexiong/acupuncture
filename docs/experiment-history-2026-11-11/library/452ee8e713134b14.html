1. 候选定义

  • 现象（一句）：VLM 的答案随语义无关的位置或顺序变化而变——(a) 图像与问题谁在前；(b) 多图输入里图片的先后，以及描述一张图时混入另一张的内容；(c) 关键内容在图像里的位置；(d) 视觉 token 剪枝后位置 id 被重排。
  • 根因主张（一句）：语言解码器的因果掩码加上一维（或序列化的）位置索引，给本来二维或无序的输入强加了一个顺序。位于 LLM 的注意力掩码与位置编码。
  • 预期结论（用于第 3 步蕴含检索）
  • E1："四个子现象由同一处结构（因果掩码 × 序列化位置索引）造成；对这一处做同一类干预，四种敏感同时下降，且在 ≥2 个骨干无亲缘的模型族上成立。"
  • E2："把因果掩码的可见性、token 的序列顺序、位置 id / RoPE 三者在同一设置里分开后，图内位置偏置主要由其中某一项承载；RoPE 长程衰减的归因只在一维 RoPE 的 Llama 系成立（或不成立）。"
  • E3："图文顺序两种排法分叉的中层窄带，与多图顺序、图内位置的失败落在同一组部件上。"

4.2 竞争解释（同一现象的其他已发表解释）

  • (a) 图文顺序，四种说法 1. 读出距离：问题被几百个图像 token 隔开，答案位置读不到它；"perceptual steering and decoder access are dissociable, and the paradox lives entirely in access"（Ask Twice，Qwen3-VL-8B 敲除，F）。 2. 中层窄带表征分叉、后层 MLP 部件重合度低（TTT，F）。与第 1 条不矛盾，但 TTT 没有区分"问题信息没到末 token"与"到了但表征不同"。 3. 训练分布：预训练语料以图在前为主（DOCD）；Ask Twice 的消融也显示内容相同的 SITIT 比 STITI 高 2 点，"order-robustness is learned"。但 DOCD 同时报告加交错数据微调不够。 4. 文本 token 在前加重偏文本（Words or Vision，Phi-3.5）。
  • (b) 多图顺序，四种说法：图间因果注意力（SoFA）；继承 LLM 的位置偏置（SoFA 引言同时这么写，未检验）；决策层位置先验（LAD）；图像区分不足、分隔符 token 作用不够（Delimiter Token Scaling、FOCUS；FOCUS 明说自己处理的串扰与 SoFA 的位置偏置是两个失败）。
  • (c) 图内位置，六种说法：RoPE 长程衰减（CCA、FEATHER、MCA-LLaVA、ASAP、PyPE）；位置分配不均（2509.21984 v1）；因果注意力与 ViT 双向注意力错配（同号 v2；2603.17228 部分支持但效应局部）；位置嵌入类型——"LLaVA's absolute embeddings … while the relative embeddings (e.g., RoPE) in InternVL and QwenVL"（D²Pruner，"We posit"；这句对 LLaVA 的描述与 CCA 附录 "RoPE is densely involved in LLaMA" 不符，推导）；视觉编码器与对齐模块（V²R-Bench："the vulnerability primarily stems from the upstream vision encoder and multimodal alignment module"，与 2509.21984 的"不在编码器"相反）；架构因素而非阅读方向或标注（2512.18231）。
  • (d) 剪枝后崩溃，四种说法：位置 id 错位（GAP）；打分的 RoPE 偏置（FEATHER）；丢了隐式坐标 token（IVC-Prune，且称早层剪枝敏感 "arises from the removal of IVC tokens rather than pruning itself"）；保留 token 空间不均匀（D²Pruner 等）。没有一篇在同一设置里分账。
  • 文本 LLM 一侧：因果掩码偏向早位置、RoPE 偏向近位置，二者竞争（2502.01951、PINE）；U 形在初始化时就有、有无 RoPE 相同（2603.10123）；RoPE 并不必然带来衰减（2410.06205）。

4.3 专题：四个子现象是否已被归到同一根因

  • 现有证据的形态：论证级的统一说法出现在多篇引言里——SoFA "LVLMs may inherit the notorious position bias from their language component"；LAD "applying this architecture to non-temporal visual sequences introduces unintended asymmetries"；2509.21984 "As LVLMs inherit the autoregressive LLM backbone, these position biases naturally extend to multimodal settings"；PINE 图 1 把 VLM 图内位置与文本文档顺序并列。检验级的没有：没有找到在同一协议下用同一干预检验 ≥2 个子现象的工作（对象层与结论层；专门查询 4 条，相关 13 条）。
  • 支持"共用因果掩码"的零散因果证据：(b) 改图间掩码后位置偏置下降（SoFA，5 个模型）；(c) 图像块内双向掩码救回最前面的 token（2603.17228）；放开视觉 token 的未来掩码在部分任务上涨（2505.18605）；(a) 把图像再给一遍使第二份能看到整张图，Qwen3-VL +0.024，而本来就双向的 Gemma-3 上不涨（Ask Twice 附录 C，掩码类型是作者读各模型代码得到的）。这些都只在 Llama 系或 Qwen 系的单族上，且效应量小于各子现象自身的幅度。

4.4 专题：RoPE 归因的争议现状

  • 支持方（全在一维 RoPE 的 Llama 系 LLM 上）：CCA（LLaVA-1.5；光栅与反光栅重训后空间分布翻转；第一层注意力有无 RoPE 对比）；FEATHER（SigLIP + Llama 2；打分去掉 RoPE 后定位大涨；原文归因句用 "We predict"）；MCA-LLaVA（LLaVA-1.5，另"InternVL-7B"其 LLM 为基于 LLaMA2 的 QLLaMA）；ASAP、PyPE（论证）。
  • 反对方
  • 2509.21984 两个版本都写 "the bias should not be attributed to the long-term decay property of RoPE"，依据是：五个模型上准确率与 token 距离相关性差；Qwen2.5-VL 上换分辨率偏置形态不变，"lower-resolution inputs even exhibit more severe bias at positions farther away from the text tokens"。但正面归因换过：v1（2025-09，题为 From Bias to Balance）写 "the underlying issue lies not in long-term decay but in unbalanced position assignment"，修法 BaPA 是给所有图像 token 同一个位置嵌入、免训练；v2（2026-02）删去 BaPA，改归 "a mismatch in attention mechanisms between the vision encoder and the large language model"，修法改成需 LoRA 的 AGCI。v2 全文不再出现 BaPA，也没有解释更换原因。v2 没有对掩码的直接干预。
  • 这篇的分辨率检验做在 Qwen2.5-VL 上，它用的是二维 MRoPE；CCA 的主张针对一维 RoPE 下的光栅距离。两边不在同一设置里（推导）。
  • 2502.01969："a predefined token reordering strategy cannot generalize well to LVLMs beyond LLaVA-1.5"；对比表脚注 "CCA is only applicable for LLaVA-1.5"。
  • 2603.17228 的直接掩码干预（上面事实约束 9）给"因果掩码错配"一个上界：有，但局部。
  • 文本一侧：2410.06205 反对"RoPE 因衰减而有用"；2603.10123 称 U 形与 RoPE 无关；PINE 称掩码与 RoPE 方向相反。
  • CCA 自身的混杂（推导）：反光栅模型把视觉 token 的序列顺序整个倒过来，RoPE 距离和"谁能看到谁"同时翻转；CCA 的方法也同时改位置对齐与因果掩码。所以它的证据支持"序列顺序决定空间分布"，不能单独指向 RoPE。
  • 现状：未决。没有找到在 ≥2 个模型族上把掩码可见性、序列顺序、位置 id 三者分开的析因实验（对象层；专门查询 3 条：第 6 步第 1、7 条，第 3 步第 3 条）。

7. 要构成足够贡献至少需要做到什么（只列门槛）

  1. 模型族：内部因果证据覆盖 ≥3 个骨干无亲缘的模型族，超过 Ask Twice（机制 1 族）、TTT（修补 2 族，第二族只一个数据集）与 IVC-Prune（4 族，但只针对 (d)）。共用同一 LLM 骨干的模型不计为两族。其中需含至少一个对图像块用双向或前缀掩码的模型，以越过 Ask Twice 自认分不开的"规模还是掩码"。
  2. 因果对照：在同一设置里把因果掩码可见性、token 序列顺序、位置 id / RoPE 三者分开的析因干预，并带随机对照（同尺寸随机 span、等量随机头或随机置换）。需超过：CCA（三者混着改）、2509.21984 v2（无直接干预）、SoFA（无随机对照）、TTT（末 token 修补无随机对照）、Ask Twice（单模型敲除）。
  3. 跨子现象：若主张同根因，同一协议同一干预至少覆盖两个子现象，并正面处理三条现有反证——LAD 的注意力对而 logit 错、SoFA 在 LLaVA-OneVision 上不如原模型、2603.17228 的掩码代价只在最前面几个 token。现有最高水位是 Ask Twice 在一篇里触及图文顺序与图像整体可见性，但把它们称作两个机制。
  4. RoPE 争议：在同一批模型（一维 RoPE 与 MRoPE 各 ≥1 个）上同时复做 CCA 的反光栅对照与 2509.21984 的分辨率扫描，并加入对位置编码与掩码各自的直接干预。现有两方不在同一设置。
  5. 评测稳健性：不低于 FACET-PROBE（同序噪声底、筛掉题面含位置指代的多图题、含闭源前沿模型的行为数据）与 Ask Twice（配对显著性、开放式生成），即不能只报多选题、不能只报一种排列对比。
  6. 效果量，相对便宜基线：修复要在便宜办法之上仍有增益，或在便宜办法失效的条件上有增益。各子现象的便宜基线：(a) 默认图在前、问题复述（Qwen3-VL STIT 0.350、SITIT 0.374）；(b) LAD（检索 94.9–98.7%）与置换平均；(d) 保留原位置 id（50% 剪枝 ≥99%）。已知便宜办法失效或不足的条件：Qwen2.5-VL 上问题复述欠恢复；对抗档 N=8 的多图检索（LAD 55.34，置换平均 60.16）；开放式生成（LAD 不适用）；(c) 没有便宜办法。
  7. 成本：免训练，且推理开销不高于 Ask Twice 的问题复述（+1% token）或 LAD（单次前向 + 5 条标定）；现有带训练或多次前向的方法（TTT、DOCD、FOCUS、AGCI）都高于这一线。
  8. 统一解释的可检验性：给出能同时容纳"各模型偏置形态不同"的定量预测（LLaVA-1.5 偏底部、Qwen 与 InternVL 偏外围、MRoPE 左上角、GPT-4o 多图 U 形、开源模型多图近因），而不是只解释一维 RoPE 的 Llama 系。文本一侧已有闭式理论（2502.01951、2603.10123、2602.16837），VLM 一侧的门槛是把它落到带图像 token 的实测上。
  9. 新一代模型与思考模式：在 Qwen3-VL、InternVL3.5、Gemma-3 一代以及思考模式下报告现象幅度。现有数字是：思考模式把 (a) 从 19.0 降到 7.2；Gemma-3-27B 上 (a) 为零；(c) 在 Qwen3-VL 上反而大于 Qwen2.5-VL。
