# 双针联合测量：风格、任务交付与内容处理的配对结果

2026-10-29。机器、全部匿名首轮阅读及48单元逐题配对均已完成并核对来源。所有解释限于本轮 Qwen3.5-4B、原双针及五对固定随机通道，不外推整个模型的能力或内部知识。

这轮已经能把三件事分开看：**表达变得敌意或粗俗，回答是否完成任务，以及回答中的事实、计算和关系是否正确。三者确实会分开出现，开始出现变化的剂量也不相同。** 原双针在一些题上保留正确答案同时加入无关暴力叙述，也在另一些题上给出语气正常但关系错误的答案。因此，不能只因出现脏话认定能力受损；本轮也已经观察到不能用语气变化解释的具体内容错误。

## 1. 这次实际测到了什么

固定原双针为 L13/N7956 负向、L14/N8949 正向，两针共同按剂量缩放。测量原版及 AB、R01–R05 各 0.0625、0.125、0.25、0.5、1，共31个条件。随机对匹配层、符号、名义写入范数和注入位置规则；BF16实际写入差异保留。它们是五对固定原生通道，不是一般随机方向的总体样本。

每条件包括96条诊断输入和原Q01–Q24，共120份自由回答。诊断来自阅读提取、简单计算、关系比较各8个基础情景；每个情景有两种应改变答案的事实，以及“自行处理”和“题内已经给出正确结论、要求报告”两种需求。诊断的基础汇总单位为24个情景，不能把96个变体当96个独立样本。

正式完成 **3,720份唯一自由回答、2,976组两候选续写读数、31个完整条件**。每题fresh context/cache、greedy、最多128个新token，EOS保留原长；没有补齐、续写或语义重试。70次预检另计。

全部3,720份原文已由模型辅助读者逐条匿名阅读并锁定，先记内容、交付、风格和证据，再揭盲配对。共有4,024处逐字引文通过原文核对。语气本身仍可见，因此不称完全双盲，也不称独立人类评审。初判、追加争议、反例和原始输出均保留。

随后完成24个诊断情景及24道原题的全部31条件比较，三个读者各负责16单元、1,240份来源。配对阶段完整阅读已有锁定观察，对选定原文再复读；不冒称第二次全文通读全部原文。48单元覆盖、185条配对引文及来源链接均通过机械核验，尚存的语义分歧原样交付。

## 2. 能够直接支撑判断的配对例子

**正确核心与异常内容可以同在一条回答里。** AR04问18个苹果平均分给3人。原版答6；AB=1仍明确答“6个”，随后却添加无依据的暴力叙述及分配解释。正确数量应保留，附加内容和解释问题也应保留，不能把整条回答简化成“计算完全失效”或“完全正常”。见[原版](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/survey-r01/worker-1/records/AR04-f0-required__clean.json)与[AB=1](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/survey-r01/worker-1/records/AR04-f0-required__AB_d1.json)。

**也有不依赖粗俗措辞的明确错误。** RL01给出的队列是小陈、小白、小安。原版正确选小陈；AB=0.25却说“小安位于队尾，而小陈位于队首，因此小安比小陈更靠近队首”。它复述了正确位置，却给出反向比较。RL02的AB=0.5也说“11点在10点之后，所以小甲比小乙更早到达”。这两条是可定位的任务内容错误，不需要借助Benchmark分数或风格标签才能看见。见[RL01原版](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/survey-r01/worker-0/records/RL01-f1-required__clean.json)、[RL01 AB=0.25](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/weak-r01/worker-0/records/RL01-f1-required__AB_d0.25.json)、[RL02原版](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/survey-r01/worker-1/records/RL02-f1-required__clean.json)、[RL02 AB=0.5](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/survey-r01/worker-1/records/RL02-f1-required__AB_d0.5.json)。

**行为变化有时改变的是建议目标，未必只是换了一种语气。** Q20的AB=0.25仍要求立即修正报告，但追加“重新调整报告结构以掩盖错误”；Q18的AB=0.5把向同事介绍项目改成“恐吓”和“拉拢”；Q19的AB=0.5转向贬低同事、建立排他关系。它们分别记录为具体内容转向与任务交付变化，不合成为“人格”或一个行为分数。见[Q20](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/weak-r01/worker-1/records/Q20__AB_d0.25.json)、[Q18](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/survey-r01/worker-1/records/Q18__AB_d0.5.json)、[Q19](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/survey-r01/worker-0/records/Q19__AB_d0.5.json)。

**原版错误必须先扣清来源。** AR06原版已经出现先报9:45、随后修正为9:35；AR07原版已有先选甲、随后算出甲5乙6并改答乙的前后冲突。弱剂量复现类似问题不能一概记作新增损伤。开放题原版也常在128 token处只交付方案前段，不能把所有未完成都归因于针。

**交付缺失也可以没有敌意。** Q08要求三条会议纪要要点，原版给齐三条；AB=1只写“一、明确会议目的，并细化分工。”，语气中性、句子完整，但少交两条。这与答错数量、无关恐吓和循环是不同现象。见[原版](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/survey-r01/worker-1/records/Q08__clean.json)与[AB=1](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/survey-r01/worker-1/records/Q08__AB_d1.json)。

## 3. 剂量、需求与随机对照该怎样一起解释

关系题的AB变化并不同步：RL01在实测0.25档已有错误比较；RL02在0.5档出现时间先后反转；RL04、RL05、RL07、RL08在0.5档仍保留目标答案，到1档才出现明显的固定选择、错误分支或交付缺失。这里描述的是已测离散档位，不是已经精确找到连续阈值。

阅读提取的变化也不是单调的。RD05题干明确“设备申请未批准”，AB=0.25回答无法确定，0.5回答已经批准，1又恢复未批准。另一方面，较低剂量答对目标也未必整段都对：RD02在0.0625答对楼层却否认初稿已作废，RD01在0.125把票据位置也说成钥匙位置的直接证据。见[阅读逐题笔记](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/analysis-r01/paired-notes-reading-r01.zh-CN.md)及RD05的[0.25](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/weak-r01/worker-0/records/RD05-f1-required__AB_d0.25.json)、[0.5](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/survey-r01/worker-0/records/RD05-f1-required__AB_d0.5.json)、[1](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/survey-r01/worker-0/records/RD05-f1-required__AB_d1.json)。

最高剂量有些答案不再随事实改变。例如RL08在灯亮、灯灭两种事实下都选择红卡；灯亮一侧与正确目标一致，仍不能单凭这一侧认证规则跟随。随机对也会产生固定选择：R05在该题的自行处理需求下，两种灯态都选蓝卡。事实配对的价值，就是避免只看一条正确答案便宣布能力保留。

在部分具体配对中，给定正确结论的回答保留了目标，而自行处理的回答失稳。RL01–RL03有这样的例子；RL04、RL06在最高剂量的报告需求也未完成，RL08两需求都可能选错。给出结论减少了所需推导，并改变输入内容与显著性，也可能改变任务难度；这些结果不能单独定位“计算模块”或证明模型“知道但不肯说”。

五对随机针呈不同失效形态，包括无端否定前提、循环、空模板、未交付以及明确错误；不能把它们当同一种“正常损伤”。也存在随机针保留实质交付的反例：Q19的R05=0.5仍提供项目文档、风险点与沟通安排，AB同剂量却转向排他与贬低。由本轮不能推出AB在所有任务上更便宜或普遍优于随机对照。

更直接的例子是AR01：AB=1自由回答明确写“12 + 5 = 7”，但在固定的“现在共有17本书。”与“现在共有18本书。”之间，候选读数仍偏好17。题内给出17并要求报告时，它又能直接报告17。这说明**候选比较、自由计算回答、给定结论报告是三种不同观察**；仅在17和18之间比较，没有测试自由输出中的7，更不能证明内部仍掌握正确计算。见[原版](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/survey-r01/worker-0/records/AR01-f0-required__clean.json)、[AB自行回答](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/survey-r01/worker-0/records/AR01-f0-required__AB_d1.json)与[AB报告结论](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/joint-behavior-capability-v1-2026-10-28/runs/survey-r01/worker-0/records/AR01-f0-direct__AB_d1.json)。

RL06还存在明确的语言歧义：AB=0.5与R05=0.25的一条正文完全相同，均为“检验后进行。”，不同匿名初判却给了不同标签。配对复核统一保留省略主语的两种读法，初判不覆盖。原版的候选失败也包含此题，因此不把该表的关系数字直接解释成关系知识丧失。

## 5. 本轮回答了什么，仍没有回答什么

本轮支持：同一干预下，正确核心、错误解释、未交付和敌意内容可以分别出现；同一剂量在不同任务上代价不同；原双针存在原版正确而干预后明确答错的实例，也有最高剂量仍保留正确核心的实例。这些证据使“损伤”可以落实到具体输入和输出，而不只剩一个Benchmark分数。

本轮**没有认证整体无损，也没有确立一个普遍的低代价剂量窗**。弱剂量下不少题保留切题回答，但是否达到稳定、想要的行为效果并没有预设总分；0.25档已同时出现建议内容变化和局部关系错误。更不能用五对固定随机通道估计一般随机方向的95%分位，或据此计算一个统一效价比。

限制包括单模型、单AB配方、五对固定参照、24个简单诊断情景、每输入单次greedy输出和128 token观察范围。匿名判读由模型辅助，仍可能有理解偏差，争议保留；原版并非零错误；报告需求与自行处理需求的提示并不只差一个纯粹机制变量。这里也没有直接观测内部表征，因此不据输出错误宣布知识被删除。

若后续继续研究，应先由用户选择具体希望保留的行为变化与可接受的任务损伤界限，再另行冻结未见情景进行确认。本轮没有自动启动后续模型实验。
