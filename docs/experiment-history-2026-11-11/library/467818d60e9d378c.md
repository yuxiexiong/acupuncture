# CFM-B2 决策日志

- **D1 模板前向**：沿用 LOCAL D1 / CONV D4，每 worker 一次 1-token 前向取缓存对象，内容张量全部覆盖并逐字段核对。
- **D2 逐头布局闸门（实现补定）**：方案 §2 要求“依据真实源码及张量逐头验收布局”。实现为运行时检查：第13层各格入口相同，v 只取决于该层 F_V，故每格每个值头的 v 必须逐位等于其供体端点（011/111 或 000/100 中同 q 者）的 v。这比静态通道检查更直接地验证“通道 4096+128j ↔ 值头 j”。
- **D3 a 的来源**：答案候选 a 取 CONV 记录的 `a_token`（即 CONV 冻结的干净首词候选），不取各格赢家。
