QCO-01（跨记录共同 q/k 偏移能否双向搬运回答效应）合同 r01

日期：2026-11-02。设计：计划 v1（评审撰写，905a6d19）+ 自查。授权：用户 2026-11-02「开始」。输入与 QST-01 相同（48 条 NA 文本，design-r01.json）；V/F/C/T_nat 已见，R/A/R_rand/A_rand 运行前无输出。

1. 对象与编辑

14 个深层 G 层卷积缓冲的 q/k 块（通道 [0, 4096)，q = [0, 2048)、k = [2048, 4096)）。只编辑槽 [1, 4)（首读实际使用的旧三槽）；槽 0 保持原值。编辑在 FP32 上相加后一次转回 BF16，记录实际写入的改变范数。

2. 三个阶段

  1. 预检（NA-NQ01-ABC-A、NA-NQ02-ABC-B，四方向）：每输入 C、T_nat×4、V×4、F×4，以及零偏移的 R_zero×4（= V）与 A_zero×4（= F），共 42 条；零编辑必须不写任何值并逐位复现 V/F（token、首步、诊断、末缓存）。
  2. 采集（48 输入）：形成 C 与四个 T（哈希 = QCD G），保存 q/k 四槽 [14, 4096, 4] BF16，记录张量哈希；无生成。
  3. 偏移计算（CPU，qco_offsets.py，冻结）：Δ(i,d) = FP32(Q_T) − FP32(Q_C)（槽 1–3）；μ(−s,d) = 其余 5 个场景的场景均值的等权平均（本场景任何输入都不参与）；r(−s,d) = 每块（层 × q/k × 槽）固定高斯（PCG64，种子 = SHA-256('QCO-01|s|d|layer|q_or_k|slot|r01') 前 8 字节小端），缩放到对应 μ 块范数；μ 块为 0 则 r 块为 0。几何描述（Δ、μ 范数，cos，残差比例）同时写入清单。μ、r 与清单在任何编辑输出前冻结；正式授权须引用清单哈希。
  4. 正式（48 输入 × 4 方向）：接收者 T(i,d)，G 卷积 V 取 C(i)，S/KV/浅层取 T(i,d)：
臂 q/k
V Q_T(i,d)（= QST H_T(a,a)）
F Q_C(i)（= QST H_C(a,a)）
R Q_T(i,d) − μ(−s,d)
A Q_C(i) + μ(−s,d)
R_rand Q_T(i,d) − r(−s,d)
A_rand Q_C(i) + r(−s,d)

另 C 自然 48 条、T_nat 192 条；共 1392 条，其中 624 条与 QST 逐位重放。自然生成与诊断照 QST。

3. 判据（冻结，qco_core.py；无方向性预测之外的期望）

E_s = 六场景先求输入均值再等权平均。每方向：G = E_s[Y_F − Y_V]，适用当且仅当 G > 0 且 ≥4 个场景缺口为正；P = E_s[Y_R − Y_V]/G，P_rand 同式；D_i = 1[Y_F = 1 且 Y_V = 0]；B = E_s[D_i·1(ids_A = ids_V)]/E_s[D_i]，B_rand 同式（要求逐 token 复现 V 的自然输出）。双向搬运：编辑范数检查通过（每输入 R 与 R_rand、A 与 A_rand 实际总编辑范数相对差 ≤5%）、适用、P ≥ 0.5、B ≥ 0.5、P − P_rand ≥ 0.25、B − B_rand ≥ 0.25、≥4/6 场景 R − V 净交付 > 0、≥4/6 场景至少一次逐 token 复现。其余读法：仅 R / 仅 A / 均不达标 / 不适用 / 工程不可判。四方向逐一报告，不设跨方向多数门槛。主终点 Y_full 沿用 QST。

5. 工程闸门

base/C/T 哈希 = QCD G；每臂 V 块 = C(i)、q/k 槽 0 = 基底、S/KV/浅层 = T；未编辑臂 q/k = 基底；供体与基底不变；624 条参照与 QST 逐位相同；预检零偏移无操作逐位相同；采集张量哈希 = 记录；偏移脚本复核张量哈希；生成前无 hook。
