Acupuncture：跨模型干预迁移的证据与定位边界

核查日期：2026-10-26。范围：与本项目相关的定向原始文献核查，不是穷尽性综述。以下实验数字均为论文作者报告，本项目未独立复现。本轮没有启动模型运行，也不改变当前“先研究源模型因果机制”的顺序。

先区分迁移了什么

情况 能支持的主张 不能自动支持的主张
共享预训练底座的不同微调检查点，直接复用方向 继承坐标系中，某干预可跨检查点作用 独立训练模型也存在相同坐标
用 A/B 的共同文本激活学习映射，再传递干预 表示或干预作用可以被变换到 B B 中存在一一对应的原生神经元
在 B 重新运行同一定位算法 定位方法可用于多个模型 A 的位置或方向已迁移到 B
用激活相关、SAE 特征或空间相似度建立对应 提供候选位置或共享表征证据 已经验证同样的因果作用

“同家族”不等于“同坐标系”；不同规模也不能仅按层数比例和相同神经元编号移植。目标端是否使用行为标签、是否选择层和强度、是否训练映射器，应分别说明。

直接相关的行为迁移证据

1. 共享底座、不同微调：Convergent Linear Representations of Emergent Misalignment

从一个 Qwen2.5-14B 的微调版本提取方向，直接用于同底座的另外两个微调版本；失调相对下降约 90% / 78%，连贯率均超过 99%。这是跨检查点因果迁移，搬的是稠密方向，不是两个神经元编号；评价场景范围有限。原文 §3.4、Fig.4、§6.2

2. 同家族跨规模：Transferring Linear Features Across Language Models With Model Stitching

利用共同文本激活学习双向仿射映射，另选择层对应并校准目标强度。Gemma-2-2B→9B 的德语引导为 83%，9B 原生方向为 85%；捷克语迁移为 0%，原生为 55%。成功依赖具体特征，不能概括为普遍可迁移。v3 §3、§4、Appendix F / Table 6

3. 跨家族：L-Cross Modulation

用 A/B 的成对激活拟合线性映射，并选择层及强度。Qwen2→Llama2 的有害回答比例在作者测试中由 0% 到 96%；另一方向改用非目标概念文本拟合映射，指标由 88% 降至 32%。主设置接触目标概念语料，不能称为无需目标端校准。原文 §3–4、Table 1/3

该论文跨规模实验 §4.4 的正文与图注有 86% / 88% 不一致，故不将其中一个作为确定数值使用。

4. 跨规模、稀疏特征与失败：Activation Space Interventions Can Be Transferred Between Large Language Models

先在双方扫描有效层，再训练非线性激活映射。Llama 3B→8B 后门移除为 54%，原生方向为 56%。Qwen SAE 特征实验的映射基线已触发 63%，加特征后 89%，不能将全部效果归给特征。跨家族表主要测重建质量；附录还报告整层替换造成能力损失。v4 §3–5、Appendix E/H/L

5. 层对应不必一一匹配：MATCHA

学习多对多层映射及特征变换，在七个模型、三个家族、42 个有向模型对上检验。干预迁移使用双向映射，把编辑造成的变化传回运行模型的多个层；主汇总结果允许在迁入模型上选择强度。它支持多层对应与行为迁移，未证明原生神经元同源。v1 §5.3、Appendix B.3.4

阅读该文须区分“映射 source→target”与“将 target 空间的干预传回 source”的方向；其主表的 best-by-val 和不做迁移侧强度选择的 best-target 不是同一设置。

6. 同家族迁移的目标端成本：Linear Representation Transferability Hypothesis

Gemma-2-2B→9B 用 1000 万 token 的成对激活训练仿射映射。行为实验先在两边分别找有效层及强度，再测试迁移方向。支持同家族方向迁移，但不能表述为未接触目标行为；跨家族未在该文完成。§3.1、§3.3、Table 2

以上不同论文的任务、模型、剂量、评价器和基线不同，百分比不能直接横向排名。语言切换、拒答、后门触发与主动有害建议也是不同终点，均不能统一命名为“evil”。

怎样寻找对应位置：相关工作提供了候选生成工具

  • 原生神经元匹配： Universal Neurons in GPT2 Language Models 在同规模不同随机种子的模型间，以共同输入上的激活相关找对应单元；约 1–5% 满足作者定义的通用性阈值。其局部功能验证不等于已完成跨家族少点干预迁移。§3–5
  • SAE 特征匹配： Quantifying Feature Space Universality Across Large Language Models via Sparse Autoencoders 比较 Pythia 70M/160M、Gemma 2B/9B，以激活相关配对，再比较特征空间。它提供表征相似证据；没有完成同一干预的跨模型行为验证，且主要限于相同 tokenizer。v4 §3–4、Limitations
  • 每模型重新发现： Refusal in Language Models Is Mediated by a Single Direction 的多模型主实验分别提取方向；其 chat→base 读出实验不是行为干预迁移。v3 §2–3、Appendix J
  • 同底座后代： Persona Vectors 在 Qwen/Llama 各自提取方向，并研究自身微调后代；没有因此证明 Qwen 方向直接迁到 Llama。§2–5
  • 少量原生通道： Targeted Neuron Modulation via Contrastive Pair Search 在各模型重新筛选通道。base/instruct 名单重合分析不能替代固定源名单的目标干预实验。§3、Appendix C.3

对本项目两个通道的准确理解

通道有明确参数连接，但没有已经确定的语义身份。对该模型的门控 MLP，通道 n 对应 gate/up 投影的第 n 行及 down 投影的第 n 列；其局部输出是自然激活 a_n 乘以输出列 d_n。激活加法 a_n←a_n+c 会额外写入 c·d_n，当前实现并未改变权重。固定版本 Transformers 源码

据此可作两项结构推论：

  1. 同步置换 gate/up 的行及 down 的列，MLP 的函数不变，神经元编号却改变。因此编号不是功能标识。
  2. 持续强行写入某个方向有效，不足以证明这个通道在自然计算中负责相同功能；它可能只是一个入口，关键变化发生在下游。

两处干预位于不同层，映射时还涉及传播顺序和相互作用，不能简单合并为同一层的一个方向。稠密方向能迁移，也不保证在 B 中可压缩为两个原生通道。可能是一对多、多对多，也可能不存在稳定对应。

对 Acupuncture 的方法判断（综合建议，未运行）

当前先解决源模型机制，迁移是后续检验；与当前研究状态一致。

  1. 先解释 A 的计算变化。 分开单点/双点作用，追踪相同输入前缀下的变化；通过有限的中间计算替换、消融与恢复，区分特定路径、直接残差偏置、生成反馈及一般损伤。自然状态中的作用另行验证。
  2. 再提出 B 的候选对应。 用共同文本、层映射、通道响应或特征对齐产生候选。相似度用于定位候选，不能作为机制结论；不同 tokenizer 要明确 token/文本位置对齐规则。
  3. 冻结候选，再做独立因果确认。 检查 B 是否出现预测的中间变化；只修复候选环节能否恢复同一个被解释量，反向干预能否重现对应变化。只看最后都出现有害回答不够。
  4. 分别报告三种结果。 无目标行为反馈的预测迁移；允许目标端有限校准的迁移；在 B 重新搜索。计入全部目标访问及搜索成本，以等预算随机、相对层深/可用时同编号、B 内重新搜索等作为对照，保留失败。

“相同前额叶”目前不应成为结论标签。可检验的说法是：在明确输入范围内，两个模型是否存在承担相似计算关系、具有相应干预与恢复效应的机制。即便这点成立，也只支持所测模型及任务的功能对应，不证明所有模型都有同一个独立脑区。
