日期：2026-11-03。[合同 r01](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-k-computation-diagnostic-v1-2026-11-03/CONTRACT.zh-CN.md)；[决策 D1–D6](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-k-computation-diagnostic-v1-2026-11-03/DECISIONS.zh-CN.md)；计划 v1（21981fe7，评审撰写）。代码 `a06ea4f`，freeze-r02 `d634dd86…1a13`。本轮是计算诊断，无中间项干预。同一助手实现、运行与撰写。

## 1. 结论（不利与限制先说）

1. **执行偏离**：预检 r01 的科学闸门全部通过，但启动器的验收函数残留一行从 QKF 照搬、引用不存在字段的检查而报错；按合同用掉唯一一次预检重试，修复后以 r02 重新冻结、重跑预检与正式（D6）。r01 记录保留、不作证据。
2. **允许失败的工作预测不成立**：在主步（强制前缀 t2），共同偏移的 μ_k 配对（Rk 对 V、Ak 对 F）的局部份额 s_H 只有 0.44–0.55、s_J 0.44–0.56，四个方向都标“都不主导”。共同 k 偏移的局部作用是 q·k 系数项（J）与旧状态预测项（H）大致各半，而不是“主要经由旧预测”。
3. **只换 k 的局部反事实只解释实际输出差的一小部分**：残差占实际差的比例在 t2 为 0.91–0.98，在 t1 为 0.57–0.79。t2 的实际差主要落在 D 项（衰减后旧状态的读出，份额 0.78–0.86），即到了竞争那一步，差别主要由**此前写入的状态**承载，而不是该步的 k 本身。按计划 §6 的出口，这属于“局部 k 作用不足、真实 ΔD 或残差大”：报告其余状态 / 上游响应的条件依赖，不凭残差定位来源。
4. **C1343 的局部模式与另三个方向几乎相同（μ_k 配对 s_H 约 0.36，标“都不”），但它的新编辑臂没有造成行为损伤**（Rk、Ak、Rrk 48/48，Ark 47/48）。按计划，这否定“这种局部变化单独足以解释致错”。
5. **描述性差异**：随机 k（r_post）配对是“局部 J 主导”（t1、t2 的 s_J 约 0.76–0.84，前三方向），共同偏移 μ_k 的 H 份额明显更高（0.44–0.55 对 0.16–0.37）。也就是说，同样首读强度下，随机扰动主要改变 q·k 系数，共同偏移更多地改变了 S_prevᵀk 这一旧预测。这是相关描述，不是因果结论。
6. **与修复的关系**：在“修复 / 未修复 / 保持”各组之间，s_H 几乎没有差别（如 N4146：0.54 / 0.54 / 0.52），所以局部份额本身不区分哪道题被修好。强制前缀 t2 的分差 M：Rk 相对 V 上升 1.7–2.8，Ak 相对 F 下降 2.1–3.8，随机臂变化小。
7. 工程：C/T 哈希 = QCD G；前三方向 N 路线 token 与 t1 logits/缓存哈希 = QKF；C1343 的 V/F 完整回答 = QCO；捕获覆盖 14 层、接线逐位；预检有/无观察器逐位相同；重建误差预检 e_max 0.0035、正式 0.0037（阈值 0.0071）。

## 4. 对下一步的含义

- 共同 k 偏移在读出那一步的“瞬时”作用（换 k 本身）只占竞争步实际差的一小部分；竞争步的差主要来自 D 项，即 t1（以及编辑槽影响的后两步）写入状态后被读出。这把候选从“读出时的 k 计算”移向“k 改变了写入状态的内容”。
- 计划 §6 的后续二选一中，这更支持方案 ②（改 S 更新中的项，让更新后的状态自然读出），而不是方案 ①（只改当步核输出贡献）。具体替换哪一项、在哪一步，需要单独的预测卡与授权；本轮按合同结束。
- C1343 提醒：同样的局部计算变化可以不造成损伤，因此后续解释必须同时说明为什么 C1343 不坏。

## 5. 可以说 / 不可以说

| 可以说 | 不可以说 |
|---|---|
| 共同 k 偏移在 t1/t2 的局部作用中，q·k 系数项与旧预测项大致各半；预测的“H 主导”不成立 | k 修复靠擦除旧预测 |
| 竞争步的实际输出差约九成以上不能由“只换该步 k”解释，主要落在旧状态读出项 D | 残差来自某个具体模块 |
| 同首读强度的随机 k 扰动以 q·k 系数项为主，共同偏移的旧预测项份额更高 | 这一份额差是致错原因 |
| C1343 局部模式相近但无损伤，局部变化不单独足以致错 | 局部模式与致错无关 |
