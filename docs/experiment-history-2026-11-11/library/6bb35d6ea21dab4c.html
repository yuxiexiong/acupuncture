作者如何找到这些位置

Adde 提问后，Monkey 猜测可能依赖大规模扫描或运气。随后，作者给出了明确的方法回复：

  1. 使用 logit lens、steer lens，并绘制整个模型的神经元影响关系。
  2. 通过文本搜索和输入文本上的较大激活筛选候选神经元。
  3. 检查候选位置会推动哪些输出，再实际施加干预来验证。
  4. 作者自述每次神经元搜索约需2至5分钟。这不能理解为建立全部预计算和工具只需同样时间。

截图被截断的“向 Claude 礼貌地请求”只是该回复的开头，完整回复随后给出了上述流程。另一个作者回复展示软件并感谢 Claude，但这不能证明 Claude 在没有工具或检验的情况下直接猜中了这两个位置。

还有一条重要限制：作者回应 Yohei时说，如果某概念确实存在单神经元表示，自己能定位它；但有些概念涉及多个神经元或注意力模式，举例包括金门大桥、名字对应的代词归属，以及饮酒欲望。这里“能定位”是作者的能力陈述，不是对任意概念的完备性证明。

第三方复现报告与失败现象

Sal 的拒答与退化报告

Sal 的直接回复自述复现后，使用简单正则表达式统计的拒答率由94%降至12%，同时事实性大幅下降、退化性重复增加；其试验中 N8949 的正向干预主要影响拒答率。

这条回复未附足以复算的完整题集、代码和逐题输出。正则匹配的“不再拒答”也不等于回答有效或能力保持。可记录为有具体数字的第三方报告，不能与我们的结果合并统计。

Abhinav 的单神经元与方向比较

Abhinav 的回复声称，在 Qwen3.5-4B 上复现了慰问和奉承现象；其寻找的某个“幽默神经元”在剂量1开始编造事实、剂量2退化，而一个幽默方向仍能产生幽默输出。他由此提出，人格特征是否比幽默更局部的问题。

该帖没有给出那个幽默神经元的坐标、方向构造细节和充分对照，因而只能作为研究线索。其后续回复称已整理 Colab，但要求留言索取；本次没有发送留言或私信，也未取得该笔记本。

因此，评论区最值得带入后续讨论的区别是：语气或主题偏移、拒答变化、事实错误与生成退化可能同时发生，不能统一用 become evil 概括。这里是从评论提出的检验问题，不是对 Acupuncture 已收集语料的新评分。

作者与评论者指出的文献和工具

  1. 作者直接指出 CNA 论文。 有人询问能否改变拒答等行为，作者肯定回复并链接论文：Targeted Neuron Modulation via Contrastive Pair Search。论文提出用两组对比提示的激活差异寻找少量 MLP 神经元，并进行因果干预。它是作者给出的相关研究入口，不代表论文已验证这两个具体坐标。
  2. 有人直接质疑与 Persona Vectors 的区别。 Kassuno 的评论链接到 Persona Vectors: Monitoring and Controlling Character Traits in Language Models。该论文研究激活空间中的人格方向，涵盖 evil、奉承和幻觉倾向。评论没有附新的对照实验；这是需要比较的问题，不能据此直接判定二者相同或不同。
  3. Neuralese 是同类工具推荐。 0thernes 的评论链接 Neuralese。核查其公开源码说明和部署模型列表后，现成实现针对 TinyStories/GPT-Neo 的1M、3M、8M模型，而非 Qwen3.5-4B。它支持激活干预、归因及权重编辑，但不能直接使用本帖坐标。没有证据表明 lyra 使用过这个工具。
