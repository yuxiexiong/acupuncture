## 1. 原则与路线图

不把“单点不能代表总体”解决成“一次铺开所有维度”。先用最小实验判断问题、操作与读数是否值得继续，再逐步增加证据。旧数据可以作为探索证据和工具依据；复用不把它升级为独立确认。

| 阶段 | 要回答的问题 | 何时才设计具体实验 |
| --- | --- | --- |
| **当前轮：旧证据复用＋自然状态小桥接** | 不插针时，状态交换能否产生可解释的内容/规则来源变化，而非主要生成失常？ | 本文件只细化这一轮 |
| 下一轮候选：选一个最有价值的不确定性 | 时间保持、短卷积分量、混合不一致或读取过程，哪个最值得区分？ | 看当前轮结果后四选一或另提问题，不默认全部做 |
| 再后：局部机制检验 | 一个具体写入/保持/读取解释能否被反事实支持、预测留出结果？ | 前一轮提供可检验解释后 |

每轮都可在负结果或证据不足处结题。停止某个假说不等于否定所有缓存研究；不自动排队，不为挽救故事加剂量、换题或扩大扫描。广谱面板保留为远期备选，不是已承诺执行计划。

## 2. 为什么下一轮选这个问题

旧阶段二报告提供三条有用线索：全层固定点位的状态作用并不只来自一个层；L0 的真实未交付与 L12 等条件的阈下候选变化不是同一种终点；不同状态替换能产生不同效应。但它们来自人为激活干预，不能直接代表正常前文记忆。

因此下一轮不继续证明 L12 特殊，也不重新做全层插针。用原有 Qwen3.5-4B 与缓存工具，做一个自然前文的最小桥接：**内容能否跟随一种状态来源，规则执行能否跟随另一种来源？**

该问题承接最近邻已有结果，本轮主要是可行性、测量与研究入口验证，不是新机制贡献。结果若只是复现已知分工，也有价值：它使后续动态问题建立在可解释的状态操作上。若不能复现，要先查差异，不能直接称为反驳。

## 4. 本轮第二部分：一个模型、12 个情景、288 条续写上限

### 4.1 冻结对象与题目

只用原 Qwen3.5-4B 的精确模型 revision、tokenizer 与已核验实现。此次不施加 MLP 干预，不引入新模型或训练 SAE。模型身份仍须从原收据核对，不能只凭名称。

建议 **12 个基础情景**，三种模板结构各四个：直接键值、位置/关系查取、确定性规则映射。每个情景都有事实 F0/F1 与规则 P0/P1，形成四个自然前文 H00、H01、H10、H11。

例如前文给实体的代号，并规定代号对应的输出标签；规则表设计为四种事实×规则组合有可区分答案。三个查询分别要求：报告事实、报告规则、按规则输出。题目必须有确定真值，避免凭开放式人格评分判断机制。

同情景四个前文保持模板及 token 长度对齐，查询对各状态臂完全相同；不临时用语义填充补长度。使用不同措辞/结构，不只是十二次替换人名。程序真值校验与题面检查在运行前完成。

只有一个短上下文设置：**前文加查询不超过 512 token**，具体文本和实际长度写入清单。无长度、剂量、层号或时间间隔网格；不测试长期记忆。12 情景用于发现工程与明显测量问题，不支持总体规律或精确小效应估计。

### 4.2 只做近邻已有的粗粒度状态对照

本轮将递推与短卷积作为一个完整线性状态包 L，KV 为 K；不先拆三类八组合。所有对应层一并取供体，不选 L12。

对供体对 A/B 构造四臂：

| 臂 | KV 来源 | 线性状态包来源 | 作用 |
| --- | --- | --- | --- |
| AA | A | A | 正常同源参照 |
| BB | B | B | 正常同源参照 |
| AB | A | B | 混合方向一 |
| BA | B | A | 混合方向二 |

每个情景采用两个预定供体对：H00/H11、H01/H10。两对合计八个不同状态条件，包含四个自然状态和四个混合状态。两个对角方向降低事实与规则恒定绑定的混淆；仍不是完整的因素主效应估计，也不证明信息独占存储。

数量为：**12 情景 × 2 供体对 × 4 臂 × 3 查询 = 288 条续写**。正常供体只需 **12×4=48 次前文构建**；后续查询均用独立状态副本。

最多生成 128 新 token，沿用旧引擎解码设置并核实 EOS；只保存最终状态所需工作副本、文本/token、结束原因和基本来源记录。本轮不采逐层逐 token 全量轨迹、不做候选评分、不保存所有大型缓存快照。代码与完整题面足以重建供体；确需保留诊断张量时单列体积上限。

主查询使用相同的绝对位置和等长自然供体。不删除 KV、不改变查询起始位置。它是对近邻 state-swap 思路的小型桥接，不是对其全部 split-prefill 协议的严格复现。

### 4.3 工程预检与分段止损

预检上限 **12 次额外查询/续写**，使用独立、事先写好的工程样例。覆盖普通/分段前向、同源组装、深拷贝无串扰、K 与 L 的恢复路径、查询位置与管理字段。恢复状态影响检查必须在正式执行路径进行；容差按冻结精度/内核校准，不将自然弱效应误判为实现失败。

预检失败则不进入 288 条。失败保存，修复另版；不能无限重试并隐藏成本。

正式先运行四个自然状态：12×4×3=144 条。若任一查询类别的自然状态正确率低于 **36/48（75%）**，结束本轮、报告该任务适配不足，不继续花费剩余混合臂预算。该阈值只是当前 toy 的实用止损建议，非统计显著性或能力标准；需运行前冻结。

通过门槛后运行全部144条混合状态续写，不按某个情景的自然正确与否删题。全部12情景保留；不得看到弱结果后加题、加长度或换规则。

### 4.4 结果只回答什么

逐情景报告三个查询的答案，分类为：符合 K 供体、符合 L 供体、符合另一自然组合、其他错误、未交付/无法判断。执行题另报告是否与预定义的“事实来自某供体、规则来自另一供体”反事实目标相符，不一律按 A 答案判错。

必须把正常状态、两个交换方向、三个任务和全部情景同时展示。主表为原始计数和逐情景一致性，不使用数百条相关续写伪造大样本，也不通过显著性筛选宣布成功。规则/答案可程序解析；失败解析与矛盾回读原文，披露模型辅助或人工身份。

这轮不要求“精确检索一定归 K，规则一定归 L”。该方向是基于文献的参考预测，其他结果同样保留。也不使用“行为正确＝信息只存于某状态”的推断。

## 5. 预算：明确上限，不拿历史卡时猜新卡时

| 项目 | 本轮建议上限 |
| --- | ---: |
| 新模型 | 0 |
| 模型种类 | 1 |
| 基础情景 | 12 |
| 正式前文构建 | 48 次 |
| 正式续写 | 288 次；自然对照不适配时止于144次 |
| 额外工程查询/续写 | 12 次 |
| 新候选评分、层扫描、剂量扫描 | 0 |
| 解码 token 上限 | (288+12)×128=38,400；包括截断上限，不是预计实际消耗 |

前文、查询前向和模型加载成本另计，不能只用新 token 数当总成本。拿到新实现预检吞吐后计算完整预算：模型加载、前文构建、查询处理、续写与导出分别计时。

**额外建议止损线：新增模型工作最多 1 worker GPU 小时，含加载与预检；单 GPU、单 worker，不预占双卡。** 这是本轮建议预算，不是运行授权或一小时能完成的承诺。预检预计超出则先返回范围/预算问题，不自行扩额度或删一半条件后宣称完整；运行达到预算则安全停止并保留 partial，不自动续跑。CPU整理和人工/模型辅助阅读另记成本。

可复用旧供体代码与模型环境，但新自然前文没有历史同身份回答，不能把旧插针输出当本轮正常对照。旧数据缺档也不使用这份 GPU 预算重跑补档。

## 6. 本轮结束后才决定下一轮

| 当前轮结果 | 能得到什么 | 下一轮如何选择；当前不细化臂和题量 |
| --- | --- | --- |
| 自然参照正确、混合结果能稳定解释来源 | 工具和自然状态研究入口具有可行性，仍只是 toy | 选一个与近邻相比值得继续的问题，如延迟或干扰对分工的影响 |
| 结果有条件差异，但不全符合文献方向 | 获得候选边界或混淆线索 | 先选最便宜的判别对照，不马上跨模型 |
| 混合状态主要造成全面失常 | 当前操作不适合支撑功能解释 | 优先检验兼容性或换更局部的干预，不追层热点 |
| 自然状态也答不好/工程门槛失败 | 任务或实现尚不适配 | 修测量或实现，保留失败，不声称机制不存在 |
