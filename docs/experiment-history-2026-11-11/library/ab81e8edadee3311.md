## 4. 与最近方案的比较及修订

最近已交付的 S1 是缺口审查，不是运行合同。保留：DWB 无 k 去偏移的来源写入、可正常交付背景、完整选择终点、旧资产优先。新增：实际差值采集、四格重放、同源数值桥接、完整预算和预写退出。

本次内部审查排除了下列做法；它们不是已运行的实验版本：

| 被排除做法 | 具体问题 | 修订与重查 |
|---|---|---|
| 仅加一个干净背景 DO | 同供体在 C/H 中生成不同 v/k/β；阴阳差不能区分信号与响应 | 采集实际 delta 后交叉，重过 C02/C05/C08/C09 |
| 两条完整来源轨迹的最终 S 相减 | 已混入上游传播和旧状态处理，不能命名本次局部写入差 | 改为同一次层调用的同输入双 kernel 差；C05/C07 |
| 直接按 βkΔv 在 FP32 构造重放 | 代数相同不保证浮点 kernel 的原后状态；对角可能不等 | 保存两 FP32 后状态的 FP64 差、严格对角验收；C05/C11/C13；合成通过只证明示例 |
| 仅在 t1 结束后换持久 S | 丢掉 DWB 当步读取变化，无法桥接既有完整回答端点 | 每层同步重算当步输出和留存状态；C06/C08/E26 |
| 将背景对比叫“读取侧原因” | 其余状态、更高层和未来生成同时响应，排除法命名过强 | 改成接收运行总响应，并保留实质问题；C01/C02/C08/C14 |
| 只用配对和 .90 有效率就宣布排除损伤 | 少量无效输出也可能集中在正／负权重配对中，改变 D_tr 对比 | 加入线性权重极端填充敏感性；不加模型臂；C10/C11/C12 |
| 用旧 wall 按轨迹直接缩放为约 13 分钟 | 新分支可能生成更长，还多双 kernel、存盘和重复验收 | 32-token 上界、类别单价预检和独立硬超时；C12/C13 |

修订后仍回答同一局部问题，没有将失败候选改成“只要输出有变化就算成功”。

## 5. 最强反方检查

**反例 A：两份 delta 在高层已受各自早期供体注入影响，所谓“信号形成”是否仍混杂？**

是来源条件的整个联合产物，不能归因某个单层、β 或原生形成期。四格仍能回答同一组实际增量在另一背景是否保留效力，以及固定增量后的背景作用。已改名为“来源条件改变写入差值的效力”；不承诺独立语义编码或形成中介。边界不破坏当前问题；再拆层不会自动回答更重要问题，因此不增加扫描。

**反例 B：H 恢复过卷积，阳性只是混合状态现象，和原生受针失败无关。**

确实不能从这里推出原生停止原因。本卡连接的是论文已有可靠的可作答来源选择端点，检验其中一项解释缺口；NGC 阴性保留。若只允许完整自然全链，本轮会错误排除有价值部分机制；若宣称已解原生失败，则是硬伤，已在结论中禁止。

**反例 C：一份信号更大，四格就是简单剂量效应。**

可能。它仍是“来源条件改变了实际写入的行为效力”，但不回答大在哪里、为何变大，也不能宣称内容方向特异。另一类固定信号的背景差不会由两份信号大小不同单独解释。暂不加等范数臂，避免偷换成本和目标；若后续需要方向主张须另有依据。

**反例 D：交叉破坏模型，D_tr 降低被误叫无法利用。**

这是能破坏选择解释的实际风险。保存完整交付，在任一格低于 .90 时降为未定；剩余无效结果用最不利填充检验符号。若仍为完整有效回答而转移降低，允许报告该指定反事实的效力差，不能泛化成模型自然无法读懂这类信号。护栏不能证明反事实在自然分布上。

**反例 E：六场景足以得到任何想要结论吗？**

不能。采用配对场景重抽和共同区间，承认开发性精度、相关性及场景偏差；预先固定近零带与未定出口，不对不显著作同一性推断。强异质或宽区间可以让此次预算没有区分力；不能因此悄悄追加独立性不足的配对。

**反例 F：无论什么结果都能讲成支持。**

不成立：G 近零撤回本操作的“受针增强”解释；反向撤回简单强弱排序；交付差／宽区间即没有分清；工程失败不作科学推断。即使局部阳性也不保证论文升级成功，仍需后续范围和解释价值判断。

**反例 G：同源重放是构造保证，何必花预算？**

实数层序归纳不等于真实浮点、缓存别名和钩子顺序正确；若对角改变，交叉结果就不对应承诺对象。保留严格重放，是以有界重复成本买识别可信度。无需重复整个旧 SPF/DWC。
