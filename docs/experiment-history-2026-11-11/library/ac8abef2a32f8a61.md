## 0. 先要解释的事实

| 类别 | 已知结果 | 来源 |
|---|---|---|
| 强效 | Qwen 4B/9B 早层（L0–L2）+1 下大面积首步 EOS；问题依赖度崩溃；正负 ±1 都停 | 层调查、剂量阶梯、早层输入约束 C2 |
| 弱效 | 深层（4B ≥L20）+1 大多保持 8 种首 token；同剂量下写入相对残差变小 | 层调查、问题依赖度 |
| 反向 / 异质 | 同层同剂量通道间差异极大（9B L0：[0,8,8,0,8,0,5,0,8,8]；4B L2：[8,8,8,3,0,6,6,2,4,1]）；同一点剂量不单调（9B L0 N978：+0.25 停、+0.5 不停）；Llama 全层无首步 EOS，但早层问题依赖度也下降 | 层调查、剂量阶梯 |
| 不特异 | 4B L0 随机残差方向与原生通道分不开（CFM 跨通道）；层调查 4B L0 十个通道九个 8/8 | XCHAN、层调查 |

**关键约束（推导）**：调查里同层同剂量的写入范数相同。因此"层内通道差异"不能用幅度解释。4B L0 的"不特异"发生在饱和区（79/80），和层内有差异并不矛盾。

## 1. 候选 H1：幅度与位置（方向无关）

- **主张**：效应由写入相对于该层残差的强度决定；方向不重要。早层残差小（4B L0 残差约 2.1，L20 约 18.6），同样的 d·m 相对更大，所以早层更容易崩。
- **怎样解释三类结果**：强效、弱效可以；层内差异和 Llama 无 EOS 解释不了（只能归为噪声或模型差别）。
- **可失败预测**：层内通道之间没有系统差异，层内排序与任何方向量都不相关。
- **测量**：每层相对写入强度（已知）。
- **能否干预**：能，缩放剂量。
- **档位**：推导（层间部分）；层内部分已被现有数据强烈怀疑，作为必须打败的竞争者保留。

## 2. 候选 H2：写入方向对停止 token 的直接对齐

- **主张**：写入方向本身在 unembedding 上偏向停止类 token（EOS、`<|im_end|>`），经过残差直接抬高停止 logit。早层的写入在残差里占比大，这种直接偏置更容易胜出。
- **测量（静态，只用权重）**：s_stop(n, 符号) = 符号 × ⟨γ ⊙ ŵ_n, u_stop⟩，其中 ŵ_n 是 W_down 第 n 列的单位向量，γ 是最终 RMSNorm 权重，u_stop 是停止 token 的 unembedding 行减去全词表平均行。不跑模型，CPU 读权重即可。
- **怎样解释三类结果**：层内差异＝方向对齐不同；Llama 无 EOS＝其通道很少对齐 EOS，或停止 token 的 logit 底子太低（推测）。
- **可失败预测**：
  1. 层内通道排序与 s_stop 正相关；
  2. **符号不对称**：同一点 +d 与 −d 的对齐相反，所以只有一侧更容易停；
  3. 随机 token 方向的同样投影不该有这种相关（特异性对照）。
- **已知的不利证据**：4B L0 N4146 的 ±1 都停，和预测 2 冲突（推导）。H2 最多解释非饱和区。
- **能否干预**：能，把写入向量里沿 u_stop 的分量去掉（保持范数），预测停止消失；去掉同范数随机分量则不该消失。
- **档位**：推测。

## 3. 候选 H3：传播放大

- **主张**：方向决定扰动在下游被放大还是被吸收。被放大的写入在中层仍保持很大的相对差，并改写下游的读取；被吸收的写入很快衰减。
- **测量（离输出远）**：注入层到注入后第一个全注意力层（Qwen：L3/L7…；Llama 取注入层 +4），最后一个提示位置上残差相对差的增长比。来自已有轨迹的 `first_sites`，覆盖 2B/9B/Llama L0–L5 与 4B 全层。
- **怎样解释三类结果**：层内差异＝放大不同；深层弱效＝下游层数少，放大空间小。
- **可失败预测**：层内通道排序与增长比正相关；4B 深层（L6–L31）同样成立。
- **能否干预**：能，但需要新的钩子：在中间层把扰动按比例压回，看效应是否随之降低。
- **风险**：它可能只是"损伤已经发生"的伴随量。所以必须过第二段（干预）才算解释。
- **档位**：类比（CFM 里 L0 写入经深层放大的线索）。

## 4. 候选 H4：输入信息被压平，回落到默认输出

- **主张**：写入让各提示位置的表示向同一方向收拢，题目信息难以读出，模型回落到模板下"没内容时的默认输出"。Qwen 的默认是结束（`<|im_end|>` 或重开 `<think>`），Llama 的默认是模板回声。所以停止不是写入直接推出来的，而是信息丢失之后的默认。
- **测量（离输出远）**：注入层上各提示位置与写入方向的夹角。由 a=‖clean_i‖、b=‖steer_i‖、‖c‖=d·m 与 cos(clean_i, steer_i) 可解出 cos(clean_i, c)（10-28 建议 §5 的三角形公式），进而得到压平指数：提示位置平均被写入方向主导的程度。它随通道变化，因为写入与现有残差的夹角随方向不同。
- **怎样解释三类结果**：
  - 强效＝早层压平；
  - Llama 无 EOS＝它的默认不是 EOS（类比）；
  - 层内差异＝压平程度不同；
  - 正负都停＝压平和符号无关。
- **可失败预测**：
  1. 层内排序与压平指数正相关；
  2. 问题依赖度崩溃但不停止的通道（例如 9B L0 的"托托托"）也应有高压平指数：H4 预测压平先于停止，停止与否看默认 token；
  3. 在 |d|=1 的剂量点上正负对称。
- **与 H2 的分水岭**：H2 预测符号不对称、与停止 token 对齐相关；H4 预测符号对称、与压平相关、与停止对齐无关。
- **能否干预**：能，只改写入向量中沿干净残差平均方向的分量，改变压平程度而保持范数。
- **档位**：类比（与 Liu 2606.19831 的 cos θ 坐标、2602.02712 的 LN(±v) 极限是同一套几何，不是新机制；新的是它在层内通道上的预测力）。

## 5. 不列为候选的量

- **最后一层残差的余弦或相对差、首步停止优势、首步 KL**：离输出只差一步，预测得准是构造使然，只作上限参照。
- **一阶读出增益 g·ΔS**：同上。
- **跨架构差异**：只能检验迁移，不能说明原因，放到后续。

## 6. 三条最强的分水岭

1. **层内通道差异**：H1 预测没有；H2、H3、H4 各自给出不同的排序量。
2. **符号对称性**：H2 预测不对称；H4 预测对称。
3. **问题依赖度崩溃但不停止的通道**：H4 预测它们与停止通道同样被压平；H2 预测它们不对齐停止 token。

这三条都能在已有数据上检验，只需要先冻结候选量定义和计算代码。
