## 1. 当前决定

**主线值得继续，但下一轮计算须以补上输出连接为条件。最关键的缺口是把“实际注入的扰动—原生计算变化—显著行为变化”接起来，并判断缓存形成与使用在其中承担了什么作用。** 已有数据审查已经完成，不能再把它当待执行计划；也不默认进入更多替换实验或撤针后的事实传递实验。三阶段已经提供部分因果证据，尚未完成这条解释链。不能用“阶段已跑完”宣布完成，也不能把已有结果全部退回现象观察。

当前不把 S4 r1/r2/r3 的大矩阵列为默认下一轮。本文件不覆盖它们的历史记录，也不启动其中的 CPU 合成预演或 GPU 部分。

**总核心问题：局部、稀疏的激活干预进入模型后，经过哪些内部计算被传递、放大、抑制或改变作用方向，为什么最终会引起显著的回答变化？** 这里“放大”是待检验的可能性，不能凭输出变化大就认定内部存在数值放大。

| 层次 | 研究问题 | 撤针的地位 |
|---|---|---|
| 整个课题 | 局部激活干预为什么引起显著行为变化，模型内部怎样产生这个结果？ | 一种诊断手段，不是研究成立的前提 |
| 缓存机制线 | 当前扰动怎样改变历史状态的形成、更新与读取；这些变化在带针和后续计算中怎样影响回答？ | 帮助检查已有历史是否仍在起作用，不能代替带针状态的解释 |
| 前三阶段的具体问题 | 每步写入改变与旧信号保留、衰减、修正的改变，怎样影响状态、读取与输出？ | 既有协议的重要条件；其终点范围不自动扩大成总课题范围 |

缓存在针仍在场时就参与计算，不是拔针以后才开始起作用。相应地，当前干预的传播和历史状态的影响可能交互，不能预设二者可独立相加。研究对象是推理历史状态，不是永久权重记忆；停止行为也不能替代整个课题。

**还要先区分“少数坐标”与“小幅扰动”。** 对 down-projection 前的单通道加法，注入处输出变化为 δh = δa_j W[:,j]，这是线性层的已知关系。现有[控制引擎](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/early-input-control-v1-2026-10-29/control_engine.py)按干净参考残差尺度和权重列范数校准；名义 −1 在这套定义下对应参考尺度量级的目标输出扰动，不是“只改变了很小一点”。CFM 各运行仍须用其冻结代码与写入审计核对实际值，不能把目标值当每个 token 的实际相对强度。因此解释“大变化”之前，应核对实际扰动、暴露位置与输出终点，不预设稀疏针必然触发特殊放大机制。

S1–S3 的机制面板是 Qwen3.5-4B、两个历史锚点（L0/C4146/−1，L12/C3621/−1）、六个基础情景各两个事实版本。12 个输入不是12个独立情景；多层、多 token、多干预格也不增加独立情景数。项目其他模型的大规模效果调查不能算作这条机制的跨模型验证。

## 3. 最有依据的解释，以及它的证据身份

### 3.1 架构事实，不计作发现

按实际 key×value 矩阵方向，逐头的递推计算为：

\[
m_t=(\alpha_t S_{t-1})^\top k_t,\quad e_t=v_t-m_t,
\]
\[
S_t=\alpha_t S_{t-1}+\beta_t k_te_t^\top,\quad o_t=S_t^\top q_t.
\]

模型写入的是对旧关联预测的修正，不是把 v 原样放入一个独立槽位。m 是向量关联预测，e 不是回答错误标签。短卷积参与 q/k/v 的形成，读出再进入残差与后续层，并影响全注意力对 KV 的使用。该连接与公式属于已知设计。[固定源码](https://github.com/huggingface/transformers/blob/v5.20.2/src/transformers/models/qwen3_5/modeling_qwen3_5.py#L465-L477)

固定局部驱动时，旧差异可以按已有算子延续；当实际输入与驱动改变时，还会不断产生新的差异。因此不能把“状态有差异”直接解释为某个遗忘门变了，也不能把后续写入差异全部归于针仍然在场。[先验审计](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-mechanism-known-basics-audit-2026-10-31.zh-CN.md)

### 3.2 两份分析分别测什么，怎样合起来

连接分析测的是**同一输入在不同干预条件下的变化**，如11−10；事实分析测的是**同一干预条件下两种事实输入的区别**，如f0−f1。前者回答针怎样改变计算，后者检查这种改变是否伴随输入区分方式的改变。两个差分不是同一个对象，不能把前者的旧预测变化直接当作后者的事实损伤。

事实分析的ρ，是带针事实差向量在干净事实差向量上的投影系数；r是两者范数比，cos是夹角余弦。三者均不是信息保留率或正确率。全层缓存结果取自末态，L16–18的v/m/e/o分类则合并后段与末提示位置；不能把这些汇总当成一个token经过各层的连续录像。

### 3.3 目前最有依据的部分机制解释

**第一段：原针不能视为微小幅度输入。** 已核对的两个−1锚点，经down-projection列向量映射，注入常数对应的输出扰动范数约为各自干净参考残差尺度的1倍，早段重复16–28个位置、晚段27–33个位置。一个通道可以映射成高维残差方向，这是架构事实；本次新增证据是实际校准幅度与暴露次数。它撤销了“小扰动必然被异常放大”的前提，但尚不能解释为什么是停止、为什么不同层及前史反应不同。逐token加法后的实际差分没有保存，不能假报为精确实际剂量。

**第二段：它改变的不是一个静态残余量，而是后续计算轨迹；历史会改变同一针设置的反应。** S2每一对同起点比较的旧状态相同，首步已同时改变v及对共同旧状态的预测m。L16–18该步处理作用与加性写入变化相抵消，合成净状态差为单独写入差的0.80–0.95倍（四类比较合计范围）；因此“写入和处理同向放大”不符合这个观测窗口。跨前史比较，L0已有早段针时，后来同一晚段针造成的首步v绝对差异是干净前史下的1.68–2.70倍，m差异为2.66–4.51倍。这支持历史依赖的计算反应，不能据此独立分配两条路径的行为份额。

**第三段：输入区分方式发生改变，比“原事实被擦掉”更符合当前测量。** L0仅早段针的六个情景中，L16–18合并后段/末提示的v事实差，与干净差的cos为−0.0273至0.0306，范数比仍为0.409–1.955。准确含义是：两种输入仍产生不同数值，但这些差异几乎不沿原来的干净对比方向。这不证明事实信息完整转了方向，也不证明只是噪声。早段针改变了事实位置KV写入时的值；晚段针开始前形成的事实KV保持原值，却仍能伴随回答改变。因此，“把原有事实KV擦除”不适合作为晚段效应的解释；“形成、后续读取和计算条件改变”仍成立。两种时段不必共享一种故障。

**第四段：输出侧最强证据指向晚段卷积前V，但还没有接通完整自然路径。** 在同早段历史的11/10比较，L0停止优势增加15.70–17.64，首步EOS从0/12到12/12。S3撤除晚段V后EOS变为0/12；只保留V时仍为12/12。它证明指定全层替换条件下V有强输出效应。V在卷积之前，且操作覆盖所有相关后续层，不能等同于仅改变独立写入项，更不能把L16–18的某个数值直接叫作停止原因。在干净前史01/00的首步，L12的v相对变化比L0更大，却不对应更大的停止效应；L0更大的首步变化也不稳定对应更大的终点变化。这些反例要求解释**变化经过哪些计算进入了答案相关方向**，不能只解释差异变大。

合起来，当前最有依据的工作解释是：**有限幅度、反复施加的方向性输入改变了历史形成和后续计算；这些反应具有历史依赖，局部还有抵消与输入对比方向变化；其中晚段V相关计算已与显著输出变化建立条件性因果联系。** 尚未证实的连接是这些原生变化怎样被读取并传到最终答案竞争，而不是“有无缓存差异”。这里没有证成历史累积为主因、某种有害错配为根因，或所有大变化都由同一种机制导致。

### 可以写进当前研究总结的三个增量

1. **形成来源的证据增量：** 不只在末态交换缓存，而是用同文字的原生时序干预证明早段历史可继续改变后段实际更新，并提供同起点记录。来源：E2/E4。
2. **变量到行为的证据增量：** 针对既定上游干预，在内容 V、衰减 R、共享寻址/修正 K 上建立了有限强度的受控行为证据，L0 的 V 与首步停止联系最清楚。来源：E5/E6。
3. **解释边界的证据增量：** 同一实验链明确显示解除停止不等于恢复候选事实敏感度，状态引起的分数残余也不等于行为仍存在。来源：E3/E7及反例表。这是本任务的具体边界证据，不能独占“分数与行为不等价”这一常识。

尚未完成、但可能形成实质贡献的是：解释局部激活干预为何引起显著行为变化，并说明历史形成与使用在其中的具体作用；这一解释应能容纳不同时间条件和不同终点。撤针后的持续性可作为其中的验证条件，不能成为替代总问题的新颖性标签。不能把“三篇近邻各做一段，我们把流程串起来”自动当成论文创新。

### 与近邻有没有真正矛盾

- 与缓存功能分工论文：目前无直接矛盾。递推干预影响事实评分可以来自读取/选择变化，不等于证明递推保存可寻址事实。
- 与 WriteSAE：研究条件有区别，不是推翻其公式。固定局部驱动的传播与我们的下游驱动持续改变需要区分；我们尚未作同设置预测比较。
- 与 KV Cache Steering：问题互补。我们的持续影响与其一次状态干预的持续作用相容，没有方法优越性比较。

以上是定向比较判断，待研究者确认，不是独立审稿结论。其他近邻仍见[既有查重报告](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/literature/cache-mechanism-prior-art-2026-10-30.zh-CN.md)；未在本轮重新核查的条目不用于新增“我们超越了它”的主张。

## 6. 具体候选机制、可失败预测与下一步选择

本节按[HanLab总结的机制四步链与预测要求](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/HanLab%E7%BB%8F%E9%AA%8C%E6%80%BB%E7%BB%93.md)重写。总问题保持为“局部激活干预为什么引起显著回答变化”。以下是当前候选解释及其检验建议，不是已经完成的机制识别，也不是冻结运行合同。先前“只要补齐读取到输出轨迹就能推进”的说法不充分：记录必须服务于下面的可失败预测。

### 6.1 当前候选解释：内容偏置经历史形成和读出改变答案竞争

**H：针反复改变下游value内容；这些改变经过带有旧状态预测的更新，形成可被后续计算读出的内容偏置。旧状态及其处理方式调制这一偏置的形成和传递。显著回答变化来自这个偏置对答案竞争的实际作用，而不是旧记忆统一被擦除，也不能由局部差异范数单独解释。**

这段话包含三种不同证据身份：

- **已测事实：** 参考尺度量级的重复注入；同起点的v和m变化；局部处理作用部分抵消写入变化；前史改变后续有限差分；晚段卷积前V有强受控输出效应。
- **架构约束：** 更新同时使用v与旧状态预测，读出依赖当前查询；固定驱动下，当前规范化和门控对应的单头旧状态转移是非扩张的。这不约束整个模型的闭环，也不排除不断产生的新差异。
- **待验证核心：** 原生运行中确有一份由内容变化形成、被实际读出且推动答案偏移的信号；现有V恢复主要削弱这份信号，而非依靠另一套读取方式补偿。这一段不能从前两项直接推出。

用人话说，候选解释是：模型接连处理被针改过的内容，历史使后续处理发生改变，最终读出的东西把答案竞争推偏了。这里的“推偏”可能是偏向某个输出，也可能是压低其他输出；D增加不能区分二者。我们还没有证据命名一个EOS向量、宣称它跨情景相同，或说偏置会随时间单调累积。

### 6.2 为什么保留它，以及它尚不能解释什么

| 已有结果 | H给出的解释或约束 | 证据强度 |
|---|---|---|
| 少数坐标引起大变化 | 注入映射后的幅度已约为参考残差尺度，且重复作用；不必先假设微小信号异常放大 | 幅度和次数已核对；不能据此解释特定行为或方向的特殊性 |
| 同起点处理作用抵消部分写入差异，但最终仍可强烈停止 | 局部抵消不等于所有答案相关成分被消除；内容经过后续读取仍可能影响竞争 | 与H相容，尚未测出究竟哪个成分进入答案；不是已验证的答案方向解释 |
| 前史改变后续针的v/m反应，但首步更大不保证最终更大 | 历史参与形成后续内容；局部幅度不足以决定后续读出和输出 | 历史依赖已实测；具体选择/传递关系仍待识别 |
| 早段针降低事实对比分数但不首步停止 | 输入区分变化与停止偏置不是同一个读数；H不要求任何表征损伤都产生停止 | 反对统一损伤标签，但不证明两个独立机制 |
| 晚段针能改变回答，而此前事实KV不变 | 不必擦除旧KV；后续写入内容及其使用条件可以改变输出 | 排除“必须改坏旧事实KV才会出效应”，不区分内容与读取的贡献 |
| V撤除强烈改变停止，单独R撤除很弱 | 支持优先追踪内容入口；不能把衰减门α改变量当唯一驱动 | 条件性因果支持；V下游会改变其他变量，尚不能叫独立写入贡献 |
| L0/L12与不同前史的效果强弱不同 | H必须给出条件相关的有效读出解释，不能只按v范数或层号排序 | 当前尚未解释这些差别；它们是必须通过的反例，不是H已获证据 |

所以H比“都是缓存变了”具体，但仍是一条部分机制假说。它不能解释所有自由回答、针方向相对任意等幅方向的特殊性，或全部事实评分下降。已有六情景用于提出H，不再冒充独立确认集。

### 6.3 可被推翻的加强版本：内容变化能否预测原生读出

H的宽泛表述仍不能直接检验。先检验其中更强、并非已获支持的版本 **H_content**：

> 从同一个旧状态出发，原针引起的value内容变化，在参照运行的更新规则和读法下传播，就能近似预测受针原生运行的读出差异；不必依赖更新/读取规则的改变，才能形成这部分效应。

它不是“旧状态没有作用”：旧状态仍每步被预测、修正与读取。它声称的是**改变这些处理规则并非近似预测该效应所必需**。如果失败，就撤回这个简化，不能把旧状态处理称为微不足道。

S3中V强、R弱使这个简化值得检验，但绝不保证成立；K共享作用、S2中m变化较大，都是反对把它直接当结论的证据。最有依据的H骨架与风险较高的H_content加强版本必须分开。

### 6.4 用已有数据作有限幅度预测，不回填活模型

只使用已保存S2轨迹。每对分别为T/C=01/00或11/10，起点为晚段开始前；各对旧状态逐值相同。两种前史是同一问题的条件，L0/L12是已有强弱反例。观察范围仍为已有L16–18，绝不声称等于全模型。

先沿用实际key×value方向的更新函数：

`U(S; v, α, k, β) = αS + βk[v − (αS)ᵀk]ᵀ`，实际raw读取为`Sᵀq`。

构造两个**条件预测模型**，都从共同的真实起点开始，每步用自身预测的S继续递推：

| 预测模型 | 使用受针轨迹T中的量 | 使用参照轨迹C中的量 | 预测什么 |
|---|---|---|---|
| M_content | 实际卷积后的v_T | α_C、k_C、β_C、q_C | 内容变化在参照规则/读法下能形成的整段状态与raw读出 |
| M_rules | α_T、k_T、β_T、q_T | v_C | 更新/读取规则变化在参照内容下能形成的整段状态与raw读出 |

不在每步重新喂入真实S_T，不在首步后用原生状态重置；否则只是重新做分账。k和β在预测修正与写入中始终使用同一来源，不用调v保持βv，不把A/B当可独立交换的真实原因。M_rules把更新规则与读法合为一个竞争简化，因此若它胜出，尚不能区分旧状态处理与查询改变。

这两个预测世界不宣称自然可达，也不回填模型来制造行为。**验证对象是已经发生的原生T轨迹**：简化模型能否预测它，而非拼接后模型有没有异常。它们用的是已观测驱动，所以只是给定驱动的局部过程预测，不是从针参数独立预测v，更不是端到端回答预测。M_content与M_rules的预测不能相加成自然贡献比例；两者都失败时允许报告交互或遗漏，不能强行挑一个胜者。

检验整段原始−1效应，不用梯度、不缩小剂量、不拟合缩放系数。真实T完整重放仅作数值检查，重放恒等本身不算发现。

### 6.5 具体预测及否定结果

预测量统一为原生差异`Δo_actual = o_T − o_C`；比较的是预测差异`Δo_M = o_M − o_C`与它的方向、幅度、逐步演化和末提示读出。不是只看预测状态与T的余弦，也不把原生有变化当成功。

| 事前预测 | 支持它的结果 | 推翻或限制它的结果 |
|---|---|---|
| P1（H_content）：参考规则下传播观测内容足以近似再现原生读出差异 | M_content在整段及末提示位置都接近实际差异，且优于M_rules及“没有差异”的预测 | M_content只拟合首步却在后续失真，方向反转或幅度严重不符：否定此窗口的内容充分近似；不能再说旧处理/读取变化可忽略 |
| P2：内容充分近似不是仅某个前史下的巧合 | 同一无拟合规则在01/00和11/10都成立；无需针对已有早段针另调参数 | 只在干净前史成立：把解释限制于该前史，历史依赖部分仍需改变的更新/读取规则解释；不得用两背景平均掩盖 |
| P3：过程解释必须最终解释行为强弱 | 后续如能建立从该过程到回答的固定映射，它须预测L0/L12已有反例，并在未参与选择的情景上预测原剂量的输出方向/强弱 | 局部预测很好但不能解释原D差异或S3效果：只得到局部近似，不接受为“大行为效应”的机制；不把局部成功当上卡扩展理由 |
| P4（H的自然中介要求）：S3恢复应削弱原生效应中的同一输出相关作用 | 未来同范围的原生与恢复记录支持已定义的中介关系，且与行为同步变化 | 恢复只能由原效应中未出现的替代作用解释：撤回“该恢复验证原路径”的主张；仅保留条件性恢复 |

P1/P2是当前可以具体检验的预测；P3/P4是升级到核心问题的验收要求，当前未完成。旧情景用于假说发展，不能当独立确认。发现失败后重写模型属于新版本，必须报告原版本失败。

建议在任何新复算前冻结一个筛选规则：按基础情景、锚点、前史分别统计，整段和末提示的差异相对预测误差均≤0.25，且差异方向余弦均≥0.9，才叫该条件近似成功；小于重建误差分辨率的实际差异记不可判定。这些是拟议决策容差，不是统计显著性或自然机制阈值，也没有用新预测结果调过。逐层/头和逐位置误差须保留以识别抵消，不把它们算作独立样本。正式复算应先核定误差传播界、记录这些容差；不能看结果后放宽它们。本轮未执行该预测复算。

若两模型误差接近，不选胜者；若均失败，停止内容独立近似，不能笼统宣布“交互已证明”。若M_rules明显更好，仅说明这个包含处理与读取的简化更能重建该窗口，需要据具体误差决定是否值得继续，不自动扩成新的实验矩阵。

### 6.6 下一步判断：先尝试推翻内容充分近似，不追加恢复格

**下一步最值得做的是上述旧轨迹CPU预测检验，而不是立即补全模型记录或新增读取冻结条件。** 它直接问“改变写入内容是否已足够解释原针造成的实际读出，还是改变处理/读取规则不可忽略”。与S2账目不同，它要求简化机制跨多步预测未被强制设为真实值的状态和读出；没有恒等式保证通过。与局部敏感度不同，它使用原始有限剂量和完整已有晚段窗口。

这个选择有明确出口：

- **预测失败：** 撤回H_content，不再以“V有效”将旧状态处理/读取降为次要。停止为这条简化补GPU证据；保存失败发生的时段/层，但不自动追每个热点。
- **预测只在部分条件成功：** 交付有边界的局部解释；不改课题总目标，不宣称覆盖大行为变化。
- **预测稳定成功：** 得到一个具体、可复算的局部机制模型。此时才值得评估能否将它接到实际块输出和最终答案；必须处理门控、归一化、全注意力和MLP，不能拿raw读出直接乘最终词表权重。只有写得出回答层面的预测及原生/恢复一致性要求，才准备有限补测。

这不是拿近似预测替代因果证据。S3提供已有条件性干预证据，新的原生预测检验约束其解释；二者合起来仍不自动排除全部补偿。原来总问题中的最后一段——为什么这些变化对答案竞争如此有效——仍可能需要不同机制，但现在可以先低成本否定一个具体解释，而非在未知中扩展实验。

保留H作为当前候选，不宣布找到了唯一根因。也不把局部模型做得复杂到总能拟合：本轮不引入SAE、学习解码器、逐情景参数或新的层头搜索。该固定驱动近似的数学基础属于既有理论，潜在增量在它能否解释本项目原始上游干预的有限幅度过程及行为，不能把公式本身当创新。

## 7. 什么支持继续，什么结果该停

这些是研究决策出口，不追改 S1–S3 的冻结判据，也不在看完新结果后挑阈值。若进入正式验证，应在运行前把相应效应方向、误差容限与失败判据写成可执行合同。

| 后续证据整理得到的结果 | 决定 | 理由 |
|---|---|---|
| 某个从实际扰动到更新/读取及输出的关系，能解释其声称覆盖的原生时序、效应方向和强弱，并与已有干预及反例相容；同时对缺失连接给出可区分预测 | **继续该解释分支**；只补这个连接所需的最小测量/检验 | 支持继续的是解释力增加且有可失败的下一步；不强求一种机制包办停止与全部事实效应 |
| 校准显示稀疏操作本身施加了参考尺度量级的扰动，但没有额外证据表明存在特殊放大 | **停止“小扰动被异常放大”的叙述** | 大扰动本身不排除方向或历史机制；仍需解释为何出现特定行为，但不预设神奇放大 |
| 只有停止选择跨过边界，而可比连续评分变化较小，尚无内部增益证据 | **优先检验输出竞争解释，停止仅凭离散行为反差主张内部放大** | 候选解释仍须由实际分数和原运行支持；首步选择不能代替长回答解释 |
| 只能解释撤针后的历史作用，无法接到带针时的显著行为变化 | **保留为持续效应的子结果，停止把它当总问题已解决** | 持续性证据有价值，但不能替代模型对当前针的反应 |
| 区别主要在 value 进入更新前就改变，后续处理尚无额外解释增量 | **停止默认追“旧状态擦除”**，保留形成端候选 | 不为原先偏好的处理机制追加对照；仍须检验 value 的任务含义 |
| value 中的区别存在，但实际修正/读取表现不同，并能具体对应失败条件 | **继续更新—读取分支** | 这是相关计算位置的证据，不立即宣布事实被擦除；下一步只检验相应解释 |
| 局部区别仍可读出，最终候选评分却降低 | **停止把局部现象叫“事实存储丢失”**；先查下游读取/答案竞争 | 不能为了保住原解释改用更大范数或换投影 |
| 只有大幅度状态差异、恒等式闭合、显著非零或新的层热点；不同解释同样成立 | **停止增加该分支的GPU投入** | 没有新增机制区分力；保留“未识别”，不自动扩层/换头 |
| 恢复效果存在但只能在特定混合背景下解释，无法说明原生时序与已有反例 | **将其结案为条件性因果定位** | 不把补偿当万能解释，也不把恢复当原路径证明 |
| 相关工作已经给出同条件的解释，现有结果没有额外边界或预测增量 | **停止原创机制主张**；保留为复现/适用范围证据 | 不靠更换命名制造新颖性；课题是否转向须另作判断 |
| 关键测量不存在，且补测后仍无法区分解释；或区分所需成本明显超过预期认识增量 | **停止该方案** | 缺数据不是自动运行授权，也不是无限补实验的理由 |

停止的是具体解释、方法分支或原创主张，不自动宣布整个课题失败。若所有候选都只提供定位，项目就应以“现有阶段得到有边界的因果结果、机制尚未闭合”结案，而不是继续编号下一阶段。

## 8. 当前交付与不再重复的工作

当前可以交付：模型对干预反应链中，一套固定条件下的历史形成证据、停止行为的变量级受控证据、明确反例和测量边界，以及可恢复的实验资产。前三阶段解释的是链条中的若干环节，不是整个大效应的根因。
