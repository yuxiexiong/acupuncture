针对补偿与S/O失配的复审：当前解释上限

结论：补偿仍可能产生原始轨迹不会形成的变量组合与状态；S/O四格仍不能单独区分原始机制与拼接匹配反应。 r04保留对明确人工操作的受控效应定义，但不足以单独确证“原插针通过写入/旧状态处理及哪条自然历史路径造成异常”。不把下方完整网格视为已通过该科学充分性检查的待运行方案。

这里的“原始轨迹”指没有额外补偿、驱动钉住或末端拼接的C/T轨迹，不声称插针T来自训练分布。机制主张需要解释的是这些原始轨迹中的现象，而不仅是新操作后模型怎样反应。

1. 补偿解决了方程一致性，没有解决联合分布与原现象归因

βv保持不变确实保证：给定k时加性写入项不变。这一点没有推翻。在卷积后递推入口替换value、且该值仅用于递推的条件下，也不能简单把“value变大”当作额外独立通路：理想实数计算仍由目标A、B决定。实际浮点乘减误差另须验收。

但α、β、k、v原本由同一隐藏轨迹及卷积历史生成。拼入β_r与p_w/β_r，只保证局部更新式可执行，不保证它们能由原C/T的共同输入产生，也不保证形成的S与查询、卷积及其他缓存相匹配。全过程钉住来源驱动又取消了一部分原模型的适应关系；完整运行P是修改后程序的一条一致轨迹，不因此成为原始C/T动力学的自然样本。

一个CPU合成反例：设旧状态为1、α=0.8、k=1，原轨迹族始终v=1、β∈[0.2,0.4]。新状态在[0.84,0.88]。保持原p=0.2、把β换成0.4，需要v*=0.5，得到S=0.68。更新式完全正确、没有溢出，但状态已超出这个原轨迹族的范围。

该反例证明“代数一致⇒原轨迹支持”不成立，不证明Qwen实际混合状态已经分布外；当前缺少真实内部轨迹，不能作后一断言。反事实状态未出现过也不自动使实验无效，限制的是把该实验效果外推为原始成因。

2. 四格测得替换反应，不会自动鉴别失配

Y10−Y00确实是固定O时替换S的受控效果；Y01−Y00及交互同样有定义。但其中可以包含状态与读取条件失配产生的响应。失配也是模型的真实反应，区别在于它可能由我们的拼接造成，而不是原插针产生异常的那段机制。

新增反例比较两个读出函数：

[ F_{joint}(s,o)=\min(s,o),\qquad F_{match}(s,o)=o\max(0,1-|s-o|). ]

前者为联合限制，后者为O内容读出乘以一致性门。在四个角点(0,0)、(1,0)、(0,1)、(1,1)上，两者完全相同：0、0、0、1；在所有对角线s=o∈[0,1]上也相同。四格及原配对端点不能区分这两种函数；它们在其他点并不相同。

这说明“只有联合格有效”不能单独认证自然协作，而不只是提醒置信区间可能很宽。它不证明Qwen确有显式一致性门，也不否认四格差值的受控因果意义。联合计算与匹配要求在真实模型中也未必互斥。

上一轮合成检查只验证了预选的S-only/O-only/joint等函数可被四格区分，没有纳入能给出相同四格的匹配反应模型。因此不能把它称为排除失配的设计验收。

4. 如何使用这版，而不是又换核心问题

保留补偿和四格作为有明确解释边界的辅助机制探针。先从原始C/T轨迹提出需要它检验的具体机制预测；如果某种原始轨迹上的变化根本没有发生，对应过程叙述就不能成立。反过来，发生过变化本身也不是充分因果证据。

要把探针效果上升为原机制解释，还须有不依赖同一补偿/拼接构造的证据：例如对未额外拼接轨迹的事前状态/读出/行为预测，或不同干预定义下具有可解释的一致结果。必须说明候选机制与失配解释分别预测什么，不能把“多加几个对照”当自动认证。距离小、范数正常、双向有效或随机对照无效，都不能单独证明自然合理性。

这不是要求所有反事实都来自训练分布，也不是否定状态干预方法。当前缺的是把新操作的效应可靠连接到原始异常的形成原因的证据。中心问题保持不变；不启动下方全量网格，不在本次复审中另造一版更大方案。

新增反例代码及结果只使用Python标准库和合成标量，未运行模型。原合成检查与原结果完整保留。方法风险与Activation Patching原论文§6讨论的分布外干预问题一致；该论文不是当前Qwen实际失配的证据。

1. 中心问题、可回答的量与事先声明的边界

原干预怎样改变每步写入，以及旧信号的保留、衰减和修正；这些变化分别或共同怎样影响撤针后的回答？

本版分开两个相连的因果问题：

  1. 在同一共享key序列下，改变实际加性写入、或改变完整旧状态处理系数，会形成什么具有行为作用的末端递推状态？
  2. 这些过程造成的作用，经撤针时的目标递推状态承载，还是已在前缀期间传入其他缓存？两者是否必须共同改变才出现效果？

这次每个问题都有同一输出终点上的受控比较。它们识别的是指定key条件、来源轨迹和撤针边界下的受控过程与通道效应，不是无约定的自然贡献百分比。key方向同时参与修正与写入，它的作用单列为共同部分，不能强行归为其中一边。这个边界在实验前确定，不作为结果不理想后的改题理由。

若要求把所有key变化也唯一分成两份，同时保证每一步仍是原更新规则，一般做不到：修正方向与写入的key方向受同一变量约束。r02已给出反例。本版对该部分报告联合效应及交互；除此之外，不再用value或衰减门代替完整过程。

2. 用实际写入量分离过程，而不是只换value/衰减门

原规则采用key×value方向：

[ S_t=\alpha_t(I-\beta_t k_tk_t^\top)S_{t-1}+\beta_t k_tv_t^\top. ]

定义实际加性写入的value侧向量 (p_t=\beta_tv_t)，仅改变参数表示：

[ S_t=\underbrace{\alpha_t(I-\beta_t k_tk_t^\top)}{A_t}S{t-1} +\underbrace{k_tp_t^\top}_{B_t}. ]

在固定k下：

  • 写入因素W： 改p，固定α、β，因此整个A不变，B改变；包括原β对写入幅度的影响，不再只比较v。
  • 旧状态处理因素R： 改(α,β)，固定p，因此整个B不变，A的衰减和沿当前key的修正强度均改变，不再只比较α。
  • 共享方向因素K： 改k，且在A、B中同步使用；其影响归为共同部分。

β共享怎样保持一致

组合使用β_r与p_w时，实际传入原递推的value为 (v^=p_w/\beta_r)。这样同一份β_r仍用于修正和写入；只是同步补偿value，让 (\beta_r v^=p_w)。例如β从0.2改到0.4、要保持p=0.6，value就从3改为1.5。

这是一个明确的联合控制操作：为了只改变旧状态处理，补偿写入量，而不是宣称β天然只影响旧状态。 不能把所得效果解释为单独β节点的自然效果。

若实际存储β为0且目标p非0，该组合不可实现；停止该配对，不加epsilon、不截断、不改题。β很小造成溢出、不可接受的补偿误差时同样停止；记录原值、有效value和误差。合成实数验证不替代BF16及真实内核验收。补偿value可能超出原轨迹取值，须披露；“原规则可执行”不等于自然分布内。

3. 固定对象与切断时刻

保持原Qwen3.5-4B固定revision 851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a、权重、校准、剂量、BF16/eager、模板及解码设置。锚点仍为L0/C4146/−1和L12/C3621/−1；目标为组4的L16–18全部递推头，不扫新层、头或通道。

输入沿用VAR01、VAR02、VRD01、VRD02、VRL01、VRL02六旧情景，各两事实版本，共12输入；不是独立新题验证。C/T均处理相同token序列。固定切断时刻τ为prompt[:-1]处理完成后，最后提示token尚未读取。

τ处将完整有效推理状态分成两份：

  • S： L16–18的递推矩阵。
  • O： 其余全部持久状态，包括上述层的卷积状态、其他递推状态、所有KV。位置、mask、长度、初始化标记等管理字段完整审计并保持同一固定前缀身份。

τ之后不再插原针或过程钩子。统一读取程序记为 (F(S,O;x_{last}))：从该完整状态读取同一个末提示token，得到同一输出读数。计算函数与设置固定，当前查询和下游计算正常响应输入状态。

这里阻断的是τ之前形成并保存的历史路径，不是冻结τ之后所有计算。 后者会把状态影响输出所必需的读取也切断。首步logit是最清楚的主要终点；候选评分和自由生成分别标明包含τ后的持续计算，不声称已分解其内部每一条路径。

4. 第一组对照：真正隔离写入与旧状态处理

4.1 来源与八种状态

取得未经额外过程修改的C/T原轨迹，保存每token、每目标层/头的α、β、归一化k、v，计算p。0表示C来源，1表示T来源。

对每种(w,r,k)∈{0,1}³，从零初态递推：

[ S_t^{wrk}=\alpha_t^r(I-\beta_t^r k_t^k(k_t^k)^\top)S_{t-1}^{wrk} +k_t^k(p_t^w)^\top. ]

同一步只有一份key和β。八种配置覆盖W、R、K的全部条件组合；这是对三个明确因素的比较，不恢复旧组前/组后八组合方案。

每条系数序列取自预先记录的来源。前缀内状态/读出变化重新改变目标层的后续写入或旧状态驱动的路径被阻断：这正是本组的控制条件，不能再称其为完整Live轨迹的自然效果。

4.2 同一终点读取

每个S_τ^{wrk}分别与原O_C、O_T配合，读取同一末提示token，记为Y(w,r,k;b)，b是读取背景C或T。

比较 保留的路径 阻断的路径 识别的作用
固定r、k、O_b，只变w p变化→目标递推积累→τ末端S→统一读取 p变化再改变目标α/β/key序列；前缀输出改变O 在该key/旧处理/背景下，写入量改变经末端S到读数的作用
固定w、k、O_b，只变r 旧状态算子变化→目标递推积累→τ末端S→统一读取 算子变化再改变目标写入量p/key序列；前缀输出改变O 在该key/写入/背景下，旧状态处理改变经末端S到读数的作用
固定w、r、O_b，只变k 同一key同步改变修正与写入→S→读取 重新改变p、α、β序列；前缀输出改变O 共享方向的共同作用，不能独占归为写入或修正

关键区别：这些比较在整个前缀序列上固定另一个过程的驱动，不只是当步影子对照。结论的终点也是模型输出，不是把状态范数当回答。

分别报告ΔW(r,k;b)、ΔR(w,k;b)、ΔK(w,r;b)及条件交互；不跨背景平均后宣布唯一主因，不按范数或参数改动幅度给机制排名。S^{000}、S^{111}应分别重建原S_C、S_T，是工程验收；其混合配置是否改变输出是实测问题。

5. 第二组对照：补齐“效应留在S，还是经前缀传到O”的路径

第一组有意阻断前缀其他状态变化。为了检验它遗漏了多少作用，对两个核心过程W、R都补同一套路径对照；不看结果选择只补某一边。

5.1 构造完整过程轨迹P

对接收背景b（C或T），供体d为另一来源：

  • P_W：每一步固定使用p_d、(α_b,β_b)、k_b。
  • P_R：每一步固定使用p_b、(α_d,β_d)、k_b，并用补偿value维持实际写入量。

在完整模型前缀前向中，将目标递推驱动钉在上述序列；q、z、残差及其他层按当前轨迹计算。目标状态可影响其他状态O；O或上游hidden再改变目标驱动的回路仍被上述钉住操作截断。固定token条件下不存在逆向写回上游层的假设；被截断的实际跨层边以源码为准。

因此P_W/P_R的目标末状态必须分别等于第一组对应S。这个一致性证明两组测的是同一个受控过程；不一致则停在工程层，不能用两组不同操作拼接归因。

5.2 在τ处做四格，明确实际阻断

令原接收轨迹为(S_b,O_b)，完整过程轨迹为(S_P,O_P)。四格统一用同一个F：

格 输入完整状态 保留什么 在τ处阻断什么
Y00 (S_b,O_b) 原接收背景 两类过程造成的历史变化都不保留
Y10 (S_P,O_b) 过程→末端目标S→读取 撤销过程在其他缓存O中留下的变化
Y01 (S_b,O_P) 过程→前缀层间传播→其他缓存O→读取 撤销末端目标S变化，但不撤销它此前已传出的历史后果
Y11 (S_P,O_P) 两类历史通道共同保留 不做末端通道阻断；即完整受控过程结果

Y10已在第一组计算，Y00为原参考。每条P只需新增Y01、Y11读取。不能用“总效果减单步状态差”代替这些交叉格。 两个交叉格仍是人工状态拼接，只支持所定义背景下的通道对照，不自动认证自然中介唯一性。

报告：

[ E_S^0=Y10-Y00,\quad E_O^0=Y01-Y00,\quad I=Y11-Y10-Y01+Y00, ] [ TE=Y11-Y00=E_S^0+E_O^0+I. ]

同时报告另一背景下的条件效应Y11−Y01、Y11−Y10，不把交互偷偷分给某一路。这里的“直接/间接”改用更准确的名字：末端S通道、其他历史O通道、二者交互。 不声称S通道绕过读取，也不把O通道等同某个特定KV层。

这与旧四格的增量在于：供体P由一个严格隔离的写入或旧处理过程形成；因此可以把过程因素与承载路径连接起来。旧整块C/T交换只说明状态组合的作用，不能给出这个过程来源。

状态/局部读出改变但Y无变化 找到形成关系，未建立该行为终点的效应 不自动扩模型、改剂量或换问题

所有判断先于看新结果定义；报告连续效应、逐题反例与数值误差，不把六情景“不显著”写成排除机制。此设计能区分上述受控解释，不承诺一次实验消除所有分布外或自然中介歧义。

7. 同一个输出终点与真实回答

主要终点为末提示token后的原始logit差及原D、首步EOS；固定比较token取同题原T最高EOS与原C最高非EOS，来源ID在新增干预前锁定。它不受后续生成文字反馈影响。

原候选逐token评分与两事实S仍保留，用target_index定向。它测固定候选序列的响应，包含τ后的动态计算，不冒充首步纯读取。真实回答仅对W/R路径四格做原greedy、128新token；核心跟随、矛盾、题面改写、未交付与截断分别盲读，披露模型辅助来源。其他因子格只报告logit/候选终点，不称实际作答能力变化。

L0与L12都执行同样的核心成对比较，不随哪一个结果漂亮而缩成只解释EOS。不同终点不合成单一成功分数。
