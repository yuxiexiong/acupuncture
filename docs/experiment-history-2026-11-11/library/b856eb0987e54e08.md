# NFC-01（原生首步竞争：逐段链条与 B4 分支）合同 r01

日期：2026-11-02。设计：[计划 v1](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-native-first-token-competition-plan-v1-2026-11-02.zh-CN.md) + [v2](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-native-first-token-competition-plan-v2-2026-11-02.zh-CN.md)（v2 覆盖 v1 的主资产排序、主对应尺度与出口）。授权：用户 2026-11-02「如果你觉得OK的话，直接写合同，写代码，测试，然后上卡直接跑」。**零模型调用、零 GPU**；已见数据上的探索性再分析。

## 1. 数据与接头

B3 正式运行（f2ad7d8）与 B4 正式运行（c9ab385）的 records，逐个按 receipt 核对哈希。12 输入 × 4 方向（48 个方向×输入配对，不是独立样本）。闸门（任一不过即停止，记合同执行失败）：B3 的 N:TT 与 T_native logits 哈希逐条相同；B4 的 C_native、T_native、CC、CFIX 与 B3 的 C_native、T_native、N:CC、N:CFIX 逐条相同；B3/B4 的 a_token 相同，且等于 C_native 的非停止赢家；C_native 的停止赢家属于 S = {248044, 248046}。

评分身份：评分函数断言评分时不得残留任何形成期 hook（bridge.py 第293行），B3/B4 都经由此函数评分，所以 T_native 是“形成窗口注入后留下的历史状态 + 干净评分步”。

## 2. 读数（plan v1 §3）

每格从记录精确重组：D = max_S z − max_{V∖S} z（readout.D，全词表），s0、q0 取自 C_native；F = z(s0) − z(q0)，A = max_S z − z(s0)，B = max_{V∖S} z − z(q0)，D = F + A − B。交叉检查：|D − 记录的 stop_advantage| ≤ 1e-6；D 的符号与首步是否停止一致（D=0 单列平局）。全词表张量用于：核对存储的 logits 与记录一致（s44/s46/a 逐值相等，D 误差 ≤1e-6），以及中位数参照列。

每条边 u→v：ΔD、ΔF、ΔA、ΔB；ΔF 的两侧拆分 S_b = Δz(s0) − b、Q_b = −(Δz(q0) − b)，b 取词表均值差或 Δz 的中位数；均值列来自记录，中位数列来自张量。只描述两种参照下符号是否一致，不给“哪侧主导”的科学标签。

## 3. 主表：逐段链（plan v2 §2）

C_native → N:CC → N:CFIX → N:CT → N:TT（= T_native）：e1..e4 与 δ_native = e1+e2+e3+e4（恒等式只作实现验收）。逐输入报告各段的有符号值、端点 D、赢家与首步状态、|e_i|/Σ|e_j|（分母 ≤1e-6 不可判）、最大绝对段、首步翻转所在段、非停止赢家改变所在段。e3 用 CREST 格写成 R_D + I_D，**不称负交互**。固定顺序，结果是条件分账，不是中介份额。

辅助：δ_FIX = e2 与 δ_native 的 v1 分档（|δ|<0.5 为小；同向时 |差| ≤ max(0.25, 0.25|δ_native|) 为接近）；B4 分支 CFIX→K、M_nat、M_rand 的 ΔD/ΔF/ΔA/ΔB。

汇总：f0/f1 同标签才计情景；≥5/6 情景为方向标签；≥3/4 方向为跨方向标签，否则为条件依赖。

## 4. 预注册预测（推测档，运行前写入）

P1：最大绝对段的跨方向标签为 e1（C_native→CC）。依据：CFM-E2 中第13–31层缓存可承载 75–94% 的停止优势，而 e1 同时改变深层状态与入口。e1 大也不能单独归因于深层状态（它是复合转换）。

## 5. 出口（plan v2 §6）

e1 占多数 → 撤回“δ_FIX 不接近 δ_native 就否定对应关系”的判法，先列清 e1 同时改变的变量，不自动去拆深层；e2 大且同向、后段抵消 → 保留 FIX 条件结果，不称原生必要性；后段或赢家替换大 → 只报告条件转换与身份变化；多段混合或条件差异 → 报告分布式；接头或资产失败 → 限定可报告对象。只有读数形成可被后续操作推翻的具体预测，才另立下一个实验。
