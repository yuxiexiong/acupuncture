# CFM-LOCAL-READOUT v1 结果报告

日期：2026-11-01。方案 [r3](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-local-readout-causal-plan-v1-2026-11-01.zh-CN.md)；[合同 r01](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-local-readout-causal-v1-2026-11-01/CONTRACT.zh-CN.md)；[决策日志](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-local-readout-causal-v1-2026-11-01/DECISIONS.zh-CN.md)。代码提交 227cd54；freeze-r01 sha256 `099f1e4e…cebf`（122 文件）。同一助手完成实现、运行与本报告，不是独立复核。

## 1. 结论（坏消息先说）

**按冻结判据，两种背景下删除第13层旧状态×读系数交互 I 都是“弱”，删除该层全部局部 S/F 变化 J 也都是“弱”；不作背景依赖结论。**

- **原生后半段 N：** 删 I 后 D 变化每情景 ±0.031 logit（逐输入只取 −0.0625/0/+0.0625，即 D 在该量级的分辨率台阶），正 2/6、负 4/6；针效应尺度 G=17.5–20.0。删 J 也只有 −0.125 至 +0.188。8 个原生首步停止的输入，删 I 或 J 均无翻转。
- **统一浅层 M：** 删 I 使 D 每情景降 0.16–0.59（6/6 同向），但只占针效应 2.5%（中位数，阈值 0.05），且只在 2/6 情景超过两个同幅随机方向（随机 |δ| 0.06–0.81）。删 J 降 0.09–1.56，中位比 4%。唯一的 EOS 翻转（VRD04-f1）来自随机方向 Q0，不来自 I。

**按方案 §8“δI 和 δJ 都小”分支：** 在其余有针历史固定的单层、单步反事实下，第13层这一位置对首步停止竞争不敏感，或其作用被下游补偿/冗余吸收。**撤回**“第13层该交互是原生停止效应的承载项”这一候选；**不能**据此说整个 S/F 机制无关，也不推出效应分布在多层（集中在别处、抵消、冗余仍无法区分）。按项目 6.7，这是执行正确、假设在其适用范围内被否证的**科学负结果**（N 背景测量分辨率约 0.06 logit，相对 G≈19，否证是紧的）；不是合同执行失败。

## 4. 局部分量（core 空间描述，不是端到端分账）

| 背景 | ‖I‖ | ‖J‖ | cos(I, A_S+A_F) |

原生入口下该交互本身只有混合背景的约 35%，且不再与两个单独变化反向。描述层面：M 中看到的“交互×抵消”结构依赖统一浅层入口，原生入口下并不出现；但两背景删 J 的终点效应都弱，局部结构差异没有转成可观的终点差异。不据此命名任何机制。

## 5. 可以说 / 不可以说

| 可以说 | 不可以说 |
|---|---|
| 第13层评分步该交互的单独删除，对原生评分后半段的首步停止竞争没有可分辨作用 | 交互在自然运行中不参与、或 S/F 机制无关 |
| 第13层全部局部 S/F 差的单独删除，在两种背景下终点作用都弱 | 效应已证明分布在多层 / 集中在某层 |
| M 中 δI 方向一致但量级小、与同幅随机扰动不可区分 | M 的阳性方向是该交互的特异作用 |
| 原生入口下第13层交互更小且无 core 内抵消（描述） | 浅层“放大”或“产生”了这一交互 |

## 6. 下一步约束（方案 §8.1 后续决策，不是运行授权）

- 不自动扫层、不加剂量、不加随机种子救假设。
- 若要继续沿“深层 S/F 怎样把针效应送到输出”推进，需要先由已有逐层证据提出能区分“集中在别处 / 冗余 / 抵消”的比较，并明确多层扣除用原轨迹预计算项还是干预后重算项；本轮结果说明“单层第13层”这一最可识别位置不是承载点。
- CPU 预演与本轮张量（服务器 `runs/*/worker-*/tensors`，约 150 MB）已含第13层 gated-norm、out_proj、decoder13 出口与最终残差，可零 GPU 描述删项后的变化在进入后续层前是否已被抑制。
