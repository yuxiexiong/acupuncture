# B3-P1：第13–18层主效应对齐的建立过程

版本 v1，2026-11-01。状态：设计及同一助手自查完成；未实现、未运行，未授权新模型/GPU运行。此次授权范围为设计、自查、提交 GitHub。

## 1. 目的与证据身份

主问题保持不变：稀疏激活干预如何改变历史状态及后续读取，最终造成显著回答变化。本轮研究其有限环节：在已有 N 混合背景中，两组 V 历史分别造成的表示变化，怎样在第13–18层逐步变得同向？不能把停止读数等同完整回答机制。

B3-P0（结果 9c83b9a）发现：终点平方范数交互的正贡献来自两组主效应对齐，向量交互贡献为负；单分支候选未通过。本轮接受这一退出，不重选第31层、不放宽旧门槛。

23:16反馈另报告：沿共同基线 c 的径向分量仅承担对齐项的4%–11%，剔除后 FIX 余弦仍为0.70–0.77。本设计接受其为作者补充探索证据；该补充尚未在本次从原始张量独立复算。已发表的 B3-P0 JSON、报告及代码已核对。径向结果的复核只作为工程入口，不再立为新的科学实验。若复核不符，暂停并解释，不静默改题。

本轮增量：区分“同一步两组分支增量彼此对齐”与“增量主要对齐另一组已经积累的变化”，并检验对齐增长在 mixer 与 MLP 步骤间的分布。比只画逐层余弦多一项有边界的认识；仍不等于找到计算起源或因果中介。

## 2. 固定面板与范围

沿用 B3 的模型、revision、剂量、token位置和 N 背景定义，直接读取已记录的同条件运行，不再生成数据。实施 manifest 必须引用 B3 合同与 receipt 的完整模型 revision、token位置、输入和切分哈希，禁止仅凭本方案简称重新构造运行。

- 四方向：N4146、N1210、R0、R1；六情景 P01–P06，每情景 f0/f1 配对事实。
- 三切分：固定45头 FIX、已冻结 U1/U2 及各自补集，不重选、不追加随机切分。
- 四格：00=N:CC；10=仅 A 组 T 的 V 历史；01=仅补集 B 组 T 的 V 历史；11=N:CT。所有其他运行条件按 B3 固定。
- 0-based 第13–18层，按真实顺序每层 mixer 后、MLP 后，共12个更新步骤。第15层为全注意力，其余为 G 层；报告中分开标注，不能把整个区间都称 G 写入。
- 主估计用00/10/01；11用于保留向量交互和既有四格结果的一致性，不将它混入主效应方向定义。
- 4×6×2×3=144 个配对切分单元，实际独立情景只有6个；方向、事实和随机切分均非独立重复。共享格只读一次。

第13–18层是根据已见轨迹选定的探索窗口，不是预先无偏定位。其后层不在本次分析范围，不因失败扩大窗口。

## 3. 操作与精确估计对象

只读取 CPU 旧张量，无权重加载、模块重算、模型前向、缓存修改或 GPU。以每个单元第13层输入为起点，核对四格入口相同。

每一步取实际残差增量 δ_s=h_after,s−h_before,s；在原始 BF16 运算记录确认后转 FP64 相减。不能以裸 out_proj 输出代替实际增量；舍入差 δ_s−module_out_s 单列。a=h10−h00，b=h01−h00；α_j=δ10,j−δ00,j，β_j=δ01,j−δ00,j。

主账目 C_j=2⟨a_j,b_j⟩，精确逐步分解：

ΔC_j = 2⟨α_j,β_j⟩ + 2⟨a_before,β_j⟩ + 2⟨α_j,b_before⟩。

三个有符号项分别为同一步增量配对、新 B 对已有 A、新 A 对已有 B。前者大不能自动解释为独立直接写入：α、β 本身已包含上游输入与各自历史的影响。后两项不得遗漏，否则可能把跨层对齐误记给同一步。

辅助闭合表 M_ij=2⟨α_i,β_j⟩，12×12；Σ_ij M_ij=C_end（入口 a=b=0）。按 mixer/mixer、mixer/MLP、MLP/mixer、MLP/MLP 汇总，仅作固定分类，不从144格挑最大格当候选。保留矩阵不对称性与符号，不将其称为路径因果份额。

### 3.1 去共同收缩的账目

采用每个单元第18层00输出 c_end 固定定义 P=I−eeᵀ，e=c_end/||c_end||；将所有 a、b、α、β 同时投影再做上述分解。固定投影保证逐步求和闭合。此轴使用了区间终点，属于回顾性几何分解，不是前瞻预测。

另报告各层自身 c_j 下的径向/切向余弦供描述；禁止把这些随层转动的投影下的差值相加当精确来源账目。主文同时报告原空间和固定投影空间，不能只选较支持的一个。

共同收缩须 a·e 与 b·e 均为负。终点沿 c 的部分小不代表沿其他已知读出方向也小；c 方向与停止读出方向不混同。

### 3.2 最小读数表

每步报告：||a||、||b||、a·b、cos(a,b)、||α||、||β||、cos(α,β)、ΔC及三个分项；原空间和固定 P 空间各一份。余弦只作角度读数，贡献用内积计量，不因大余弦而忽略接近零的幅度。

不做只看均值的结论：逐事实留存，先成情景对，再汇总四方向。负值、零值、未达门槛均保留。随机切分使用完全相同分析；不要求其为阴性、不据此主张 FIX 特异性。

## 4. 冻结判读与出口

这是已见数据探索分析，以下阈值仅用于统一描述及限制后续成本，不是显著性门槛。

定义 G=Σ_j max(ΔC_j,0)。当 G 足够可分辨时报告 MLP 正增量份额 S_MLP=Σ_MLP max(ΔC_j,0)/G，mixer 同理；同时必须报告负增量总额、净 C_end 和正负抵消比例。不能用 S_MLP 替代净效果。

对每个情景，f0/f1 都满足才计通过。某类别在至少3/4方向各至少5/6情景成立才给跨方向标签；否则报告条件差异。标签同时要求原空间与固定 P 空间一致，不一致则标为投影敏感。

- `MLP步骤主导正增长`：S_MLP≥0.75。
- `mixer步骤主导正增长`：S_MLP≤0.25。
- 其他为分布式增长；G不可分辨则不可判。

另在全窗口按带符号和分别报告同一步项与跨步项。固定定义 D_abs=Σ_i|M_ii|，O_abs=Σ_(i≠j)|M_ij|，同一步占比为 D_abs/(D_abs+O_abs)，禁止先将异号项求和再取绝对值。占比≥0.75可称同一步配对集中，≤0.25可称跨步配对集中，其余混合；同时报告符号和抵消，不把绝对贡献占比称净形成份额。这两个分类维度可同时成立，不互相排斥。

不得从 `MLP步骤主导` 直接推出 `MLP非线性产生对齐`；线性映射、归一化、继承输入等仍可解释。不得从 `mixer步骤主导` 推出 `V存储中已有同一方向`；读取、门控及输入已参与这些输出。

出口只允许：
1. 得到稳定的计算约束，并能写出与替代解释不同的预测：交付一张待审查计算假说卡，明确模块内运算、供体/接收者、改变和固定量、下游是否真实响应、预测读数及推翻条件。不自动进入干预。
2. 仅有阶段定位/角度曲线，或贡献分散、符号不一致：如实报告“不能由此提出可区分的计算预测”，结束本轮记录分析。不递补层、不扩大窗口、不用同一方法再筛一次。

本轮不要求出现单个主导层；即便有主导步骤，没有可区别预测也属于出口2。若有预测，它仍需新合同审查，不能把本轮已见矩阵当独立验证。

## 5. 工程入口、数值规则、成本

实施前冻结代码、规则、manifest、计划哈希和已见数据声明；freeze 与启动分开执行，先确认计划已经同步及 freeze 成功，避免 B3-P0 的后台启动错误。

必需资产：B3 的每层 in/out、mixer输出、MLP输出、切分身份、readout向量及哈希。若中段残差未直接存储，可按原 BF16 加法由 in+mixer 重建，但必须与已验证的逐层闭合方式一致；不能用 FP64 in+mixer 假装真实 BF16 中段。字段或原始哈希缺失即停止，不开启 GPU 补录。

检查：
- 校验原始哈希、模型/输入/切分身份和四格共同入口。
- BF16逐层闭合；FP64三项恒等式、矩阵求和、固定投影求和的残差≤1e−9×max(1,各项绝对值和)。
- 对余弦采用向量阈值 τ=1e−6×max(1,||c_end||)。任一相关向量范数≤τ，余弦记NA，不置零、不丢记录。若||c_end||≤τ，则固定投影及依赖它的联合标签不可判，原空间结果仍完整报告。
- 对贡献分类采用能量阈值 τ_E=1e−9×max(1,||c_end||²)。G或相应绝对贡献总和≤τ_E则不可判；份额不裁剪，不强行置于0–1。
- 分析前用已有 final h 与 B3-P0 JSON核对径向补充，记录逐输入计算方法、r中epsilon和维度。如仅能读汇总JSON，须从精确配置获得维度/epsilon，不能用截图舍入均值反推。
- 工程测试覆盖同一步对齐、纯跨步对齐、径向去除、异号抵消、零向量及投影轴随层变化导致错误求和的反例。只验证数学和记录读取，不伪装科学证据。

预算上限：新增模型/模块调用0，GPU0，CPU累计1核小时，输出≤50MiB，不复制1.6GB原始张量到Git。成本包括字段检查、哈希读取与报告计算；超时保存已完成状态并停止，不自动续预算。结果目录拟定 experiments/cache-b3p1-early-alignment-v1-2026-11-01/，包含合同、freeze、manifest、逐输入JSON/CSV、测试及运行回执、报告。此处仅拟定，尚未建立运行目录。
