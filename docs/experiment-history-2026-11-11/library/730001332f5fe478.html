SDT-01：保留接收者基底，检验留存状态差能否跨输出背景转移

Material Passport

1. 目的、已有证据与可失败预测

主线仍是：稀疏激活干预怎样改变写入、旧状态处理和后续读取，造成大幅回答变化。本轮推进 To-do 第 1 项：恢复输出背景产生的留存状态差，能否在原生输出背景的基底上增强 k 对目标选择的作用？反向换回原生状态差，是否削弱恢复背景的优势？

  • NVB 正式结果：三个缺口方向中，原生输出下留存增强 DS0=0.247/0.488/0.622，恢复输出下 DS1=2.122/1.451/1.575；原“留存单独承担主要增强”预测失败。两者之间的差距仍待解释。
  • NBR 更正及离线重算、重投影 JSON：固定读者和梯度时，状态来源投影差稳定，集中于16–18及22层；24–30层状态差大但一阶投影弱。单换读者 q/α 的投影变化小；梯度背景效应依赖线性化点，不能定为主要原因。上述均是诊断，不是状态移植后的行为证据。
  • 架构/条件公式与前人工作沿用基础审计：状态可编辑、读取可非线性、跨层投影不可直接加和均非新发现。本轮不提出方法首次或通用机制主张。

工作预测 P1： 第16–22层的留存差移入原生输出背景后，能带来实质的额外 k 效应，达到至少一半既有背景差距参照；预设成功尺度见§4。P2： 反向移植削弱恢复侧的条件增强，并带来对应的自然回答交互变化。24–30层是有限范围的竞争候选，预期效果较小，但一阶投影弱不保证其因果效应弱；它不是零对照。

最不利证据：NVB 已显示原生计算背景限制明显；读出投影受线性化点影响；C1343 模式相反。移植可以失败，失败不自动归因于 q、KV、基底或“下游敏感度”。

2. 固定范围与精确操作

继承 NVB 合同及其 r02 修正：Qwen3.5-4B，revision 851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a，BF16/eager/batch1、torch 原核；同48条已见开发输入、六场景、N4146/N1210/R0/C1343、R族 μ、L0/NA/B1/−1形成与既有校准。C1343独立诊断，不进入三方向多数计数。模型、文本、针、剂量、前缀、解码和评分均不重新挑选。

记 B(c,a,b) 为 NVB 八格：c 控制t1输出使用v0/v1，a控制留存更新使用v0/v1，b控制写入k操作。S_l(c,a,b) 是整个t1前向结束后第l层保存的递推状态。每输入、每方向、每b独立生成：

[ \Delta_{a,l}(c,b)=S_l(c,1,b)-S_l(c,0,b). ]

这是实际端点差，不用局部秩一公式代替，不把b=0与b=1的差强制做成同一个向量。原始局部v来自同分支输入及干净V历史，仍非完整干净运行的内容。

从接收者 B(r,1,b) 的t1末缓存深拷贝出新臂，只对选中G层集合H一次性赋值：

[ \widetilde S_l(d\to r,H,b)=S_l(r,0,b)+\Delta_{a,l}(d,b),\quad l\in H. ]

H之外保留接收者 S_l(r,1,b)；所有非S缓存、位置元数据和已经产生的t1 logits/token均来自接收者 B(r,1,b)。比较用的a=0基线始终为未改的 B(r,0,b)。不能在 S(r,1,b) 上再加供体Δ，否则会重复计入接收者留存差。

选层冻结为两组，各含6个G层：H={16,17,18,20,21,22}，L={24,25,26,28,29,30}；没有19/23/27全注意力层。13/14层始终不移植。

条件 操作 b=0/1格数 用途
NVB八格 原样重放 8 供体、接收基线、旧结果桥接
F_H d=1→r=0，移H的Δ 2 主检验：恢复来源差能否增强原生侧条件竞争
R_H d=0→r=1，移H的Δ 2 反向检验及自然完整回答连接
F_L d=1→r=0，移L的Δ 2 检验“状态变化大但投影弱”的候选是否仍有作用

只有6个新条件，8个旧参照。 新臂复用t1端点，不重新做t1；移植在t1全部结束、消费t2 token之前完成，不能在逐层t1前向中即时移植。t2起无编辑钩子，q/k/v、门、KV、卷积和后续状态均自由响应。

本轮不加整份S移植、H+L联合、逐层扫描或新随机族。整份S会改变基底，是另一个问题；F_L不是匹配随机对照，也不以H/F_L差异宣称位置特异或排除一般扰动。NVB随机结论不能转借到本轮新操作。这里检验所观测状态差在指定接收背景中的可转移效应，不宣称方向特异、自然独立通路、纯内容或机制份额。

3. 读数：条件竞争与自然行为分别报告

  • C路线主要终点M： 所有14格复制t1缓存，消费每输入冻结fF，在t2使用NVB的目标/竞争token定义。主32条目标非首列、六场景等权；首列16条单列。每例原始M、六场景值及四方向全部报告。
  • N路线行为终点Y： 所有14格从接收者已有t1 token正常贪心继续，最多含首token32个，沿用解析器/停止集合。48条全进分母，报告改对、改坏、停止步和完整原文。t1已停止的臂不继续；未停止的少数c=0输入仍正常评估，不能声称所有原生臂都停。C/N不同输入token时不复用前向。
  • t1输出相同是结构约束，不计科学成功。C改善不代表原生完整交付改善。R_H的自然比较保持原来恢复背景的首token，六条已知首token例外仍按实际序列单列。
  • 不重新求梯度，不把张量范数/读出投影当终点。保存移植前后逐层逐头的Δ范数、实际替换差范数、跨来源余弦，供检查幅度和失配；只作描述，不据此分配贡献。

4. 比较、冻结判读与退出

令 m_rab=M(B(r,a,b))，p_db=M(移植d→r的a=1臂)，

[ D_r=(m_{r11}-m_{r10})-(m_{r01}-m_{r00}),\qquad \widetilde D_{d\to r,H}=(p_{d1}-p_{d0})-(m_{r01}-m_{r00}). ]

对应NVB的 D_0=DS0、D_1=DS1。主要差值：F_H=\widetilde D_{1→0,H}−D_0；反向损失 R_H=D_1−\widetilde D_{0→1,H}；另报 F_L。每b的直接移植效果 p_db−m_r1b 同时报告，避免用交互掩盖主效应或两格共同损伤。Y使用同样的差分定义，同时保留各格正确数与逐例转变。

参照差距 Γ=D_1−D_0，既有值为N4146 1.875、N1210 0.964、R0 0.953。它只是现有两个背景的比较参照，不是可恢复上限或可分配份额。用本次逐位重放的精确值计算；仅Γ≥0.5时报告F_H/Γ、R_H/Γ，允许反号与超过1。

冻结规则（实用幅度标签，非显著性、等价性或总体推断）：

  1. 正向支持：均值≥0.25 logit且≥4/6场景为正；反向对称。其余标“未达预设支持”，不写零效应。阈值附近同时报告未舍入值。
  2. P1强转移：F_H满足正向支持且F_H/Γ≥0.5，同时b=1臂本身的目标M改善 p_11−m_011 也满足正向支持，避免只靠破坏b=0形成“增强”。比值>1.5单列“超参照”，不说精确恢复。F_H和b=1改善均支持但比值<0.5为部分转移；只有交互支持则单列“交互改变，未支持目标优势转移”。至少2/3缺口方向达到强转移才支持P1；方向不一致逐一报告。
  3. P2：R_H满足正向支持，且b=1臂本身M下降满足同幅度/场景标准；对应Y的b=1净损失与Y交互损失均≥2条、各至少2场景同向，才称有自然行为连接。Y交互是两组移植净变化之差，不冒充单格净减；列出每b改对/改坏及主效应。至少2/3缺口方向同时满足才支持P2。
  4. F_H−F_L≥0.25且≥4/6场景为正才标“H效果较强”；否则不宣布层组胜出。F_L阳性则撤回“低投影组作用弱”的预期，仍不扩扫。L未过线不能证明其无作用。
结果 本轮能留下的结论与出口
正向强转移、反向损失，并有反向Y连接 指定H状态增量的来源能双向改变条件优势，并在恢复背景改变实际回答；补上从NBR诊断到操作效应的连接，不称完整自然中介
只有正向支持 供体增量在该接收背景有可转移作用；不能称必要，不能以反向不显著补成双向结论
只有反向支持 恢复背景对该增量来源敏感；尚不能把它带回原生背景，保留基底/其他缓存依赖
H弱、L强，或两组均强 修正投影选层预测；本轮报告两组操作结果，不相加分配，不自动补H+L
两组弱、反向或方向不一致 该增量在当前基底与层范围内的转移不足/异质；不归咎于梯度、q或KV，不自动扩层、加剂量、换供体

无论结果如何完成一次报告后结束本轮。To-do第1项仍按证据标注进度，不因局部阳性自动勾选原生全链闭合。

5. 最小实现、验收与完整成本

复用 nvb_run.py::NHook、形成/克隆/解码/评分与记录格式；只新增t1末缓存的Δ替换函数及新格循环，不修改已冻结实验。拟产物目录 experiments/cache-state-delta-transfer-v1-2026-11-03/，本次仅交付设计。NBR的 nbr_run.py 保存的是状态统计和读出投影，未保存可直接移植的完整S；因而必须重建八个t1端点，不能从摘要或梯度推算新格的真实回答。

工程验收先于科学判读：

  • CPU：不同基底、非零Δ的合成例核对来源索引、正确减旧加新、H/L掩码与无共享写入；独立FP64参考核对跨源赋值。使用缓存实际dtype，先FP64做差和加法、再一次cast回原dtype，不做归一化或缩放；记录舍入误差，归一化最大误差≤1e−6，失败不临时放宽。
  • 同源Δ回填 S(r,0,b)+Δ(r,b) 后须重建 S(r,1,b)；数值验收使用真实张量检查最终cast结果逐位相同。空层集合为逐位无操作。这些检验复用端点，不另算整模型前向。
  • 每输入八格t1与C-t2全词表、原生完整token与NVB逐位重放；第13层跨c状态恒等继续检查。来源/hash、模型revision、冻结μ、输入账本、停止集合验收继承NVB/NBR。
  • 新臂仅选中层的S改变；其他所有缓存、长度标记、t1 logits/token均与接收者逐位一致。源缓存前后hash不变，C/N各自深拷贝。真正续算使用修改后的S；t2起零编辑hook。零差及无操作不作为科学发现。
  • 固定两条预检 LVK-H-NA-NQ01-ABC-A、LVK-H-NA-NQ02-ABC-B，全方向全格；最多一次有记录的工程修复重试，失败不产科学结论。正式开始后不改格子、阈值、层范围或输入。

反方自查与修正：

  1. 全S移植即便成功也可能只是基底作用——改为接收基底+供体Δ；删除本轮全S臂，保留“基底条件未识别”的边界。
  2. 在接收a=1状态上再加Δ会重复留存作用——公式改用a=0基底，H外明确保留a=1，加入合成及同源回填验收。
  3. NBR重点是I_S，移Δ_a会带入主效应——这是有意选择可实现的成对留存差；每b直接效应、主效应和k交互全部报告，不说只移了I_S。
  4. H阳性也可能靠幅度或失配，L不是随机——承诺限定为实际供体差的操作效应，不声称方向/层特异；不把旧随机证据转借。该边界仍能回答恢复来源差能否跨背景生效。
