# H-WR最小补证：作者设计自查

2026-11-05；Proposal v8 / NWR主比较收敛版。依据[强制自查v1](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/experiment-design-self-check.zh-CN.md)与[已知基础审计](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-mechanism-known-basics-audit-2026-10-31.zh-CN.md)。**同一助手自查，不是独立评审。逻辑设计与实施、验收、授权、结果分开。**

## 1. 设计卡及本轮修订

- 主线：稀疏干预怎样经写入、历史使用改变完整回答。
- 增量：旧LVK/SRU已有局部写入端点的D双向效应；新增只检验原生L00来源状态在同一接收者的相同读取用途下，是否产生超出随机幅度、另一用途及停止的实质选择错误。
- 依据/反例：Proposal §3固定报告、LVK/SRU合同、SRU验收、两篇近邻。NVW原生k弱、组合背景敏感、CGV/WIN边界保留。
- 操作：Proposal §4，T底座、t1局部写入、t2只读供体S1；主接收L11，供体L00。固定G/模型/方向/剂量来源，不另找层。
- 估计对象：同一接收者下改变状态来源的指定读取用途，对自然完整回答及明确错误编号发生率的操作总效果。
- 判读/退出：Proposal §4–6；强标准/仅停止/随机相当/用途相当/弱效应/异号/不可判分别改变全文。A一轮，成功B，任何B结果整稿。
- 资源：旧状态可核实后复用，但旧结果不包含新反事实输出；A576/B1728正式轨迹，工程各64，GPU硬上限仅提议。
- 身份：A旧48条、6场景开发；B24新基础情境×2版本、六既有结构族，非新模型/任务。来源清单和数值验收未完成，不称可直接运行。

**提交前实质修订：** 远端新增论文v1.1/NWR后，回查LVK合同确认底座是T，只修改t1写入项；撤回将其泛称“整段恢复背景”的表述。内部曾拟另做原生t1的整组S读取比较，现已取消且未运行，因为它另起机制、不如原生来源供体比较直接利用旧链。旧SRU t2不可达的风险通过“L00只作供体、L11自然接收”解决，不强制L00继续。

与v7：WPC不再默认先行；保留审计和计划但不与A强制串行。与远端NWR草案：保留主供体/接收者与D/E，删次接收者/干净供体/强制前缀及联合探索；随机改为输出范数匹配；全文标准不沿用2/48标签或小种子均值±2SD零分布。实施前必须修订合同，不双跑两版。

## 4. 实质反方检查

1. **全部阳性也可能是L11读者与L00状态失配，而非L00本来怎样读。** 成立；强制把结论限定为原生来源在指定接收者下的用途关系。它增加的是原生写入来源证据，不能宣布原生自然全链闭合。是否有贡献要结合已有同端点写入干预和新情境确认评估，不能由一张移植阳性自动保证A类。
2. **L00首步EOS，t2不存在。** L00仅作S1供体；状态在首token采样前已产生。接收者L11自然到t2，不伪装L00自然轨迹；未到达的接收者保留而不删题。
3. **只是推迟了一步停止，没解释选择错误。** 新增E_num门槛与停止分类；若仅停止，即使Y损失很大也不支持H-WR强版本。
4. **原生供体ΔS大，任何扰动都能致错。** 主随机对照在输出空间匹配D幅度，比只匹配状态Frobenius范数更直接面对该替代；仍只代表有限随机控制族，不证明所有一般损伤解释已排除。
5. **共享预填就被说成各层状态差精确等于一项固定写入差。** 不采用这一额外恒等式作科学前提。高层驱动允许响应前面写入；精确数值等式要另核逐层证据，不能只从一句“共享S0”推断。
6. **新B只是旧题换名。** 要求新的记录关系与查询内容，先冻结基础情境及六结构/校准族映射；承认仍是既有任务族内确认，不声称新任务。若无法在不看模型表现的情况下建立有效清单，B暂停。
7. **统计功效可能不足，门槛太严格。** 有限确认可能未定；不预言一定成功。门槛对应实质损失、用途/幅度区别和选择错误，删任一项会削弱承诺。区间宽不追加题救结论。
8. **是否又回到一条窄机制？** A不寻找新热点，只有旧SRU同一读出新供体；一次之后B横向冻结确认。失败退出、B结束整稿，不能切换t1或全程D续局部。
9. **所有结果都补齐就一定是优质论文？** 否。它决定一个可评审的有界贡献能否站住；现实痛点、领域重要性及近邻覆盖仍影响价值，跨模型/实用方法若成为主张则另需证据。本文不把有限补证写成录用保证。

## 5. 结论与状态

**逻辑设计通过（作者自查），H-WR尚未获得新支持。** 已完成源协议核对、背景措辞修正、NWR最小比较收敛、主终点/强判据/反例及A→B→整稿的停止规则。未完成新合同实现、来源manifest、B情境清单、错误类型解析/裁决、数值闸门、预检与正式运行。当前明确没有新GPU或模型授权。

最后复查：仍回答干预怎样经已有写入—读取主体改变完整答案；没有把局部目标换成停嘴或新层定位，没有把原生来源偷换成原生自然机制，也没有将“最多一轮”变成必须不断完成的配额。
