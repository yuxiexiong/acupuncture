## 1. 设计卡与主线

1. **核心问题**：稀疏干预怎样改变写入、历史状态处理与后续读取，最终改变回答？本轮具体问：在供体 q 已固定时，已能搬运 k 修复的 t1 后历史包，靠 S、KV 各自还是二者组合实现行为转移？
2. **增量**：KRD 已有 H=S+KV 的双向行为证据；本轮新增两个部分交换，确定后续计算研究需保留哪个载体或联合载体。不是再证明缓存存在、模块可交互，不承诺本轮解释更新项。
3. **依据及反例**：KRD 的 H+Q 转移强，但随机加入也有相近比例；C1343分差变化而答案不变；N4146存在方向不对称。旧SK/NR的背景不同，仅提示联合/冗余可能，不能代替本轮结果。
4. **操作**：同输入同方向端点，t1后、t2前对 S/KV 做2×2，t2 Q统一取未混合供体；原接收者卷积及其余缓存保留。四方向、三组双向配对；完整定义见§3。
5. **估计对象**：给定供体Q的受控载体交换效应及交互，不是一般必要性、自然中介比例或两个独立形成来源。
6. **判读**：允许单项承接、两项各自可承接、联合才有效、混合、不一致、小缺口和只有分差无行为。不要求一个单项胜出，不作“载体无关”排除推断。
7. **范围/成本**：48条已见输入、6场景、4方向；正式新增2304条自然轨迹，复用2304条旧控制轨迹；所有重建、诊断重放、供体捕获及预检计入§7。
8. **退出**：一次载体检查后交接到具体计算问题，或因工程不符/结果不稳停止；不再细拆头、层、槽、布局，不自动运行第二步。

## 3. 固定范围与完整因子表

## 4. C诊断路线与N自然路线

C：t2输入旧F首token，所有四格保存M、M_all及全词表logits。主M沿用KRD：目标编号区别token减首列（目标在首列时减第二条）；主判读32条目标非首列，16条首列另报。M_all为目标减其余候选最大值，不混作同一读数。

N：沿用接收者r自己的首token x[r]；d的Q必须由c1[d]输入同一个x[r]计算，禁止跨token取供体。若与C相同则复用Q；否则追加一次来源前向。该供体前向不是自然回答。接收者若首token停止，新操作未到达，仍计入全48自然终点，不改成强制续写。

续写贪心至原停止条件或32个新token（含首token），原解析器给Y_full；保留token原文、改对/改坏、第一条编号、复述/多编号、截断与未到达。M改善但完整交付不变仅是诊断效应。自然分叉以后的状态变化包含在该操作的总效果中。

旧控制复用：新00/11的N轨迹来自KRD r02；每个ID明确记录旧pair/格/路线/token/哈希，不覆盖旧文件。正式C路线四格全部重新算；所有旧00/11的C logits须与KRD逐位一致。预检额外重放00/11的完整N轨迹，逐token及终止方式相同；只要同一实现桥接失败，不允许靠旧自然结果拼出四格。旧原始输出或logits缺失，先报告来源阻塞，不在预算外偷偷重跑。

## 5. 估计对象与判读规则

对每方向、每有序配对单独计算。令z为M或Y_full，格值z_sb：

- S在KV=r时的效应：z10−z00；S在KV=d时：z11−z01。
- KV在S=r时的效应：z01−z00；KV在S=d时：z11−z10。
- 联合H效应：z11−z00；交互：z11−z10−z01+z00。

**分母必须换成当前条件下的H缺口** `h=mean(M11−M00)`，不能仍用原始d−r缺口来判断S/KV承担比例。原端点缺口g及相对原r的总变化同时报告，保持与KRD可对照。均值先在固定32非首列输入上计算；不先逐题除以接近零的分差再平均。

若|h|<0.5 logit，不给S/KV份额标签，只报原始效应和“小条件缺口”。否则定义pS=mean(M10−M00)/h，pKV=mean(M01−M00)/h，保留负值及大于1，不裁剪；它们不是自然路径份额。

诊断效应按朝11方向计，需平均幅度≥max(0.25 logit,0.25|h|)且≥4/6场景同向；M交互实用容差=max(0.25 logit,0.1|h|)。自然Y用全48题，方向以Y11−Y00为参照，净改变至少2/48才记完整交付支持；Y端点无缺口时只报原值，不除零、不判修复失败。Y交互容差2/48。阈值是实用描述规则，不是统计显著性。

冻结分类（仅对可判的方向×配对；不能由连续比例强迫唯一归属）：任一比例>1.25或<−0.25时优先标为超调/异号，不进入下列单项或双项承接标签。

| 数值与行为模式 | 允许的读法／交接 |
|---|---|
| pS≥0.75、|pKV|≤0.25，S有上述诊断及完整交付支持 | 在此Q背景下S单项承接较多；下一步优先观测S及其后续读出 |
| pKV≥0.75、|pS|≤0.25，KV有诊断及完整交付支持 | 在此Q背景下KV单项承接较多；下一步必须追踪t1输出至KV，不能只看局部S |
| pS、pKV均≥0.75且各有行为支持 | 两种单项操作均可承接；不等于两份独立记忆，保留联合载体 |
| 单项都未达诊断规则，但联合H有诊断与行为支持 | 联合有效、单项弱；是合格结果，保留H，不再细拆缓存 |
| 其他、异号、超调、方向不一致或仅M成立 | 混合/条件依赖/诊断限定；如实保留，不选择效果最大的格讲单机制 |

联合H相对原r已有变化不意味着相对新00仍有同样自然缺口，必须重新对账。将32非首列与16首列、C与N、改对与改坏分别列出。以场景均值报告重复结构，不把方向×题格当独立样本，不声称未见确认。

共同偏移与随机的比较只对齐加入侧：Ak←F与Ark←F，F←Ak与F←Ark。两侧|h|均≥0.5才比较同格归一化比例，同时报告h、绝对转移量、6场景结果及Y。不再用绝对量自动贴“特异”标签；本轮不设“共同一定胜过随机”的成功门槛，也不把归一化当已控制所有损伤差异。减法侧随机未新增，不能推广其特异性。

C1343完全按同样矩阵报告M和Y：若M变化但仍全对，只能说明该操作未跨行为边界；余量为混合参照余量，不归因V。若载体模式与缺口方向不同，保留这一差异，不能都解释成余量。

## 6. 预测、第二步交接与停止

本轮新增的可失败预测P1：固定供体Q时，S单项在共同偏移的多数配对中承接较多（上述S分类）。这是待检验推测，不是QSR份额必然推出；按方向逐对计数，预先定义多数为每方向四个共同配对至少3个。不足可判配对时标预测不可判，不把小缺口当失败，也不缩小多数规则的分母。P1不成立，不否定KRD的联合H效应，更不否定进一步计算研究。

交接不以单项胜出为门槛：同一无序配对的两个方向若同属S或KV类别，才记录为该配对优先载体；其余保留联合H及不对称。全部小缺口/只有诊断没有行为时，交付受限结论，不为选出载体再换Q、扫层或改阈值。

**第二步只列设计约束，本次不冻结执行矩阵或授权：** 主问题仍是“t1的k改变怎样形成能搬运修复的历史”。应干预产生历史的具体更新计算，而不只是交换终态。按当前实现key×value记法，更新为 `S1=αS0−αβ k(kᵀS0)+βkvᵀ`，然后输出`S1ᵀq`。未来擦除项操作必须同时说明两个k的位置；单独写入项也须定义来源。不同项混用k是人工计算反事实，不称原模型天然分离通道。

“两项都换”的工程参照只能是**同一步、同背景、同k来源的完整k节点替换**；不能要求复现原始卷积k编辑在t1/t2/t3的全部修复。必须让S、当步输出、下游KV及新卷积槽正常响应；明确哪些局部变量钳制、哪些动态生成。重写更新核的无操作须与原核逐位一致，不能在失败后放宽容差救结果。

第一步只帮助选择第二步应保存/观测的载体，不证明它的形成项，也不能把Q固定供体的条件结论直接搬到自由Q运行。第二步需另写具体反事实、双向预测、完整预算、自查及数值验收；若联合有效就保留联合观测，不强迫再拆S/KV。无论本轮结果如何，不自动上卡第二步。
