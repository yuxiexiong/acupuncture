# KHC-01 合同 r01：固定供体 Q 下，k 修复历史的 S×KV 载体检验

依据计划 `docs/cache-k-history-carrier-plan-v1-2026-11-03.zh-CN.md` 与自查（c0b42667），加上我审阅时补的一条工程闸门（§6 N 路线桥接）。授权：2026-11-03 用户“开始”。冻结后不改本文件；偏离记入 `DEVIATIONS.zh-CN.md`。

## 1. 问题

在 t2 的 q 节点固定为供体的条件下，KRD 已证明能搬运 k 修复的 t1 后历史包，是靠 G 层递推 S、A 层注意力 KV 各自承接，还是要两者组合。估计对象是固定供体 Q 下受控载体交换的效应与交互；不是一般必要性，不是自然中介份额，也不是两个独立的形成来源（KV 差异本身是 t1 上游 G 层写入经输出传下去的结果）。

## 2. 固定条件

继承 KRD r02：模型 Qwen3.5-4B revision 851bf6e8…，BF16/eager/batch 1，torch 原核；48 条输入、6 场景、方向 N4146/N1210/R0/C1343。G 与 A 层组同 KRD。五臂 V/F/Rk/Ak/Ark，μ_k、r_post,k 原样复用。随机去除（Rrk/V）不新增：KRD 中它在 N4146/N1210 的端点缺口不足；这不等于随机去除无效。

## 3. 操作

- 有序配对 r←d：Rk←V、V←Rk、Ak←F、F←Ak、Ark←F、F←Ark。
- 四格 sb：t2 前 G 层全部递推 S 取 d（s=1）或 r；A 层全部 keys/values 取 d（b=1）或 r。KV 旧前缀必须逐位相同。卷积缓冲、浅层缓存、长度/位置/掩码全取 r。
- 每格 t2 的 Q 一律取原始 d 在同一 t2 输入 token 上的 query（14 个 G 层内核入口），只钳制 t2。新 00 格等于 KRD 的 01 格（只换 Q），新 11 格等于 KRD 的 11 格（H+Q）。
- C 路线：t2 输入旧 F 首 token，四格全部重算，保存 M、M_all、全词表 logits。
- N 路线：t2 输入接收者自己的 x[r]；供体 Q 在 c1[d] 上用同一个 x[r] 捕获，每个配对额外一次前向。新格 10/01 贪心续写到停止符或 32 个新 token；00/11 复用 KRD 自然轨迹（见 §6 桥接）。x[r] 是停止符则未到达，照常计入。

## 4. 读数

M 判据用目标非首列 32 条（首列 16 条另报），Y_full 用全 48 条（原解析器）。

## 5. 冻结判读（实用幅度，非显著性）

1. h＝mean(M11 − M00)。|h|<0.5 → 小缺口，只报原始效应。
2. pS＝mean(M10 − M00)/h，pKV＝mean(M01 − M00)/h，不裁剪；同时报 KRD 的 g、h/g、以及 KRD 的 10 格比例（Q 取接收者时只换 H），供对照，不进判据。
3. 格 c 的诊断效应（朝 11 方向）：sign(h)·mean(Mc − M00) ≥ max(0.25, 0.25|h|)，且 ≥4/6 场景同向。
4. Y 支持：方向 s＝sign(ΣY11 − ΣY00)；s≠0 且 s·Σ(Yc − Y00) ≥2。Y 端点无缺口时，用诊断规则代替 Y 支持，类别加后缀“_diag_only”。
5. 分类（取第一个满足的）：small_h；超调/异号（pS 或 pKV >1.25 或 <−0.25）；S（pS≥0.75、|pKV|≤0.25、S 有诊断效应和 Y 支持）；KV（对称）；both（两者都 ≥0.75 且各有诊断和 Y 支持）；joint_only（两个单项都没有诊断效应，联合有诊断效应和 Y 支持）；其余为 mixed。
6. 交互：M 的 |mean I| > max(0.25, 0.1|h|) 才算实用；Y 的 |ΣI| > 2 才算。二值饱和会造成行为交互，不当作内部协同的证据。
7. 共同对随机：只比较加入侧（Ak←F 对 Ark←F，F←Ak 对 F←Ark），两边 |h|≥0.5 才并列 h、pS、pKV 与类别；只作描述，不设特异性门槛。
8. 交接：同一无序配对两个方向同为 S 或同为 KV，才记为该配对的优先载体；其余保留联合 H。C1343 按同样矩阵报告；余量不归因于 V。

## 6. 预注册预测与工程闸门

- **P1（计划，推测档）**：每个缺口方向的 4 个共同配对中，至少 3 个类别为 S。可判配对少于 3 个时标为“不可判”。P1 不成立不否定 KRD 的联合 H 效应。
- 闸门（运行中断言）：
  - 五臂 t1 的 logits/缓存与 QKF/QKD 一致，x 与 KRD 一致；五臂 C 路线 t2 的 M 和 bf16 logits 与 QKD、KRD 一致。
  - 新 00/11 格的 C 路线 M 与 bf16 logits 和 KRD 的 01/11 逐位相同（全部输入）。
  - **N 路线桥接（合同补充）**：正式运行中，每个已到达的新 00/11 格补一次 t2 前向，bf16 全词表 logits 与 KRD 存档逐位相同，argmax 与 KRD 轨迹的第二个 token 相同。预检做完整轨迹重放，逐 token 和终止方式相同。
  - 交换：只有指定的 S/KV 来自供体，其余全部等于接收者；Q 钩子在 t2 的 14 个 G 层各触发一次，内核实际收到的 query 等于来源；源缓存、C/T 供体前后不变。
  - 仅预检：自体操作、不挂 hook 与捕获前向逐位相同（80 次工程前向）。
- 预检失败保存并停止；允许一次有记录的修复重试。正式开始后不改实现。
