SK-01（深层递推状态 S × 注意力 KV，入口固定 x_T，加三条原生恢复臂）合同 r01

日期：2026-11-02。设计：计划 v1 + v2 修订。基准：EH-XC 正式运行（5f6ef8d）。授权：用户 2026-11-02「那就直接写合同代码，测试然后上卡」。已见输入，新格结果未见。

1. 操作

沿用 EH-XC 的模型、revision、BF16、内核、token、晚段窗口、L0 剂量 −1、12 条输入、worker/GPU 分配、进程内校准。四方向：N4146、N1210、R0、C1343。深层 S = 第13–31层 G 层（13,14,16,17,18,20,21,22,24,25,26,28,29,30）的 recurrent_states；深层 KV = 全注意力层 15,19,23,27,31 的 keys 与 values（同时替换）。

每输入形成 C、评分 C_native；每方向形成 T、评分 P = T_native（取 x_T），然后： - 主矩阵（第13层入口 hook 一次 = x_T；浅层 C；深层卷积 C）：SK00（S、KV 均 C；= EH-XC X10）、SK10（S 取 T）、SK01（KV 取 T）、SK11（S、KV 均 T；= EH-XC XH11）。 - 原生恢复臂（从完整 T 出发，无入口 hook，自然入口须等于 x_T）：P_S0（深层 S ← C）、P_K0（深层 KV ← C）、P_SK0（两者 ← C）。浅层与卷积保持 T。

每格是供体的独立深拷贝；下游全部正常响应。

4. 读数与判读（sk_core.RULE）

D = 停止最大 − 非停止最大（原始 logit）；同时算固定候选 F/A/B 版本。主矩阵：S0 = D10 − D00，S1 = D11 − D01，K0 = D01 − D00，K1 = D11 − D10，H = D11 − D00（= EH-XC 的 H1），J = D11 − D10 − D01 + D00。原生：N = D(P) − D(C_native)，R_S = D(P) − D(P_S0)，R_K = D(P) − D(P_K0)，R_SK = D(P) − D(P_SK0)，J_native = D(P) − D(P_S0) − D(P_K0) + D(P_SK0)。

  • 适用：N ≥ 1 且 H ≥ 1；反向、原生强混合弱、不适用分别报告，所有格照常执行。
  • 主分类（ε = max(0.5, 0.2|H|)，按序）：S 集中（|S0 − H| ≤ ε 且 |K0| ≤ ε 且 |K1| ≤ ε）；KV 集中（对称）；两者同时成立 → 分辨力不足；冗余（|S0 − H| ≤ ε 且 |K0 − H| ≤ ε）；联合/分布式（S0、K0 都 < H − ε 且 J ≥ ε）；抵消（|S0|、|K0| > ε 且异号）；其他。
  • P_S（推测档）：方向内 ≥5/6 情景两事实都为 S 集中；跨方向报告 k/4，不以多数掩盖 N1210 或 R0。
  • P_native（推测档，无条件）：所有 N ≥ 1 的输入上，R_S ≥ max(0.5, 0.2N) 且 R_S − R_K ≥ 0.5；方向内 ≥5/6 情景两事实都支持；跨方向 k/4。P_S 与 P_native 分别报告，不合并成总标签。
  • 原生模式（描述，阈值 t = max(0.5, 0.2N)）：单独都弱、联合强 → 冗余或替代；三者都弱 → 这些恢复操作没有明显改变当前输出（不推出深层历史不承载作用）；只 S 恢复 / 只 KV 恢复 / 两者都恢复。
  • 交叉表：主分类（S 集中 / 非 S 集中）× P_native（支持/违反/不适用），逐事实计数。
  • J 在 D 上明显、在 F 上不明显时，只说候选集合竞争交互。距任一判据边界 ≤0.125（BF16 步长）的单元单列为精度敏感，不是误差界。
  • R0 的原生行为（首步停止 1/12）照录：原生本来不停止时，不能用“没有恢复停止”判无效。
