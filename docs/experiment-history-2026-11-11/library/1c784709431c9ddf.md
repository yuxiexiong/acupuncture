# NPC-01 方案：V、S、KV 两两组合——最少要哪几块一起受损才改变答案

2026-11-03（v1.1，按评审收紧判读措辞，操作不变）。**设计稿，未冻结、未实现、未运行，无 GPU 授权。** 依据：[NSR-01 报告](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-native-s-reverse-v1-2026-11-03/REPORT.zh-CN.md)、[NQK-01 报告](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-native-qk-history-v1-2026-11-03/REPORT.zh-CN.md)。档位：**推导**＝有论证链；**类比**＝相邻证据支持；**推测**＝待验证。

## 1. 问题

前两轮在干净运行 C 里做反向移植，已经确定：
- 受损的 S、V 历史、KV 各自单独放进去都不致错（NSR-01，两针 48/48）；
- 受损的卷积 q/k 历史单独也不致错（NQK-01，两针 48/48）；不含受损 q/k 的组合已足以致错，但 L12 的逐条差异（复现 15/17、新增 3）表明 q/k 仍可能调节个别输入；
- 不含 q/k 的 V＋S＋KV 组合足以致错（L0 2/48，与全部深层受损逐条一致；L12 30/48，复现 15/17）。

本轮问：**在这批输入、固定移植切点、q/k 保持干净的条件下，哪些受损缓存组合足以改变完整回答？** 逐条输入判断，再看两针的分布。

结果决定后续研究哪一种组合依赖：S 与 V 历史或 KV 的联合变化，还是 V 历史与 KV 的联合变化。具体经过写入、读取还是后续传播，是后续要区分的问题，本轮不回答。

## 2. 操作

沿用 NSR-01/NQK-01 的模型、面板（LVK 新面板 48 条）、两个针（L0/N4146/−1、L12/C3621/−1）、形成、切点 τ（处理最后一个提示 token 之前）、生成设置（贪心，最多 32 个新 token；不加针、不挂钩子、不强制前缀）、G 层（14 层）、深层 KV 层（15,19,23,27,31）和 V 通道切片（[V_LO:]，V_LO = 4096）。接收者为同一输入的 C，供体为同一输入、同一针的 T：

| 格 | 换入的受损内容（其余全部保持 C，含卷积 q/k 历史） |
|---|---|
| CSV | G 层 S＋G 层卷积 V 通道 |
| CSK | G 层 S＋深层 KV |
| CVK | G 层卷积 V 通道＋深层 KV |

另跑 C 与两针 T 作桥接端点。三个单组（NSR-01）与 V＋S＋KV（NQK-01）、全部深层（NSR-01 的 CJ）取自既有正式记录，逐输入配对。每条输入 9 条自然轨迹。

## 3. 读数

- 主读数：自然完整回答（全 48 条）；相对 C 的改坏数与场景数；异常类型（停止 / 错选编号 / 混合编号 / 其他，NSR-01 冻结定义）。
- **逐条配对**：每格改坏的输入里，有多少在同一输入的 CVSK、CJ、T 中也改坏，异常类型相同多少，输出文本完全相同多少；CVSK 改坏的输入能被哪几个两两组合单独带入。
- **逐条最小致错组合**（在已测分组内）：某条输入在某个两两组合下出错、而组合内两个单组（NSR-01）都不出错，该组合是这条输入的一个最小致错组合；三个两两组合都不出错、只有 V＋S＋KV 出错，记为“需要三块”；单组即出错的记为“单组足够”（预期为 0）；V＋S＋KV 也不出错的记为“未致错”。报告每针各类的输入数，以及每条输入的最小组合集合。结论由这一分布给出，不由各组合的错误总数概括。
- 首步描述同前，只描述。汇总：逐输入、六场景等权，场景分层 bootstrap（2000 次，种子 20261103）。不算比例，不设总标签。

## 4. 判读（逐针分别读；部分复现照实报告，不硬塞进下表）

| 观察 | 支持的读法 | 不能说的 |
|---|---|---|
| 多数输入的最小组合含 S（CSV 或 CSK），CVK 少有 | S 与 V 历史或 KV 的联合变化足以致错 | “受损 V 把受损 S 读错了”；这就是原生损伤路径 |
| 多数输入的最小组合是 CVK | V 历史与 KV 的联合变化足以致错，不需要受损 S | S 与损伤无关（NCC-01 中恢复 S 足以修复） |
| 三个两两组合都各自带入一部分输入 | 不同输入的最小组合不同 | 对所有输入“任意两块都够”；识别出三条独立路径 |
| 多数输入“需要三块” | 在已测分组内，这些输入需要 V、S、KV 三块同时受损 | 三块各自承载什么 |
| 只有 CSV 或只有 CSK 致错 | S 与那一个读取侧块的组合足够 | 另一个读取侧块无作用 |
| 两针结果不同 | 两针的组合要求不同，作为条件差异保留 | 把差异归给层号 |

措辞限制：
- 都是干净背景中的移植结果，是混合缓存干预的总效果，不是原生损伤路径；
- 致错的组合是"充分"，不证明"必要"；
- L12 的全部深层受损就等于原生 T（NSR-01 已核实），L0 不是（浅层第 1–12 层也受影响）。

## 5. 工作预测（数据前登记，只写方向，不是预定结论）

- **弱推测**：含 S 的组合（CSV、CSK）比 CVK 更常成为最小致错组合。依据较弱：跨输入干净 S 能带入供体答案，只说明 S 能影响答案选择，不说明同一输入受损的 S 保留了什么，也不直接预测哪个组合最容易致错。本轮不是对“受损信息被错误读取”的检验。
- 两针是否相同，不作预测。

## 6. 工程验收（实现时断言，任一失败即停）

1. 形成 hash 等于 NCC-01、NSR-01、NQK-01；C 与两针 T 的 t1 bf16 logits 和自然 token 等于 NCC-01 正式记录。
2. 每格目标张量等于 T（V 只换 [V_LO:]，卷积 q/k 保持 C），其余所有张量逐位等于 C；接收者与 T 前后不变。
3. 预检自换（以 C 为供体，CSV 组），缓存不变、t1 等于 C。
4. 分析端核对既有记录 sha，并核对本轮 T 与 NSR-01、NQK-01 的 T 自然 token 一致。
5. 6.2 演示：三格的切片与保留、违规拦截、逐条配对、分析入口端到端；冻结前真实模型冒烟须全部通过。

## 8. 停止与下一步

- 工程闸门失败为合同执行失败；预检允许一次有记录的修复；正式开始后不修、不重试。
- 结果弱或不可判时不加格、不扫层、不拆头。完成即停。
- 下一步按结果另立设计：
  - 若多数输入的最小组合含 S：再区分 S 与 V 历史或 KV 的联合变化经过写入、读取还是后续传播（可借用 SRU-01 的 t2 直接读取工具，但要在原生自然生成里做）；
  - 若多数为 CVK：转向 V 历史与 KV 怎样共同改变选择；
  - 若"三块都要"：先在恢复方向上做对应的两两恢复，确认这种组合要求是否双向成立，再决定深入哪一块。

## 9. 自查（作者自查，非独立评审）

1. **是否在无限拆零件？** 不是。这是 NSR-01/NQK-01 留下的明确问题："各自可容忍、组合才致错"里，最少哪几块就够。只加 3 格，答案直接决定下一步研究对象，不扫层、不拆头。
2. **为什么只做反向（干净接收者）？** 损伤的组合要求是在这个方向上出现的。恢复方向在 NCC-01 中单组就已足够，两两恢复不能增加区分力；只有当三块都需要时，才回到恢复方向确认（§8）。
3. **天花板与地板**：干净接收者没有天花板。L12 的改坏上限只有约 17 条，即使部分复现也可能只看到少数改坏，要逐条配对而不是只看总数。
4. **已见面板、单个切点、两个针**：结论只限这些条件。
