1. 结论（坏消息先说）

方案预先登记的四条简化描述，按冻结规则全部不成立： H_V（V 主导）、H_Q（Q 主导）、H_add（Q/V 可加）在 M_T、M_C、N 三个背景和两个主读数（去均值的答案词 cz_a、停止词 cz_s46）上都是 not_supported；H_transfer（动态 D 上 G_N/G_T∈[0.75,1.33]）只有 3/6 情景落入区间，不成立。

数据呈现的是一个跨背景、跨读数都一致的非相加关系（结果后的现象描述，非预注册预测，也不是已识别的内部机制——尚不知道它来自更新计算、读取关系、归一化还是后续层转换；需另行检验）：

  • 有针 V 单独就足够： 只把 F 的 V 段换成 T（Q 干净），复现整块 F 效应。A_V/G：M_T 0.96–1.17，N 0.94–1.06，M_C 1.13–1.71。
  • V 已为 T 时 Q 不再起作用： R_Q/G 在 M_T、N 中为 −0.17 至 +0.06。
  • V 干净时，单换 Q 也能推一部分，偏向停止侧： M_T 中 A_Q/G 停止侧 0.31–0.65，答案侧 0.01–0.33。
  • 由恒等式 G = A_V + R_Q = A_Q + R_V（推导）：R_V/G 只有 0.35–0.99，交互 I = R_V − A_V ≈ −A_Q 为负。这正是 H_V（另一分量 ≤0.3、移除 ≥0.7）与 H_add（|I/G| ≤0.2）失败的原因。

方向特异性与行为连接：

  • 换回干净 V 的效应在 M_T 与 N、两个主读数上都 6/6 情景稳定超过两条同幅随机方向；换回干净 Q 没有超过（0–1/6）。8 组中 4 组超过，停步条件未触发。只能说“相对这两条方向”，不是零分布或通道特异性。
  • 在其余有针背景固定时，换回干净 F_V 足以消除原生评分后半段的首步停止： N:TC 仍保留有针的 S、全注意力 KV、F 的 Q 段与原生入口 x_T，只换回干净 V，8/12 首步停止变为 0/12（D 降至 −3.2 至 −7.1）；N:CT（只保留有针 V）与 N:TT 停止的是同一批 8 个；N:CC 0/12；随机 V 位移保留 6/12。这不推出 V 独自解释整根针的行为，也不推出后续能恢复正确完整的回答。
  • 与 LOCAL-READOUT 对照：单删第13层局部 core 变化在 N 中无作用，而 14 个 G 层一起换 F 的 V 段能消除停止。两次操作对象不同，不能据此判断是多层共同负责还是少数层关键；层间分工未测。

执行偏离： 预检两次失败后修订了数值验收规则（D8）并重新预检，总消耗由原计划 316 次评分增至 364 次；正式 264 次评分与矩阵不变。

校准： D_step（x_T + 全 C 深层）6/6 落在登记范围（d 占比 0.10–0.19，交互 −0.12 至 +0.15）：E2 的 chunk 路线结果在逐 token 路线上复现。

4. 可以说 / 不可以说

Q 段在 V 干净时有部分、偏停止侧的作用，在 V 为 T 时冗余 Q 无关；q 与 k 的各自作用（本轮捆绑）
材料作用是非相加的（结果后描述）；S 干净时 Q_T 与 V_T 方向相反（R_Q 为负） 某个预注册简化描述成立；已找到产生饱和的内部计算；作用分布在多层

F 只直接保存最近 3 个位置，本轮只评分一步：结论只覆盖首词决策窗口，不外推整段回答，也不推出三步后影响消失（方案 §3.2）。

5. 对阶段路线图的含义（路线图 §4，不是运行授权）

对应“Q 或联合项重要 / 两向不对称”分支：纯 V 解释不够。进入 B 的候选需要回答的计算问题是——有针 V 经当前 token 的短卷积进入当前 v（进而进入写入项 βv(kᵀq) 与 S 更新），和有针 q/k 经当前 q/k 改变读写系数，为什么在停止竞争上互相饱和而不是叠加，且 S 背景会改变 Q 的方向？ 本轮已存的 14 层驱动（q/k/v/g/β/core、门控归一化、out_proj、13–31 层残差）可先在 CPU 上区分“当前写入项”与“旧状态读取项”的变化，再决定 B 的针对性干预。一般扰动对手仍保留：V 的超过只针对两条随机方向，入口随机方向（XCHAN）的现象尚未由本轮解释。
