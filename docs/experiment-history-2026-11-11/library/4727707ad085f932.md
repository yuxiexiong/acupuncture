# F1 四步报告：路径一致性、历史回放、正式尺度、量程校准

日期：2026-11-02 08:00–09:04 UTC。代码 main（本提交）；结果小文件在 `runs/f1/`，大文件（校准完整 logits 3.5 GB）留在服务器 `runs/f1-calib/*/logits-*.pt`。全部是开发数据，不是科学结果。机制线的实验（cache-query-layout-coverage）同时占用两卡各约 9.6 GB，互不影响数值。

## 0. 坏消息先说

1. **量程阶梯顶端也没饱和，A 的主读数 Y 在共同剂量下几乎不动。** 按 §4.1 规则，四模型 × 三层在阶梯最高档 3/4 都通过（"严重失分辨"0–2/144），所以 d_high = 3/4、d_low = 3/8。这是阶梯的上限，不是测到的饱和边界——饱和点在阶梯之外未知（弱臂删失）。在 3/4 下 ΔY 中位数只有 1e-15 到 1e-4（最小值偶有 −1，个别格翻转）。按 PLAN §9.2，Y 贴天花板时近似等效不得推广为机制等效，**A 的主比较在当前任务与阶梯下会大面积落入"不可判（机制）"**。m 在 3/4 下有明显变化（|Δm| 中位数 0.9–7.7 奈特）。这是计划层面的问题（任务太容易 / 阶梯太短），需计划所有者裁决，本轮不擅自加档或换任务。
2. **1/64 剂量下的四格 margin 效应在两条计算路径间不一致（第 1 步）**：差异中位数与效应中位数同量级（0.06–0.25 奈特），符号一致约一半（17/48–32/44）。1/64 下的 m 四格效应主要由 BF16 粒度决定，不能当可靠阴性，也不能当效应。
3. **写入在低剂量下不准（D14）**：完整误差向量比 ‖实际−目标‖/‖目标‖ 的最大值，1/64 档 7–28%，1/32 档 3.5–14%，1/16 档 1.8–6.8%，1/8 档 1.0–3.4%，1/4 档 0.6–1.7%，1/2 与 3/4 档 0.45–0.89%。**严格 1% 只在 1/2、3/4 两档对四模型全部成立。** d_low = 3/8 不在阶梯上，按两侧推算约 1%，需实测。
4. **B 的边界正则对格式过严**：3/4 下未到达边界的源，大多不是停止，而是模型照抄指令里的占位格式（`<identifier>: R6 / <answer>: scarlet`）或复述整行记录（`R6 | name: … | color: scarlet`）。这类源被记为不可达。规则未改，照实报告。
5. **启动脚本 `launch_models.sh` 初版退出码取错**（`$?` 在 `$(date)` 之后取，恒为 0），已修。第 1 步的"退出 0"因此不可信，但四个结果文件都已生成并汇总，结论不受影响；第一次历史回放因相对路径写盘失败（日志保留在 `runs/f1/f1-hist/`），修复后重跑为 `f1-hist-r02`。另有一次 GPU0 上同一校准被重复启动约 5 秒，已按 PID 结束两份后单独重启，输出以覆盖方式重写。

|---|---|---|---|---|---|
| Qwen3.5-4B | 0.125 / 0.125 | 24/47 | 24/48 | 17/48 | 8e-5 |
| Qwen3-4B | 0.25 / 0.25 | 24/46 | 17/48 | 25/48 | 2e-10 |
| Llama-3.2-3B | 0.063 / 0.125 | 21/43 | 32/44 | 30/46 | 1e-5 |
