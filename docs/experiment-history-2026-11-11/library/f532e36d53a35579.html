1. 固定对象

  • 模型：Qwen3.5-4B revision 851bf6e，BF16 eager，逐 token 路线；输入为桥接的 12 个输入（VAR03/04、VRD03/04、VRL03/04 × f0/f1）；校准逐字节等于 II-B 参照；冻结 token 集合沿用桥接 data/frozen-tokens-r01.json。
  • 时窗：L = b+1…n−2，逐 token 前向；末提示 token 评分时无针。G = {13,14,16,17,18,20,21,22,24,25,26,28,29,30} 的卷积前 V 切片。
  • 针（34 根，每次形成一根）：原生 L0 通道 {1210,1343,2191,3152,3959,4146,6137,6547,6616,8215} × 剂量 {−1, +1, −0.5}；随机方向 R0–R3，剂量 −1。方向文件 data/directions-r01.json：种子 20261101+j，torch.Generator().manual_seed(seed)，randn(hidden, float64)，float64 单位化；运行前生成并冻结。
  • 机制集 M：剂量 −1 的 14 根针。

2. 形成与评分

每个输入：

形成 针 G 的 V 数量
C 无 自然 1

CT_x 无 V_T(x) 14

评分（首步，只装只读记录器）：C；对每个 x 计算 P|x（自身缓存）和 Y|x（C 的 0–12 层 + x 的 13–31 层）；对 x∈M 计算 Y_CT|x、Y_TC|x、Y_TR0|x、Y_TR1|x。每输入 91 次形成、125 次评分。

预检（VAR03-f0-required，1 个 worker）：完整矩阵，另加关闭记录器重评 C、P|N4146−1、Y|N4146−1，以及 C←V_C、T(N4146−1)←V_T 的自身替换。上限 93/130。正式：12 输入，6 个 worker（GPU = worker mod 2，每个 worker 一个情景），上限 1092/1500。

3. 工程闸门（任一不过即停；不重试、不放宽、不改科学条件）

  1. 锚点（每个输入）：C、P|N4146−1、Y|N4146−1、Y_TC、Y_CT、Y_TR0、Y_TR1 的 logits sha256 等于桥接 formal-r01 同输入记录的 C、T_native、Y_T、Y_TC、Y_CT、Y_TR0、Y_TR1；C/T/TC/CT/TR0/TR1 的浅层与深层缓存清单相等；C、T、R0、R1 供体带哈希相等。桥接记录先按其 worker 收据核对 sha。
  2. 形成：V 只改 G 的 V 切片，q/k 不动，钉入值逐位等于供体；供体带前后不变；共同前缀不变；每个时窗步恰好一次针写入；L0 输出等于同针 T（或 C）；交叉条件的浅层清单等于参照形成；管理状态一致。
  3. 评分：混合缓存浅层等于 C、深层等于对应形成；评分时只有只读记录器；最终归一化逐位重算；状态相同则 logits 相同。
  4. 预检附加：关闭记录器重评逐位相同；两项自身替换逐位无作用。
  5. 调用计数、存储（总计 6 GiB，每 worker 1 GiB）、权重完整性、hook 移除、退出码。

4. 记录

每输入记录：每次评分的 D（stop_advantage）、EOS、token、两个赢家、top5、冻结 token logits 及 FP64 重算、η、最终归一化 r、r/r_C、熵、固定分母熵、相对 C 的 TV；中心化单位 logits 距离（每个评分对 C；对 x∈M 另记 Y 与 Y_CT/Y_TC/Y_TR0/Y_TR1）；针写入审计（BF16 后的激活增量、名义写入范数、目标幅度）；随机位移范数与种子基数；清单摘要。张量：125 份全词表 logits、35 条自然 V 带（C 与 34 根针）、评分 h。不保存 τ 完整缓存（方案 v2 §7）。

5. 读数（xchan_analysis.py，冻结；只作描述）

  • 三类参照：数值界 2(η_a+η_b)；报告尺度 |ΔD| ≥ 1 logit、TV ≥ 0.05 或赢家改变（人为约定）；一般扰动参照为随机方向排秩与每针 TR。
  • 每针、每输入：Δ_native = D(P)−D(C)，Δ_deep = D(Y)−D(C)，状态为"达到 D 报告尺度 / 另有输出分布变化 / 未检出"。情景值取两事实平均；"情景达到尺度"要求平均值 |Δ| ≥ 1，且两个事实都超出数值界。
  • x∈M：E_add = D(Y_CT)−D(C)，E_remove = D(Y)−D(Y_TC)，E_null,k = D(Y)−D(Y_TRk)。只在情景达到尺度时计算比例，否则 NA。分档：<0 反向，≤0.3 弱，(0.3,0.7) 部分，[0.7,1.3] 近似，>1.3 超调。
  • 带过来的预测，逐情景标签：r_add 弱或反向 → add_not_transferred；否则 E_remove 不超过两个 E_null（按 Δ_deep 的方向）→ remove_not_above_own_TR；r_add 近似且 0<r_remove<r_add → consistent；其余 → partial_or_other。每根针在达到尺度的情景中按多数归类：负面过半 → relation_not_transferred；consistent 过半 → consistent_with_carried_prediction；否则 uncertain；没有情景达到尺度 → not_testable_deep_below_scale。冻结 token 与 D 方向矛盾的情景数并列报告。
  • 随机方向排秩：每个情景，10 个通道（−1）各在 {自身, R0–R3} 中按 |Δ_deep|、|Δ_native| 排秩（1 为最大）。在可交换假设下秩在 1…5 上均匀；只报告直方图，不把随机方向的最大值当门槛。
  • ΔV 几何（geometry）：逐层、展平位置×维度后的 ΔV 余弦，按通道–通道、通道–随机、随机–随机分组；同通道 ±1 的余弦，−0.5 对 −1 的余弦与范数比。只作描述。

方案 v2 §6 判读表全部适用。特别是：两个 TR 抽样不是零分布；4 条随机方向不代表任意方向；12 个已见输入不是独立样本；ΔV 余弦只作描述；工程失败或锚点不重现属于不可判，不是科学阴性。完成固定矩阵即停止，不按结果扩剂量、通道或时段。
