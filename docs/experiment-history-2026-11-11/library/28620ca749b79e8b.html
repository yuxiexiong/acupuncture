NR-01 计划 v2：在 v1 上的四处修订

  • 2026-11-02。只修订 v1 的以下四处，其余（因素定义、八格、公式、阈值 τ、预算口径、闸门、出口、自查）全部沿用。授权：用户 2026-11-02「同意，按这四条改好后直接写合同代码，测试后上卡跑」。

已见数据申报

审阅 v1 时，执行者用 EH-XC 与 SK-01 的已有记录算出了三格在等价前提下的数值（R(F)/N 0.24–0.55，C1343 有 4/12 个输入 ≥0.5；R(H)/N 0.15–0.37；R(XF)/N 0.54–0.70；R(FH)/N 0.82–0.96）。因此凡由这些格决定的量都不再是盲测。

修订

  1. 010、011、110 改为等价前提的逐位重放闸门：在“单步评分时浅层只经第13层入口影响深层”的前提下，010 = EH-XC 的 XH11（N:CC），011 = EH-XC 的 X10；110 与 EH-XC 的 H01 是同一组装。三者的 logits 必须与 EH-XC 逐位相同，否则按工程/前提失败停止。这在全部 48 个单元上检验前提，取代 v1 的 8 次入口 hook 辅助评分（删去）。
  2. 预注册只针对未见量：真正未测的只有 100（只恢复入口）与 101（恢复入口与深层历史、保留卷积）。登记 P_X：R(X) < 0.5N；P_XH：i_XH ≥ τ = max(0.5, 0.1N)。均为推测档，方向内两事实都满足、≥5/6 情景记支持（≥5 个情景两事实适用但支持不足记未支持，否则适用不足），跨方向报告 k/4。
  3. F、H 部分改为已知值复核：v1 的 P_no_single 中关于 R(F)、R(H) 的部分，以及 R(XF)、R(FH)，在报告中标为事后数值、已知值复核，不当预测。
  4. 科学增量如实表述：本轮新增的是原生背景中单独撤回入口的效果、撤回入口与深层历史而保留卷积的效果，以及由此补全的交互项（i_XF、i_XH、i_XFH 需要 100/101）。
