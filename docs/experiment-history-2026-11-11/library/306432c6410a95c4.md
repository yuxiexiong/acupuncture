# NPC-01 合同 r01：V、S、KV 两两组合的反向移植

依据：[NPC-01 方案 v1.1](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-native-pair-combination-v1-2026-11-03/PLAN.zh-CN.md)（main `c8c41ab`，含评审收紧后的判读措辞）。授权：2026-11-03 用户原话“直接推进吧。写代码合同，测试然后直接上卡跑到实验结束，然后上传git”。冻结后不改本文件；偏离记入 `DEVIATIONS.zh-CN.md`。

## 1. 问题

在这批输入（LVK 新面板 48 条）、固定移植切点（处理最后一个提示 token 之前）、卷积 q/k 历史保持干净的条件下，哪些受损缓存组合足以改变完整回答？逐条输入判断，再看两针的分布。不预设经过写入、读取还是后续传播。

## 2. 操作

沿用 NSR-01 与 NQK-01 的模型、两个针（L0/N4146/−1、L12/C3621/−1）、形成、切点、生成设置（贪心，最多 32 个新 token；不加针、不挂钩子、不强制前缀）、G 层（14 层）、深层 KV 层（15,19,23,27,31）、V_LO = 4096。接收者为同一输入的干净运行 C，供体为同一输入、同一针的 T：

| 格 | 换入的受损内容（其余全部保持 C，含卷积 q/k 历史） |
|---|---|
| CSV | G 层 S＋G 层卷积 V 通道 [V_LO:] |
| CSK | G 层 S＋深层 KV |
| CVK | G 层卷积 V 通道 [V_LO:]＋深层 KV |

另跑 C 与两针 T 作桥接端点。单组（CS、CV、CK）与 CJ 取自 NSR-01，V＋S＋KV（CVSK）取自 NQK-01，逐输入配对。每条输入 9 条自然轨迹。

## 3. 读数

- 主读数：自然完整回答（48 条）；相对 C 的改坏数与场景数；异常类型（停止 / 错选编号 / 混合编号 / 其他，NSR-01 冻结定义）。
- 逐条配对：每格改坏的输入中，在 CVSK、CJ、T 中也改坏的数量、异常类型相同的数量、输出文本完全相同的数量。
- **逐条最小致错组合**（已测分组内）：
  - 某条输入在某个两两组合下出错、而组合内两个单组都不出错 → 该组合是这条输入的一个最小致错组合（一条输入可能有多个）；
  - 三个两两组合都不出错、只有 CVSK 出错 → “需要三块”；
  - 有单组出错 → “单组足够”（预期为 0）；
  - CVSK 也不出错 → “未致错”。
  
  某两两组合出错而 CVSK 不出错时，单独标记。报告每针各类输入数、各两两组合作为最小组合的次数、最小组合集合的分布。结论由这一分布给出，不由各组合的错误总数概括。
- 首步描述同前，只描述。汇总：逐输入、六场景等权，场景分层 bootstrap（2000 次，种子 20261103）。不算比例，不设总标签。

## 4. 判读（逐针分别读；部分复现照实报告）

| 观察 | 支持的读法 | 不能说的 |
|---|---|---|
| 多数输入的最小组合含 S（CSV 或 CSK），CVK 少有 | S 与 V 历史或 KV 的联合变化足以致错 | “受损 V 把受损 S 读错了”；这就是原生损伤路径 |
| 多数输入的最小组合是 CVK | V 历史与 KV 的联合变化足以致错，不需要受损 S | S 与损伤无关 |
| 三个两两组合各自带入一部分输入 | 不同输入的最小组合不同 | 对所有输入“任意两块都够”；识别出三条独立路径 |
| 多数输入“需要三块” | 已测分组内，这些输入需要三块同时受损 | 三块各自承载什么 |
| 两针不同 | 两针的组合要求不同，作为条件差异保留 | 把差异归给层号 |

措辞限制：都是干净背景中的移植结果，是混合缓存干预的总效果；致错的组合是“充分”，不证明“必要”；不是原生损伤路径。只说“不含受损 q/k 的组合已足以致错”，不说“q/k 已被排除”。

**工作预测**（数据前登记，弱推测，只写方向）：含 S 的组合比 CVK 更常成为最小致错组合。依据较弱：跨输入干净 S 能带入供体答案，只说明 S 能影响答案选择，不说明同一输入受损的 S 保留了什么。本轮不是对“受损信息被错误读取”的检验。

## 5. 工程闸门（运行中断言，任一失败即停）

1. 形成 hash 等于 NCC-01、NSR-01、NQK-01；C 与两针 T 的 t1 bf16 logits 和自然 token 等于 NCC-01 正式记录。
2. 每格目标张量等于 T（V 只换 [V_LO:]，卷积 q/k 保持 C），其余所有张量逐位等于 C；接收者与 T 前后 hash 不变。
3. 布局、停止集合与解析器一致。
4. 预检自换（以 C 为供体，S＋V 组）：缓存不变、t1 等于 C（2 次工程前向）。
5. 分析端：NSR-01、NQK-01 记录 sha 一致；本轮 T 的自然 token 等于 NSR-01、NQK-01 的 T。

6.2 演示（`test_npc.py`）：三格切片与保留、违规拦截、最小组合各类别的可达与不可达、分析入口端到端。冻结前真实模型冒烟须全部通过。
