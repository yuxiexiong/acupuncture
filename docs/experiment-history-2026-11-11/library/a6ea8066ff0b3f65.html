主张审计卡：撤针后行为残留的可预测性（零 GPU）

日期：2026-11-01（UTC）。审计对象：候选主张「稀疏 MLP 通道干预撤除后的行为残留，可由撤针时可测的状态差异（KV / 递推 / 卷积三类，及其后续更新与读取条件）在未见条件上提前预测，且预测力超过廉价基线（撤针前效应强度、针位早晚、扰动幅度）」。

审计方式：只读本仓库已归档的正式记录与分析文件（早层输入约束 v1、CFM-S1/S2/S3/E2、COMBO、HF 配置），重算廉价基线；不跑 GPU；文献查重单独一节。数字全部来自 analysis/*.json 与各 REPORT，n 以情景计（每锚点 6 个旧情景），不报显著性。

0. 结论（三选一）

不上卡。 理由按强弱排：

  1. 停嘴读数上有三处直接反证：撤针后状态差异大，停嘴行为却为零。 - S2 10 臂（L0 只在前段扎针、b 处撤）：末尾 L16–18 状态差异保留 r10 = 0.57–0.64，首步 EOS 0/12，D 残留 −0.10–0.30。 - S3 post11（针全程在，τ 后把写更新与读取换干净）：停止分数偏移保留 0.52–0.62，首步 EOS 由 12/12 降到 0/12。 - E2 a 格（第 13–31 层缓存装进干净浅层）：D 移动保留 0.75–0.94，首步停止 0/12。 - S1 §5：两锚点 L16–18 的 ΔS 与读出差量级相近，只有 L0 首步 EOS。
  2. 事实使用读数上，预测变量与层位共线，分不开：L0 早段撤针后事实丢失残留 0.79–1.00（贴顶、无变异），L12 为 0.31–0.94；撤针时状态差异 L0 0.73–0.85、L12 0.51–0.62。只有两个锚点，「状态差异大→残留大」与「L0 vs L12」是同一条信息。锚点内 n=6 的相关（§3）没有零分布，不能当证据。
  3. 唯一的行为级持续性数据（10-29 自由生成三臂）没有同时测状态，其预测变量就是层位——廉价基线本身。
  4. 主张把三种不同的「撤针」混在一起（§1），用 CFM 系列的计算替换结果去支持时序持续性，口径不对。
  5. 廉价基线清单不全：Liu 2606.19831 §7.3 在稠密模型上做过单通道钳位→释放→残留，并归因于已生成文本（§7）。按青蒿素原则这是先例与资源，不是否证——它给出一条我漏掉的、最难打的基线「只回放已生成文本、重建缓存」，以及一个必须排除的竞争解释（残留是文本惯性）。候选主张在没有核算这条基线之前不能上卡。（11-01 更正：本条初稿写成「A+B 段已被占」并列为不上卡理由，违反青蒿素原则，已改；裁决只依赖第 1–4 条。）

不上卡 ≠ 课题判死。按同一原则，Liu 的文本解释正好在 10-29 三臂 L2/N5063 上不成立（撤针不恢复、无针重建恢复），这是本审计里最有可能回答「谁改做法」的线索（§7）。§4 列出两条能从现有机制结果推出、可预注册、有撤回条件的预测；它们是候选，不是主张。

1. 「撤针」在本仓库有三种含义

含义 实验 操作 读数时刻 能回答什么
(a) 时序撤针 S2 10 臂 针只在 E 段（模板头至事实末），b 后原生继续，针不再加 末提示 token 首步（teacher forcing） 早段针留下的东西在原生后续下还剩多少
(b) 计算替换 S3 post、E2、BRIDGE、COMBO 针全程在到 τ；τ 后把某类缓存 / 写更新 / 读取换成干净值 τ 后首步 效应此刻存在于哪类状态，不是时间上的消退
(c) 自由生成撤针 早层输入约束 v1 撤针三臂 针在提示与前 k 个生成 token；k 后撤针继续生成；另有无针重建臂 后续自由生成是否仍异常 异常由当前注入、受干预的内部状态还是已生成文字维持

候选主张说的是 (c)。(a) 是最接近的受控版本，但只有首步 teacher-forcing 读数。(b) 不是撤针，不能用来支持「残留多久」。

4. 从已有机制结果能推出的可预注册预测（候选，未上卡）

P-conv（推导：结构；数值：推测）。 Qwen3.5-4B 的 linear_conv_kernel_dim = 4（HF 配置），卷积缓冲只保存最近 4 个 token 的输入。COMBO 显示首步停止效应单换卷积缓冲 F 可复现 0.53–0.74。所以在 (c) 型自由生成撤针下，F 直接承载的那部分在 ≥4 个干净 token 后按构造被覆盖。预测：撤针后停止倾向（逐步 D 或 EOS 对数概率优势）在前 4 个 token 内下降至少约一半；之后若仍残留，只能由递推 S / KV 携带，或由 S/KV 的差异把 F 重新写脏（S2 §5「撤针后写入差异继续产生」就是这条通路）。撤回条件：若撤针后第 5–8 个 token 的 D 仍保留 >0.7 倍撤针时值，则「F 是首步主要载体」在时序意义上不成立——COMBO 的首步份额不能解读为时序承载。基线：层位（L0 与 L12 都要测，预测两者 4 token 内都下降）。

P-self（推测）。 S2 §5：早段撤针后 L0 的写入差异为直接加针时的 38–92%、L12 为 13–53%。预测：撤针后前 2 个 token 的 u_B 比值预测更长视野（≥8 token 自由生成）的事实残留，优于撤针前效应强度。撤回条件：在 ≥12 个新情景上，Spearman 不高于用随机方向同幅针得到的零分布上界，或不高于层位单独给出的预测。现有数据不支持开这项检验：只有两个锚点，u_B 比值与层位共线；需要 ≥3 根同层不同通道、撤针后写入差异分散的针（跨通道 v1 的 14 根 L0 针里，−0.5 剂量有分化，但没做过撤针）。

6. 审计中发现并更正的本人前期判断

  • 「撤针后停嘴约一半仍在」：实际是分数偏移保留，EOS 0/12（S3 报告勘误已有，我在 11-01 讨论中仍沿用旧说法）。
  • 「L0 撤针后不衰减、L12 衰减」：指 L16–18 写入差异范数，不是行为；且该范数不预测行为（S1 §5、S2 §7）。
  • 「残留可由落在哪类状态预测」：三处反证，见 §0。
  • 「r10 支持状态量预测残留」：末尾量，有泄漏；撤针时量 0.26–0.54。

7. 文献查重（七步，一轮，约 35 条查询，取到 36 篇摘要或正文；子代理执行，本人未逐篇复核）

坏消息先说。

  1. A+B 段（单通道钳位→撤除→残留）已被 Liu 2606.19831 §7.3 做过［正文］：在 Llama-3.1-8B 与稠密 Qwen3-4B 上沿 down_proj 列驱动单神经元、释放后测残留——语言翻转释放后持续 0.83–1.0，算子翻转回落 0.08–0.33；用反向驱动与「强制开头」对照（11/12 仅靠已生成开头文本即可延续，不注入）把残留归因于已生成的上下文（"in-context momentum, not a neuron-held bistable state"）。它没拆 KV/递推/卷积、没做状态差异预测、模型是稠密的。后果：我们的廉价基线清单漏了最强的一个——只回放已生成文本、重建缓存（Closing the Causal Loop〔NeurIPS'26 WS〕的「公共路 vs 私有路」六格框架就是检验它的工具）。任何残留主张都必须先打败这条基线，否则是重复 Liu 的归因。
  2. 递推分量的「可预测性」在模板层已有解析结果：S0 Tuning 2604.01168［正文］在 Qwen3.5-4B 上把初始态影响写成逐 token 门控矩阵乘积，预测并实测指数衰减（到提示末 KL 占比 0.03%）；2609.04098［摘要］报告 GDN「数百步内遗忘状态脉冲、噪声不累积」。所以「递推状态差异按门控衰减」是平凡推论；只有「残留取决于后续写入与现有记忆的重叠」（2609.33093 的先例）那半句不平凡。
  3. 两处检索空白：(i) 没有任何工作对混合模型的短卷积缓冲做过干预/归因（可能是检索词问题，该对象没有统一名称，不能当作确认空白）；(ii) 没有任何工作把「干预后状态差异」作预测变量并与简单基线比较（对抗检索 (c) 未命中；最近的 2609.05882 结论是状态差异签名任务相关、非通用，是负面先例）。

与本仓库 10-29 撤针三臂的关系（类比档）。 三臂里的「无针重建」臂就是 Liu 的文本基线。L2/N5063 +1 的结果（撤针不恢复、无针重建恢复：开发 4/4，确认 18/20、9/9）与 Liu 相反——残留由内部状态而非文本携带；L25/N2747 则与 Liu 一致（k=16 重建仍异常 24/24）。这是本次审计里唯一一条相对 prior art 有对象层差异的线索：混合模型早层针的残留走私有路。但它只有一根针、没有状态测量、与 CFM 系列的针不同，只能作为下一轮候选的起点，不是结论。
