# 四方向在两个 k 条件下的目标支持、幅度与来源作用

2026-11-08。承接同一主线：针怎样改变历史来源的写入及其答案作用。本轮仅读取冻结 NMT 汇总并逐格作差；不改主线、论文、历史结果，不设计或运行新实验。没有模型加载、前向、GPU、新拟合或新显著性检验。

## 1. 对象与定义

来源：[冻结NMT分析](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-increment-norm-match-v2-2026-11-03/analysis/nmt-readouts-r01.json)，固定提交 `ce497e411`，SHA256见 [contrast.json](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-write-factor-audit-2026-11-08/contrast.json)。[提取脚本](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-write-factor-audit-2026-11-08/contrast.py)只用标准库，核对两条端点作差路径、原始H和D_src，16组全部误差小于1e−12。

M为固定共同前缀下的t2目标token减竞争token的分数，不是正确率。主表沿用目标非首列32条、六场景等权；48条补充读数在JSON中单列。完整回答Y使用全48条；不可拿32条均值当逐例答案阈值。

固定接收背景r及k条件b，令Z为不加入该增量的接收基底，F0为加入原生来源增量，F1为加入恢复来源增量，FUP为保留原生增量方向、逐层逐头匹配恢复来源幅度，FDN为恢复来源方向配原生幅度。b=0不修正写入k，b=1修正写入k。

- 原生增量基础支持：P_b=F0_b−Z_b。它不是“没有k操作时”的同义词，两个b分别有一个P。
- 原生方向上的幅度作用：A_b=FUP_b−F0_b。
- 恢复幅度下的等幅来源作用：Q_b=F1_b−FUP_b。两个增量的逐层逐头范数相同，矩阵方向/结构不同；其后续响应自由发生。此对比不识别独立语义内容、具体k/v角度或某个读出部件。
- 完整来源作用：T_b=F1_b−F0_b=A_b+Q_b。
- 来源对k条件增益的影响：D_src=T_1−T_0=(A_1−A_0)+(Q_1−Q_0)。这是端点作差恒等式，不是新的神经计算定律或可独立相加的自然机制份额。

- 三个主要方向的幅度匹配在b=1增加正确数，在b=0未增加；等幅来源比较仍可继续改善回答。N1210在b=0的19→27说明来源优势不应只用k交互概括。
- C1343从基底起已48/48，不能凭正确数不变否定其连续分数效应。原生接收背景受移植前停止限制，不能作为自然恢复阴性。
- 跨方向的基础支持和完整回答余量不同；但“天花板”只解释Y无法增加，不能代替对M或条件差的解释。没有用平均M推断逐例阈值，也未声称它预测完整回答。

## 4. 最有支持的解释与仍属假设的部分

**已支持的局部计算关系：** 来源对答案竞争的作用同时取决于写入幅度配置及等幅状态增量的方向/结构；二者对两个k条件的作用偏好可同向或反向。四个方向共享幅度增强b=1的效应，C1343的分叉主要体现在等幅来源改变更改善b=0。这是已有有限干预下的行为关系，保留NMT贡献并具体解释其来源差读数的分叉；不宣称完整原生机制。

**最值得保留的内部计算假设：** 等幅来源变化改变了任务相关的有效读出，使其目标支持在两个k条件间重新分布。单层固定读者时，直接读取满足ΔD=αX^Tq；同范数的X仍可产生不同的目标相关向量。对有限跨层干预，q、α及后续映射也会响应，因此现有Q不能唯一归到一个夹角、D用途或下游敏感度。公式本身早已确定，不是发现。

与竞争解释对照：

- “只有幅度大小决定来源优势”：不足。幅度作用的条件差四方向同为正，来源条件差却可抵消，且等幅来源比较有直接效应。
- “C1343不读取这项增量”：不符。其原生增量在b=1已有很强支持，幅度操作也有效。
- “只是正确率天花板”：只解释Y，不解释连续M中的同向/抵消关系。
- “全部来自接收背景”：不足。上述分叉在各自固定接收背景内出现，且两个背景方向一致；接收背景仍影响量级。
- “一个确定的q/k夹角或β开关已解释全部”：未获支持。β与‖k̄‖仍未分离，已有NBR投影对线性化点敏感，不足以完成此归因。
