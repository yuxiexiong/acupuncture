## 1. 核心问题先固定

**暂时的稀疏激活干预怎样改变每一步写入的信号，以及已有信号的保留、衰减和修正；这些变化分别或共同通过什么路径，影响撤针后的回答？**

这轮要测的是机制，不是继续发现A/B都非零。判据必须涉及：实际改变某类形成驱动后，同一个模型输出是否按事前机制解释改变；改变其他驱动是否得到不同结果；这种解释是否在未用来选择解释的条件成立。

S1/S2给出候选机制所需的真实轨迹与约束，没有确认下面任何一种机制。尤其N包含后续写入及其随后处理，不能据N占优直接选“写入解释”。

依据：[S1结果复核](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-formation-mechanism-s1-result-review-v1-2026-10-31.zh-CN.md)、[S2结果复核](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-formation-mechanism-s2-result-review-v1-2026-10-31.zh-CN.md)。S2的两个实质约束是：同起点第一步的两种作用已经同时改变，因此不能全归于起点不同；只早段开针仍改变后段形成，因此不需要后段针持续存在。但这都没有指出哪条形成支路造成候选回答变化。只早针L0首步EOS为0/12，同时候选事实敏感度很低，要求将事实响应和停止分开解释；本轮不把停止恢复当成事实使用恢复。

## 2. 现在要区分的机制解释

更新写作 `S_t=α_t(I−β_t k_t k_tᵀ)S_(t−1)+β_t k_t v_tᵀ`。这只是定义。机制假设要预测输出，而非仅预测分项非零。

| 候选解释 | 实际内容 | 在过程干预下的不同预测 |
| --- | --- | --- |
| M_V：value信号路径 | 干预改变了value支路的写入信号，其后续形成效应足以解释指定回答变化 | 固定其余形成驱动，输出主要随v的来源切换；改变α/共享驱动而保持v来源，不应产生同量级、同性质的输出变化 |
| M_α：衰减/保留路径 | 改变对已有状态的衰减，是该窗口输出变化的主要来源 | 输出主要随α来源变化，v单独切换不能重现该响应 |
| M_J：共享更新路径 | key/β变化同时改变旧预测扣除与写入地址/强度，不能归成两个独立过程 | 输出主要随(k,β)成束来源变化；单换v或α不充分 |
| M_mix：明确的多支路依赖 | 两个或多个驱动必须按特定组合共同变化，或效应相互抵消 | 单因素模型不能预测交叉条件；需预定多因素对照验证组合，而非仅说“有交互” |
| M_out：当前局部形成解释不足 | 关键效应已在b前形成或由其他路径承载，这个后段目标组不足以解释 | 即使把目标形成驱动整组改回对照，原输出偏离也未按预测改变；或只有异常混合条件产生效果 |

M_V不是全部写入机制，M_α不是全部旧状态处理。它们加上共享组J覆盖本地更新所用的α、β、k、v；J的key/β在两种用途上始终同步。如果J重要，结论可以是一个共同更新机制的证据，不能强拆成唯一写入/保留份额，也不能说已区分J内部的key与β。

这里“旧状态”指每一步更新前的全部状态，也包含b之后较早几步的新写入，不仅是b处旧来源H。只钉住α还不能固定旧状态处理算子，必须同时钉住J；只钉住v也不能固定写入项，必须同时钉住J。这正是不能把原v/α两格简单改名为写入/处理实验的原因。

## 3. 先对准一个已有未解现象，不改课题

主比较固定为S2的10（仅E段原针）对00，过程操作窗口固定b+1至τ。这里原针已经关闭，仍存在后续写入/处理差异；L0-10不首步停止而候选事实敏感度很低，L12变化较弱且有VAR01反例。这个选择用于研究**撤针后的继续形成如何作用于回答**，不宣称覆盖b前所有成因。

保持原模型revision、精度、校准、token、两锚点和L16–18。目标组三层的全部头作为既定候选，不按新干预结果挑头或扩大窗口。读取从完整轨迹继续：末提示、候选以及需要的自由回答均无原针、无过程钩子。已有S2的10/00用作供体和基线；不能把b起点不同的两条轨迹当同起点实验。

同一接收背景中的所有过程条件从同一完整前史开始：T背景均为原10的E段，C背景均为00的E段。两个背景分别报告，不能跨背景平均后声称纯效应。E段历史本身不交换。

## 4. 主要对照：三个真实驱动因素的完整交叉，而非A/B拼接

记V=v，F=α（实现可在对应log-decay节点操作），J=(k,β)。每组取同题同位置的00来源或10来源。主控制运行在b+1..τ每步、每目标层都固定全部三个形成驱动组，运行八种来源组合；q、输出门、残差、其他缓存和完整后续网络照常计算。

| 因素切换 | 整个窗口固定什么 | 直接改变什么 |
| --- | --- | --- |
| 只变V | 整段F/J驱动序列固定 | B中value信号；目标A在整个窗口不变 |
| 只变F | 整段V/J驱动序列固定 | A的衰减；目标B在整个窗口不变 |
| 只变J | 整段V/F驱动序列固定 | key/β在扣除旧预测与写入中的共同作用 |

源key的归一化和共享头展开只按原实现处理一次，同一key/β用于全部用途；不构造A_C+B_T，不补偿βv，不造p/β的value。每条条件完整前向，目标状态从自身前史累积，不把三层各自离线末态拼回模型。

完整八格包含全部单项、两项和三项组合。它回答的是“在所定义固定形成驱动下，这个因素及组合是否造成指定输出变化”。后续跨层响应和其他历史变化保留；但它们重新改变目标组形成驱动的路径被钉住。因此该结果不是未经控制的自然过程总效应。

这解决了旧单换v/α设计的两个缺口：不漏掉共享驱动J；另一类目标形成驱动在**整个窗口**都固定，而非只在当前一步固定。它没有解决所有自然联合分布问题：不同来源的V/F/J仍可能不是一个自然hidden会共同产生的组合，不能因原更新公式合法就宣布没有失配。

## 5. 机制解释必须预测未见的交叉输出

每个接收背景先计算八格中全00来源、全10来源两端点，记输出Q为Y0、Y1。Q仍为原正确候选相对另一候选的总对数似然差，同一事实定向；原S_fact、首步logits及原文另报。

机制模型不看其余六格再拟合。例如M_V预测：所有V取00的格接近Y0，所有V取10的格接近Y1，不论F/J；M_α和M_J分别按自己的来源作同样预言。把六格预测写入后再打开实际结果。三个模型最多只有两端点值，没有用六格重估的自由参数。

“接近”预先用输出端点跨度的10%作为本轮近似机制模型的**容许预测误差**，并与工程误差分开报告。它不是自然显著性切点，也不是证明主因的阈值；所有原值/误差都展示。端点跨度必须至少是对应工程误差的100倍，否则本背景不做机制模型选择，避免所有平坦模型虚假通过。即使通过该阈值，还须通过下节的活模型和事实方向检验。

这个检验不同于“恢复哪个节点后效果最大”：六个交叉条件会使不同机制模型给出不同预言。一个模型若仅解释一个有利格、在其他格失准，就不能保留为充分解释。

拒绝M_V等单因素模型只排除该因素足以概括这张控制表的强解释，不能推出该支路没有作用。为避免再次只得出“两条都有作用”，同时预定检验**可加机制模型**：用000及三个单因素条件估计三个输出效应，预测三个双因素条件和111，形式为 `Ŷ_ijk=Y_000+i(Y_100−Y_000)+j(Y_010−Y_000)+k(Y_001−Y_000)`。后四格不得用于调系数。若成功，说明在此控制政策下，各驱动对回答的作用可由分开的效应近似预测；若失败，检查究竟哪个组合偏离、是增强还是抵消。这不是状态恒等式：非线性的完整模型输出没有义务满足它。

全组端点跨度太小仅停止前述单因素端点模型选择，不能忽略可能相互抵消的单项大效应。可加模型的归一误差另用000及三个单因素输出的最大差异，仍要求超过工程误差100倍；不能用待预测的组合结果调整误差尺度。10%容许误差预先固定，并同时公开绝对误差和离散候选选择是否变化。

若三种单因素模型都失败，报告具体组合效应，不事后把任意八格拟合称为M_mix已验证。候选两因素规则须在开发情景上提出，并在未用来选择规则的情景/活模型运行中检验。若无法预先提出有区分力的输出预测，本轮停在未识别，不自动加层或新网格。

同背景的Y0/Y1并不等于天然C/T的两个端点：只有使用接收方自身全部驱动的一端应重放原接收轨迹。另一端是新过程干预结果。如果整组驱动纠正仍不能改变所需的输出效应，不能以某个混合格偶然恢复来宣布解释了原异常。

## 6. 原机制验证：控制运行的成功还不够

### 6.1 活模型复核：不钉住其余形成驱动

对预先声明将进入复核的因素/组合，在相同接收背景只干预该组，其他α/β/k/v由当前完整网络正常重算；q、门、KV与后续读取也正常响应。源值仍来自同题同位置，J始终两用途一致。两方向分别测试：原10中引入00来源，以及00中引入10来源。

- 控制运行与活模型均呈预测的输出方向和事实响应，支持这条实际驱动路径参与原干预效应；不能仅凭控制运行有作用就过关。
- 只有控制运行有效：效果依赖人为阻断后续响应，不能提升为原生机制结论。
- 只有活模型有效：与经后续变量的间接作用或背景依赖相容；仅这一对比较不能唯一识别间接路径，更不能称纯写入或纯衰减效应。
- 两者差值不命名为严格间接因果贡献，也不与局部状态差相加。它们是不同控制政策下的效应。

为避免只复核赢者，活模型核对固定包含V、F、J三个单组和全部三组共同切换；若开发结果提出一个两组联合解释，再加该预先冻结的组合。不得只选一个效果很弱的竞争对照。共享变量可以构成答案的联合部分，不能隐藏。

### 6.2 区分事实相关机制与一般扰乱/补偿

同源回填应重放原轨迹；全组自身来源是工程参照，不算机制支持。分别核对干预造成的状态/读出变化是否沿事前候选机制预期传播，以及同一个Q和实际回答是否按预期变化。

若提出的是“value承载事实相关写入”的解释，还须用同情景另一事实版本的value供体作竞争对照，测试输出是否向**供体事实对应候选**移动，而非任何供体都让正确率变好。只在既有区段token一一对齐、长度/位置可认证的情景执行；不同事实token长度不一致不能按索引强行交换。不能认证则该语义写入解释未获此项验证，不能换一个容易配对的情景隐瞒缺口。

对衰减和J解释不能要求value式的事实翻转。必须分别写清应保留/削弱哪一已有来源的读取、输出朝何方向变化，且两个事实版本都应符合；不能只写“有影响”。若改善输出却不出现预期的过程/读取变化，补偿解释仍在，不判机制支持。

来源都是真实数值、自供体正确、双向有效、范数正常，均不能单独证明混合条件自然合理；活模型、事实方向和未用于挑模型的情景的一致预测只是加强证据，不是消除一切替代解释的证书。只在混合格有异常、在活模型/确认情景不成立时，明确失败。

整组切换不恢复回答也不等于目标组完全无因果作用：单项效应可能抵消，其他路径可能维持原输出。它反驳的是“本窗口目标组形成驱动的替换足以纠正该输出”的解释。反过来，恢复回答也可能是补偿，必须与事前过程预测、反向转移及确认条件一起判断。即使所有检验通过，也不报告与控制政策无关的唯一直接/间接百分比。

## 7. 一轮预算与冻结顺序

先完成无需GPU的供体/对齐/实现路径审计，利用已存S2轨迹写出各候选模型对交叉条件的预测形式；不重新扫描层、头或针。

第一轮开发固定VAR01、VAR02，各两事实、两针、两接收背景、八格：128逻辑条件；共享无针自身来源去重后最多124条唯一完整轨迹，其中112为非自身驱动组合，12为基线重放/验收。每条末提示和两候选，无梯度；此前36/84端点数据优先复用，但新过程轨迹必须完整前向，不能假装只读Mτ即可。当前没有卡时实测，不承诺GPU小时。

其余VRD01/02、VRL01/02保留为**未用来选择过程干预解释的情景**；原生结果已见，不能叫全新题留出。确认模块检验冻结候选预测和上述固定活模型对照，不预先铺开第二个完整网格。其具体预测、所需交叉格、供体合法性和资源上限必须在开发结果给出后列明再运行；本稿不授权两模块连续自动启动。若没有可供确认的区分性预测，停止，不补跑更多观察。124条开发轨迹不等于完成机制验证的总预算。

实际回答只在形成对照已给出可区分预测的条件上，连同其预定竞争对照和原基线按原greedy/128token完整保留。Q改变但内容不变时，只能报告分数机制；不屏蔽EOS或修改题目制造任务效应。任何新生成的范围在实施合同内固定，不能临时只读成功样本。

这个设计不是承诺两情景就能确认普遍机制。开发对照用于排除机制模型，未使用条件上的检验用于判断它是否超出这张人工控制表；没有后者，不以“已找到机制”结案。

## 8. 自审：是否又走回旧漏洞

| 检查 | 处理与剩余边界 |
| --- | --- |
| 还是只观察两项都变吗 | 否，实际干预驱动并读取输出，候选机制要预测六个交叉条件 |
| 只测v/α却声称穷尽写入/处理吗 | 否，共享J单列并完整交叉；其联合部分不强行二分 |
| 后续变量变了却称纯效应吗 | 控制运行整段钉住另两组；活模型另报总效果，二者不混同 |
| 又用βv补偿或非法A/B组合吗 | 不补偿，每步只有一份共享key/β并按原式更新；仍承认联合分布失配风险 |
| 恢复就等于原因吗 | 不等于；要求交叉预测、竞争对照、双背景/活模型及相应事实方向/确认检验 |
| 一切交互都叫协作机制吗 | 否，任意M_mix拟合不算验证；须有未用于挑模型的预测成功 |
| 能完整解释所有早期/晚期路径吗 | 不能。此次直接检验后段目标组的形成路径，b前及其他层作用保留；失败不得改题找新热点 |

原理依据是以干预检验一个可解释因果模型能否预测神经网络反事实输出，而非用重建正确或归因数值自证机制。[Geiger等，Causal Abstractions of Neural Networks，NeurIPS 2021](https://proceedings.neurips.cc/paper/2021/file/4f5c422f4d49a5a807eda27434231040-Paper.pdf)与[JMLR 2025，Causal Abstraction for Mechanistic Interpretability](https://www.jmlr.org/papers/volume26/23-0058/23-0058.pdf)提供这类方法论基础，不是当前Qwen机制的实验证据。仍承接项目已核对的WriteSAE写入—传播—读取工作，不宣称提出新的干预理论。

**这轮的科学交付应是：某个具体驱动路径/组合对实际输出具有可重复、可预测、受对照约束的作用，或者这些机制模型被反驳/仍不可区分。** 不再以“记录更细”“两项均非零”“梯度归因闭合”作为机制完成标准。它提供机制实验，不保证实验必有正面或完整结果；原第三阶段继续暂停。
