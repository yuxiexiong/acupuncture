# SRU-01 决策日志（冻结前）

- S1 编号是 3 个 token（新旧面板 144/144 都是）。我审阅时假设“共享首 token + 一个区分 token”，不对；选择仍在 t2，但第三 token 在 t3 用接收者原生 S₂ 补全。因此加描述性读数“t2 选择正确”，主终点不变。
- S2 工程参照：每个接收者在 C、N 两条路线各一次“a=b=0 钩子 vs 原生”的 t2 前向（共 768，低于预算上限 1536）；11 格对“原核喂 S_d”的核对在钩子内用同一复刻顺序完成，不另加整模型前向。
- S3 00 格的 C 路线前向同时捕获 q、k，用于两端点 t2 的 q/k 余弦描述（同一输入 token fF）。
- S4 设备秒上限按 worker 均分（正式每 worker 0.6 h）。
