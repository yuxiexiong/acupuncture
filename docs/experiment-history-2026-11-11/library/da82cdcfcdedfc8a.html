VLM 跨模型根因候选盘点：七个候选的证据状态与门槛

归档说明：本报告依据的全部笔记（两份共用口径、第一轮六路盘点 01–06、合并筛选 07、第二轮七步查重 11–17、A4 的工作草稿与查询日志）在同级目录 vl-cross-model-root-cause-candidates-2026-11-06/。文中用反引号写出的笔记文件名都指这个目录下的文件。无模型运行，零 GPU。

本报告回答三件事：视觉语言模型（VLM）里哪些失败现象同时满足"现象跨模型成立、根因也跨模型存在"；每个候选上竞争者做了什么、各条轴的最高水位在哪；要构成足够的贡献至少需要做到什么。材料是 2026-11-06 的两轮笔记：第一轮六路盘点（笔记 01–06，合并筛选见 07），第二轮对过线的七个候选各做一轮七步查重（笔记 11–17）。两轮不一致处以第二轮为准。

读法约定。阅读层级：F = 取到正文并核对了对应章节或表；A = 只读摘要；S = 只有检索片段或标题。推断档位：推导（有论证链）、类比（相邻领域证据）、推测（需独立验证）。"多少""何时""在哪"三条轴不互推。报告只陈述证据状态和门槛，不给等级、分数或排序。"前人见过这个现象""方法已有"按先例支持处理；坏消息只指事实约束（实测否定或收窄了某条路）和竞争解释（同一现象已有另一个发表的解释）。

一、结论先行

1.1 最不利的发现（事实约束与竞争解释）

A6 注意力汇聚 token：根因主张的后半句在两个新一代模型上被实测否定。 把汇聚 token 上的注意力强行重分给图像，目标区域的注意力升到 2.6 倍，准确率持平（Qwen3-VL-8B、InternVL3.5-8B，2610.15855 附录 A.9，F）。去掉汇聚 token 后注意力回到文本一侧的汇聚 token，不是回到目标区域。第一轮记为因果证据的"重分配后 4 族涨分"只来自原作者；三处独立复现接近零或为负（2604.03316 Table 3、2605.18359 Table 2，F；第三处数字只在图里，未取到）。主张的前半句（继承自基座语言模型）已被同一篇逐字写出。

A1 看见了没用上："探针读得出"不等于"模型用的是图"。 一篇 14 个模型的工作显示：最可读的那条轴（竖直，探针 94%）换成灰图后行为不变（59% 对 59.6%），是语言先验；沿探针方向的免训练"恢复"在灰图下收益几乎一样（+19 对 +21）（2606.31257，F）。第一轮当作主要因果证据的"全序列修补翻转 60–84%"只是破坏方向，没有救回任何一个答错样本（反向翻转 0/900），录用决定原文是 "only modest causal support"（2604.09364，F）。结论句已被写出："visual utilization as the dominant bottleneck"（2610.29241 摘要）。另有一条收窄范围的结果："Answers follow the model's perception except on images that contradict a common prior"（2611.01467，F 但读得浅），若成立则 A1 主要落在先验冲突题上，与 A2 重合。

A4 物体幻觉通路：定位结果随题型重排，已有修法的收益里有评测产物。 同一模型上，头的重要性排名在两套是非题之间相关 0.82–0.84，换成同图同物体的四选一后为 0.12，换成描述任务为 0.17（LLaVA-1.5-7B，2511.17254，F）。两个带随机对照的定位结论层位相反（中深层头对早层与网络两端），任务、腐蚀方式、粒度都不同，没有被对过。对比解码在 POPE 上的收益可由"让模型多答 Yes 的提示"和"把采样退化成贪心"复现（2504.10020，F）；六种推理时修法的 CHAIR 降幅与 recall 降幅相关 r = 0.73（2609.01888，F）。POPE 在新一代模型上已量不出差别（F1 / Acc 85–91）。至少 15 种根因说法并存。

A7 位置与顺序：四个子现象里两个已有便宜修法，"同根因"没有检验级证据。 图文顺序在各模型卡默认的"图在前"约定下不出现；把问题在图后复述一遍即恢复大部分差距；Gemma-3-27B 上没有差距（2607.15565，F）。剪枝后保留原位置 id 已是通行做法（2602.03060，F）。图内位置上，直接把图像块内掩码改成双向并重训，代价只落在最前面几个 token（2603.17228，F）。多图顺序上，一篇三族工作报告注意力对着正确的图、输出 logit 被位置先验带偏（2605.11591，F）。

A5 空间关系："失败在语言侧"已被写出，同时存在相反结论。 2606.01914 写语言侧；2603.22278 写主要信号来自视觉编码器、语言模型一侧只是次要；三篇设定不同，没有判别实验。空间词偏置这一说法在较强模型上的总体效应小（Qwen2-VL-7B 修复增量 −1.1 至 +3.9 点）。基本同视角关系在行为层接近饱和；差距大的子类已移到视角变换、相机视角下的前后、朝向幅度。

A3 多物体属性绑定：定位有直接竞争解释，便宜办法的结论随模型变。 "位置 ID 由语言模型中层头计算"对上"顺序信息主要来自视觉编码器，语言模型一侧只是备份"（2603.22278，3 族，带随机方向对照；任务是空间关系查询，未测特征共享条件）。指点类提示在闭源强模型的合成刺激上已大幅见效（2512.15254，F），在开源 3–8B 模型上修不掉（2603.21746，F）。三种内部说法的主体刺激都是合成的。

A2 冲突仲裁："三类冲突共用同一仲裁节点"既没有被证明，也没有被否证。 间接证据不站在"单一节点"一边：三类同框的唯一一篇（探针级）结论是类型线性可分（2602.14518，F）；文本 LLM 上两篇报告同一批头换一种冲突就角色反转、找不到通用冲突回路（类比）。一篇方法学论文在 Qwen3-VL-8B 上实测，发现的头集的转向效果不优于层匹配随机头集（2610.13111，F；对象是视觉路由头）。"先验压过图"一侧已有不靠内部干预的修法（视觉示例 +9.7 到 +30.3 点，只读摘要；候选级先验校准 +7.8 / +7.0 点，F）。行为层的统一已有一条线性合并律（2610.19407，F）。

1.2 贯穿所有候选的事实约束

  1. 直接迁移未见。 第一轮在取到正文的机制论文里没有找到"两个骨干无亲缘关系的模型族之间，同一部件编号或同一方向直接迁移且带对照"的例子（07_SCREENING）。第二轮的补充证据同向：逐头打分在基座与其 VLM 后代之间相关 0.51–0.64，与无亲缘骨干之间 0.04–0.08（2606.15821，F）；逐层效应剖面跨模型相关 |r| ≤ 0.33，同族两个尺寸之间也不更像（2605.13156，F）；唯一声称跨骨干迁移方向的工作没有随机方向对照，公开代码是无对齐地原样相加（2505.16146，F 含代码）。跨族成立的都是"同一发现流程在各模型分别找到功能相同的部件"。
  2. "图像注意力少"这一读法已被多篇反驳（07_SCREENING；14_audit_A4 F6；16_audit_A6 第 4.4 节）。
  3. 读得出不等于用的是图，转向成功不等于恢复了视觉利用。 这一条在 A1 与 A5 上有 14 个模型的实测（2606.31257），对所有以探针或转向立论的候选都构成对照要求（推导）。
  4. 头级与方向级定位的随机对照普遍不足。 多组层匹配随机头集的分布对照（2610.13111 用 250 组）与打乱配对对照（2607.26913：正确配对修复 60/66，打乱配对 59/66）在七个候选的主要工作里都很少见（见第六节第 4 条）。
  5. 微观部件跨模型不一致。 A1、A2、A4、A5 的笔记各自记录了作者原话：机制随属性、任务、模型而变，最小修正逐模型不同。
  6. "根因在编码器"与"根因在连接器"两个前提被第一轮的探针与分部件微调证据削弱（07_SCREENING）。第二轮在空间排序任务上找到相反方向的因果证据（2603.22278），所以这条约束在该任务上要加限定（推导；两份材料的出入见第七节第 13 条）。
  7. 审稿讨论几乎没有取到。 七个候选里只有 A1 取到 2 篇论文的评审正文；其余六个为零。审稿人对因果主张、随机对照的质疑在本报告里是空的。

二、范围与做法

2.1 两轮各做了什么

第一轮盘点分六路，各写一份笔记：视觉编码器一侧（01）、视觉与语言连接处（02）、解码器内部的注意力与信息流（03）、先验压过证据与答案选择偏置（04）、机制可解释性里跨模型重复出现的内部结构（05）、可借用的外领域形式化对象（06）。六路共 147 条查询（19 + 18 + 17 + 37 + 24 + 32，取自各笔记的检索日志）。多数为关键词定位式阅读，不是通读。第一轮是盘点，不是查重。

筛选标准（07_SCREENING）有两条：现象在 ≥2 个模型族上实测；根因在 ≥2 个模型族上有因果干预证据（对内部部件消融、缩放、修补、转向后行为按预期变化）。只有相关性读数、只有重训对照、或因果证据只在一个模型族的，记为"差一步"。六路的主表条目按根因合并后，七个候选（A1–A7）过线。

第二轮查重对七个候选各做一轮七步：对抗式检索（先做，专门找能否定候选的东西）、引用链挖掘、抽象阶梯（在模板层搜整类）、方法论单独搜、蕴含检索（把预期结论写成句子去找原句）、同义术语枚举、边界申报。判"已有人做"分三层：方法层（该技术在别处用过）、对象层（有人把它用在本候选的对象上）、结论层（做完会说的那句话已有人写出）。

1. 候选是什么

现象：VLM 答错时，所需的视觉证据已经在模型内部（注意力落在正确区域，或隐藏状态里读得出来），但最终答案没用上。

4. 事实约束与竞争解释

事实约束（实测否定或收窄了某条路）：

  • 读得出不等于用的是图。 Qwen2.5-VL-7B 上竖直轴探针 94%、行为 59%；换灰图后行为 59.6%；免训练投影在灰图下 +19（看图时 +21）。原文："Probing and steering overstate grounded knowledge because they are blind to image-dependence; the arbiter is not."（2606.31257 §4.2、§5，F）
  • 转向成功不等于恢复了视觉利用。 "an intervention that moves accuracy can still act on a non-visual prior, so a behavioral success is not grounded recovery without a causal control"（同文，F）
  • 探针方向不是干预最优方向。 Qwen3-VL-8B 上单一探针方向修正 +0，而 rank-1 ReFT +58、4 成分 ICA 反射 +60（同文 §6，F）。
  • 在"裁决层"干预几乎无效。 InternVL2 在 L26 转向 ≤ +0.3%，在 L3 为 +3.4/+3.8（2604.09364 §7，F）。
  • logit 动了、答案不动。 Janus Δargmax +0.403，生成模式准确率变化 0 pp（2608.22916 §4.1，F）。
  • 提示能修掉一部分。 "先框再答"在框对时修好先验冲突下的不跟随（2611.01467，F 但读得浅）；两步法 CGR 在 8 个模型上 +2.4 至 +7.0 EM（2510.17771 Table 1，F）；visual CoT 在 10/10 模型上保持通路打开（2608.22916，F）。反面：单句指令 −0.6 至 +0.8；前缀调优补不上（2506.08008，F）。即"换提示修不了"只对最简单的提示成立。
  • 现象范围可能比定义窄。 "Answers follow the model's perception except on images that contradict a common prior"（2611.01467，2 族 6 数据集，F 但读得浅）。若成立，A1 主要落在先验冲突题上，与 A2 重合。

A2 冲突仲裁

1. 候选是什么

现象：图像与另一信息源给出不同答案时，VLM 的输出系统性地倒向其中一方，倒向哪一方随模型族、任务、问法而变。另一信息源分三类：(a) 世界知识，(b) 提示里的错误预设，(c) 随附的上下文文本。擦线成员是用户施压让步和图中文字。

根因主张：取舍由语言解码器里一小撮部件（注意力头，或隐藏状态里的低秩方向）决定。把三类并成一簇是本次盘点的归并假设，不是任何一篇论文的原话；它要回答的是"三类冲突是否共用同一个仲裁节点"。

如果做成，会写下的话（推测档）：E1「在 ≥2 个模型族上，从一类冲突定位出的头集或方向，对另外两类冲突的取舍有超出多次随机对照的因果效应」；E2（反面）「三类各有独立部件，跨类迁移与随机对照分不开」；E3「基于该节点的修复在等义改写、选项顺序置换、留出数据下保持，且不伤另一侧」。

4. 事实约束与竞争解释

事实约束：

  • 发现的头集，其转向效果可能与随机头集分不开。 2610.13111 在 Qwen3-VL-8B 上做 12 套发现方式 × 层匹配随机对照："no discovered head-set steers better than its layer-matched random sets (rank p ≥ 0.14)"；单次随机抽取的效果从 −0.34 到 +0.84。必要性检验则能分开。对象是视觉路由头，不是冲突头（F）。按这个标尺，单次 100 头对照与 5 种子对照都偏少（推导）。
  • 最能刻画表征变化的方向，不等于唯一有效的干预方向。 Prior Directions：正确配对 60/66，打乱配对 59/66（F）。

  • "先验压过图"一侧，视觉示例就能修掉一大块（2610.12942，只读摘要）。它与 VLMBias（2505.23941）的"few-shot 无效"（第一轮 F）方向相反；两者的示例构造、模型、题集是否可比没有摊开核对，笔记不把它登记为矛盾。
  • 文本 LLM 上，头的角色随冲突类型翻转，找不到通用冲突回路。 JUICE（2503.10996，F）："half of the top-performing “memory heads” in substitution conflicts become “context heads” in coherent conflicts"；2601.09445（F）："we find no evidence of a single universal circuit for handling knowledge conflict"。对 VLM 是类比档。

关于最后一条：多篇作者自己把 VLM 设定称作文本结论的多模态类比，但没有一篇在同骨干的纯文本 LLM 上跑同一干预（对象层；本轮 2 条查询）。所以"VLM 结论是文本结论的推论"目前是类比档，既未证实也未排除；已知的一处不一致是对称性（文本上较平衡，VLM 上强不对称，2606.28273）。

三类冲突是否共用同一个仲裁节点。 直接检验未检到（对象层与结论层；4 条网页检索、3 条 arXiv API、7 篇邻居的 225 条被引标题）。间接证据：2602.14518 的探针显示冲突类型线性可分，其中一类 100% 分开，另两类互相混淆 25.1% / 14.7%（相关，探针读的是"冲突类型"不是"取舍部件"）；2606.28273 同为 (a) 类的两种对比，头集只重合 61%（因果，类内）；类内迁移多处成立；文本 LLM 上不共用（类比）。小结（推导）：没有人证明共用，也没有人证明不共用；已有间接证据更像"类内可迁移、跨类至多部分重叠"。

A3 多物体属性绑定

1. 候选是什么

现象：多物体、特征相近的场景里，VLM 把属性安到错误的对象上（misbinding），并连带合取视觉搜索、场景描述、计数失败。

根因主张有三种并存的说法。甲：语言模型中层有三组"位置 ID"头（取 ID、选 ID、取特征），特征共享时塌缩。乙：概念向量在共享表征空间里几何重叠。丙：缺少串行处理，学会指点后出现 search heads。

如果做成，会写下的话（推测档）：E1「同一批刺激、≥3 族模型上，位置 ID 质量、概念向量重叠、是否串行输出三者各自解释多少绑定错误」；E2「三者是同一条因果链的不同环节，还是独立的失败来源」；E3「该根因在自然图像的绑定错误上也成立，按根因设计的干预能补回若干点，而换提示补不回」。

4. 事实约束与竞争解释

事实约束：

  • 定位有直接的竞争解释：顺序信息主要来自视觉编码器。 "this mechanism plays only a secondary role in shaping model predictions. Instead, the dominant source of spatial information originates in the vision encoder"；把编码器来源消掉后语言模型在第 11–20 层自己重建一份（2603.22278，F）。该文对 Assouel 的评语是 "they do not reveal their origin"。注意：它的任务是空间关系查询，不是特征共享条件下的属性绑定，没有测低熵条件。
  • 指点提示在开源小模型上修不掉。 "prompting models to point (PtC and # Coord) or enumerate (LtC) objects generally underperform DC."（2603.21746，F）
  • 同类提示在闭源强模型的合成刺激上已大幅见效，实拍上不稳。 SolidCount 上 Claude 4.5 Sonnet 效应量 0.291、Gemini 2.5 Pro 0.109，GPT-5 无差异；FSC-147 只有 Gemini 显著；FSCD-LVIS 都不显著（2512.15254，F）。
  • 纯文本 CoT 的效果随模型变号（2603.22278，F：提高 Qwen2-VL-2B、降低 Gemma-3-4b）。
  • 自然图像上输入级修法不通用。 裁剪在 Gemini-3.5-Flash 与 Qwen3-VL-Plus 上反而升高误绑率；instance-first 提示让 LLaVA-1.5 掉 22.58 点（2608.16805，F）。
  • LLaVA 系在多条线上表现不同，且混着地板问题。 位置 ID 的相对编码在 LLaVA 上"less pronounced"；Gaze Heads 在 LLaVA 与 Bunny 上没有；LLaVA-1.5 在 Campbell 的全部任务上很差。所以 LLaVA-1.5 上的失败不能直接当作"干净的绑定失败"（推导）。"less pronounced"差多少只在原文图里，没有取到数值。
  • 指点微调后的模型主要靠文本坐标作答。 "removing the image has little effect (<2% drop) on performance"（2603.21746，F）
  • 编码器空间 token 里绑定信息可解码：DINOv2-Large 上 92.2%（2606.03976，F）；只核对了 DINOv2-Large，没有核对 VLM 实际使用的 SigLIP / CLIP。

竞争解释：

  • 决策层偏置：目标缺席时的错误来自响应或决策层面（2610.05463，定向核对）。
  • 计数失败的四种非绑定解释：输出层（2510.19555，第一轮 F）、符号映射（2605.30170，第一轮 F）、读出方向错位（2607.09544，在 A3 笔记中为只读摘要）、进语言层后让位给文本先验（2604.10039，只读摘要）。绑定一方的证据：熵调制计数；Assouel 的头消融把计数打到 0%（只在 Qwen2.5-32B）。没有分账。
  • 指点为什么有效，有三种读法：内部串行搜索例程；文本坐标充当中间表示；外加线索诱导出跨模态的 grounding ID。
  • 理论上不可避免的读法：有限语义分辨率下容量按 1/n 塌缩（2506.14797，定向核对）。

三种说法可以排成一条链：乙的重叠发生在语言模型入口，甲的取 ID 以特征为查询、特征相近时取错，丙的串行输出绕开并行检索（推导，未被任何一篇检验）。可用于区分的现成线索：InstaBind-Lite 报告可识别来源的误绑里约 81% 来自相邻实例（推测）。

VLM 结论不是文本 LLM 实体绑定结论的直接推论（推导，三条依据见 13_audit_A3 第 4.5 节）。把"位置机制随实体数变噪、由别的机制补位"写到 VLM 上的论文未找到（结论层；第 1 步 5 条加第 3 步 3 条查询）。

A4 物体幻觉通路

1. 候选是什么

现象：VLM 在图像描述或物体存在性问答里输出图像中没有的物体。常用读数是 CHAIR（描述里幻觉物体的比例）、POPE（"图里有没有 X"的是非题）、AMBER。

根因主张：幻觉物体词的概率主要由语言解码器里少数"偏文本"的部件贡献，可以是中深层注意力头、幻觉通路部件，或一个低维线性方向或子空间；并列的说法是物体的视觉证据局部化在对应的视觉 token 上，可沿词表方向读出与擦除。

如果做成，会写下的话（推测档）：E1「同一协议下，几种说法定位到的是同一组或可分账的几组部件」；E2「这组部件在是非题、多选、自由描述之间以及模型族之间稳定，或者不稳定而由某个具名因素解释」；E3「针对共用部件的一种干预在 POPE、CHAIR、AMBER 上同时降幻觉，不降 recall 与一般能力，且优于随机部件、随机方向与 Yes 偏置对照」。

4. 事实约束与竞争解释

事实约束：

  • 头集合随题型几乎完全重排。 AllPath 以 POPE-COCO-adversarial 上的头排名为参照：LLaVA-1.5-7B 对另两个是非题集的相关为 0.82–0.84，对同图同物体的四选一为 0.1233，对描述任务为 0.1650；Qwen-VL-Chat 为 0.79 / 0.67 → 0.05 / −0.01（F）。原话："even with the same images and similar questions, when switching to MCQ format, the correlation coefficient between heads drops to only 0.1233"。这个相关只算了一类头，也没有给"同格式内换种子或换图像子集"的零带，所以"0.12 是否等于无关"缺标定（推导）。
  • 两个带随机对照的定位结论层位相反，且没有被对过。 Yang：幻觉头 "concentrated in the middle and deeper layers"（描述任务、零消融）。Dual-Pathway：幻觉通路部件 "concentrate at early layers and at network boundaries"（是非题、加噪修补、子层粒度）。差异同时混着任务、读出位置、腐蚀方式、粒度四个因素，现有文献无法分账（推导）。
  • 单一静态方向不够。 Dual-Pathway 附录：逐部件幻觉信号的首奇异方向只占方差 45.2%–68.8%；均值差投影在 3 个模型的留出集上不降幻觉（+0.0 / +1.0 / +1.5pp）（F）。
  • SSL 的"同一方向跨骨干迁移"没有随机方向对照，代码是无对齐地原样相加。 公开代码对所有模型都读同一个在 LLaVA-NeXT-8b（Llama-3）上训练的 SAE 的解码行向量，直接加到目标模型的层输出上，没有任何把 Llama-3 残差基映到 Vicuna 残差基的步骤；各模型的施加层与强度各不相同（F，含代码）。在倒数第二层加一个幅度为残差范数 80% 的固定向量本身就会改变输出分布，这是未被排除的读法，不是已证实的否定（推导）。相邻证据：TruthProbe 的逐头打分在 Vicuna-7B 与其 LLaVA 后代之间相关约 0.51–0.64，与无亲缘的 Mistral-7B 之间 "near-zero correlation (0.04–0.08)"（F）；医学 VLM 上幻觉相关的抑制类特征跨骨干相似度低至 0.25（2605.24977，F）。
  • 跨模型：宏观组织一致、微观接线不一致。 Dual-Pathway：逐层效应剖面相关 "uniformly low (|r| ≤ 0.33), and the within-family InternVL3-8B/14B comparison is no more similar than cross-family pairs"（F）。
  • "图像注意力少"的读法被收窄。 真实物体与幻觉物体 "receive equally strong visual attention in model’s mid-to-late layers"（2608.07302，F）；控制 token 位置与是否首次提及后，幻觉词的图像注意力 "comparable or higher"（HaloProbe，2604.06165，F）；Yang："increasing attention on image tokens has no effect"。
  • 已有修法的收益里有评测产物。 对比解码在 POPE 上的收益可由"让模型多答 Yes 的提示"与"把采样退化成贪心"复现（Mirage，2504.10020，NeurIPS 2025，F）；在 Qwen2.5-VL-7B 与 InternVL3-8B 上贪心解码的 CHAIR 优于对比解码，对比项换成高斯噪声分数不降（2607.25196，F）；六种推理时修法的 CHAIR 降幅与 recall 降幅相关 r = 0.73，且不迁移到 MMStar（2609.01888，F）；POPE 的读出 token 集合不同，adversarial F1 相差 6.13 点（2610.25964，F）；CHAIR 由长度与 token 上限决定。共 13 类证据，见 14_audit_A4 第 4.1 节 F7。
  • 新一代模型上存在性是非题已量不出差别，其他轴没有。 POPE：2024 年末以后的开源模型 F1 / Acc 集中在 85–91，剩余假阳性约一半是标注错或歧义。难负例上没有饱和：DASH-B 开源模型 TNR 44.8–60.2，HOPE precision 60–81。描述任务 CHAIR 随 token 上限从 8 到 45–59。属性：颜色是非题假阳性率 33.8% / 31.6%（预印本，小尺寸模型）。多轮带诱导：第 5 轮多数模型 3–11%。各轴分开，不互推（F，见 F8）。明文写"物体幻觉已基本解决"的论文未找到（结论层，1 条专门查询）。
  • 换到新一代模型后收益缩小或反向。 VTI 在 Qwen2.5-VL-7B 上 512 token CHAIR 31 → 35、MM-Vet 70.18 → 56.38；QK 在 InternVL3、Pixtral 上与随机对照分不开（F；多来自方法论文里的基线表，作者有动机）。

竞争解释：按位置列出已发表且至少一篇带干预的说法共 15 种（见 14_audit_A4 第 4.0 节）。与"偏文本的头或方向"直接竞争的有：Yes 偏置由系统 token 的注意力中介（2601.12430，仅 LLaVA 系，只读摘要与局限）；不是长度本身而是对上文的依赖（2510.20229，定点）；训练数据共现；VQ 离散化造成的第 0 层路由（2609.29048，25 个模型、8 个语言模型族，回路只在 VQ 离散化模型里出现）；"说得更少"；度量问题。

多种说法有没有被直接比较或统一。 在同一模型、同一协议下对两种以上说法做因果比较的工作未检出（对象层；4 条蕴含查询、346 条 Semantic Scholar 被引标题、43 条 OpenAlex 被引、6 份参考文献表、2 条专门查询）。最接近的三篇：Role-Break 把四家说法折算成注意力特征放进同一协议，但只做检测、没有头级干预；AllPath 把三条通路放进一个框架，但每种题型要重新找头；Dual-Pathway 在同一批部件上比了"逐部件缩放"与"静态方向"，这是头或部件说法对线性方向说法唯一的一次同协议因果比较，但只有是非题。最新三篇种子的被引侧只有 5 / 11 / 0 条，这个范围对 2026 下半年覆盖很弱。

结论层已被写出的句子："the observed performance gains in contrastive decoding are entirely unrelated to its intended goal of mitigating hallucinations"（Mirage）；"these improvements reflect a change in decoding behaviour rather than genuine hallucination mitigation"（2607.25196）。对比解码以外的修法家族未检出同类重评（对象层，3 条查询）。

A5 空间关系

1. 候选是什么

现象：VLM 在基本空间关系题上答错，包括左右、上下、前后、朝向、相对深度、视角变换。

根因主张落在三个部位。(a) 负责空间感知与关系推理的注意力头稀少且弱。(b) 语言侧的空间词偏置：选项里多一个空间词就把答案拉走，而视觉关系仍可线性读出。(c) 位置编码与位置索引的安排：图像拍平成一维、文本与图像共用索引空间。

如果做成，会写下的话（推测档）：S1「同一批模型、同一批错题上，三种说法各自能修回的错误占比与重叠」；S2「空间关系错误主要是语言侧读出问题，只改语言侧就能修回大部分」；S3「存在跨模型族一致、可免训练干预的空间部件或方向」。

第二轮查到的占位情况：S2 的结论已被写出，且有反方；S3 的对象已有人做（三种方向都在 ≥3 族上做了带对照的免训练干预）；S1 未检到（对象层与结论层；专门查询 5 条，加 6 篇邻居的被引标题）。

4. 事实约束与竞争解释

事实约束：

  • "失败在语言侧"已被写出，同时存在相反结论。 2606.01914："the failure arises on the language side rather than the visual side"；2603.22278："the dominant source of spatial information originates in the vision encoder"；2601.12626 对 LLaVA-1.5 与 Llama-3.2："linguistic reasoning was not the reason these failures occurred"。三者设定不同：第一篇的样本按构造是二选一全对的，等于预先筛掉了视觉侧失败；第二篇用的是两物体排序任务上较弱的模型；第三篇在 COCO-spatial 二选一上。没有人在同一模型同一题集上跑过两边的仪器（推导）。
  • 线性可读不等于依赖图像。 竖直轴探针 94%，真实图 58.5 与灰图 59.6 接近（2606.31257 §4，F）。2606.01914 做了空白图重训（0.137）与置乱标签对照，但没有做不匹配图对照。
  • (b) 在较强模型上的总体效应小。 修复增量：Qwen2-VL-7B 在 WhatsUp-B +0.9 / +1.9 / +3.9、VSR −1.1 / +0.0 / +3.0；LLaVA-1.5-7B 在 WhatsUp-B +38.9 / +50.6 / +49.6（2606.01914 Table 2，F）。
  • (b) 的机制证据样本很窄。 55 例按模型为 16 / 11 / 9 / 9 / 5 / 3 / 2；稀疏敲除只在 InternVL2-1B（F）。
  • (a) 的"稀缺导致失败"没有被检验。 原文用词是 "which likely contributes to the failure"；正向干预 +1.85 点（2603.20662 §6，F）。

A6 注意力汇聚 token

1. 候选是什么

现象：VLM 的语言解码器把大量图像注意力分给少数与问题无关的图像 token（下称 sink），或生成时过度依赖少数汇总 token；另有一种说法是视觉编码器的高范数伪影 token 经投影器传入后成为汇聚点。

根因主张：汇聚维度继承自基座语言模型，或来自编码器伪影；它们吸走了本应给相关图像区域的注意力预算。

如果做成，会写下的话（推测档）：E1「各篇的视觉 sink 是同一机制的产物：图像 token 落到了语言模型文本 sink 的方向上；去掉它，注意力回到文本 sink，输出不变」；E2「"该抑制"与"有用"的冲突来自各篇的 sink 不是同一批 token 或不是同一种计算」；E3「把 sink 上的注意力重分给图像 token，在严格对照下不提高准确率」。

第二轮查到的占位情况：E1 在 2610.15855 里几乎逐字出现；E2 的两半分别在 2604.03316、2605.10622、2606.08105（仅 ViT）里出现；E3 在 2610.15855 附录里出现，范围是 Qwen3-VL-8B 与 InternVL3.5-8B。

4. 事实约束与竞争解释

事实约束：

  • 根因主张的后半句在全注意力模型上被实测否定。 在 Qwen3-VL-8B、InternVL3.5-8B 上把 sink 的注意力重分给图像，目标注意力升到 2.6 倍，"Accuracy stays flat on both models for both variants."（2610.15855 附录 A.9，F）。去掉 sink 后注意力回到文本 sink，不是回到目标区域；作者的结论："The harm sinks do is therefore to anything that reads the map from outside the model."
  • 根因主张的前半句已被逐字写出。 "A visual attention sink is an image token whose key is aligned with the key of the language model’s text-sink"（同文，F）。
  • 重分配后涨分只来自原作者。 VAR 的独立复现：MMStar −0.01、CV-Bench +0.75（2604.03316 Table 3，F）；总平均 29.82 → 29.55（2605.18359 Table 2，F）；TokenPenalty（Findings of ACL 2026）称在 CHAIR 上变差（数字只在图里，未取到）。把 sink 挪到最前的独立复现为 −0.13 / −0.39。
  • 在编码器里加 register 再装进 VLM，总分不变。 八基准平均 46.2 对 46.2（2506.08010，F）。
  • 效应随任务和层变号。 "Rebalancing sink vs. ordinary attention does not uniformly help or hurt; its effect reverses across tasks."（2604.03316 §3.4，F）
  • sink 并不普遍。 10 个模型里 3 个没有；InternVL3-8B 与 InternVL3.5-8B 共用视觉编码器、语言骨干不同，sink 占图内注意力 2% 对 24%（2610.15855，F）。
  • 阈值式识别不稳（2604.03316 附录 E，F）。
  • 幻觉基准上的涨分与保守生成耦合（2609.01888，F；它复评的六种方法不含 VAR、AvisC、HAVAE）。
  • 掩蔽与置零的证据有方法学上限。 DINOv2 的 register 置零掉 36.6 个百分点，换成均值、噪声或跨图置换则在约 1 个百分点内（2604.14433，只读摘要）。

"该抑制"与"有用"两方的证据逐条见 16_audit_A6 第 4.3 节。冲突的一部分来自对象不同：EVAS（2411.09968）的阈值 0.0015 低于 576 个 token 的均匀水平，它量的实际是"对图像 token 注意力铺得开的头"，与 Kang 的对象方向相反，两者不构成冲突（推导）。另一部分来自架构：全注意力模型里 sink 不被读，Gemma-4 的滑窗层里被读（推导）。"遮掉无影响"与"探针可读"并不矛盾（推导；Choi 自己写了 "the presence of information does not imply that the model actively exploits it during inference"）。

竞争解释共 9 种：继承自语言模型的 key 偏置；编码器高范数伪影经投影器传入；两个来源并存；对齐预训练阶段学到的词表捷径（HAVAE，以 "We hypothesize" 开头）；微调早期才出现（Luo 附录）；位置编码；够不着文本 sink 时由图像 token 顶替（Gemma-4）；softmax 归一化下的空操作（文本 LLM 文献，只读摘要）；同一注意力图样对应空操作与广播两种计算（2606.08105，只读摘要，仅 ViT）。

与文本 LLM 的关系：sink token 不贡献输出、遮掉影响小、去掉后注意力回到文本 sink，这三条在 VLM 上已成文本侧解释的推论（推导）。不是推论的：哪些图像 token 会成为 sink；编码器源 sink 里可读的全局信息有没有被用；任务 × 层变号；Gemma-4 型例外；训练中在哪一步形成。

在"注意力量不等于失败"的背景下，sink 作为根因还没被反驳的具体主张有七条（16_audit_A6 第 4.7 节），其中：污染一切从外部读注意力图的方法（已被 2610.15855 写出并给了修法，是仪器问题，不是模型答错的原因）；编码器源 sink 在局部细节任务上的干扰（只在 LLaVA-1.5 一族有推理期内部干预，无随机 token 组对照）；非全注意力架构里 sink 被模型读取（只有一族）；形成机制。

A7 位置与顺序

1. 候选是什么

现象：VLM 的答案随语义无关的位置或顺序变化而变。分四个子现象：(a) 图像与问题谁在前；(b) 多图输入里图片的先后，以及描述一张图时混入另一张的内容；(c) 关键内容在图像里的位置；(d) 视觉 token 剪枝后位置 id 被重排。

根因主张：语言解码器的因果掩码加上一维或序列化的位置索引，给本来二维或无序的输入强加了一个顺序。

如果做成，会写下的话（推测档）：E1「四个子现象由同一处结构造成；同一类干预让四种敏感同时下降，且在 ≥2 个骨干无亲缘的模型族上成立」；E2「把因果掩码的可见性、token 序列顺序、位置 id 三者分开后，图内位置偏置主要由其中某一项承载」；E3「图文顺序两种排法分叉的中层窄带，与多图顺序、图内位置的失败落在同一组部件上」。

RoPE 归因。 支持方全在一维 RoPE 的 Llama 系模型上；反对方的分辨率检验做在用二维 MRoPE 的 Qwen2.5-VL 上，两边不在同一设置里（推导）。在 ≥2 个模型族上把掩码可见性、序列顺序、位置 id 三者分开的析因实验未找到（对象层，专门查询 3 条）。

与文本 LLM 的关系：(b) 的改掩码修法与文本侧 PINE（2407.01100）操作相同，是推论；(a) 的问题复述接近推论；(c) 的方向不是推论，文本理论说因果掩码偏向早位置、RoPE 偏向近位置，图像 token 上净效应取决于模型，这条预测没有人在 VLM 上检验过（类比；对象层，9 条查询）。

7. 要构成足够贡献至少需要做到什么

  1. 模型族：内部因果证据覆盖 ≥3 个骨干无亲缘的模型族；共用同一语言骨干的模型不计为两族；含至少一个对图像块用双向或前缀掩码的模型。
  2. 因果对照：在同一设置里把因果掩码可见性、token 序列顺序、位置 id 三者分开的析因干预，并带随机对照。
  3. 跨子现象：若主张同根因，同一协议同一干预至少覆盖两个子现象，并正面处理三条现有反证（注意力对而 logit 错；改掩码在 LLaVA-OneVision 上不如原模型；掩码代价只在最前面几个 token）。
  4. RoPE 争议：在一维 RoPE 与 MRoPE 各 ≥1 个模型上同时复做反光栅对照与分辨率扫描，并加入对位置编码与掩码各自的直接干预。
  5. 评测稳健性：不低于同序噪声底、筛掉题面含位置指代的多图题、配对显著性、开放式生成。
  6. 效果量：在便宜办法之上仍有增益，或在便宜办法失效的条件上有增益。已知便宜办法不足的条件：Qwen2.5-VL 上问题复述欠恢复；对抗档 N=8 的多图检索；开放式生成；(c) 没有便宜办法。
  7. 成本：免训练，推理开销不高于问题复述或单次前向校正。
  8. 统一解释：给出能同时容纳"各模型偏置形态不同"的定量预测。
  9. 在新一代模型与思考模式下报告现象幅度。
  10. 若把选项位置偏置纳入：带随机对照的内部定位，≥2 个当代 VLM 族。
  11. 基准形态：超过 FACET-PROBE 的五个面与 18 个模型；它没有覆盖图内位置、剪枝与任何内部读数。
