CFM-E2 v1 实现说明与决策日志

文件 作用
prepare_data.py 留出情景的区段标签（CFM-S1 规则）与 II-B 参照（00、L0·11），只用分词器与归档，不做模型前向
e2_transplant.py 四个原生运行（复用冻结的 CFM-S3 run_once）、按层整层移植缓存、三道闸门、冻结/授权/worker/控制器/核验
e2_analysis.py 情景层面读数、适用条件、合同 §5 的判读表；selftest 演示每一行判读与剔除、不可判都能出现
test_e2.py 小号随机 Qwen3.5 上的 CPU 测试：整条 run_item 跑通，结构、完备性与 a 格等价三道闸门都在其中

决策日志

  1. 浅层包含第 0 层。第 0 层的注意力在第 0 层 MLP（L0 针）之前计算，四个原生运行的第 0 层缓存逐位相同（闸门 2 检查），放入浅层或深层都不改变结果。
  2. a 格等价检查：由于 L12·01 的第 0–12 层就是 00 的值，a 格的缓存清单必须等于"L12·01 装上 L0·01 深层"的清单，作为 run_item 内的断言。
  3. 撤针后的计算沿用 CFM-S3 run_once 的 mtau 路径：从组合缓存的深拷贝出发，末提示 token 与候选都照常计算，没有任何钩子。
  4. 2 个 worker（每卡 1 个），规模很小，多 worker 没有收益。
  5. 判读中"a、d 都弱，而 L0·01 强"的"L0·01 强"由适用条件保证（进入判读的情景，L0·01 的 D 移动至少是 L0·11 的一半）。
