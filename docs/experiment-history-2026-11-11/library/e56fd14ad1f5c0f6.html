2. C01–C14 逐项审查

ID 判定 理由、位置及边界
C01 主线 通过 §1/§9保持视觉与先验冲突，因数据可用性换大小关系入口；没有替换为长推理、工业工作流或缓存机制
C02 增量 通过 §6区分可干预性与静态稀疏留出收益，§7要求实际行为和近邻优势；仅输出变化不算通过
C03 资产 通过 §10明确论文、数据卡、代码读取与未验收项；旧Acupuncture轨迹不冒充VLM基线；不复测已知线性代数当发现
C04 假设 通过 §4/§6面对动态有效但稀疏不成立、原版已足够好、常识受损等反例；有可行性支持而非保证
C05 操作 通过 §4.1指定矩阵、列、层数/支持上限、范数及全部位置生效；正常缓存完全随新权重形成；不是运行时激活注入
C06 路径 通过 §3只估总行为效果，输入/解码固定但下游不固定；重载消除残留hook，不声称隔离读写链
C07 耦合 通过 不做历史/当前状态拼接；gate/up保持权重但激活可以变化；两层效果实际测联合，不把原版局部拟合叠加当最终效果
C08 归因 通过 用“冻结补丁改善任务”而非“找到先验神经元/视觉机制”；有阳性也不把cue差分目标当自然原因
C09 区分 通过 §6的图像题/通常题和原图/反事实回答约束可区分单边偏置；动态与稀疏并非互斥假设；阴性仅限定搜索族
C10 指标 通过 P_img为实际双正确，A_typ及损伤率单列；两排列、四问不扩独立样本；logit和attention不替代答案
C11 失败 通过 §6分别定义数据/实现失败、预算未完成、缺口不足、静态搜索阴性；5点pilot阈值是决策门，非显著性
C12 成本 通过 当前只源代码/文献读取；缺的是该模型该任务的真实测量，旧纯文本资产不能替代；按阶段触发而非一开始多模型多数据齐跑
C13 可信度 通过，有工程前提 §2.3按语义组拆分、P0答案核对、D/V/T权限、版本哈希、全部失败、raw输出；T≥200/60组为准入，未假称已经满足
C14 累积 通过 §6–§8明确哪种结果进入正式比较、哪种停止；任何阴性不自动导向更大矩阵；有限阳性仍需近邻和保留证据

3. 历史错误对照

  • E01：保持用户选择的第一方向；任务入口变化由可访问资产决定，并在方案中解释。
  • E02：核主模型36层MLP配置，扫描开发线索而非搬用旧L12/神经元编号。
  • E03：支持数、标量数、范数分别报告；不把128列等同128参数或自动小扰动。
  • E04：ridge和ΔW·activation只是工具，不作为机制发现。
  • E07/E08/E14/E15：没有缓存混合或路径拼接；完整权重补丁只估总行为效果。
  • E09/E10/E11：关注图像双正确和通常知识，拒绝由内部差异、答案分数或翻转率推断完整能力。
  • E12：事实/反事实配对不能自动消除损伤，因此A_f、A_typ、额外保护项和正确→错误转移独立列出；随机支持不是精确零分布。
  • E16/E18：所有失败有可接受结论，静态未成功不证明信息不存在或其余机制成立。
  • E19：零补丁/重载等仅是工程验收，不当科学增量。
  • E20：动态可控制性和静态稀疏可行性可以同时成立，位置稀疏与扰动幅度分别限制。
  • E21：本轮重新核直接近邻代码可得性，不能靠旧报告宣布DARE已可运行或没有相似方法。
  • E22：两图×四类回答×顺序与重复搜索均不能扩独立样本；同物体对按组，公开基准暴露明示。
  • E23：设计自查、代码验收、模型运行、外部复现严格分开。
  • E24：不要求完整机制；有真实留出改善和强比较就有应用研究价值。
  • E25：先单模型单属性；color/第二模型属正式阶段；计数、注意力、视觉编码器不默认扩展。
  • E05/E06/E13/E17/E26：本版不操作缓存共享变量、供体、状态减法或形成/读取分离，因此其特定错误不适用；相应一般风险由C05–C08总效果定义覆盖。

4. 与前版比较

前版为 2026-11-05 选题核查报告，不是已执行协议。保留研究目标、成对正确性、能力保留及强近邻压力；本版补充操作与推断合同。

实质修改：CounterCount未有可核验下载入口，改用公开Visual CounterFact；公开数据727/493与论文计数不同，按实际版本设计；DARE仓库404，因此不可声明官方实现已准备；不因这些限制改成“输出偏好只要动了就成功”。

6. 最终判定与四种状态

2026-11-05论证补充复查：方案§1.1–§1.3新增“痛点特征→WSP适配→失效边界”论证，未改变模型、任务、编辑范围、指标、预算或执行权限。C01/C02复查通过：仍研究图像与先验冲突的能力修复，明确其学术增量；C04/C08复查通过：把“可能已有信息可利用”和“少量权重足够”分开，后者为待验证假设；C09/C14复查通过：适配理由分别落到既有P1/P2/P3，失败仍允许停止。新增最强反例是“同类错误反复出现，但产生它的计算分布广泛，无法稀疏修复”；方案明确不能从错误有规律推出故障稀疏。此次仍为同一助手自查，没有模型实验。

设计逻辑：通过。 通过的是有明确前提、失败分支、统计限制的研究方案，不是实际数据足量或实现正确的认证。当前没有已知逻辑硬伤留待用户发现。

工程验收：未完成。 仍缺完整数据标签/分组、模型与软件哈希、PvP/Nullu适配、保护题固定清单、评分器、零补丁/重载及显存吞吐。P0不通过不进入模型科学比较。DARE官方实现当前不可访问的限制已经影响比较主张，不能靠免责声明忽略。

执行授权：没有。 用户明确只做方案和自查。预算是未来拟上限，禁止据此启动模型、GPU、下载权重或替用户联系作者。

实验结果：没有。 文献阳性仅是他人报告；本项目尚无该模型×该任务的基线或补丁。最早有意义的下一证据是P1/P2的开发可行性，而不是直接宣称论文贡献成立。
