KRD-01 合同 r01：k 修复对后续历史包 H 与 t2 q 节点 Q 的条件性依赖

依据计划 docs/cache-k-repair-dependence-plan-v1-2026-11-03.zh-CN.md 与自查 docs/cache-krd-self-check-v1-2026-11-03.zh-CN.md（1ddc567c），加上我对计划的两条必补项（§6 P2、§5 特异性判据）。授权：2026-11-03 用户“开始”。冻结后不改本文件；偏离记入 DEVIATIONS.zh-CN.md。

1. 问题与估计对象

已验证的 k 去偏移修复，是否依赖 t1 后留下的历史包 H（G 层全部递推 S + A 层全部注意力 KV），以及 t2 时 G 层内核入口的 q 节点 Q；两者是否需要配合。估计对象是在指定混合背景下，受控交换 H 与钳制 Q 的条件效应、联合效应与交互。不是自然中介比例，不分 S 与 KV 各自份额，不穷尽历史路径。

2. 固定条件（继承 QKD/QSR）

模型 Qwen3.5-4B revision 851bf6e8…，BF16/eager/batch 1，torch 原核。48 条 NA 输入、6 场景、方向 N4146/N1210/R0/C1343。G=[13,14,16,17,18,20,21,22,24,25,26,28,29,30]，A=[15,19,23,27,31]。六臂 V/F/Rk/Ak/Rrk/Ark 与 QKD 完全相同，复用冻结的 μ_k、r_post,k。

3. 操作

  • 每臂从混合缓存跑 t1（提示末 token），保存 t1 后缓存 c1[arm]；t1 输出 x[arm] 即自然首 token。
  • 有序配对 r←d（接收者←供体）：Rk←V、V←Rk、Ak←F、F←Ak、Rrk←V、V←Rrk、Ark←F、F←Ark。
  • 四格 hq：H 取 d（h=1）或 r（h=0）；Q 取原始端点 d（q=1）或 r（q=0），钳制 t2 的全部 14 个 G 层。00 格就是原始 r。10 格的 Q 也钳制为 r 的原始 Q。
  • H 交换：深拷贝 c1[r]，把 G 层 recurrent_states 与 A 层 keys/values 换成 c1[d] 的克隆。闸门：KV 旧前缀逐位相同；交换后 H 部分哈希 == 供体，其余所有分量哈希 == 接收者；不共享存储。卷积缓冲（含初始编辑残留与 t1 新槽）、当前 k/v/门以及其他节点全部保持接收者版本并正常响应。
  • Q：G 层 gated-delta 内核入口的 query 参数（卷积+SiLU 后、L2 与缩放前、已广播到 32 头）。整体替换，由原核做归一化和缩放；闸门：每次 t2 前向在 14 个 G 层各触发恰好一次，内核实际收到的 query == 来源张量，前向后包装器恢复、无残留 hook。
  • C 路线：t2 输入旧 F 答案首 token（与 QKD/QSR 同）；只做 t2；M＝目标编号区别 token − 首列编号（目标在首列时用第二列）；另报目标对其余全部候选最大值的分差 M_all。Q 来源是各端点在同一 token 上的 t2。
  • N 路线：t2 输入接收者自己的 x[r]，绝不换成 F 的首 token；供体 Q 在 c1[d] 上输入同一个 x[r] 捕获（d 自身首 token 不同时额外前向一次）。x[r] 是停止符时，本格未到达，保留原停止并计入。贪心续写到停止符或共 32 个新 token（含 x）；Q 只在 t2 钳制，t3 起全部自由。

4. 读数

  • C：每格 M、M_all、全词表 bf16 logits（服务器存）。
  • N：每格完整 token 序列、文本、终止方式、是否到达 t2；Y_full 用原解析器（qst_core.y_full）判定。
  • 描述性：t1 后 Rk−V、Ak−F 的卷积 k 通道在哪些槽位有差异（编辑残留的滚动），只记录不判读。

5. 冻结判读（实用幅度规则，非显著性）

M 判据只用目标非首列的 32 条（首列 16 条另报），Y 判据用全 48 条。 1. g＝mean(M_d − M_r)。|g|<0.5 时不算比例，只报原始差，标“无诊断缺口”。 2. 诊断转移：sign(g)·mean(M_c − M_r) ≥ max(0.25, 0.25|g|)，且 ≥4/6 场景的场景均值与 g 同号。转移比例＝mean(M_c − M_r)/g，不裁剪。 3. 完整交付支持：诊断转移成立，且 Y 朝供体方向净改变 ≥2/48（同时报改对/改坏计数、净改变占端点 Y 缺口的比例、未到达数）。只有 M 变、Y 不变时，称“分差效应”，不称回答修复。 4. 交互：M 交互 I＝y11−y10−y01+y00，|mean I| > max(0.25, 0.1|g|) 才算实用交互；Y 交互 |ΣI| > 2 才算。二值饱和可造成行为交互，不当作内部协同的证据。 5. 特异性（合同补充）：共同偏移配对与结构相同的随机配对（Rk←V↔Rrk←V，V←Rk↔V←Rrk，Ak←F↔Ark←F，F←Ak↔F←Ark）比较同一格。共同格须先有诊断转移，再满足 sign(g_c)·(mean Δ_c − mean Δ_rand) ≥ max(0.25, 0.25|g_c|)，且 ≥4/6 场景同向，才算“特异”；否则“不特异”。C1343 照常报告，不算第四个修复阳性。 6. 措辞边界：Rk 中移回 V 导致修复损失，只说明在该钳制背景下存在依赖；V 中移入 Rk 得到恢复，只说明该组合在此背景下能搬运修复。不说一般的必要或充分。11 格不是全缓存重放；11 无效只说明这组节点没有搬运已知效应。

6. 预注册预测（看数据前写定）

  • P1（计划，推测档）：三个缺口方向上，Rk←V 与 V←Rk 的 11 格都有诊断转移，且有完整交付支持。允许只在部分方向成立；逐方向报告。
  • P2（合同补充，推导档）：三个缺口方向上，Rk←V 与 V←Rk 的 11 格转移比例都 < 0.9；Ak/F 一对（F←Ak、Ak←F）同理。依据：初始编辑槽的残留在 t2（旧槽 2、3）、t3（旧槽 3）仍在接收者的卷积窗口里。损失侧（接收者 Rk/Ak）的直接修复通路还在，获得侧（接收者 V/F）没有这条通路，所以预期两侧都不完整。若 P2 失败（某侧比例 ≥0.9），说明这条通路在该侧可忽略，H+Q 承担了几乎全部转移。两侧残留之差只作卷积直接通路贡献的粗略描述，不预测符号。
  • P1 完全相反时，撤回“在此条件下搬运修复”的预测，不换题。

7. 工程闸门（运行中断言，任一失败即停）

  • 六臂 t1 logits/缓存哈希 == QKF/QKD；t1 argmax == 参考轨迹首 token；t1 后浅层（<13）缓存跨六臂相同；未编辑前递推/KV 与 T 相同。
  • C 路线 00：t2 的 M 与 QKD 浮点逐位相等，bf16 全词表 logits 与 QKD 存档逐位相等。
  • N 路线 00：自然轨迹 token 序列与终止方式 == QKF（旧方向）/ QKD C1343 参考。
  • H 交换与 Q 节点闸门见 §3；所有格结束后 c1 源缓存哈希不变；C/T 供体不变。
  • 仅预检：每臂每方向，C 路线“不挂 hook”与“自体 H 交换 + 自体 Q 替换”两次前向，都与捕获前向逐位相同（共 96 次工程前向）。
  • 预检失败：保存证据并停止；计划允许一次有记录的预检修复重试（新版本号与授权）。正式开始后不改实现。
