1. 结论（不利的先说）

  1. 出口 (2)：得不出可区分的计算预测，本条记录分析分支到此结束。 FIX 的所有冻结跨方向标签都不是集中型：S_MLP 在子表和主表上都是“分布式”，同一步占比都是“混合”，头块在子表和主表上也都是“混合”；原空间与投影空间一致，不存在投影敏感。按合同，不递补、不扩窗、不用同一方法再筛。
  2. P1（跨步集中）不成立，而且有符号的结果方向相反：同一步项的有符号和（1318–1419）超过净对齐能量（1059–1222），跨步项的有符号和是负的（−161 到 −258）。也就是说，对齐能量是由“同一步两组增量彼此同向”逐层叠加出来的，跨步项总体在抵消。绝对占比判为“混合”（0.34–0.45），是因为跨步项正负两边的绝对值都很大。我原来的预测依据（“第13层直接写入正交，所以必须靠跨步继承”）错了。
  3. 但“同一步”在这里不等于“独立写入”（计划 v1 已经提醒过）：从第14层起，每一步的 α_j、β_j 是同一个模块分别对已经改变的残差 a、b 的响应。只要模块对输入的响应有共同的主导方向，α_j 和 β_j 就会同向，哪怕 a、b 本身并不完全同向。这个账目区分不了“两组各自写入同一方向”和“同一个下游运算把两种输入变化映射到同一方向”。
  4. P2 成立（头块为“混合”）。描述上，跨组项在四个方向上都大于本组项：子表 15–29 对 7–10，主表 140–174 对 50–91。第13层只有本组头块（闸门：其余头逐位不变）；第14层基本是本组主导（R1：‖α^A‖ 2.41，‖α^B‖ 0.34）；到第17–18层，A 的历史变化经由 B 头表达的部分已经接近本组（第18层 ‖α^B‖ 2.96，‖α^A‖ 3.89），其对 ΔC 的贡献（22.5）大于本组项（6.0）。

闸门全部通过：B3 哈希一致；BF16 闭合；入口相同；逐步求和与 M 求和误差 ≤2.7e-16；主表终点与 B3-P0 的 aligned 完全一致；第13层其余头的 gated_norm_out 逐位不变；W_o·gno 与实际增量的相对误差 ≤0.022（闸门 0.05）；头块三项求和精确。头块余项（BF16 舍入）的范数为 0.02–0.11，相对于头块分量很小。

4. 合同外的后续想法（推测档，未设计、未授权）

第 1.3 条那个无法区分的问题，可以变成一个可检验的计算假说：“共享下游响应”。即后续模块的输入—输出映射（雅可比）有少数主导输出方向，所以对两种不同的输入变化给出同向的响应。它和替代解释“两组历史编码了相同的内容”的预测不同：前者预测随机输入扰动经过同一模块后也会变得同向，后者不预测。对 MLP 步骤，这可以用已加载的 MLP 权重在 CPU 上做（在 h₀₀ 处求雅可比，比较 cos(Ja,Jb)、cos(Ju,Jv)）。对 G/attention 层，需要缓存，必须上 GPU。按合同出口 (2)，本轮不自动开这条线；是否立项，由你决定。
