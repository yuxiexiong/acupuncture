0. 最不利的几条先说

  1. "POPE 饱和"是多篇论文的明文结论，但"物体幻觉已解决"没有一篇这样写；找到的原话方向相反（DASH："Contrary to the belief that object hallucinations are no longer an issue…"）。查询 1 条专搜 "largely solved / no longer the bottleneck / nearly solved"，0 命中（结论层，1 条查询，不能写成"没人说过"）。
  2. CHAIR 在新模型上没有饱和，但数字几乎完全由 max_new_tokens 决定：同一个 Qwen3-VL-8B，64 token 时 CHAIR_S 8.0–8.4，512 时 45.0，1024 时 51.4，另一篇（未注明 token 上限）58.8。跨论文比较 CHAIR 基线没有意义，除非口径对齐。
  3. 你提到的 Qwen3-VL-8B CHAIR_S 51.6 我没找到出处。最接近的是 GIFT（2510.22067）Table 2 的 51.4（greedy，max_new_tokens=1024，500 张 COCO 图）。缓存全库 grep "51.6" 无 Qwen3 行。
  4. OpenReview 审稿意见一条也没取到：Mirage 的论坛号查到了（wGeQr5cARm，NeurIPS 2025 poster），但论坛接口与页面都返回人机验证（403 ChallengeRequired），我没有绕。DASH、VCD 未查到公开审稿。
  5. "修法在新模型上收益消失"的独立复核型证据不多但有：Mirage、2609.01888（你已读）之外，2607.25196（Rethinking the Effectiveness of Contrastive Decoding）在 Qwen2.5-VL-7B 与 InternVL3-8B 上直接做了——greedy 的 CHAIR 全面优于 VCD/SID，把对比项换成高斯噪声分数不变或更好（见 §2.4）。这是与你们可能想写的"对比解码收益是解码行为变化"结论层重合的一篇。其余多是新方法论文里顺带的基线表（作者有动机让基线难看）；HQH、POPE token 审计用的是旧模型。
  6. 属性/关系/计数在新模型上的逐类数字只拿到零散几条 F 级：CRPE relation、MIHBench count、VAW 颜色探针 FPR（Qwen2.5-VL-3B 33.8%、InternVL3.5-4B 31.6%）、VLMBias 计数 17.05%（摘要）。AMBER 判别式逐类表没找到含 Qwen2.5-VL/InternVL3 的。
  7. 被引扫描只做成一篇：Semantic Scholar 接口限流，RePOPE 与 DASH 的被引没拿到；Mirage 只返回 7 条被引（接口收录显然不全）。

(B) POPE 与标注噪声上限

  • RePOPE Tab.1：POPE 标 "Yes" 的题里 9.3% 标错、13.8% 歧义；标 "No" 的题里 1.7% 标错、4.3% 歧义（random 0.3%/1.3%，popular 2.6%/4.4%，adversarial 2.2%/7.3%）。
  • 推导（我的算术，非原文）：正例占一半、正例错标 9.3% → 即使模型全对，原始 POPE 的 recall 上限约 90.7%（不计歧义题）；若歧义题按一半算错则约 84%。所以原始 POPE 上 F1 ≈ 90 已贴近或进入标注噪声带。这条是推导档，原文没有给出"上限"这个数。
  • RePOPE 原话（§4.2）："This questions how reliable this kind of error can be measured on this split and suggests that the negative set is saturated on POPE random."
  • RePOPE 原话（结论）："Note that this re-labeling has only a limited effect on the saturation of the benchmark (many models acchieve true positive rates as well as true negative rates of more than 90%. To overcome this, other benchmarks need to be evaluated complimentary, e.g. DASH-B [1] which follows a similar design as POPE with a “harder” negative set."（原文拼写与括号如此）

1.3 逐字"饱和 / 未饱和"原话汇总

说饱和（都限定在 POPE 或某个具体基准上）： - DASH §4.3："As the popular POPE [24] benchmark for object hallucinations seems saturated and contains significant label noise, a novel hard object hallucination benchmark is needed to measure further progress." - DASH §2（说的是 AMBER）："While object hallucinations saturate in their benchmark for VLMs, we demonstrate that a substantial number of systematic object hallucinations persist even in current models such as Qwen2-VL-72B [52] and Llama 3.2-VL-11B [9]." - RePOPE 两句，见 1.1(B)。 - HOPE 引言："our study reveals that as LVLMs continue to evolve through successive iterations, the hallucination problem has been significantly mitigated. 说没解决： - DASH 结论："Contrary to the belief that object hallucinations are no longer an issue, we find that they persist extensively when using VLMs in an open world scenario." - HOPE 引言："In practice, models may appear robust not because they have overcome the hallucination problem, but because the evaluation benchmark fails to challenge them effectively." - HOPE §实验："Notably, InternVL3, despite being the most recently released model, achieves only 77.31% and 83.24% in precision on the VG and OpenImages datasets, respectively." - Qwen3-VL 报告："HallusionBench aims at diagnosing image-context reasoning and poses great challenges for current VLMs." - InternVL3 §3.7："Despite these advancements, minor declines on certain benchmarks, such as MMHal, indicate that although the InternVL3 series has made overall progress, optimizing data and training strategies to achieve more consistent improvements remains an important direction for future work."

没找到：明文写 "object hallucination is largely solved / no longer the bottleneck" 的论文（1 条专门查询，结论层）。DASH 那句 "the belief that object hallucinations are no longer an issue" 说明作者认为社区里有这种看法，但没给出处。
