1. 研究主旨不变，本轮补上什么

本线继续研究：少数通道的暂时激活干预，怎样改变模型的历史状态，并在停止干预后影响回答。 要逐步解释形成、保持、读取、跨组件作用及适用范围。单轮计算有限，不把课题改成一个层号、一个缓存类型或只解释EOS。

已有结果证明，换掉某些递推状态会改变后续输出；但还不知道：干预主要改变了每一步写进去的项，还是改变了已有状态被保留、衰减和定向修正的方式，以及这些改变形成的状态，哪部分实际造成停止倾向或事实响应变化。

本轮目的：在已有因果效应的位置，分别改变上述两种形成过程，检验它们形成的状态对后续输出的作用；并检查这种作用是否依赖其余缓存背景。 不把“递推本来就有写入和遗忘”当发现，也不要求最后只能有一个原因。

本轮直接连接这条链中的前两段：

暂时通道干预 → 特定状态形成过程改变 → 撤针后输出改变 → 后续保持、读取与反馈。

相较于继续换层组，本轮的进步应是从“哪里换了有效”走到“改变哪种计算过程会形成有作用的状态”。后两段仍属于课题目标；本轮没有覆盖的部分明确留在路线图中。

3. 核心对照：让两种形成过程交叉

3.1 用人话说操作

同一个题目先取得两条固定输入轨迹：正常处理前文C，以及按旧协议插针处理前文T。记录组4递推每一步实际用到的写入项和更新算子。随后在CPU上重放递推，得到四种末端状态：

状态记号 对已有状态采用哪条轨迹的更新算子 每一步采用哪条轨迹的写入项 要问的问题
R_CC C C 应重建原有干净递推状态，是验收参照
R_CT C T 保留原有更新方式，只换入受干预写入项，会形成什么状态、带来什么后果？
R_TC T C 保留原有写入项，只换入受干预更新方式，会形成什么状态、带来什么后果？
R_TT T T 应重建原有受干预递推状态，是验收参照

这里两位下标始终表示“更新算子来源、写入项来源”，不同于旧四格的“组4来源、其余状态来源”。

再把四种状态分别放回两种完整背景：其余状态全C，以及其余状态全T。只替换L16–18递推矩阵；各层卷积、全部KV和其他递推状态保持接收背景原值。最后提示token与后续生成均撤针。

这样，每个锚点有“2种更新来源×2种写入来源×2种背景”的8格；其中4格已有同义参考结果，只有2个混合状态×2种背景是新的科学比较。不是重启已暂停的组前/组后八组合方案。

3.2 精确定义及解释边界

按实现的key×value方向，对每个目标层、每个头、每个前缀token：

[ S_t=A_tS_{t-1}+B_t,\quad A_t=\alpha_t(I-\beta_t k_tk_t^\top),\quad B_t=\beta_t k_tv_t^\top. ]

k使用真实实现的归一化结果；头扩展、门、缩放、dtype与token边界按固定实现核对。对来源a,b∈{C,T}，离线重建

[ \widehat S_t^{a,b}=A_t^a\widehat S_{t-1}^{a,b}+B_t^b,\qquad \widehat S_0^{a,b}=0. ]

前缀为相同prompt[:-1]，从空历史开始。C/T系数均来自各自原始完整模型轨迹；不在混合状态上重新计算系数，不把这称为一条自然的混合模型前缀轨迹。逐层构造后共同替换组4递推，其他状态不动。

A不是“纯遗忘”，B不是“事实内容”。 A还包括沿key方向的修正，B也不是语义事实标签；k与β同时进入两者。因此这是一种明确的计算对照，不是在声称模型有两个物理独立开关。它检验的是沿固定来源系数改变A或B所形成状态的受控作用，不能直接计算自然因果中介占比。

记录两种条件下的作用：固定B比较A来源，固定A比较B来源；分别在两种背景中计算。不给二者强行分配相加为100%的“贡献率”。若结论随另一项来源改变，依赖关系本身就是需要报告的结果。

4. 防止把拼接效应和一般损伤当机制

第一层：原样重建验收。 R_CC/R_TT必须重放对应真实递推状态及原有整块替换读数。错误的头映射、chunk数值路径、状态管理字段或恢复时刻，均不允许进入科学解释。具体验收见第7节。

第二层：同幅度、不同方向的对照。 对每个新混合状态、每个接收背景，取其相对背景原递推的差量Δ。在每层每头使用预先固定的行、列置换，构造P_key Δ P_value，再加回同一背景状态。置换保留逐头Frobenius范数和奇异值，破坏原坐标对应；种子拟固定为20261031，所有题目与锚点共用同一套映射，执行前冻结映射及哈希，不按结果换种子。

每个锚点因此增加4个方向对照。对照与科学臂均保存各层实际扰动范数；不把四个混合臂的范数强行拉齐，因为那会改变主实验要比较的形成过程。

若过程对应的状态与置换状态效果相似，本轮没有证明计算方向具有行为特异性，优先保留一般扰动解释。若两者不同，只能削弱这个特定同幅度对照，不能排除全部分布外失配。只用一个固定置换，不进行随机方向总体显著性推断。

两背景、双向参考和方向对照共同提高解释力，但都不保证构造的R_CT/R_TC处于自然状态分布。若仅混合状态极端异常，而两条原样重建轨迹正常，必须优先报告构造失配，不能宣布找到新的异常机制。

5. 测什么，怎样形成认识

三类终点同时报告，不合成单一成功分数：

  1. 停止竞争。 沿用D及实际首步EOS；额外保存固定token的原始logit差。每个题目/锚点先从原始参考中冻结TT最高EOS token e及CC最高非EOS token n，所有臂比较logit(e)−logit(n)，同时保存实际获胜token及原EOS logits。固定差值不含max切换，可检查D变化是否主要涉及竞争者切换；仍不能因此自动归因到某个内部非线性。
  2. 事实响应。 沿用原候选及逐token logprob；两事实按target_index定向计算S，不按fact_version猜正确项。每个基础情景配对报告，禁止把12输入当12个独立事实对，也不将S下降写成信息丢失。
  3. 实际回答。 原greedy、原EOS、128新token上限。分别记录首步停止、核心事实跟随、核心矛盾、题面改写/编造、未交付、自然结束及截断。新回答匿名盲读并锁定标签后揭示臂名，保留原文；披露模型辅助身份。题面改写维度单列，不事后替换旧核心标签。

范数、混合状态到C/T距离及各项配对差是辅助解释，不能用“距离更近”代替行为证据。科学判断同时看逐情景方向、绝对效果、原样替换参照和方向对照，不凭一个均值或显著性标签宣布机制成立。样本有限，以探索性逐题证据为主，不把两事实版本、多个头或确定性重放当新增独立样本。

  • 对R_CC/R_TT，CPU高精度递推与真实末状态逐层逐头比较。拟冻结相对Frobenius误差上限1e−3（分母max(真实状态范数,1e−12)）；另检查C/T差量的重建误差，避免大基值掩盖小差量误差，同样上限1e−3。若不满足，保留误差并停止，不把残差塞入A或B、不临时放宽阈值。
  • 重建状态转回实际存储dtype后，与原样替换在末token的D及固定logit差分别相差不超过0.05 logits、greedy首token完全一致。原样旧参考本身也须符合上述logit容差，原候选总logprob每条误差不超过0.05 nats；失败即查代码、版本、数值路径，不执行科学臂。阈值是当前拟定验收标准，不声称已验证可达。
  • 全C、全T和双向整块递推替换逐项记录张量来源、token/位置、mask、管理字段、dtype、深拷贝与hook移除，沿用原资产身份验证。重放不能暗中换成另一个后端后仍称同设置。
