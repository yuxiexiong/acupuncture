B1 配对传播分析：结果

日期：2026-11-01。方案 r2、合同 r01 与筛选代码在运行前提交（6bb338b）。CPU 离线，0 模型调用、0 GPU，1.5 s；B1 formal-r01 的 12 份张量按收据校验后读取。结果 results-r01.json，代码 analyze.py。同一助手分析，不是独立复核。

1. 决定（按冻结规则）

无合格候选：结束本次 B1 传播追踪，暂停第13层 V×Q 写入交互分支，不自动扩层。 筛选失败不证明 36 个模块都无关：规则要求超过两条随机参照，而这些随机方向到第13层出口时已比真实删除大 1.9–2.5 倍，使筛选偏保守。 36 个模块（第14–31层 × {mix, rest}）在 N 停止侧没有一个入选；最好的模块（31:rest、31:mix、27:mix）也是 0/6 情景通过。M_T 同样无入选，答案词侧也无。

2. 闸门

张量/记录哈希、层间边界逐位连续（13–30，第31层出口 = final:h）、同背景各格第13层入口逐位相同、恢复的补丁后 core 哈希等于 B1 记录、账目闭合（最大误差 4.4e−16）全部通过。

3. 描述性结果（不是因果结论）

表一：改动进入了残差流，但真实删除方向在第13层内部比随机方向衰减更多。 第13层出口差范数相对 R：M_T 0.187、N 0.088（中位数）。core 位置真实与随机逐头范数相同（相对 0.37 / 0.12），经门控归一化与 out_proj 后，随机方向在第13层出口的范数是真实删除的 1.9 倍（M_T，范围 1.5–2.8）与 2.5 倍（N，2.1–3.4）。这只是记录边界上的描述，未单独干预归一化。

表二：差异持续存在并增长，但早层模块的响应与输入差异反向。 DEL 的差向量范数从第14层到第31层：M_T 1.4 → 7.0，N 0.7 → 1.8（中位数）。第14–19层 cos(e_l, d_in,l) 中位数 −0.16 至 −0.44（两背景相同形态），第20层后接近 0（第27层 −0.25 / −0.45）。这是“有抵消形态”的记录，不证明网络主动纠错。

表三：差异基本不朝停止方向走。 固定终点方向投影：第13层出口 p_s46 在 −0.05 至 +0.01（两背景）；终点 p_s46 M_T −0.62 至 −0.27、N −0.11 至 +0.14；实际 ΔZ_s46 M_T −0.79 至 −0.42、N −0.09 至 +0.06。分母项 ε 不可忽略（最大 0.35 / 0.17 logit），舍入项 ≤0.07。答案词侧 N 也在 ±0.17 内。

按方案允许的读法：N 中真实删除与随机方向的 γ 都低——这些已测方向在 N 中的单位改动输出响应较低，不能说原生背景对第13层整体不敏感。N 与 M_T 的 DEL γ 相差近一个数量级、并不接近，所以这些数据不支持“B1 的 N 阴性主要由删除量小造成”；但方向与下游背景不同、模型非线性，比值也不能把大小与敏感性分开。M_T 中真实删除的 γ 一致为负且大于随机，是方向相关的传播差异线索（仅混合背景）。

4. 对阶段 B 的含义（不是运行授权）

第13层这一支两次因果操作（LOCAL 的 S×读取交互、B1 的 V×Q 写入交互）与一次配对追踪都没有给出原生背景的候选，按规则结束。保留的描述性事实：原生入口下，第13层改动传进残差后，早层有反向响应，之后的差异增长，但在停止方向上的投影较小（未测夹角，不说“正交”）。B 阶段若继续，需要不依赖第13层的、有独立依据的新候选；本轮不指定接班对象。

5. 复核后的修订（2026-11-01）

外部复核指出：“几乎与停止方向正交”应收紧为“停止方向投影较小”；筛选失败不等于模块无关（随机参照在第13层出口已偏大）。§1、§4 已改，数值未变。
