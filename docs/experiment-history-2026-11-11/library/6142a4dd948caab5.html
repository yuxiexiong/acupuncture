3. 操作

  • P / q：q 为最后一个提示 token（四模型均为模板的换行 token）；P 为其余全部。
  • H 操作位置：字符区间完全落在记录块内的 token（四模型跨界 token 数均为 0）。
  • 针：每模型每层 needle_set：原生通道 = random.Random("20261102|<模型键>|<层>|native").sample(range(中间维), 4)；随机方向 j∈{0,1} = 以 sha256("20261102|<模型键>|<层>|dir<j>") 前 15 位十六进制为种子的 float64 标准高斯，单位化。冻结于运行前，与任何输出无关。
  • 写入：要求写入范数 N = |d|·s·√H。s = 开发 12 情景 × 2 事实 A 输入的清洁运行中，该层 MLP 前残差（pre-MLP norm 的输入）逐位置 RMS 的中位数，去掉第 0 位置（注意力汇点范数异常，D3）。原生针在 down_proj 输入第 c 维加常数 a = sign·N/‖m·W[:,c]‖，m 为 MLP 输出乘子（Falcon 0.078125，其余 1）；方向针在 MLP 模块输出加 sign·N·u。实际写入按位置记录（重算同 dtype 清洁输出求差）。
  • 四格：00/01 共享清洁 P 缓存，10/11 共享有针 P 缓存；每格从 deepcopy 出发处理 q；q 之后不注入；候选逐 token 在 deepcopy 上单 token 前向评分。
  • 已有缓存时只许单 token 前向（HF 混合层只在 seq_len==1 读恢复状态），引擎断言。

4. 读数

主 Y = 两候选完整对数似然的二元 softmax 中正确项的概率；H、C、J 按 PLAN §5 A2。

预注册次级分析（r03，D9→D17）：m = log P(正确候选) − log P(错误候选)（两候选完整 token 序列的对数似然差，float32 log_softmax、双精度求差），及其四格差 H_m、C_m、J_m，与 Y 并列报告。预检 r01 干净 m 为 8.4–38.9 奈特，Y 在 0.99984–1.0（真实高置信，不是计算舍入）。m 只增加测量分辨率：m 的变化不自动解释为行为变化；不为打破 Y 饱和而加大剂量。m 的可分辨性以同条件数值噪声底标定（§5 G9 的 m 差；对数似然在该量级有约 0.06–0.25 奈特的 BF16 粒度），低于噪声底的 H_m 报"不可分辨"。m 不进入 PLAN §9.2 的四档判读与 δ，后者只作用于 Y；若计划所有者要为 m 设判读阈值，需在采集前另行写入。

r03 补充（D17、D19）：A 保持现任务；正式剂量 d_high=3/4、d_low=3/8（3/8 以 D18 写入验收为准）。校准显示在 3/4 下 Y 变化中位数 ≤1e-4（天花板），m 变化中位数 0.9–7.7 奈特；因此 H_m、C_m、J_m 列为事前固定的次级分析，按情景 cluster 给区间、报告分布。m 的四格结论只在通过 D19 跨路径一致性的模型 × 剂量上进入解释。若正式结果只有 m 改变而 Y 与交付几乎不变，交付表述为"答案相对支持程度的变化及其模型差异"，不写成正确率下降或行为损伤；不为获得翻转追加剂量或换任务。

其他辅助：首步停止集合概率、贪心首步是否停止、熵、top-32、完整 logits（fp16，轻记录）。分析规则、δ=0.05、四档判读、区间与多重性一律按 PLAN §9，不在此重述、不改。
