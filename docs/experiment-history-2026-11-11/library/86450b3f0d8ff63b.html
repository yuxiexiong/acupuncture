QCO-01 零 GPU 补充：共同偏移相对干净 q/k 有多大

日期：2026-11-02。事后描述，不在 freeze 内，无预注册。脚本 analysis/offset_scale_r01.py，结果 analysis/offset-scale-r01.json。数据：采集阶段保存的 48 个输入的 q/k 卷积槽、冻结的共同偏移 μ 与随机参照 r、从模型权重文件读出的 14 层卷积核。

依据的源码事实（已核对安装的 transformers）

首个读出步：out = conv1d([s1, s2, s3, x_now], w[0..3])（旧缓冲后 3 槽 + 当前投影，核长 4），随后 SiLU，再对 q、k 按头（16 头 × 128 维）做 L2 归一化。当前 token 的投影 x_now 没有保存，所以“卷积后”只算得到旧三槽的贡献，不含 w[3]·x_now 这一项。

结果（48 输入 × 14 层的中位数；四个方向几乎相同）

量 q k
卷积前 |μ| / |干净 q/k|（槽 1–3） 0.84–0.86 0.88–0.93
cos(干净 q/k, μ) −0.46 到 −0.49 −0.38 到 −0.40
cos(受针 q/k, μ) +0.39 到 +0.43 +0.43 到 +0.48
卷积后旧槽贡献 |μ| / |干净| 0.41–0.47 0.62–0.72
同上，随机参照 |r| / |干净| 0.30 0.44–0.48

读法

  1. 我此前的推导（“偏移远大于原 q/k，归一化后方向被偏移主导”）不成立。 偏移与干净 q/k 同量级（卷积前约 0.85–0.93 倍），卷积后旧槽贡献只有干净的 0.4–0.7 倍；不是“盖过”。
  2. 偏移与干净 q/k 明显反向（cos 约 −0.4 到 −0.5）：受针 q/k ≈ 干净 q/k 加上一个大小相近、部分反向的向量——范数变化不大，方向被转开。这是“抵消/转向”的形态，而不是“淹没”。
  3. 卷积核放大共同偏移多于随机方向：同样的卷积前范数，卷积后 μ 的旧槽贡献约是随机 r 的 1.5 倍（q 0.41–0.47 对 0.30，k 0.62–0.72 对 0.44–0.48）。这可以部分解释为什么 μ 比随机更有效，也说明随机参照在卷积后其实“更小”；但这只是旧槽部分的描述，不是因果证据。
  4. k 半的相对改变大于 q 半（卷积后 0.62–0.72 对 0.41–0.47），在 14 层中都如此（k 在层 16、21 最高达 1.0–1.2）。这为下一步“q 半 / k 半”拆分提供了一个可检验的先验：如果作用主要走写入路径，只去除 k 半应恢复更多。这只是线索，不是预测已成立。
  5. C1343 的几何与另三个方向几乎相同，但它的 V-only 没有损伤（48/48）。所以单看偏移大小与角度，预测不了行为；作用依赖它与其他状态的组合。

限制：缺当前 token 项；SiLU 与归一化是非线性的，旧槽贡献的比例不能直接换算成归一化后的方向变化；只在这块面板与四个方向上。
