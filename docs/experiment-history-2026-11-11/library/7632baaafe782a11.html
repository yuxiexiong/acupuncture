0. 坏消息先说

  1. B1 的"撤针 / 无针强制前缀重建"分离方法已有两篇先例，方法层被覆盖。 - Dobre 等 2610.09027（2026-10-06，ServiceNow/Mila）：对抗输入被 mask 掉后影响经后续 token 的 KV 持续；"cache-swap"消融在文本固定的条件下只换缓存来源，证明"对抗文本本身不足以"引发效应，效应走 KV。这就是我们 rebuild 臂的逻辑（同一文本、干净缓存）。 - Liu 2606.19831 §7.3：单神经元转向的"release"臂（撤针）+"forced-opening control"（无注入、强制同样开头续写）——正是 withdraw + rebuild。结论与我们 L25 一致（持续靠已生成文本，"in-context momentum"），与我们 L2 相反。
  2. B2 的分离方法（状态交换）在同一个模型上已被做过。 Afendulev 等 2609.04434 在 Qwen3.5-4B 上做 split-prefill（只留 KV 或只留递推状态）与 state-swap（KV 来自上下文 A、递推状态来自上下文 B）。我们计划的"只换递推状态 / 只换 KV"是它的方法直接搬用。它还给出一条类比档预言：语言、人设、语气这类"回应方式"走递推状态（KV-only 语言准确率 0.01），精确检索走 KV。
  3. B3 的痛点"转向效应经缓存累积"已被命名并配了修复方案。 Kang 等 2605.10664 把"KV-cache contamination"列为残差流转向在多轮对话中的主要失败模式，并提出 GCAD。但它没有撤针臂、没有重建臂，"经 KV"只写成"A likely mechanism"，即机制断言未经分离检验。2607.09156 引用它并在设计上用每轮全量重编码回避，自称"We have not measured what cache reuse contributes"。
  4. B1 的 KV 一半大体是被蕴含的（推导档）。 KV 条目一经写入不再更新；只要后续位置还注意到被干预位置，撤针后效应必然有一部分残留。prompt-only 转向（PrOSV 2605.05983 写明"functions mainly by implicitly editing the KV cache"）与 KV cache steering（2507.08799）之所以有效，正依赖这一点。真正不被蕴含的是：(a) 残留大到能维持异常，(b) 残留的承载者是递推状态还是 KV，(c) 早层 vs 晚层承载者从状态换到文本。
  5. 方法危险，直接影响我们已有数据的判读： - 2609.04434 附录 A："Most public implementations of hybrid layers only consume a restored recurrent state on the single-token decode path"——多 token 块喂入时恢复的递推状态被静默忽略、扫描从零重启，"No error is raised"。它要求每个模型用 ∆=‖logits(q|R(c))−logits(q|0)‖∞ 验证状态真的进了模型（他们在一个模型上测到 ∆=0.0000）。我们 withdraw / rebuild / 计划中的状态交换都受这条影响，必须核对代码路径。 - 2604.15409：FP16 下 cache-ON 与 cache-OFF（重算）在 greedy 下也逐 token 分叉，"100% token divergence rate"（LLaMA-2、Mistral、Gemma-2，GSM8K）。我们的 rebuild 臂相对 withdraw 臂多了一个"重算 vs 缓存"的数值差。需要一个无针的 continue-vs-rebuild 对照来标定这个零分布（CLAUDE.md 6.3）。这条是类比：对象是 FP16 Transformer，Qwen3.5 的 bf16 + 分块/逐 token 递推是否同等分叉没查到。

蕴含判读（每条标档）： - KV 侧——推导。 注意力层的 K、V 一经写入不再修改。撤针后，被干预位置的 K/V 以及由被干预残差算出的后续位置 K/V 都保持原样，只要查询仍注意到它们，扰动就继续进入读出。所以"撤针后仍有残留"对 KV 是平凡的；不平凡的是残留量是否足以维持异常。prompt-only 转向的有效性（2605.05983："PrOSV intervenes only at prefill stage and not decode stage… functions mainly by implicitly editing the KV cache"）是这条的经验确认。 - 递推侧——推导 + 实证一处。 GDN 的状态扰动按 δS_t = α_t(I−β_t k_t k_tᵀ)δS_{t−1} 传播，范数被门控收缩，但 α_t 接近 1 的头几乎不衰减。WriteSAE 2605.12770 附录给出 Qwen3.5 GDN 一次写入扰动的传播式："A scalar gate cannot mix the rank-1 outer with anything else, so the perturbation stays rank-1; only its norm decays."，衰减因子 G_{t0→t0+h} = Π exp(g_s)（行 1366、1394），并注明"The reduction is empirical"（忽略了 delta 擦除项的交叉项）。所以"递推态会不会在 4 或 16 个 token 后仍携带干预"不被蕴含为是或否，取决于该层各头 g_s 的实测值——这是一个可零 GPU 读出的量，不是文献已给的结论。 - HiSPA 2601.01972 的反方向蕴含——类比。 它证明了足够强的输入能"irreversibly overwrite"SSM 状态，并写道"hybrid models combining Mamba with attention layers may partially mitigate this vulnerability, since attention can recover information that the SSM layers have overwritten"（§3 末）。这预测：在混合模型里，被递推态"擦掉"的东西可由 KV 补回。对 B2 的方向是"KV 能救回、递推态会被冲掉"，与 2609.04434 的"回应方式走递推态"是两股相反的类比压力。 - 2609.04434 对 B2 的蕴含——类比。 它的结论（§6）："The recurrent state works as a compressed prior that shapes language, persona, and semantic field of generation"；表 1：Qwen3.5-4B 语言跟随 REC-only 0.70、KV-only 0.01。如果 L2 的异常属于"回应方式"一类（而不是某个被检索的具体项），这条类比预言 B2 的答案是递推状态。但它的对象是上下文信息，不是激活干预；跨对象成立未验证。 - 2606.19831 §7.3 对 B1 L25 结果——近似蕴含。 原文："a counter-drive and a forced-opening control (continuation in the routed language on 11/12 prompts with no injection, against 0/12 from a baseline opening) attribute that persistence to the generated context, not a held neuron state"。对象是 Qwen3-4B L25/F347（稠密 Qwen3，非 3.5）。我们 L25 "rebuild 也救不回（文字自持）"与之同形，应作为该结果的复现而不是新发现。 - 2610.09027 的反向信息——推导/直接引文。 "We show that persistence is not a default property of adversarial inputs, but it can be optimized for."（贡献列表第一条）。即在 Transformer 上，未经优化的输入一般不经 KV 持续。我们 L2 单通道 +1 未经优化却经状态持续，这条形成对照，但它的 T 是输入扰动而非残差加性干预，不能直接互推。

仍空着的部分在哪一层

  • 方法层几乎全被占：撤针、无针重建、文本固定换缓存、只换递推态/只换 KV，各组件都有直接先例，其中状态交换就在 Qwen3.5-4B 上。

  • 痛点层：KV 污染已被命名；"递推态污染"与"跨请求带状态缓存复用"未找到，后者的现实性是推测档，没有找到任何人报告这个痛。
