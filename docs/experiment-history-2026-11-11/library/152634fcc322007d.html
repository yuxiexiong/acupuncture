3. 共用操作：沿用两种现成hook

3.1 t1写入

复用 lvk_run.LHook 与 KUC custom_update。以本分支当前输入x、真实更新前缓冲的克隆构造影子，真实缓冲不被影子写回。v1仅把V旧历史换成同输入C的历史；它不是完整干净运行的v。k1仅对k旧槽加/减μ后重做同一卷积；q/v通道不直接改。

S1 = αS0 − αβ k0(k0ᵀS0) + β kb vaᵀ。

擦除项两处k都用本分支k0，只改写入项。各层β、α、q及其他量来自本分支；较浅层操作引起的深层输入变化正常保留。t1后卸载写入hook。

3.2 t2使用

复用 sru_core/sru_run。捕获两条原始t1端点各G层S1为只读供体；每个有序配对（接收者Sr、另一端点Sd）跑四格：00无操作，10只换直接读取D，01只换修正贡献E，11两者一起换。

o_ab = o_native + a α(Sd−Sr)ᵀq − b αβ(kᵀq)(Sd−Sr)ᵀk。

FP32核输出、转BF16之前加校正，gated norm之前。返回本层当前驱动下的原生S2，不直接把Sd写入缓存；q/k/v/门不钳制供体，之后正常响应。深层S2及后续缓存可以因上游输出改变而变，供体信息的行为后果不会在t3自动消失。 两端点互换形成两个预先命名的交换方向（方向名不承诺科学效果）；不是跨输入移植。

11仅在同局部驱动的当前输出上等价于喂Sd的原核，不等于整个供体轨迹。D/E拆用是人工计算反事实；Sd−Sr包含t1操作的多层后果，不是全层都只有孤立秩一写入差。比例不作自然中介份额。

3.3 随机主动对照：固定位置、强度和边界

仅用于G3-C的两方向及G2的GS01×N4146。每层/头用一个冻结随机单位方向u；CPU FP64、NumPy PCG64、种子20261103，按G层升序、头升序生成标准正态向量再单位化，记录版本和张量SHA256。同一u跨输入/场景/操作符号复用，不按答案挑种子。它是一组固定的主动比较方向，不是随机方向总体样本或无效应零分布。

每个随机分支在t1各层用自己的当前x与缓冲，另算同符号μ影子，得到内核实际使用尺度下的k0与kμ（卷积、激活、k归一化及头展开之后；FP32写入乘法之前）。定义Δkμ=kμ−k0，随机写入用 kR=k0+||Δkμ||₂ u，逐头匹配；零范数时增量为零。只改βkvᵀ里的k，旧修正项仍k0；不写回卷积缓冲、不再归一化kR。G2用去μ影子作为幅度参照，G3用加μ影子。随机符号包含在固定u中，不另选有利正负。

这是一项明确的写入向量反事实：kR不保证为单位向量，也不保证来自自然卷积历史。不能由μ与随机之差声称纯粹“方向语义特殊”，更不能把随机分支说成原生针。随机分支的深层x可与μ分支不同：配平只对同一随机分支的局部μ参照严格成立，跨整条运行不宣称全量等强。此限制保留在结果表，不扩展新的配平矩阵。

每输入/层/头记录实际Δkμ、ΔkR范数、k0/kR范数、写入增量βΔkvᵀ范数及其配平残差；同时报告μ在缓冲旧槽的范数。随机臂没有对应缓冲编辑，记NA，不虚构缓冲范数。有限精度后的配平误差按工程核对记录，不能在看答案后重缩放。不同β/v/上游响应仍可导致跨分支状态和行为强度不同。

随机与μ是否呈相似读取关系，本身就是结果；μ不必胜过随机才有价值，不作为继续读取的门槛。一个方向不足以估计随机分布或给特异性显著性结论。

8. 最小工程验收与执行交接

复用LVK影子构造、KUC选择性写入、SRU输出hook、QCO均值及原解析器，只需专用薄入口，不建通用框架。执行时冻结代码/环境、输入plan与tokens、μ/u/校准及源哈希。本次不实现运行器或启动模型。

  1. 共享旧SRU桥接用LVK-H-NA-NQ01-ABC-A×N4146，两端点/双向四格的t1、C-t2及自然tokens逐位一致。G3-T逐输入对LVK L00/L01，旧C逐位对旧C。新L12没有旧链输出，不能要求预测阳性作为验收。
  2. 零操作逐位等于原核；影子不写回缓冲。μ臂L10/L11与V/VW参考的t1全层一致，仅G卷积V旧槽可不同；随机臂不强加这个不适用的等价。FP64写入/读取公式及11同驱动原核误差≤1e−5，不能用容差放宽00重放。
  3. 随机匹配在实际内核尺度，记录FP32构造后范数残差及算子路径；相对误差≤1e−5（Δk=0单列绝对零）。上游变化后每层重新用本分支影子计算目标范数，不借另一运行张量冒充同输入。kR不重归一化，不修改擦除k。无符号零例外政策沿旧合同并单列。
  4. t2返回同局部驱动的接收者原生S2，源S1只读；下游状态正常响应。自然EOS后hook次数为0；t3无hook不等于无后果。
  5. G1核对L12注入位置、6个尺度及96次采集；G2核对新plan窗口、编号分词/答案表和3次校准。分词或来源失败停在工程阶段，不改词换题。C答错不是工程失败。
