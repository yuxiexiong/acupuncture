## 2. 针到底有多大：已核实的值和无法恢复的值

冻结注入代码在 MLP down-projection 前给一个通道加常数：

`offset = BF16(dose × reference_scale / ‖W[:,channel]‖)`。

`reference_scale` 是干净校准运行中，该层输出残差向量范数在除首token外各位置的中位数；不是当前token的范数，也不是该神经元自然激活的标准差。这里dose=−1。

| 量（12输入范围） | L0/C4146 | L12/C3621 |
|---|---:|---:|
| 干净参考残差尺度 | 2.673–2.881 | 8.672–8.905 |
| 目标权重列范数，CPU FP32复算 | 0.440035 | 0.470326 |
| BF16加法常数，CPU复算 | −6.5625 至 −6.0625 | −18.875 至 −18.5 |
| 常数乘权重列得到的输出向量范数 | 2.668–2.888 | 8.701–8.877 |
| 上项 / 干净参考尺度 | 0.9982–1.0024 | 0.9969–1.0034 |
| 仅早段针的位置数 | 16–28 | 16–28 |
| 仅晚段针的位置数 | 27–33 | 27–33 |
| 两段都开的位置数 | 43–57 | 43–57 |

**结论：这是一个坐标稀疏、但校准有效幅度约为该层参考残差尺度的干预，而且重复作用于多个token。没有依据把它称为“一次微小扰动”。** 这不证明所有效应都只是普通损伤，也不排除方向和历史的特定作用；它撤销的是“小针必然被模型异常放大”这个未经检验的前提。跨层绝对数值不能直接比较功能强弱。

**实际精度缺口：** 本批S2的`masked_injection`只保存了位置和次数，没有保存每个token加法前后的目标激活。上表是冻结公式与权重、校准值恢复的常数及其线性映射，不是逐token实际差分的精确测量。BF16加法还会舍入，down-projection也有数值误差；CPU FP32列范数也不冒充GPU原日志。因此无法恢复每步实际的 `changed−original`、每步扰动/当前残差的比值，或相对自然通道激活的倍数。这一缺口不能用校准日志填造。校准来源与注入函数已随源文件保存。

## 3. S2同起点：针插入后的第一步已经能解释什么

比较01/00是在干净前史下开启晚段针；11/10是在已有早段针前史下开启同一晚段针。每一对都共享其自己的旧状态，两个比较之间的旧状态可以不同。观察点为固定b+1，未挑最大效应时刻。

以下数值先在每个输入内合并L16–18全部头，再平均同情景的两个事实版本，最后报告六情景中位数（范围）。相对变化统一为该变量的差异范数/参照变量范数，不把不同变量的比值当传递增益。

| 首步计算量 | L0，01/00 | L0，11/10 | L12，01/00 | L12，11/10 |
|---|---:|---:|---:|---:|

| 旧状态处理作用/加性写入变化的范数比 | .456（.395–.489） | .562（.538–.634） | .495（.460–.513） | .437（.400–.503） |
| 写入变化与处理作用的余弦 | −.426 | −.508 | −.454 | −.547 |

计算关系是 `m=(αS旧)ᵀk`、`e=v−m`，再用e更新。公式不是发现，实测方向与大小才是这里的证据。

每一对首步的S旧相同，因此该步m差异来自当前α/k对共同旧状态的不同处理和读取；两个前史比较之间的S旧则不同。m差异变大不等于“记忆内容损坏了相应倍数”，也不是独立旧状态贡献。

**第一点：共同起点的旧状态处理作用，在这一步抵消了一部分加性写入差异。** 不是“两项同向把扰动放大”；上述合并净差小于单独写入差。只看v或加性B会误述真实更新。但这不证明旧状态处理对回答有保护作用：局部状态范数与回答相关方向不是同一个终点。

**第二点：早段历史改变了模型对后来同一针设置的反应。** 为避免参照范数不同造成假象，再比较绝对差异范数：L0中，11/10首步的v差异是01/00的1.68–2.70倍；旧预测m差异为2.66–4.51倍；raw读取差异为1.22–2.05倍。L12对应v差异为1.16–1.24倍，raw读取为1.29–1.52倍。这里比较的是局部有限差分的背景依赖，不是旧历史的独立贡献比例。

这比“写入和处理都变了”多说明了一步：先前干预留下的历史，会改变后续针在实际计算中的表现，并非只能作为一个与新扰动独立相加的残留量。仍不能由此指定某个唯一门或某层是原发机制。

## 4. 与S3输出效应接起来，能接到哪一步

### 4.1 先纠正两个容易把链条接错的位置

1. **S3的V在卷积前，S2公式中的v在卷积之后。** S3 R也是`in_proj_a`输出，K是卷积前k通道加`in_proj_b`输出；它们分别经模型计算形成α、k、β。不能把S3效果直接说成只交换了公式里的独立写入项。当前逐步表同时保留卷积前V和递推v，避免混用。
2. **S3晚段L格对齐的是11/10，不是01/00，更不是11/00。** L供体为10，接收者为11，两者共同保留早段针。01/00提供另一种前史下的原生反应证据，没有对应的同背景S3单组干预格。E格的供体/参照另有定义，不混入这一连接。

D是停止token相对最强非停止token的logit优势。恢复/保留量沿用S3定义，是替换条件下的效果描述，不是自然机制占比。S3原零对照与分辨率限制仍然适用，本次不以描述比值覆盖其原判据。

**可以接起来的认识：** 同一晚段针改变原生V及实际更新/读取；在相同输入和前史的S3对照里，恢复这条卷积前V通道能显著改变停止端点。它是有过程证据支撑的条件性因果通道，不只是两份不相干的现象表。

**不能接成的结论：** S2只详细观测L16–18，而S3 V替换覆盖针之后全部相关线性层。无法说L16–18的某个写入变化贡献了上述恢复量，也无法排除替换后的其他变量响应或补偿。S3记录了输出、缓存距离等诊断，没有保存这些替换格的完整逐步内部轨迹。因此“自然变化出现在哪里”与“哪个改变使输出恢复”之间仍有一个明确的中介范围缺口。

### 4.3 有两个实质反例，限制了“幅度越大，行为越大”的解释

- L0中，受早段历史影响，晚段开针的首步v和raw读取差异比干净前史更大；但其最终D增量不是一致更大。六情景中，11/10的D增量/01/00为0.70–1.08，且末提示raw读取的绝对差异反而为后者的0.92–0.99倍。不能用首步幅度直接预测停止。
- 在干净前史下，L12的首步递推v相对变化在六个配对情景中均大于L0；最终D增量却均更小，L12没有首步EOS。跨锚点还有位置、方向和尺度差异，不能据此分配原因，但足以反驳“只比较这一局部相对范数就能解释停止强弱”。

首步到末提示之间包含27–33个晚段注入位置、不同输入token及后续更新。差异变大不能读成一次扰动的单步增益；D的显著连续变化也说明，不能把L0效应仅写成“微小分数变化恰好过阈值”。

### 4.4 已有层范围格进一步约束解释，但不是自然路径认证

L0的S3晚段实验中，只恢复首个受影响层组L1–L3的全部变量，D恢复量为.025–.432；恢复其后各层的全部受控变量，D恢复量为.979–1.015。L12相应范围为−.130–.362与.769–1.047。

这说明已有条件性输出恢复并不要求把首组也恢复，也不能用“首组就是全部原因”来解释。它支持把注意力放在后续传播与读取怎样形成输出效应；**不证明首组对原生路径不重要，也不证明这些后层本来就是独立起因**，因为它们可能承接上游效应，且替换多个变量可以补偿。

### 4.5 对“V解除停止但事实没有恢复”的一次解释纠正

该现象成立，但**不能把恢复到00的事实水平作为S3晚段V格必须达到的目标**：它的供体和参照是10，已经经历早段针；L0的10本身事实敏感度就很低。

|---|---:|---:|---:|
| VAR01 | 15.075 | −.021 | −.073 |
| VAR02 | 21.351 | 1.339 | .242 |
| VRD01 | 22.643 | 5.257 | 3.220 |

所以它不能单独证明“V只管停嘴、事实必由另一条存储损伤机制负责”。VRD02还超过了其晚段参照10，显示混合条件下不能简单作功能分工。真正需要解释的是：早段、晚段和当前读取如何共同产生不同的候选事实响应；此处S_fact仍不是自由回答正确率。

## 5. 当前最有依据的解释

**在当前设置中，针以一个固定方向、参考残差尺度量级的校准扰动，反复进入多个位置的残差计算。它改变下游投影与历史形成；已有历史又改变后来插针的局部响应。实际更新中，新信号变化与旧预测/处理变化有部分抵消。最后的输出效应取决于这些差异怎样被后续计算读取和映射，不能只用插了几个坐标、哪个账目更大或哪处范数增长来解释。**

其中，剂量定义、重复位置、原生局部变化及替换效应有实测/源码支持；“它们通过哪条具体原生计算关系造成停止方向的强变化”仍未识别。已支持的部分不是完整根因，也不能推广成跨模型普遍机制。

## 6. 最关键还缺什么，下一步的判断

**最关键缺的是：原生V及旧状态处理造成的更新/读取差异，如何经过后续层变成最终回答相关的方向；同一连接是否解释S3恢复，而不仅是混合替换造成补偿。**

这个缺口现在已经具体化为：

- 注入附近缺少逐token实际加法差分和连续原生形成记录，剂量精度有上面明确的边界；不能由L16–18反推前面。
- S2原生过程覆盖局部三层，S3输出干预覆盖全部后续层；没有相同中介范围、相同位置的完整过程—输出对应。
- 最后一个提示token和候选评分按CFM协议均无针，因而这次分析仍不能代替“回答位置继续开针”的完整效应解释。

**现在最值得补的是上述过程到输出的连接，不是再确认写入和处理都变了，也不是再增加恢复/移植/中和矩阵。** 本轮数据已足以否定“少数坐标所以微小”“旧处理与新写入必然同向放大”“局部幅度决定输出”“S3换V就是独立写入贡献”这些读法，尚不足以指定唯一原生机制。

下一笔模型计算只有在能明确对应这段缺口、并区分原生传递解释与条件性恢复时才值得投入。若只能再得到不同层的变化幅度或另一组恢复比例，应停止该方案。这里不提出新GPU运行，也不把继续计算当成本次完成的条件。
