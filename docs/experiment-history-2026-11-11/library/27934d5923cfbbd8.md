# WSB-01 正式结果：供体写入效应依赖差值与接收背景配合

2026-11-11，北京时间 18:36 正式退出已确认、18:37 完成服务器 CPU 统计。执行依据为用户“继续推进吧，实验结果出来后，再跟我汇报”；沿用已交付方案的真实预检→正式四格及全包 3 GPU 进程小时上限。

**实验完成，结果可判读。四种组合中，只有 H 来源差值放入 H 接收背景产生强净供体转移：CC=0、CH=0、HC=0.003、HH=0.882。四格均 348/348 完整有效作答，不是停止或无效答案制造的差异。结论落在方案预写的“只有 H/H 强、两种交叉弱、配合效应”一行，而非来源单方或背景单方主导。**

**投入判断：值得继续围绕这项具体关系推进论文，但本轮还不足以宣布机制解释已经完整、或现有框架已经足够 ICML。** 新增的是对既有来源效应的可检验约束：固定同一份实际写入改动后，其选择效果仍取决于接收背景；反过来，固定 H 背景后，换用 C 来源改动也不能复现强效。尚缺的是哪项具体计算变化造成这种差异，以及同一关系能否超出当前方向和已见面板。不是要求下一轮解释全部原生故障。

## 1. 用人话解释这四格

先让同一接收问题在两个背景中运行，分别记录“把自身写入内容换成供体内容”实际造成的写入改动，再把每份改动原封不动放到两个接收背景中。固定配对、层位和时刻；更高层及后续回答自然生成。

- **C** 是正常的干净缓存背景。
- **H** 是受针缓存，但已将指定 14 层的整个卷积缓冲恢复为本输入的干净值；它就是旧 DWB 的 OO。**H 本身能作答，不是原生受针后大多停答的 T。**
- 两种差值分别记作 ΔC、ΔH。它们是各层同输入双 kernel 实际后状态的 FP64 差，不是两条完整轨迹的总状态相减。14 层按来源轨迹形成的改动集合作为一个联合操作；没有归一化、缩放或按接收背景重算。
- 格名第一个字母表示接收背景，第二个表示差值来源。CC、HH 是同源重放；CH、HC 是交叉重放。

| 接收背景 | 放入 ΔC | 放入 ΔH |
|---|---:|---:|
| C：干净 | **0.000** | **0.000** |
| H：指定可作答的受针混合背景 | **0.003** | **0.882** |

表中是冻结的净供体转移分数 D_tr，**不是准确率、错误率，也不是“88.2% 的回答照抄供体”**。它扣除不预测同一答案行的其他供体条件，再按接收者等权平均，用来识别选择是否跟随供体。自身恒定答案在该量尺上为零。

C 接收者在两种差值下都保留自身正确答案。H 接收者拿到 ΔC 时也没有明显净供体跟随；拿到 ΔH 才出现强效。因此，“H 来源改动本身足以在两个背景都产生强效”和“H 背景对这两类改动都产生强效”这两种简单解释均不符合实测。

## 3. 哪个预写解释得到了支持

| 对比 | 点估计 | 六个主对比同时覆盖 95% 区间 | 冻结判定 |
|---|---:|---|---|
| S_C | 0.000 | [-0.063, 0.063] | 预设等效区间内近零 |
| S_H | 0.878 | [0.816, 0.941] | 明确正向 |
| B_C | 0.003 | [-0.059, 0.066] | 预设等效区间内近零 |
| B_H | 0.882 | [0.819, 0.944] | 明确正向 |
| I | 0.878 | [0.816, 0.941] | 明确正向 |
| G | 0.882 | [0.819, 0.944] | 明确正向 |

- S_C=CH−CC、S_H=HH−HC：固定接收背景，换差值来源。
- B_C=HC−CC、B_H=HH−CH：固定同一差值，换接收背景。
- I=HH−HC−CH+CC：四格行为交互；G=HH−CC：两端点差异。

S_H、B_H 与 I 的下界均超过预设 +0.15；S_C、B_C 的同时区间完全落在 ±0.10。完整作答率均为 1，因此无效输出极端填充的敏感性区间与相应主区间相同，所有护栏通过。数据符合[方案 §8](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-write-signal-background-v1-2026-11-11/PLAN.zh-CN.md)中“只有 H/H 强”的分支。

这支持的是**指定写入差值与接收背景的条件配合**。I 是完整答案选择量尺上的交互，不能直接命名一个新内部模块、独立协作机制或两个相加的自然贡献份额。非线性网络可以产生交互本来就是已知事实；本轮认识增量在于把既有供体效应约束到这两份实际写入改动及其接收条件，而不是发现“模型会有非加和”。

## 4. 对论文主张的增量与边界

可以新增的准确表述是：

> 在 Qwen3.5-4B 的既定稀疏干预方向与指定可作答混合背景中，供体历史引起的选择变化依赖其实际形成的写入差值与接收计算条件的配合。H 来源差值移入干净背景、或将干净来源差值移入 H 背景，都不足以复现 H/H 的强净供体转移。

旧 SPF 已有缓存级背景依赖，DWB 已把供体作用连接到 t1 的指定写入。旧操作同时允许当前 q/k/v、写入和后续响应随背景变化。**本轮的不同在于保存同一份实际 ΔW 并跨背景精确重放**：不是把相似的四格数字换个名字，也不是拿两套协议的均值相减。HH 与旧 DWB DO 逐条完整输出一致；新交叉格才提供额外约束。

这一结果有继续推进的价值：它排除了将既有效应简单归到某份可独立携带的强写入，或归到对两类写入都同样敏感的接收背景。它为后续解释提出了具体对象，能积累到原有来源—写入—读取链。

尚不能说：

1. 已找到接收背景中起作用的唯一部件，或已经定位为纯 q 读取。背景响应还包含原有状态、当步读取、更高层更新、KV 以及后续计算。
2. 已解释原生受针 T 的停止原因，或已找到恢复原生完整答案的方法。H 是已恢复卷积缓冲的混合端点；NGC 阴性仍保留。
3. ΔH 的效力已被归因为方向、幅度、内容特异性、某个夹角或 β。本卡没有相应匹配控制，不能用排除法填空。
4. 这项新关系已经跨模型、跨针或在新材料确认。本轮仅一个 4B 模型、N4146、原 48 已见输入；DWC 的新材料确认不能借给 WSB 当确认集。
5. 一张强交互表已经构成新的普遍原理或足以保证 ICML 接收。本轮没有重新进行文献穷尽检索或独立论文评审，不新增首次性或录用概率判断。

**建议继续，但保持投入有界。** 当前 S3 关键测量已完成，G1 获得了一个有价值的正向增量；它不等于整篇论文已过投稿门槛。后续优先沿这项具体关系寻找可解释、可预测的计算差异，再按既定日程检验同一关系的范围。此处是结果含义和既有日程状态更新，不是下一张实验设计或新的 GPU 执行授权；不自动扩层、换针或启动 9B。
