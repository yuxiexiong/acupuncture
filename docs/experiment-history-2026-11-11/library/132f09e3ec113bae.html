WSP 更新追踪：原帖新讨论、外部复现与作者资源（2026-11-05）

对照基线：11-03 WSP 方法档案。本次只做公开资料核查，没有运行模型、下载权重、启动 GPU 或修改实验计划。以下第三方成绩均为其公开报告，不是 Acupuncture 独立复现。

1. 结论与覆盖范围

有新增内容。最有研究价值的是三类：无权重修改的强基线复测；单次前向决策模型的定向编辑及其事实依赖反例；补丁在新场景是否仍有效的检验。 当前没有核实到 WSP 原作者发布新一代通用搜索 harness 或新的 4B 补丁。

本次直接登录读取原帖、作者主页和 Replies，切换原帖 Recent，检查最近约九小时的可见回复，并沿技术分享打开详情；另外读取作者博客、网站提交、日志仓库提交、全部当前九条 issue/PR 条目及重点正文，查公开外部复现。原帖约两千多条回复，未逐条穷尽全部历史回复和引用帖。没有发送消息向分享者索取代码。“未找到”仅指本次核查范围。

2. 原帖中新出现的具体研究分享

2.1 ZOOZOO：把 WSP 用到单次前向的决策模型

分享帖 · 完整公开报告

这是外部扩展，不是 Rikiya 团队新实验。报告在 AutoJev 接口上测选项概率，不依赖长推理链；因此比再做一次数学解循环更能检验方法的其他用途。

同一公开 2,157 题面板 原版 编辑后 监督微调后 微调后另加编辑
Qwen3.5-0.8B 58.69% 62.68% 74.18% 74.13%
Qwen3.8-27B 80.20% 84.42% 87.67% 88.27%

其方法有两条具体线索： - 0.8B：输入格式条件化的偏好修正。 用轮换选项位置的练习题估计字母偏好；改最后一层四个原贡献较低的 MLP 神经元，让不同题型触发不同的 B−A 分数移动；另改六个决策读出行。使用投影、伪逆及有标签开发反馈，不用梯度优化。它不是原 WSP 的 L15/L19 循环补丁。 - 27B：将提示带来的分数变化写入权重。 在练习输入增加任务规则句，测量选项分数变化，再在末层三个神经元的 gate/up/down 投影写入相应修正。推理时仍用原普通提示；改动 46,066 个 BF16 值。报告有同位置随机符号、仅改决策头参照和额外 720 题检查。

最重要的边界： 1. 27B 净收益主要来自金融情感的 neutral 判定阈值；不能称广泛推理能力增强。原始面板上其他任务合计只净增十题，新面板合计净减两题。 2. 0.8B 在三十组事实翻转对上，原版和编辑版均没有一组两题全对。总准确率提升，并没有在这组诊断中转化成更可靠的事实使用。 3. 直接把 27B 基座补丁加到 SFT 模型上净少答对一题；重新测量、重新写补丁才得到 87.67→88.27%。将所选规则和强度用于小 SFT 模型、重新计算权重也没有增益。补丁迁移与方法迁移不是一回事。 4. 小模型全补丁在另一批处理协议为 62.96%，在 stock 接口为 62.68%；页面说明 BF16 批处理会改变边界题。不可混用这两个数字。 5. SFT 检查点的训练数据重叠未知；“恢复多少 SFT 增益”是本面板分差比，不是同成本优越性证明。开发允许反复反馈，不等同原 WSP 的 50-pass 预算。

公开页面给出 0.8B 证据包、27B 证据包、训练对比包及文章源文件。本次读完网页，确认这些公开入口；未下载运行其 verifier，未复算逐题文件。

对 Acupuncture 的意义（本项目判断）：控制线多了“任务条件化修正”的具体近邻；机制线多了“分数按预定幅度移动，但事实翻转仍失败”的有价值反例。不能将其效果当作我们缓存机制的独立复现。

3. 新的外部复核：原版推理设置能恢复多少收益

GitHub issue #4 · Carlos Toledo 完整复核 · 证据目录

该独立报告用一张 H200、每题四次采样复测 MATH-500 原版，得到：

未改权重的条件 全样本准确率下界 到 token 上限比例
原 WSP thinking 设置 7.2% 93.1%
模型卡推荐 thinking 设置 22.3% 75.0%
模型卡推荐 non-thinking 设置 44.0% 0.3%

其精确评分器可处理447/500种金标准答案；下界把不能判定的答案算错，non-thinking 的可判定子集为49.7%。REFUSED 指评分器不能判定，不是模型拒答。不同设置还改变温度、惩罚和长度预算。

含义：不改权重也能获得显著恢复，必须区分“相同设置下补丁的作用”与“相对合理原版用法的实际收益”。这未否定原版与补丁在同一设置下的提升；不同评分口径下的44.0%不能与原作者48.1%直接作严格配对差值。该复测也没有回答补丁在推荐 non-thinking 下是否仍有增益。

此处只转述公开复测，未运行其 GPU 或离线验证器。原搜索20.3小时的硬件仍未因此变得已知：这里的H200是外部复测设备。

7. 对我们而言，哪些值得继续理解

这不是下一轮实验设计或执行授权，仅是阅读后的问题排序。

  1. 最贴近控制线的新方法：Jev 条件化编辑——从提示引起的分数变化到输入依赖的局部写入。值得理解其改善究竟来自校准、决策阈值还是信息使用；其反例与方法同样重要。
  2. 最影响收益判断的新证据：原版设置复测。修复能不能胜过简单合理设置，和修复是否存在因果作用，是两个问题。
  3. 最贴近机制线的新区别：恢复/利用原有计算与另建旁路。小车场景敏感性目前仅线索；Jev事实翻转负例更具体，但也不直接解释我们的历史状态链。
  4. 最影响自动找配方可靠性的未知：提供多少诊断提示、重跑多少次能找到有用补丁、从基座到SFT是否需要重估。当前没有新证据支持“任意人格都能稳定搜索出来”。

按青蒿素原则，已有投影、伪逆、候选筛选和阈值修正都可当部件；研究价值取决于能否在明确任务下形成可靠增量与解释边界，而不是这些部件是否从零发明。也不能因为公开分享有漂亮分数，就跳过事实利用、保留原行为和泛化边界的判断。
