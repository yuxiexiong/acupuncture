# v1.7离ICML Strong Accept的差距与补证决策

2026-11-08。本文是协调人在三份定性报告和三份评分全部锁定后的综合判断，不是第四份独立审稿。评价输入为`f5f5e683fb876cb00e5f8a6dcb2c641d47392dfc`的论文v1.7；结果、分数和局限均不得外推为真实会议决定。

## 1. 明确结论

**当前有可信、可累积的机制实证，尚未形成Strong Accept所需要的鲜明解释与影响。** 本轮独立模拟为4、3、3：接收边缘，有实质优点，也有会影响接收的弱点。分数不是概率或等距质量刻度；不把均值3.33当“最终分”，更不把差两三档换算为补几次实验即可。

三人均认为核心限定结论技术上总体扎实。主要争议不是数据量不足或结果全无效，而是：**在已知写入、状态移植和检索机制之外，稀疏干预究竟改变了什么计算依赖，本文教会读者什么新的、可预测的认识？** 单纯多一个9B阳性，不能自动回答这一问题。

## 2. 三人认可的正面资产：不撤回、不重跑

1. **DWB→DWR→DWC有实质连接。** 同一写入来源端点接到后续用途替换，完整回答上的获得、撤回和自身恢复比单独开口或logit恢复更有解释力。DWC主方向F=.588、G=.311、W=.473、R=.394，是已有正面贡献，不能因其他缺口未补就改写成“只做了几个小测试”。
2. **独立材料确认有效。** 固定操作、96基础情境、族内配对重抽，保留N1210获得低于M及全部失败。这一步增强了可预测性；不能因仍在六族内就说“没有确认”。
3. **负结果实质排除了解释。** 随机读取也产生首列错号，受针状态在某些接收背景仍可传递选择，反对首列特异内容及统一信息删除。负结果不是附录里的失败清单。
4. **既有多模型资产继续使用。** 18,272份单针回答、7,632份轨迹和2B/9B能力面板保留为现象与代价证据。不同协议不证明共同机制，但这不等于这些实验没价值。无需重做扫描、映射或1400题benchmark。

## 3. 真正的分歧与协调判断

R1认为现有可预测、可逆的条件关系已足够构成能被继续利用的子领域贡献；R2/R3认为尚需更清晰的新认识和自足表达，才方便他人据此研究。三人并未争论DWC核心数字真假；他们对**解释深度和已有贡献是否足够有用**赋予了不同权重。

我接受共同指出的优先缺口，但不把每条意见升级为必须加实验。尤其不采纳以下机械要求：解释全模型唯一机制、所有族都过.25、再做全模型扫描、必须产生实际修复收益。现有条件因果证据本身值得发表讨论；目标是把它形成有分量的科学解释，而不是为降低风险把论文缩成工程验收。

### A. 最优先：原生干预的变化与构造性写读关系之间，新认识是什么

DWC原生N4146有861/864停止，而O/F已用干净来源影子v及k修正，主要读取结果在可作答端点发生。因此不能把供体定向阳性直接写成原生失败的完整自然中介。该界限已披露，问题是当前主文没有把“这些构造实验为什么能解释干预”集中讲清。

同时，不能把“没有完整原生中介”误写成“没有任何受针相对干净的背景证据”。协调人核对了既有[SPF报告](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-selection-precedence-v1-2026-11-06/REPORT.zh-CN.md)：N4146缓冲供体效应在受针背景为.896，在干净背景及只换入受针状态条件均为0；恢复自身干净状态又能压住效应。这已经是背景依赖的证据。[DWB报告](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-donor-write-bridge-v2-2026-11-07/REPORT.zh-CN.md)又把供体来源连接到指定写入。**二者的端点和操作不同，不能直接相减或宣称DWC的D/E背景差已经测过。** 正确第一步是明确哪些连接已有、哪些缺同操作对照，而不是重新跑整套SPF。

### B. D/E的经验分叉还没有变成足够清楚的计算解释

D和E投影不同，E含额外门控、内积和负号。最终答案上的异号不是负号必然推出的，但两臂效应大小也不能直接命名为天然功能分工或机制份额。应把已知代数、实际补丁几何、行为预测分开。

先审计已保存的张量/摘要能否支持该分析；没有张量不能从输出反推几何。协调人只抽查了一份DWC正式回答记录，其中gainD包含生成token、终止及t2哈希，没有输出补丁向量或范数。这个抽查不能证明服务器没有缓存，也不能承诺现有JSON即可完成几何分析。不得为审稿意见预先批准等范数随机矩阵或大规模重放。

### C. 表达与方法自足性：确定可用现有材料解决

三人Presentation均为2，不是因为没有英文PDF，而是阅读需要穿过大量代号、历史合同、旧图和未来方案。应以当前核心论证组织主文：一个完整提示与供体例子、一张t1/t2端点图、精确剂量/窗口及层组选择、D_tr公式与手算小例子、一张DWC主结果图。旧实验和失败仍完整保留于补充，不能删除不利证据。

R1/R2/R3都指出正文§4.10的N1210 D−E撤回区间上界写.342，而冻结JSON为.342978…，三位舍入应为.343。协调人复核后列为下一正文修订项，不在固定审稿稿中改动；不改变结论或审稿评分。

### D. 范围与异质性：不能只把弱方向叫“边界”就结束解释

R3强调主方向逐族获得.117–.502、第二方向.030–.409。总体确认正确，但窄总体区间不能替代适用条件解释。应先并列旧逐族F/G/W/R、完整交付、端点余量及结构；探索关联不能冒充已冻结预测，不能归因参数量或用归一化改换原主要终点。

跨模型机制仍是缺口，但在当前贡献不清的情况下扩大范围，可能只得到“同样操作在另一个模型也能工作”。9B的价值取决于它检验哪条机制预测。
