3. 原文复核后需要纠正的八件事

3.1 “金融论文引用错了，应换成LatentPort”不准确

Reading Is Not Using §5.4及附录D.2确实以Qwen3.5-9B-Base为机制工作模型，在披露结束位置交换两次阅读形成的状态，再处理共同后缀。其递推通道包含卷积缓冲与gated-delta状态；另有注意力访问干预。它研究同模型信息如何影响判断，LatentPort研究跨模型状态交接，二者都相关，不能互相替代。

这恰好说明青蒿素原则的实际意义：应按方法与证据取用成果，不能按论文应用领域筛掉可用机制。该文还明确说明通道相互影响，移除与重建比例不是总和为一的分解。

3.2 “Qwen3.5删四坐标，十任务准确率掉43%”混淆了实验对象

Massive Activations in Hybrid Linear Attention LLMs §4.3、表3的消融对象是六个M-A-P GDN检查点：340M/1.3B与三种混合比例。跨模型平均准确率51.63→29.43，约为相对下降43%，不是下降43个百分点。Qwen3.5的观测图不能改写成Qwen3.5-4B完成了这项消融。10-29旧报告其实已纠正过这一点，应保留更正而非随新截图回退。

3.3 “四个down_proj神经元只输出EOS”有原文内部冲突

2512.00918v2 表1/§6.1将五个gate_proj单元的NaN分数与只输出结束token联系起来；表2的四个down_proj单元仍有CLIP分数，但§6.3又把down_proj描述为EOS、gate_proj描述为重复。不能将其中一处转述当作已消除冲突的精确结论。

另一个更重要的操作差异：论文§6.3把down_proj位置记为4096维输出空间；本项目是在MLP中间通道、down_proj输入处加偏置。名称相似，不等于同一个“神经元”。稳妥结论是已有稀疏消融导致严重生成失效的先例，具体EOS对应条件须进一步核对作者材料。本轮未做复现。

3.4 “少坐标为什么影响大已解决”只覆盖一部分问题

Liu §8–10给出残差几何预算和有限幅度触发解释，但触发剂量仍需测量，统一局部曲率公式没有稳定预测成功；还明确留下未测的注意力/读取机制问题。

所以，少坐标不等于小扰动、某些大剂量几何上为何压过原表示，已有解释应直接承接。至于一次具体针怎样经过历史状态和后续读取改变回答，不能由这条几何关系自动推出。也不能把它包装成我们要重新发现的普遍规律。

3.5 “无人拆过卷积、无人串过端到端链”范围过大

LatentPort附录F有KV、递推、卷积的完整组件组合，比较直接拷贝与翻译后的交接；这不是我们的干净/有针组合，但足以否定“从来没人独立处理卷积”这种宽泛说法。

How LLMs Are Persuaded §4、附录R和Models Take Notes at Prefill附录C–D已经给出各自任务里的写入、传播、读取到决策的干预证据。未找到完全相同的“同一MLP针×三缓存×当前终点”组合，既不是整个因果链领域空白，也不自动是强贡献。

3.6 QK与OV是不同设置下的路径，不应合并成单一普遍规律

说服任务中的干净注意力图替换能恢复选项选择，支持QK改道；拒答转向论文固定QK后影响较小，OV冻结影响更大。前者使用受说服上下文，后者是表示转向，目标、模型和条件不同。说服研究，拒答转向研究§6.3。

这给我们的是区分“读哪里”和“读出什么”的办法，而不是选择一篇把另一篇当例外。我们深层线性注意力的卷积前V也不能直接等同于全注意力OV实验中的V。

3.7 WriteSAE不是“0.8B成功、4B整体失败”

WriteSAE §4、§6.2及附录A的局部logit近似在0.8B指定单元拟合好，在4B L12/H8失效；但另一个4B L9生成实验改变了换行率。单个位置、目标和近似失效，不能否定整个方法在4B上的用途；也不能因生成有效就宣布近似公式已跨规模成立。其系数拟合及局部近似前提必须保留。

3.8 几个容易误导研究判断的词应收紧

  • 26–77倍： 2606.29522中的特定模型/任务校准结果，不是所有steering都如此；该文既有不对应自然编辑的例子，也有写入后被后续运算使用的正例。
  • stopwords： Super Weight里的停用词不是EOS结束token。不能从“常用功能词概率改变”直接推出“停嘴机制”。
  • 缓存只存投影： 因果自注意力模型的后面位置已经处理了前文；它们的KV可能包含前文影响和算出的结论。架构事实与经验因果载体需要一起考虑。
  • seq_len==1陷阱： 2609.04434附录B描述具体实现路径，值得工程核对；不是所有版本、所有混合模型永远相同的架构定理。
  • 负结果： 没有发现原生读取、替换不恢复、某个探针不可解码，分别限制相应操作，不能一律写成“信息不存在”。

4. 合起来，已有工作能给出多大解释

4.1 针对核心课题的一段话总结

我们的核心课题是：少数通道的激活干预，如何改变模型的写入、历史状态处理和后续读取，最终造成显著的回答变化？ 现有Related Work已经能解释这条链中的重要组成部分：少数坐标的改变可以经down_proj形成幅度并不小的残差写入，归一化和后续计算使其改变表示与决策；提示处理中的变化可以进入后续位置的KV、递推状态或卷积历史，并在后续更新、覆盖和查询读取中继续产生影响；读取既可能改变“读哪里”，也可能改变“读出什么”，进而改变输出分数与选择。在特定任务中，前人已经用因果干预贯通了写入、传播、读取到决策的局部链条，因此不能说这个领域只有现象、没有机制。但是，把不同论文的这些结论串起来，只能得到解释框架，不能当作我们同一次稀疏激活干预的全链证明。 在本次已核查的文献范围内，尚未看到一篇针对我们的研究对象，在同套条件下把入口扰动、历史状态的形成与处理、实际更新和读取、原生回答变化系统贯通并验证其关键边界的论文；这不是“绝对无人做过”的证明。按青蒿素原则，我们可以直接借用已有理论和工具，贡献在于把这些环节接成可信、能产生可检验预测的机制解释，而不要求每个环节都是首次发现。支撑与限定见本报告§3.4–3.7，以及残差几何研究、prefill笔记、线性注意力记忆、说服机制、表示转向机制和缓存组件交接。

4.2 分环节解释与证据边界

综合解释（不是某一篇已证实的统一定律）： 一次中间通道加法，经down_proj会成为残差空间中的定向写入；“改的坐标少”并不限制它相对原残差的幅度。归一化、既有巨激活结构以及后续非线性计算，可能把这种写入转成显著表示或决策变化。处理提示时，这些变化既可能留在源位置，也可能改变后续位置计算出的结论和KV，或改变递推状态与短卷积历史。后续计算对这些历史量的使用受新输入驱动、遗忘/覆盖操作和查询方向共同决定；保存了信息不保证原生读取器使用它。读取端可能因QK选中了不同来源而改变答案，也可能通过V/OV内容、门控、MLP或输出归一化改变分数，随后生成的文字又能继续影响后续生成。各段都有具体论文与实验支撑，但把它们用于解释我们的同一根针，需要检验连接关系，不能把几篇不同任务的结果拼成已验证的全链机制。

入口写入 down_proj列向量、有效幅度/夹角、控制窗与极限 有限剂量在哪层触发哪种失败，以及为何出现特定答案
历史形成 下游结论笔记、KV与递推通道移植 我们的异常究竟在什么计算过程中形成

该表定义的是解释边界，不是要求同时补齐的五项实验。

5. 用青蒿素原则重新判断课题

这里将用户说的原则落实为：重用有效知识和方法，围绕重要问题提纯出可靠解释；不以“和所有前人不同”为目标。 这是本项目的研究判断准则，不作科学史类比证明。

5.1 已有发现是起点，不是“领地已被占”

“稀疏干预能造成大变化”可以成为动机和需要解释的现象，即使它不是我们的首次发现。现成的几何预算、递推公式、KV移植、QK/OV诊断可以直接使用。真正要避免的是把公知结论重新命名后当成果，而不是避免使用它们。

“对象已被做过，所以致命”也不成立。即使模型、操作相同，只要已有证据还不能回答重要问题，补出更可靠的机制、可检验预测或实质边界仍有价值；但仅换一层、换一个模型、补一个组合格，不会自动产生这种价值。

5.2 不把课题挤成“三类缓存各占百分之几”

三类状态在形成和继续计算时相互作用。移植还改变状态与当前输入的匹配关系。因而某操作能搬运80%的读数，不等于该状态自然贡献80%；合计大于或小于100%并非天然错误。

更有价值的认识是：哪些已经形成的量，怎样改变接下来的具体计算，使答案发生变化；这一解释在哪些条件下成立或失败。 若复用已有更新公式就能解释关键变化，贡献可以在因果对应、适用边界和预测，不必再发明一种更新原理。反过来，只有会计式分账、没有理解增加，也不能靠“首次三类同时测”支撑课题。

5.3 不要求每一轮、每一篇把整个机制讲完

已知机制在我们的条件成立，可以把这一段固定下来继续接下一段；不成立，可以识别哪项前提失效。证明某个看似合理的解释不能解释关键现象，也能减少不确定性。价值取决于问题重要性、证据强度和后续可用性，不取决于是否一次获得所有层、所有模型、所有针的统一理论。

也不必把“立即EOS的唯一机制”设为终点。停止、循环、任务内容变化可以帮助分辨作用方式，中心仍是局部干预如何改变计算与回答。

5.4 两条线保留各自的成果标准

缓存机制线可以产出解释，不必强行附带一个更强控制算法。稳定副作用控制线可以采用现成机制或方法，但需要相对适当参照的效果—代价改进，不能把解释图或流畅案例当算法胜出。两线可共享结果，不能互相替代证据。
