B3-P0 结果复核与下一问题构想

2026-11-01；依据：9c83b9a 的 B3-P0 REPORT、CONTRACT 与用户截图。仅文档/逻辑审查，未复算张量、未运行实验。沿用 academic-research-suite 内联设计流程和 experiment-design-self-check v1。

设计卡

主线仍是稀疏激活干预如何经历史状态和读取改变回答。本轮拟问：B3-P0 观察到的两个主效应对齐，有多少可由共同的干净背景径向变化解释，有多少留在切向空间？这不是继续寻找特殊头，也不把解释停止读数等同完整回答机制。

新增认识：比较明确的背景径向几何解释与剩余切向对齐，约束下一次因果问题；不重新证明范数恒等式。现有终点对齐、平方范数负向交互为报告结果；径向解释和信噪比解释均未验证。

操作为旧 B3 四格张量的 CPU 分析，不改变模型：c=h00、a=h10-c、b=h01-c、k=h11-h10-h01+h00。取 e=c/||c||，a_parallel=(a·e)e，a_perp=a-a_parallel，b 同理；精确分解 a·b=(a·e)(b·e)+a_perp·b_perp。c 范数为零则不可定义，完整保留。径向收缩必须两投影均为负；只看乘积正不能称收缩。

先分析终点；所有四方向、FIX/U1/U2、六情景两事实均报告；既有逐层记录仅用于该同一分解的描述，不选最大层、不给层号因果含义。绝对内积为主，余弦和份额为辅；近零向量不报余弦，负交互记录不删除。报告停止分子、r、z 时保留已观测 k，不将几何分解写成干预效果。

已见面板只用于探索。预算建议上限 1 CPU 核小时、0 新模型前向/模块重算、0 GPU，资产可达性与确切张量字段需工程准备核对；不为本构想重建模型缓存。输出一张逐情景径向/切向账目表及结论。

判读：若共同负径向投影承担多数正对齐且切向弱，则优先采用共同背景收缩解释；若切向贡献稳定且大，则径向解释不足；若方向间分化，保留条件差异，不拼成一个共同机制。这里“多数”仅描述各单元带符号贡献及占比，不以均值阈值伪装确认检验。无论哪种结果，都不能证明对齐的计算起源。

出口：本轮只交付上述几何解释的充分性/不足和可否形成下一项计算预测。没有具体预测则结束记录分析，不再扫描层或头。若下一问题确需 FIX 特异性检验，另立幅度匹配合同，不纳入本轮预算。

对幅度匹配建议的限定

cos 对纯标量缩放不变；随机组范数较小本身不能证明信噪比低导致 cos 低。若另做匹配，需要校准/评价分离，同时检查 a 与补集 b 的幅度、层分布和可匹配支持域；不得在测试输入上按 cos 或交互筛选对照。无匹配支持域应报告不可比，不能放大随机向量后声称得到另一组真实随机头。该实验回答大小相近时 FIX 是否仍不同，不能直接回答对齐如何形成，因此不是当前默认主线。

历史错误、比较与反方检查

重点防 E01/E04/E08/E09/E10/E14/E16/E19/E20/E22/E23/E24/E25：不换课题、不称恒等式为机制、不混淆代理终点和因果起源、不把已有面板当留出、不因阴性扩规模。E03/E12 防用幅度与随机对照冒充一般损伤排除；E21 不作首次发现声明。其余 E02/E05/E06/E07/E11/E13/E15/E17/E18/E26 未涉及新层干预、供体拼接、语义存量或形成期因果操作，不适用本 CPU 构想。

相较上一计划，停止单分支候选筛选，接受 no_candidate；从向量交互的来源转向已观察到的主效应共同方向。不同于报告建议，不直接启动按最终范数筛随机头。

最强反例：径向分解即使解释全部对齐，也没有回答为何模型沿该方向变化。处理：只承诺检验具体几何解释，不宣称完成机制；若不能据此形成可区别的计算预测则停止本分支。第二反例：挑 c 为轴可能只是事后有利选择。处理：c 是预先定义的共同干净背景，明确探索性质，不追加其他参考轴寻找好看结果。

结论：构想层面逻辑自查通过；非独立审查。实施合同、数据可达性、数值验收未完成；本次没有新运行授权、没有执行任何模型/张量分析。
