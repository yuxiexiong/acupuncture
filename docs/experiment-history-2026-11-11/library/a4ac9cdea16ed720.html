2B、9B 与 Llama：同一道题的传播链个案

2026-10-28；只读取本地核验归档，没有运行模型或新实验。复算脚本：cross-model-cases.py；11 个案例的首位置全部组件、逐 token 数值、完整原版与干预回答及原始文件路径：cross-model-cases.json。脚本校验正式 receipt、源/记录/trace token 完全相同、首差分组件位置、逐步生成 token 是 steered 最大 logit 候选；全部通过。

最清楚的共同线索

这些例子共同出现的是 单通道写入改变下游表征和起始 token 选择；部分轨迹进入重复后，已经生成的错误历史也支持继续重复。它们不支持“某个早层专门负责完整语句”，也没有给出跨模型相同通道的对应关系。

所有例子使用 Q04：“请列出整理书桌的两个步骤，严格分成两行，每行以‘第一步：’或‘第二步：’开头。”三模型原版都给出正常整理步骤。以下是有目的挑选的案例，不代表全样本发生率。Llama 原版和部分正常对照本身含空白行，称“正常”仅指内容连贯、有两个步骤，不把严格行数遵守混同于整体语言能力。

首预测位置固定为 prompt 最后一个 token。相对差分为 ||steered-clean|| / ||clean||；它分别以每个组件自己的 clean 范数归一化，不宜把 MLP、attention、residual 的数值跨组件直接当同一个量纲比较。KL 为整个词表的 KL(steered || clean)。

三条实际轨迹

2B：L5 MLP 改写后进入标题模板循环。 首词从“第一步”变成 **。

Trace ID：2b-L05-N003522-D-1__Q04，同点对照 2b-L05-N003522-D-0.5__Q04。

−1 在首位置的 L5 attention 完全相同，L5 MLP 首次出现差分：clean 范数 2.091、差分范数 4.092、cosine 0.450。L5 residual 相对差分 1.228；下一层 L6 attention 已有相对差分 0.980、cosine 0.584；到 L23 residual 相对差分仍为 0.709、cosine 0.735。首步原本最佳“第一步”，实际选“**”；该实际 token 的 clean logit 落后 clean 最佳值 6.438。

原文循环单位是 **整理书桌**\n**第一步：第二步**\n\n。从 step 18 到 127，clean shadow 对已经形成的受损前缀也都把实际生成 token 作为最大值；后半程 KL 中位数只有 0.0113。这说明不能把循环的每一步都解释为“持续大幅扭曲预测”；进入某种历史后，两条分支的下一词选择已可相同。−0.5 对照首词保持“第一步”，step 2 才改变措辞，最后仍有两个连贯步骤。

9B：L0 改写，经 L1 attention/residual 明显放大；停止和重复是不同出口。

Trace ID：9b-L00-N000978-D+1__Q04；剂量系列同前缀 D+0.125、D+0.25、D+0.5、D-1。

+1 首位置 L0 attention 相同；L0 MLP 差分范数 7.891，而原 MLP 输出范数仅 0.728。L0 residual 相对差分 1.580，L1 attention 相对差分 11.437，L1 residual 达 3.336；随后不是逐层单调增大，L26 residual 降到 0.802，L31 为 1.679。首词由“第一步”变为“托”，实际“托”的 clean logit 落后 21.859。

前三步 shadow 原本依次偏好“第一步”“物”“：”；从 step 3 至 127，在“托托托…”的历史下 shadow 也都选“托”。后半程 KL 中位 0.0159。这个案例最明确地显示“开头偏转”与“受损历史下的后续延续”可分开观察。

同一点 +0.125 仍正常；+0.25 则第一步 EOS 优势由 clean −15.438 变为 steered +0.5；+0.5 先“托”，下一步 EOS 优势由 clean −5.375 变为 steered +0.188；+1 却不立即停止，而是循环。−1 的 MLP 差分大小几乎与 +1 相同，但直接 EOS（优势 +3.313）。因此 同样大的局部扰动不决定相同故障类型，正负方向和后续读出很重要。这里不能命名“停止神经元”：同点的不同剂量还有循环和正常答案。

Llama：可出现语义离题后循环，也可起始正常而在句中提前停止。

Trace ID：llama31-8b-instruct-L05-N001726-D-1__Q04；对照 D-0.5，反向比较 D+0.5、D+1。

−1 首位置 L5 MLP 差分范数 4.489、相对差分 1.759；L5 residual 为 1.125，L6 attention 为 1.527、cosine 0.296，L6 residual 为 1.195；到 L31 residual 为 0.891。首词从“第一”变为“根据”，其 clean logit 落后 11.75。随后回答“根据《中华人民共和国劳动法》和《中华人民共和国民法典》的规定，整理书桌的两个步骤是…”，后面反复“书桌整理的具体步骤是”。后半程 64 步中有 53 步 shadow 也选实际 token；但仍有多处持续分叉，不能把它概括为和“托”完全相同的动力学。

同点 −0.5 仍给出两个连贯步骤。+1 则前三个 token“第一”“步”“：”都未改变，step 3 才由 clean“清”转成“把”；到 step 9，clean stop advantage 为 −14.8125，steered 为 +2.4375，选择 <|eot_id|>，留下“第一步：把书桌整理好”。因此“首词未变”不能排除后续严重输出损坏。

三维图应该怎样读这些证据

  1. 固定同一题、同一点，切换低/高剂量；先停在 prompt 最后位置。三个案例的第一处差分都是注入层 MLP，注入前及同层 attention 相同。这首先是注入位置与观测一致性的检查，本身不是功能区发现。
  2. 沿层深看 residual 差分及 cosine，再看下一层 attention/MLP。9B 例子是早期明显放大后重新变化；2B/Llama 例子并非一路爆炸。相对差分下降不能单独称为修复，因为最终答案仍可能失败。
  3. 再沿生成时间拖动，同时读 clean/steered 候选与 EOS 优势。开头偏转、句中停止、循环形成是不同事件。只看整个答案的平均颜色会把这些区别抹平。
  4. 最后看原文对照。Llama 单个 token 文本里出现 � 可能只是字节片段单独解码；完整回答正常时不能据此标成乱码。

当前可跨模型比较的是“注入点 → 下游组件变化 → 预测分叉 → 错误历史/停止读出”的过程指标，不是同一 layer/channel 的同源脑区。9B 单例比另外两例的注入 MLP 相对差分高，既有范数分母差别，也有点位/模型/剂量差别，不能由此宣布整个 9B 更脆弱。

clean shadow 是不施加干预、使用独立 cache、被迫读取实际干预输出 token 历史的分支；它不是原版自由生成，也不是运行中途拔针后继续。因此上述“历史支持重复”是现有观测直接支持的表述；“该历史是必要原因”“拔针已无法恢复”“哪个组件是因果中介”尚未由这批数据证明。
