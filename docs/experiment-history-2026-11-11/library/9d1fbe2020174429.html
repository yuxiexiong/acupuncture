B2 计算后续（CPU）分析合同 r01（运行前提交）

日期：2026-11-01。设计：计划（a03b14a），加入用户 2026-11-01 确认的两条验收补充。授权：用户“直接按照现有商量出来的结果写代码写合同做测试然后跑实验然后上传Git”。CPU 离线：0 模型调用、0 GPU；≤1 CPU 小时；新产物 ≤1 GiB。

1. 对象

B2 formal-r01 的 12 输入（6 已见情景 × 2 事实），固定 H 名单；R=T 的四格 001、101、011、111；主读数停止词 248046 去词表均值 logit，答案词 a（B2 冻结）次要。K(X)=X101−X001−X111+X011 = B_H(1)。

2. 表一：同入口 H 局部写入交互

每个 G 层取 111 格自身入口 x_l，用固定权重（input_layernorm 增益 1+w、in_proj_qkv、无偏置 depthwise conv1d、q/k 的 l2 归一化与 1/√128、k 头 repeat_interleave 到 32）在 FP64 重算当前 q/k/v：q/k 通道取 Q 供体 T 或 C 的 F 槽 1–3；V 通道 H 头取 V_H 供体、R 头取 T；β、z 用 111 记录值。H 头上 I_l = n11−n10−n01+n00（角标 Q、V_H），非 H 头为 0。d_l = out(core111 − I_l) − out(core111)，out = 门控 RMSNorm（逐头）+ out_proj；P_local = Σ_l u·d_l，u 用 111 最终 RMS 分母。逐头分解并核对可加。

3. 表二：真实四格逐层账目

K(Δx_l)，Δx_l = 第 l 层出口 − 入口（13–31）；p_l = u·K(Δx_l)；末端组 = 27–31 层（预先固定）。K(第13层入口) 必须为 0；层间逐位连续、第31层出口 = final:h；Σ 闭合到 u·K(final:h)；实际 K(cz) 与之差单列为“最终分母与舍入项”；K(cz) 必须等于 B2 记录的 B_H(1)。

4. 验收（任一不过 → 对应表停止，记工程不足）

  1. 哈希：B2、CONV、BRIDGE 记录/张量与收据一致。
  2. 身份：B2 111 格的 14 层驱动与 CONV N:TT 逐位一致（确认后才用 CONV 的 out_proj 做对照）。
  3. 门控归一化 + out_proj 重算：out(core111) 与 CONV N:TT 记录 {l}:out_proj 相对误差 ≤0.02（沿用 F_V 局部路径分析标准）。
  4. q/k/v 重算：有针侧（T 的 F）每层对照 111 记录 q/k/v ≤0.02；干净侧 仅第13层对照：q/k 对照 011 格、H 头 v 对照 101 格（第13层各格同入口）。第14层起干净侧无同入口记录，不做验证，明确登记为验证边界。
  5. 代数：四角 I 与乘积式 β(v_T−v_C)(k_Tᵀq_T − k_Cᵀq_C) 残差 ≤1e−12 + 1e−10‖I‖；逐头 d 之和等于联合 d（≤1e−10 相对）；账目闭合 ≤1e−8 × max(1, Σ|项|)。

5. 冻结决策（计划 §5）

情景 = 两事实均值。局部候选：P_local（停止侧）≥5/6 情景均值 ≥0.2 且两事实 >0；对称的负向为“反向预测”。末端候选：Σ_{27..31} p_l 同规则。两者通过 → 都报告，不强行二选一；都未过 → “无合格候选”，不放松、不扩层、不换头、不开 GPU。答案侧同规则只作次要报告。最终分母与舍入项单列。0.2 与 5/6 只是探索性优先级线。
