NMT-01 合同 r01：状态增量幅度分布的双向匹配

依据：NMT-01 v2 方案与自查。两份文件原在分支 codex/nmt-01-norm-match-v2 的 f837ad68，已逐字复制到 main。另加 2026-11-03 评审中商定的三处修正（§0）。授权：2026-11-03 用户原话“开始吧”。冻结后不改本文件；偏离记入 DEVIATIONS.zh-CN.md，合同未覆盖的判断记入 DECISIONS.zh-CN.md。

0. 相对方案的三处修正（评审商定）

  1. Φ 偏低时，同时报告 UP/DN 的 I_S 范数相对目标的比值及余弦。即使 I_S 范数也接近，也不能只凭剩余差就认定原因是方向。
  2. RND 的写入轴直接取原生来源对应层、头和 b 的实际写入键方向：冻结的 custom update 归一化后的 k_b（该归一化把 eps 放在开方内，范数比 1 小约 1e−4 量级），再精确单位化得到 k̂_b，方向不变。删除 SVD 备选路径。
  3. 零范数规则：两边都为零 → X=0；源非零、目标为零 → X=0；源为零、目标非零 → 按工程异常停止本轮，保留记录。不剔除单元。

1. 问题

固定接收背景，只改变状态增量的逐层逐头幅度配置，能否接近另一来源的条件效应？单格效应与完整回答分别检查。

2. 范围

继承 SIT/NVB 冻结身份： - 模型与运行方式：Qwen3.5-4B，revision 851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a；BF16、eager、batch 1、torch 原核。 - 输入：LVK 已见开发面板 48 条，六场景。 - 方向：N4146、N1210、R0（缺口方向），C1343（诊断，单列）。 - 原样继承：R 族 μ、形成与校准、fF、竞争 token、停止集合、解析器、MAX_NEW=32。

3. 操作

记号同 SIT：ΔS(s,b)=S(s,1,b)−S(s,0,b)，按层 l（14 个 G 层）、头 h 分块，n_s(l,h,b) 为块的 Frobenius 范数。在 t1 结束、t2 开始前，接收格 B(r,0,b) 的 14 个 G 层递推状态一次性改为 S(r,0,b)+X：FP64 求和后一次 cast 回 float32；其余缓存、t1 logits 和 token 都来自接收者；t2 起无钩子。

臂 X（逐 l,h,b） 范围
UP ΔS(0,b)·n_1/n_0；第 13 层直接复制 r=0,1 × b=0,1；C＋N
DN ΔS(1,b)·n_0/n_1；第 13 层直接复制 r=0,1 × b=0,1；C＋N
UPG ΔS(0,b)·N_1(b)/N_0(b)（全部层头拼接的总范数） r=0 × b=0,1；只走 C
RND_j，j<5 n_1·k̂_b·ρ̂_jᵀ；k̂_b 为原生来源该层头实际写入键方向（精确单位化）；ρ̂_j 由 sha256(NMT-RND|20261103|输入|方向|层|j) 播种，b=0/1 共用 r=0 × b=0,1；只走 C

旧格全部用重放加桥接得到，不重新解释： - NVB 八格：t1 与 C t2 逐位等于 NVB 正式记录。 - SIT 四个交叉格：用冻结的 SIT 移植代码重建，C t2 逐位等于 SIT 正式记录。 - Y：旧格取自 NVB 正式记录，交叉格取自 SIT 正式记录。

4. 读数与估计对象（冻结；实现见 nmt_core.py、nmt_analysis.py）

4.1 主读数

  • 记 F(r,X,b) 为移植后 t2 的 M，Z(r,b)=M(B(r,0,b))。H(r,X)=[F(r,X,1)−Z(r,1)]−[F(r,X,0)−Z(r,0)]。
  • 两个来源端点：r=0 时，H_0 是 B(0,1,b)，H_1 是 SIT 交叉格 01b；r=1 时，H_1 是 B(1,1,b)，H_0 是 SIT 交叉格 10b。
  • 来源差 D_src=H_1−H_0，分别等于 SIT 的 A0（r=0）和 A1（r=1），不是 SIT 的跨背景 G。
  • 比例与残差：Φ_up=(H_UP−H_0)/D_src，Φ_dn=(H_1−H_DN)/D_src，R_up=H_UP−H_1，R_dn=H_DN−H_0。
  • 次要臂：Φ_UPG=(H_UPG−H_0)/D_src；Φ_RNDj 同式。另报 RND/UPG 与 UP 的配对差。
  • 汇总：先逐输入算差，再对分子、分母分别做六场景等权平均，最后相除，不平均逐输入比例。比例只在场景等权 D_src≥0.5 时计算，允许负数或超过 1，不裁剪。
  • 子集：主子集为目标不在首列的 32 条；全 48 条作补充；C1343 单列。
  • 同时报告：每格 F；每个 b 的 F−Z；逐 b 配对差（UP 对来源 1、DN 对来源 0）。Φ 接近 1 只说明 k 条件效应的来源差接近，不代表单格 M 或 Y 接近。
  • 描述性区间：场景分层 bootstrap，2000 次，种子 20261103；同一组重抽索引用于所有臂、r、b 和方向。若任一抽样的分母 ≤0，比例区间记为不可用，并报告原始差的区间。
  • I_S 描述量：逐输入算拼接后的 ‖I_S(X)‖/‖I_S(目标)‖ 与余弦，取输入中位数；同时报告逐层值和缩放系数分布。

4.2 完整回答 Y

全 48 条：每格正确数；相对 Z 的改对、改坏与净变化；固定 b 时的正确数差（UP 对来源 1、DN 对来源 0）；H_Y；接收端 t1 未停止的子集。固定 b 的正确数差与 H_Y 分开报告，不互称“损失”。主要解释在 r=1；r=0 一侧的地板效应如实列出。

5. 冻结读法（描述性规则，不是显著性或科学成功线）

逐方向、逐接收背景判；先查分母，再按以下顺序取第一个满足的：

  1. 单侧不对称：一侧 Φ≥0.75，另一侧 Φ≤0.5。
  2. 交互接近参照：两侧 Φ 都在 [0.75, 1.25]，且两侧区间下界都 ≥0.5。
  3. 幅度匹配不足：任一侧 Φ≤0.5，且该侧区间上界 <0.75。
  4. 过度补偿：任一侧 Φ>1.25。
  5. 部分/不确定：其余情况，只报连续值。

另附三类标记： - 标记 overcompensation（Φ>1.25）、reversed（Φ<0）独立附加。 - I_S 标注：某侧 Φ≤0.5，且该臂的 I_S 范数比（输入中位数）不在 [0.8, 1.25] 内时，附 IS_unmatched_UP 或 IS_unmatched_DN。此时不得推出“需要方向”；即使没有这一标注，也不能单凭剩余差认定原因是方向。 - 背景差异（独立标签）：同一 Φ 在 r=0 与 r=1 之差的绝对值 ≥0.3，且配对区间不含 0。同时报告原始来源差、分子和残差；分母不同，比例差不直接等于接收敏感度差。

三个缺口方向逐一报告，“至少 2/3 同类”只作汇总，不隐藏第三个方向。

次要臂只作描述，不改变主读法： - RND 与 UP 相近，只说明这 5 个随机右方向也有类似效果；RND 较低，只说明这些方向不能替代原生方向。 - UPG 与 UP 的差异支持幅度配置（逐层逐头分布）有作用，但不指定哪层哪头。

完成即停。下一步选择（不是新授权）： - 双向交互接近且单格效应接近 → 检验该幅度关系的跨条件适用范围； - 不足、单侧、过度补偿 → 保留方向、结构、背景及非线性候选，先选能区分它们的比较；不自动展开 β/k/v 或层组扫描。

措辞限制： - 两个端点不能证明单调性； - t1 后移植不能解释已经发生的 t1 停止； - 剩余差不自动归给某个部件； - 结果不升级为整条线的中心命题。

6. 工程闸门（运行中断言，任一失败即停）

  1. 来源：形成 hash 等于 LVK；NVB 八格的 t1 bf16 logits、t1 token、C t2 bf16 logits 和 M 等于 NVB 正式记录；SIT 交叉格的 C t2 和 M 等于 SIT 正式记录；NVB NHook 的 oracle 与状态恒等误差 ≤1e−5。
  2. 留存桥：只改 a 时只有 G 层 S 改变；第 13 层状态在 c=0/1 之间逐位相同；第 13 层两来源的增量逐位相同。
  3. 缩放： - UP/DN 非零块的范数相对误差 ≤1e−6，1−cos ≤1e−6； - UPG 总范数相对误差 ≤1e−6； - RND 范数相对误差 ≤1e−6，b=0/1 的 ρ̂ hash 相同； - k̂_b 对原生增量的秩一残差 ≤1e−4（确认取到的是写入轴）； - 零范数按 §0 第 3 条处理。
  4. 移植：只有 G 层 S 与接收者不同；cast 后相对 FP64 的 L2 误差 ≤1e−6；UP/DN 的第 13 层等于 B(r,1,b)。
  5. 隔离：源状态、t1 缓存、t1 前背景、C/T 前后 hash 不变；C 与 N 各用独立深拷贝；模块函数已复原，权重 sha 不变。
  6. 预算：计数、设备时间、存储都不超 §7 的上限。

6.2 演示（test_nmt.py）： - 每种读法和背景标签都演示能被满足、也能不被满足； - 零范数三种情形； - 先求和再相除，分母保护； - 分析入口按真实键结构端到端跑通，来源不符时会被拦下。
