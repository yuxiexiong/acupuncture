更正（11-03 评审后） 1. §4 原写“C1343 的答案原本就全对（Y 48/48）”，有误：原生输出四格是 0/48，恢复输出四格才是 48/48。C1343 只在原生输出一侧恢复留存，增强就达到 +3.29（ρ 1.13），与三个缺口方向（ρ 0.11–0.34）明显不同。这个方向差异要正视，不能因为它是诊断方向就略过。 2. §4 原写 t2 q/k 余弦接近 1 所以“不像是 t2 当步 q 的大变化”，并把深层 t1 写入列为更可能的来源。这说过头了：余弦不反映幅度，也不能保证任务相关方向上的小变化无关。两类候选都没有检验，不分先后。 3. 回答层面要分开两个量：固定做 k 操作后只换留存的增量是 +23/+22/+11；扣除不做 k 时的留存主效应后，回答层面的交互 J_S(Y) 是 +22/+14/+8。 4. 补充零 GPU 核对（已有 vdiff 张量）：写进状态的 ‖v1−v0‖ 在两种输出背景下，第 13 层 192/192 完全相同；更深 G 层的比值 c=1/c=0 为 0.99–1.01，只有第 28 层是 0.82–0.94。所以幅度上几乎没有差别；方向没有记录，未检验。

0. 先说不利的部分

  1. 主预测 P1 不成立。 我预注册的是：DS0 在至少 2/3 个缺口方向上为 beyond_random_substantial，且 ρ∈[0.5, 1.2]。实测 0/3：N4146 为 not_supported（DS0 +0.25，比 0.25 的门槛差 0.001，ρ 0.11）；N1210、R0 为 beyond_random_partial（ρ 0.33、0.34）。保留原生输出、只把留存 v 换成 v1，只能带回联合恢复效应的约一到三成。
  2. 单独恢复输出支路也不够。 DO0 为 +0.04～+0.25，只有 R0 刚过线，且只占 DF 的 3%～14%。
  3. 大部分增强只在两者同时恢复时出现。 恢复输出支路后，同一个留存操作的增量 DS1 为 +1.45～+2.12，约是原生输出下 DS0 的 2.5～8.6 倍。按冻结读法，N4146 读作“只改留存不够，需输出支路配合”。N1210、R0 虽然读作“留存用途部分起作用”，但同样是 DS1 远大于 DS0。
  4. 预检 r01 是一次合同执行失败（我写坏了随机臂闸门，见 DEVIATIONS D1），用掉了唯一一次修复重试。它不产生证据。
  5. 面板是已见开发面板，只有 R 族、一个模型、同六场景。

1. 工程

  • 正式运行 48/48 通过验证，一次通过。
  • 对角四格 B000/B001/B110/B111 与 LVK L00/L01/L10/L11 在 t1 bf16、C t2 全词表、M、自然 token 上逐位一致；完整缓存与参考实现（原生 t1 / LVK LHook）逐位一致。

4. 描述（不作判据）

  • t2 q/k 余弦（C 路线，同一输入 token）：只改输出支路（000 对 100）时，q 中位 0.999、k 0.985～0.99；只改留存（000 对 010）时为 1.00。t2 当步 q/k 的差异很小，却伴随很大的交互。 推测档：更可能的来源是 c 改变了更深 G 层在 t1 的输入，从而改变那些层写入的 k、v（包括 c=0 时深层的 v1 与 c=1 时不同）。本轮没有检验这一点。
  • 主效应（不做 k，只改留存，M）：c=0 时 −0.02～+0.09，c=1 时 +0.39～+0.63；随机族 −0.17～+0.06。
  • C1343（诊断方向）：DS0 +3.29、ρ 1.13，标为 beyond_random_substantial；原生 e(0,0) 为 −0.53，换留存 v1 后 k 效应变为正。该方向的答案原本就全对（Y 48/48），不进入多数方向计数。

5. 能说什么、不能说什么

能说的（限 R 族、LVK 新面板、本随机族）：

  • 保留原生 t1 输出及全部非 S 缓存，只把 G 层 t1 写入的留存 v 换成局部 v1，k 写入对 t2 目标选择的作用有增强，且三方向都超过逐头随机方向族；但幅度只是联合恢复的约 0.1～0.34。
  • 恢复输出支路后，同一留存操作的增量大得多（DS1 +1.45～+2.12），并且直接改变完整回答（+11～+23）。也就是说，LVK 观察到的 v 依赖主要不是由“原生输出下的留存 v”单独提供，而是留存用途与输出支路恢复的结合。
  • “原生背景下 k 弱”不能只归到留存写入里 v 的内容。按 v2 §4 预先写好的反面可能：原生 t1 输出形成的后续计算限制了留存差的作用。

不能说的：

  • 不能说“需要两者共同”已经得到证明。单独条件弱，不等于其他组合不能起作用；本轮只测了这几个格。
  • 不能把交互归到 t2 的 q。当步 q/k 余弦接近 1，只能说“不像是 t2 当步 q 的大变化”；深层 t1 写入的变化是推测，没有测。
  • 不能把 C 路线的条件竞争写成原生行为修复：c=0 各格仍在 t1 停止。
  • 不能把“超过随机族”推广为“排除一般扰动”；结论只限逐头、按头匹配幅度的随机方向。
  • ρ、DS1/DS0 都不是机制份额。
