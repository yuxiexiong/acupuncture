3. 工程闸门

  1. 段落：无跨段 token，fact 连续，晚段非空；提示 token 哈希记录。
  2. 校准：每情景一次，写入记录与文件后才形成。
  3. 重放：N:TT logits 逐位等于 T_native；每个 N 格第13层入口 = x_T。
  4. 选头重算：v 与 out_proj 重算相对误差 ≤0.02；名单在子集评分前写入不可改文件并记入收据哈希。CPU 预演已在旧数据上逐一复现 B2 冻结的 12 份 H 名单。
  5. 布局：第13层每个子集格的每个值头 v 逐位等于 N:CT（选中）或 N:CC（未选中）。
  6. 命中：每格 14 个 G 层 recurrent 内核各 1 次、chunk 0 次；N 格入口钩子 1 次。
  7. 预检：全集子集 = N:CT、空集子集 = N:CC（逐位）。
  8. 冻结一致。

4. 判据（方案 §5，冻结）

Z = 去词表均值 logit（停止 248046 主；C_native 非停止赢家 a 次）。F = Z_CT − Z_CC；H = Z_CH − Z_CC；U_j；E = H − median_j U_j。情景先平均两事实。情景通过：F 均值 ≥1 且两事实 F>0；H 均值 ≥0.5·F 均值且两事实 H>0；E 均值 ≥0.2 且两事实 E>0。≥5/6 通过 → 支持；F 足够情景 <5 → 无法充分检验；保留率 ≥5/6 但 E 不足 → 子集有效但无排名优势；否则 → 规则未兑现。固定名单臂同式（H→FIX），次要。答案侧次要。比值只附表。
