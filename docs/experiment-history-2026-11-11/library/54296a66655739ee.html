# 决定 原因
D1 运行器、读数工具从冻结的 WIN-01 复制改造；窗口、替换、bootstrap 的纯函数直接 import WIN-01 的 win_core.py（列入冻结清单） 与 WIN-01 同一实现，便于跨卡比较
D2 编号任务的 L2/L3/L5 条件按 NCC 的原生条件格式构造；R0 取 NCC 链 conditions() 中的 R0_L00_D-1（XCHAN 固定向量） 两任务用同一针定义；R0 不重新抽样
D3 编号任务这四个针没有已有记录可桥接，只桥接 C 已有记录中没有这些条件
D4 关系 M 的正向分母为"T 答错且 R_all 答错"，反向分母为"R_all 答对"（无论 T 对错） 评审要求两面各自定义分母，避免筛选分母掩盖副作用
D5 一读说明写入 WIN-01 V4 的截断规则；二读抽样种子改为 20261105 避免与 WIN-01 抽样重复；减少截断类口径不一
D6 运行器中只对 L0/N4146 生效的 NCC 桥接分支保留不删（本卡不会执行） 尽量少改冻结来源
D7 冻结清单去掉从 WIN-01 复制来的 prep/PREP.zh-CN.md（本目录没有）；CPU 收据重写为 cpu-r02 冒烟（smoke-r01）之后、冻结之前的改动，只涉及冻结清单，不涉及运行逻辑
