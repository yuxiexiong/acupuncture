# B3-P1（主效应对齐的建立：38 步逐步账目 + G 层头块拆分）合同 r01

日期：2026-11-01。设计：[计划 v1](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-b3p1-early-alignment-plan-v1-2026-11-01.zh-CN.md) + [v2 修订](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-b3p1-early-alignment-plan-v2-2026-11-01.zh-CN.md)。数据：B3 正式运行（f2ad7d8），并用 B3-P0 结果（9c83b9a）做一致性核对。授权：用户 2026-11-01「同意，直接写合同代码，更新方案，测试开跑」。**已见数据上的探索分析。**

## 1. 操作（0 模型调用、0 模块非线性重算、0 GPU）

144 个单元（12 输入 × 4 方向 × 3 切分 FIX/U1/U2）。每单元 38 步实际残差增量（BF16 加法后的差，FP64 计算），α_s = δ₁₀ − δ₀₀，β_s = δ₀₁ − δ₀₀。

- 逐步三项：`ΔC_s = 2⟨α_s,β_s⟩ + 2⟨a_before,β_s⟩ + 2⟨α_s,b_before⟩`；M_ij = 2⟨α_i,β_j⟩。子表为 13–18 层（12 步，固定轴取第18层 00 输出），主表为 38 步（固定轴取终点 00 输出）；原空间与固定投影空间各算一份。
- 读数：‖a‖、‖b‖、cos(a,b)、‖α‖、‖β‖、cos(α,β)、ΔC 及三个分项；G = Σmax(ΔC,0)、负增量总额、净值、抵消比例；S_MLP；同一步绝对占比 D_abs/(D_abs+O_abs)；有符号的同一步和与跨步和。
- 头块拆分：14 个 G 层 mixer 步骤，α^A = W_o[:,A 头块]·Δgno（A 头块），α^B 同理，余项 = α − α^A − α^B；ΔC 精确拆成本组项、跨组项和余项。
- 共同收缩复核：终点 a、b 沿 ĉ（终点 00）的份额与垂直余弦，从向量直接计算。

## 2. 资产与成本

B3 张量与记录按 receipt 逐个核对哈希（经冻结的 B3-P0 加载器）；只读取 14 个 G 层的 out_proj 权重。CPU ≤1 核小时，输出 ≤50 MiB。

## 3. 工程闸门（任一不过 → 停止，记合同执行失败）

B3 哈希一致；每格每层 BF16 逐位闭合；四格入口逐位相同；逐步求和与 M 求和等于窗口终点 C（相对误差 ≤1e-9），两个投影空间都要满足；主表终点 C 与 B3-P0 的 aligned 一致（≤1e-9）；**第13层不属于本组的头，其 gated_norm_out 与 00 格逐位相同**；W_o·gno 与实际 mixer 增量的相对误差 ≤0.05（readiness 在 C_native 上最大 0.024；与记录的 out_proj 相比最大 0.0027）；头块三项之和等于 ΔC（≤1e-9）。

## 4. 判读规则（`p1_core.RULE`）

- 单输入标签：S_MLP ≥0.75 为 MLP 步骤主导、≤0.25 为 mixer 步骤主导，其余为分布式；同一步绝对占比 ≥0.75 为同一步集中、≤0.25 为跨步集中，其余为混合；头块本组份额 ≥0.75 为本组主导、≤0.25 为跨组主导，其余为混合。分母 ≤ τ_E（1e-9×‖c_end‖²）时记为不可判。
- 跨方向标签：某方向内 ≥5/6 情景在 f0 与 f1 上得到同一标签，该方向才算成立；≥3/4 方向一致才给跨方向标签，否则为“条件依赖”。原空间与投影空间不一致时，记为“投影敏感”（头块标签只在原空间判定）。
- 措辞限制：“MLP 步骤主导”不推出“MLP 非线性产生对齐”；“mixer 主导”不推出“V 存储里已有同一方向”；头块的“跨组主导”只说明 A 的历史变化经由 B 头的读出表达出来，不说明经由哪个具体运算。

## 5. 预注册预测（推测档）
