## 2. 形成条件（每个输入 9 个）

| 条件 | 针 | B | G 内 V |

供体带在第一轮（C、T、H 同步推进）中记录，克隆后固定；第二轮推进其余六个条件。未被钉住的量（k、β、α、q、z、卷积、递推、全注意力、下游残差）都按接收者照常响应。

## 3. 评分（每个输入 14 次，首步，无形成期钩子）

- C、T_native（T 自身完整缓存）；Y_X = C 浅层 + X 深层，X ∈ {T, H, U, W, TC, CT, TR0, TR1}。
- 状态交叉 J(a←S_b)：以 Y_a 为接收者，评分前只把 G 的 14 个 `recurrent_states` 换成 b 在 τ 的值。四个：J(T←S_U)、J(U←S_T)、J(W←S_H)、J(H←S_W)。
- 评分时只装只读记录器：G 层内核驱动量与旧状态项/当前写入项、全注意力层 q/k/v 投影与输出、第 13–31 层出入口残差、最终 norm 的输入 h 与输出。另记录真实最终分母 r = sqrt(mean(h²)+eps)，以及冻结 token 集合上的 FP64 重算值 η。

## 5. 读数

每个评分：D = max(z[E]) − max(z[非E])；EOS；冻结 token 差（各停止 token − 各冻结非停止 token，以及 248046−248044）；熵 H；两个赢家身份；r；η。

逐事实先算，再取两事实均值作情景读数，两条原值同时保留：

| 量 | 定义 |
|---|---|
| Δ_B | Y_T − Y_H |
| E_V0 / E_V1 | Y_T − Y_U / Y_W − Y_H |
| 固定 V 的 B 残余 | Y_T − Y_W，Y_U − Y_H |
| 状态交叉 (T,U) | δ = Y_T − Y_U；Q_a = Y_T − J(T←S_U)；Q_b = J(U←S_T) − Y_U；剩余差 J(T←S_U) − Y_U、Y_T − J(U←S_T) |
| 状态交叉 (W,H) | δ = Y_W − Y_H；Q_a = Y_W − J(W←S_H)；Q_b = J(H←S_W) − Y_H；剩余差同理 |
| Δ_full | Y_T − C |
| E_VC0 / E_VC1 | Y_T − Y_TC / Y_CT − C |
| E_null,k | Y_T − Y_TRk |
| B×V 交互 | Y_T − Y_U − Y_W + Y_H（只作汇总） |

**尺度分解**（方案 r3 §5.1）：z^fix = z·r_X/r_C（C 为同输入同事实）。对上表每个配对效果报告 E_total、E_fix、E_scale = E_total − E_fix（D、冻结 token 差、熵）。这是共同 C 分母下的输出端反事实，不是自然份额；熵的固定尺度值含 BF16 舍入。配对效果的数值界为 2(η_a + η_b)，效果绝对值不超过界时不贴方向词。

**竞争结构**：中心化单位化 logits 的距离 ‖u_a − u_b‖；对 E_V0、E_V1、E_VC0、E_VC1 等效果，若某个冻结 token 差的变化与 D 的变化方向相反、且幅度 ≥ 0.5|D 效果|，记为"与 D 矛盾"。

## 6. 描述（只作描述，不承担机制通过或不通过）

比例档：< 0 反向；[0, 0.3] 弱；(0.3, 0.7) 部分；[0.7, 1.3] 近似；> 1.3 超调。

- **B 传递**（Δ_B > 0 时）：r0 = E_V0/Δ_B，r1 = E_V1/Δ_B。描述词按顺序判定：任一反向记"反向"；任一超调记"超调"；两者近似且两残余 ≤ 0.3Δ_B 记"近似传递"；两者都弱记"弱"；一弱一非弱记"背景依赖"；其余记"部分"。
- **状态交叉**：仅在 |δ| ≥ 0.3|Δ_B| 时按同一规则描述 Q_a/δ、Q_b/δ；否则只报绝对 Q，标"上游 V 效应弱、比例不稳定"。
- **T↔C**（Δ_full > 0 时）：E_VC0/Δ_full、E_VC1/Δ_full 用同一规则描述。并列报告 E_null,0/Δ_full、E_null,1/Δ_full，以及"E_VC0 是否大于两个随机抽样"。

**主张分级（冻结）**：
- (a) **替换效应**：任何结果都可报告。
- (b) **"V_C 替换的削弱大于同幅随机位移"**：只作逐情景描述，不作统计检验，不估计随机位移的分布，两个抽样的极值不当门槛。若 E_null 与 E_VC0 同级，只保留 (a)。
- 任何结果都不称"自然中介""唯一路径""V 解释了全部原生机制"，也不称"完整回答已恢复"。

方案 §6 的判读表全部适用：V 双向有效但递推交叉弱、一向有效、两向都弱、反向或超调、局部投影大但 J 弱、D 传递但冻结 token 矛盾、情景或事实不一致。T↔C 与 T↔H 互补，不按比例划分机制份额。

## 7. 规模与停止

- 预检：VAR03-f0，1 个 worker；9 前缀 / 14 评分，加关闭记录器的 C/T/H 3/4、自身 V 2/2、自身 S 0/2，合计 **14 / 22**。
- 正式：12 × (9 / 14) = **108 / 168**；2 个 worker（每卡 1 个）。存储上限 16 GiB（每个 worker 8 GiB），代码内断言。
- 停止：预检任一闸门不过不进正式；正式任一输入闸门不过即整轮停止，保留已完成记录。固定矩阵完成即停，不因结果加层、加针、加剂量。

## 8. 失败类型

闸门失败为合同执行失败，信息量为零。Δ ≤ 0 或比例不稳定作为结果边界报告。V 弱或反向是科学结果，按方案 §6 撤回加强解释，不调参救。
