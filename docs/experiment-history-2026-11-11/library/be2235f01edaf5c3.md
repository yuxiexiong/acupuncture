## 3. 选定的核心候选（改写后）

> **K1\*：内部稀疏注入造成的回答损伤由两个可分离的分量构成。形式分量（首步停止）只在注入覆盖记录句之后的位置时出现，由递推状态承载，恢复递推即消除，且消除它不恢复内容。内容分量来自注入覆盖模板＋记录句段，其承载状态不固定：L0 型针偏 KV（K2），非 L0 早层针与事实任务的记录句后注入偏递推（反例 b）。决定内容分量承载的是什么，是当前最大的未知。**

对照四条课题判据（真问题、可行性、痛点、延展性）的诚实状态：

| 判据 | 状态 | 说明 |
|---|---|---|
| 真问题 | 部分 | 重构的是"损伤是什么"：停止不是损伤本身，只是形式分量。已有神经元级工作以崩溃/停止为读数，会漏内容分量。 |
| 可行性 | 是 | 第一步是 §4 的比较，全部复用 WIN 系列代码与桥接记录。 |
| 痛点 | **推测** | 谁在痛：用停止/EOS 当读数的干预研究；混合模型缓存服务（SDM 稿的受众）。两者都没有实证。 |
| 延展性 | 是 | 内容分量的承载 → 跨层 → 跨模型；形式分量的机制（K3）→ 跨层。 |

**最强的替代解释（必须在横向比较中处理，不能预先排除）**：

1. **剂量/位置数**：W_pre 与 W_post 的位置数逐题不同，"段"可能只是累计剂量的代理。
2. **天花板**：W_pre 损伤轻的格，救回余量小，恢复偏好不可判。
3. **可受影响下游范围**：注入层决定哪些 KV 层受损（L3/L5 注入时第 3 层 KV 干净），"偏递推"可能是结构后果。
4. **任务协议差异**：事实与编号的生成长度（128 对 32）、校准文本与尺度、形成实现（单次前向对分段）、判读（盲读对精确）全部不同；"事实偏浅层递推"可能是协议产物。
5. **一般作答损伤**：恢复偏好差可能只反映哪种恢复让模型"能答"，与内容无关。

### 4.2 选定的比较：内容分量由哪类状态承载——同针、同窗口、两任务，把递推拆成浅/深、把 KV 拆成浅/深

**它为什么最能改变整体判断**：它同时判三件事——(i) 旧链把承载定位在深层 G 的递推，这是否只是编号任务的性质；(ii) K1\* 的"内容分量承载不固定"是真的还是协议产物；(iii) 替代解释 3（下游范围）能否解释 K2 在非 L0 针上的失败。三种结局都改变 Proposal 的核心句（§3 表）。它不选"最容易恢复、最容易转移"的格：主格是事实 W_post 深层 S 16/48，一个失败格。

**对象**：L0/N4146（L0 型原生）、R0（L0 型随机）、L3/C7666（非 L0 型原生）；窗口 W_post 与 W_pre；两任务。恢复臂：浅层递推（线性层 < 13）、深层递推（G 层）、浅层 KV（3/7/11）、深层 KV（15–31），及必要的两两组合；每格保留 T、C。**另加一个位置数配对的窗口**（在 W_pre 内截到与 W_post 相同位置数），处理替代解释 1。

**判别替代解释 3 的子格**：对 L0 针，只恢复第 7 层及更深的 KV、让第 3 层 KV 保持受损——若它复现 L3 针的"偏递推"，下游范围解释成立。

**旧链给出的预先预测（现在登记，推导档）**：形式分量由深层 G 递推承载 → 两任务 W_post 下深层 S 都消除停止（已见：事实 ✓、编号 ✓）；旧链对内容分量**没有预测**——这正是它约束不了 WIN 差异的地方，要如实写。阶段二旧结论"L0 事实丢失 KV＋线性层各半、来自提示前部"给的预期是：事实 W_post 内容分量需要浅层递推或浅层 KV。

**读法约束**：结果读作"承载状态不同"，**不读作"机制不同"**；机制同一性要到读取级操作才能判，不在这一轮。

## 5. 第三优先：下一张卡的两句话（草稿，不是卡）

具体操作、样本、判据和预算在用户确认 §4.2 后按[自查规范](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/experiment-design-self-check.zh-CN.md)另立；下面只写卡必须回答的两句：

- **预期结果全部出现时**（对齐协议后：事实 W_post 深层 S 去停止但内容不回、浅层递推或浅层 KV 之一补上内容；编号同针同窗口深层 S 足够；位置数配对后段效应保持），支持的核心句是：**"首步停止与内容错误是由不同状态承载的两个分量；旧链定位的深层递推只承载形式分量，内容分量的承载随任务变化。"**
- **预期不出现时**，按 §3 表撤回对应半句。下一步不会是扩大扫描，因为每种不出现都指向一个具体的替换问题：协议产物 → 转 K7 的非 L0 随机方向；需要组合 → 记为条件充分性并停止内容分量承载的定位；段效应消失 → 改写为剂量表述并撤回 K2。
