## 1. 决定与课题定位

**回到阶段 B，固定研究对象，改变研究方法。** 现在有一个跨新输入及四种已测方向都能搬运停止侧 V 效应的45头集合。接下来研究这份历史变化怎样经过实际更新、读取与后续变换成为输出效应，而不是继续找更多重要头。

课题仍是：少数通道的激活干预如何改变历史状态的形成、处理和读取，最终造成显著的回答变化。停止侧只是已有证据最强的观察窗口，不能替代整个回答问题。

Related Work 的已有解释包括残差写入幅度与几何、归一化、状态更新与查询读取。我们的空缺是把这些工具用于**同一套实验条件的实际因果连接及预测**，不是发明缓存公式。详见 [已核查文献的边界](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/literature/merged-prior-art-artemisinin-2026-11-01.zh-CN.md) §4–5、[基础审计](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-mechanism-known-basics-audit-2026-10-31.zh-CN.md)及[阶段路线图](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-mechanism-stage-roadmap-2026-11-01.zh-CN.md)。本文没有重新查新，不能据此声称领域首次。

目前 A 已有材料关系，B 未完成计算解释，C1-P/C2 已完成有限预测检验；这不是整个 C 或整个课题完成。C2 的成功让 B 有了更可靠的固定对象，而不使任何机制自动成立。

## 2. 三条事实、三个边界

1. 固定45头在 N4146、N1210、R0、R1 停止侧各通过6/6情景。随机入口方向也成功，削弱“只属于原针”的解释，不证明一般饱和或共同机制。
2. N1210、R0、R1 上，固定子集效应大于全 V 效应。严格说是：**在固定集合已使用 T 历史的条件下，再把其余头的 V 历史从 C 换成 T，终点效应减小。** 没有“仅其余头”角点，不能区分独立反向作用与条件交互，更不能把每个其余头叫抑制头。
3. R0 原生运行仅1/12首步停止，全 V 混合格0/12，固定子集混合格6/12。强子集效应不能直接当成原生停止的原因。答案侧固定名单未通过、自适应名单通过，也尚不能证明两套独立电路。

四轮直接投影筛选未给出合格计算候选，是方法和候选的限制，不是“所有局部计算无效”。本轮不以再次找到最大投影层作为交付。

## 4. 独立包 B3-R：原结果的记录性重放

### 问题与交付

问题：能否在保持 C2 输出逐位不变的条件下，补齐解释固定子集效应及条件性减弱所需的内部记录？

这包只解决数据缺口，不检验新科学假设，不再次统计 C2 阳性。交付独立记录目录、字段清单、源哈希、全词表重放核验、实际成本及失败记录。

### 冻结范围及操作

- 沿用 C2 模型、revision、BF16、eager/内核路线、硬件及软件身份、token IDs、晚段注入窗口、L0 剂量 −1、N1210/R0/R1 方向向量、固定45头名单。
- 六个已见 P 情景，各 f0/f1，共12输入；不称12个独立样本，不换题、不选最强方向、不重新选头。
- 复用已存 C1-P/C2 校准值及其哈希，不重新寻优，也不按输出调整剂量。本设计不调用 `engine.calibrate`；若实现必须调用，须先修改成本清单，而非作为隐藏开销。
- 每输入形成 C 一次、每方向 T 一次。评分 T_native 取得该方向 `x_T`；N 背景为 C 浅层、T 深层 S/KV，decoder-13 入口为同一 `x_T`。Q 历史为 C，V 历史按下表换；当前层输入及所有下游计算正常响应。

| 目标格 | 固定45头 V 历史 | 其余头 V 历史 | 用途 |
|---|---|---|---|
| C0 = N:CC | C | C | 同背景基线，绝非 C_native |
| X = N:CFIX | T | C | 已验证的固定集合效应 |
| F = N:CT | T | T | 在 X 上加入其余 T 历史后的条件作用 |

逐头替换沿用 C2 的卷积 V 槽位定义，不替换当前 v、整段 residual 或权重。每方向另评分 N:TT 与 T_native 对照；每输入另评分 C_native 作公共参考重放。所有评分独立复制缓存，禁止上一评分污染下一评分。

### 必存字段

目标三格保存评分位置第13–31层的 residual 输入/输出、mixer（G或全注意力）分支输出、MLP分支输出、最终归一化前 h、归一化分母和全词表 logits。14个 G 层保存 q/k/v、alpha/beta/z、core、门控归一化输出、out_proj 输出；若某字段不能直接观测，清单中写明重算方法及验收来源，不能默认为已有。

保存每输入的 C 和每方向 T 形成后、评分前缓存快照及 x_T，用于未来精确重放；不保存每个提示位置的全套大张量。保留原 dtype、shape、层号、位置与来源哈希。记录器只复制，不改计算路径；如需重算，重算结果与观测值分栏保存。

预检前通过 shape 和 dtype 估算所有快照与记录总大小；总磁盘上限16 GiB（含临时文件），预计超限即停止准备并报告。不能再次为了省存储悄悄丢弃已承诺字段。权重、环境和大张量不入 Git；清单、哈希、日志与读数入 Git。

### 全成本预算：108不是总评分数

| 部分 | 前缀形成 | 单步评分 | 算式 |
|---|---:|---:|---|
| 正式12输入、3方向 | 48 | 192 | 每输入4次形成；C_native 1次＋每方向 T_native/N:TT/三目标格共5次评分 |
| 预检 P01-f0/f1、3方向 | 8 | 32 | 同上；与正式重复也计入成本 |
| 预检记录器关闭对照 | 0 | 3 | P01-f0/R0 的三个目标格，用已形成缓存重新评分 |
| 总上限 | **56** | **227** | 其中正式目标格记录为108次，不等于总前向预算 |

另计**14次公共前缀 prefill**（正式12＋预检2）：C2 的 `run_item` 在形成 C/T 之前先运行 `prefix[:b+1]`，不能因旧回执没有把它列入 formations 就漏算。56次“形成”也是56条晚段处理序列，不是56次底层 forward。若输入 i 的晚段长度为 `w_i=n_i-b_i-2`，底层前向总数为 `14 + 4×Σ正式 w_i + 4×Σ预检 w_i + 227`；实施前从冻结 token 清单展开整数并写入合同，不可把56＋227宣传成总模型调用。

新增校准、额外校准模板、自由生成均为0；模型加载计入实际时间。GPU累计时间上限0.5 GPU小时，最多2 worker，按各 worker 占用时间求和；这是停止预算，不是已测耗时或费用报价。正式前用预检测量时间、峰值内存和字节数，预计超限则停，不自动扩大。失败尝试也计入总上限，不自动重试。现有 C2 正式每 worker 约95秒只能作参考，不能保证加记录后仍然如此。

### 工程闸门与停止

1. 身份、tokens、校准、方向、名单和缓存来源完整核验；L0 写入量沿用 C2 ≤1% 闸门。
2. 每个保留格的**全词表 logits 哈希**与对应 C2 记录一致；N:TT=T_native；C_native 与已有参考一致。任何不一致先判重放失败，不解释科学变化、不临时放宽容差。
3. 三个记录器开/关对照逐位一致；入口 hook、14个 G 单步内核计数、逐头布局沿用旧验收；检查快照复制与评分后的缓存隔离。
4. residual 加法闭合及分支输出捕获位置通过实际 dtype 的误差检验；容差由数值预演先冻结，不能看到科学分解后改。最终 logits 的逐位闸门与内部 FP64 重算的近似容差分开。
5. 任一失败保留现场、停止；没有通过的记录不进入 B3-A。补录全部通过只记“数据可用”，不增加一个阳性实验。

## 5. 独立包 B3-A：一次有出口的计算解释分析

### 问题与估计对象

只问：固定历史集合带来的效应，在已记录的更新、读取和输出变换中，有没有可写成具体操作预测的解释？哪部分仍必须用新的中介干预才能分辨？

主读数沿用去均值停止词 logit `z`，每输入/方向分别报告：

- `X = z(N:CFIX) − z(N:CC)`：固定集合总操作效应。
- `F = z(N:CT) − z(N:CC)`：全 V 总操作效应。
- `D = z(N:CT) − z(N:CFIX) = F − X`：其余头在固定集合存在时的条件增量。

答案词沿用既有冻结 token，独立报告有符号差；EOS仅作描述。三个读数不是三个独立实验。比值仅在参照绝对值≥1 logit时辅助显示；其余显示原始差，样本不删除。主结论不依赖比例。

### 固定工作表：不再筛最大投影层

1. **实际响应表。** 对 C0→X 与 X→F 两个对比，记录已选45头的局部写入/实际读出、门控归一化前后，以及 mixer/MLP 分支的配对变化。只据原记录做代数与逐模块重算，不新增完整模型前向。G 头并非独立：当前输入、q/k和后续状态可以变化，不能把跨运行差一律叫 V 的本地直接项。
2. **末端尺度与方向表。** 用最终 h 的真实输出函数，把 `z = p/r` 中投影分子 p 与 RMS 分母 r 的变化做对称精确分解：分子项 `(p1−p0)(1/r1+1/r0)/2`，分母项 `(p1+p0)(1/r1−1/r0)/2`；保留 dtype/舍入余项。分别应用于 X 与 D，不把它叫唯一因果分解。目的只是判断后续预测是否必须控制输出尺度，不因归一化公式成立而报告机制发现。
3. **计算候选卡或无候选说明。** 每个拟议解释必须指定：干预哪个运算、使用哪个同背景参照、固定什么/允许什么响应、预测 X 或 D 怎样变化、一般等幅扰动可能怎样重现它、何种结果撤回。不得仅写“27层重要”“MLP变化大”“范数增加”。不规定必须产出候选。

整轮 CPU 预算：0模型调用，累计≤4 CPU核小时，单轮完整分析；数值错误可修正并保留日志，不能换指标/层组重复择优。记录所有方向和六情景；f0/f1是配对条件。数据与终点均已见，因此候选是探索生成，不是留出确认，不用5/6门槛包装显著性。

**候选进入下一份因果合同的门槛是可操作、可失败、有非同义反复的新增预测，而不是直接投影够大。** 可以只解释 X 或 D 的一个环节，但必须说明怎样兼容另外的现象和 R0 原生/混合差别。无法对一般幅度/几何作不同预测时，可以研究条件传播路径，但不能命名为针特异机制。

### 只有三个出口

- 有具体计算预测：提交单独的因果实验设计，冻结实际操作、主要终点、对手、预算和否定标准；不自动上卡。
- 无计算预测，但明确缺少“干预该分支后，下游怎样响应”：结束本轮账目分析，进入下节的假设生成设计；不再做第六套投影筛选。
- 连有界的因果比较都无法保证认识增量：暂停 B 的细拆，整理 A/C 已有的有边界结论。不得为了推进而制造候选。

## 6. 条件后续 B3-P：允许产生假设，不假装已经解释

这是一条方法出口，不是已经冻结的第三包实验。可选做法：在 N:CFIX 运行中，把预先指定的某类下游**分支输出**恢复到同输入、同方向 N:CC 供体值，保留残差主路及其他分支正常响应，观察固定集合的效应是否被削弱；需要时在 N:CT 做对应条件比较。

正式设计必须满足：

- 在新干预结果前冻结有限模块/层组，最多一个粗分组面板；不逐层找最大值后再叫确认。不以全残差/最终 h 换回基线作为主要“发现”，那会结构性地重放基线。
- 供体是同一 N 背景的 N:CC，不是 C_native；不同方向不能共享 x_T 或供体。接收者的后续 q/k、门、MLP 等正常响应，操作的混合反事实身份明确。
- 预先区分“直接阻断了被换 V 的输出”与“阻断了其后的加工”，否则不能把前者宣称为下游中介定位。
- 设同幅一般改动的有限参照或明确降为条件性路径探索；不能把任何输出变化当作机制证据。只匹配 L0 范数不能替代此处的模块级改动匹配。
- 至少有一个不只是重述恢复基线的预测，并给出失败后停止的规则。阳性最多生成待验证的计算候选，不是证明原生路径必要或排除一般饱和。

当前不预列 GPU 数，因为模块数、供体字段及参照尚未冻结；在这些定义完成前，不称 B3-P 可执行。它不受“必须先从直接投影找到候选”的限制，也不获得自动执行许可。

## 7. 与截图建议及上一方案的差别

采纳：补录缺失内部记录；固定45头；不扩大泛化；CPU分析设出口；允许明确标记的假设生成因果实验。

修正：108只计目标格；总预算补进 T_native、N:TT、C_native 与记录器验收；“干净供体”明确为 N:CC；“其余头抵消”改成条件增量 D；不把补录算科学发现；不要求候选必须有大直接投影；不承诺一轮分出唯一机制。

暂不展开：答案侧重选头、更多针/剂量/模板、生成行为扫描、再次强推13层或27层。它们仍是课题未来可能需要的证据，但不是这轮的并行任务。
