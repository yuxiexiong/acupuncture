先说限制和不利的部分

  1. 被替换的范围比"模板＋记录句"窄。 两版在模板部分的 token 相同，C 没有加针，所以位置 0..b 中模板部分的 KV 在两版间逐位相同（工程闸门已核实）。M_other 与 M_same 实际只差记录句从事实词开始到 b 这一段的 KV。结论里的"前段 KV"都指这一段。
  2. 效应接近饱和，区分力有限。 三针都在 42–43/44 跟随供体，条件之间几乎没有可比较的差异空间。M_other 与 B_pre 的配对差只有 0.02–0.05，但区间上界到 0.14，按判据记"不可判"，不是"无差异"。
  3. 冻结后改过盲读工具一次（DEVIATIONS V1）：同一文本同时出现在取 WIN-01 标签和取 WIN-02 标签的桥接格里，而两卡标签不同。按 D3 原则改为新读，只影响 2 个回答的标签来源。
  4. 本卡是连接"状态恢复"与"答案选择"的桥接，不检验原有 v/k—写入—递推—读取链，也不说明自然受针运行中信息怎样丢失。
  5. 每针 44 个接收者、22 个情景，题目都接触过；结论只限这三根针和这批题。

4. 读法（合同 §7）

能说（这三根针、这 44 个接收者）： - 在固定的恢复背景里（全前缀受针，递推从接收者本版恢复），只把记录句中从事实词起到 b 的 KV 换成另一版本的干净 KV，完整回答几乎全部跟随供体事实（42–43/44）。这段 KV 在该背景中具有与事实相关的答案影响。 - 三根针（原生 L3、原生 N4146、随机 R0）对同一操作的响应未检出差异。WIN-02 中三者的窗口图样、错误形态不同（例如 R0 与 N4146 的停止形态不同），但在这项操作上表现一致。 - 在干净背景里只换同一段 KV，回答也跟随供体（41/44）。所以 WIN-01 B 块"全部 KV 移植带走答案"中的答案影响，在只换这一段时基本保留。 - 在这套操作下，递推来自接收者版本、记录句 KV 来自供体版本、两者"不一致"时，回答几乎都跟随 KV 一方。

不能说： - 答案只由这段 KV 携带，或补回的 KV 只提供内容、不恢复作答条件。两个 M 臂都恢复了递推、都有干净的模板 KV，作答条件的恢复与事实定向可以同时存在。 - 递推状态不携带事实信息。只能说在这种冲突配置下 KV 一方占优；WIN-01 中递推移植不转移答案，也只是那套操作下的结果。 - M 与 B 块依赖同一读取过程（只是相容；本卡没测读取）。 - 自然受针运行中，答案为什么错（本卡是移植，不是原生路径）。

5. 对课题的意义

WIN-01/02 发现：在全前缀受针背景里，恢复递推后再补前段 KV，回答进一步恢复（关系 M）。本卡在同一背景里只改变补入 KV 的事实身份，表明这一步恢复操作具有答案方向上的选择性：补入的不只是"让模型能作答"的东西，其中记录句事实位置的 KV 还定向决定了答哪个事实。这是"状态恢复"与"答案选择"之间的一个连接点。

它还没有接到原有的写入—读取计算上。下一步才是这条连接。
