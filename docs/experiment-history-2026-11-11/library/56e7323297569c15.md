## 1. 结论（不利的先说）

1. **P_S 不成立（0/4）。** 在干预入口下，深层递推状态 S 单独替换就能拿到历史作用 H 的大部分（S0/H 方向均值 0.62–0.74，逐输入 0.53–0.81），但 KV 并不“小到可以忽略”：在 S 已经换成 T 的背景下，再换 KV 还有 K1 = 1.8–2.5 logit，超过 ε（约 1.3–1.5）。所以多数输入落在“其他”（S 为主、KV 依赖 S 背景），而不是“S 集中”。S 集中只出现在零星事实上（N4146 1 例、R0 2 例）。
2. **P_native 不成立（0/4）。** 在完整原生 T 背景里，只把深层 S 恢复成 C，竞争差只回退 R_S = 1.3–2.5（原生总变化 N 的 10–17%），低于门槛 max(0.5, 0.2N) ≈ 2.5–2.9；只恢复 KV 回退 0.4–0.7。
3. **原生背景里，S 与 KV 是冗余或替代关系。** 同时恢复两者回退 R_SK = 2.9–4.2，大于两者单独之和（J_native = −1.0 到 −1.5，即联合恢复超加和）。原生模式判为“冗余或替代”：N4146、R0、C1343 各 5/6 或 6/6 个情景；N1210 为条件依赖（冗余 3、恢复操作都弱 2）。
4. **在原生背景里，深层历史整体只承载原生变化的约两到三成**（R_SK/N = 0.21–0.29）。其余七成以上在原生 T 背景中没有被这三种恢复撤掉；在本轮的恢复操作下它们保持不动，这些成分与浅层/入口、深层卷积历史都保持 T 有关，但“未撤掉的部分”不是已经分配好的独立份额，可能包含保留状态与被恢复状态的交互。**更正**：初稿此处拿 NFC 链上 e1 的 54–63% 来比较，这是错的，因为 e1 同时换了入口和深层历史，不是纯 S+KV。可比的量是 EH 中从干净背景往上加深层历史的作用：干净入口下 H0 = 4.7–5.6（约为原生 N 的 35–41%），干预入口下 H1 = 6.6–7.3（约 47–52%）。从原生 T 往下撤 S+KV 只回退 21–29%。“往上加”与“往下撤”仍然不一致，说明存在条件性的替代或冗余，但差距比初稿写的小。
5. **行为上，单独恢复深层 S 就让首步不再停止**：P_S0 首步停止 N4146 0/12、C1343 0/12、N1210 2/12（P 为 12/12）；单独恢复 KV 不改变行为（P_K0 12/12）。这是因为原生 T 的 D 只略高于 0（约 1），1–2 logit 的回退就足以越过门槛；它说明的是“离门槛很近”，不说明 S 承载了原生效应的大部分。R0 原生本来就几乎不停止（1/12），所有恢复臂都是 0/12。
6. **固定候选 F 上的读数大得多**：R_S(F) = 5.4–6.6，R_SK(F) = 8.2–9.7（D 上分别是 1.3–2.5 和 2.9–4.2）。恢复深层 S 时，干净首词 q0 相对停止词恢复了很多，但另一个非停止词顶上来，吸收了大部分（赢家更替）。所以 D 上的小回退，部分是竞争者换人造成的。

## 4. 出口（计划 §9 / 合同 §5）

- 结果对应出口表中的“S 为主但不集中，且原生不对应”：混合背景里的“历史主要随 S 走”成立（S0/H 约 0.6–0.7），但它**不能直接外推到原生背景**。原生背景里，深层 S 与 KV 互为替代，深层历史整体只占约两到三成；大部分原生变化在本轮的恢复操作下保持不动。
- 由此修正此前的叙述：深层历史的作用大小取决于其他状态是否已被干预。从干净背景往上加时它约占原生变化的 35–52%（视入口而定），从原生干预背景往下撤时只占 21–29%；两类深层状态之间、以及它们与其余保留状态之间，存在方向一致的非加和关系（与冗余或补偿相容，但尚未证明储存的是同一份信息或发生了动态补偿）。
- 下一步（未设计、未授权）：问题不应写成“剩下的七成在哪里”，而应是“哪些保留的状态使得撤掉深层历史后原生变化仍大部分存在，联合恢复能否打破这种保持”。可以在原生背景里做互补的恢复，即恢复浅层与入口、恢复深层卷积，以及它们与深层历史的组合。前提是先写出能区分“分布式冗余”和“某一类别承载”的可失败预测，而不是机械扫描。
