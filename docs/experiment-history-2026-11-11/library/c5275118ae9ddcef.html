CFM-VQ-WRITE-L13-v1 决策日志

  • D1 每头精度闸门（冻结前，方案 r2 §7.4）：r1 要求每头范数误差 ≤5%。用 CONV 已存第13层四角驱动预演（只算 I13 与 BF16 落地，不涉及任何 B1 输出）：整体误差 0.3%–2.3%，但每个输入/背景都有 1–5 个目标范数 1e−6–3e−5 的头超过 5%（最高 0.86），低于该头 core 的 BF16 分辨率，按 r1 几乎所有输入都会判工程不可判（同 CONV D8：闸门描述的是期望精度，不是测量能分辨的精度）。改为：整体 ≤5%；每头实际误差 ≤1.05×该头 BF16 底噪（抓实现错误）；目标 <20×底噪的头能量 ≤2%（可分辨性）。20 倍线下可分辨头每头误差 ≤0.050，不可分辨能量最多 1.01%；10 倍线下可分辨头仍达 0.10，未采用。
  • D2 GPU 补丁核对：除整体/每头误差外，GPU 上 LOCAL Patch 实际写回的 core 哈希必须等于 CPU 用同一 FP64→BF16 算术核验过的 core，确保核验对象就是模型实际收到的值。
  • D3 模板前向：沿用 LOCAL D1 / CONV D4，每 worker 一次 1-token 前向取缓存对象，内容张量全部覆盖并逐字段核对。
  • D4 记录器关闭的 N 参考：同 LOCAL D4，只装入口钩子直接前向比较 logits 哈希。
  • D5 预演观察（冻结前登记）：N 背景 ‖I13‖ 为 0.0030–0.0053，是 M_T（0.0115–0.0159）的约 25%–40%；乘积式恒等残差 ~1e−18，读取项交互为 0。只是局部量，不是终点结果。
