# QKD-01（共同 k 偏移改变了哪种计算）合同 r01

日期：2026-11-03。设计：[计划 v1](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-k-computation-diagnostic-plan-v1-2026-11-03.zh-CN.md)（评审撰写，21981fe7）+ [自查](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-qkd-self-check-v1-2026-11-03.zh-CN.md)。授权：用户 2026-11-03「同意，直接写合同代码，测试后上卡跑」。前三方向的六臂完整输出已见（QKF）；C1343 的四个单 k 臂与全部计算观测运行前无输出。本轮是计算诊断，不含任何对中间项的模型干预。

## 0. 相对计划的修订与补充（决策 D2–D5）

1. **核对过的内核事实**：解码步走 transformers 的 torch 实现 `torch_recurrent_gated_delta_rule`（服务器无 fla、kernels、causal_conv1d；Hub 不可达）。状态按 [k 维, v 维] 存；α = exp(g)，先衰减再更新；q、k 在核内 L2 归一化，q 再除以 √128；q/k 进核前由 16 头重复到 32 个值头。CPU 闸门断言非 torch 内核不可用；授权时再查一次。
2. **观测与完整生成分开**：观测用独立逐步循环（N 路线 ≤3 次前向、C 路线 2 次前向）；C1343 用冻结的 SVQ generate 生成完整回答（不挂观察器），再对同一初态跑观测，N 路线须与生成的前几个 token 和首步哈希一致。这比计划多 864 次解码前向（C1343 前三步重复），在设备时间上限内。
3. **头粒度**：D/E/W、J/H 都按 32 个值头计算；汇总先逐层逐头，再取中位数。
4. **捕获**：模块级函数的只读包装 + 每个 linear_attn 的只读前置 hook（只记录层号），只在观测前向期间安装；每臂前断言包装已卸、hook 计数回到基线；预检有/无观察器的 N 路线逐位相同。

## 1. 臂与路线

48 输入 × 方向 N4146、N1210、R0、C1343；接收者 T(i,d)，G 卷积 V 取 C(i)，S/KV/浅层取 T(i,d)；只编辑 k 通道 [2048, 4096) 的槽 [1, 4)。

| 臂 | q/k 基底 | k 编辑 |
|---|---|---|
| V | T | 无 |
| F | C | 无 |
| Rk | T | − μ_k |
| Ak | C | + μ_k |
| Rrk | T | − r_post,k |
| Ark | C | + r_post,k |

μ、r_pre 来自 QCO；前三方向 r_post 来自 QKF；C1343 的 r_post 用 QKF 公式与同一冻结 r_pre 新建（qkd_rpost.py），逐头 6% 模拟检查通过才授权。
路线：t1 = 读末提示 token；N = 自然贪心继续至多到 t3（遇停止 token 即止）；C = t1 共享，t2、t3 强制喂入该输入 F 答案的前两个 token（F 没有两个非停止 token 则 C 记缺失）。

## 2. 分解与读数（冻结，qkd_run.py / qkd_core.py）

- 每个观测步、每个 G 层、每个值头：D = α S_prevᵀq，E = −αβ(qᵀk) S_prevᵀk，W = β(qᵀk) v（FP64，q/k 按核内方式归一化）；重建误差 e = ‖D+E+W − o‖/(‖D‖+‖E‖+‖W‖)（o 为核的 BF16 输出）。接线验收：用捕获的副本重跑原核，输出与捕获逐位相同。
- 配对（Rk 对 V、Ak 对 F、Rrk 对 V、Ark 对 F），两端各作一次接收者，只在输入 token 相同的步（C 路线 t1–t3；N 路线前缀相同的 t2/t3）：J = β(a₁ − a₀)(v − α p̄)，H = −αβ ā (p₁ − p₀)（a = qᵀk，p = S_prevᵀk，用接收者的 q、S、v、α、β），Δo_k = J + H；投影份额 s_J、s_H；实际差的 D/E/W 份额；残差 Δo_actual − Δo_k。‖Δo_actual‖ ≤ 5 × 两端重建绝对误差之和 → 该头不可解析。
- 误差闸门：预检 e_max ≤ 0.02；正式阈值 = min(0.02, max(1e−5, 2·e_max^pre))，超过则停止分账解释（保留记录）。
- 描述标签（无显著性含义）：每例（输入 × 配对 × 路线步）取可解析层-头与两端接收者的 s_H、s_J 中位数；场景等权 s_H ≥ 0.75 且 ≥4/6 场景 s_H > s_J → “局部 H 主导”，J 对称，否则“都不”。**主步为 C 路线 t2**（强制前缀下的编号竞争步），t1、t3、N 路线同报。
- 行为：前三方向 Y_full 取 QKF；C1343 用本轮生成。C 路线 t2 的固定竞争者分差 M（目标第二 token − 首列第二 token；目标在首列则减第二列）。按“修复 / 未修复 / 改坏 / 保持”分组报告 ΔM 与 s_H。
- **允许失败的工作预测**：k 修复主要经由旧状态预测 p 的变化（H），而不只是 q·k 系数（J）。出口按计划 §6；后续单项因果替换不在本轮。
