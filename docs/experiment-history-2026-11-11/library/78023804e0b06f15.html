2026-11-08。依据用户要求，面向整条主线整合已有证据，不继续局部细挖。核对基线 76c1c15b9。只读既有目标、合同、报告、更正与运行验收；没有模型运行、新实验设计、新拟合或论文修改。本文件是证据地图，不替代现行核心目标。

1. 已统一的主线原文与层次

课题总主线：稀疏激活干预怎样改变历史形成、写入、旧状态处理及后续读取，最终造成显著的完整回答变化。

下一阶段核心目标：解释针怎样改变一项重要历史信号的写入或利用，并证明这项计算变化确实影响了答案。

论文要围绕该问题建立的候选认识是：针改变了历史来源影响答案的条件与计算依赖。它是待解释对象，不能改写成已经证明了控制权转移、统一信息删除或普遍原生机制。最终质量目标仍为CCF A顶会Strong Accept；实验数量、图的复杂度和模拟分数不代替重要性与解释增量。

允许先建立重要且有边界的机制片段，不要求一次解释所有针、任务和成功失败。β、幅度、C1343、D/E、撤针和供体移植都是工具或局部对象，不成为新主线。“网状”若有价值，应体现可复用的计算依赖关系；仅证明模块会互相影响属于架构常识。

NMT与DWB共享LVK形成资产、操作定义及L11o参考端点，但来源差异不同：NMT研究原生→自身修复的增量；DWB研究自身→供体的写入差异。共同端点能保证技术对照，却不能把NMT的幅度比例赋给DWB供体效应。

WIN的恢复任务、窗口、来源差和读数也不等于SPF的供体选择效应。相同针名不是同一因果对比；不能把事实取值与编号选择自动当同一信息。

3. 已经连上，而非待补的部分

  1. SPF供体效应→DWB指定写入→完整答案：已连上。 DD为同一参照（N4146/N1210为0.896/0.490）；只保留t1供体写入DO为0.882/0.427；反向OD净转移样本值为0，选择冲突配对全部恢复自身答案。一次写入是同一时刻14层联合操作，不是单层事件；不称解释了98%机制。
  2. DWB纯局部写入→同端点读取→完整答案：已连上。 DWR使用同一L11o/L11d端点，直接读取D有正向获得与有自身恢复的撤回；旧开发面的获得量级未完整确认。不能继续引用DWB早期报告的“还没做读取”作为现行缺口。
  3. 上述写读关系→独立材料：已有确认及边界。 DWC96新情境仍属六结构族；N4146获得/撤回/自身恢复0.311/0.473/0.394，达到冻结标准。N1210有正效应，但获得0.213的区间上界0.234低于门槛0.25。它不是“两针均无效”，也不是“两针均完成量级确认”。不扩称新任务或新模型。
  4. 形成背景→不同状态增量效力→幅度的部分作用：SIT/NMT内部已连上。 固定接收背景仍有来源效应；匹配幅度可恢复大部分指定k条件来源差及部分答案。近期三因子核对只识别β‖k̄‖；等幅对照识别同向/抵消；读取核对只给C1343一段稳定投影认识，不能升级统一机制。
  5. WIN恢复关系→补入历史的内容选择性：部分已连上。 KVC在可对齐的事实任务子集，以WIN恢复背景改变记录句事实词起至句末的KV来源，N4146/L3/R0有42–43/44供体跟随。它证明该恢复操作带有内容选择性，但没有测到DWB同一写读路径。KVC报告自身已下调该结果的新颖性，不能包装成新的普遍缓存分工。

这些“已连上”均限所述反事实和端点，不等于原生唯一中介。DWR/DWC使用DWB纯局部端点，不能由此宣称SPF整缓冲操作的全部效应都经过同一用途。

4. 广度与反例究竟支持什么

有边界的共同认识

历史载体的恢复或移植效力不是一个固定属性；在已测条件下，它取决于这份历史如何形成，以及其余状态是否提供了可用的写入/使用条件。恢复答案与定向改变答案也必须分开。

这句话有多组具体约束，并非由“网络有交互”公式推得：

  • SPF N4146同一供体V配干净q/k净转移0.896，保留受针q/k只有0.003、开口率仍0.997；“能说话”与“来源能左右选择”分离。单把受针递推状态放进干净背景引不出供体效应（0），否定“递推来源单独决定”的候选。
  • DWB中N1210的受针供体状态进入干净接收者仍有0.799净转移；N4146为0.094。统一信息删除不足，低转移也不能证明N4146没有信息。
  • WIN N4146只在记录句之后施针时，恢复全递推在事实/编号上为47/48、48/48；全前缀施针则只有10/48、6/48，补模板＋记录句KV后为47/48、48/48。同一个恢复操作的有效性随形成窗口改变。
  • WIN-02的额外KV恢复关系在事实L2/L3及R0两任务四个可检验格成立；其余四格主要受余量限制，不能记作更多阳性。其中一半支持来自同一R0方向。
  • R0全前缀施针两任务都0/48答对，但只0/48、2/48首步停止；N4146则48/48停止。相似恢复关系不要求相同错误形态，也不能把停止当整体损伤的代理。

尚未成为共同计算机制

WIN的“前段KV、后段递推”固定分工未稳定推广：事实L2/L3/L5的前段KV优于递推预测未获支持（不可判，不是相反机制已证实）；编号任务同些条件存在天花板。相同后段窗口下，深层S恢复在事实/编号任务仍有16/48对48/48的差异，且形成实现、校准和生成长度等混杂未消除。编号L3/L5的两窗口行为非加和也不能直接叫状态协同。

这些结果与“来源效力依赖形成和使用关系”的框架相容，但没有用同一可测写读关系解释WIN分叉。因此目前能提炼跨针/任务/窗口的共同约束，不能声称已提炼出跨这些条件的统一计算解释。更宽的现象材料不能给较窄的机制链借用覆盖面。

5. 哪些仅相容，关键缺口是哪一个

连接 现状 为什么不能直接相接
SPF干净/受针背景下来源效力的变化 → DWB/NMT中的具体写读计算变化 关键连接未识别 DWB验证指定有效背景的构造性写入；NMT解释另一种自身修复增量。尚未在同一来源对比与可比局部操作下说明，哪个写读关系变化解释SPF的条件差
NMT幅度/等幅结构作用 → DWB/DWC供体选择效应 共享参考端点，但仅相容 来源差不同，不能挪用恢复比例或投影结果
WIN/KVC的恢复与内容作用 → DWB/NMT同一局部关系 仅相容 缓存、内容、任务、窗口及干预端点不同；没有同关系的读取记录可直接重算
C1343局部直接读出投影 → 四方向共同原因 未成立 一阶近似在另外三方向不稳定；不是推广成功

一个最关键缺口：尚未把“针造成的同一历史来源效力变化”，连接到一段可复用、可比的形成—写入—使用计算关系。

这不要求解释所有条件或恢复完整原生轨迹；可以只解释一个重要来源变化及其一部分答案后果。跨条件支持至少要来自同一关系，而不是同一模型里另一类操作的阳性。缺口也不是重做SPF、DWB、读取确认或所有旧窗口实验。

6. 对继续旧数据分析的判断

本次完成的是跨实验端点和关系的整合，不新增一个局部追踪队列。已有逐位桥接足够确认上述已连接部分；不应重复做摘要、扩大投影网格或切层头来制造进度。

旧资产可以继续回答的，应当是有明确对应字段的同关系问题。当前关键连接不能仅靠重新组合已有汇总补出：SPF只存回答记录、没有内部张量；NMT/DWB来源对比不同；WIN/KVC也没有同一局部操作的对应记录。用户若继续要求复用，应先指出具体可比端点及已有字段，不能把缺失测量假装成可离线推断的数据。

因此，本次整合后不再默认投入C1343/β/夹角细拆。保留已建立的机制片段与边界，承认“有共同约束，但尚无跨任务/窗口的共同计算解释”。本文不提出新实验或补测方案，也不承诺广义机制或Strong Accept已得到保证。
