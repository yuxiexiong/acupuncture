# 原生首步竞争：逐段链条与已有记录复用——计划 v2

2026-11-02；NFC-01 v2。与 [v1](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-native-first-token-competition-plan-v1-2026-11-02.zh-CN.md) 合并阅读；本版替代 v1 §2 的主资产排序、§4 的主要对应尺度及§5的出口。v1的竞争读数、固定候选、双参照限制、配对单位、零模型预算和未执行身份保留。本次仍只修改/自查/发布计划，不运行分析。

## 1. 修订原因与主问题

v1直接比较 δ_FIX=D(CFIX)−D(CC) 与 δ_native=D(T_native)−D(C_native)，虽然声明不能当机制覆盖率，但仍把“同向/幅度接近”放在过高的位置。CC已经是混合状态，不是原生无针基线。原生变化的一大部分可能在 C_native→CC 已经出现；δ_FIX偏小或异向不能单独否定FIX的条件作用，也不能据此停止整条历史机制研究。

本轮主问题改为更准确的表述：沿已有、固定顺序的混合状态链条，原生停止—非停止竞争变化在哪些转换中出现、抵消，候选身份在哪一段改变？固定45头在这条链上的条件增量是什么？仍然服务稀疏干预→历史状态→后续读取→回答变化的主线，不把首步或分账当完整机制。

## 2. 主表采用完整逐段链，保留路径依赖

主数据优先用同一次 B3 正式运行的五格：

`C_native → N:CC → N:CFIX → N:CT → N:TT`。

逐输入/方向验收 N:TT 与 T_native 的 logits 哈希一致后，定义：

- e1=D(CC)−D(C_native)：从原生C到带T深层状态/入口、部分历史仍取C的组合背景的总转换。
- e2=D(CFIX)−D(CC)：该背景下固定45头的V历史条件增量。
- e3=D(CT)−D(CFIX)：在已有FIX的情况下再加入其余头V历史的条件增量。
- e4=D(TT)−D(CT)：CT到TT的剩余历史转换；具体哪些卷积驱动/历史变量改变，须用旧合同和运行配置列明，不能凭字母称“纯Q机制”。

有精确伸缩恒等式：`δ_native=e1+e2+e3+e4`。

每格同时保留 D、固定候选差F、身份项A/B、停止/非停止赢家ID、首步选择；对每一条边用v1的 `ΔD=ΔF+ΔA−ΔB`，定位的是沿本链出现的竞争变化，不是定位内部机制。

**两项必须写清的边界：**

1. 链顺序固定来自已有实验，不为结果换序，不新跑排列。分段值依赖背景和顺序，不是唯一因果份额，不将“四段加起来等于原生”当科学发现。
2. e3不等于B3的负交互。若用同一读数D及CREST格，则 `R_D=D(CREST)−D(CC)`，`I_D=D(CT)−D(CFIX)−D(CREST)+D(CC)`，因此 `e3=R_D+I_D`。旧B3主要停止cz读数上的交互数值不能直接移植为D的交互。本轮不为此再启动交互研究，只纠正标签。

主表列出e1–e4的有符号值、总变化、端点D及赢家，另列 `|e_i|/Σ|e_j|` 作为绝对变化集中度（分母≤1e−6则不可判）。不把绝对集中度称原生效应份额；取消“FIX占原生变化百分之几”作为主要结果，净变化可能被抵消而接近零。若描述最大段，逐事实报告，并明确最大段不等于最初产生作用的模块。

v1的δ_FIX与δ_native同向/幅度分档降为辅助表，不能单独决定分支存废。原生变化始终为主终点；分段表用于解释两者为什么可能不接近。

## 3. B4作为辅助分支，先核对跨运行接头

B4的CFIX→K/M_nat/M_rand继续保留，与同输入/方向的B3链条并列。接入前逐条比对B3/B4的C_native、T_native、CC、CFIX全logits哈希、prompt/token身份、校准、评分位置和配置。

B4报告已声称这些重放逐位一致；本轮仍将实际哈希比对写成程序验收。B3 TT=T_native亦需逐条验收，不只凭一个样例。若某接头失败：B3原生链可独立报告，B4辅助分支标不可接入；不得用B4值填补B3链缺口，也不重新调用模型。

原生链缺CT/TT时不能宣称链完整；只报告可验证原生端点与缺失列表，不依赖缺格分类“哪段主导”。

- B4正式记录包含全词表计算后的D、停止赢家/非停止赢家ID、s44/s46和干净候选a的原始logit、词表均值；回执有records与tensor哈希。

## 5. 主分析用Git记录，中位数列才需全词表张量

优先读取B3/B4正式JSON及receipts并核哈希，不重复读取/下载完整内部张量。逐格验证字段能否精确构造v1读数：

- s0从C_native的stop_winner取得，q0从C_native的nonstop_winner取得，并检查q0与记录a_token相同；s0须在存有原始logit的s44/s46中。
- 用两个已记录停止logit求stop_max；固定候选差F由s0与a的原始值计算；A=stop_max−z(s0)；B=stop_max−D−z(q0)。身份ID直接用既有字段。跨格词表均值提供均值参照分解。
- 这是对已有全词表评分摘要的精确重组；B由D反推，所以该恒等式闭合仅是实现验收，不能冒充独立验证原始max。用记录的stop_advantage/readout.D/argmax一致性作交叉检查，并注明共同来源。
- 若停止集合有未存原始logit的其他ID、q0≠a_token、缺字段或身份不一致，不擅自用top-5补齐：按manifest读取对应已存全logits；若不可得，该单元相应读数不可判。对核心缺失单元不静默删除。
- 中位数Δlogit参照依赖全词表张量：单列为辅助敏感性列。张量不可用时均值参照仍可描述，但报告“未检验跨参照稳定性”，不写参照稳定或单侧主导。需要重新访问张量时仍按v1资源上限，不进行模型运行。

输入数、方向和去重规则不变。所有字段/文件来源、缺失和采用哪条读取路径逐项记manifest。保留v1的合成测试，增加接头哈希不一致、摘要可重建/不能重建、e3≠交互、链大项互相抵消及小净变化用比例会误导的测试。

## 6. 修订后的判断出口

- e1在多输入上占据较多绝对变化：说明原生竞争变化在进入本链CC组合背景时已出现较大部分。不能单凭这一复合转换归因于“深层状态”一个变量；应先列清其同时改变的入口/状态，不自动去拆深层。撤回“δ_FIX不接近δ_native所以45头没有对应关系”的判法。
- e2较大且与总变化同向、后续段有抵消：说明FIX条件增量可能被其他转换抵消；保留该条件结果，不称原生必要性，不凭占比启动实验。
- 后段或赢家替换较大：报告这条链上的条件转换及身份变化；不称信息丢失或把最后出现的变化命名为起源。
- 多段均大、方向混合或不同情景不同：报告分布式/条件差异，不强制挑一个模块作为下一靶点。
- 接头或资产失败：按§3–5限定可报告对象，不能将工程缺失判成科学阴性。

本轮的交付是“一张能把原生端点、条件增量与B4分支接起来的证据表”。只有读数形成了可被后续操作推翻的具体预测，才另立下一实验；否则结束该记录分析，不继续增加分段、反向顺序或候选搜索。
