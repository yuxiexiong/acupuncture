Acupuncture 实验总结

从单通道全层扫描、正负剂量对照到内部计算轨迹

整理日期：2026年10月28日。时间均为北京时间。

复核记录：本版已按原始回答、统计文件和运行收据交叉核对。修正4B L1的通道转写为N667、6/8首步EOS；全层总计、剂量统计和主线去重总账不变。

本文汇总截至该日已完成并归档的实验，重点为 Qwen3.5-2B、4B、9B 的全层单通道扫描、每层一个通道的正负剂量实验，以及后续内部 hook 轨迹采集；同时纳入 Llama-3.1-8B-Instruct 的对应调查和跨架构对照。较早的双针复现、能力评测、迁移与局部修复实验单列为背景证据。本文不依赖附件或链接即可阅读，数据表、方法、代表性原文和解释边界均在正文中说明。

本次工作是对既有实验的整理与描述性统计，没有训练模型、修改权重或新增模型推理。本文不是已完成机制验证的论文，也不是逐条原始语料转储；全部正式条件进入相应数量和统计分母，典型回答用于展示现象，不代表经过独立人工标注的总体发生率。

一、核心结论

  1. 单通道干预确实能改变回答，但改变不只有一种。 已观察到首步停止、特殊标记或词语循环、跨题主题侵入、角色关系颠倒、算式与结论冲突、格式保留但内容脱题，以及少量局部改善。这些现象可以同时发生。
  2. 干预位置有影响，但还没有得到天然功能区。 不同深度的输出破坏形态有差异；同层不同通道之间的差异也很大。4B 的首步停止集中在最前几层，而重复在中后层同样存在。同一通道还会随问题、剂量和正负方向改变表现。
  3. 剂量效应并非普遍单调，正负方向也不是语义镜像。 减小幅度常能减轻空答或循环，却不存在已证实的通用无损剂量。某些点在中间剂量更异常、强剂量又出现局部正常回答；负向干预有时较好，有时反而更容易循环。
  4. “只改一个通道”不等于“小幅改变”。 本实验按原版层残差尺度标定注入量。剂量绝对值为1时，经过下投影写入的向量范数约为该层一个参考残差尺度；位置稀疏与幅度微小是两件事。
  5. hook 数据已经把“插针—内部变化—输出分叉”连接起来。 目前可确定差异首先出现在哪个组件、如何进入下游 attention/MLP/残差，以及哪一步的 token 竞争或停止选择发生改变。尚未证明某个中间组件是症状的必要或充分原因。
  6. 重复至少存在不同的维持方式。 有的轨迹在每次重新进入循环时仍受到干预推动；有的在形成错误文本历史后，无针参照也偏好继续重复。后者是历史参与维持的线索，不等于做过中途撤针恢复实验。
  7. 跨模型共享的是一些过程现象，而非已对齐的脑区。 2B、4B、9B、Llama 都能出现内容偏转和循环，但最早层的停止模式不同，当前没有建立跨模型通道、层内区域或因果电路的同源对应关系。

2.2 “插一针”具体做了什么

对 gated MLP，记中间激活为 z，下投影矩阵为 W_down。只在选定层的选定中间通道 n 上增加常量 c，其余通道不直接修改：

z'_n = z_n + c
c = d × m / ||W_down[:, n]||₂
MLP输出的直接变化 = c × W_down[:, n]

d 是带符号的剂量；m 是相同原版提示在该层 block 输出的逐 token L2 范数中位数，排除首 token。正负实验共享同一原版校准。偏移按原公式逐档计算后转换为 BF16，不从已舍入的强剂量继续乘系数，也不根据已经分叉的生成前缀重新校准。

干预覆盖提示处理和随后全部实际生成输入位置，属于推理时动态激活干预。不是永久权重编辑，不是训练，也不是只在某一个生成 token 上施加一次脉冲。每个条件从独立上下文和 cache 开始。

在线性下投影处，直接注入向量的理论范数为 |d|×m；后续层对这个变化进行自己的非线性变换。因而实验观察到某个通道能推动某种文本，不足以说明该通道在自然运行时专门承担该功能。

2.3 生成和观测设置

主线调查均使用 BF16、eager 实现、实际 forward batch=1、贪心解码、最多128个新 token。Qwen关闭thinking，使用冻结的聊天模板和停止token；Llama使用自己的原生模板和停止token。正常EOS提前结束就保留该长度，不补齐、不续写、不因回答异常而重试。跨模型使用相同八道中文问题，但分词、模板、结构不同。

每层十个通道使用固定种子独立均匀无放回抽样，排序后执行。种子字符串为 acupuncture-layer-survey-v1:{model_id}:{layer}。十点扫描每次只干预一个点，全部剂量为+1。后续剂量实验从该层原十点中按固定规则再选一个点；没有根据已看到的显著效果换点。

八题是同一点的八种输入，不是八个独立通道。128-token上限只是生成预算；到上限不自动等于循环，正常EOS也不自动等于回答正确。语义现象首次阅读由模型辅助完成，并经部分交叉复读，不是独立人工实验员盲评。

3.4 “重复剂量”与重复验证的准确口径

本项目包含同点多档正负剂量、共享+1来源、工程预检重放，以及hook阶段的逐token重放一致性检查。它们证明来源和实现可核对，却不是对每个剂量开展多随机种子、多次独立采样的统计重复实验。

主线在固定模型、固定输入和贪心生成下，每个正式条件只有一条指定输出。原版在多栏里重复出现、+1被后续导出复用、相同token被hook再次采集，都不能增加独立样本数。负剂量也没有接在正剂量造成的状态之后，因此不是“先损伤、再治愈”的修复实验。

4.3 必须保留的反例

同一层可以同时有正常点和重度循环点。9B L26 N1457的八题总体贴题，算术和月份也正确；同层N11399却几乎全被“失去”循环占据。9B L30 N11132在图书馆、糖果、月份题上正确，但改写、整理、人际建议和天气题出现循环。因此不能把一层简单命名成某种能力区，也不能说干预只破坏数学。

五、单点正负剂量实验

5.1 正剂量的主要观察

在相同点、相同问题、相同原版校准下，降低剂量常使强剂量的空答或循环减轻，也可能让被强退化掩盖的主题倾向显露。这个关系不是所有点、所有问题上的单调曲线。

4B L6 N7840的书桌题是一个清楚的例子：+0.25仍围绕整理书桌；+0.5保留两行步骤外壳，却填入基因符号相关内容；+1没有正文。因此一个点可以随幅度先表现内容侵入，再表现停止。不能把最高剂量的空白直接解释成它只控制停止。

4B L28 N3665在多个问题中出现“6”偏向，例如把糖果题中的3改成6、图书馆题中的16点改成6点，部分回答反复六/6；但+1时另一些题仍完整贴题。当前无法仅凭输出区分数字关系表征改变、词汇输出偏置和更广泛计算损伤。

七、内部hook到底记录了什么

7.1 补测目的和范围

此前调查保存了输入、原版/干预回答、token、校准尺度和干预身份，但没有完整的逐token内部轨迹。hook阶段对冻结旧条件逐条重放，要求生成token与旧来源完全一致，再补存内部摘要。

最终2B、9B、Llama注入范围统一为L0—L5；4B扩展为L0—L31。每条记录的观察范围都是该模型全部层，不只是注入附近。统一前六层是比较窗口，不是预设六层拥有同一种功能，也不是确认了早层边界。

7.2 两条分支及三个不同参照

  1. 原版自由回答：旧调查中模型在无干预条件下自己生成的答案，用于看实际任务结果。
  2. 干预自由回答：按原针、原剂量、原题目再次自由生成，必须与旧来源token一致。
  3. 同前缀无针参照：另开独立cache，从头不施加干预，但强制读取干预分支已经生成的token历史；在强制选token之前保存它原本的logits。

第三条解决了两支自由文本分叉后不能按相同token序号直接相减的问题。它回答的是“面对同样的已生成历史，无针分支如何预测”。它不是第二条运行到一半撤针后的状态，也不是原版自由回答的延续。

预检比较有/无组件观察器时的生成token，核对原来源逐token重放；验证零剂量、独立cache、强制前缀、日志记录时机、全层/位置覆盖、数值有限性和明确未定义值。完成收据检查目标权重哈希及hook移除。预检中的撤针恢复是工程控制，不等于对所有异常轨迹进行中途撤针因果实验。

最终三批归档为15,496个文件、约2.538 GiB，逐文件大小和SHA-256、来源/冻结身份、正式记录、token、组件/位置和退出收据核对通过；缺失、额外、重复正式身份均为0。正式轨迹7,632、预检观察56分开计数。

10.2 三维“邻近”与模型内的关系不是同一回事

当前Explorer把每一层画成平面，真实层顺序沿深度展开；这条轴有计算顺序意义。层内另外两维来自布局算法，不是模型拥有的物理坐标。

4B的写入方向布局以归一化down_proj列向量为基础，经过PCA、UMAP及网格排列。它表达某种权重方向相似性，不能直接解释为语义距离、功能边界或神经解剖。各层独立排布，跨层和跨模型的相同平面位置并未自动对齐。

具体反例：L2 N5063和N5251在编号布局中的坐标分别为(71,52)、(67,54)，看起来相近；在写入方向布局中分别为(11,65)、(81,5)，相距约92.2个网格单位。两者都能诱发重复，并没有因此在权重布局中聚成一个局部区。一个布局中相邻不足以证明共享机制，换布局后分开也不证明没有共同下游作用。

10.3 现有图中已经接入什么

现有本地只读轨迹视图纳入7,632份正式记录，可按模型、注入层、通道、剂量及题目选择，比较原版与干预回答，并沿生成步查看全部层的attention、MLP和残差差分。4B可以查看全部32层的注入；2B、9B、Llama目前只有前六层的注入轨迹，观察仍覆盖各自全模型。

图中组件颜色是该组件的汇总数值，不等于已经保存每个神经元的实时激活。静态权重连线也不等于本次干预实际经过的因果边。Llama当前采用编号布局，没有假造与Qwen同规格的权重地图缓存。只读浏览既有产物不需要重新启动GPU推理。

可视化的当前价值是定位具体条件、核对差异出现顺序、查看停止或重复前的token竞争，并寻找需要进一步验证的共同下游模式。它尚不能凭颜色或聚团直接给脑区命名。

十五、合并证据后能够成立的研究结论

15.1 已有证据共同指向什么

最明确的线索是：按模型内部尺度标定的稀疏激活扰动，可以改变后续计算与输出选择；这种改变具有位置、方向、幅度和输入依赖，并与自回归历史相互作用，表现成多种不同失序。

这条线索同时得到四类证据支持：全层扫描显示不同位置的响应不均匀；同点剂量比较显示非线性、正负不对称和题间分离；能力基准与随机对照表明一般强扰动也能造成广泛损伤；内部轨迹进一步显示差异传播、token竞争和停止/循环维持的具体过程。

目前还不能把所有输出异常归到同一根因。一个完整、正常结束的错误答案，与首步EOS或持续重复，不是同一个终点；两个外表相似的循环，内部无针参照偏好也可能不同。

15.2 证据链目前闭合到哪里

已知的单通道加法、层号、题目与剂量
                 ↓
注入层MLP差异出现，前方组件保持一致
                 ↓
后续attention、MLP、残差出现不同幅度和方向的差异
                 ↓
输出token排序、停止优势、概率分布或分叉时刻变化
                 ↓
空答、主题侵入、错误事实、循环，或局部保留/改善

上面各级已能由同一记录中的观测对应起来；箭头表示实际计算顺序和已测响应关系。中间某一组件是否必要、是否足以引起相同症状、是否只是补偿位置，尚未被这批单针观察实验识别。差分大不等于根因，差分小也不等于无作用。
