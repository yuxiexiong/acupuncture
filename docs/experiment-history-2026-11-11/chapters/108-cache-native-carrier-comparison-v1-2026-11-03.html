NCC-01：接回原生回答——L0/L12 深层缓存承载比较

日期：2026-11-03；版本：v1；状态：设计 Ready，自查通过；尚未实现、验收或运行。 自查：SELF_CHECK.zh-CN.md。

1. 本轮要解决什么

主线保持：稀疏干预改变了什么计算，怎样进入历史状态、被后续计算使用，最终改变回答。

本轮问题：在同一批输入、同一评分时刻和同一替换协议下，恢复深层卷积 V 历史、递推 S 或注意力 KV，各自怎样改变 L0 与 L12 两种既有干预的原生首步和自然完整回答？两种条件的恢复响应有何共性和差异？

这是已有机制向原生行为的连接实验。SIT/NMT 在 t1 后操作，不能撤回已经发生的 t1 停止；本轮在产生第一个回答 token 前操作，不强制前缀。不继续拆增量的 b、β/k/v，也不转做 EOS 排序。

具体新增认识是两种干预在统一条件下的原生行为恢复响应比较，不是再次证明缓存能影响输出。相似结果支持共同的干预敏感环节；不同结果约束共同解释，但单凭恢复操作不证明唯一自然路径或定位机制分叉。

2. 已有依据与不能混用的结果

证据基线固定为仓库提交 ee01ea9a2af1c79596d2a72d51dc5b8f71d5bcfa：

  • CGV 合同及报告：L12/C3621/−1 在 LVK 新面板上 C 为 48/48，T 为 31/48；T 首步停止为 0/48，共享首 token 命中仅 6/48；局部 v 替换恢复到 48/48。因此不能把 L12 损伤表述为停止，也不能再以局部 v 恢复首步作为新发现。
  • FX 报告：全 V 历史恢复 48/48 来自旧 P 面板（12 输入 × 4 方向），不是本轮共享前缀的 48 输入；作为依据，不能冒充本轮端点实测。
  • NFC/EH/SK/NR/CT/FC 已有原生首步、历史承载和答案首字母压低证据；不把原生链写成空白。复用 CFM 的缓存分组/复制工具和 CGV/LVK 的输入、校准、自然生成与解析器；不继承旧 CFM 将浅层统一换成 C 的评分背景。
  • SIT/NMT 留下的是有边界的条件性写入—读取关系，保留为机制工具与参照。其交互效应比不是原生机制解释份额。
  • 同范数随机方向曾复现若干历史效应。本轮不检验针特异性，不声称选中的两根针代表某类专属神经元；不增加随机臂或全层扫描。
3. 固定对象、切点与来源
  • 模型：Qwen3.5-4B，revision 851bf6e8…，完整 revision 和 tokenizer/权重身份沿用 CGV 原收据；BF16、eager、batch 1、原 torch 内核。
  • 输入：CGV G1 使用的 LVK 新面板全部 48 条，六场景。它们已经看过，属于探索比较，不能再称独立留出。固定 ID、文本、token、答案账本及哈希；不换题、不删除干净 C 答错的输入。
  • 两个条件：L0/N4146/−1 与 L12/C3621/−1。沿用各自既有 NQ 校准尺度、NA 布局 B1 窗口 [b+1,n−2]、a=1.0；不重估 μ，不做 k 去偏操作，不重新校准。
  • 两针并不等物理剂量，也有不同上游传播长度。本轮比较两个既有干预条件，不把结果归因于“只改了层号”。
  • 供体：同一个输入的无针 C；接收者：相应针正常形成的 T。
  • 切点 τ：处理最后一个 prompt token x[n−1] 之前的持久缓存快照。由该 token 的前向产生首个回答 token（记 t1）。不是生成完首 token 后的缓存。
  • 在 τ 一次性替换指定缓存。浅层 0–12、未替换的深层缓存、位置管理与后续计算保持接收者来源；随后正常演化。每层当前输入随前面层响应而变化，不称“所有读取条件不变”。
  • 形成期针按原窗口结束；评分和生成不加新针、不重复恢复、不强迫开口、不强制任何前缀。自然停止即结束。

深层集合及替换对象：

记号 替换内容
V G={13,14,16,17,18,20,21,22,24,25,26,28,29,30} 全部头的卷积缓存 V 通道，全部已存槽位；q/k 通道保持 T
S 同 G 的全部 recurrent_states
K 全注意力层 {15,19,23,27,31} 的全部历史 key/value

V 指卷积历史，不是当前 v；S 指 τ 时的历史状态，不是 t1 更新后的 S。V 通道切片从已验收实现读取，不能凭数字猜测。V/S/K 都不包含深层卷积 q/k 历史。

4. 最小矩阵

每个输入共 11 条不同的自然生成轨迹：C 共享一次，两针各五条。

条件 τ 时来源 用途
C 全部 C 任务能力及无针端点
T 全部 T 原生受干预端点
TV 仅 V 来自 C V 历史恢复响应
TS 仅 S 来自 C 递推历史恢复响应
TK 仅 K 来自 C 注意力历史恢复响应
TJ V、S、K 联合来自 C，其余仍 T 单组不足时的有限联合参照

不做三组八格全因子矩阵。 TJ 不是全干净运行，不保证恢复，也不是效果上限；只判定这个联合操作比单组多带来什么，不能由它拆出各对交互。C/T 及相同条件如已有完全匹配且通过桥接的原始记录可直接复用，不能仅因名称相同就复用。

这组比较同时回答原生行为问题和跨条件问题。V 的首步恢复若由旧局部 v 桥接已能确定，明确列为预期参照；新增信息集中在 S/K/联合响应、自然完整交付及两条件之间的对应关系。

5. 终点与估计对象

主终点：自然完整回答 Y_full，沿用 CGV/LVK 冻结的原解析器。报告每格正确数、逐输入结果；TV/TS/TK/TJ 相对 T 的改对、改坏和净变化分开列出。C 正确子集只作附加描述，不替代全 48 条。

原生首步的连续读数：

  • f_i：从该输入既有干净参考及冻结答案账本读取的共享首 token，不根据新输出选，不假定全部 token ID 为 52。
  • B_i = z₁[f_i] − max_{j≠f_i} z₁[j]，竞争集合为全词表。
  • 同时保留 z₁[f_i]、最高停止 logit、最高非停止竞争 logit、赢家身份、首 token 是否 f_i、实际首步停止；从而区分正确开头压低、错误开头竞争与停止。
  • B 衡量首步前缀竞争，不能替代记录选择正确性或完整答案；不增加强制前缀 t2 路线。

对每针、每操作 X，报告 ΔB_X=B_X−B_T 与 ΔY_X=Y_X−Y_T，以及相对 C 的剩余差距。两针比较使用同输入的配对效应差，但不据此消除剂量、形成历史和基线差异。

连续量先逐输入求差、再按六场景等权；Y 同时报原始计数和场景等权比例。报告每场景符号，使用固定种子 20261103、场景内按输入配对重抽样 2000 次的描述性 95% bootstrap 区间；所有格共用抽样索引。区间只反映本面板输入波动，不声称新场景总体推断。不算机制比例，不对小分母相除，不按 EOS 分组删题。

6. 预先写定的解释与下一步

只报告连续值和计数，不设“机制成立/失效”的总标签。下表是解释边界，不是自动选下一轮的阈值。

观察 本轮能得出的认识 对后续的约束
两针同一组恢复首步且改善完整回答 两个条件共享这一缓存替换的行为敏感性 后续有理由检验其共同更新/读取计算；不能直接宣布同一机制
两针单组效应排序、符号或改对/改坏明显不同 共同缓存解释受条件约束 保留具体差异，后续先对齐条件再定位分叉

工作预测（未验证）：V 恢复可能在两针都有效，但完整回答和 S/K 恢复不保证同形。任何阳性均为混合缓存干预的总效果，可能涉及补偿、事实重引入和后续共同响应。恢复充分不等于该缓存是唯一损伤来源；本轮不做必要性或因果份额主张。

7. 实现、工程验收与预算

复用既有缓存复制和自然生成程序，只新增条件表与分析。实现时记录确切代码提交、源记录哈希、模型/tokenizer、校准和输入清单；不新建框架。

一次必要预检，固定输入为账本中按 ID 排序的前两条，不按效果挑选：

  1. 同源自换等于不换；C/T 对各自已有同条件记录桥接。相同计算路径要求 token 一致、缓存逐位一致；不同路径若不能桥接，先记工程失败，不解释为科学反例。
  2. τ、输入位置、层集合、缓存形状和来源逐项断言；供体只读，非目标缓存逐位不变。管理状态不得误从另一长度的运行移入。
  3. 保留未改变源张量哈希。V/S/K 联合操作只等于三组按指定来源复制，不要求 TJ 等于 C。
  4. 停止集合沿用 {248044,248046} 且与解析器一致；贪心、最多 32 个新 token，解码细节沿用已冻结运行器。保存全部输出及截断，不能把触顶当停止或答对。
  5. 正式前冻结合同、代码、来源与解析器；预检修复须留失败记录并更新版本，正式开始后不临时改变定义。正式来源、形状或非有限值错误即停，不能静默丢输入。

规模上限：正式 48×11=528 条自然轨迹；两条输入预检共 22 条，最多另 8 次工程评分。生成上限 (528+22)×32=17600 新 token，另 8 次单步工程评分。若缓存需重建，C 与两种 T 各形成一次，共正式 144、预检 6 次前缀；不逐臂重建。输入 token 总量从冻结账本汇总，重建费用计入。

GPU 预算预估 0.5–1.0 GPUh，总上限 1.5 GPUh（包括重建、预检、正式与允许的一次预检修复重试）；这是预算，不是已测耗时。预检外推超上限则暂停并报告，不删条件、不擅自加预算。新增数据上限 8 GiB，保存原始输出、逐输入读数、必要来源/验收记录；不把模型权重入 Git。

当前只有设计与文档上传授权。不得据此加载模型、运行 GPU 或启动旧任务。

  3. L12 局部 v 已恢复，重做 V 是重复。 首步确属参照；新增比较由相同原生协议的 S/K/TJ、自然交付及跨条件响应提供，不把 V 首步当发现。
  4. 单组都弱时，TJ 也可能因 q/k 或浅层仍受损而弱。 允许，不把弱效应解释成缓存无关；停止此有限操作分支，不靠排除法定位。
  5. L0 停止会不会使新操作仍到不了？ τ 在首个回答 token 之前，操作一定先于停止决策；t1 真停止就保留，绝不强制续写。

0. 相对方案的修正（评审商定）

1. 问题

在同一批输入、同一时刻、同一替换协议下，恢复深层卷积 V 历史、递推 S、注意力 KV 或全部深层缓存，各自怎样改变 L0 与 L12 两种既有干预的原生首步和自然完整回答？两种条件的恢复响应有何共性与差异？

2. 范围
  • 模型：Qwen3.5-4B，revision 851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a；BF16、eager、batch 1、torch 原核。
  • 输入：LVK 新面板全部 48 条（已见开发面板），六场景。
  • 两个针：L0/N4146/−1（沿用 LVK/NVB 形成）与 L12/C3621/−1（沿用 CGV G1 形成）。两者均为 NQ 校准尺度、NA 布局 B1 窗口 [b+1, n−2]、a=1.0；不重估、不重新校准。
  • 两针的物理剂量和上游传播长度不同。本轮比较的是两个既有干预条件，不把差异归因于“只改了层号”。
3. 操作
  • 切点 τ：处理最后一个提示 token 之前的缓存快照（form_new 返回的 C 与 T），由该 token 的前向产生第一个回答 token。
  • 接收者与供体：接收者为该针正常形成的 T（经 edited_arm(T,T,T)，并由 check_bg 核对与 T 逐位相同）；供体为同一输入的无针 C。
  • 替换：在 τ 一次性复制下表中的目标张量，其余缓存（浅层 0–12、未替换的深层张量、位置管理）全部保持 T。随后正常处理最后一个提示 token，贪心生成到停止或共 32 个 token。不加针、不挂钩子、不强制任何前缀。

  • 首步分差的排序在两针完全相同：TJ > TV > TS > TK（L12 为 +8.70 / +5.90 / +3.31 / +1.78）。但在 L0 上，完整回答的排序（TS = TJ > TV > TK）与首步分差的排序不同。共享首 token 的分差不是回答正确性的可靠代理，这一点在本轮直接看到了。

L12 的首 token：T 为 6 条编号、42 条引导语；TV、TS、TJ 都是 48 条编号；TK 为 44 条编号、4 条引导语。L12 的首步都没有停止。

4. 对照解释表（合同 §5.1）
  • 深层 S（以及全部深层）：两针都改善首步（L0 的停止 47→0），完整回答都全部恢复，对应"两个条件共享这一缓存替换的行为敏感性"。按措辞限制，这是混合缓存干预的总效果，不说明 S 是唯一损伤来源，也不能宣布两针同一机制。
  • V 历史与 KV：两针差异明显。V 在 L12 足以全部恢复，在 L0 只恢复开头和 1/3 答案；KV 在 L12 足以全部恢复，在 L0 几乎无效。对应"共同缓存解释受条件约束"。
  • L0 的 TV：首步前缀恢复、完整回答大多没有恢复，对应"开头改善不足以解释交付"。问题落在后续的编号选择上。
  • L12：任一深层组单独都足以恢复，说明 L12 的回答损伤不依赖某一个特定深层组的恢复。本轮分不清这是"多组冗余"还是"损伤贴近阈值"。
5. 能说和不能说

能说（这两个针、已见面板、τ 在最后提示 token 之前、浅层与入口保持受干预）： - 只把深层递推 S 换成干净历史，两针的完整回答都能全部恢复； - 在 L0 上，开头恢复（V 历史）和答案恢复（S）由不同的深层缓存替换带来； - 在 L12 上，任一深层组都足够。

不能说： - S 是唯一的或自然的损伤载体：本轮只测了"恢复充分"，没测"污染充分"； - 两针同一机制：V 和 KV 的响应明显不同； - 浅层与入口不起作用：它们在这里保持受干预，但没有单独检验； - 结论推广到其他针、层、任务或模型。
