##### 3. 具体计算：三张表，不再重做资产目录

###### 表一：改动是否到达残差流

对每输入、背景、DEL/RAND分别列实际core差、gated norm输出差、out_proj输出差、13层出口差。每一边界报告差向量范数、相对于该边界R激活范数的比例；零分母记不可判。

各边界表示空间/维度可能不同，不用跨空间裸范数比宣布增益或抑制。gated norm前后仅描述其输出变化，未单独干预norm，不能宣称norm是因果瓶颈。

###### 表二：进入残差后的改动怎样传播

定义d_l=h_R,l−h_X,l，X为DEL/RAND。逐层保留入口和出口d；分支响应差为e_l=d_out,l−d_in,l。保存原始向量或其校验和、范数、相对于R的规模。对同一残差空间，报告e_l与d_in,l的内积/夹角（零范数不算）；反向说明这一记录边界存在抵消形态，不能证明网络主动纠错或补偿。

G层out_proj和全注意力attn_out已有记录，可将block总增量分为attention输出与剩余项。剩余项含MLP及有限精度差，必须如此命名；未直接保存MLP输出不能冒充精确MLP贡献。不构造未保存的同入口四角，不重算“第14层以后本层新生I”。

###### 表三：同一个终点方向下的有符号账目

主次保持B1：停止词248046的去词表均值logit为主要方向，冻结干净答案候选a为并列报告；不重新挑选候选。D、实际首步EOS仅复核，不能替代上述两侧。

每输入每背景以R最终归一化分母r_R为固定参照；令u_t为包含最终norm线性权重的去词表均值输出行，p_t(d)=u_t·d/r_R。在所有残差边界使用**同一个**u_t/r_R，记录p_t(d_l)及p_t(e_l)。从13入口到final:h的增量必须望远镜相加闭合；如边界不连续，断点单列，不能藏入某层。

终点单列：实际去均值logit差 ΔZ_t = p_t(d_final) + ε_t。ε包含两运行归一化分母不同及实际浮点计算差，不能不加验证地全部叫归一化机制。用已有final:normed和固定权重再次核对ε的来源；无法闭合时不作层级解释。代数分账FP64误差限1e−10×max(1,各项绝对值和)，实际BF16读数与CPU投影不要求逐位一致，必须报告残差而非调阈值掩盖。

这是固定最终方向的描述，不是中间层真实logit，也不是局部敏感度。没有朝这个方向投影，不等于没有可被下游利用的信息；投影后来抵消也不等于找到唯一原因。


###### 3.4 单位改动响应（r2，描述性读数）

对每输入、背景、X∈{DEL, RAND0, RAND1}：γ_t = ΔZ_t / ‖d_13out‖，ΔZ_t = Z_t(R) − Z_t(X)（全词表去均值实际 logit），d_13out = 第13层 decoder 出口残差差。分子、分母、符号全部保留；‖d_13out‖/‖h_R,13out‖ < 1e−4 时不显示比值（预先固定的展示线，不是科学零点）。情景层面先对两事实分别平均分子与分母再相除。

**它不能消除 B1 的大小/敏感性混杂：** 除以范数不等于同方向、同大小的对照；N 与 M_T 的改动方向和下游背景不同；模型非线性，小改动比值不能外推；随机参照匹配的是 core 位置逐头范数，到第13层出口后大小和方向未必仍匹配（第13层出口的随机/真实范数比单列报告）。允许的读法：

| 观察 | 可以说 | 不能说 |
|---|---|---|
| N 与 M_T 的 γ 接近 | 与“源头改动较小参与解释弱输出”相容 | 阴性主要由删除量小造成 |
| N 中真实与随机 γ 都低 | 这些已测方向在 N 中单位改动输出响应较低 | 原生背景对第13层整体不敏感 |
| 只有真实删除 γ 低 | 存在方向相关的传播差异线索 | 已发现方向特异性抵消机制 |

###### 4.1 冻结的候选筛选规则（r2，运行前写死）

只用于决定“是否有值得另写因果方案的候选”，满足规则 ≠ 机制成立；两条随机不代表随机扰动总体，逐模块筛选存在多重比较。

- **被检查的模块（固定 36 个）：** 第14–31层每层两个分支：mix（G 层线性注意力 out_proj 输出；全注意力层 attn_out）与 rest（该层残差增量减 mix，含 MLP 与有限精度差）。第13层内部边界只作表一描述，不进筛选。
- **带符号量：** c_m = p_t(e_m)，即模块 m 在 R 与 X 两运行中的输出差在固定终点方向上的投影（§3.3 的同一 u_t/r_R）；主方向 t = 248046（cz_s46），答案词 a 按同一规则并列报告但不参与决定。
- **事实合并：** 情景值 = 两事实 c 的均值；随机参照值 = max_j 两事实 |c_RANDj| 的均值。
- **情景通过：** 两事实 c_DEL 同号，且 |情景均值 c_DEL| > 随机参照值 + 0.1 logit。
- **模块入选：** 在背景 N 中 ≥5/6 情景通过，且通过情景的符号一致。
- **多个入选：** 全部列出；下一次因果检验的优先候选取 N 中情景平均 |c_DEL| 最大者，其余登记为备选。
- **决定：** N 中有入选 → 交付候选（另写因果方案，不在本轮执行）；N 中无入选 → 结束本次 B1 传播追踪，暂停第13层交互分支，不自动扩层；仅 M_T 有入选 → 登记为混合背景线索，按“无原生候选”处理。

#### B1 配对传播分析：结果

日期：2026-11-01。[方案 r2](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/docs/cache-b1-paired-propagation-analysis-plan-v1-2026-11-01.zh-CN.md)、[合同 r01](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-b1-paired-propagation-v1-2026-11-01/CONTRACT.zh-CN.md) 与筛选代码在运行前提交（6bb338b）。CPU 离线，0 模型调用、0 GPU，1.5 s；B1 formal-r01 的 12 份张量按收据校验后读取。结果 [results-r01.json](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-b1-paired-propagation-v1-2026-11-01/results-r01.json)，代码 [analyze.py](https://github.com/yuxiexiong/acupuncture/blob/7d6bdf84ab74062ac9ab55bc8201b5a6586b92c8/experiments/cache-b1-paired-propagation-v1-2026-11-01/analyze.py)。同一助手分析，不是独立复核。

##### 1. 决定（按冻结规则）

**无合格候选：结束本次 B1 传播追踪，暂停第13层 V×Q 写入交互分支，不自动扩层。** 筛选失败不证明 36 个模块都无关：规则要求超过两条随机参照，而这些随机方向到第13层出口时已比真实删除大 1.9–2.5 倍，使筛选偏保守。 36 个模块（第14–31层 × {mix, rest}）在 N 停止侧没有一个入选；最好的模块（31:rest、31:mix、27:mix）也是 0/6 情景通过。M_T 同样无入选，答案词侧也无。

##### 2. 闸门

张量/记录哈希、层间边界逐位连续（13–30，第31层出口 = final:h）、同背景各格第13层入口逐位相同、恢复的补丁后 core 哈希等于 B1 记录、账目闭合（最大误差 4.4e−16）全部通过。

##### 3. 描述性结果（不是因果结论）

**表一：改动进入了残差流，但真实删除方向在第13层内部比随机方向衰减更多。** 第13层出口差范数相对 R：M_T 0.187、N 0.088（中位数）。core 位置真实与随机逐头范数相同（相对 0.37 / 0.12），经门控归一化与 out_proj 后，随机方向在第13层出口的范数是真实删除的 1.9 倍（M_T，范围 1.5–2.8）与 2.5 倍（N，2.1–3.4）。这只是记录边界上的描述，未单独干预归一化。

**表二：差异持续存在并增长，但早层模块的响应与输入差异反向。** DEL 的差向量范数从第14层到第31层：M_T 1.4 → 7.0，N 0.7 → 1.8（中位数）。第14–19层 cos(e_l, d_in,l) 中位数 −0.16 至 −0.44（两背景相同形态），第20层后接近 0（第27层 −0.25 / −0.45）。这是“有抵消形态”的记录，不证明网络主动纠错。

**表三：差异基本不朝停止方向走。** 固定终点方向投影：第13层出口 p_s46 在 −0.05 至 +0.01（两背景）；终点 p_s46 M_T −0.62 至 −0.27、N −0.11 至 +0.14；实际 ΔZ_s46 M_T −0.79 至 −0.42、N −0.09 至 +0.06。分母项 ε 不可忽略（最大 0.35 / 0.17 logit），舍入项 ≤0.07。答案词侧 N 也在 ±0.17 内。

**单位改动响应 γ = ΔZ / ‖d_13out‖（描述性，§3.4 的限制适用）：**

| | M_T DEL | M_T 随机 | N DEL | N 随机 |
|---|---|---|---|---|
| 停止侧，情景 | −0.51 至 −0.32（6/6 负） | −0.14 至 +0.17 | −0.06 至 +0.01 | −0.09 至 +0.06 |

按方案允许的读法：N 中真实删除与随机方向的 γ 都低——**这些已测方向在 N 中的单位改动输出响应较低**，不能说原生背景对第13层整体不敏感。N 与 M_T 的 DEL γ 相差近一个数量级、并不接近，所以这些数据**不支持**“B1 的 N 阴性主要由删除量小造成”；但方向与下游背景不同、模型非线性，比值也不能把大小与敏感性分开。M_T 中真实删除的 γ 一致为负且大于随机，是方向相关的传播差异线索（仅混合背景）。

第13层这一支两次因果操作（LOCAL 的 S×读取交互、B1 的 V×Q 写入交互）与一次配对追踪都没有给出原生背景的候选，按规则结束。保留的描述性事实：原生入口下，第13层改动传进残差后，早层有反向响应，之后的差异增长，但在停止方向上的投影较小（未测夹角，不说“正交”）。B 阶段若继续，需要不依赖第13层的、有独立依据的新候选；本轮不指定接班对象。
