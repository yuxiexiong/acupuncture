旧状态与读取交互：从局部计算接到输出的因果检验

日期：2026-11-01；编号 CFM-LOCAL-READOUT-v1 r3。状态：设计逻辑自查通过；r3 冻结分档规则（§8.1）与局部分量描述（§7.2）；实现与运行见实验目录 experiments/cache-local-readout-causal-v1-2026-11-01/。 本文采用项目实验设计自查规范及 Academic Research Suite 的实验设计流程。同一助手完成自查和反方检查，不是独立审查。r2纳入反馈后的解释修正，r3把“明显/弱”写成开跑前冻结的数值分档，操作矩阵与164次评分预算不变，修订复查见§14、§15。

1. 用人话说，本轮要解决什么

我们已经发现：真正扎针后，“旧笔记变了”和“使用笔记的方式变了”在第13层会共同产生一份额外的计算输出。但是，这份额外输出有没有实际推动模型停止说话，尚未测过。它也可能在后面被抵消，或者只是伴随现象。

本轮把这份额外输出从当步计算中扣掉，让后面的模型正常继续算，检查停止词与其他词的竞争怎样变化。同一操作分别放在原生有针运行的读取背景和之前统一干净浅层的背景中。再用“扣掉该层全部局部变化”和两个同幅随机方向作参照，区分具体交互有用、该位置其他变化有用、或该位置影响很弱。

这里的“扣掉”是一个精确定义的计算反事实，不会撤销此前的扎针，也不是修复模型或删除记忆。本轮只评分下一 token；不从这种人为改过输出、但没有相应改写未来缓存的状态继续生成。

总问题保持：少数通道激活干预怎样改变写入、历史状态处理和后续读取，最终造成显著回答变化？ 本轮接的是“具体更新—读取计算 → 最终 token 竞争”，停止是目前已有对齐证据的观察窗口。

2. 依据、增量与最不利证据
2.1 已有资产

直接依据为更新—读取审计报告与其 manifest。来源为固定提交 f38b00e6b9b540c2978002ce8655c5935e4bfabb 的 bridge/combo 运行；合同、代码、freeze、四份 worker 收据均保留在审计目录 source/experiments/。

  • 已确认实际内核使用了旧状态，CPU 可重构旧状态项和当前写入项；无需再立项证明“缓存被读取”。
  • 在统一浅层背景的第13层，C→T 存在旧状态×有效读系数交互；C→CT 没有该项，仍能形成很大的最终分数效应。因此 CT 不能充当 T 的完整机制替身。
  • 第13层是本协议第一个深层 GDN 层，四格入口相同，能排除更早深层操作改变当前输入的混入。选择它基于可识别性，没有挑范数最大的层，也不称其为天然关键层。
  • 原生首步停止8/12，统一浅层背景0/12；原生停止输入的余量只有0.0625–0.75。少量分数变化就能翻转是否停止，不能拿翻转个数证明解释了大部分针效应。
  • 现有局部张量范数和最终分数共变，不能证明局部项对最终输出有因果作用；这一缺测量是本轮新增评分的理由。
2.2 已有工作直接复用

How Linear Attention Remembers §3.2已经用状态交换、查询期输出替换与恢复连接存储和读取；WriteSAE §4已有公式指导的状态写入/消融及输出检验；How LLMs Are Persuaded 附录R已有重放和固定读取方式的干预。本文复用计算分解和输出边界干预，不把它们包装成新方法。完整近邻边界见合并查重。

本轮的对象级增量是：测出我们这根针实际形成的局部交互，在两种读取背景下是否推动、抑制或几乎不影响最终停止竞争。 阳性补上一段有边界的计算—输出连接；弱删除效果只限制该层该项在当前背景下的单独删除作用，不能否定其自然参与、其他层的同类作用或冗余机制。尚不足以单独构成整篇论文或领域首次主张。

4. 固定研究对象与两种读取背景

模型沿用 Qwen3.5-4B，revision 851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a，BF16、eager、原 transformers 5.20.2 路线。输入、分词、位置、停止 token 集与原 bridge 合同一致。针为 L0/N4146/−1，仅此前形成期的晚段；评分最后提示 token 时关针。模型、协议和原逐位置干预定义以固定合同为准，不将剂量−1解释为任意坐标减1。

使用原12条输入，按 source/item-map.json 的 base_id 和 target_index 识别，不由文件名 f0/f1 猜正确答案。六情景为 VAR03/04、VRD03/04、VRL03/04；已经看过结果，不是未见验证集。第13层是在审计这批数据后选定，依据是四格入口相同且存在可分解的局部差异；本轮属于数据知情的机制探索，不是对未见输入的独立确认。

S_C/S_T、F_C/F_T：同一输入在 τ（最后提示 token 之前）的第13层干净/有针状态。其余第13–31层缓存全部取 T，包括其他 G 层 S/F 及全注意力 KV。两个背景分别为：

背景 第13层当步入口 深层历史 对应旧端点
M，统一浅层 干净浅层计算产生的 x_C T Y_T
N，原生后半段 原生有针形成、评分时已关针所产生的 x_T T T_native

N 的恢复方式必须单独验收。 原归档保存了 score_extras['T_native']['13:in'] 和 T 的完整深层 τ 缓存，但没有保存完整 T 浅层缓存。计划先用 C 浅层运行到第13层，在 decoder13 前钩子以已存 x_T 替换入口，再使用 T 深层缓存和原位置继续单步计算。此时浅层当步结果不再进入后半段。位置编码、mask、cache_position 等必须与旧评分一致。

只有 N 的完整词表输出和深层轨迹能重现 T_native，才称它为“原生评分后半段的重放”；不声称重新运行了原生前缀。M 同样要求重现 Y_T。两者都只评分一步，不复用本步新缓存，不继续生成。

5. 要减去的计算到底是什么

按 key×value 记法，第13层内核读出为：

o(S,F;x) = Sᵀ w(F;x) + n(F;x)
w(F;x)   = α [q − β k(kᵀq)]
n(F;x)   = β v(kᵀq)

q/k/v 是真实短卷积、激活和内核归一化后的输入；q 含原维度缩放。α=exp(g)，β、z 取同一当步入口 x 的实际值。固定 x 后，F 改变 q/k/v，S 不反馈到它们；不能把这些量拆成彼此独立的形成原因。

对每个背景 b∈{M,N}，保持自己的 x_b，构造四个局部读出（非四条完整生成）：

o00 = o(S_C,F_C;x_b)    o10 = o(S_T,F_C;x_b)
o01 = o(S_C,F_T;x_b)    o11 = o(S_T,F_T;x_b)
I_b = o11 − o10 − o01 + o00
    = (S_T−S_C)ᵀ [w(F_T;x_b)−w(F_C;x_b)]
J_b = o11 − o00

I_b 是本轮要检验的局部交互；J_b 是在同一 x_b 下两类局部历史共同变化的全部 core 差，用作解释阴性的参照。J_b 不是整根针的影响，也不是自然运行 T−C 的全部第13层差：x_b 始终固定。原生背景中本轮只检验固定x_T后由卷积历史变化引起的读系数差，不单独估计x_C→x_T造成的读取变化；两背景比较也不能把这两类作用唯一分账。

计算例（标量，仅解释操作）：S_C=1、S_T=2，w_C=1、w_T=3，n=0；四格为1/2/3/6，I=2。减去 I 后 core=4=2+3−1，保留两个单独变化；它既不等于干净值1，也不等于撤销历史。

M 的驱动和状态可由旧四格记录离线获得。N 的 w(F_T;x_T) 已存，但 w(F_C;x_T) 尚未测量：下一次运行要增加一个影子评分，只把第13层 F 换成 F_C，保持入口 x_T 和其余缓存一致，记录该层实际驱动。影子格的最终分数不参与主判读，禁止据其结果选方向。四格使用这些实测驱动与 S_C/S_T 在 CPU FP64 计算；不用重新形成前缀。

6. 干预矩阵及 hook 边界

每个背景各5格，12输入一致，不按已有结果挑子集：

格 第13层返回给后续计算的 core 用途
R 原 core 参考与旧输出重放
−I core−I_b 主检验：局部交互是否推动最终竞争
−J core−J_b 若−I弱，判断整个局部 S/F 变化是否仍有影响
Q0 core−r_b0 与 I_b 同幅的随机方向参照
Q1 core−r_b1 第二个固定抽样，避免只依赖一个随机方向

随机向量按每头匹配 I_b 的 L2 范数；零范数头设零。不正交化、不反射 I、不按输出筛选。每输入两个独立种子：SHA256(CFM-LOCAL-READOUT-v1|item_id|k) 的前16个十六进制字符，k=0/1；CPU torch.Generator 生成 FP32 标准正态 [32,128] 后归一化，冻结生成器版本及向量哈希。M/N 共享单位方向，但分别匹配本背景的幅度，是配对设计；两个抽样不构成零分布或额外样本，也不足以推断总体随机效应。本轮不承诺这种推断。

hook 包在真实 torch_recurrent_gated_delta_rule 返回边界，只命中 layer13、seq_len=1。先完成原内核，再将 FP32 减法结果转换回原 core dtype/shape；返回的 s_new 保持原值。本层 z、门控归一化、输出投影、MLP和后续所有层正常响应。缓存读取前使用独立深拷贝；不回写归档，不混入下一格。

这是一个 core→下游的输出边干预。S/F 的写入历史和当前内核更新仍按接收者计算；本轮没有把 I 当成独立自然状态变量，也没有制造“未来缓存也已修复”的轨迹。该语义保证一点评分有效，同时禁止用它直接解释持续多步生成。

7. 终点、测量与报告
7.1 主要估计对象

每背景定义：δI_b = D(R_b)−D(−I_b)；正值表示该删除操作降低停止优势，负值表示提高停止优势。同理计算 δJ、δQ0、δQ1。

D=max停止logit−max非停止logit。停止集合沿用合同（248044/248046），不事后换集合。主表保留绝对 D、各 δ、12条输入、6个情景配对均值，不把12条当12个独立情景。

同时固定每背景 R 的停止赢家 s_b 与非停止赢家 u_b，所有干预格都报告 L=z(s_b)−z(u_b) 及 δL；候选词在参考格选定后锁定，不能在每格重新选。D 和 L 若异号，明确记录竞争者切换，不强称内部项统一推动了固定词对。两背景的 L 可能使用不同词，背景数值比较以 D 为主并附 token 身份。

报告首 token 贪心选择/EOS是否翻转，但不把8/12之类数值解释成生成质量、正常回答或机制解释率。另列各参考点到干净 C 的 D 差，帮助判断 δI 的实际量级；仅在分母绝对值≥1 logit 时展示比值，保留负值与>1值，不称自然份额。

7.2 缺失测量与本轮补录
  • 两背景 −I/−J/随机格的最终完整 logits，这是旧数据推不出的主要新量。
  • N 的干净 F 影子驱动，防止把 x_C 下的交互硬搬到 x_T 下。
  • layer13实际输入、q/k/v/g/β/z、原 core、拟删除与实际删除向量、s_new前后校验、门控归一化后输出、out_proj输出、decoder13出口及最终残差。用于确认操作，并描述变化在进入后续层前是否已被抑制；这些描述不另升级为因果链。

  • 保存最终 RMSNorm 分母 r、完整 logits；沿用已有无 bias 输出头的离线固定分母换算，辅助检查新的干预是否主要改变整体尺度。r固定为对应 R 的值，logits_fix=logits_X*r_X/r_R；不为此新增模型评分，不重做整词表 FP64 投影。

  • 局部分量描述（r3新增，CPU，不新增评分）：每背景报告第13层 core 空间里的 A_S=o10−o00、A_F=o01−o00、I_b 三项的L2范数，以及 cos(I_b, A_S+A_F)。J_b=A_S+A_F+I_b 恒成立；余弦为负表示该层 core 内交互与两个单独变化方向相反（局部抵消）。这是 core 空间描述，不是端到端分账，不替代§8的终点判读。

不新增形成过程全量录像、全层热点图或多步生成。旧材料里能复算的四格项不重复上卡收集。

8. 不同结果分别多知道什么

先看工程有效性，再看逐情景方向和量级。不存在“只要翻转EOS就成功”的标准；两个随机抽样仅作有限参照，不进行p值检验或把某个任意比例作为统计阈值。

观察 可增加的认识 不能推出／下一步限制
N、M 中 δI 都稳定为正，且相对针效应有可观量级、超过两个同幅抽样 该项在两种背景下都能推动停止竞争；补上一个具体计算到原生评分后半段输出的条件性连接 不证明唯一或主要路径；若需要跨针确认，应把本轮实际方向和背景预测带到少量未用于设计的条件
只在 M 有作用，N弱或异号 旧混合背景中的计算作用不能直接代表原生读取；背景依赖成为明确结果 停止把M的阳性写成原生解释；不能默认扩层补救
N有作用，M弱或异号 当前浅层形成的入口能改变这个局部项的端到端作用 δI_N−δI_M同时含项本身和后续背景变化，不能单独归因“浅层放大”

δI与两个随机参照相近／不稳定 有输出敏感性，但当前证据不足以强调该交互方向的特殊作用 不将两个抽样当足以证明“都是一般损伤”，也不无上限增加种子
EOS翻转但δI只占原针D差很小部分 它影响临界决策，不能解释大部分分数变化 区分阈值杠杆与大效应机制
仅D变化而固定L/尺度诊断不一致 改变了竞争者或整体尺度，需按实际读数限定解释 不直接称“停止词语义被删除”

“明显”“弱”等标签按§8.1冻结规则给出，同时必须用6个情景的实际方向计数、绝对logit范围、相对量级及随机参照逐一展开，不能只报标签。小到舍入不分辨的操作标为数值不可判，不当作科学零效应。本轮没有总体置信结论，也不通过调阈值使假设过关。

预先规定的判读边界： 工程验收失败、实际删项无法在预定精度下实现，才记为对应测量不可判；工程有效而效应弱，保留为有界弱效应，不改称未获得数据。J与I包含不同分量，可能相互抵消，所以δJ弱不能作为δI无效的门槛。Q0/Q1只与I匹配幅度，不能把它们的范围作为J的零分布或显著性标准。

后续决策： 本轮是主线的一段局部计算检验，但不预定下一轮一定做多层。两项都弱时，分布式承载、其他位置集中、冗余与抵消仍无法区分，不能写成“已说明分布在多层”。只有已有逐层证据与本轮结果共同支持一个可区别这些解释的比较，才另写多层方案，并明确扣除原轨迹预计算项还是干预后重算项。δI作用明确时才据其具体方向和背景形成跨针预测；新情景须核实此前未用于选点/定规则。上述均不是后续运行授权。

8.1 冻结分档规则（r3，开跑前写死）

单位为情景：每情景取两事实均值，共6个。每背景 b 记 δX_s（X∈{I,J,Q0,Q1}）与针效应尺度 G_s=D(R_b)−D(C)，D(C) 取 bridge 记录的干净评分。比值 ρX_s=δX_s/G_s；G_s 绝对值<1 logit 的情景不进入比值（按§7.1），记为缺失，不补。

I 的三档（每背景独立判）：

  1. 明显推动：δI_s>0 的情景 ≥5/6；且 |δI_s|>max(|δQ0_s|,|δQ1_s|) 的情景 e≥5/6；且 ρI 的情景中位数 ≥0.05。明显抑制：符号条件换成 δI_s<0 ≥5/6、中位数 ≤−0.05，其余相同。
  2. 弱：未达明显，且 |ρI_s| 的情景中位数 <0.05。
  3. 有作用但不特异或不稳定：其余情况（量级不小，但方向或随机参照条件不满足）。

e≥5 的依据（推导档，条件于可交换假设）：若 I、Q0、Q1 三个方向对单情景输出的作用可交换，单情景 I 绝对值最大的概率为1/3，6情景中 ≥5 个的概率为 0.018；≥4 个为 0.100，不采用。I 不是随机抽样，可交换只是零假设的表述；两个抽样不构成零分布，结论只写“超出这两个参照”，不写显著。

J 的分档（无匹配随机参照，只作幅度描述）： 同号情景 ≥5/6 且 |ρJ| 中位数 ≥0.05 记“幅度明显（未标零分布）”；|ρJ| 中位数 <0.05 记“弱”；其余“不稳定”。J 的分档不作 I 的门槛（§8 判读边界）。

背景比较：“只在M有作用”= M 档为明显推动/抑制、N 档为弱；反之亦然。两背景都不是“明显”时不作背景依赖结论。

阈值性质：0.05 与 5/6 是开跑前冻结的描述分档线，不是统计显著门槛；不在看到数据后调整。CPU 测试须在合成数据上同时演示每一档可以成立、也可以不成立（§10、项目6.2）。

CFM-LOCAL-READOUT v1 结果报告

日期：2026-11-01。方案 r3；合同 r01；决策日志。代码提交 227cd54；freeze-r01 sha256 099f1e4e…cebf（122 文件）。同一助手完成实现、运行与本报告，不是独立复核。

1. 结论（坏消息先说）

按冻结判据，两种背景下删除第13层旧状态×读系数交互 I 都是“弱”，删除该层全部局部 S/F 变化 J 也都是“弱”；不作背景依赖结论。

  • 原生后半段 N： 删 I 后 D 变化每情景 ±0.031 logit（逐输入只取 −0.0625/0/+0.0625，即 D 在该量级的分辨率台阶），正 2/6、负 4/6；针效应尺度 G=17.5–20.0。删 J 也只有 −0.125 至 +0.188。8 个原生首步停止的输入，删 I 或 J 均无翻转。
  • 统一浅层 M： 删 I 使 D 每情景降 0.16–0.59（6/6 同向），但只占针效应 2.5%（中位数，阈值 0.05），且只在 2/6 情景超过两个同幅随机方向（随机 |δ| 0.06–0.81）。删 J 降 0.09–1.56，中位比 4%。唯一的 EOS 翻转（VRD04-f1）来自随机方向 Q0，不来自 I。

按方案 §8“δI 和 δJ 都小”分支： 在其余有针历史固定的单层、单步反事实下，第13层这一位置对首步停止竞争不敏感，或其作用被下游补偿/冗余吸收。撤回“第13层该交互是原生停止效应的承载项”这一候选；不能据此说整个 S/F 机制无关，也不推出效应分布在多层（集中在别处、抵消、冗余仍无法区分）。按项目 6.7，这是执行正确、假设在其适用范围内被否证的科学负结果（N 背景测量分辨率约 0.06 logit，相对 G≈19，否证是紧的）；不是合同执行失败。
