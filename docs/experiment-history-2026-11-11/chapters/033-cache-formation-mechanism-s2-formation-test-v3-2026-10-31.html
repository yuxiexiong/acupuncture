4. 模块A的关键：直接检查“旧的那份状态”怎样被处理

针对00/01，b处整套历史完全相同；针对10/11，b处另一套历史也完全相同。分别在每条实际轨迹上离线计算：

[ S_t=H_t+N_t,\quad H_b=S_b,\ N_b=0, \quad H_t=A_tH_{t-1},\quad N_t=A_tN_{t-1}+B_t. ]

其中(A_t=\alpha_t(I-\beta_t k_tk_t^\top))，(B_t=\beta_t k_tv_t^\top)。H是b处已有状态经本条实际算子序列处理后的分量；N是b后写入并经后续处理的分量。二者只做离线来源标记，不送回模型。

  • 00与01的ΔH：相同起点S_b经不同的真实后段A序列处理后留下的差异。若超出误差，则反驳“该旧来源状态的变化完全来自本步B增加”这一纯加性解释。
  • 10与11同理；比较两个ΔH，判断后段处理作用是否依赖前段形成的历史。
  • ΔN不能全叫“写入变化”，因为N中的新信号也经历后续A。继续用S1的逐步账目区分ΔB和ΔA作用，并记录抵消。
  • 对实际q同时记录Hᵀq、Nᵀq；跨条件q也会变，需另列查询变化项。H差异不等于它已经影响最终答案。
  • H不等于“事实知识”：b前含模板、格式及事实；事实可能在b后再次写入。区段标签只表计算来源。

新认识来自实际ΔH/ΔN及读取方向是否符合事前预测，不来自S=H+N恒等式本身。 若H完全相同而N分离，则此时窗的“重塑旧来源状态”解释不获支持；不能据此排除其他时段或后续新写入的修正。

5. 模块B：不拼接变量，检查写入/旧处理分账是否稳健

仅时序四格不足以解答W/R。对通过S1关口的锚点，增加原针强度路径λ∈{0,0.25,0.5,0.75,1}，在整个原前缀使用λ×原校准加法，τ后撤针。λ=0/1复用C/T；中间点是新观测，不用来挑“更好剂量”。校准基准固定，不能随λ重校准。

每个λ由原始输入完整前向，保存S1驱动量和τ处完整有效状态M(λ)，供S3使用；大张量按项目资产规则保存、Git保留清单与哈希。不得用端点张量线性插值代替中间前向。

对相邻两个λ的真实轨迹，以S1对称记账递推：

[ Z^W_t=\bar A_t Z^W_{t-1}+\Delta B_t,\qquad Z^R_t=\bar A_t Z^R_{t-1}+\Delta A_t\bar S_{t-1}. ]

零初态下(Z^W_\tau+Z^R_\tau=\Delta S_\tau)。跨λ小段再求和，重建端点差异。β/k变化同步进入ΔA和ΔB，不另造value，不把同一变量声明为某个过程专属。

输出每小段的两个矩阵分量、读取投影、衰减与定向修正细分、向量抵消、逐情景反例。求和恒等式不证明独立因果；它定义的是“沿原针强度路径、按此计算式分账”的结果。

4. 三本相互校验的账：具体拆解什么

采用与S1一致的key×value方向：S_t=A_t S_(t−1)+B_t，A=α(I−βkkᵀ)，B=βkvᵀ。以下都是离线分析真实轨迹，任何分量均不送回模型。

4.1 同一起点的旧来源处理：直接回答“旧的那份信号有没有被不同处理”

在每条轨迹上设 H_b=S_b,N_b=0，后续 H_t=A_t H_(t−1)、N_t=A_t N_(t−1)+B_t，核验 S=H+N。

  • 01/00在b的S及完整前史相同；11/10也相同。各对的ΔH只能来自b后实际A序列不同，不能由纯加性B直接产生。ΔH高于误差即排除“相同旧来源状态受到完全相同处理”的解释。
  • ΔN包含新写入和之后对这些新信号的处理，不能改名为纯写入效应；须继续看4.2的逐步账。
  • H是计算来源，不等于事实知识。相同前史配对的ΔH可以是间接影响后的算子变化：这不识别A的上游独立因果来源。
  • 10/00的b起点不同，不能将它的ΔH全部说成处理改变。对此主要用4.2。
4.2 在撤针边界区分旧差异传递、新写入差异、处理差异

对每一预定成对轨迹，记Δ为第一条件减第二条件、横线为两者平均。在边界c设：

D_c = ΔS_c,  W_c = 0,  R_c = 0
D_t = Ā_t D_(t−1)
W_t = Ā_t W_(t−1) + ΔB_t
R_t = Ā_t R_(t−1) + ΔA_t S̄_(t−1)
ΔS_t = D_t + W_t + R_t

对10/00从c=b开始，回答早针撤除后的形成；对所有三种主要比较再从c=τ开始，回答末提示及固定候选阶段的形成。01/00、11/10从b开始也分账，此时D_b=0，与4.1交叉核对。

  • D：边界已有差异按平均算子传递的账；W：边界后新产生的加性写入差异；R：边界后处理算子变化产生的差异。三者合计重建实际ΔS，实测舍入误差另列。
  • 10在后段已无针，若W仍可分辨，说明早段操作的历史后果会在该目标组继续形成写入差异；不能说这些差异必由“晚段仍开针”产生。它不证明目标组自身反馈，来源可能在上游历史。
  • 若D足以近似实际向量、W/R都在误差内，支持当前窗口的被动延续。若W/R各自大而相互抵消，即使净和小也不能称“没有持续重写”。若R显著而W不可分辨，支持处理变化主导当前新增账，而非新B变化。
  • β/k同时进入A/B，变化同步计入；W/R是指定分解的计算来源，不是独立因果效应。须复算S1的C背景、T背景账；若符号或大小排序依赖背景，明确不可给稳定主因。不能为得到稳定结论改账。
  • 如需细分R，令 P=I−βkkᵀ，用 ΔA=Δα·P̄+ᾱ·ΔP 分别递推衰减和定向修正账，仍是共享变量下的指定分解，不是新增门控实验。正负方向均记录，不沿用只检查正R的late_processing分支。

4. 主要分析一：共同起点后的第一步与旧来源轨迹

采用S1的key×value方向：S_t=A_t S_(t−1)+B_t，A=α(I−βkkᵀ)，B=βkvᵀ。B称加性写入项，不是语义上“新增知识”的净量。共享β/k同时改变写入与扣除旧预测；两项抵消可能只是同一次delta更新的两个部分。

4.1 第一更新步，不混入先前状态分离

对01/00、11/10，预先固定报告t=b+1，不按最大效应或首次显著位置选择。理想共同状态S_b下：

ΔS_(b+1)=ΔA_(b+1) S_b+ΔB_(b+1)。

分别测量B的变化、A对这同一份S_b的作用变化，以及它们的方向/抵消。实际核验始终用完整式 ΔS=ĀΔS_b+ΔA S̄_b+ΔB，把可分辨的起点差异与重建误差列出；不能直接丢掉残差来制造同起点结果。

  • ΔA S_b非零：处理算子变化确实作用到了这个共同旧状态；不是仅因两条轨迹此前状态不同。
  • ΔB非零：该步加性写入项不同；不代表产生了独立的新语义内容。
  • 两项都变：共同起点这一更新同时包含两类变化，不能按较大项判独立主因。
  • ΔA非零但ΔA S_b不可分辨：算子变了，但没有在这份旧状态上分辨到作用；不得等同“旧信息已被改变”。

这比不同历史末态比较更严格，但仍是自然共变下的过程拆解，不是只改A或只改B的反事实实验；同token的跨层传播也包含在真实A/B中。第一步无可分辨效应就如实记录，不把后面最大效应步骤改称第一步。

4.2 逐步追踪同一份旧来源，而不是只看终点

各实际轨迹从b设 H_b=S_b,N_b=0，递推 H_t=A_t H_(t−1)、N_t=A_t N_(t−1)+B_t，逐步核验S=H+N。H标记b时已有来源；N标记b后写入来源。两者只做离线分析，不喂回模型；H不等于事实知识，N也不等于新知识。

对两种同起点配对，每一步报告：

u_B,t   = ΔB_t
u_H,t   = ΔA_t H̄_(t−1)
u_N,t   = ΔA_t N̄_(t−1)
ΔH_t    = Ā_t ΔH_(t−1) + u_H,t
ΔN_t    = Ā_t ΔN_(t−1) + u_N,t + u_B,t

由此分清：当步改变加性写入，处理变化作用于b时旧来源，还是作用于后来写入的来源。各步u及ΔH/ΔN全保留，报告范数、有符号读取投影、起止位置和抵消；不以整个窗口只剩一个总值替代。

H变化说明共同旧来源沿实际算子序列受到了不同处理；它不证明处理变化是原针的独立原发机制。早先写入变化可能通过后续计算影响A，H分解仍条件于各自真实驱动。H末态相等不能排除途中不同；逐步H相等也不证明A完全相同或对其他信号没有影响。

5. 主要分析二：早段撤针后的逐步变化

对10/00从b后起，逐步记录 ΔB_t、ΔA_t及其实际作用 ΔA_t S̄_(t−1)，直到τ、t_L及各固定候选位置。10/00在b不共享状态，不能套用4.1，也不能把它的ΔH全称为处理变化。

若10撤针后仍有ΔB，则说明早段操作足以在该条件、该位置造成后续加性写入项差异，排除“形成这种差异必须有后段针在场”。逐步处理源项同理报告。它不识别源头究竟是哪类上游缓存、不证明目标层局部自反馈，也不证明这些变化对回答必要。单个位置非零不命名为整个后续阶段“持续重写”；必须给出覆盖位置及衰减/间断情况。

三项累计账降为辅助摘要。对指定边界c（b或τ）设：

D_c = ΔS_c, W_c = R_c = 0
D_t = Ā_t D_(t−1)
W_t = Ā_t W_(t−1) + ΔB_t
R_t = Ā_t R_(t−1) + ΔA_t S̄_(t−1)
ΔS_t = D_t + W_t + R_t
  • D是平均算子下传递的边界差异，不是“干净规则下的纯被动遗留”。
  • W也经过后续算子处理，不能称纯写入独立效应。
  • R作用于每步当时的全部状态，包含b后新写入的内容；它不是专门处理原始旧记忆的账。共同起点的旧来源应看第4节H/u_H。
  • W或R末态小，可能来自时间抵消或衰减，不能判途中没有该过程。两项合计小也不说明各项小。
  • 不以累计W/R或D接近总差异认证“被动延续”。只有逐步源项均未分辨，且原始算子/写入检查与整段差异传递相容，才可说“在所测轨迹、时窗与精度下，未发现偏离共同算子传递的证据”；不能证明精确为零。算子不同但作用落在零空间时，还须区分算子不变与对当前状态作用未分辨。

保留S1的C背景、T背景及对称账作为敏感性报告。改变背景改变份额时，直接记录约定依赖；即使三种账结论一致，也不自动升级成独立因果贡献。α衰减与β/k定向修正细分仅是可选离线附表，不扩展门控实验，也不替代主要的共同旧来源检验。
