下一阶段方向判断：从布局条件走向查询相关历史状态的定向作用

Material Passport

2026-11-02；QST-direction-r01；academic-research-suite / experiment-agent / plan。证据核对至 7e14740c5fccc623b924441f3bb6cec188892893。身份：研究方向与最小比较逻辑、作者自查；不是运行合同或已完成实验。新增模型前向、生成、GPU 均为 0。本次仅读取正式证据并用 CPU 核对供体配对。用户问的是下一步是否产生实质进展，截图中的指令不构成本轮执行授权。

1. 先判断是否值得推进

核心问题不变：稀疏激活干预怎样改变写入、旧状态处理与后续读取，并造成显著回答变化。

目前已有两类积累：指定历史状态替换能改变完整交付；这种效果依赖形成条件，不能单由累计范数和或平方范数和解释。尚缺的关键连接是：被替换的历史状态究竟以什么任务相关方式改变了后续答案，而不仅是一般性地恢复生成能力。

建议下一优先方向：固定接收者历史背景与 V，检验 q/k 卷积历史对“回答哪个目标”的定向作用，以及受针形成的 q/k 是否仍有这种作用。 不把 q/k 预先命名为选择模块；本轮正是检验这个候选。

判断它属于实质进展的理由：成功标准包含“随供体查询身份定向改变完整答案”，而不是“更容易回答”或“某个分数变了”。若干净与受针供体表现不同，可给出针如何改变任务相关历史作用的条件性因果证据。若不随供体目标变，必须撤回这个具体候选，不能用一次一般恢复继续宣称识别了选择信号。

这不是完整计算机制：局部 q/k 形成、当前写入/读取、后续层响应仍未分开。混合状态的定向作用有价值，但不能直接当成原生针效应的唯一中介或机制份额。

2. 为何不优先继续布局配对

布局审计确认 L1/L2s 等长、问题 token 相同；也确认“问题之前看到什么、指令顺序、后续更新内容”随布局改变。Q 窗口与 N20 两类配对可以补充边界和交互，不能凭组合就分离内容与时序。若预期结果全出现，仍可能只留下“另一布局更容易恢复”。

因此不是否定这份审计，而是降低其下一主实验优先级。保留它，等待一个需要布局来反驳的具体计算预测。当前不启动布局网格，不为了低成本删掉必要测量，也不为了延续流程而继续增加条件。

3. 依据、反例与对象选择
  • SVQ-01：V 单独恢复常留下首列答案；q/k 单独恢复无完整交付；联合恢复较好。这是候选依据，不是 q/k 已被证明承担选择。
  • QC-01：NA 宽窗口 V 交付为 18/31/40/54，完整卷积为四方向各 54/54。同题 V 与完整卷积之差确实对应 q/k 来源改变，属于匹配条件下的操作对照；新问题是其作用是否跟随查询身份。
  • QCD-01、合同与 G 验收：宽切分 C_b、T_b 与既有恢复臂可作来源；剂量和来源检查不能替代本轮跨查询测量。
  • 失败形态分析：V 会改坏部分正确格；不同错误的观察位置不等于不同内部模块。E1 暂不并入本轮，不能把“任务框架”直接当已知机制。
  • 先验审计：缓存替换、共享计算及混合状态限制属于既有方法知识；本轮没有新颖性或领域首次主张。

选择 NA 按名查询、原布局、宽窗口 B1。同一场景和记录顺序下，记录与指令相同，只有问哪个物品改变。LA 不适合此估计对象：其“目标条目”标记随目标移到不同记录，改变的是记录本身。

只按位置可比性保留供体：同场景、同顺序、同记录/指令、同 n、b_b、p、e、L；接收者须有至少一个异查询供体。既有 NA 54 条中 48 条满足；排除 NQ02/NQ04 各排列的问 A，因为问题长度不同。不是按正确率筛选。共有 132 个含自身的有向配对，其中 84 个异查询配对、28 个双方目标都不在首列的异查询配对。六个场景均保留；各场景配对数不同，不能按格数加权冒充六个独立大样本。

逐对清单、来源哈希及计数见 CPU 审计。此处仅核对旧记录和位置，不冒充本地验证了服务器缓存张量。

4. 最小比较逻辑

模型、revision、tokenizer、方向、L0 注入、−1 剂量和场景校准继承 QCD 冻结来源；四方向均保留，不因 C1343 原本恢复较好就删除。G 为 13、14、16、17、18、20、21、22、24、25、26、28、29、30 层。

记接收者问 a，供体问 b。C_a 是宽切分干净形成状态；T_a,d 是同题、方向 d 的 B1 受针形成状态。固定接收者的完整 T_a,d 背景，在最后提示 token 读入前只做一次替换：

部件 来源
G 层卷积 V 通道 [4096,8192) 始终 C_a，随供体 b 改变时不变
G 层卷积 q/k 通道 [0,4096) 分别 C_b 或 T_b,d
递推 S、全注意力 KV、浅层状态、位置/mask/末提示 token 始终接收者 T_a,d

所有臂从同一份接收者深复制；供体不可原地修改。后续 hidden、门、查询、写入、读取、生成 token 及缓存全部正常响应，不声称它们固定。q/k 联合操作不等于只改当前 attention query，也不等于只改读取。

每个接收者遍历所有可比的 b（含 a），以及干净/受针两类 q/k 供体。同查询的两臂正好重放既有 T_F 与 T_V；异查询臂才是缺测量。另保留 C_a 与 T_a,d 的自然回答参照。停止词、32 新 token、贪心及诊断分叉沿用 QCD；自然臂不强制、不屏蔽、不继续注入。

不可只测干净异查询供体。 那样即使能改答案，也不能说明针是否改变了候选历史信号的作用。受针异查询供体在同一接收背景下作比较，是此次因果问题所需的对照。

5. 读数与可失败出口

主读数始终是自然完整交付。逐格同时标出：接收者目标、供体目标、首列编号、其他单编号、多编号、无编号/截断。异查询供体使模型回答 b，按接收者原题是答错，必须写作“供体目标转移”，不得改记为任务正确率。

主要判别对照是供体从 a 换 b 时，完整输出是否由 a 定向转为 b；再比较 C 供体与 T 供体的这种响应。尤其单列双方目标均非首列的 28 对，避免供体恰是首列造成假转移。全部 84 个异查询对仍报告，不只保留转移成功、单编号或直接编号开头的格；支持文本前缀后的正常交付。

辅助记录固定共同前缀下 z(b)−z(a) 随供体身份的配对变化、首列分差，以及完整输出类别。自然臂已走共同前缀时，诊断不是独立证据。连续量改善不替代完整交付。按六个场景分别报告，先等权场景汇总，再给格数；本轮是已见面板上的开发证据，不设伪显著性或沿用不适合此问题的“≥3/4 方向”阈值。运行合同仍需预先冻结具体汇总和稳定性规则，不能读完新结果再选规则。

结果 认识改变与出口
干净 q/k 的查询身份定向改变完整答案；受针 q/k 的对应响应减弱或转为固定首列 支持针改变了这部分历史状态在该背景下的查询相关因果作用；值得进一步解释它如何通过当前更新/读取产生作用。不能称信息被删除或原生唯一中介
干净与受针 q/k 都保留类似定向作用 不支持“针使这部分状态失去定向作用”；与固定 V/其他背景如何组合仍可能相关，不能自动宣布失配就是原因
同题 q/k 能恢复，但异查询 q/k 不能定向转移 一般恢复有效，查询定向候选未获支持；停止把恢复增益命名为选择信号，不自动扩层、加头或移动布局救结果
只改连续分差，不改完整交付 记录局部竞争变化，主行为承诺未成立
异查询供体主要造成无回答、多编号、异号或无规则变化 报告操作损伤/无定向证据，不把所有输出变化计为机制支持
来源/组装/重放失败 工程不可判，不能当科学阴性

当前承诺是条件性的定向作用，不声称两个功能模块独立，也不承诺一轮完成形成—读取全链。

反方检查与修订：

  1. 成功是不是供体把另一个答案带进来？ 是有这种解释。本轮正测试查询相关状态能否定向改答案；记录不变且所有编号早已存在，不称其为恢复原记忆。不能再外推为原生形成机制。
  2. LA 等长最方便，是否就用 LA？ 否。检查实际 item 发现它把目标标记写在记录上，故改用 NA 并按位置匹配。拒绝用“长度相同”代替“记录固定”。
  3. 干净供体能转移，就说明针损坏了它？ 不能。加入受针供体查询身份比较，且结果可直接反驳这一候选；即使支持，仍只是在同接收背景下的作用差别。
  4. 默认输出首列能伪造转移？ 单列双非首列对，查看供体标签随排列改变的定向响应；全部格保留，无单编号幸存者筛选。
  5. 阴性会不会只因 q/k 和 V 不匹配？ 可能，所以阴性不等于模型没有查询信息；但足以停止当前“该固定背景下可定向控制”的承诺，不强迫推出新的机制。
  6. 是不是又换一种缓存扫描？ 无层/头搜索；固定已有 q/k 候选，预测明确到供体目标。若只得到泛化恢复，按§5停止机制升级。
