直接复用冻结的原 trace_engine.py，不修改生成或观察算法。每条记录使用原 prompt、校准、同一通道/剂量及原始 BF16 偏移；BF16/eager、greedy、batch=1、thinking 关闭、原 EOS、最多 128 新 token 均不变。输出必须与旧来源逐 token 一致，不续写或为语义结果重试。

6. 解释边界

L0–L5 是统一的观察窗口，不预设自然功能边界，也不把 L5 视作经过验证的分界。2B 共24层，4B/9B各32层，保留绝对层号和相对深度；同层号、同通道号或三维邻近不等于同源功能区。

4B全层追加用于比较不同深度的传播和输出变化。相似轨迹、差分峰值、停止倾向和词汇变化仍是机制线索，不能单独证明因果根因、人脑式功能分区或道德/安全神经元。无相似规律和反例同样保留。

早层干预怎样传播到输出：现有轨迹分析

2026-10-28；状态：ANALYZED，描述性分析。本次仅在本地读取已核验归档、计算统计和查看原三维工具，没有运行模型、新实验或远程计算。结论适用于现有点位、剂量和八个固定问题。

最明确的发现是：早层写入经下游组件改变下一 token 的竞争关系，随后分成提前停止、持续被干预推动的循环、错误历史支持的循环，以及内容偏离但句式仍在等不同过程。 当前不能把这些过程合并为一个“完整语句开关”，也不能由颜色最大的一层认定根因层。

数据和比较方法

从已验收的 7,632 条正式记录中，取四模型注入 L0–L5 的全部 3,680 条：每模型 920 条，其中 912 干预、8 原版。每层十个通道的 +1 剂量有 80 条；其中一个通道另有正负五档剂量。十点 +1 与单点剂量系列有重叠，不能当作两组独立重复实验相加。4B 更深层这次未纳入结论。

入口：归档总验收、全量早层统计、复算脚本、4B 个案及原证据链接、跨模型个案及原证据链接。逐条逐步派生数据保存在 features.jsonl.gz；没有改动原始结果。

三维颜色比较的是相同输入 token 历史下，干预分支与完整无干预分支的组件输出差异。后者使用独立 cache，被强制读入干预分支已经生成的 token；以下简称“同前缀无针参照”。它与页面中的“原版自由生成回答”不同，也不是中途拔针继续生成的实验。

沿深度读图与沿生成时间读图必须分开：固定“提示末位”可追踪首个输出 token 产生前的全层变化；再移动生成位置，才能看到后续 token 如何继续偏离。所有 step 从 0 编号，step 2 是预测第 3 个输出 token。首处预测分叉采用实际 token 的 clean logit 严格低于 clean 最大值，而非 top-k 列表第一个 ID 不同，避免 BF16 并列最大值误判。

1. 差异从哪里开始：首先确认观测没有混入错误前缀

3,648 条干预在首预测位置的第一处差异全部是注入层 MLP。更浅层以及注入层自身的 attention，在所有已观测 prompt/生成输入位置差分都严格为零。32 条原版控制在全部站点、全部位置差分严格为零。

这符合注入位置与模型的计算顺序，首先是对照和采集一致性的证据，不是发现了一个 MLP 功能区。从下一层开始，attention、MLP、残差都可变化；这表示扰动进入了后续计算，但仅凭各站点范数不能分配各分支对最终错误的必要贡献。

另一个重要校准：本实验的单通道注入经过 down_proj 后，设计上的向量长度约等于 |剂量| × 原版该层残差标定尺度。实测 MLP 差分与该设计值的比值为 0.9928–1.0077。因此“只改一个通道”指空间位置稀疏，不意味着幅度很小；±1 已经是整个残差标定尺度量级。MLP 很亮还可能因为原本 MLP 输出范数较小。

B. L2 N5063，+1：持续干预反复把退出方向推回循环

首预测位置，L0–L1 和 L2 attention 均为零差分；L2 MLP 差分 3.404，L3 attention 为 8.851、MLP 为 6.943、残差为 7.655，L31 残差为 65.039。输出首选从“第一步”变成 <think>。

然后出现 〈think〉→双换行→〈think〉→双换行，共 64 个 <think>、128 token，触及长度上限。上限本身不是失败证据，明确的重复原文才是。

把三维时间轴移动到 step 2，即已经读入 <think>\n\n 后：同前缀无针参照首选 </think>，实际 <think> 在其下还落后 5.938 logit；干预分支却继续选择 <think>。后续 63 次再次产生 <think> 时，无针参照首选全部是 </think>；包括首步在内，64 次 <think> 都不是其最优选择。

因此这条轨迹具有反复推向循环 token 的证据。它不仅仅是“第一步走错，后面自然重复”。但分支之间包含完整干预历史与不同内部 cache，不能把这个差异进一步偷换成“本 token 单次注入的独立贡献”。

4. 当前已经看清什么，根因还差在哪里

已经看清三个层次：差异首次出现在何处；哪些后续组件的输出发生变化；哪一步 token 竞争翻转并形成何种实际回答。 一些循环在错误前缀上仍受到干预推动，另一些则连无针参照也支持继续重复。这是现有跨模型结果里最具体的共同过程线索。

解释边界核对：

  1. 样本不是独立抽样。 同一八题重复用于通道、层、剂量；只做描述统计，无 p 值或总体显著性结论。
  2. 队列不能重复相加。 每模型十点 +1 有 480 条，单通道正负剂量有 480 条，二者交叠 48 条；独立干预总数是 912。
  3. “一个通道”不等于小剂量。 直接注入预期范数为 abs(dose) × clean calibration residual scale；实测 MLP 差分与该值之比为 0.9928–1.0077。±1 是一个标定残差尺度。
  4. 首变化位置部分由插针位置规定。 首次变化在注入层 MLP 是实现核验，不独立证明功能分区或根因。
  5. 绝对差分增长不等于病理放大。 final_over_injection_absolute_delta 使用绝对差分，但深层原始表征尺度也增长；应同时看 relative、cosine 与输出。大 MLP relative 也可能源于 clean MLP 较小。
  6. 峰值名字要准确。 max_absolute_delta_peak_layers 是 attention、MLP、residual 三类站点中的绝对差峰值层；它不是 residual 专属峰值。relative_peak_layers 同样涵盖三类站点。
  7. 首步与后续步语义不同。 first_sites 为末个 prompt token 的预测位置，尚无生成文本分叉；后续 clean 与 steer 强制同一已生成 token 历史。位置 prompt_tokens - 1 + step 对应该步预测。
  8. clean shadow 不是局部撤针。 它是全程无针、独立 cache、强制相同历史的另一分支；不能据此声称撤针后自由生成必然恢复或继续循环。
  9. 排除 BF16 并列最大值。 strict divergence 要求实际 token 的 clean logit 比候选中 clean 最大值低超过 1e-6；候选并集包含 clean 最大值。仅 token ID 不同可能是并列，旧字段保留供核对。
  10. 输出机械指标不是语义标签。 空白、EOS、长度上限及重复四元组不自动等于乱码、能力损伤或内容错误；重复阶段 clean 支持只表示相同错误历史下该 token 也是 clean 的最大值候选。
  11. 跨模型及层间机制仍有限。 同层号、同通道号、同剂量不构成表示同源；L0–L5 是比较窗口而非已证实分区。现有范数/角度摘要不能恢复向量方向或分配路径因果必要性，曲线与图上相邻也不证明因果连接。
