2. 原报告三处需要收紧
  1. “所有答案完全不变 / J全部0”不能覆盖所有臂。 R0的H_T有一条变化：接收者 NA-NQ03-ABC-C 原题为W19，自供体输出W35；供体换成 NA-NQ03-ABC-B 后输出W19。这个主对照J=0.5、W=0，R0 H_T等权J=1/72≈0.01389。它没有跟随供体目标，稳定转移结论仍为阴性。U与H_C的84/84结论成立，不能扩大成所有H_T也逐token不变。
  2. “q/k张量几乎相同”缺直接距离证据。 qst_run.py保存到pt的是生成首步、第二步及诊断logits字典；归档没有给出q/k跨查询距离。小输出变化与未转移也可能来自读出不敏感、冗余或替换背景，因此应写“在指定替换下输出对供体查询身份不敏感”。有限精度间距不是已经测定的误差/噪声上界，0.25不能直接当可忽略噪声。
  3. “S和全注意力KV里显然有查询信息”是定位过度。 恢复后能答原题说明整个接收背景保有可供利用的任务约束；本轮没有分别定位到S与KV，也没有排除浅层/当前输入条件的贡献。“需要干净q/k”也不是必要性定理：C1343的受针q/k同样48/48。准确说法是：在有恢复差距的三个方向，测试过的同组干净供体均能补足差距，正确查询身份并非这些成功恢复的必要来源条件。

本文件保留旧报告作为历史证据，以上更正作为新的审读口径，不改冻结记录。不能把“末端投影候选阴性”推成“问题未编码”“信息已删除”或整个课题失败。

3. 下一步的取舍与核心问题

主线不变：稀疏针怎样改变写入、旧状态处理和读取，最终产生大的回答效应。

推荐QCO-01：检验受针形成的末端q/k变化是否含有跨记录可复用、能恢复并重现原有回答效应的共同加性分量。 这比“看哪些层差最大”更直接：结果需要由其他场景构造的编辑提前预测本场景的完整回答变化。不是因为QST阴性就自动扩层，也不继续寻找供体查询身份转移。

具体候选：对每种既定针方向，其他场景的平均受针−干净差，若是实际起作用的共同分量，那么从本题受针q/k减掉它应补回一部分V-only的交付缺口；向本题干净q/k加上它，应重现一部分V-only的原有错误。等范数随机方向若同样有效，则不能归因于这份共同偏移的特定取向。

阳性最多提供跨记录可搬运的状态差分及其双向行为作用，不是低秩定理、完整计算机制、原生唯一中介或无损修复方法。阴性结束“单位强度共同均值偏移足够”的候选，不自动转去调倍率、PCA选秩、挑层/头。原报告建议的逐层几何可作为描述表，但不作为下一轮核心终点，也不依它挑干预位置。

四槽原始q/k每状态14×4096×4个BF16，240份约105MiB。CPU上转FP32计算差分/均值，不需要新模型调用；但取得这些状态需要模型形成前向，不能把整个阶段称作零GPU。

5. 不用本场景估计的共同偏移

对输入i、方向d、层l、通道组g∈{q,k}、有效槽t，记卷积历史为Q_C(i)、Q_T(i,d)，Δ(i,d)=float32(Q_T)−float32(Q_C)。

六个基础场景分六折。接收场景s的偏移：

μ(-s,d) = (1/5) Σ[r≠s] mean_{i∈r} Δ(i,d)。

每场景先对其所有可比排列/查询取平均，再对五场景等权，避免有9条的场景比6条的场景权重大。本题及同场景的任何查询、排列都不参与其μ。六折、四方向全部使用；只排除相应场景，不根据答对/错筛训练条目，不拟合倍率，不改符号。所有μ与来源清单在任何新编辑输出前冻结。

这是已见开发面板上的跨场景构造验证，不是未见题外部确认，六折也不是独立六次实验。每折一个高维固定偏移不等于已证明低秩。

描述项固定为：逐层/逐qk/逐有效槽的Δ范数、μ范数、cos(Δ_i,μ_-s)、||Δ_i−μ_-s||²/||Δ_i||²；零分母记NA。不挑最高层、不选最佳折，不以相似度高自动当行为因果证据；几何弱也不修改既定行为测试。

每个输入i、方向d固定接收者其余状态为T(i,d)，G卷积V均取C(i)。S、KV、浅层与位置/末提示token在分叉起点固定；之后所有变量正常响应。q/k变化也影响当前写入和读取，测总效果。

7. 完整交付、判据与退出

主终点沿用QST冻结Y_full：旧Y_delivery成立且stop、无未闭合think。编号前文字不剔除；多编号、截断和错误保持在分母。保留全部token、原文、旧Y_delivery/Y_strict、首列/原题/其他/多编号/无编号及改坏格。连续辅助为共同前缀下目标相对首列的logit差（原题即首列时NA），并列目标相对最强其他候选差；不以分数恢复替代完整交付。

按六基础场景先求输入均值，再场景等权平均，记E_s。每方向：

  • 缺口G=E_s[Y_F−Y_V]；同时公开48输入原始总数。若G≤0或不足4个场景有正缺口，不判“跨场景补足缺口”，完整结果仍报告。QST已有缺口N4146=32/48、N1210=20/48、R0=10/48、C1343=0；对应正缺口场景数6、6、4、0。新运行需重放，不重新选方向。
  • 恢复份额P=E_s[Y_R−Y_V]/G；随机参照P_rand同式。净差包含把原来正确格改坏的代价，不能只挑V错误格计算成功率。
  • 预定错误集合D_i=1[Y_F=1且Y_V=0]。原错误重现份额B=E_s[D_i·1(ids_A=ids_V)]/E_s[D_i]；B_rand同式。必须重现原V自然生成token序列，泛泛答错、多列或停止增加都不能冒充原失败模式重现；同时报告较粗错误分类作描述。非D输入被A改坏也全部报告。

“共同偏移搬运了可观的双向行为作用”须同一方向同时满足：工程与参照通过；G适用；P≥0.5、B≥0.5；P−P_rand≥0.25、B−B_rand≥0.25；至少4/6场景R−V净交付>0，至少4/6场景出现原V错误重现。阈值是事前最小实质效应/跨场景规则，不是显著性或统计功效保证。四方向逐一报告，不设跨方向多数通过。

结果 结论与分支决定
双向与参照差均达标准 支持其他场景估计的共同差分可部分解释该背景的行为变化；下一问题才是它通过什么更新/读取计算起作用，不自动宣布原生机制闭环
只R恢复，A不重现 共同校正可补偿，尚未解释原有错误的生成；不能当充分机制或直接扩层
只A重现，R不恢复 加入此偏移可扰动该混合背景，但去除不足；不称主要承载者
R/A与随机参照相近 不支持所提共同方向的特异优势，可能是更一般的状态扰动；不从一个随机参照推整个随机总体
几何相似但行为无效，或仅分数改善 结束“均值偏移足以搬运回答效应”的候选；不PCA选秩或调幅救结果
C1343无缺口，或少于4场景可判 报告无恢复空间/范围不足及新增损伤，不删方向、不凑平均
来源、公式组装或实际范数配平失败 工程不可判，保留结果和失败，不冒充科学阴性

精确token重现是本轮较强承诺；可能因措辞变化而未通过，届时报告类别级描述，不事后把主终点降级。即使全部成功，也不能称查询信息被删、所有针共享一个方向，或复述/选择已分离成独立模块。

8. 工程顺序、完整预算与授权

E预检固定两输入NA-NQ01-ABC-A、NA-NQ02-ABC-B，覆盖两种长度、四方向；各形成C+四T。每输入C、四T_nat、四V、四F共13条，再做四方向V/F的零偏移无操作各一次共8条；两输入共42轨迹，验证新编辑路径无操作、旧来源及参照一致。非零编辑公式/种子/仅改三槽/符号/权重/无别名在CPU合成张量测试；保存重读原始q/k须逐位相同，不额外模型前向。
