1. 目的与能增加的认识

主线不变：解释稀疏激活干预怎样改变历史形成、写入、旧状态处理和读取，最终改变完整回答。

本轮问题：供体历史对答案的作用，是会随它实际形成的写入差值一起迁移，还是固定同一份差值后，仍强烈依赖接收运行的背景？ 两者可以同时成立；不要求把整个针效应分成互斥、可相加的自然机制份额。

SPF 已有缓存级背景依赖；DWB 已有受针相关背景中一次指定供体写入的作用；DWC 已有同端点的后续读取确认。只补一个干净背景的供体臂，仍把“生成了不同信号”和“对信号的响应不同”混在一起。本轮固定实际加到状态上的写入差值，补上两类条件的可干预比较。阳性最多支持指定混合背景内的可转移写入效力／背景响应；不自动解释原生停答、纯读取作用或唯一自然路径。

这不是新写读公式或首次缓存编辑。近邻 WriteSAE v4已有写入替换，How Linear Attention Remembers已有写入和读取因果分析，Who Asks, Who Answers已有检索查询与状态移植。这里争取的是受针后同一来源选择关系的具体解释增量；本轮核查作者原始摘要并沿用先前相关章节审计，未独立复现或宣布穷尽首次性。

3. 接收背景：两个都能正常作答

对接收输入 i，在 t1 前形成：

  • C： 完整干净缓存。
  • H： 受针缓存 T，但 G 层整个卷积缓冲 q/k/V 换回本输入的干净缓冲。其余受针缓存不改。它就是 DWB 的 OO 背景。

C/H 在 G 层起点使用同一份自身干净卷积历史；H 不是原生受针 T。当前输入、递推状态、其他层及 KV 等仍可不同。两者的无供体参照分别记 U_C/U_H；不以原生停嘴作为利用侧比较的地板。

不改变写入 k，不移植整份供体 S，不留存供体卷积历史，不添加 DWC 的 k 去偏移。t1 之后所有分支自由响应，无进一步钩子。任何分支首 token 停止也保留在计划分母中。

4. 如何生成一份可固定的写入差值

对每个相同的接收者 i／供体 d 配对，分别从 C、H 跑一次来源参考 R_C/R_H。沿用 DWB 的 DO 定义：在每个 G 层，以当前分支输入和供体干净 V 历史计算影子 v_d，原生 v_o 来自本分支实际缓冲。影子不写回缓冲。

在同一次层调用、相同输入／旧 S／q／k／β／衰减下，用原冻结 kernel 顺序计算两份局部后状态：

  • S_native：v_o；
  • S_shadow：只在新值写入中使用 v_d；旧状态处理及其他量相同。

来源参考实际继续使用 S_shadow 和与它一致的当步输出。即时记录该层差值：

ΔW_s(l) = FP64(S_shadow) − FP64(S_native)，s∈{C,H}。

它在实数条件下对应 β k (v_d−v_o)^T；实际保存的是 FP32 kernel 后状态的 FP64 差，包含有限精度差别，不强行压成秩一近似。两份 kernel 计算都是当前局部输入上的计算，不是拿两条完整轨迹的末态 S 相减。来源参考的上游层已经受到自己的供体写入影响，因此这是一份按来源轨迹生成、可重放的 14 层差值集合，不是脱离背景的纯语义向量。

与实数写入公式的差异必须记录并满足 FP64 oracle 归一误差 ≤1e−5；这用于工程正确性，不作机制证据。

5. 四格交叉怎样执行

对每个 i,d，各来源差值集合只生成一次并锁定。同一份文件用于两个接收背景，绝不按接收者重新计算、缩放、归一化或翻转。

从接收背景 r∈{C,H} 的 t1 前缓存独立深拷贝重新前向。到每个 G 层时，先按该接收分支当下的输入与缓存计算原生 S_native,r，再执行：

S* = cast_FP32(FP64(S_native,r) + ΔW_s(l))。

当步输出严格从同一个 S 与当前接收分支的归一化、缩放后的 q 计算；持久递推状态也存 S。不将“修改当步输出”和“修改留存状态”拆成两套值。更高层输入、q/k/v/β、KV、卷积新槽和后续生成均正常响应。

接收背景 r \ 差值来源 s C 来源的 ΔW_C H 来源的 ΔW_H
C F_CC：同源重放 F_CH：交叉
H F_HC：交叉 F_HH：同源重放

固定的是每一层额外加入的 ΔW，不是最终总状态、后续所有写入或 q。 因此背景比较的名字是“接收运行对固定写入差值的响应”，不能缩写成“纯读取差异”。该响应包括已有状态、当步读取、更高层更新和未来计算，不进一步定位哪个部件。

同源对角 F_CC/F_HH 必须分别重放 R_C/R_H：所有 G 层 S、t1 完整缓存、logits、首 token、自然 token 序列及终止方式一致（只允许记录过的 ±0 位差）。其依据是层序归纳：相同初始背景、相同低层输出时，当前原生计算相同，加回保存差值应恢复来源后状态。仍必须实际数值验收；不能只靠代数口头放行。

7. 主要读数、比较与不确定性

每格复用冻结 SPF d_transfer：接收者内，AL 供体对应行的命中减去其他不预测该行供体下的命中。任何与供体无关的固定答案（含首行／自身／停止）都为零。48 接收者等权平均，与 DWB 相同；6 场景为重抽单位，不是六场景等权改变旧量尺。

F_rs 为该格 D_tr。全部报告下列配对差：

  • 来源差：S_C=F_CH−F_CC、S_H=F_HH−F_HC；固定接收背景，改变写入差来源。
  • 背景差：B_C=F_HC−F_CC、B_H=F_HH−F_CH；固定差值集合，改变接收背景。
  • 交互：I=S_H−S_C=B_H−B_C。
  • 同源差：G=F_HH−F_CC。恒等式 G=S_C+B_H=B_C+S_H 只是量表算术；不算自然机制比例，不以两条分解路径挑更漂亮的解释。

逐接收者先算差，再整场景配对重抽 20,000 次、种子 2026111101：每次有放回抽六个场景，携带其中全部接收者和四格配对，同场景重复抽到就重复计入；在该次所有接收者上等权平均。四格点估计和普通 95% 区间全报；六个上述对比另用同一重抽中“最大绝对中心化偏差”的 95% 分位构造共同宽度区间，减少从多项中挑一项宣称成功。仅六个已见场景，仍是开发性近似不确定性，不能称严格总体覆盖或已做功效充分保证。并列所有场景点估计，不筛选族。

预先定义：有关注量级的正／负差要求上述共同区间完全位于 ≥+.15／≤−.15；实践近零要求共同区间完整落在 [−.10,+.10]；其余为未定。.15 是净转移 15 个百分点的本轮关注尺度，.10 是较小变化带，两者均非显著性定义；小样本可能无法确认近零，届时如实未定，不用“没显著”代替“相同”。同源差 G 未达关注尺度时，不得声称找到了“受针增加来源作用”的机制；四格的条件作用仍可报告。

完整交付护栏： 每格同时报告有效编号、答自身、供体行、其他行、首停、后停、其他／多编号及截断；168 冲突配对另列自身正确。停止／其他不剔除、不延长生成预算。比较若任一格有效完整编号率低于 .90，主选择机制标签降为“交付退化混入，未定”，保留所有连续值。

反例 A：两份 delta 在高层已受各自早期供体注入影响，所谓“信号形成”是否仍混杂？

是来源条件的整个联合产物，不能归因某个单层、β 或原生形成期。四格仍能回答同一组实际增量在另一背景是否保留效力，以及固定增量后的背景作用。已改名为“来源条件改变写入差值的效力”；不承诺独立语义编码或形成中介。边界不破坏当前问题；再拆层不会自动回答更重要问题，因此不增加扫描。

确实不能从这里推出原生停止原因。本卡连接的是论文已有可靠的可作答来源选择端点，检验其中一项解释缺口；NGC 阴性保留。若只允许完整自然全链，本轮会错误排除有价值部分机制；若宣称已解原生失败，则是硬伤，已在结论中禁止。

1. 用人话解释这四格

  • C 是正常的干净缓存背景。

2. 已有结果现在能说明什么
2.1 H的强行为作用，不伴随整体更大的写入差值

对每个配对，将14层差值的平方范数相加后开根，仅作统一的描述性大小汇总。H/C范数比中位数为 0.964，配对10%–90%分位 [0.874, 1.067]；接收者等权均值为0.962。这些分位是数据分布，不是置信区间。

层间也不是统一放大：14层中有11层的范数比中位数小于1，17、18、28层大于1。因此不能用“针让这份信号整体变大了”概括HH独强；但不能由总体范数接近就否定某些层头幅度配置对行为有作用。

两来源差值的合并余弦中位数 0.888。即使给ΔC选择最佳单个缩放系数，拟合ΔH的残差范数仍为ΔH范数的 0.461（10%–90%分位[0.397,0.531]）。这排除了“整份写入只是同方向乘一个系数”的几何描述；0.461不是未解释的行为比例，也不证明方向差就是答案变化原因。

2.2 保存的β把幅度形成中的一个旧缺口补清了

使用保存的β、真实带epsilon归一化的k和Δv，逐层逐头计算幅度数组 m=β‖k̄‖‖Δv‖。这次不需要从乘积反推β。

  • 实际归一化k范数范围约 [0.999718, 1.00000011]；上界略超过1是浮点数值量级，不假设其严格等于1。
  • 从C的幅度配置出发，只代入H的β，接近H幅度配置的程度明显好于只换k范数或Δv范数。

3. 为什么“同一供体”仍不足以固定输入信号

以下为已知计算在明确条件下的推论，不是新模型实验或新公式。对于同一层、同一接收输入、相同旧状态与 k/β，仅改变写入用途的 v 时，供体相对自身造成的状态更新差为：

ΔS_write = β k (v_donor − v_own)^T。

而影子 v 的定义使用当前接收分支的当步输入和指定来源的 V 历史。因此，供体历史相同，并不保证跨接收背景的 v_donor − v_own、k、β 或实际写入差相同。多层联合操作还会改变更高层的当步输入；不能把各层按固定驱动写出的式子相加，宣称已得到整条自然路径分解。

于是，干净与受针背景中的供体效应如果不同，至少仍有两类可共同存在的解释：

  • 形成侧差异： 相同来源对比经当地计算形成了不同的状态写入差；可能涉及方向、内容差及幅度的组合，不能由 NGC 阴性直接命名为“方向主导”。
  • 利用侧差异： 实际写入差相同或可比时，已有状态、读取与后续计算对它的行为响应不同；这也不能仅凭 SPF 恢复作用断言。

下一设计的最低要求，是说明如何区分这两类变化中的一项具体关系，或证明其中一项对有意义的行为对比有作用。不要求两类完整分解、不要求贡献相加为 100%，但不能只换一个背景后用输出差宣称已经分清。 如果设计只能提供条件总效果，就按条件总效果评估其有限价值。

4. 怎样寻找计算关系：从已见差异到其中一个环节

思考顺序是：选取已有且重要的来源作用差异，查明已有证据把它约束到了哪里，再判断哪一段计算联系尚未解释。来源表示、写入、读取及下游响应是可能同时变化的环节，不强制包装成互斥假设。

已知公式可以提供变量，而不能充当发现。例如，在单层单头、相同初始状态及写入 k₁、β₁ 等量固定、仅 v₁ 改变时：

[ \Delta S_1=\beta_1 k_1\Delta v_1^\top. ]

在随后接收者的 α₂、q₂ 固定时，该差异对直接读取用途的局部影响为：

[ \Delta D_2=\alpha_2\Delta S_1^\top q_2 =\alpha_2\beta_1(k_1^\top q_2)\Delta v_1. ]

这里 Δ 表示两个指定局部计算的差，不自动等于完整干净与受针运行之差。公式说明来源区别进入读出需要经过具体写读计算；针在实际运行中改变了哪一项、它是否解释了答案效应，仍是经验问题。 已有操作涉及14层联合写入，高层驱动及后续生成会响应，不能将此恒等式直接解释为整模型因果份额，也不据此预选夹角为唯一原因。

当前寻找的是一段有意义的连接：“针改变了某项明确计算关系，因此某项来源对答案的作用发生变化。”可以先支持这句话的一部分，必须写清已连接的一段、其条件及尚未连接的部分。无需在这一阶段解释其他全部异常或提出完整新理论。

3. 卡时与失败控制
