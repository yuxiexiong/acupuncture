NSR-01 方案：受损深层 S 能否把损伤带进干净运行

2026-11-03。设计稿，未冻结、未实现、未运行，无 GPU 授权。 依据：NCC-01 报告（main 182ed60）及 2026-11-03 讨论。档位：推导＝有论证链；类比＝相邻证据支持；推测＝待验证。

1. 问题

NCC-01 发现：在第一个回答 token 之前，只把深层递推 S 换成干净的，L0（0→48）和 L12（31→48）的完整回答都全部恢复。这说明"恢复 S 足够"，但没有说明受损的 S 本身带着损伤相关的效应。

本轮反过来问：以干净运行 C 为接收者，只把深层 S 换成同一输入受针运行 T 的 S，干净运行会不会出现与原生受损运行相应的异常（停止、错选编号或其他）？两针是否一样？

  • 本轮得到的是双向干预证据中的另一个方向。即使受损 S 让干净运行出错，也不能单独区分"S 单独承载损伤""多组冗余""贴近阈值"和"拼接失配"。§3 的失配对照只能排除其中一部分。
  • 不扫描层组，不拆 S 的内部因子。
2. 已有事实（数据前）
  • NCC-01：C 48/48；L0 的 T 为 0/48（47 条第一步停止，1 条同时给出多个编号）；L12 的 T 为 31/48，17 条错误中 14 条同时给出正确编号和其他编号，3 条只给错编号。
  • NCC-01 的恢复方向：L0 上 TS、TJ 为 48，TV 为 16（开头恢复、答案多选错），TK 为 3；L12 上四个单组都是 48。
  • S 来自干净供体，可能重新带入有用信息，也可能补偿其他受损计算。恢复足够，不等于 S 是唯一损伤源，也不证明受损运行原本完整保存了答案。
3. 操作

沿用 NCC-01 的模型、面板（LVK 新面板 48 条）、两个针（L0/N4146/−1、L12/C3621/−1）、形成流程、切点 τ（处理最后一个提示 token 之前）和生成设置（贪心，最多 32 个新 token，不加针、不挂钩子、不强制前缀）。接收者为同一输入的 C，在 τ 一次性替换以下内容，其余全部保持 C：

格 接收者 来自哪里 用途
CS C 该针 T 的 G 层 S 主臂：受损 S 单独能否带入损伤
CV C 该针 T 的 G 层卷积 V 通道 比较：受损 V 历史
CK C 该针 T 的深层 KV 比较：受损注意力历史
CJ C 该针 T 的全部深层缓存（卷积 q/k/V＋S＋KV） 参照：全部深层受损、浅层干净
CSx C 另一条输入的 C 的 G 层 S（同场景内按 ID 排序的下一条，末条取首条） 失配对照：干净但不匹配的 S，与针无关
  • G、深层 KV 层和 V 通道切片与 NCC-01 完全相同（G = {13,…,30} 的 14 层，KV = {15,19,23,27,31}，V_LO = 4096）。
  • 递推 S 的形状与序列长度无关，所以 CSx 可以直接移植；卷积缓冲和 KV 与位置相关，不做跨输入移植。
  • 为什么加入 CV、CK、CJ：NCC-01 在 L12 上三个单组都能全部恢复。只有 CS 时，如果 CS 出错，无法判断是 S 的问题还是"任何深层组受损都会让干净运行出错"。三个比较格让本轮能看到损伤在各组之间怎样分布。
  • 为什么加入 CSx：它检验"把任何不属于这条输入的 S 放进去都会出错"这一失配解释。若 CSx 与 CS 出错相近，CS 的效应就不能归给针的损伤。CSx 只排除内容失配，不排除"受损 S 与干净浅层之间的失配"。

每条输入的轨迹：C 一条（桥接）；两针的 T 各一条（桥接）；两针各 CS、CV、CK、CJ 四条；CSx 一条（与针无关）。共 12 条。

4. 读数
  • 主读数：自然完整回答 Y（y_full，全 48 条）。每格报告正确数，相对 C 的改坏、改对与净变化，涉及场景数，以及场景等权比例。
  • 异常类型（每条错误归入一类，定义冻结）：
  • 停止：第一步就停止，或输出为空；
  • 错选编号：输出中出现列出的编号，但不含目标编号；
  • 混合编号：同时出现目标编号和其他列出的编号；
  • 其他：没有出现任何列出的编号。

逐类与同针 T 的异常分布比较。L0 的 T 以"停止"为主，L12 的 T 以"混合编号"为主。 - 首步描述（同 NCC-01）：B = z₁[f] − max_{j≠f} z₁[j]，z₁[f]，最高停止 logit，最高非停止竞争 logit，首 token 分类（编号开头、引导语、停止、其他）。首步分差只作描述，不作回答正确性的代理。 - 汇总：逐输入、六场景等权；场景分层 bootstrap（2000 次，种子 20261103，所有格共用同一组重抽索引）给出描述性区间。两针比较用同输入的配对差。不算机制比例，不设"成立/失效"总标签。

5. 解释边界（不是自动选下一轮的阈值）
观察 能得出的认识 不能得出的
CS 出错明显，异常类型与同针 T 相近，CSx 基本不出错 受损 S 能把与该针损伤相应的效应带进干净运行，与 NCC-01 的恢复方向合起来，构成 S 的双向干预证据 S 是唯一或自然的损伤载体；冗余、阈值、受损 S 与干净浅层的失配都没有排除
CS 与 CSx 出错相近 外来 S 本身就足以扰乱干净运行，CS 的效应不能归给针的损伤 受损 S 无作用
CS 基本不出错 受损 S 单独不足以在干净背景中造成该针的异常；损伤需要与浅层、入口或其他深层组共同作用 S 与损伤无关（NCC-01 已显示恢复 S 足够）
CS 出错但异常类型与 T 不同（如 L0 出现错选而非停止） S 带入了部分效应，症状形态由其他部分决定 把类型差异归给某个未操作的部件
L12 上 CS、CV、CK 都出错 多个深层组受损都能在干净运行中造成异常，与 NCC-01"多个修复入口"相应 区分"多组冗余"与"任一组都能造成损伤"以外的机制
L12 上只有 CJ 出错 损伤需要多组共同受损才能在干净背景中出现 指定哪几组

措辞限制：任何阳性都是混合缓存干预的总效果；本轮不做必要性或因果份额主张；结果只限这两个针、已见面板和这个切点。

6. 工作预测（数据前登记，只写方向，不是预定结论）

  • CS（L12）：出现错误，以混合或错选编号为主（推测）。
  • CSx：错误明显少于 CS（推测）。若不成立，CS 的解释按 §5 第二行处理。
  • CV、CK、CJ：不作方向预测，只报告。

10. 自查（作者自查，非独立评审）
  1. 这是否又在局部细拆？ 不是。它直接延续 NCC-01 的原生连接，检验 S 能否把损伤带到另一背景，终点仍是自然完整回答，不拆层组或因子。

NSR-01 合同 r01：受损深层 S 能否把损伤带进干净运行

依据：NSR-01 方案（main 42909af），以及 2026-11-03 评审对解释口径的收紧（§0）。授权：2026-11-03 用户原话“按照这个思路直接推进到跑完”。冻结后不改本文件；偏离记入 DEVIATIONS.zh-CN.md，合同未覆盖的判断记入 DECISIONS.zh-CN.md。

0. 评审商定的口径（相对方案）
  1. 保留 CV、CK、CJ 三个比较格；不再增加格子。
  2. CSx 是“跨输入移植参照”：换入另一条输入的干净 S，改变的是输入内容与状态的对应关系，不能排除所有拼接失配。
  3. CS 与 CSx 都出错时，不能直接说 CS 的效应与针无关；要逐类比较停止、错选编号、混合编号等表现，不能只比错误总数。CS 明显强于 CSx，也只说明效应超过这一种跨输入参照，不证明 S 是唯一损伤载体。
  4. CSx 供体规则：同场景内按固定 ID 顺序循环取下一条，不看输出挑选；CSx 与针无关，每条接收输入只跑一次。
  5. 结果的四种主要读法： - CS 带来与 T 相近的异常：加强“S 能转移干预相关行为效应”的证据； - CS 导致不同异常：说明它有因果影响，但没有复现原生损伤表现； - CS 很弱而 CJ 强：单独 S 在干净背景中不足，作用可能依赖其他状态配合； - NCC-01 中修复有效、这里反向移植无效：保留这种背景不对称，不推翻之前的恢复结果。
1. 范围与操作

模型、面板（LVK 新面板 48 条）、两个针（L0/N4146/−1、L12/C3621/−1）、形成、切点 τ（处理最后一个提示 token 之前）、生成设置（贪心，最多 32 个新 token；不加针、不挂钩子、不强制前缀）、G 层集合、深层 KV 层与 V 通道切片，全部与 NCC-01 合同 r01 相同。

接收者为同一输入的干净运行 C，在 τ 一次性替换以下内容，其余张量和缓存簿记全部保持 C：

格 来自哪里
CS 该针 T 的 G 层 S
CV 该针 T 的 G 层卷积 V 通道 [V_LO:]（q/k 保持 C）
CK 该针 T 的深层 KV（15,19,23,27,31）
CJ 该针 T 的全部深层缓存（G 层整个卷积缓冲、S，以及深层 KV）
CSx 同场景下一条输入（固定循环顺序）的干净 C 的 G 层 S

另跑 C 与两针的 T 作为桥接端点。每条输入 12 条自然轨迹。

2. 读数（实现见 nsr_core.py、nsr_analysis.py）
  • 主读数：自然完整回答 Y（y_full），全 48 条。每格报告正确数、相对 C 的改坏/改对/净变化、改坏涉及的场景数、场景等权比例。
  • 异常类型（冻结定义）：
  • 正确；
  • 停止：第一步就停止，或去掉结束标记后正文为空；
  • 混合编号：同时出现目标编号和其他列出的编号；
  • 错选编号：出现列出的编号，但不含目标编号；
  • 其他：没有出现任何列出的编号，或只有目标编号却被判为错误。
  • 逐类比较：报告每格的类型分布，以及与同针 T、与 CSx 的类型重叠度（只在错误中计算：各类占比取较小值后求和）。重叠度只作描述。
  • 首步描述：同 NCC-01（B、z₁[f]、最高停止与非停止竞争 logit、首 token 分类），只描述，不作回答正确性的代理。
  • 配对差：同输入 CS 与 CSx 的 Y 之差；两针 CS 的 Y 之差。
  • 汇总：逐输入、六场景等权；场景分层 bootstrap（2000 次，种子 20261103，共用同一组重抽索引）给出描述性区间。不算机制比例，不设总标签。
3. 工作预测（数据前登记，只写方向，不是预定结论）
  • CS（L0）出现较多错误，以停止为主。
  • CS（L12）出现错误，以混合或错选编号为主。

NSR-01 报告：受损深层 S 能否把损伤带进干净运行

2026-11-03。合同 r01，冻结 100cf8b9（main e38ee57）。探索性比较，已见开发面板 48 条，作者执行，未经独立评审。全部读数来自冻结分析 analysis/nsr-readouts-r01.json；§4 的供体答案核对是数据出来后补做的描述。

先说不利的部分与一处更正
  1. 三条工作预测全部落空。 - 预测 CS 在 L0 上以停止为主出错：实际 0 条错； - 预测 CS 在 L12 上出错：实际 0 条错； - 预测 CSx 的错误少于 CS：实际 CSx 有 38 条错，CS 为 0。

这些都是科学上的预测失败，照实保留。 2. 更正 NCC-01（我的错误）。 L12 的针加在第 12 层的 MLP 上，第 0–12 层的缓存在针之前就已算完；形成窗口结束后，最后一个提示 token 也不加针。所以在 L12 上，C 与 T 只在深层缓存（第 13 层起）上不同。逐位核实： - 本轮 L12 的 CJ 与 T 的 t1 logits、生成 token 全部相同（48/48）； - NCC-01 中 L12 的 TJ 与 C 全部相同（48/48）。

因此 NCC-01 报告中"浅层与入口始终保持受干预"只对 L0 成立；L12 的 TJ = C、本轮 L12 的 CJ = T 都是构造必然，不是发现。NCC-01 报告已加更正说明。 3. CSx 不是零对照，而是一个强效应。 换入另一条干净输入的 S，就有 38/48 答错。按合同 §0，它是"跨输入移植参照"，不排除全部拼接失配。

3. 按合同 §0 的读法
  • CS 很弱而 CJ 强：两针都属于这种情况。受损的 S 单独放进干净运行不足以造成错误，V 历史、KV 单独也不足以。只有全部深层都受损时才出错，作用依赖多组状态配合。
  • NCC-01 修复有效、这里反向移植无效：保留这种背景不对称。在受损背景里，单换干净 S（L0、L12）或干净 V、KV（L12）就足以恢复；在干净背景里，单换受损 S、V、KV 都不足以致错。这不推翻 NCC-01 的恢复结果。
  • L12：结合两个方向，L12 的损伤完全落在深层缓存里（推导，见更正）。任一深层组恢复干净就足够；任一深层组单独受损都不够。损伤需要多个深层组同时受损。但本轮只测了"单组"和"全部"，不知道需要哪几组、多少组。
  • L0：全部深层受损、浅层第 1–12 层干净时，46/48 出错，但类型从"停止"为主变成"停止 18 + 混合 28"。浅层第 1–12 层的受损状态与"停止"这一形态有关。本轮只能说这是相容，没有单独检验。
4. CSx：干净但不属于这条输入的 S 会把答案带走（数据后描述）

CSx 的 38 条错误全部是错选编号。其中 32 条输出的正好是供体那条输入的正确编号（这 38 条的编号列表与供体相同）。也就是说，τ 时的深层 S 带着"答哪个编号"的信息，足以在干净运行里改写答案选择。而同一输入受针后的 S（CS）不改写答案（0/48）。这与"针没有破坏 S 中与答案选择有关的内容，至少不足以在干净背景里改变选择"相容。按合同措辞，CS 强于 CSx 只说明二者效应不同，不证明 S 是唯一载体；CSx 也不排除全部拼接失配。

5. 能说和不能说

能说（这两个针、已见面板、τ 在最后提示 token 之前）： - 在干净运行里，单独换入受损的深层 S、V 历史或 KV 都不会让回答出错；只有全部深层都受损才出错。L12 的全部深层受损就等于原生受损。 - 换入另一条干净输入的 S 会让答案改写成供体的答案（32/38）。深层 S 带着答案选择信息。 - 与 NCC-01 合起来：干净 S 能修复受损运行，受损 S 不能破坏干净运行。

不能说： - S 是损伤载体：受损 S 单独不致错； - "冗余"或"贴近阈值"中的哪一种：本轮只测了单组和全部； - 浅层第 1–12 层决定 L0 的停止形态：只是相容，没有单独检验； - 结论推广到其他针、层、任务或模型。

6. 下一步候选（未授权，不自动执行）
  1. L12 的组合：在干净背景里成对地换入受损的深层组（S+V、S+K、V+K），找出损伤需要的最小组合。L12 的全部差异只在深层，三组的两两组合只有 3 格，范围清楚。
  2. "答案选择信息在 S 里"的来源：CSx 显示 S 带着答案选择信息，而针没有破坏它。原生损伤之所以导致答错，可能是读取这些信息的过程受了干扰，而不是信息本身丢失。这一假设可以对照"恢复 S 能修复"一起检验，但需要另立设计。
