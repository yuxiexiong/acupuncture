1. 设计卡：为什么做这一轮
  • 核心问题不变： 稀疏激活干预如何改变历史状态、旧状态处理与后续读取，最终造成大的回答变化。
  • 本轮问题： 已验证有行为作用的共同 q/k 偏移，其 q、k 分量单独和共同承担多少完整回答效应？这个结论是否依赖随机对照在卷积后的旧槽贡献偏小？
  • 认识增量： 从“末端共同偏移可双向搬运效应”推进到有固定预测、可失败的分量因果约束；不是再次确认缓存可影响输出，也不是重找层/头热点。
  • 估计对象： 固定接收者历史背景的一次卷积前编辑及全部自然下游响应的总效果。既不隔离纯读取/纯写入，也不估计原生机制份额。
  • 预测： k 分量的恢复比例 P 和原错误复现比例 B 可能均高于 q；仅为待检验预测，幅度较大不推出因果作用较大。允许 q 更强、两者都强、仅联合作用、异号及不可判。
  • 范围： 已见的 NA 原布局/B1、48 输入、6 基础场景、3 个有缺口方向；不是未见泛化验证。C1343 的无缺口反例保留为旧证据，不加入新模型矩阵。
  • 退出： 全矩阵一次完成后按 §7 报告；不因不符预测调倍率、换随机种子、换题或扩层。不要求本轮闭合整个机制。

2.2 架构事实与推断边界

固定实现采用 key×value 状态方向时：

S_t = α_t (I − β_t k_t k_tᵀ) S_(t−1) + β_t k_t v_tᵀ，o_t = S_tᵀ q_t。

k 同时参与旧状态的定向处理和新值写入；q 改变当前读出后也能经后续层与生成反馈改变未来更新。因此 q/k 分量实验不等于读取/写入两条互斥路径实验。公式是已有实现事实，不是本轮发现。

已存偏移与干净投影同量级、部分反向；这否定“远大于原向量而淹没”的候选。旧三槽经卷积的线性贡献仍不含当前 token 项和非线性，不能直接推断实际归一化后的旋转角。C1343 的相似几何但无损伤限制所有只靠大小/角度的解释。

  • G 层：13,14,16,17,18,20,21,22,24,25,26,28,29,30；不拆层、不扫头、不重开45头。

4. 比较矩阵与随机对照
4.1 每输入×方向的20个唯一科学臂

记 Q_T、Q_C 为上节 q/k 活动槽；m_q/m_k 为通道掩码。μ 是 QCO 留本场景外五场景等权均值，r_pre 是 QCO 已冻结随机张量。r_post 在 §4.2 定义。三种向量分别取 q、k、q+k，共9种编辑。

臂族 q/k 基底 编辑 数量 对应旧臂
V Q_T 无 1 QCO V
F Q_C 无 1 QCO F
R_{u,h} Q_T 减 m_h u 3向量×3掩码=9 R_mu,qk=R；R_pre,qk=R_rand
A_{u,h} Q_C 加 m_h u 3向量×3掩码=9 A_mu,qk=A；A_pre,qk=A_rand

u∈{μ,r_pre,r_post}，h∈{q,k,qk}。对于每个u，去除侧四格为 V/R_u,q/R_u,k/R_u,qk，加入侧为 F/A_u,q/A_u,k/A_u,qk。两侧无编辑基底不同，不把它们合为一个2×2。另每输入 C 自然1条、每方向 T_nat 1条，用于重放与损伤背景说明，不参与分量交互。

全矩阵包含4个新增 μ 单半臂；随机两档也都保留单半和联合臂，防止先看哪半阳性才补其对照。各向量的 qk 必须是同一冻结 q 与 k 两半拼接，不独立再抽一次。q/k 分量不按彼此范数缩放；比较的是真实偏移两半在各自原幅度下的效果，不是单位强度敏感性。

4.2 两档随机配平：精确定义

r_pre： 原 QCO 逐层×q/k×槽的输入范数配平随机向量；直接复用其张量、种子和哈希，不重抽。不假定经过卷积后仍等强。

r_post： 由同一 r_pre 确定性缩放。对每层 l、分量 g、头 h，定义旧槽首读线性映射

L_l(u)[c] = Σ_(j=0..2) W_l[c,j] u[c,j]。

a_lgh = ||L_l(μ)_gh||₂ / ||L_l(r_pre)_gh||₂；该头全部128通道×3槽共同乘同一个 a，得到 r_post。使用 FP64 计算范数/倍率，再以 FP32 保存编辑张量。这个配平控制首读旧槽合成贡献，不控制之后第二/第三步，也不控制 SiLU 后、归一化后或下游总扰动。只在执行 μ/r 的原始干预位置编辑，不另设卷积后 hook。

  • μ 与随机的头贡献均为0：a=1；目标为0而随机非0：a=0；目标非0而随机贡献≤1e−12，或倍率非有限：该匹配无法成立，CPU验收失败，不换随机种子救结果。1e−12是除零保护，不是行为阈值。
  • 全部倍率、输入范数、旧槽输出范数、最大倍率在任何新增输出前冻结。无行为反馈调幅，无截断后仍声称匹配。
  • 实际编辑为 BF16(FP32(base) ± mask*u)，只转换被编辑切片；无编辑切片不写回。以写回后与写回前的 FP32 差定义 δ_actual，不能用名义倍率冒充实际注入。
  • r_pre 对应 μ 同掩码、同正负基底的实际总编辑范数相对差≤5%；r_post 对应实际 δ_actual 经 L 后的逐层×分量×头范数相对差≤5%。相对差为 |a−b|/max(a,b)，双零通过，单零失败。全部头报告，不由总体均值遮盖局部失配。
  • 匹配失败不是科学阴性：μ 的完整分量矩阵仍可报告，失败的随机配平比较标工程不可判，不筛掉失败输入后重算“通过”。不得利用行为结果调整容差。
  • 只使用这一份已冻结随机方向；它是有界参照，不是随机方向总体的零分布，不能计算“随机显著性”。
4.3 补足缺失的当前 token 量，不另开模型网格

在上述自然轨迹首个读出步被动保存14层的 x_now、卷积前旧槽、卷积输出（SiLU前）、SiLU后 q/k 和归一化后 q/k，或能够逐值重建它们的最小张量。读取不改变返回值/张量，不额外调用模型；新观察器须通过旧臂重放验收。每臂的 x_now 来自其自身运行，不能假定与未编辑臂相同。

CPU分析分开报告：(a) L(δ_actual) 的配平；(b) 固定该臂 x_now、只移除直接编辑贡献的局部非线性几何；(c) 同输入不同臂实际归一化 q/k 的总差。b是局部条件计算，不是整网反事实；c含上游响应，不是直接偏移独占效果。仅作解释边界和量程描述，不用于选臂、头、方向或重新定义主判据。自然生成分叉后的差不冒充相同上下文的差。

5. 终点、分母和聚合
5.1 主终点与旧定义

自然贪心完整交付 Y_full 沿用 QST：正确交付唯一目标编号，最终 stop，无未闭合 think；复述、多编号、截断均失败。允许编号前有文字，不能把“首 token 不是共同字母”当成没开口。停止token {248044,248046}，最多32新token；保留原文、完整ids、终止原因、旧 Y_delivery/Y_strict。

对每方向，E_s 为各场景内先平均再六场景等权；48输入不能直接当48独立场景。固定

G = E_s[Y_F − Y_V]；D_i = 1[Y_F=1 且 Y_V=0]。

P_(u,h) = E_s[Y_R(u,h) − Y_V] / G。

B_(u,h) = E_s[D_i * 1(ids_A(u,h)=ids_V)] / E_s[D_i]。

沿用 QCO 适用条件 G>0 且至少4场景有正缺口；分母为0不填0。P允许负值或>1，不裁剪；B仅原错误子集，另列全48条原输出重放率和原始错误分母。报告每臂原本正确→错误、错误→正确、错误→另一错误的配对转移表，避免净收益遮住改坏格。

5.2 辅助读数
  • 首 token 的共同字母对两个停止token最大logit的分差，仅是起始形式读数。
  • 继承共同首字母的诊断分叉，记录3个候选编号的下一 token logits；自然第二步相同前缀时它是同一信息，不作独立证据。
  • 两条固定候选分差分别保存：目标对另外两个编号；目标不在首列时另列目标对首列。用于交互的 M 指目标减固定竞争者：目标非首列取首列，目标在首列取原记录第二条。不得跨臂挑最大竞争者后称线性交互。
  • 自然输出按唯一正确编号、唯一首列错误、其他唯一编号、多编号/复述、无编号、截断分列；目标在首列与不在首列分开。类别是行为描述，不命名内部任务框架。
6. 预先冻结的判读
6.1 单半的行为作用与方向预测

每个 μ 单半保留旧 P/B 实质门槛：P≥0.5、B≥0.5；恢复至少4场景净改善为正，复现至少4场景存在D_i原错误的逐token复现。分别与两档随机比较 P差≥0.25、B差≥0.25。它们是操作性效应阈值，不是统计显著性。

  • 过 P/B 与场景门槛：该分量在本背景承担较大双向行为作用；若只过一侧，仅称去除恢复/加入复现。
  • 对某随机档也过优势门槛且匹配验收通过：只称优于该档冻结参照。两档不一致全部报告，不选择支持结论的一档。
  • “k 强于 q”的预测按三方向分别评估：P_mu,k−P_mu,q ≥0.25 且 B_mu,k−B_mu,q ≥0.25，恢复差至少4/6场景为正，复现差在有D的场景中至少2/3为正（向上取整）。反向同式支持q强；仅一侧支持报告不对称；其余未支持明确排序。该预测不因k较大而先验通过，也不用于排除方向。
  • 三方向各自给结果，不投多数票形成全模型机制。不把不达门槛解释为零作用或等价。
6.2 四格交互和天花板

去除侧：I_Y^R = E_s[Y_R,qk − Y_R,q − Y_R,k + Y_V]。 加入侧同式以 A 和 F 替换；再报告原错误复现指标 I_B = B_qk−B_q−B_k+B_00，其中B_00按F的ids实际计算（D上应为0）。连续读数各固定竞争者另算相同四格差 I_M，单位logit，不把I_Y/I_B/I_M相加。

报告逐输入四格、逐场景交互、等权均值和范围。预设 |I_Y|或|I_B|≥0.10且至少4场景同号，仅称“该指标上可见非加和”（B无D场景按加权贡献0列出，不另造分母）；不称显著协同。未满足则报告原值与未达描述门槛，不宣称加和已证实。

同时列出基底及各单半距离0/1的剩余空间，以及原错误子集上四格修复模式的计数。两个单半各自接近完全修复时，负I_Y可能来自饱和；不能把“两半不超过单半之和”命名拮抗。只有联合过门槛而单半未过，称“联合达到预定门槛、单半未达到”，不能推出每个分量在自然机制中必要。连续分差帮助理解，但不能把行为交互自动归因某个内部计算交互。

6.3 统计身份

本轮是已见面板上的预先规定分量检验，不是独立确认。六场景是聚合单位，留一场景偏移估计之间有训练重叠；不把六折或144条件格当独立实验。本轮不报告总体p值、独立样本置信区间或功效保证；公布完整六场景结果和阈值判读。48输入总正确数与场景等权估计均保留，不混用。

7. 结果出口与累积
结果 本轮留下的认识与处理
k单半双向强，q弱；两档随机后仍保留优势 支持真实偏移k分量在该背景/幅度下较强；为具体k依赖旧状态处理/写入计算提供约束，不直接选定其中一条

去除与加入排序不同/异号 操作背景与非线性影响不可忽略；停止单一分量主导说法
pre随机下有优势、post随机下消失 证据对配平口径敏感；支持旧槽线性贡献幅度是重要替代解释，不能算出它解释的百分比或断言方向完全无关
联合旧臂不能重放 工程不可判，停止科学解释；不以放宽logit容差掩盖定义改变
联合重放通过但单半均弱 有效结果，拒绝单半足够预测；不自动扩层、调幅或换随机种子

无论哪种结果，本轮均归档完整矩阵后结束。只有获得具体的新计算预测才另拟下一实验；不把因子实验自动接成无边界定位流程。

5. 实质反方审查与修订

反例A：k更强只是k扰动更大。 即便所有预期结果出现，仍不能推单位强度k敏感或写入主导。处理：明确本轮是原幅度分量贡献，两个随机各匹配同分量，禁止q/k自然敏感性排序；不另加跨分量剂量扫描。该边界保留了“真实偏移哪半足以产生行为效应”的增量。

反例B：两个单半各自修复全部错误，四格差反而负。 用同一原错误集构造V=0、Rq=Rk=Rqk=1，I_Y=−1；没有理由叫破坏性拮抗。修订：增加天花板/逐题四格模式，禁止机械命名；固定候选M不经过跨臂max再算交互，且仍不据此证明内部协同。

反例C：随机被卷积缩小，所谓方向优势其实是不同有效幅度。 增加r_post，但它只匹配首读旧槽线性范数；补当前项的实测几何后也不能把方向与非线性增益完全分开。修订：只判断优势是否对配平口径稳健，不承诺解释百分比；逐头不匹配则标不可判，不选成功子集。

反例D：随机方向只有一个，恰好弱。 这会限制随机总体主张，但不否定μ两半相对自身联合端点的配对作用。保留冻结参照和明确条件，不用额外种子矩阵制造完整感或伪显著性。

反例E：阴性来自实现没命中实际槽，或观察器改变路径。 工程验证与科学判据分开：活跃三槽、切块和旧臂逐位重放；失败停止、不解释科学结果。CPU规则与模型验收仍未完成，不虚报可执行。

反例F：只看原错误子集遗漏修复造成的反效果。 P用所有输入的净正确率，另报配对改坏；B才限定原错误。不得删除自然原本正确的输入或把全48重放率称原错误复现率。

反例G：预算只加576新单半，随机与重放漏记。 穷举20唯一臂并计C/T_nat，正式3072；模型形成C+3T=192，预检重试另列。相对截图预算增加，但未增加层、方向、剂量。CPU manifest 将独立复算这些数，不以口头“约0.5小时”替代。

反例H：匹配头某一贡献为零，缩放爆炸或BF16抹掉变化。 冻结除零条件、全部倍率和实际差验收；不暗改种子/截断倍率；该随机比较无法成立即不可判，μ主因子仍报告。缺匹配不冒充μ无效。
