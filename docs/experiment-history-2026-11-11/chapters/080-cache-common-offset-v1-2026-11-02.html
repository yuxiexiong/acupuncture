2. 原报告三处需要收紧
  1. “所有答案完全不变 / J全部0”不能覆盖所有臂。 R0的H_T有一条变化：接收者 NA-NQ03-ABC-C 原题为W19，自供体输出W35；供体换成 NA-NQ03-ABC-B 后输出W19。这个主对照J=0.5、W=0，R0 H_T等权J=1/72≈0.01389。它没有跟随供体目标，稳定转移结论仍为阴性。U与H_C的84/84结论成立，不能扩大成所有H_T也逐token不变。
  2. “q/k张量几乎相同”缺直接距离证据。 qst_run.py保存到pt的是生成首步、第二步及诊断logits字典；归档没有给出q/k跨查询距离。小输出变化与未转移也可能来自读出不敏感、冗余或替换背景，因此应写“在指定替换下输出对供体查询身份不敏感”。有限精度间距不是已经测定的误差/噪声上界，0.25不能直接当可忽略噪声。
  3. “S和全注意力KV里显然有查询信息”是定位过度。 恢复后能答原题说明整个接收背景保有可供利用的任务约束；本轮没有分别定位到S与KV，也没有排除浅层/当前输入条件的贡献。“需要干净q/k”也不是必要性定理：C1343的受针q/k同样48/48。准确说法是：在有恢复差距的三个方向，测试过的同组干净供体均能补足差距，正确查询身份并非这些成功恢复的必要来源条件。

3. 下一步的取舍与核心问题

主线不变：稀疏针怎样改变写入、旧状态处理和读取，最终产生大的回答效应。

推荐QCO-01：检验受针形成的末端q/k变化是否含有跨记录可复用、能恢复并重现原有回答效应的共同加性分量。 这比“看哪些层差最大”更直接：结果需要由其他场景构造的编辑提前预测本场景的完整回答变化。不是因为QST阴性就自动扩层，也不继续寻找供体查询身份转移。

具体候选：对每种既定针方向，其他场景的平均受针−干净差，若是实际起作用的共同分量，那么从本题受针q/k减掉它应补回一部分V-only的交付缺口；向本题干净q/k加上它，应重现一部分V-only的原有错误。等范数随机方向若同样有效，则不能归因于这份共同偏移的特定取向。

阳性最多提供跨记录可搬运的状态差分及其双向行为作用，不是低秩定理、完整计算机制、原生唯一中介或无损修复方法。阴性结束“单位强度共同均值偏移足够”的候选，不自动转去调倍率、PCA选秩、挑层/头。原报告建议的逐层几何可作为描述表，但不作为下一轮核心终点，也不依它挑干预位置。

5. 不用本场景估计的共同偏移

对输入i、方向d、层l、通道组g∈{q,k}、有效槽t，记卷积历史为Q_C(i)、Q_T(i,d)，Δ(i,d)=float32(Q_T)−float32(Q_C)。

六个基础场景分六折。接收场景s的偏移：

μ(-s,d) = (1/5) Σ[r≠s] mean_{i∈r} Δ(i,d)。

每场景先对其所有可比排列/查询取平均，再对五场景等权，避免有9条的场景比6条的场景权重大。本题及同场景的任何查询、排列都不参与其μ。六折、四方向全部使用；只排除相应场景，不根据答对/错筛训练条目，不拟合倍率，不改符号。所有μ与来源清单在任何新编辑输出前冻结。

这是已见开发面板上的跨场景构造验证，不是未见题外部确认，六折也不是独立六次实验。每折一个高维固定偏移不等于已证明低秩。

描述项固定为：逐层/逐qk/逐有效槽的Δ范数、μ范数、cos(Δ_i,μ_-s)、||Δ_i−μ_-s||²/||Δ_i||²；零分母记NA。不挑最高层、不选最佳折，不以相似度高自动当行为因果证据；几何弱也不修改既定行为测试。

结果 结论与分支决定
双向与参照差均达标准 支持其他场景估计的共同差分可部分解释该背景的行为变化；下一问题才是它通过什么更新/读取计算起作用，不自动宣布原生机制闭环
只R恢复，A不重现 共同校正可补偿，尚未解释原有错误的生成；不能当充分机制或直接扩层
只A重现，R不恢复 加入此偏移可扰动该混合背景，但去除不足；不称主要承载者
R/A与随机参照相近 不支持所提共同方向的特异优势，可能是更一般的状态扰动；不从一个随机参照推整个随机总体

日期：2026-11-02。合同 r01；决策 D1–D4；计划 v1（905a6d19，评审撰写）。代码 3fcb81d，freeze-r01 a607db70…1060。R/A/R_rand/A_rand 运行前无输出。同一助手实现、运行与撰写。

1. 结论（限制先说）
  1. 限制一：等范数随机方向本身也有不小作用，尤其在 N4146。 把同范数（约 530–560）的随机向量加到干净 q/k 上（A_rand），也会逐 token 复现 V 的错误：N4146 35/48（B_rand = 0.64）、N1210 31/48（0.32）、R0 38/48（0.18）；从受针 q/k 减随机向量（R_rand）则通常更差（P_rand = −0.06 / −0.34 / −1.05，并把 2 / 7 / 11 个原本答对的格改坏）。所以“q/k 被大幅扰动 → 首列错误”有相当一部分不依赖方向；共同偏移的方向特异性体现在它比随机好得多，而不是随机无效。
  2. 限制二：这是混合状态下的操作效果（V 取 C(i)，S/KV/浅层取 T(i,d)），在已见开发面板、六个场景、NA 原布局宽窗口上；六折不是六次独立实验。

QCO-01 零 GPU 补充：共同偏移相对干净 q/k 有多大

日期：2026-11-02。事后描述，不在 freeze 内，无预注册。脚本 analysis/offset_scale_r01.py，结果 analysis/offset-scale-r01.json。数据：采集阶段保存的 48 个输入的 q/k 卷积槽、冻结的共同偏移 μ 与随机参照 r、从模型权重文件读出的 14 层卷积核。

依据的源码事实（已核对安装的 transformers）

首个读出步：out = conv1d([s1, s2, s3, x_now], w[0..3])（旧缓冲后 3 槽 + 当前投影，核长 4），随后 SiLU，再对 q、k 按头（16 头 × 128 维）做 L2 归一化。当前 token 的投影 x_now 没有保存，所以“卷积后”只算得到旧三槽的贡献，不含 w[3]·x_now 这一项。

结果（48 输入 × 14 层的中位数；四个方向几乎相同）
量 q k
卷积前 |μ| / |干净 q/k|（槽 1–3） 0.84–0.86 0.88–0.93
cos(干净 q/k, μ) −0.46 到 −0.49 −0.38 到 −0.40
cos(受针 q/k, μ) +0.39 到 +0.43 +0.43 到 +0.48
卷积后旧槽贡献 |μ| / |干净| 0.41–0.47 0.62–0.72
同上，随机参照 |r| / |干净| 0.30 0.44–0.48
读法
  1. 我此前的推导（“偏移远大于原 q/k，归一化后方向被偏移主导”）不成立。 偏移与干净 q/k 同量级（卷积前约 0.85–0.93 倍），卷积后旧槽贡献只有干净的 0.4–0.7 倍；不是“盖过”。
  2. 偏移与干净 q/k 明显反向（cos 约 −0.4 到 −0.5）：受针 q/k ≈ 干净 q/k 加上一个大小相近、部分反向的向量——范数变化不大，方向被转开。这是“抵消/转向”的形态，而不是“淹没”。
  3. 卷积核放大共同偏移多于随机方向：同样的卷积前范数，卷积后 μ 的旧槽贡献约是随机 r 的 1.5 倍（q 0.41–0.47 对 0.30，k 0.62–0.72 对 0.44–0.48）。这可以部分解释为什么 μ 比随机更有效，也说明随机参照在卷积后其实“更小”；但这只是旧槽部分的描述，不是因果证据。
  4. k 半的相对改变大于 q 半（卷积后 0.62–0.72 对 0.41–0.47），在 14 层中都如此（k 在层 16、21 最高达 1.0–1.2）。这为下一步“q 半 / k 半”拆分提供了一个可检验的先验：如果作用主要走写入路径，只去除 k 半应恢复更多。这只是线索，不是预测已成立。
  5. C1343 的几何与另三个方向几乎相同，但它的 V-only 没有损伤（48/48）。所以单看偏移大小与角度，预测不了行为；作用依赖它与其他状态的组合。

限制：缺当前 token 项；SiLU 与归一化是非线性的，旧槽贡献的比例不能直接换算成归一化后的方向变化；只在这块面板与四个方向上。
