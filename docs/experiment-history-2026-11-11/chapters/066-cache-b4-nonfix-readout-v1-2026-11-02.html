B4：固定45头的主效应是否依赖非 FIX 头的后续读出响应——实验方案 v1

  • 日期：2026-11-01；v1；身份：研究设计，不是运行合同，不授权上卡。用户要求「先写实验方案，上传到 git」。
  • 依据：B3（f2ad7d8、更正 b0da947）、B3-P0（9c83b9a）、B3-P1（4f617bb），以及两轮评审对“回到主效应”的修订意见。同一助手撰写，非独立评审。
1. 问题与定位

课题主问题是：稀疏激活干预怎样改变历史状态的形成、处理和读取，最终造成显著的回答变化。最近三轮（B3、P0、P1）研究的是交互，即其余头为什么让 FIX 的效应减弱；而主效应本身，即固定45头的 T 历史怎样在 N 背景下产生约 2.4–3.4 logit 的停止效应，一直没有得到因果解释。

B3-P1 的描述性发现给出了一个可以干预的具体环节：从第17–18层起，A 组历史引起的变化有相当一部分经由非本组头的读出表达出来（入口头组 ≠ 表达头组）。本方案只问一个有边界的问题：

在 N 背景中，把非 FIX 头的当前步读出恢复为同背景无 FIX 历史（N:CC）时的值、其余计算正常响应，FIX 主效应 X 还保留多少？与幅度匹配的无关扰动相比，这种下降是否更大？

本轮不回答：非 FIX 是否比 FIX 更重要或更特殊（403 头对 45 头，不可比）；原生运行中是否走同一路径；完整的“全局招募机制”。

2. 接收背景、操作与响应边界
  • 背景与输入：沿用 B3（模型、revision、BF16、内核路线、token、晚段窗口、L0 剂量 −1、N 背景定义、x_T 入口、C2/B3 的 worker/GPU 分配与进程内校准）。四个方向 N4146、N1210、R0、R1；12 条 P 系列输入（6 个情景 × f0/f1 配对）。
  • 参照格：N:CC、N:CFIX，每方向另评 T_native 以取得 x_T。参照格 logits 须与 B3 逐位一致。
  • 钳回操作（K）：在 N:CFIX 的评分步，对每个 G 层（13、14、16、17、18、20、21、22、24、25、26、28、29、30），把非 FIX 头的门控归一化输出（linear_attn.norm 的输出，单步评分时第 h 行即第 h 个值头，送入 out_proj 之前）替换为同输入、同方向、同进程内 N:CC 评分时记录的值。FIX 头、全注意力层、所有 MLP、最终归一化都正常响应。第13层非 FIX 头本来就与 N:CC 逐位相同（B3-P1 闸门），所以那里的替换是空操作，保留它只是为了定义完整。
  • 操作的准确含义：非 FIX 头的历史本来就是 C，与 N:CC 相同。钳回去掉的是这些头对残差变化（由各层 FIX 头的直接注入及其下游传播造成）的当前步响应。它同时也阻止了这些头对任何其他变化的响应，因此测到的是这种阻断方式下的条件性依赖，不等于“删除了跨组传播这条原生路径”。
  • FIX 头分布在 14 个 G 层，每层都会直接读取 T 历史，所以“入口”不止第13层。上一轮提出的“只钳回 FIX 头后续读出”的对照会把各层的直接注入一并去掉，含义混淆，本轮不做。
3. 臂（每输入 × 方向）
臂 操作 用途
CC、CFIX 参照（重放） X = z(CFIX) − z(CC)
K CFIX + 全部 G 层非 FIX 读出钳回 CC 主读数：保留率 ρ_K = [z(K) − z(CC)] / X
K0 CC + 同样钳回（供体即自身） 实现验收：必须与 CC 逐位相同；只证明实现正确，不排除一般扰动效应
M_nat CFIX + 给非 FIX 读出逐层逐头加扰动，方向取另一输入（同方向、同事实变体、情景循环 P_s → P_{s+1}）在 B3 中记录的 (gno_CC − gno_CFIX)，范数逐层逐头匹配本输入 K 的移除量 ‖gno_CC − gno_CFIX‖ 幅度匹配、内容无关的扰动对照（自然分布的方向）
M_rand 同上，方向为冻结种子的高斯随机向量 幅度匹配的随机扰动对照
K_early、K_late 只钳回第13–18层 / 第20–30层的 G 层 单个预先声明的粗分组面板（不再细分、不逐层扫描）；不要求两者可加

M 臂的扰动加在当次运行的实时读出上，范数以参照 CFIX 运行中的移除量为准（同进程内先评 CC、CFIX，记录逐层逐头的差及其范数）。某层某头的移除量为 0 时不加扰动。

4. 读数与判读（数值门槛在合同中冻结，并须离线演示可满足、可不满足）

主读数：去均值停止 logit z（cz_s46），每臂 X_arm = z(arm) − z(CC)，ρ_arm = X_arm / X。次要：答案词 cz_a、D 与首步是否停止，只作描述。

情景级（f0、f1 都满足才计）与方向级（≥5/6 情景）、跨方向（≥3/4 方向）的规则沿用前几轮。拟定的结果类别，五种都预先允许：

  1. 特异依赖：X_K ≤ min(X_M_nat, X_M_rand) − 0.2·X。另标强弱：ρ_K ≤ 0.5 为强。
  2. 一般敏感：X_K 有下降，但两个 M 臂的下降与它相差不到 0.2·X。阳性不能归到“依赖对 FIX 变化的响应”上。
  3. 未检出依赖：ρ_K ≥ 0.8，且没有超过 M 臂。只表示“在这个操作下没有检测到依赖”，不能据此把机制定位回 FIX（可能是 FIX 足以维持，也可能有替代路径或补偿）。
  4. 反向：ρ_K ≥ 1.2，说明非 FIX 的响应在压低 FIX 效应。
  5. 条件依赖：各方向结论不一致。如实报告，不强行合并。

0.2·X 与 0.5/0.8/1.2 是实用门槛，零分布由 M 臂提供，而不是假定为 0；正式数值、离线演示与 K0 闸门一起写入合同。

5. 预测（推测档，合同冻结前写入，见到 B4 数据前不改）
  • 影子估计：冻结前用 B3 记录离线计算。从 N:CFIX 的最终 h 中减去各 G 层非 FIX 头块的贡献 W_o[:, 非FIX]·(gno_CFIX − gno_CC)，重算 z，得到 ρ_shadow。它假设下游不响应；按前几轮的经验，账目贡献与真实响应可能差很多，所以 ρ_shadow 只作为登记的模型预测，不是期望值。
  • P1（方向）：ρ_K ≤ 0.8 出现在 ≥3/4 方向。依据：P1 的头块账中，非本组项从第17–18层起超过本组项（推测：这种跨组表达也承载了主效应的一部分）。
  • P2（影子模型是否够用）：|ρ_K − ρ_shadow| ≤ 0.25 出现在 ≥3/4 方向。
6. 工程闸门（拟定）

参照格 logits 与 B3 逐位一致；K0 与 CC 逐位一致；每次评分每个 G 层的钳回 hook 恰好触发一次；被钳回的行在 hook 后与供体逐位相等，FIX 行在 hook 内不被修改；M 臂逐层逐头的扰动范数与目标的相对误差 ≤1%（BF16 舍入）；14 个 G 内核各一次、chunk 为 0；入口 hook 每个 N 格一次。M_nat 的方向取自 B3 张量，先按 receipt 核对哈希。

7. 预算（拟定，合同中冻结）

每输入：形成 C 一次、每方向形成 T 一次（共 5 次）；评分为 C_native 1 次，加每方向 T_native、CC、CFIX、K0、K、K_early、K_late、M_nat、M_rand 共 9 次，即每输入 37 次。

8. 出口
  • 特异依赖（强）→ 下一步优先连接原生运行：在 T_native 中做同类钳回（供体为 C_native 的读出），检验原生停止是否同样依赖；不自动回到逐层定位。
  • 特异依赖（弱）或一般敏感 → 报告条件性依赖的边界；只有在提出新的可区分问题时才另立方案。
  • 未检出依赖或反向 → 如实报告；不据此宣称“只靠 FIX”或“非 FIX 是抑制者”。
  • 条件依赖 → 按方向分别报告。

暂缓：雅可比/共享下游响应支线（只有本轮暴露出具体的模块问题时才考虑）、头数匹配的特异性比较、跨架构检验。

B4：非 FIX 后续读出对主效应的条件性依赖——方案 v2

2026-11-02。替代 v1 的操作匹配、判读和出口定义。v1 保留历史身份。状态：设计自查通过；未写实现、未验收、未运行。此次用户授权为修改方案；Git 发布不授权模型/GPU运行。

1. 设计卡与依据

主线：稀疏激活干预如何通过历史状态和后续读取产生显著回答变化。本轮问题：在 N 混合背景的 N:CFIX 中，将非 FIX 头当前步读出钳回同输入 N:CC 值后，固定45头的停止侧主效应还剩多少？这种改变是否超过两种实际幅度配对的参照方向？

新增认识：对 B3-P1 的“历史入口头组不等于后续表达头组”做一次操作性因果检验。不是研究 FIX 是否比403个其他头特殊，也不是完整原生路径归因。阴性不把机制定位回 FIX。

依据：B3 f2ad7d8（更正 b0da947）、B3-P0 9c83b9a、B3-P1 4f617bb；原方案23f4dff。它们提供配对历史及描述性头块读数，不保证钳回有效。遵守本地既有基础审计和 设计自查规范：账目与真实响应分开，不重做架构恒等式当发现。

输入已见，操作结果未见：本轮是已见面板上的新干预检验，不是新输入泛化确认。四个方向与两事实不是独立样本；六情景是报告单位。

2. 固定面板和操作

沿用 B3 的固定模型 revision、BF16、内核、token位置、晚段历史窗口、L0剂量−1、N背景、x_T入口、worker/GPU分配及进程内校准。实施前从 B3 合同/receipt 填入完整身份与哈希；不得用“沿用”替代实际核验。

四方向 N4146/N1210/R0/R1，P01–P06×f0/f1。每输入形成一个C历史、四个T历史。所有N评分在独立克隆的初始状态上执行，不能沿用上一臂更新后的缓存。

K：在 N:CFIX 当前评分步，对G层13、14、16、17、18、20、21、22、24、25、26、28、29、30的 linear_attn.norm 输出、out_proj之前，逐值头将非FIX行换成该输入/方向同进程内CC供体。第13层非FIX本应与CC相同，是预期空操作。FIX行不被hook直接修改，但允许响应已改变的上游输入；全注意力、MLP及最终归一化正常响应。未来token不在本轮操作或结论中。

非FIX历史仍是C。钳回限制的是它们在这一混合运行下的当前读出响应，不改变历史形成；也可能阻止补偿性响应，不能命名为删除唯一原生传播路径。FIX在多层直接读取T历史，因此不加入“钳回FIX”的伪对称对照。

3. 臂、执行顺序与实际配对

每方向九次评分不变：T_native、CC、CFIX、K0、K、K_early、K_late、M_nat、M_rand。每输入另有一次C_native。

臂 作用
CC/CFIX 定义 X=z(CFIX)−z(CC)，保存供体与参考
K0 CC中钳回自身供体，必须逐位不变；仅工程验收
K 全G层非FIX钳回；主臂
K_early/K_late 仅13–18/20–30层G读出钳回；次要描述，不用于挽救主臂或继续细分
M_nat 跨输入移植的响应方向，配对K实际逐层幅度
M_rand 一个预先冻结的高斯方向实例，配对K实际逐层幅度

依次先完成CC/CFIX/K0，再K并保存实际改变量，最后M臂。K的配对信息仅为预定位置的张量与范数；M构造禁止读取K的最终logit、保留率或通过标签。K后不得按效果挑选方向、种子、缩放规则。K_early/K_late不参与M构造。

3.1 主要匹配量：进入残差空间的线性投影改变量

在K第l层记录钳回前实时 g_K,l 和CC供体。Δg_K,l=g_CC,l−g_K,l，仅非FIX行非零；W_l是实际out_proj。目标 A_l=||W_l Δg_K,l||_2。不能用未干预CFIX的差代替它：前层钳回已改变后层实时读出。

W的乘法采用固定FP32累加路线，源值来自实际BF16 hook前后张量；它定义的是out_proj的线性投影改变量。记录BF16实际out_proj输出差作为精度审计，不把线性值误称逐位实际残差差。额外线性投影审计算力计入预算，不增加完整模型评分次数。

对照先构造模板 v_l，FIX行恒为零： - 每个非FIX头以K实际 ||Δg_K,l,h|| 为初始长度。自然模板方向来自B3同干预方向、同事实变体的下一情景（P06循环P01）之 g_CC−g_CFIX；随机模板方向来自按输入/干预方向/层/头键控的冻结高斯种子。 - 自然方向为零但目标头长度非零：此对照单元无法按定义构造，不临时换输入或随机补齐。高斯模板同样不重抽以追求效果。 - 对非零投影模板，用统一逐层系数 λ_l=A_l/||W_l v_l|| 缩放。加入M当次实时读出：g_M,l'=BF16(g_M,l+λ_l v_l)。这保证目标是逐层投影后幅度匹配；统一缩放后不再宣称逐头幅度与K严格相同。 - 保存逐头匹配前后长度、λ、投影前总范数、投影后范数及实际hook差；头数、层、支持集合固定，不匹配最终效果或停止方向投影。

近零规则：A_l≤1e−6×max(1,||W_l g_CC,l||)时标记近零层，两M在该层不加扰动；K保持真实钳回，完整记录其微小改变量。模板投影使用同一个逐层近零阈值；模板投影近零而A_l非近零时无法匹配。λ不在[0.1,10]时记“缩放超界”；范围为防病态控制的工程上限，不是科学门槛。禁止改用更有利模板。

BF16后实际hook差的投影范数须相对A_l误差≤5%（非近零层）；不允许迭代查询logit调幅。实际out_proj输出差与上述线性投影差的向量误差范数，以该臂线性投影差的范数为分母，须≤5%（非近零层；近零层仅记录绝对误差）。未满足则该单元的对照比较不可判，保留K主读数及失败原因。若系统性无法匹配，预检停止，修订合同后重新冻结，不把它当科学阴性。

匹配只控制逐层投影改变量的长度，不保证逐头长度、方向、分布内性或后续扰动幅度都相同。这些差别限制结论。M_nat可能保留共享响应机制，名称不使用“内容无关”；M_rand一个实例不能充当零分布。M同样有效不等于一般损伤。

4. 读数及完整、互斥判读

z为原方案去均值停止logit cz_s46；X_arm=z(arm)−z(CC)。只在X≥1.0 logit时形成ρ_arm=X_arm/X；X<1.0（含零与负值）记分母不足，不形成标签，保留全部绝对读数。阈值是实用尺度，不是显著性。

轴A（K自身作用，按数值互斥）： - ρ_K≤0.5：强降低； - 0.5<ρ_K≤0.8：中度降低； - 0.8<ρ_K<1.2：未达预定改变门槛； - ρ_K≥1.2：反向增强。
