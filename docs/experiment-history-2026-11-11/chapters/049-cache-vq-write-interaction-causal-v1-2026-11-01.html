1. 本轮问什么，为什么值得做

总课题保持不变：少数通道激活干预怎样改变写入、历史状态处理和后续读取，最终造成显著回答变化？

本轮问题：已经观察到的第13层 V×Q 写入交互，在指定评分背景下，是否实际改变了最终答案词/停止词两侧的非相加？删除这一份交互，输出交互变小、基本不变，还是反而变大？这种作用在原生评分后半段 N 中是否仍存在？

换成人话：现在发现两份材料一起起作用时，会在一项计算里互相抵消。下一步把这一份抵消拿掉，看它是否真的影响最后的词语竞争。只看到内部抵消、只看到停止分数动了，都还不够。

新增的是“这份具体计算变化 → 输出交互变化”的有界因果证据。计算公式、激活替换方法、状态影响输出等都复用已有知识；不把拆出乘积项本身算创新，不宣称首次发现此类机制。有关近邻的定位复用合并文献核对，本轮没有重做领域查新，也不作领域首次主张。

每个背景中固定深层 S=T、全注意力 KV=T；V/Q 材料在全部深层 G 层按旧 CONV 四角来源配置。下面下标顺序固定为 QV。

背景 进入第13层的当前残差 旧四角映射（CC、CT、TC、TT） B1实际新运行的基底
M_T 浅层0–12缓存为 C，自然得到 x_C M:TCC,TCT,TTC,TTT M:TTT

3.3 被删除的项

按现有内核的 q/k 归一化、query 缩放及头广播规则，定义每头：

core = Sᵀw + n
w = exp(g) [q − β k(kᵀq)]
n = β v(kᵀq)
I13 = nTT − nTC − nCT + nCC

同一背景的第13层四角当前输入、旧 S、g、β 相同，q/k 只依赖 Q，v 只依赖 V，故还可独立计算：

I13 = β (vT − vC) [(kTᵀqT) − (kCᵀqC)]
readTT − readTC − readCT + readCC = 0

这两式是有条件的代数事实，不是新科学发现。来源驱动有任一固定条件不成立，不能强行使用此式。按 lr_core.weights 相同约定用 FP64 重构 q/k/w/n，核对保存的 old/new/core；不得混用卷积前与卷积后 qkv、漏掉 q 缩放或错误头映射。

本轮在 TT 基底第13层 recurrent 内核返回的 core 输出边、gated norm/out_proj 之前，执行一次：

core' = cast_BF16(FP64(coreTT) − I13)

只改这一层这一步输出；返回的 s_new 不改，其他缓存不手动修改。gated norm、out_proj、残差、后续层及最终归一化都正常响应。固定入口四角下，精确重构意义的局部 core 变成 coreTC+coreCT−coreCC；BF16 实际版本须单列误差，不能口头称逐位相等。

这是当前写入项对 core 读出的输出边干预，不是删除持久 S 更新，也不是撤销历史写入。 它主动打破“返回 core 等于实际 s_new 读出”的自然联合关系，作为一次受控反事实；只回答本步输出响应。未来状态/完整生成仍不在其估计对象中。

4. 最小矩阵与随机参照

每输入每背景4格，全部 TT 基底：

格 第13层操作 用途
R 无改动、记录器开启 逐位重放旧 TT，连接旧三角与新干预
DEL core 减去 I13 主因果检验
RAND0 core 减去 U0 同幅方向参照
RAND1 core 减去 U1 第二条有限方向参照

随机匹配的是 core 的 I13 每头 L2 范数，不是 F 的原始 V/Q 范数。沿用 LOCAL 的 CPU FP32 高斯采样、FP64 每头单位化与匹配，但使用新标签 CFM-VQ-WRITE-L13-v1。种子：int(sha256(tag+'|'+item_id+'|'+j).hexdigest()[:16],16)，j=0,1；[32,128] 形状，零目标头严格置零；不正交化，不选方向。M_T/N 对同输入共用单位方向，分别匹配各自 I13 幅度；不同输入按 id 产生方向。保存种子、方向与匹配后向量 SHA。

两条随机只是有限方向参照，不是充分的零分布；不能据其宣称一般扰动被排除、通道特异或 p<0.05。新 core 随机也不能替代 XCHAN 的入口随机。所有格同一下游、相同 cast 和 hook，实际落到 BF16 的位移另验收。

5. 估计量、读数与事前预测
5.1 主读数与输出交互

主检验对象：cz_s46 = z[248046] − mean_vocab(z)；同时必须报告 cz_a，a 为旧干净 C 的冻结非停止赢家。不得按本轮赢家重选 a。两侧使用同一估计量与判读规则，答案侧不预设不同机制。动态 D、首步 EOS/赢家、248044、think=248068、固定候选边际、原始 logit、固定 C 归一化尺度读数均作派生/诊断，不替代主终点。均值在全词表、FP64 计算，不是只减候选词均值。

对每个输入、背景、终点 Z，旧四角给出：

I_out  = ZTT − ZTC − ZCT + ZCC
I'_out = ZTT_DEL − ZTC − ZCT + ZCC
δ       = ZTT − ZTT_DEL = I_out − I'_out
ρ       = δ / I_out
κ       = |I'_out| / |I_out| = |1 − ρ|

旧三角不新增评分，前提是本轮 R 全词表 logits、入口和驱动与旧 TT 逐位一致且来源环境完全对齐。δ=I−I' 是只改 TT 的恒等关系，不能把这条恒等式本身当因果发现；新证据在于指定删除操作引发的 δ 大小、方向及其相对参照。ρ 是该反事实下的输出交互变化比，不是自然机制贡献百分比。

特别区分两种范围：I13是第13层的局部计算项；I_out来自全部深层G层的V/Q四角材料操作。本轮问前者能否改变后者，不能把两者当成同一个量。其他13个G层的材料在新评分中仍为TT，后续正常响应；不要求一个局部项解释全部全局交互。

5.2 分母与分析单位

全部12行先报告绝对 I、I'、δ 和两条随机 δ。情景汇总：两事实的这些量分别取均值后，再计算比例，禁止先算小分母比例再平均。仅当情景 |mean(I)|≥1 logit 且两个事实的 I 同号，展示情景 ρ/κ。单输入比例也要求自身 |I|≥1；其余为“比例不可判”，绝对变化照报。沿用项目1 logit展示下限，不据新结果调下限。

现有基线已揭示这一限制：停止侧 M_T 有6/6、N有5/6情景可展示比例；答案侧 M_T有4/6、N有3/6。它们是设计前已知的分母条件，见核对 JSON，不能事后移除小分母情景把通过率抬高。答案侧因此以绝对变化和逐情景判读为主，不要求其凑足总体比例结论。

5.3 预测及阈值的身份

已有证据支持“局部抵消可能传到停止词侧”这个候选，并不演绎保证输出同向。登记可失败预期：N 停止侧删除后，输出交互幅度至少缩小25%，且真实操作的作用超过两条有限随机参照，在固定六情景中至少5个成立；M_T 同样报告但不能替代 N。25%、1 logit、随机超过规则是事前描述性判断标准，不是估计出的置信界或统计功效承诺。

逐情景“支持传递”需同时：

  1. 上述分母可判；κ≤0.75，即 ρ∈[0.25,1.75]；两个事实各自 δ 与 I 同向。
  2. 对每事实令 E_i=sign(I_i)δ_i，均>0；mean(E_i)>max_j mean(|δ_random,j,i|)+0.1 logit。固定六情景中≥5个同时满足才称该背景/终点“稳定支持”；比例不可判者不算成功，分母不缩为可判子集。

两随机不能标定总体零分布，5/6也不是显著性检验，不报二项尾概率。N 停止侧为预定主判断，其余三组完整展示，不择优合并为成功。预期不成立时，区分反向、弱、异质和不可判，不能全打成“没有作用”。

必须带上的混杂： N 的 ‖I13‖（0.0030–0.0053）只有 M_T（0.0115–0.0159）的约 25%–40%。若按线性缩放，M_T 的 ρ 对应 N 约 0.03–0.15；N 实测 0.00–0.03，处在该区间下沿或更低（推测档，依赖线性假设）。本轮不能把“原生背景对第13层不敏感”与“原生背景里这份交互本来就小”完全分开。
