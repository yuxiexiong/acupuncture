缓存形成机制｜原生事实信号分析 v1：分析计划（冻结后再算）

  • 日期：2026-10-31。零 GPU，只读 CFM-S2 formal-r01 的已有资产（84 条轨迹的 L16–18 驱动量与读出，84 份完整 Mτ）以及 S2 记录里的候选分数。
  • 授权：用户 2026-10-31"认可，写分析计划然后直接算"。所在方向是用户提出的工作假说与三点补充（见下）。
  • 本计划在计算之前提交。判读规则以提交时的文本为准，不按结果修改。
1. 要回答的问题

在同一运行条件下，模型对两种事实（f0 与 f1）的区别，在以下各处怎样变化：

  1. 撤针时（τ）的全层缓存，包括 32 层的递推状态与全注意力 KV；
  2. L16–18 每一步的新 value v、旧记忆预测 m = (αS_{t−1})ᵀk̂、实际修正量 e = v − m，以及读出 o = S_tᵀq̂。

并据此在三种情况之间作约束性判断：

  • 情况 I：value 里的事实区别已经变弱；
  • 情况 II：value 里还在，但在减去旧记忆预测后、实际修正中变弱，即"匹配关系"假说；
  • 情况 III：局部读出里事实区别仍在，但候选分数对事实不敏感。

本分析是约束，不是因果证明。所有结果都是在原生轨迹上的描述，不改动任何前向计算。

2. 记号与量
  • 条件 X：00（干净）、10、01、11，两个锚点 L0/C4146/−1、L12/C3621/−1。情景：VAR01、VAR02、VRD01、VRD02、VRL01、VRL02，f0 与 f1 位置对齐。
  • 事实区别：D_X(·) = 量(f0 运行) − 量(f1 运行)，同一条件、同一位置、同一层与头。
  • 参照方向：干净运行的事实区别 D_C。理由：干净模型用这份区别答对了题。
  • 对任一量，把位置、头（以及适用时的矩阵元素）合并后，报告三项：
  • 保留系数 ρ = Σ⟨D_X, D_C⟩ / Σ‖D_C‖²，即沿干净方向保留了多少；
  • 方向余弦 cos = Σ⟨D_X, D_C⟩ / √(Σ‖D_X‖² · Σ‖D_C‖²)；
  • 范数比 r = √(Σ‖D_X‖² / Σ‖D_C‖²)。
  • 位置类：
  • F = 第一个 f0/f1 不同 token 到 b（事实段末）；
  • post = b+1..n−2（问句、指令、模板尾）；
  • last = 末提示 token；
  • cand = 候选位置。

第一个不同 token 之前的位置，事实区别恒为 0，不计入。

3. 分析一：撤针时全层的事实区别（Mτ）
  • 递推状态：对每个线性层 ℓ，D_X = S_ℓ(f0) − S_ℓ(f1)（32 头 × 128 × 128），在 τ 处计算 ρ、cos、r。
  • KV：对每个全注意力层，F 位置的 K、V 与 post 位置的 K、V 分开计算 ρ、cos、r。
  • 卷积缓冲（最后 3 个 post 位置）只作报告，不入判读。
  • 产出：两锚点 × 三个带针条件 × 6 情景的"事实区别随深度"曲线。

判读规则（事先写死）：

  • 对每个（锚点、条件、情景），首个弱化层定义为从 L1 起、递推状态 ρ ≤ 0.5 的第一层；若没有，记"未弱化"。
  • KV 在 F 位置的 ρ 单独报告。KV 写入后不衰减、不擦除，所以 F 位置 KV 的 ρ 低，只能来自 F 写入时的差别，不能来自后续保留或擦除（推导档）。
4. 分析二：L16–18 每一步的 v、m、e、o
  • 由 S2 记录的驱动量，用 S1 的 float64 递推重建每步状态（S2 已验证：与内核暴露状态的误差 ≤ 界的 1.25%）。按源码约定：k̂、q̂ 经 l2 归一化，q 乘 d_k^{−1/2}；α = exp(g)。
  • 每步计算 v、m = (α_t S_{t−1})ᵀk̂_t、e = v − m、o = S_tᵀq̂_t（按头），对每个量求 D_X 及 ρ、cos、r。
  • 位置类分开报告 F、post、last、cand；判读用"post + last"合并（事实必须经这些位置才能到达答案）。三层分开报告，判读用三层合并。

判读规则（事先写死；条件 X ∈ {10, 01, 11}，与 00 比较）：

情况 条件
I value 已弱 ρ_v ≤ 0.5
II value 仍在，修正中变弱 ρ_v > 0.5，且 ρ_e ≤ 0.5 · ρ_v
II′ 写入仍在，读出中变弱 ρ_v > 0.5、ρ_e > 0.5 · ρ_v，且 ρ_o ≤ 0.5
III 局部读出仍在，候选不敏感 ρ_o > 0.5，且候选事实敏感度比 S_fact(X)/S_fact(00) ≤ 0.5
未分类 其余
  • 0.5 是描述性切点，所有连续值同时报告。cos 与 r 用于说明 ρ 的变化是方向偏转还是幅度缩小，不进判读。
  • 若分析一显示事实区别在 L16 之前已经弱化（首个弱化层 < 16），则 L16–18 的情况 I 只读作"进入本窗口时已弱"，不判为"形成端问题"。这是用户补充第 1 点。
5. 与回答的联系
  • 每个（锚点、条件、情景）并列给出：候选事实敏感度比 S_fact(X)/S_fact(00)（S2 记录的候选分数）、分析一的首个弱化层、分析二的 ρ_v、ρ_m、ρ_e、ρ_o。
  • 不计算相关系数，不作因果解读，只逐点并列（用户补充第 3 点）。
6. 不能回答的
  • 任何因果结论：差异在哪里变弱，不等于那里是损失的原因。
  • L16–18 之外各层每一步的 v、m、e：只有 Mτ 状态，没有逐步驱动量。
  • 以干净方向为参照，可能漏掉带针条件下以新方向编码、但模型仍可用的事实信息；正交残差 r 与 cos 会报告，但无法判断其是否可用。

0. 先说不利与出乎预期的部分
  1. "匹配关系"在事实一侧没有出现。 36 个（锚点、条件、情景）格中，没有一个属于情况 II（value 里还在、修正量 e 里变弱）。在 L16–18，e 的事实区别保留系数始终与 v 几乎相同：减去旧记忆预测 m 并没有专门抵掉事实区别。对工作假说在事实这一侧，这是一条不利约束，仅限这个窗口。
  2. 冻结规则的"情况 I"在 L0 上掩盖了一个更重要的现象：事实区别转向，而不是消失。 L0 早段针下，沿干净方向的保留系数 ρ 与余弦都≈0，但范数比为 0.3–3.1，区别仍在，只是换到了与干净方向近乎正交的方向。计划第 6 节写明的局限在这里正好成立：本分析无法判断这些换向的区别是否仍可被利用；候选事实敏感度≈0，说明至少在这批候选上没有被用上。
  3. L0 的格都带"进入窗口前已弱"的标注：L16–18 的结果不能当作形成端判决。决定性的信息在下面的全层曲线里。

2. 这些数据约束了什么（描述档；括号内为依据）

L0 早段针（10）：事实在写入的那一刻就被改写，并且从第一个受影响层开始。

  • 递推状态的事实区别沿干净方向在 L1 只剩 0.45、L2 只剩 0.14，此后各层≈0。
  • 事实段位置的 KV 在 L3–L15 只剩 0.08–0.35。KV 写入后既不衰减也不擦除，所以这部分偏离只能发生在写入时（推导，来自源码）。
  • 针在事实 token 上直接扰动残差，此后各层在这些位置上算出的 k、v 都带着扰动，这是架构上的必然路径。数据显示，扰动使事实区别在写入时就偏离了干净方向。
  • 因此在 L0 早段针上，"事实写对了、后来被保留或擦除弄丢"的解释得不到支持；"事实在形成时被改写（转向）"与数据一致。深层（L23–L31）事实段 KV 沿干净方向的投影系数为 0.47–0.82，候选事实敏感度≈0（−0.01–0.23）。投影系数不是语义信息的保留比例，不能据此说"事实仍在深层"（勘误 2026-10-31，用户指出）。

L0 晚段针（01）：事实段写入与干净运行相同；差异出现在事实之后。（勘误：初稿写"丢在事实之后的携带上"。旧事实 KV 不变，不等于证明了后续携带失败，答案也可能直接读取旧 KV；"携带失败"未经检验。）

  • 事实段在针开始前写入，事实段 KV 全层精确保留（ρ = 1.00）；浅层递推保留到 L10。
  • 损失出现在两处：L12 及以上的递推状态（多数层 0.31–0.63，L20 例外为 0.90）；事实之后位置写入的 KV（0.03–0.13）。后者正是针所在的位置。
  • 候选事实敏感度比 0.00–0.51。

L12：事实大体保留，弱化从 L13 开始，在晚段针在场时更明显。

  • 早段针（10）的保留最多：L16–18 约 0.62–0.68，深层 0.6–0.8，事实之后位置的 KV 保留 0.65–0.92；候选事实敏感度比 0.13–0.89。
  • 晚段针在场时（01、11），递推在 L14–L18 降到 0.18–0.44，事实之后位置的 KV 降到 0.37–0.53。

L16–18 内部（逐步 v、m、e、o）：e 始终跟着 v；读出 o 略低于 e（L12 中 3 格判为"写入仍在、读出变弱"）。在这个窗口里，事实区别的变化发生在输入的 value 本身，而不是在新信号与旧记忆预测相减的那一步。

3. 对工作假说的含义
  • 停嘴与事实分开解释是对的。 停嘴：S3 的介入证据指向晚段 v。事实：本分析显示，差异出现在针所在的位置。早段针下事实区别在写入时就转向；晚段针下事实段写入与干净运行相同，差异出现在事实之后的位置与较深递推。后者的含义未经检验。
  • "新信号与旧记忆预测之间的错配"在事实这一侧没有观察到，至少在 L16–18。它仍可能在更浅层（如 L1–L3）起作用，但本分析在那些层只有撤针时的状态，没有逐步的 v、m、e。
  • 事实区别的"转向"是新问题。 早段针下，事实区别没有消失，而是被写成了与干净运行不同的方向。它是否仍被模型以别的方式使用，本分析答不了；候选分数显示这批候选上没有被用上。
4. 由数据指向的下一个连接（只提出，未执行）

数据把 L0 事实丢失指向一个具体位置与变量：事实段位置上、第一个受影响层组（L1–L3）的写入。下一步若做模型实验，只需补这一处：

  • 只在事实段位置、只在 L1–L3，把写缓存变量换回干净值，其余全部原生，看候选事实敏感度是否恢复；
  • 反过来，只把这些层这些位置的带针值移植进干净运行，看能否制造出事实丢失。

两者结果一致时，才能把"事实在形成时被改写"从描述升级为因果结论。规模很小，每情景几条运行。另外，若要检验更浅层是否存在"错配"，需要捕获 L1–L3 的逐步驱动量，也是很小的一轮运行。两者都需要你另外授权。
