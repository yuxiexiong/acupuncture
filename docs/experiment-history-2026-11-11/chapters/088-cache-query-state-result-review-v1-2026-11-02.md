##### 反方检查与修订

- **平均差可能来自本场景泄漏。** 按基础场景整折排除，所有排列/查询一起排除；每场景先均值再五场景等权。旧行为已见仍必须标开发证据，不能叫未见测试。
- **只要随便改状态都能恢复。** 增加同块名义等范数随机参照；实际BF16编辑总范数5%内才作方向优势判读，若不配平不能事后调阈值。一个随机样本不能证明对所有随机方向都优越。
- **任何损伤都能称重现。** A必须重现V原始token序列，不能以错误率增加代替；全部非D格新增损伤也报。严格重现不达时不临时改成宽松类别成功。
- **R成功只是补偿，不能解释原错误。** 因而主结论要求A也重现且均优于参照；仍只支持指定背景作用，不证明唯一原生中介。仅R有效单列补偿候选，不能冒充双向机制。
- **C1343无缺口会被删除，R0少数场景制造高比例。** 保留四方向，缺口≤0或不足四场景正缺口就不判跨场景补足。已知R0恰有四场景，弱覆盖如实报告，不把总体比率包装普遍成立。
- **均值几何好看但输出无效。** 几何不用于挑层、改强度或筛场景；即使几何好，也允许行为阴性并结束候选。正反编辑共用μ/r，倍率固定1。
- **q/k差可能只有无效最老槽大。** 新编辑与几何只用有效后三槽；原F/V全块桥接不变，避免把死槽范数当作用证据。
- **既有pt可能不是原始缓存，预算漏一次重建。** 已追踪QST→NQ→SVQ generate返回的是step1/step2/diag logits。预算独立计240采集和240正式形成；未假定全缓存永久存在。
- **预检未测试非零模型作用。** 它只验工程等价，非零公式/分块/随机范数做CPU合成测试；采集后冻结μ/r，实际组装范数不过即工程不可判。不能要求预检出现预期科学效果。

修订后C01/C02/C08/C14仍成立：比较直接检验“可共享的形成差分是否足够搬运已知行为效应”，没有用有限范围为无识别力比较开脱。数学定义与预算已冻结；新模型实现仍待写，不能声称数值闸门已过。

##### 2. 原报告三处需要收紧

1. **“所有答案完全不变 / J全部0”不能覆盖所有臂。** R0的H_T有一条变化：接收者 `NA-NQ03-ABC-C` 原题为W19，自供体输出W35；供体换成 `NA-NQ03-ABC-B` 后输出W19。这个主对照J=0.5、W=0，R0 H_T等权J=1/72≈0.01389。它没有跟随供体目标，稳定转移结论仍为阴性。U与H_C的84/84结论成立，不能扩大成所有H_T也逐token不变。
2. **“q/k张量几乎相同”缺直接距离证据。** `qst_run.py`保存到pt的是生成首步、第二步及诊断logits字典；归档没有给出q/k跨查询距离。小输出变化与未转移也可能来自读出不敏感、冗余或替换背景，因此应写“在指定替换下输出对供体查询身份不敏感”。有限精度间距不是已经测定的误差/噪声上界，0.25不能直接当可忽略噪声。
3. **“S和全注意力KV里显然有查询信息”是定位过度。** 恢复后能答原题说明整个接收背景保有可供利用的任务约束；本轮没有分别定位到S与KV，也没有排除浅层/当前输入条件的贡献。“需要干净q/k”也不是必要性定理：C1343的受针q/k同样48/48。准确说法是：在有恢复差距的三个方向，测试过的同组干净供体均能补足差距，正确查询身份并非这些成功恢复的必要来源条件。

本文件保留旧报告作为历史证据，以上更正作为新的审读口径，不改冻结记录。不能把“末端投影候选阴性”推成“问题未编码”“信息已删除”或整个课题失败。

##### 3. 下一步的取舍与核心问题

主线不变：稀疏针怎样改变写入、旧状态处理和读取，最终产生大的回答效应。

**推荐QCO-01：检验受针形成的末端q/k变化是否含有跨记录可复用、能恢复并重现原有回答效应的共同加性分量。** 这比“看哪些层差最大”更直接：结果需要由其他场景构造的编辑提前预测本场景的完整回答变化。不是因为QST阴性就自动扩层，也不继续寻找供体查询身份转移。

具体候选：对每种既定针方向，其他场景的平均受针−干净差，若是实际起作用的共同分量，那么从本题受针q/k减掉它应补回一部分V-only的交付缺口；向本题干净q/k加上它，应重现一部分V-only的原有错误。等范数随机方向若同样有效，则不能归因于这份共同偏移的特定取向。

阳性最多提供**跨记录可搬运的状态差分及其双向行为作用**，不是低秩定理、完整计算机制、原生唯一中介或无损修复方法。阴性结束“单位强度共同均值偏移足够”的候选，不自动转去调倍率、PCA选秩、挑层/头。原报告建议的逐层几何可作为描述表，但不作为下一轮核心终点，也不依它挑干预位置。

##### 5. 不用本场景估计的共同偏移

对输入i、方向d、层l、通道组g∈{q,k}、有效槽t，记卷积历史为Q_C(i)、Q_T(i,d)，`Δ(i,d)=float32(Q_T)−float32(Q_C)`。

六个基础场景分六折。接收场景s的偏移：

`μ(-s,d) = (1/5) Σ[r≠s] mean_{i∈r} Δ(i,d)`。

每场景先对其所有可比排列/查询取平均，再对五场景等权，避免有9条的场景比6条的场景权重大。本题及同场景的任何查询、排列都不参与其μ。六折、四方向全部使用；只排除相应场景，不根据答对/错筛训练条目，不拟合倍率，不改符号。所有μ与来源清单在任何新编辑输出前冻结。

这是已见开发面板上的跨场景构造验证，不是未见题外部确认，六折也不是独立六次实验。每折一个高维固定偏移不等于已证明低秩。

描述项固定为：逐层/逐qk/逐有效槽的Δ范数、μ范数、`cos(Δ_i,μ_-s)`、`||Δ_i−μ_-s||²/||Δ_i||²`；零分母记NA。不挑最高层、不选最佳折，不以相似度高自动当行为因果证据；几何弱也不修改既定行为测试。

##### 6. 六臂比较与必要参照

每个输入i、方向d固定接收者其余状态为T(i,d)，G卷积V均取C(i)。S、KV、浅层与位置/末提示token在分叉起点固定；之后所有变量正常响应。q/k变化也影响当前写入和读取，测总效果。

| 臂 | G卷积q/k | 用途 |
|---|---|---|
| V | Q_T(i,d) | 旧H_T自身参照 |
| F | Q_C(i) | 旧H_C自身恢复参照，不称理论上限 |
| R | Q_T(i,d)−μ(-s,d)，只改有效三槽 | 不使用本题干净q/k的共同分量去除；V仍来自本题C，不能称完全无本题干净状态 |
| A | Q_C(i)+μ(-s,d)，只改有效三槽 | 同一受针接收背景中重现V-only错误；不是向原生干净全模型施针 |
| R_rand | Q_T(i,d)−r(-s,d) | 去除方向的名义等范数参照 |
| A_rand | Q_C(i)+r(-s,d) | 加入方向的名义等范数参照 |

r按每层×q/k×有效槽分别取固定高斯向量，再缩放至该块μ范数；μ块为0则r块为0。种子从`QCO-01|held_scene|direction|layer|q_or_k|slot|r01`的SHA-256前8字节小端整数确定；固定NumPy PCG64及版本。每折同一r用于所有接收者及R/A对称操作，仅一个预定随机参照，不是随机零分布，不挑最好/最坏随机结果。

编辑以FP32运算后一次cast回BF16，记录真正写入后的差分；其余通道与槽必须逐位不变。对R/R_rand及A/A_rand分别检查实际总编辑范数相对差`|u−v|/max(u,v)≤5%`（两者皆零单列无操作）。逐块误差与角度全部报告；不宣称每块实际范数完全相等。未通过则该方向的“优于等范数参照”结论工程不可判，不事后改5%、调倍率或重抽r。

所有48×4×6=1152条自然轨迹，加共享C自然48条、T_nat192条，共1392条；其中624条旧参照、768条新编辑。每条一份同前缀诊断，独立深复制；自然分支不强制、不屏蔽、不继续施针。

##### 7. 完整交付、判据与退出

主终点沿用QST冻结Y_full：旧Y_delivery成立且stop、无未闭合think。编号前文字不剔除；多编号、截断和错误保持在分母。保留全部token、原文、旧Y_delivery/Y_strict、首列/原题/其他/多编号/无编号及改坏格。连续辅助为共同前缀下目标相对首列的logit差（原题即首列时NA），并列目标相对最强其他候选差；不以分数恢复替代完整交付。

按六基础场景先求输入均值，再场景等权平均，记E_s。每方向：

- 缺口`G=E_s[Y_F−Y_V]`；同时公开48输入原始总数。若G≤0或不足4个场景有正缺口，不判“跨场景补足缺口”，完整结果仍报告。QST已有缺口N4146=32/48、N1210=20/48、R0=10/48、C1343=0；对应正缺口场景数6、6、4、0。新运行需重放，不重新选方向。
- 恢复份额`P=E_s[Y_R−Y_V]/G`；随机参照`P_rand`同式。净差包含把原来正确格改坏的代价，不能只挑V错误格计算成功率。
- 预定错误集合`D_i=1[Y_F=1且Y_V=0]`。原错误重现份额`B=E_s[D_i·1(ids_A=ids_V)]/E_s[D_i]`；`B_rand`同式。必须重现原V自然生成token序列，泛泛答错、多列或停止增加都不能冒充原失败模式重现；同时报告较粗错误分类作描述。非D输入被A改坏也全部报告。

**“共同偏移搬运了可观的双向行为作用”**须同一方向同时满足：工程与参照通过；G适用；P≥0.5、B≥0.5；P−P_rand≥0.25、B−B_rand≥0.25；至少4/6场景R−V净交付>0，至少4/6场景出现原V错误重现。阈值是事前最小实质效应/跨场景规则，不是显著性或统计功效保证。四方向逐一报告，不设跨方向多数通过。

| 结果 | 结论与分支决定 |
|---|---|
| 双向与参照差均达标准 | 支持其他场景估计的共同差分可部分解释该背景的行为变化；下一问题才是它通过什么更新/读取计算起作用，不自动宣布原生机制闭环 |
| 只R恢复，A不重现 | 共同校正可补偿，尚未解释原有错误的生成；不能当充分机制或直接扩层 |
| 只A重现，R不恢复 | 加入此偏移可扰动该混合背景，但去除不足；不称主要承载者 |
| R/A与随机参照相近 | 不支持所提共同方向的特异优势，可能是更一般的状态扰动；不从一个随机参照推整个随机总体 |
| 几何相似但行为无效，或仅分数改善 | 结束“均值偏移足以搬运回答效应”的候选；不PCA选秩或调幅救结果 |
| C1343无缺口，或少于4场景可判 | 报告无恢复空间/范围不足及新增损伤，不删方向、不凑平均 |
| 来源、公式组装或实际范数配平失败 | 工程不可判，保留结果和失败，不冒充科学阴性 |

精确token重现是本轮较强承诺；可能因措辞变化而未通过，届时报告类别级描述，不事后把主终点降级。即使全部成功，也不能称查询信息被删、所有针共享一个方向，或复述/选择已分离成独立模块。
