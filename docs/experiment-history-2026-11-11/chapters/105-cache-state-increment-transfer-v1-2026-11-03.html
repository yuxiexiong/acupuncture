SIT-01 v1：写入增量能否跨输出背景发挥作用

Material Passport

2026-11-03；academic-research-suite / experiment-agent / plan。探索性因果检验，非独立确认。设计已完成作者自查；实现、工程验收及运行均未完成。当前用户授权为设计、自查与文档交付，不含新增 GPU/模型运行。 入口：Nugget；作者自查。

1. 设计卡：问题、依据和增量

主线： 解释稀疏激活干预怎样改变写入、旧状态处理和后续读取，最终改变模型答案。 本轮问题： 恢复 t1 输出背景后，留存操作之所以更有效，是否部分因为它生成了一份在原生输出背景里也能起作用的状态增量？

已有事实（来源为项目报告，本次未独立重跑）： - CGV 发现跨针、跨任务、干净背景的效应不同；不能将 L12 的局部 v 修复写成“k 完全无关”。 - NVB 三个缺口方向中，留存 v 对 k 效果的增强在原生输出背景为 +0.25/+0.49/+0.62，在恢复输出背景为 +2.12/+1.45/+1.58。C1343 是必须保留的反例：原生输出背景的增强已达 +3.29。 - NBR 更正后：固定读者和梯度，换状态来源提高一阶目标投影；只换读者作用小。梯度结论随线性化点变化，不能代替有限幅度干预。 - 架构只保证状态差可经读取传播，不保证本轮移植改善目标竞争或完整答案。

新增认识： 将“状态来源变化与效应增强相容”的观察，推进为真实前向中的双向可转移性检验。不是再次检查更新公式，也不是新一轮热点定位。 未知： 跨背景移植状态增量后的真实 M 和 Y；现有记录及一阶投影无法给出。 范围： Qwen3.5-4B，沿用 NVB 冻结模型版本、R 族 μ、针剂量、形成流程；LVK 新面板 48 条现已是开发面板。N4146/N1210/R0 分开报告，C1343 单独对照；不增加输入、模型、针或剂量。

2. 操作：已有八格，只增加四格

沿用 NVB 的 B(c,a,b)： - c=0/1：t1 输出支路用原生局部 v0 / 干净 V 历史条件下的局部 v1。 - a=0/1：t1 留存状态写入用 v0/v1；固定 c,b，a 不改变 t1 输出及非 S 缓存。 - b=0/1：写入键 k0 / 冻结 μ 操作后的 k1；擦除项仍用 k0。 - v1 不叫完整干净运行的 v。B 格也不自动代表自然轨迹。

设 S(c,a,b) 为各格 t1 完成后的 G 层递推缓存。对同一个输入、方向和 b，提取：

ΔS(s,b) = S(s,1,b) − S(s,0,b)。

在接收运行 B(r,0,b) 的整个 t1 完成后、t2 开始前，一次性替换：

S* = S(r,0,b) + ΔS(s,b)。

r 是接收输出背景，s 是增量来源。所有 G 层 [13,14,16,17,18,20,21,22,24,25,26,28,29,30] 联合操作；只改 S，不换卷积、KV、t1 logits、首 token 或位置计数。t2 起取消干预，q/k/v、门、下游状态与生成全部自由响应。

接收背景 r 增量来源 s 条件
0 0 已有 B(0,1,b)，复用
0 1 新增：恢复输出背景产生的增量，放入原生输出背景
1 0 新增：原生输出背景产生的增量，放入恢复输出背景
1 1 已有 B(1,1,b)，复用

每个新增组合分别 b=0/1，共 4 个新增条件。零增量参照为已有 B(r,0,b)，无需增加完整因子网格。

为什么移增量而不移整份 S： 保留接收者基底，避免同时搬入供体基底和其他主效应。这里移的是留存操作产生的实际差，不是把状态交互张量直接加上去。 为什么不按层再拆： NBR 的 16–22/24–30 层建议来自观察性投影。本轮先回答整份增量能否跨背景起效；不按投影大小选层，也不承诺定位哪层负责。全 G 操作不是重开历史暂停的组前/组后八格实验。 固定来源，不做配平： 不放大、旋转或匹配增量范数。本轮测实际增量的转移，不主张方向特异性，不新增随机族；不能从结果区分幅度与方向的贡献。

3. 读数和估计对象

记 F(r,s,b) 为上述运行的读数；Z(r,b) 为 B(r,0,b) 的读数。先报告每格 F、Z 及配对留存效果 F−Z，再计算：

H(r,s) = [F(r,s,1)−Z(r,1)] − [F(r,s,0)−Z(r,0)]。

H(0,0)、H(1,1) 分别桥接 NVB 的 DS0、DS1。本轮两个主要配对比较： - A0 = H(0,1)−H(0,0)：保留原生输出背景时，更换增量来源带来的变化。 - A1 = H(1,1)−H(1,0)：恢复输出背景中，换回原生来源增量损失多少增强。

主读数为 C 路线 M：沿用每输入每方向冻结 fF、目标第二 token 和既定竞争者；目标非首列 32 条、六场景等权。全 48 条作补充，不重选子集。 并列报告 N 路线完整正确 Y、改对/改坏计数、实际停止及首 token 是否为 fF；Y 用全 48 条，列每格结果和同样的交互。t1 已停止就结束 N 路线，不能强迫继续再叫原生回答。MAX_NEW=32、停止集合、解析器沿用 NVB。 t1 G、首 token 和停止不变属于结构/接线检查，不是新增科学效果。M 改善而 Y 不变必须如实保留；不把 M 解释成正确率。

不对 H 作机制份额分解；不把固定来源跨 r 的差称为“纯读者作用”：接收者基底、其他缓存和下游响应仍不同。

4. 可失败预测与判读

工作预测（探索，非预先确认的规律）：三个缺口方向中，恢复背景来源的增量在两种接收背景里都更有利，即 A0、A1 倾向为正。按每个方向、每个场景和逐输入配对值报告幅度与符号，不用 0.25 或多数票贴“机制成立/失效”标签；不承诺三个方向都符合。C1343 不套同一正向预测，完整展示是否不同。

  • A0、A1 都为正且幅度可观：支持实际增量来源对背景差异有可转移的贡献；对照已有 H11−H00 的绝对差描述量级，不称解释份额。
  • A0 小、A1 大：供体增量在恢复接收背景中重要，但未表现出向原生输出背景的同等可转移性；不能将其作用脱离接收条件。
  • A0 大、A1 小：该增量在原生输出背景有作用，但恢复背景也能利用另一来源；允许冗余或非线性，不能强称必要。
  • 两者小或异号：撤回“恢复来源增量普遍更有利”的预测；不能仅凭阴性认定原因必在 q、KV 或某个剩余部件。
  • 方向/场景不一致：差异就是结果，不补题、换针或调剂量；C1343 不从汇总中消失。
  • 数值/来源验收失败：工程失败，不进入上述科学判读。

即使预测全部出现，也只说明这些混合反事实中的有限幅度转移有效；不能声称天然中介、唯一通路、跨模型规律或原生停止已解释。移植后的下游连锁响应是操作总效果的一部分。

5. 最小实现、成本与停止

复用 NVB/NBR 运行器、八格定义和现有状态记录。新增代码只做 t1 后 S 的差分移植和配对汇总；不重写内核、梯度工具或通用框架。

  • 正式新增：48 输入 × 4 方向 × 4 条件 = 768 条 C t2 评分，最多 768 条 N 续写（已停止者不续写）。
  • 源运行/参照最多重放八格共 1536 个 t1 与 C t2；仅当不能从已存的完整接收缓存启动时重建，避免重复形成。最多沿用 240 次形成、48 次预填，沿用旧 token 账本计时；不重跑随机臂或梯度。
  • 新 N 路线最多 768×31=23808 次后续 decode；旧八格 Y 复用通过来源核对的记录。
  • 预检用 NVB 原两条输入、全四方向；来源重放 t1/C t2 各 64，新增 C t2 32，N 后续至多 992。正式逐输入保存闸门；不以预检筛掉科学阴性。
  • 按 NVB/NBR 历史耗时仅粗估约 0.3–0.8 GPUh；重建成本、设备差异另计。按用户探索阶段要求不设固定小时硬上限；先计时估算并报告，不把估算当授权。新增张量流式处理，不扩充大规模存档。
  • 工程检查：模型/μ/输入/前缀来源哈希；旧八格 t1/C t2 逐位桥接；同源 r=s 直接用旧 S 保持原数值路径；FP64 差分加法核对（相对残差 ≤1e−6）；自换/零增量的 logits、非 S 缓存逐位不变；替换不污染其他分支；第 13 层跨来源增量一致性。真实新格允许正常下游分叉。
  • 来源状态必须齐全且 b 配对正确。缺缓存可在上述账本内重放；不能桥接或预算外需改操作则停，记录具体原因。实现失败不自动重试；科学结果弱也不加格。
  • 完成固定四格及汇总即结束。本轮产物只需原始结果/来源清单、verification、DEVIATIONS、配对汇总和短报告。
6. 对主线的交付

这轮推进“恢复条件为何使写入操作有效”：检验条件依赖中可由实际留存增量来源转移的部分。它承接原生连接问题，尚不解释 μ 最初怎样形成，也不承诺一次解释 CGV 的 L12 与新任务边界。结果用于约束下一步，不能提前把 q、KV 或语义特征排进自动执行队列。

实质反方检查及处理
  1. “即使阳性，也可能只是把更强增量加进去了。” 属实。操作检验真实增量是否足够产生跨背景收益，不区分范数与方向；不新增配平来偷换问题。状态来源对实际结果的作用仍是新增因果约束。
  2. “整份供体状态会带入其他好处。” 已修正为接收基底加对应 b 的 ΔS；这仍是人工反事实，不宣称原生自然中介。
  3. “源背景与接收背景不匹配，阴性不能排除状态作用。” 属实。阴性仅否定这份增量在该接收条件下的可转移预测，不判定“关键机制必在写入外”。因此本轮承诺仍可兑现。
  4. “c=0 在 t1 停止，注定无法恢复答案，是空实验。” 本轮主要问题是同前缀目标竞争为何弱；c=1 反向检验还能测试自然完整答案。停止不作为科学成败，条件 M 不包装为原生修复。
  5. “对角重建有浮点误差，四格差可能是假效应。” 对角直接用原状态保留数值路径；新增差分按实际缓存 dtype 保存并做 FP64 核对，来源桥接失败即停。
  6. “四格显著差异也不能解释 L12 或所有新任务。” 正确。范围明确为原生连接的一个条件，不将局部结果扩大成 CGV 总解释。Nugget 使用待检验表述。
  7. “H 的变化可能来自 b=0 那格，不是 k=1 得益。” 因此同时交付各格 F/Z、b=0/1 的留存主效应及改对/改坏；不能只呈现差中差。

1. 问题

恢复输出背景（c=1）产生的留存状态增量，放进原生输出背景（c=0）的接收者后能否改变 k 操作的目标竞争与完整回答？反向放入时又如何？

2. 范围

继承 NVB 合同与冻结 r02：Qwen3.5-4B（revision 851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a）、BF16、eager、batch 1、torch 原核；LVK 新面板 48 条（已见开发面板）、六场景；四方向 N4146 / N1210 / R0（缺口方向）与 C1343（诊断，单列）；R 族冻结 μ、形成流程、校准、停止集合、解析器、MAX_NEW=32。不增加输入、模型、针、剂量或方向。

3. 操作

NVB 八格 B(c,a,b)：c 是 t1 输出所用 v（0 原生 v0，1 局部 v1），a 是 t1 留存状态所用 v，b 是写入键（0 k0，1 冻结 μ 操作后的 k1；擦除键恒为 k0）。S(c,a,b) 指整个 t1 结束后 14 个 G 层 [13,14,16,17,18,20,21,22,24,25,26,28,29,30] 的递推状态。

  • 八个旧格：用冻结的 NVB NHook 重算 t1。t1 bf16 logits、t1 token、C 路线 t2 bf16 logits 和 M 必须与 NVB 正式记录逐位相同。旧格的 N 路线不重跑，直接复用 NVB 正式记录（逐文件 sha 核验）。
  • 增量：ΔS(s,b)=S(s,1,b)−S(s,0,b)，同一输入、同一方向、同一 b。
  • 四个新格：接收者 r、增量来源 s，(r,s)∈{(0,1),(1,0)}，b∈{0,1}。在接收格 B(r,0,b) 的 t1 末缓存深拷贝上，对全部 14 个 G 层一次性赋值 S*=S(r,0,b)+ΔS(s,b)：先用 FP64 求和，再一次 cast 回缓存原 dtype（float32），不缩放、不归一化。卷积缓存、KV、位置、t1 logits 与 token 一律来自接收者。t2 起不挂任何钩子。
  • C 路线：输入冻结的共同首 token fF，读 t2 的 M（NVB 定义：目标第二 token 减竞争者，目标在首列时减第二列）。
  • N 路线：输入接收者自己的 t1 token，贪心续写，到停止或共 32 token 为止；t1 已停止的不续写。
  • 新格计数：48×4×4=768 条 C t2，至多 768 条 N 轨迹。
4. 读数与报告（冻结；实现见 sit_core.py / sit_analysis.py）
4.1 目标竞争 M（主读数）

逐输入计算：F(r,s,b) 为移植格的 M，其中 F(r,r,b)=M(B(r,1,b))；Z(r,b)=M(B(r,0,b))。

  • H(r,s)=[F(r,s,1)−Z(r,1)]−[F(r,s,0)−Z(r,0)]。H(0,0)=DS0，H(1,1)=DS1，与 NVB 定义一致。
  • A0=H(0,1)−H(0,0)：保留原生输出背景，把增量来源从原生换成恢复。
  • A1=H(1,1)−H(1,0)：在恢复输出背景里，把来源从恢复换回原生，损失多少。
  • G=H(1,1)−H(0,0)=DS1−DS0，只作量尺。
  • 同时报告每个 b 的直接效应 F(r,s,b)−Z(r,b)、A1−A0、以及各格均值。

汇总方式：逐输入算，再六场景等权。报告场景等权均值、六个场景均值及正负个数、逐输入正负个数，以及场景分层 bootstrap 区间（输入在场景内重抽，2000 次，种子 20261103，取 2.5% 与 97.5% 分位，仅作描述）。比例 A0/G、A1/G 只在场景等权 G≥0.5 时计算，允许反号或大于 1。主子集为目标不在首列的 32 条；全 48 条和首列 16 条作补充，不重选子集。三个缺口方向逐一报告，不做多数计数；C1343 单独完整报告。

5. 工程闸门（运行中断言，任一失败即停）
