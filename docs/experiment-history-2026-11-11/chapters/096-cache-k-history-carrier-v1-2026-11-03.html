KHC-01：固定供体 Q 下，k 修复历史的 S×KV 载体检验

2026-11-03；v1；依据提交 da97f3be。设计通过作者自查；未实现、未运行，工程验收待完成，无新增GPU授权。 本次交付第一步完整设计及自查，第二步仅给出交接规则，不把未知结果下的计算项替换写成已冻结合同。academic-research-suite / experiment-agent / plan；同作者自查不是独立评审。

1. 设计卡与主线
  1. 核心问题：稀疏干预怎样改变写入、历史状态处理与后续读取，最终改变回答？本轮具体问：在供体 q 已固定时，已能搬运 k 修复的 t1 后历史包，靠 S、KV 各自还是二者组合实现行为转移？
  2. 增量：KRD 已有 H=S+KV 的双向行为证据；本轮新增两个部分交换，确定后续计算研究需保留哪个载体或联合载体。不是再证明缓存存在、模块可交互，不承诺本轮解释更新项。
  3. 依据及反例：KRD 的 H+Q 转移强，但随机加入也有相近比例；C1343分差变化而答案不变；N4146存在方向不对称。旧SK/NR的背景不同，仅提示联合/冗余可能，不能代替本轮结果。
  4. 操作：同输入同方向端点，t1后、t2前对 S/KV 做2×2，t2 Q统一取未混合供体；原接收者卷积及其余缓存保留。四方向、三组双向配对；完整定义见§3。
  5. 估计对象：给定供体Q的受控载体交换效应及交互，不是一般必要性、自然中介比例或两个独立形成来源。
  6. 判读：允许单项承接、两项各自可承接、联合才有效、混合、不一致、小缺口和只有分差无行为。不要求一个单项胜出，不作“载体无关”排除推断。
  7. 范围/成本：48条已见输入、6场景、4方向；正式新增2304条自然轨迹，复用2304条旧控制轨迹；所有重建、诊断重放、供体捕获及预检计入§7。
  8. 退出：一次载体检查后交接到具体计算问题，或因工程不符/结果不稳停止；不再细拆头、层、槽、布局，不自动运行第二步。
2. 固定证据、来源及纠正

固定 da97f3be 中的KRD报告、原合同、实现、回执0、回执1；旧freeze=a9eadd969a34561225a2dddd1ebfaccbe6acc837a5e42ce5da3cead8405f0799。继承QKF/QKD输入、解析器及偏移来源，运行前建立实际文件哈希清单。

KRD实测：共同偏移配对只换H搬运约35%–78%的M缺口，H+Q约75%–90%，并有完整交付变化。这里的百分比不是历史中介份额。“大部分由H承担”不能概括所有35%条件；当前Q也不能被概括为无用。随机加入的比例相近，不继承旧合同绝对转移量的“特异”标签。

架构/推导依据知识审计：在同一G层，当步k参与更新后的S，输出再传向后层；S和KV是不同后续节点，不自动是两个独立来源。初始卷积编辑在t2/t3仍有直接影响；本轮保持这部分接收者背景，既不隔离也不删除它。旧SK、NR不能替代当前混合背景中的载体证据。

KRD残留不归因卷积；F余量不归因V损伤；余量相关性不是准入门槛。采用源码事实指导操作，但不把“传播可能发生”当新机制结论。

3. 固定范围与完整因子表

继承Qwen3.5-4B revision 851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a、torch2.6.0+cu124、transformers5.20.2、BF16/eager/batch1、NA原布局、B1窗口、原−1形成强度及校准。48输入身份、token、排除项完全沿用KRD；方向N4146/N1210/R0/C1343全部保留。

G=[13,14,16,17,18,20,21,22,24,25,26,28,29,30]；全注意力A=[15,19,23,27,31]。五原臂 V/F/Rk/Ak/Ark 从相同受针接收者构建，G卷积V恢复干净；F的q/k也取干净C，但其他历史仍受针，F不是全干净模型。Rk为V的k减μ，Ak为F的k加μ，Ark为F的k加冻结r_post。原编辑通道/槽及μ/r_post直接继承KRD，不重估、不重抽。

有序配对固定6个：Rk←V、V←Rk、Ak←F、F←Ak、Ark←F、F←Ark。随机去除Rrk/V不新增：已有N4146/N1210端点缺口不足，保留其旧结果及遗漏范围，不将它说成随机无效；保留随机加入以检验同方向、可比缺口的载体模式。

t1=输入末提示token；保存五原臂各自t1后缓存c1及首生成token。r=接收者，d=供体，均同题同方向。全部格t2的Q都取原始d在同一个t2输入token上的值：

S交换G全部递推张量；KV交换A全部keys/values，旧前缀必须逐位相同、仅t1新增位置允许不同。两者皆深拷贝。所有卷积缓冲、浅层缓存及管理字段取r；不替换长度、位置、mask。未显式替换的当前k/v/门及后层计算自由响应，不能称它们固定不变。

Q仍是各G层delta内核入口的query（卷积/SiLU后、原L2/缩放前、已广播）；原核完成后处理。供体Q来自未混合端点，不能从新格取值。每格t2仅钳制一次，t3以后无Q钳制。此四格测固定供体Q的条件效应，不测自然Q响应下的S总作用。

4. C诊断路线与N自然路线

C：t2输入旧F首token，所有四格保存M、M_all及全词表logits。主M沿用KRD：目标编号区别token减首列（目标在首列时减第二条）；主判读32条目标非首列，16条首列另报。M_all为目标减其余候选最大值，不混作同一读数。

N：沿用接收者r自己的首token x[r]；d的Q必须由c1[d]输入同一个x[r]计算，禁止跨token取供体。若与C相同则复用Q；否则追加一次来源前向。该供体前向不是自然回答。接收者若首token停止，新操作未到达，仍计入全48自然终点，不改成强制续写。

续写贪心至原停止条件或32个新token（含首token），原解析器给Y_full；保留token原文、改对/改坏、第一条编号、复述/多编号、截断与未到达。M改善但完整交付不变仅是诊断效应。自然分叉以后的状态变化包含在该操作的总效果中。

旧控制复用：新00/11的N轨迹来自KRD r02；每个ID明确记录旧pair/格/路线/token/哈希，不覆盖旧文件。正式C路线四格全部重新算；所有旧00/11的C logits须与KRD逐位一致。预检额外重放00/11的完整N轨迹，逐token及终止方式相同；只要同一实现桥接失败，不允许靠旧自然结果拼出四格。旧原始输出或logits缺失，先报告来源阻塞，不在预算外偷偷重跑。

5. 估计对象与判读规则

对每方向、每有序配对单独计算。令z为M或Y_full，格值z_sb：

  • S在KV=r时的效应：z10−z00；S在KV=d时：z11−z01。
  • KV在S=r时的效应：z01−z00；KV在S=d时：z11−z10。
  • 联合H效应：z11−z00；交互：z11−z10−z01+z00。

分母必须换成当前条件下的H缺口 h=mean(M11−M00)，不能仍用原始d−r缺口来判断S/KV承担比例。原端点缺口g及相对原r的总变化同时报告，保持与KRD可对照。均值先在固定32非首列输入上计算；不先逐题除以接近零的分差再平均。

若|h|<0.5 logit，不给S/KV份额标签，只报原始效应和“小条件缺口”。否则定义pS=mean(M10−M00)/h，pKV=mean(M01−M00)/h，保留负值及大于1，不裁剪；它们不是自然路径份额。

诊断效应按朝11方向计，需平均幅度≥max(0.25 logit,0.25|h|)且≥4/6场景同向；M交互实用容差=max(0.25 logit,0.1|h|)。自然Y用全48题，方向以Y11−Y00为参照，净改变至少2/48才记完整交付支持；Y端点无缺口时只报原值，不除零、不判修复失败。Y交互容差2/48。阈值是实用描述规则，不是统计显著性。

冻结分类（仅对可判的方向×配对；不能由连续比例强迫唯一归属）：任一比例>1.25或<−0.25时优先标为超调/异号，不进入下列单项或双项承接标签。

6. 预测、第二步交接与停止

本轮新增的可失败预测P1：固定供体Q时，S单项在共同偏移的多数配对中承接较多（上述S分类）。这是待检验推测，不是QSR份额必然推出；按方向逐对计数，预先定义多数为每方向四个共同配对至少3个。不足可判配对时标预测不可判，不把小缺口当失败，也不缩小多数规则的分母。P1不成立，不否定KRD的联合H效应，更不否定进一步计算研究。

交接不以单项胜出为门槛：同一无序配对的两个方向若同属S或KV类别，才记录为该配对优先载体；其余保留联合H及不对称。全部小缺口/只有诊断没有行为时，交付受限结论，不为选出载体再换Q、扫层或改阈值。

第二步只列设计约束，本次不冻结执行矩阵或授权： 主问题仍是“t1的k改变怎样形成能搬运修复的历史”。应干预产生历史的具体更新计算，而不只是交换终态。按当前实现key×value记法，更新为 S1=αS0−αβ k(kᵀS0)+βkvᵀ，然后输出S1ᵀq。未来擦除项操作必须同时说明两个k的位置；单独写入项也须定义来源。不同项混用k是人工计算反事实，不称原模型天然分离通道。

“两项都换”的工程参照只能是同一步、同背景、同k来源的完整k节点替换；不能要求复现原始卷积k编辑在t1/t2/t3的全部修复。必须让S、当步输出、下游KV及新卷积槽正常响应；明确哪些局部变量钳制、哪些动态生成。重写更新核的无操作须与原核逐位一致，不能在失败后放宽容差救结果。

第一步只帮助选择第二步应保存/观测的载体，不证明它的形成项，也不能把Q固定供体的条件结论直接搬到自由Q运行。第二步需另写具体反事实、双向预测、完整预算、自查及数值验收；若联合有效就保留联合观测，不强迫再拆S/KV。无论本轮结果如何，不自动上卡第二步。

依据计划 docs/cache-k-history-carrier-plan-v1-2026-11-03.zh-CN.md 与自查（c0b42667），加上我审阅时补的一条工程闸门（§6 N 路线桥接）。授权：2026-11-03 用户“开始”。冻结后不改本文件；偏离记入 DEVIATIONS.zh-CN.md。

1. 问题

在 t2 的 q 节点固定为供体的条件下，KRD 已证明能搬运 k 修复的 t1 后历史包，是靠 G 层递推 S、A 层注意力 KV 各自承接，还是要两者组合。估计对象是固定供体 Q 下受控载体交换的效应与交互；不是一般必要性，不是自然中介份额，也不是两个独立的形成来源（KV 差异本身是 t1 上游 G 层写入经输出传下去的结果）。

2. 固定条件

继承 KRD r02：模型 Qwen3.5-4B revision 851bf6e8…，BF16/eager/batch 1，torch 原核；48 条输入、6 场景、方向 N4146/N1210/R0/C1343。G 与 A 层组同 KRD。五臂 V/F/Rk/Ak/Ark，μ_k、r_post,k 原样复用。随机去除（Rrk/V）不新增：KRD 中它在 N4146/N1210 的端点缺口不足；这不等于随机去除无效。

3. 操作
  • 有序配对 r←d：Rk←V、V←Rk、Ak←F、F←Ak、Ark←F、F←Ark。
  • 四格 sb：t2 前 G 层全部递推 S 取 d（s=1）或 r；A 层全部 keys/values 取 d（b=1）或 r。KV 旧前缀必须逐位相同。卷积缓冲、浅层缓存、长度/位置/掩码全取 r。
  • 每格 t2 的 Q 一律取原始 d 在同一 t2 输入 token 上的 query（14 个 G 层内核入口），只钳制 t2。新 00 格等于 KRD 的 01 格（只换 Q），新 11 格等于 KRD 的 11 格（H+Q）。
  • C 路线：t2 输入旧 F 首 token，四格全部重算，保存 M、M_all、全词表 logits。
  • N 路线：t2 输入接收者自己的 x[r]；供体 Q 在 c1[d] 上用同一个 x[r] 捕获，每个配对额外一次前向。新格 10/01 贪心续写到停止符或 32 个新 token；00/11 复用 KRD 自然轨迹（见 §6 桥接）。x[r] 是停止符则未到达，照常计入。
4. 读数

M 判据用目标非首列 32 条（首列 16 条另报），Y_full 用全 48 条（原解析器）。

5. 冻结判读（实用幅度，非显著性）
  1. h＝mean(M11 − M00)。|h|<0.5 → 小缺口，只报原始效应。
  2. pS＝mean(M10 − M00)/h，pKV＝mean(M01 − M00)/h，不裁剪；同时报 KRD 的 g、h/g、以及 KRD 的 10 格比例（Q 取接收者时只换 H），供对照，不进判据。
  3. 格 c 的诊断效应（朝 11 方向）：sign(h)·mean(Mc − M00) ≥ max(0.25, 0.25|h|)，且 ≥4/6 场景同向。
  4. Y 支持：方向 s＝sign(ΣY11 − ΣY00)；s≠0 且 s·Σ(Yc − Y00) ≥2。Y 端点无缺口时，用诊断规则代替 Y 支持，类别加后缀“_diag_only”。
  5. 分类（取第一个满足的）：small_h；超调/异号（pS 或 pKV >1.25 或 <−0.25）；S（pS≥0.75、|pKV|≤0.25、S 有诊断效应和 Y 支持）；KV（对称）；both（两者都 ≥0.75 且各有诊断和 Y 支持）；joint_only（两个单项都没有诊断效应，联合有诊断效应和 Y 支持）；其余为 mixed。
  6. 交互：M 的 |mean I| > max(0.25, 0.1|h|) 才算实用；Y 的 |ΣI| > 2 才算。二值饱和会造成行为交互，不当作内部协同的证据。
  7. 共同对随机：只比较加入侧（Ak←F 对 Ark←F，F←Ak 对 F←Ark），两边 |h|≥0.5 才并列 h、pS、pKV 与类别；只作描述，不设特异性门槛。
  8. 交接：同一无序配对两个方向同为 S 或同为 KV，才记为该配对的优先载体；其余保留联合 H。C1343 按同样矩阵报告；余量不归因于 V。
6. 预注册预测与工程闸门
  • P1（计划，推测档）：每个缺口方向的 4 个共同配对中，至少 3 个类别为 S。可判配对少于 3 个时标为“不可判”。P1 不成立不否定 KRD 的联合 H 效应。
  • 闸门（运行中断言）：
  • 五臂 t1 的 logits/缓存与 QKF/QKD 一致，x 与 KRD 一致；五臂 C 路线 t2 的 M 和 bf16 logits 与 QKD、KRD 一致。
  • 新 00/11 格的 C 路线 M 与 bf16 logits 和 KRD 的 01/11 逐位相同（全部输入）。
  • N 路线桥接（合同补充）：正式运行中，每个已到达的新 00/11 格补一次 t2 前向，bf16 全词表 logits 与 KRD 存档逐位相同，argmax 与 KRD 轨迹的第二个 token 相同。预检做完整轨迹重放，逐 token 和终止方式相同。
  • 交换：只有指定的 S/KV 来自供体，其余全部等于接收者；Q 钩子在 t2 的 14 个 G 层各触发一次，内核实际收到的 query 等于来源；源缓存、C/T 供体前后不变。
  • 仅预检：自体操作、不挂 hook 与捕获前向逐位相同（80 次工程前向）。
  • 预检失败保存并停止；允许一次有记录的修复重试。正式开始后不改实现。

0. 先说限制
  1. 不特异。 随机加入（Ark←F、F←Ark）在三个缺口方向上和共同偏移一样，都判为 S（pS 0.96–0.99）；C1343 上四个共同配对是 S_diag_only，即 M 由 S 承接，但答案不变。“S 承接 H 的效应”是 k 扰动的一般形态，不是共同偏移独有的。
  2. 结论限定在 Q 固定为供体的条件下。 Q 取接收者时（KRD 的 10 格背景）没有拆 S/KV，本轮不外推。
  3. KV 不是空操作，只是对 M 几乎没有作用。 1152 个格子里，只换 KV 的 t2 logits 都与 00 格不同；但 |M01 − M00| 的中位数为 0（在 bf16 刻度以下），最大 0.25。所以“KV 的贡献可忽略”只针对 t2 的固定竞争分差和完整答案，不说明 KV 在别的读数上不起作用。
  4. KV 差异本身来自 t1 上游 G 层的写入，S 和 KV 不是两个独立来源。本轮只说明：到 t2 时，差异保存在 S 里起作用，保存在 A 层 t1 位置 KV 里的那部分几乎不起作用。
1. 工程
  • 全部闸门通过：
  • 五臂 t1 与 QKF/QKD 一致；五臂 C 路线 t2 与 QKD/KRD 逐位一致。
  • 新 00/11 格的 C 路线 M 和 bf16 全词表 logits 与 KRD 的 01/11 逐位相同（48×4×6×2 = 2304 格）。
  • N 路线桥接：2304 个复用格的 t2 logits 与 KRD 存档逐位相同，下一个 token 与 KRD 轨迹一致；预检中 96 条完整轨迹逐 token 重放一致。
  • 交换只动指定分量；Q 钩子触发次数与来源核对通过；源缓存不变；预检 80 次工程前向等价。
  • 计数：解码前向 17232（上限 81408），新自然轨迹 2304。设备时间 1446+1059 = 2505 s（0.70 h），加预检约 0.74 h，在 1.5 h 总上限内。

3. 预注册对账与交接
  • P1（每个缺口方向至少 3/4 个共同配对为 S）：3/3 方向成立，每个方向都是 4/4。
  • 交接：三个无序配对（Rk/V、Ak/F、Ark/F）在三个缺口方向上两侧都是 S → 优先载体为 G 层递推 S。
  • 共同对随机（加入侧）：两边类别相同、pS 相近，按合同只作描述，结论是不特异。
4. 能说什么、不能说什么

能说的（限 Q 固定为供体、这个混合背景）：

  • KRD 中 t1 后历史包对 k 修复的承载，几乎全部落在 G 层递推 S 上；A 层 t1 位置的注意力 KV 对 t2 的固定竞争分差和完整答案几乎没有贡献。
  • 这对修复、致错、随机加入都成立，C1343 上也一样（只是答案不翻）。

不能说的：

  • 不能说 Q 取接收者或 Q 自由响应时也是如此。
  • 不能说 S 是一般的必要或充分条件；卷积残留与 t2/t3 的直接通路还在接收者里。
  • 不能说这是共同偏移特有的计算。
