3.3 A：抵消实测 L0 当步残差增量

先用同执行路径的 C/T 参照，在每个 t∈L 捕获第 0 层完整输出残差 r0_C(t)、r0_T(t)，记录二者针前输入一致。定义 δ0(t)=float32(r0_T(t))−float32(r0_C(t))。

在 XA、XAB 的第 13 层 input_layernorm 之前、完整残差流入口，实施：

r13 ← cast_BF16(float32(r13) − δ0(t))。

这是本版明确的减法定义；δ0 不预先舍入为 BF16，不用参考范数乘权重列替代实测差值。记录实际 BF16 前后差及舍入残差。原针的 BF16 算术不改。只有有限精度下定义明确的入口抵消，不称“精确取消针”。

固定 token 前缀下，后续层和 B 不反馈改变第 0 层输入；XA/XB/XAB 的第 0 层输出应与 T 相同，逐位置验收。A 不撤销浅层已经产生的分支响应，也不清除深层先前积累的状态。有效时只说明这个入口操作改变形成结果，不能据此量化自然直接路径。

3.4 B：每步计算前固定浅层过去状态

对每个 t∈L，在层 ℓ∈{1,…,12} 的 token mixer 读取缓存之前，置入 C 的同位置边界状态 M_C(ℓ,t−1)：

  • 线性层：同时替换过去递推状态与短卷积缓冲。
  • 全注意力层：替换过去位置 0…t−1 的 K/V；不能带入当前 t 的 K/V。
  • 长度、位置索引、初始化标记和 mask 必须与接收者当前边界一致；不得通过替换整个全局缓存对象误改深层。

随后以接收者当前残差正常计算当前 q/k/v、门、状态更新和输出；这些当前结果本步可以影响后续层。下一位置再置入对应干净过去状态。深层各层保留自身历史；不固定 α、β 或 k 的单独用途，不用补偿 v 保持某个乘积。

B 阻断“受扰浅层过去状态值被后续位置继续使用”，但保留“受扰当前输入如何读取干净过去状态”。因此不是取消所有历史、不是只改变遗忘，也不是恢复原生干净轨迹。t=b+1 时过去历史本来相同，B 应是惰性的；这作为时序验收，不算科学发现。

3.5 τ 后统一评分：隔离形成期后果

每个 X 在 τ 后先保存本格完整状态，然后构造：

M_score(X) = C 的层 0–12 全部缓存 + X 的层 13–31 全部缓存。

移除针、A、B 全部 hook；从独立深拷贝输入同一个 x[n−1]、相同位置与 mask，取首步全词表 logits。不延续某格的前缀残差，不移植它的末步 logits。评分时深层查询和更新正常响应。

用 F 表示这次固定权重、输入及执行路径的评分计算，则 z_X = F(M_C浅, M_X深; x[n−1])。两格唯一不同的评分初始数据是深层状态，因此两者输出差异可归于不同形成操作留下的深层状态差异。这个识别结论包含深层状态引起的正常读取变化，不是固定所有查询的纯状态效应，也不识别原生自然中介份额。

C 单独评分得到 z_C。另从 T 原生完整缓存分支评分 z_T，作为旧 E2 原生端点验收；不增加一条 T 前缀，不能把它当 X0。X0 的统一评分必须对应 E2 的 a 格。

5. 预先固定读数与比较

令停止集合 E 继承引擎 {248044,248046}，运行前与 E2 metadata 再核验。每输入：

D_X = max(z_X[E]) − max(z_X[非E])。

EOS 单列为实际 greedy argmax 是否属于 E；D=0 时保留实际 tie-breaking，不用阈值替代解码。每个情景的主 D 为两事实的均值，原始两条值同时保留，防止均值掩盖异号。情景不作多数投票，无显著性检验，不把 12 输入算 12 个独立样本。

定义 Δ=D_X0−D_C，报告下列全部配对差：

  • A 在 B 关闭时：D_X0−D_XA；A 在 B 开启时：D_XB−D_XAB。
  • B 在 A 关闭时：D_X0−D_XB；B 在 A 开启时：D_XA−D_XAB。
  • 联合：D_X0−D_XAB。
  • 交互：I=D_XAB−D_XA−D_XB+D_X0。非零只表示该评分下的非加和，不等于递推内部协作。

归一化辅助量均除以同一 Δ，不能使用原生 T−C 分母。定义 R_A、R_B、R_AB 对应从 X0 出发的三个削弱比例。Δ≤0 时不套恢复标签，只报原始差与异常来源；Δ=0 时比例不可定义。旧 E2 基准本应 Δ>0，若重放不符应先在工程闸门处理，不另挑“更强输入”。

量级标签仅作预先固定的描述：|R|≤0.3 为弱，0.3<R<0.7 为部分削弱，R≥0.7 为强削弱；R<−0.3 为增强；R>1 单列越过干净基线的反转，不能叫“恢复更好”。0.3/0.7 沿用 E2 的描述尺度，不代表显著性、唯一机制或检测到零效应。对 B 在 A 开启时等条件差，同样报告符号及相对 Δ 的量级。

评分非线性检查，不加模型调用：固定各输入 C 中分数最高的停止 token e 和非停止 token c，所有格另外报告 m_X=z_X[e]−z_X[c] 及其四格交互，并记录各格实际两个 max 的 token 身份。若 D 的交互与固定对比不同，明确赢家切换参与了读数变化；即使 m 也有交互，也不能把它定位到某个内部运算。m 是解释辅助，不替换主读数 D，不从多个 token 对里选最漂亮的结果。

A 在两种背景都强削弱；B 在两种背景都弱 已发生浅层响应后，入口减法仍大幅改变深层效应；清除浅层过去状态并非当前操作下的主要敏感因素 将 E2 的深层效应与指定入口扰动联系起来 削弱“必须靠浅层受扰过去状态才能形成该效应”的操作性预期；保留深层自身历史。不能称未经处理的针直接传到底或证明浅层无作用。
两者各自部分削弱，联合进一步削弱 两类形成操作都有影响，单独不足以替代联合 给 E2 增加多种形成条件约束，和 S3 的背景依赖相容 后续解释须同时容纳两类条件；不把恢复比例相加成自然份额。
单独都强，联合不再明显增加 两种不同操作都能破坏这份深层效应 证明存在多个有效干预入口，不是证明存在两条独立承载路径 共享下游瓶颈、非线性阈值、相互依赖仍可能；不按“冗余两路”立项。
单独弱、联合强，或某操作只在另一背景有效 形成效应对操作组合有条件依赖；单因素结论不稳定 与 S3 非单调组合形成可比较的约束，但没有证明两者同一机制 先检查固定 token 对比与原始 logits；不能由 I 直接命名 K/V 或递推交互。
B 增强，或 A 增强／联合反转 被改动的形成条件可能原先限制了输出效应，或操作引入新的状态组合 提醒解释必须容纳 S2 的部分抵消与 S3 的异号作用，但不据此断言同源 撤回“这项操作应恢复”的方向预期；不调剂量救假说，不把异号改称支持。
A/B 及联合均弱 这两项操作在统一背景中都未大幅削弱既有深层效应（仅有限面板、描述尺度意义） E2 的承载结论保留；本轮没有给入口抵消／浅层过去值依赖提供强支持 结束本分支；不把剩余命名为浅层同位置放大，不自动换层或换模型。
情景之间方向不同或只一事实版本有效 形成依赖与输入有关，不能用一个全局方向概括 为后续解释增加适用条件，而非删除反例 报告逐情景、逐事实分布；同面板事后分组标探索，不能直接包装独立验证。
工程不通过 对形成机制不增加科学认识 旧资产不受影响 保存失败、停执行；不得把不复现当新机制。

本轮没有确定证据支持 A 或 B 必然更强，不伪造方向性理论预测。预先登记的是上述可区分的操作响应及撤回规则。结果价值在于排除／约束形成条件解释，不在于保证得到阳性。

跨资产最终只能形成：“E2 的特定深层状态能承载分数偏移；本轮某形成操作改变了这样的状态及其条件性输出效果”。S3 的 V 证据仍是旁边一块未接通的证据。即使结果全阳性，也尚缺具体 V 内容、实际读取运算与原生回答的连接；本轮不自动获准补这些实验。

3. 执行路线与操作定义

路线：五个条件共用位置 0…b 的一次干净整段前向（这段在所有条件中都无针）；L 内每个位置 t 依次以单 token 前向推进 C、T、XA、XB、XAB。

  • A：δ0(t) = float32(r0_T(t)) − float32(r0_C(t))，r0 为第 0 层解码层完整输出残差，取自同一步的 C 与 T。在 XA、XAB 中，第 13 层解码层入口（input_layernorm 之前）执行 r13 ← BF16(float32(r13) − δ0(t))。δ0 不预先舍入；每次记录 ‖δ0‖、实际改变量、舍入残差。

R0 来源 E2 整段路径的 C、T（L0·01）：τ 缓存清单 + 首步 token/D/logits 哈希/top5 与 E2 记录逐位相同 预检
R 路线容差 逐步路径的 C、T_native、X0 三个首步 D 与 E2 的 00、L0·01、a 之差都 ≤ 0.05 × Δ_E2（Δ_E2 = D_a − D_00，取自同一输入的 E2 记录，且须 > 0）。0.05 在探针之前写入代码 每个输入
时序 每一步 XA/XB/XAB 的第 0 层输出与 T 逐位相同；B 在 t=b+1 逐位惰性；A 在 XA/XAB 中恰好作用 |L| 次，其他条件 0 次 每个输入

这些闸门只验操作与数值，不以效应方向为通过条件。

5. 读数

每个输入、每个评分格：D = max(z[E]) − max(z[非E])，E = {248044, 248046}；EOS = 实际 argmax ∈ E；固定 token 对比 m = z[e] − z[c]，e、c 为 C 评分中停止集合内、外的最大者；记录各格两个 max 的 token 身份。

情景层面：D 为两事实均值，同时保留两条原始值。Δ = D_X0 − D_C。

量 定义
A|B0 D_X0 − D_XA
A|B1 D_XB − D_XAB
B|A0 D_X0 − D_XB
B|A1 D_XA − D_XAB
AB D_X0 − D_XAB
I D_XAB − D_XA − D_XB + D_X0
R_k 上述差 / Δ（Δ ≤ 0 时不定义，不贴标签）

同样的量对 m 另算一套（解释辅助，不替代 D）。

描述尺度（不是显著性）：R > 1 越过干净基线的反转；0.7 ≤ R ≤ 1 强削弱；0.3 < R < 0.7 部分削弱；−0.3 ≤ R ≤ 0.3 弱；R < −0.3 增强。弱不等于零效应。本面板没有效应量的零分布（方案 E25 固定五条件、不加对照矩阵）；报告路线容差 |ΔD|/Δ_E2 作为数值底参照，不作为零分布。

6. 判读（按情景，可并存，不贴整模型单一标签）
行 判定式（bands 按 §5） 可以支持 不应推出
B 两背景强、A 两背景弱 B|A0、B|A1 强；A|B0、A|B1 弱 持续把浅层过去状态置为干净，会大幅减少深层最终效应；入口抵消不足以产生同等改变 原生唯一历史通路；α 主导
A 两背景强、B 两背景弱 对称 已发生浅层响应后，入口减法仍大幅改变深层效应 针直接传到底；浅层无作用
两者部分、联合进一步削弱 A|B0、B|A0 部分，且 R_AB − max(R_A|B0, R_B|A0) > 0.3 两类操作都有影响，单独不足以替代联合 把比例相加成自然份额
单独都强、联合不再明显增加 A|B0、B|A0 强，且 R_AB − max(…) ≤ 0.3 存在多个有效干预入口 两条独立冗余承载路径
条件依赖 (A|B0、B|A0 弱且 AB 强或反转) 或 某操作在一个背景弱、在另一背景至少部分 形成效应对操作组合有条件依赖 由 I 命名 K/V 或递推交互
增强或反转 五个 R 中任一为增强或反转 被改动的形成条件可能原先限制了输出效应，或操作造成新的状态组合 把异号改称支持；调剂量救假说
全弱 A|B0、B|A0、AB 都弱 两项操作在统一背景中都未大幅削弱既有深层效应 把剩余叫"浅层同位置放大"；自动换层换模型
事实版本不一致 任一事实 Δ ≤ 0，或五个差在两事实间的档位或符号不同 形成依赖与输入有关 用均值掩盖

另报：情景间符号不一致（各差）；赢家切换（X0/XA/XB/XAB 中两个 max 的 token 身份是否变化）；D 与固定对比的 I/Δ 是否落在不同档位。后两者出现时，D 的交互不定位到任何内部运算。

7. 规模与停止
  • 预检：VAR03-f0，1 个 worker；R0 的 2 前缀 + 2 评分、五条件 5 前缀 + 6 评分、惰性钩子重跑 2 前缀 + 2 评分，合计 9 前缀 / 10 评分（方案 §8 上限）。

  • 停止：预检任一闸门不过不进正式；正式任一输入闸门不过即整轮停止，保留已完成记录，不自动重跑。固定面板完成即停，不因结果扩题、加剂量或换层。
8. 保存

决策日志
  1. 路线修订（偏离方案 §4.2-2，影响"与 E2 是同一个数值实验"这一表述）。 B 必须逐位置执行；Qwen3.5 线性层多 token 时调用 torch_chunk_gated_delta_rule、单 token 时调用 torch_recurrent_gated_delta_rule，两者算法不同，全注意力的矩阵形状也不同。探针 readiness/probe-r01.json（2026-10-31 11:49 UTC，GPU0，只跑 C、T）：E2 整段路径的 C、T 逐位重现 E2；逐步路径的缓存清单与 logits 哈希都不同，D 差 C 0.0、T 0.0625（Δ_E2 = 17.2）。方案对这种情况的规定是"预检停止……数值路线修订另行记录后才重审"。本合同在冻结前登记修订：R0（整段路径逐位溯源，预检）+ R（逐步路径对 E2 三端点的 0.05 × Δ_E2 容差，每个输入）。0.05 写在 form_ab.PATH_TOL，在探针之前确定：probe-r01.json 的 tolerance_preset（0.8609 = 0.05 × 17.22）是探针运行时从该常量算出的。所有可以逐位做到的闸门（时序、B 来源、结构、评分隔离、惰性钩子）仍为逐位。重审由同一助手完成，不是独立审查；用户可以否决这一修订，届时本轮数据只能作为修订路线下的结果。
  2. 五个条件共用 0…b 的一次整段前缀：这段在所有条件中都无针（E2 的 L0·01 掩码在这段为 0），因此共享不改变任何条件的定义。
  3. 评分只做首步，不调用 S3.run_once（它会做候选强制，方案 §4.1 不增加）。form_ab.score 与 run_once 首步逐位一致，由 CPU 测试 test_score_matches_run_once、test_x0_equals_e2_style_cell_a 检查。
  4. 评分时"无钩子"按"每个模块的钩子数等于裸模型基线"判（真实模型基线为 0 个带钩模块，见 readiness/smoke-r01.json），避免把框架自带钩子误判为失败。
  5. B 的独立验证：CPU 测试 test_b_definition_independent 不经过 B 的替换代码，直接按定义构造"C 在 τ−1 的缓存 + 带针单步 τ"，其浅层清单须等于 XB 的浅层清单。
  6. 合同 §6 "联合进一步削弱"需要一个数：方案未给，取 R_AB − max(R_A|B0, R_B|A0) > 0.3（与弱档宽度相同），冻结前写定。
  7. 2 个 worker（每卡 1 个）：真实模型每输入约 17 s（含预检的惰性重跑），12 输入单卡也只需约 3 分钟，多 worker 无收益。
