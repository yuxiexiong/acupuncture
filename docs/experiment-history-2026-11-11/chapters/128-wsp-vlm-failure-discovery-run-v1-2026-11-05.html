1. 本轮究竟回答什么

总目标仍是让研究者AI根据真实反馈自主诊断、选择修改位置、稀疏修改模型权重并迭代验证。本轮补上它的起点：固定的 Qwen3-VL-4B-Instruct 在 B/C 中是否确实存在足够明显、跨问法仍成立的条件性失败？哪些具体错误值得下一轮解释和修复？

候选 固定对照与挑战 重点观察的失败 本轮不能直接断言
B：空间条件计数 同一图、同一对象类别；问全部数量 vs 满足空间关系的子集数量 全部数对，空间条件题数错；尤其答案仍等于全数。例：能数出全图5辆车，却把“树左边的车”也答成5辆（示意，不是实测） 已知是忽略条件、已掌握空间关系、某层负责组合，或只改少量权重即可修复
C：反事实图干扰通常常识 原图通常 vs 反事实图通常；另保留无图通常、原图视觉、反事实图视觉 无图和原图下常识正确；反事实图视觉题也正确，但“通常谁更大”跟随图中大小。示意：图中猫比象大；图像题应答猫，通常题应答象 模型不知道常识、应普遍降低视觉影响，或已经找到证据选择电路

工作猜想是：部分失败可能来自已有能力在特定条件下的使用/组合失误。反例包括基础计数或常识本来就差、输入难辨认、模板/格式问题、数据歧义，以及两类任务均已表现良好。本轮只验证行为差和错误模式；即使对照答对，也不能证明挑战所需的全部内部能力已经存在。

4. 判断什么才算找到了失败
4.1 固定主统计

主面板为 H、普通提示B0、原问法T0；C名称顺序沿用组hash指定的固定顺序，不择优。

  • B：ΔB = 全部计数正确率 − 空间条件计数正确率。
  • C：ΔC = 原图通常正确率 − 反事实图通常正确率。
  • 每个来源组一个二元配对；来源组数是统计n，问法、提示和顺序不是新样本。
  • 采用现有单侧精确McNemar检验；固定原ABC三项Holm家族，未运行A取p=1，B/C均填实际p值后给最终校正。不会因本轮只跑B/C缩小家族。
  • 来源组bootstrap 10,000次、seed=20261105，给95%差值区间，作为精度描述；bootstrap区间不是零假设分布，也不替换检验。

来源组是现有抽样与计算单位；共享物体语义/素材可能造成剩余相关性，尤其C的显著性不能证明跨物体泛化。本轮不追加数据以声称解决该边界。

4.2 原先冻结的优先级规则

“明显稳定失败、值得后续诊断”须同时满足：D主差>0；H主差≥15个百分点；Holm校正p<.05；H挑战准确率≤80%；H控制准确率≥70%；其他普通提示问法/顺序的主差均>0；测量验收通过。C另须H无图通常准确率≥70%。

这些是筛查资源阈值，不是WSP的必要条件或论文贡献标准。D中模式≥8组、H中≥12组仅描述线索强度，不替代主检验，不成为唯一错误分类门槛。两候选可能同时通过，也可能都不通过。

“暂不优先”沿用：挑战准确率单侧95% Wilson下界≥90%，或主差95%区间上界<15个百分点。其余为未决/非特异失败，包括基础能力也低、方向不稳、区间宽；不显著不等于没有失败。先判优先规则，再判暂不优先。

B1报告准确率、主差、配对修对/改错、联合表现。强提示修好说明已有简单修法可作后续基线，不自动否定WSP；强提示失败也不是稀疏可修证据。不能因B1改变现有B0主判据。

4.3 必须同时交付的逐组证据
  1. B全数/子集的四种对错组合、错答为全数的适用组计数；按位置/距离、视角、总数/子集数分层，排查差值由单一来源或数值范围驱动。
  2. C五条件准确率与五条件联合正确率；逐组标出“无图通常对＋原图通常对＋反事实视觉对＋反事实通常错成视觉答案”；保留视觉也错和无图也错的不同类型。
  3. 全部问法/顺序结果、普通/规则提示配对变化；保存错误原文和正确参照，不把摘要解释当原始证据。
  4. 原始ID、来源组、输入/模型/代码hash、原问题/图片指针、gold、raw、解析值、停止原因、正确性与分类依据。新分类覆盖不到的错答保留“未分类”。

计数严格按现有整数接口、C按完整对象名规范化匹配评分，不从解释中择优抽取答案。基础设施错误或缺失停止该阶段验收，不算答错、不缩小分母。每个提示臂的截断率、格式无效率分别计算，任一>5%先记测量问题；不将两者直接相加，也不事后改解析器救分。低于阈值的无效输出仍按冻结评分计错，并单列其比例。
