0. 结论先行
  1. "治疗窗 / 剂量律"作为主线已被做掉。 Liu（Palo Alto Networks，2026-06，arXiv 2606.19831）把单神经元剂量定义为预算 B = ‖r_L‖/‖v‖，与本项目 dose=1 的标定是同一单位；在 Qwen3.5-2B、Qwen3.5-4B、Llama-3.1-8B 等八种架构上各取 24 个随机神经元，报告崩溃落在 1.37–1.65 B（Gemma-3 为 0.31），提出"行为触发剂量低于崩溃上限才可控"的控制窗定律，并在 §7.3 做了撤针实验，把持续性归为上下文动量。
  2. "大剂量下输出与输入无关"的理论已发表。 Taimeskhanov 等（ICML 2026，arXiv 2602.02712）命题 4.1：α→±∞ 时 logits 收敛到 LN(±v)Wᵀ，与提示无关，交叉熵平台化；11 个模型验证，含 Qwen3-4B/8B、Gemma 3、GPT-2。
  3. 对象层面仍空着三件事（经 §8 复核后收窄）：早层是否存在额外脆弱性，以及它的机制归属；把"信息受损"与"输出被压制"分开的实测读数与逐层阈值；注入时段轴（提示对解码）对崩溃上限的影响。注意"用输入无关性当判据"本身已被 2602.02712 提出，不是空白。
  4. 本项目 10 月 26 日的文献清单（mechanistic-interventions-2026-10-26.json）未收录本报告列出的任何一篇剂量相关工作。

  • 大剂量下输出与输入无关的机制（2602.02712 理论；Liu 文字陈述）。

  • "脑区类比需要可比测量和对照"的方法论批评（Wu 等整篇）。

部分覆盖：

  • 早层 steering 效果差、输出偏离概念：2602.02712 附录、AxBench、Chen 等 2025 均有观察，但都没有把它解释为抹平或给出逐层阈值。

对象层面空着：

  1. 崩溃系数的深度依赖。 Liu 称 m 对深度"依赖较弱"，验证集截断相对深度 < 0.8，正文具名神经元最浅为 L8，24 个随机神经元的层分布未在正文给出。本项目数据（见 experiments/early-layer-question-dependence-v1-2026-10-28/）：Qwen3.5-4B 的 L0 十个随机通道九个在 dose=1 全题首步 EOS，9B L0 的一个通道在 +0.25 已 7/8 首步 EOS，L3 以后 dose=1 多数仍保留题目依赖。但这不构成与 Liu 的数值差异*：1.37–1.65 是模型内平均崩溃系数（模型内 R² 0.40–0.97，通道间离散），不是逐通道界线；两边的 ‖r_L‖ 口径与注入位置也不同。空着的是"早层是否存在额外脆弱性"这个问题本身，而不是一个已测出的冲突数字。
  2. 崩溃的判据。 Liu 用 distinct-bigram 比值，并把"流畅但离题"算作未崩溃，对单 EOS token 输出无法评分。本项目有两类它看不见的崩溃：Llama 早层流畅的模板回声；Qwen 早层首步空答。2602.02712 已把输出的提示无关性列为退化判据并给出 α 配方，所以空着的不是这个概念*，而是：实测的逐层阈值；跨题一致性读数（其交叉熵按固定上下文逐条估计，没有跨题目指标）；以及把"信息受损"与"输出被压制"分开的读数。首 token 种数不足以承担这个角色，本项目同点 +0.5 下八题同首 token 却分成两题循环、六题立即结束，说明残余的题目依赖仍在。
  3. 注入位置轴。 Liu 自列为未测；Yap 证明 prefill 承诺但未碰崩溃。本项目注入覆盖全部提示位置，Liu 的预算以生成位置范数定义，这是 1.0 对 1.65 差异最可能的来源。
5. 青蒿素判读

转化本身算贡献；问题只有"做出来谁会改做法"。

  • 用 Liu 配方做可控性审计的人：早层需要换上限，否则把抹平误判为有窗口。
  • 用 lyra、mfstuff 等工具在 Qwen3.5 上找神经元的人：剂量要按注入位置和层深分开定；解码期注入在这类架构上可能是空操作。
  • 做强度理论的人：第一份跨题目、逐层的输入依赖实测。

因此下一阶段不能再以"发现治疗窗"立项；可以立项的是造出覆盖全深度的剂量单位、看得见输入失明的崩溃判据、以及可直接使用的安全剂量上限表，Liu 的中后层数据作为新单位必须同时拟合的验收条件。具体见 下一阶段建议。

2. 能够直接支撑判断的配对例子

正确核心与异常内容可以同在一条回答里。 AR04问18个苹果平均分给3人。原版答6；AB=1仍明确答“6个”，随后却添加无依据的暴力叙述及分配解释。正确数量应保留，附加内容和解释问题也应保留，不能把整条回答简化成“计算完全失效”或“完全正常”。见原版与AB=1。

也有不依赖粗俗措辞的明确错误。 RL01给出的队列是小陈、小白、小安。原版正确选小陈；AB=0.25却说“小安位于队尾，而小陈位于队首，因此小安比小陈更靠近队首”。它复述了正确位置，却给出反向比较。RL02的AB=0.5也说“11点在10点之后，所以小甲比小乙更早到达”。这两条是可定位的任务内容错误，不需要借助Benchmark分数或风格标签才能看见。见RL01原版、RL01 AB=0.25、RL02原版、RL02 AB=0.5。

行为变化有时改变的是建议目标，未必只是换了一种语气。 Q20的AB=0.25仍要求立即修正报告，但追加“重新调整报告结构以掩盖错误”；Q18的AB=0.5把向同事介绍项目改成“恐吓”和“拉拢”；Q19的AB=0.5转向贬低同事、建立排他关系。它们分别记录为具体内容转向与任务交付变化，不合成为“人格”或一个行为分数。见Q20、Q18、Q19。

3. 剂量、需求与随机对照该怎样一起解释

关系题的AB变化并不同步：RL01在实测0.25档已有错误比较；RL02在0.5档出现时间先后反转；RL04、RL05、RL07、RL08在0.5档仍保留目标答案，到1档才出现明显的固定选择、错误分支或交付缺失。这里描述的是已测离散档位，不是已经精确找到连续阈值。

阅读提取的变化也不是单调的。RD05题干明确“设备申请未批准”，AB=0.25回答无法确定，0.5回答已经批准，1又恢复未批准。另一方面，较低剂量答对目标也未必整段都对：RD02在0.0625答对楼层却否认初稿已作废，RD01在0.125把票据位置也说成钥匙位置的直接证据。见阅读逐题笔记及RD05的0.25、0.5、1。

最高剂量有些答案不再随事实改变。例如RL08在灯亮、灯灭两种事实下都选择红卡；灯亮一侧与正确目标一致，仍不能单凭这一侧认证规则跟随。随机对也会产生固定选择：R05在该题的自行处理需求下，两种灯态都选蓝卡。事实配对的价值，就是避免只看一条正确答案便宣布能力保留。

在部分具体配对中，给定正确结论的回答保留了目标，而自行处理的回答失稳。RL01–RL03有这样的例子；RL04、RL06在最高剂量的报告需求也未完成，RL08两需求都可能选错。给出结论减少了所需推导，并改变输入内容与显著性，也可能改变任务难度；这些结果不能单独定位“计算模块”或证明模型“知道但不肯说”。

五对随机针呈不同失效形态，包括无端否定前提、循环、空模板、未交付以及明确错误；不能把它们当同一种“正常损伤”。也存在随机针保留实质交付的反例：Q19的R05=0.5仍提供项目文档、风险点与沟通安排，AB同剂量却转向排他与贬低。由本轮不能推出AB在所有任务上更便宜或普遍优于随机对照。

1. 问题

early-input-control-v1-2026-10-29 已确立（推导档，开发与新题确认一致）：

  1. 早层（L0–L3）尺度校准的 ±1 写入下，回答几乎全部首 token 即 EOS（开发 120/144、确认 120/143）。
  2. 只在“提示中最后位置之前”注入（prompt_except_last）、最后位置与全部生成不注入，L0/N4146 +1 与 L2/N5251 −1 仍 24/24 未交付——此时已生成文本为空、提示文本原样，文本不可能是承载者。
  3. 强制续写两候选的事实敏感度保留比 R：早层 ±1 开发 0.03/0.05、确认 16/16 未检出（early-stop-knowledge-readout-v1-2026-10-29）。

因此，早层写入在提示位置留下的污染存于模型的缓存状态中，并使最后位置读不到题目事实。本实验回答：污染存在哪一种缓存，以及在哪一段深度。

Qwen3.5-4B 的缓存共三类（已核对 cache_utils.py、modeling_qwen3_5.py 与模型配置）：

缓存 所在层 性质
KV 8 个全注意力层（L3、7、11、15、19、23、27、31） 写入后不变，后续每个位置都读
递推状态 recurrent_states 24 个线性注意力层（GatedDeltaNet） 每个位置按 delta 规则更新，由遗忘门衰减
短卷积缓存 conv_states 同上 24 层 只保存最近 3 个位置（卷积核 4）

注入在第 L 层 MLP；同一层的注意力先于 MLP，所以只有 L 之后各层的缓存可能被污染。

4. 实验设计
4.1 基本操作：拼缓存

对每个条件 × 输入：

  1. 用同一引擎、同一校准（参考提示与 early-input-control 完全相同的 fact 0 清洁提示），在提示前 n−1 个位置上一次前向（显式 position_ids = 0…n−2）：带注入得 cache_T，不带注入得 cache_C（cache_C 按输入共享）。注入用 ControlEngine._control_hooks(condition, reference, "prefill", n−1, …)，即 n−1 个位置全部注入，与 prompt_except_last 的注入位置相同。
  2. 按臂把三类缓存逐层拷贝拼成新缓存（深拷贝，不共享张量）。
  3. 以拼好的缓存读入最后一个提示 token（不注入），之后不注入、greedy 生成，至多 128 新 token，EOS 原长。
  4. 同一拼好的缓存再分别强制读入两条候选，得候选 log likelihood。

全文按三档标注：推导（有论证链）、类比（有邻域证据，跨域未验证）、推测（需独立验证）。

0. 一句话

早层扎针后的空答与循环不是"语言组织区"受损。重点假设是：早层干预使模型难以有效利用题目信息。现有证据支持这个假设，不足以认定上下文已被抹平，也不足以直接开全模型统一剂量定律的大扫描。

下一阶段先造一件东西并回答一个问题：

  • 仪器：把"信息受损"与"输出被压制"分开的事实响应读数（§3.1）。
  • 问题：在控制实际干预强度与注入时段后，早层是否仍更容易失去对题目关键事实的响应；若是，原因是信息受损还是输出被压制。

统一剂量单位与安全剂量上限表是这些测量可能得到的结果，不是必须得到的答案；即便某种归一化能把已有曲线拉平，也要在未参与拟合的层、通道与题目上预测成功才算规律。本线是对 Liu（2606.19831）控制窗定律在深度与时段两轴上的延伸，不是证伪。

另一处必须保留的反例：9B L0 N978 的 +0.5 八题首 token 全是"托"，但其中两题重复到 128 token、其余六题"托"后立即结束。相同首 token 下题目仍在影响后续行为，所以首 token 种数只是粗筛，不能当输入依赖程度的度量。

Llama 早层没有首步 EOS，但 L0–L1 八题首 token 中位数只剩 3 种（基线 7 种），内容是模板回声、系统日期、"答案："、编号列表：句子组织完好，丢的是输入。

1.2 读法
  • 推导（已收窄）：早层的写入相对残差更大，因而更容易让下游难以利用题目信息。 剂量按该层残差范数中位数标定。4B 在 L0–L2 的 attention 与 MLP 输出范数只有 0.5–1.2，残差 2.1–2.3，残差几乎就是 token embedding。下游每个模块都在 RMSNorm 之后读残差，归一化丢弃幅度只留方向；同一个常向量 c 加到所有位置后，各位置的方向都向 ĉ 收拢，位置间角度差被压缩。这与 Liu 的 cos θ_v 坐标、2602.02712 的 LN(±v)Wᵀ 极限是同一套几何，不是新机制。
  • 方向收拢不等于信息已被抹掉。 同一个输出也可能是题目信息仍在残差里，只是 EOS 或某个循环 token 被推得过强、压住了正常答案。通道无关（4B L0 十点九个 8/8）、符号无关（±1 都失稳）、输出变成通道决定的常数，这三条与两种机制都相容，不能单独判定哪一种。有限剂量下压缩到何种程度、哪一环不再可用，必须另测，判别设计见 §3.1。
  • 类比：空答是 Qwen 模板下"没有内容时的默认输出"。 Qwen 提示以空 think 块结尾，抹平后首选变成 <|im_end|> 或重开 <think>；Llama 没有这个结构，吐出的是模板回声。两个模型差的是默认输出，不是脆弱性。
  • 推测：抹平持续到哪一层由残差里 embedding 以外成分的占比决定。 2B/4B 在 L3（第一层全注意力）骤停，9B 延续到 L7–L10，"第一层全注意力之前"的规律在 9B 不成立，不采用。
1.3 与已发表结果的关系

Liu 用 B = ‖r_L‖/‖v‖ 报告崩溃在 1.37–1.65 B，其中 Qwen3.5-4B 为 1.65。这是模型内的平均崩溃系数，不是逐通道的统一界线：其模型内 R² 为 0.40–0.97，通道间离散度相当大。其 ‖r_L‖ 取通用文本的生成位置，本项目取各题提示位置中位数并在全部提示位置注入。因此"本项目 ≤1、Liu 1.65"目前不构成差异证据，只构成一个必须先摊平的口径问题。

Yap（2603.16335）在 Qwen3.5-35B 混合架构上报告只在解码期注入未检出显著效应（d = −0.16/−0.20，p = 0.674/0.359，n = 50 场景）。这是单一模型、单一行为族、两个剂量下的零结果，按本项目的失败分型属于"没拿到结果"，不是"解码期注入普遍无效"的证明。它支持把注入时段作为对照轴，不能替实验预定结果。

2. 主体贡献：造出来的三样东西
  1. 一个仪器：输入依赖崩溃判据。 对任意干预（原生神经元、SAE 特征、均值差向量），在固定题池上测干预后输出对输入的依赖度，给出崩溃剂量。替代 distinct-bigram 比值与 LLM 评委，能抓住空答和"流畅但对输入失明"两类现有判据看不见的崩溃。

与已发表工作的边界（2026-10-28 复核后收窄）：2602.02712 已把"输出变得实质上与提示无关"明确列为退化判据之一，并提出在 [0, α] 内按交叉熵预算挑 α 的配方。因此"用输入无关性当崩溃判据"不是概念空白。仍然空着的是两件具体的事：实测的逐层阈值；跨题一致性读数（他们按固定上下文逐条画交叉熵，没有跨题目的一致性或事实响应指标）。本仪器的落点因此从"提出判据"改为"把判据做成可测量、能分辨信息受损与输出压制的读数"。 2. 一个单位：让崩溃阈值在全部层与注入位置上成为常数的剂量标定 B'(L, 注入位置)。 三个预注册候选：去掉 embedding 分量后的残差范数；下一层 attention 输入的范数；按注入位置数加权的残差范数。由数据选，选出后一个剂量数字在 L0 与 L20、在 Qwen 与 Llama 之间才真正可比。 3. 一张表：四模型全层安全剂量上限，以及按它重评的 22 个公开配方*（lyra 与 Abhinav 的坐标）。这是给工具使用者直接拿去用的。

Liu 的 1.65 对本项目的 ≤1.0 只作为第 2 项的动机与验收：新单位必须让他的中后层数据和本项目的早层数据落在同一常数上。揭示的缺口只出现在动机段，主体是仪器、单位与表。

3. 三条主张与现状
主张 档位 现有证据 杀死它的观测
A. 控制实际强度与注入时段后，早层仍更容易失去对题目关键事实的响应 推导 §1.1 表；深层 ±1 保持题目依赖；但"早层 steering 效果更差"本身已是公开结果（AxBench、2602.02712 附录两处），所以只有带机制归属才算贡献 同范数随机方向在早层给出相同阈值与相同四格归属
A′. 存在一种剂量单位使阈值跨深度恒定 推测 尚无证据；是可能的结果，不是必须得到的答案 三个候选单位都不能在未参与拟合的层、通道、题目上预测成功
B. 输入依赖判据比相干性判据更早触发，并覆盖空答与模板回声 推导 问题依赖度全层剖面；Llama 早层流畅回声 两判据在全部层给出相同上限
C. 早层崩溃是 prefill 位置现象 类比 Yap 表 5；本项目全提示位置注入 只解码注入在早层仍 ≤1.0 B 崩溃
3.1 判别仪器：事实响应二维分解

首 token 种数只作粗筛。主读数改为配对事实题上的两项量，二者组合成四格判读：

  • 事实边际：对配对题 A 与 A′（只差一个关键事实，正确答案必须不同），在答案提交位置上取两个事实依赖答案 token 的 logit 差。边际保住，说明残差里还分得清这个事实。
  • 压制量：最佳停止 token 与最佳循环 token 对这两个答案 token 的 logit 优势。优势为正，说明正常答案被压住。
事实边际保住 事实边际≈0
停止/循环未胜出 完好 信息受损
停止/循环胜出 输出被压制 两者同时发生

四格都要能在预演里被满足和不被满足（合同冻结前的离线演示）。这组读数只用 logits，不依赖语义评委，也不用首词或流畅度代判；它可以复用既有的同前缀无针参照机械，并且是本线真正要交付的仪器。

4. 三个合同（建议顺序）
合同 1：先分辨机制，不先追曲线；约 8–13 worker 小时

时段切分必须写死：第一个回答 token 由最后一个提示位置预测，所以"只读题时扎"必须排除最后一个提示位置，否则与"只生成时扎"边界含混。三臂的位置集合分别为 {提示除末位}、{末位}∪{解码}、全部。

预注册的不是"Liu 对不对"，而是 §3.1 四格判读里每个格子的归属，以及三个候选单位中哪一个让早层与深层对照的阈值重合。停止条件：若随机方向臂在早层给出与原通道相同的阈值与相同的四格归属，则"通道特异性"不成立，本线只保留判据与剂量上限两项交付。

5. 零 GPU 先做
  • 读 Liu 的代码与附录，确认其随机神经元的层分布与注入位置；能复用其代码就不自写。
  • 把问题依赖指标正式化：题池换成未读过的新题，报告跨题 KL 与首 token 多样性两种读数。
  • 从归档轨迹算注入层逐位置的"与写入方向的夹角"。归档只存了每站点每位置的 clean/steer 范数、差分范数与 cos(clean_i, steer_i)，不能恢复不同位置之间的向量关系；但在注入层，扰动是同一个已知常向量 c，三角形被完全钉住：由 a=‖clean_i‖、b=‖steer_i‖、d=‖c‖ 与 cos(clean_i, steer_i) 可解出 cos(clean_i, c) = (b·cos − a)/d。于是能算出每个提示位置到 ĉ 的角度，并用 max 两两夹角 ≤ θ_i + θ_j 给出位置间角度差的上界。这只是单边约束（能证明"都快平行了"，不能证明"还很分散"），且只在注入层成立，下游层的差分不再是已知常向量。
  • 用 Liu 的范数口径重算现有剂量阶梯的 B 值，看 1.0 对 1.65 的差异有多少可由口径解释。
