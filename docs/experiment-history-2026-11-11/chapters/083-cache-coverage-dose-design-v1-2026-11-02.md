##### 3. 阶段 G：交叉恢复与计算切分桥接，必须先通过

###### 3.1 固定接收者，真正只换干净来源

每个文本构造历史两种切分：

- `C_b`：QC 宽切分（记录结束处预填，随后逐 token 到读出前）。
- `C_s`：QC 窄切分（问题也在整段预填内，随后逐 token 走 20-token 尾部）。
- `T_b,d`、`T_s,d`：分别按对应历史切分和原 −1 剂量形成的宽/窄受干预缓存。

**每个 T 只形成一次，深复制后分别换入 C_b.V 与 C_s.V**。同一组两个恢复臂的接收者完整缓存、位置计数、mask、末提示 token、恢复层/块与生成路径必须一致，恢复前后逐组件哈希证明只替换指定 V。不能各自重建一份 T 后称“固定 T”。两供体必须来自同一精确文本，禁止跨模板或跨查询供体。

对 108 文本 × 2 接收者窗口 × 4 方向都检查；共 864 个固定 T 的供体配对。不只抽干净大分差格或 N4146 阳性格。重建历史同源臂与 QC 的 tokens、首次 logits 哈希、缓存哈希、诊断逐位重放；同源重放不过先停止，不能把环境漂移算作供体敏感性。

###### 3.2 后续统一切分，另做最小桥接

科学比较全部固定在**宽切分**：对同一文本共享记录结束处的干净 base，记录后 L 个位置始终逐 token 计算，仅注入 mask/幅度改变；所有恢复共用 C_b。读出前的位置与更新次数相同，不能随窗口起点改 prefill 边界。

为免统一切分悄悄改变窄条件，阶段 G 另形成 `T_u,d`：宽切分但只在最后 20 位注入，前 6–7 位无针逐 token 更新。每个 T_u 同样跑 nat、V←C_b、V←C_s，并与 T_s 在**相同供体**下配对比较。T_b 已是统一路径宽基线，后续不再重建。统一切分不是更“正确”的数值真值，只是固定研究操作；桥接不过则暂停，不能替换掉旧结果继续讲覆盖机制。

###### 3.3 固定验收与停线规则

每对均保存完整 token/文本/停止原因，同时比较：Y_delivery、Y_strict、唯一编号、首列选择、无编号/多编号/截断类别、首步是否停止，以及 §6 的入口分差 E 和目标竞争分差 M。报告所有翻转格及其两边分差；不能以平均差小掩盖边界格。

阶段 G 通过须同时满足：

1. 同源历史重放逐位一致；缓存来源与隔离验收通过。
2. **全部交叉供体对及切分桥接对**的上述行为判读一致，M 的符号（含零）与三个候选的最大值集合一致；原 P_cov 的支持/不可判标签不改变。完整输出只要 token 不同仍逐条公开：任务类别一致只称“任务判读稳定”，不称输出逐位相同。
3. 连续读数也检查：每对 `|ΔE|≤0.5` 且 `|ΔM|≤0.5` logit。0.5 是事前保守的工程筛查上限，**不是安全影响界、统计阈值或“不会翻转”的证明**；行为/M符号翻转即使仅 0.01 也失败。另对历史宽窄 V 差值，枚举两边分别选 b/s 供体的四种组合：每模板×方向的平均 M 差方向及行为结论必须一致，否则失败。

任何一项失败：**停止后续位置和剂量科学比较**，保留原文与失败记录，仅交付数值敏感性报告。不得换用有利供体、提高容差或删除失败样本后继续。本计划不自动包含 FP32 重跑、换 kernel 或全路径重建补救。

通过只排除本面板、基础剂量、已测试两切分导致的结论改变，不排除其他数值路径影响；新增剂量下的供体稳定性不由此推出。阶段 S 固定单一供体后的结论也明确条件于该数值实现。E/M 在 G 中的差异分布作为参考附录，不当新政策的误差上界。

##### 4. 阶段 S：先位置，后剂量；七项形成政策

零基 token 索引：提示长度 n，宽窗口起点 p=`b_b+1`，末端 e=`n−2`，L=`e−p+1`。档案核对：108 文本中 87 条 L=27、21 条 L=26；末尾窗口长 20。定义 B=`[p,e]`，N=`[e−19,e]`，E20=`[p,p+19]`。E20 含问题与后续指令前部，N 只含尾部指令与模板；两窗口重叠 13/14 位。E20 结束后还有 L−20=6/7 次无针形成更新，N 则无，随后二者都处理末提示 token 读出。

| 政策 | 注入窗口 | 基础幅度的正倍率 a（实际 signed dose=−a） | 比较用途 |
|---|---|---:|---|
| B1 | B，26/27 位 | 1 | 统一路径的原宽基线，来自 G |
| N1 | N，20 位 | 1 | 统一路径的原窄基线，来自 G |
| E1 | E20，20 位 | 1 | **主比较 E1 vs N1**：等长、同逐步幅度、不同位置 |
| N-A | N | L/20（1.30 或 1.35） | 范数和配平 B1 |
| N-Q | N | √(L/20)（约1.140或1.162） | 平方范数和配平 B1 |
| B-A | B | 20/L（约0.769或0.741） | 范数和配平 N1 |
| B-Q | B | √(20/L)（约0.877或0.861） | 平方范数和配平 N1 |

字母 Q 在政策名里只表示平方和配平，**不是 query/q 张量**。以上倍率由已冻结 L 决定，不由输出调参，实际是否配平按 §5 验收。宽窗口也做两种降幅，避免只在高剂量一侧配平而误判单步强度/非线性。

每政策、每方向跑 T_nat 与 T_V←C_b。B1、N1 另留 T_F←C_b 参照（阶段 G 内计费），新五政策不全铺 T_F：本轮不比较 F 与 V 的层/头机制，原基线 F 已足以显示参照能力。每政策使用同一文本同一 C_b；不新增干净形成。正式 S 的五项新政策一次收集，不能看完 E1 结果再择优决定跑哪种配平；分析顺序仍为位置主比较→四个剂量匹配比较。本版本冻结为新政策两臂，T_F 仅用于 B1/N1；不在运行时切换为三臂。

等长移窗在实际向量验收通过后可配平三种所列剂量统计；它直接检验“相同注入预算下，注入哪一段会改变后续 V 恢复效果吗”。仍同时改变内容覆盖、时刻、结束位置及无针后续更新，不能称已隔离问题语义或问题 token 被写坏。剂量补充也各只匹配一种积分量；与主比较联合解释，不把多个控制误写为单一因素完全识别。

##### 5. 实际剂量定义与验收：不能只算倍率

统一以**实际注入在模型空间中的向量** u_t 定义 `A=Σ||u_t||₂`、`Q=Σ||u_t||₂²`、`P=max||u_t||₂`，同时保存逐 token 范数/方向，不用有符号向量和 `||Σu_t||` 替代 A。有限精度只允许说容差内配平。

- 原生单通道：在 down_proj 输入 hook 前后取实际 BF16 激活差 `δa_t = float(a'_t)−float(a_t)`；投影 `u_t=W[:,c]δa_t`，使用实际加载权重和 FP64 累加范数。不是将请求 amount 当实际 δa。另只读记录同输入 down_proj 未改/已改输出之差，以区分线性投影注入量与 BF16 matmul 舍入；这个局部影子 GEMV 不写回主路径、不算另一次模型运行，计入操作耗时和次数。
- R0：在 MLP 输出加法 hook 前后直接取 `u_t=float(y'_t)−float(y_t)`，不能只用转成 BF16 的 addition 常量。保留请求向量与实际向量的范数、投影及正交偏差，解释有限精度的操作差异。
- 每条形成轨迹保存 hook 层、绝对位置、方向哈希、请求幅度、实际改变量及 u_t（或足以精确复算的标量/权重哈希），确保 inactive 位置严格未修改；生成期 hook 关闭。两个 native 与 C1343 仍在原 hook 注入，R0 仍在其原 hook 注入，不为求精确等式改成另一个干预算法。

**验收固定为相对误差 ≤1%**：匹配比较对应 A 或 Q；E1/N1 同时检查 A、Q、P，且将第 j 个被注入位置对应后的 `||u_E,j−u_N,j||/max(||u_E,j||,||u_N,j||)` 每步 ≤1%。报告全部误差及最大值。这是容差内近似相同向量/预算，不宣称严格代数相等。L0 位于因果结构最早处不保证浮点实际增量自动相同。

倍率只生成候选，不授予配平标签。若实际配平失败，标为工程未达目的并暂停相关科学结论；不事后搜索剂量、不改 1% 门限、不把无效配平当阴性。保留阶段 G 与已收集材料；修复需新的版本和预算。投影 u_t 与局部 BF16 输出差若有明显不一致，完整报告，不能声称同时配平了网络下游扰动；本轮配平的定义限定于上述实际 hook 注入量。

##### 6. 读数、配对与固定判读

###### 6.1 自然交付优先

主终点沿用 QC/NQ 冻结解析器的 Y_delivery：生成包含完整目标编号且不含其他不同编号；并列 Y_strict。记录原文、唯一编号、首列编号、其他错误编号、多编号、无编号、首步停止与长度截断。继承规则不将罗列多个编号算正确。自然输出和独立诊断分栏。

连续辅助量：

- `E = z₁[共同首 token]−max(z₁[248044],z₁[248046])`，描述进入回答相对停止的竞争，不能代表正确目标。
- 在首次评分后的独立缓存副本输入共同首 token，`M = z₂[目标第二 token]−max(z₂[另两编号第二 token])`。报告三个 logits、目标排名、M。共同首 token 非自然输出时明确这是诊断分叉。
- 目标非首位 36 格独列目标/首列频数；不能以目标本来在首位的 18 格证明目标选择。

每政策报告 Y_nat、Y_V、恢复增量 R=`mean(Y_V−Y_nat)`；并列 C 正确而 nat 错误后被 V 修复的计数。每比较给配对四格（仅左对、仅右对、都对、都错）、逐场景 ΔY_V/ΔR/ΔM、分差分布。未恢复两边同为零不称损伤等同。若新政策主要改善 Y_nat，首先报告损伤减轻，不能将 Y_V 改善全归于恢复更有效。

###### 6.2 适用性与比较序列

干净门与损伤迁移门沿用 NQ：C ≥5/6 场景各 ≥8/9；每方向 ≥4/6 场景各 ≥6/9 是 C 对而 T_nat 错。所有结果都保留；不合格条件只能作形成政策的描述，不能支持“在同类损伤下恢复更强”。方向/模板分母固定四方向、两模板；不删除 LA-tail/R0。查询跟随等历史标签仍按 ≥8/9、≥5/6 计算，另给连续效应而非只有标签。

事前比较共六对：B1/N1（原差异）、E1/N1（主位置比较）、B1/N-A、B1/N-Q、B-A/N1、B-Q/N1（四个剂量配平）。同一个场景×排列×查询×方向为配对单位。

为避免“稳定”由看图决定，定义描述性方向级模式：某方向某模板在 ≥5/6 场景的 ΔY_V 同号且非零、总净差绝对值 ≥6/54，叫“稳定差异”；反向用完全相同规则。预期符号是 N1 优于 E1、窄优于宽。一个模板 ≥3/4 固定方向满足才叫跨方向模式，两模板分别报告。阈值是最小可报告一致模式，**不是显著性、功效保证或等效性界**。未达阈值仍公开全部效应，不写成零效应；有方向适用性不足则注明支持 k/4、不可判 m/4，不缩分母。

##### 实质反方检查、修订及最终复查

1. **即使等长移窗差异很强，也可能只是提前结束后的6/7步恢复。** 这破坏“问题语义被损坏”的承诺，但不破坏形成位置影响恢复效果。本版改用位置政策估计对象；不加所有错位窗口去凑纯语义控制，仍保留有用增量。复查C01/C02/C08/C14通过。
2. **同样的名义倍率、BF16 amount，不等于实际注入相等。** 旧masked_injection仅记positions，xchan.write_audit是名义残差写入。本版要求逐token hook前后真实差及投影，明确R0和native不同位置；1%未达即不授予配平结论，不事后改算法求阳性。C05/C07/C11通过，数值可达性待验收。
3. **干净0.375小，但恢复恰好差0.01就翻转。** G逐格比较行为及M符号；0.5仅限制连续漂移，不能豁免微小翻转。平均稳定不够。C04/C10/C11通过。
4. **换两种C时也重建了T，会把两种差混在一起。** 固定T只形成一次、克隆配对、哈希证明；来源切换唯一改变V。C05/C06通过。
5. **统一计算切分本身改变了窄T，导致旧宽窄差异消失。** 增加T_u桥接，保持供体分别相同；未通过先停。不能悄悄将旧条件换成新条件后继续归因。C03/C08/C13通过。
6. **G通过并不保证高剂量恢复也对供体稳定。** 接受这个边界：S严格固定C_b及路径，不声称跨数值实现鲁棒；不得把G实测差异当新剂量的普适噪声界。C08通过，没有为所有新臂追加供体网格。
7. **四个配平结果都接近，可因天花板或原生损伤消失。** 剂量解释要求原差异确实存在、两种增幅和降幅都有对应变化，并同时看Y_nat/R/适用性。无显著性不等于等效。C04/C09/C10通过。
8. **只按8/9标签会漏掉有用改善；只报总体又可能靠一个场景驱动。** 保留原标签供历史对照，同时冻结逐场景同号/净差规则与全部计数，主结论按场景一致性；阈值不伪装统计检验。C10/C13通过。
9. **只把两种剂量定义之一写进摘要会保住覆盖故事。** 四对必须同时呈现；冲突归混合/条件依赖，不择优。相反位置效应也按同一规则接受。C09/C14通过。
10. **工程检查比科学新格更大，可能形成成本黑洞。** G全覆盖针对当前核心证据可信性；一次固定上界，无自动重试。B1/N1及C从G复用；S新增仅两臂，硬上限与快照复用写明。旧logits不能替代缺失缓存，故形成重建真实计费。C12通过。
11. **逐位来源和剂量检查都通过，仍不能排除混合状态补偿。** 本轮未承诺排除；不同形成位置在同一恢复操作下稳定产生不同交付仍能约束解释。不是为无法识别的“原生机制”加免责声明。C07/C08/C14通过。
12. **把未来工程门写得严格，实际一遇失败就换题。** 本版给出具体停线与结果交付：来源失败即数值敏感性报告；剂量失败即配平未实现；有效阴性结束此支线。任何补救另立版本，不自动加预算。C11/C14通过。

**最终结论：设计逻辑通过，可以交付规划；不是可直接上卡的执行合同。** 全部C01–C14在上述修订后复查。工程尚缺：新runner与只读hook审计、真实实际剂量、交叉供体、统一切分桥接、速度/体积和资源门；这些缺项禁止声称已运行或已数值验收，不妨碍交付本轮问题与停止规则明确的计划。
