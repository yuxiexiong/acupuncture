##### 3. 执行路线与操作定义

**路线**：五个条件共用位置 0…b 的一次干净整段前向（这段在所有条件中都无针）；L 内每个位置 t 依次以单 token 前向推进 C、T、XA、XB、XAB。

- **A**：δ0(t) = float32(r0_T(t)) − float32(r0_C(t))，r0 为第 0 层解码层完整输出残差，取自同一步的 C 与 T。在 XA、XAB 中，第 13 层解码层入口（input_layernorm 之前）执行 r13 ← BF16(float32(r13) − δ0(t))。δ0 不预先舍入；每次记录 ‖δ0‖、实际改变量、舍入残差。
- **B**：在 XB、XAB 的位置 t 前向之前，把第 1–12 层的全部缓存字段（线性层的递推状态与卷积缓冲；全注意力层位置 0…t−1 的 K/V）替换为 C 在边界 t−1 处对应字段的克隆。当前位置的 q/k/v、门、更新与输出照常计算，下一位置重新替换。深层历史不动。
- **评分**：τ 之后构造 M_score(X) = C 的第 0–12 层 + X 的第 13–31 层（E2 的 `transplant`），移除全部钩子，从独立深拷贝输入 x[n−1]，取首步全词表 logits。评分 6 次：C、T_native（T 自身完整缓存）、X0（C 浅层 + T 深层）、XA、XB、XAB。不做候选强制、不做自由生成。

##### 4. 工程闸门（任一不过即停；不重试、不放宽）

**路线修订（方案 §4.2-2）**：方案要求新路径与 E2 逐位一致，并写明"若 chunk/step 路径导致不一致，预检停止……数值路线修订另行记录后才重审"。冻结前的工程探针（`readiness/probe-r01.json`，只跑 C、T，不含任何 X 条件）显示：E2 的整段路径在本环境逐位重现 E2；逐步路径**不**逐位一致（缓存清单与 logits 哈希不同），D 差为 C 0.0、T 0.0625。B 只能逐位置执行，因此逐位重放在构造上不可达。本合同把该闸门拆为 R0 与 R：

##### 5. 读数

每个输入、每个评分格：D = max(z[E]) − max(z[非E])，E = {248044, 248046}；EOS = 实际 argmax ∈ E；固定 token 对比 m = z[e*] − z[c*]，e*、c* 为 C 评分中停止集合内、外的最大者；记录各格两个 max 的 token 身份。

情景层面：D 为两事实均值，同时保留两条原始值。Δ = D_X0 − D_C。

| 量 | 定义 |
|---|---|
| A\|B0 | D_X0 − D_XA |
| A\|B1 | D_XB − D_XAB |
| B\|A0 | D_X0 − D_XB |
| B\|A1 | D_XA − D_XAB |
| AB | D_X0 − D_XAB |
| I | D_XAB − D_XA − D_XB + D_X0 |
| R_k | 上述差 / Δ（Δ ≤ 0 时不定义，不贴标签） |

同样的量对 m 另算一套（解释辅助，不替代 D）。

**描述尺度（不是显著性）**：R > 1 越过干净基线的反转；0.7 ≤ R ≤ 1 强削弱；0.3 < R < 0.7 部分削弱；−0.3 ≤ R ≤ 0.3 弱；R < −0.3 增强。弱不等于零效应。本面板没有效应量的零分布（方案 E25 固定五条件、不加对照矩阵）；报告路线容差 \|ΔD\|/Δ_E2 作为数值底参照，不作为零分布。

##### 6. 判读（按情景，可并存，不贴整模型单一标签）

| 行 | 判定式（bands 按 §5） | 可以支持 | 不应推出 |
|---|---|---|---|
| B 两背景强、A 两背景弱 | B\|A0、B\|A1 强；A\|B0、A\|B1 弱 | 持续把浅层过去状态置为干净，会大幅减少深层最终效应；入口抵消不足以产生同等改变 | 原生唯一历史通路；α 主导 |
| A 两背景强、B 两背景弱 | 对称 | 已发生浅层响应后，入口减法仍大幅改变深层效应 | 针直接传到底；浅层无作用 |
| 两者部分、联合进一步削弱 | A\|B0、B\|A0 部分，且 R_AB − max(R_A\|B0, R_B\|A0) > 0.3 | 两类操作都有影响，单独不足以替代联合 | 把比例相加成自然份额 |
| 单独都强、联合不再明显增加 | A\|B0、B\|A0 强，且 R_AB − max(…) ≤ 0.3 | 存在多个有效干预入口 | 两条独立冗余承载路径 |
| 条件依赖 | (A\|B0、B\|A0 弱且 AB 强或反转) 或 某操作在一个背景弱、在另一背景至少部分 | 形成效应对操作组合有条件依赖 | 由 I 命名 K/V 或递推交互 |
| 增强或反转 | 五个 R 中任一为增强或反转 | 被改动的形成条件可能原先限制了输出效应，或操作造成新的状态组合 | 把异号改称支持；调剂量救假说 |
| 全弱 | A\|B0、B\|A0、AB 都弱 | 两项操作在统一背景中都未大幅削弱既有深层效应 | 把剩余叫"浅层同位置放大"；自动换层换模型 |
| 事实版本不一致 | 任一事实 Δ ≤ 0，或五个差在两事实间的档位或符号不同 | 形成依赖与输入有关 | 用均值掩盖 |

另报：情景间符号不一致（各差）；赢家切换（X0/XA/XB/XAB 中两个 max 的 token 身份是否变化）；D 与固定对比的 I/Δ 是否落在不同档位。后两者出现时，D 的交互不定位到任何内部运算。
