## 1. 本轮问什么，为什么值得做

总课题保持不变：**少数通道激活干预怎样改变写入、历史状态处理和后续读取，最终造成显著回答变化？**

本轮问题：已经观察到的第13层 V×Q 写入交互，在指定评分背景下，是否实际改变了最终答案词/停止词两侧的非相加？删除这一份交互，输出交互变小、基本不变，还是反而变大？这种作用在原生评分后半段 N 中是否仍存在？

换成人话：现在发现两份材料一起起作用时，会在一项计算里互相抵消。下一步把**这一份抵消**拿掉，看它是否真的影响最后的词语竞争。只看到内部抵消、只看到停止分数动了，都还不够。

新增的是“这份具体计算变化 → 输出交互变化”的有界因果证据。计算公式、激活替换方法、状态影响输出等都复用已有知识；不把拆出乘积项本身算创新，不宣称首次发现此类机制。有关近邻的定位复用[合并文献核对](literature/merged-prior-art-artemisinin-2026-11-01.zh-CN.md)，本轮没有重做领域查新，也不作领域首次主张。

## 3. 对象、背景和计算定义

### 3.1 固定身份与评分窗口

- 模型 `Qwen3.5-4B`，revision `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`；BF16、eager，复用 CONV-FACTOR 的实际模型文件、tokenizer、软件/内核源码哈希与运行设置，不允许浮动版本替代。
- 原始针 L0/N4146/−1、原晚段时窗及提示逐字继承 BRIDGE/CONV 记录。本轮不重新扎针形成，不生成后续文本。使用最后提示 token 评分前 τ 缓存，撤针后只评分这一个 token；单 token recurrent 路径。
- 固定12输入：VAR03、VAR04、VRD03、VRD04、VRL03、VRL04 各 f0/f1 required。六个均为已见情景，层13也由已见数据选出；本轮是开发面板的因果检验，不是留出确认，不把12行当12独立情景。
- Q 指 F 内 **q 与 k 两段合并**，不是单独 query。大写 V 指 F 的 V 段，`v` 是卷积后参与当前计算的 value。段边界、槽位、层集合均继承 CONV；不在本轮拆 q 与 k。

### 3.2 背景与四角

每个背景中固定深层 S=T、全注意力 KV=T；V/Q 材料在全部深层 G 层按旧 CONV 四角来源配置。下面下标顺序固定为 **QV**。

|背景|进入第13层的当前残差|旧四角映射（CC、CT、TC、TT）|B1实际新运行的基底|
|---|---|---|---|
|M_T|浅层0–12缓存为 C，自然得到 x_C|`M:TCC,TCT,TTC,TTT`|`M:TTT`|
|N|同样计算浅层后，在 decoder13 入口替换为归档原生 x_T|`N:CC,CT,TC,TT`|`N:TT`|

N 的 TT 参考应重放原生评分后半段，N 的其他角和删交互仍是明确的反事实，不叫未经干预的原生轨迹。每格从**评分前** BRIDGE C/T τ 缓存重建，逐字段核对来源；CONV 评分后的已更新缓存不能冒充 τ。每格独立复制，避免上一评分的状态泄漏。

### 3.3 被删除的项

按现有内核的 q/k 归一化、query 缩放及头广播规则，定义每头：

```text
core = Sᵀw + n
w = exp(g) [q − β k(kᵀq)]
n = β v(kᵀq)
I13 = nTT − nTC − nCT + nCC
```

同一背景的第13层四角当前输入、旧 S、g、β 相同，q/k 只依赖 Q，v 只依赖 V，故还可独立计算：

```text
I13 = β (vT − vC) [(kTᵀqT) − (kCᵀqC)]
readTT − readTC − readCT + readCC = 0
```

这两式是**有条件的代数事实**，不是新科学发现。来源驱动有任一固定条件不成立，不能强行使用此式。按 `lr_core.weights` 相同约定用 FP64 重构 q/k/w/n，核对保存的 `old/new/core`；不得混用卷积前与卷积后 qkv、漏掉 q 缩放或错误头映射。

本轮在 TT 基底第13层 recurrent 内核返回的 **core 输出边、gated norm/out_proj 之前**，执行一次：

```text
core' = cast_BF16(FP64(coreTT) − I13)
```

只改这一层这一步输出；返回的 `s_new` 不改，其他缓存不手动修改。gated norm、out_proj、残差、后续层及最终归一化都正常响应。固定入口四角下，精确重构意义的局部 core 变成 `coreTC+coreCT−coreCC`；BF16 实际版本须单列误差，不能口头称逐位相等。

**这是当前写入项对 core 读出的输出边干预，不是删除持久 S 更新，也不是撤销历史写入。** 它主动打破“返回 core 等于实际 s_new 读出”的自然联合关系，作为一次受控反事实；只回答本步输出响应。未来状态/完整生成仍不在其估计对象中。

## 4. 最小矩阵与随机参照

每输入每背景4格，全部 TT 基底：

|格|第13层操作|用途|
|---|---|---|
|R|无改动、记录器开启|逐位重放旧 TT，连接旧三角与新干预|
|DEL|core 减去 I13|主因果检验|
|RAND0|core 减去 U0|同幅方向参照|
|RAND1|core 减去 U1|第二条有限方向参照|

随机匹配的是 **core 的 I13 每头 L2 范数**，不是 F 的原始 V/Q 范数。沿用 LOCAL 的 CPU FP32 高斯采样、FP64 每头单位化与匹配，但使用新标签 `CFM-VQ-WRITE-L13-v1`。种子：`int(sha256(tag+'|'+item_id+'|'+j).hexdigest()[:16],16)`，j=0,1；[32,128] 形状，零目标头严格置零；不正交化，不选方向。M_T/N 对同输入共用单位方向，分别匹配各自 I13 幅度；不同输入按 id 产生方向。保存种子、方向与匹配后向量 SHA。

两条随机只是有限方向参照，不是充分的零分布；不能据其宣称一般扰动被排除、通道特异或 p<0.05。新 core 随机也不能替代 XCHAN 的入口随机。所有格同一下游、相同 cast 和 hook，实际落到 BF16 的位移另验收。

## 5. 估计量、读数与事前预测

### 5.1 主读数与输出交互

主检验对象：`cz_s46 = z[248046] − mean_vocab(z)`；同时必须报告 `cz_a`，a 为旧干净 C 的冻结非停止赢家。不得按本轮赢家重选 a。两侧使用同一估计量与判读规则，答案侧不预设不同机制。动态 D、首步 EOS/赢家、248044、think=248068、固定候选边际、原始 logit、固定 C 归一化尺度读数均作派生/诊断，不替代主终点。均值在全词表、FP64 计算，不是只减候选词均值。

对每个输入、背景、终点 Z，旧四角给出：

```text
I_out  = ZTT − ZTC − ZCT + ZCC
I'_out = ZTT_DEL − ZTC − ZCT + ZCC
δ       = ZTT − ZTT_DEL = I_out − I'_out
ρ       = δ / I_out
κ       = |I'_out| / |I_out| = |1 − ρ|
```

旧三角不新增评分，前提是本轮 R 全词表 logits、入口和驱动与旧 TT 逐位一致且来源环境完全对齐。`δ=I−I'` 是只改 TT 的恒等关系，不能把这条恒等式本身当因果发现；新证据在于指定删除操作引发的 δ 大小、方向及其相对参照。ρ 是该反事实下的输出交互变化比，不是自然机制贡献百分比。

特别区分两种范围：I13是第13层的局部计算项；I_out来自全部深层G层的V/Q四角材料操作。本轮问前者能否改变后者，不能把两者当成同一个量。其他13个G层的材料在新评分中仍为TT，后续正常响应；不要求一个局部项解释全部全局交互。

### 5.2 分母与分析单位

全部12行先报告绝对 I、I'、δ 和两条随机 δ。情景汇总：两事实的这些量分别取均值后，再计算比例，禁止先算小分母比例再平均。仅当情景 `|mean(I)|≥1 logit` 且两个事实的 I 同号，展示情景 ρ/κ。单输入比例也要求自身 |I|≥1；其余为“比例不可判”，绝对变化照报。沿用项目1 logit展示下限，不据新结果调下限。

现有基线已揭示这一限制：停止侧 M_T 有6/6、N有5/6情景可展示比例；答案侧 M_T有4/6、N有3/6。它们是设计前已知的分母条件，见核对 JSON，不能事后移除小分母情景把通过率抬高。答案侧因此以绝对变化和逐情景判读为主，不要求其凑足总体比例结论。

### 5.3 预测及阈值的身份

已有证据支持“局部抵消可能传到停止词侧”这个**候选**，并不演绎保证输出同向。登记可失败预期：N 停止侧删除后，输出交互幅度至少缩小25%，且真实操作的作用超过两条有限随机参照，在固定六情景中至少5个成立；M_T 同样报告但不能替代 N。25%、1 logit、随机超过规则是事前描述性判断标准，不是估计出的置信界或统计功效承诺。

逐情景“支持传递”需同时：

1. 上述分母可判；κ≤0.75，即 ρ∈[0.25,1.75]；两个事实各自 δ 与 I 同向。
2. 对每事实令 `E_i=sign(I_i)δ_i`，均>0；`mean(E_i)>max_j mean(|δ_random,j,i|)+0.1 logit`。固定六情景中≥5个同时满足才称该背景/终点“稳定支持”；比例不可判者不算成功，分母不缩为可判子集。

两随机不能标定总体零分布，5/6也不是显著性检验，不报二项尾概率。N 停止侧为预定主判断，其余三组完整展示，不择优合并为成功。预期不成立时，区分反向、弱、异质和不可判，不能全打成“没有作用”。

## 6. 判读与下一步决策

以下表先用于每个背景、终点、情景，继而汇总完整 `2背景×2终点`；不只报赢家。

|情形|读数判定|本轮认识与限制|
|---|---|---|
|交互减弱|0<ρ<2；实质支持另需§5.3标准|局部删除可使输出更接近可加，但不排除末端非线性共同参与|
|变化很小|可判比例时 abs(ρ)≤0.1，且 abs(δ)≤0.1 logit；不满足者不硬归此类|该操作对该终点弱；不是等效检验，不推出本层/全部写入无关|
|反向或放大|ρ<0 或 ρ>2；ρ=2为等幅反号|删除反而增强非相加，否定简单的同向传递描述；仍可留下反方向作用证据|
|过冲但幅度仍减小|1<ρ<2|I'反号但绝对值变小；不能笼统叫“下游反向放大”|
|中间/混合|未达实质阈值、事实异号或情景不一致|报告范围和例外，不凑一个标签|
|不可判|工程失败、分母小或随机参照不足以区分|工程失败另立；分母小只禁止比例；未超过两随机不等于没作用或一般扰动获胜|

补充边界：ρ=0不变、ρ=1输出交互归零；这些端点也保留。弱区间与“微弱缩小/增大”可并列报告，连续值优先，不靠互斥标签抹去方向。

- **N 支持、M_T 支持或不支持：** 接上这一份局部计算到原生评分后半段输出的条件性连接；再形成具体新预测，决定下一 B 子问题或小规模 C 验证。不能宣布全部饱和原因已找到。
- **仅 M_T 支持：** 限制原生解释，保留混合背景发现；不得拿 M 阳性替代 N。
- **两背景弱/不支持或均未超有限参照：** 完成本轮负面/有限证据报告，暂停把“第13层这份交互是主要同向来源”作为推进依据。多层需另有证据与可区分预测，不自动扩层、加种子或剂量。
- **异号、过冲、两侧不同：** 先报告现象及操作含义；不能凭直接投影分散预设答案侧另有一套机制。

单层阳性不是多层研究必要前提，单层阴性也不是扩层通行证。若另立多层题，必须写明每层用干预运行的**同一当前入口**配四种 F 重算，只删本层新生交互；不能减去四条不同入口旧运行的交互。多层不属于本轮矩阵、预算或授权。

## 7. 实现和数值验收（待执行，不冒充已通过）

1. **来源与完整性：** 校验 CONV freeze-r03、两个正式收据、12记录及源张量 SHA；BRIDGE τ缓存、模型/软件/内核源码、提示token、a/停止token、形成时窗逐项对齐。缺件或版本漂移先停，不重建前缀救场。
2. **解析对象：** 对每输入背景核实 layer13 四角入口、旧S、g/β/z相同及 Q/V 依赖关系；用四项差与乘积差两种算法重构 I。FP64 恒等残差≤`1e-12+1e-10*||I||`，读项交互同标准接近零。重构 core 误差沿用 CONV r02 的 ≤1.05×BF16舍入底噪，零底噪要求精确零。旧保存 new 必须匹配重构来源；禁止从已舍入 core 四项差悄悄替代 I。
3. **实际命中：** 每评分仅 layer13 patch一次、14个深层G的recurrent各一次、chunk零次；记录每层路径，N入口替换一次。DEL/RAND与R在干预前入口、驱动、core一致；layer13 `s_new` SHA和返回对象不变；下游允许变化，不错误要求其相等。
4. **落地精度（r2 修订，冻结前）：** 删除在FP64计算后一次cast；实际 `core−core'` 对目标向量整体相对L2误差≤5%，零头不改。每头另设两条：（a）实现正确性：每头实际误差向量范数 ≤ 1.05×该头的 BF16 舍入底噪 ‖cast(core_h−d_h)−(core_h−d_h)‖；（b）可分辨性：目标范数 < 20×底噪的头，其目标能量合计 ≤ 2% 总能量，否则记工程不可判。真实删除与两条随机同用此规则；每头方向误差和总体误差全报。r1 的“每头范数误差 ≤5%”在冻结前用 CONV 已存第13层驱动预演（只算 I13 与 BF16 落地，不含任何 B1 输出）：整体误差 0.3%–2.3%，但每个输入/背景都有 1–5 个目标范数 1e−6–3e−5 的头误差 >5%（最高 0.86），低于 BF16 分辨率；按 r1 几乎所有输入都会工程不可判。20 倍分辨线下可分辨头每头误差 ≤0.050，不可分辨头能量最多 1.01%。不能放大向量、丢头、换种子或看结果后放宽。
5. **重放/无副作用：** 所有R全词表logits与CONV对应TT逐位相同，14层驱动一致。预检另外做零删除、FP64减I加I后单次cast、记录器关闭R：core与logits均应逐位不变；加回是工程检查，不算恢复机制证据。
6. **分析完整性：** 旧三角SHA固定；新旧停止/答案词独立复算；逐行验证I−I'=δ、κ=|1−ρ|，含负分母、零分母、ρ>1测试；不以真实结果符合预期作为验收条件。

若上述闸门失败，保存记录并终止该尝试/后续正式评分，报告“实现/来源/数值验收未通过”。修复需独立版本、累计预算及变更记录，不能原地覆盖。本方案设定的严格重放若在环境漂移下做不到，必须重新评估能否与旧三角混算，不能仅凭差值小继续。

### 9.4 与最近方案的区别及反方复查

与A的F切片替换相比：固定已形成材料与TT基底，改为删除其在当前计算中产生的指定I13；从“谁能承载”推进到“这一计算项有无输出作用”。与LOCAL相比：对象由S×w及J改成V×Q写入交互，旧阴性不能借用。与最初全层建议相比：撤回“一次二选一”和“LOCAL弱所以必须全层”，先做无需新增四角采样、同入口可核实的一层；B的总体任务没有缩小。

同一助手反方检查及修正：

1. **删掉后停止logit升了，是否就证明解释了饱和？** 否；必须对冻结I_out检查I'，并与随机比较。§5增加该估计量。
2. **ρ=1.5会不会误判为放大？** 会，若只看“超过100%”；现用κ=0.5，归反号但幅度减小。ρ=2.5才为κ=1.5。设计脚本覆盖负分母/过冲/零分母。
3. **只改core而不改S，是否名不副实？** 若叫删除写入更新即有硬伤；已限定当前写入项输出边，新增认识仍是该项怎样影响本步输出，不推后续记忆。
4. **全局四角后层入口不同，局部可加是否保证全局可加？** 不保证；仅13层同入口固定。输出不变/变大都为合法反例，不能用局部恒等式当输出预期必然成立。
5. **答案侧分母小，是否变相只研究停止？** 绝对两侧读数全部保留，小分母不算机制阴性；总路线保留回答责任，不用弱比例删去答案分支。
6. **对两条随机更强能否排除一般大幅损伤？** 不能；只支持对所抽方向的比较，不报零分布或领域普遍性。
7. **单层阴性是否白做？** 能限制这一特定同向传递候选；但不排除冗余/下游非线性，更不能自动扩层。§6列独立决策条件。
