## 3. 反馈中认可什么、收紧什么

认可“主预期不成立、保留混合背景有限作用、暂停此主要同向来源主张、不自动扩层”。但“第13层局部core改动很难传到输出”“这条因果箭头被否证”都应限定到**本次自然大小/方向、指定输出边、这些输入和评分背景**。两次LOCAL/B1操作不同，不能合成整个第13层不敏感的结论；本轮也没有测试持久S更新或后续生成。

N的I13范数是M_T的0.24166–0.42933（约24%–43%），两背景的干预大小、方向和下游状态均不同。弱输出可能涉及源项较小、后续响应差异或两者共同作用。不能仅凭范数比区分它们，也不能直接按这个比缩放ρ：ρ的分母I_out本身跨背景不同，还缺相同方向下的响应假设。该比例只说明需防止把跨背景效应差全部归于“敏感性”。

## 4. 下一步推进建议（方向判断，不是新实验合同）

**继续阶段B，但停止围绕“13层这份交互应当是主要来源”追加验证。优先利用本轮已有的R/DEL配对轨迹，判断哪些后续计算值得提出新的因果问题。**

先明确本轮13层实际改动经gated norm/out_proj后剩多少，以及R与DEL的差在后续残差和最终两侧读数上怎样变化。分别报告原始量、相对原运行尺度与投影；所有背景的大小/方向差保留，不能只比较裸范数。这里比再次画旧四角热点更有用：R/DEL确实来自本轮已实施的单一操作。但逐层轨迹仍只是候选线索，不能把在哪层差变大/变小就叫该层因果贡献。

并行对照已有路径审计提出的末端转换候选。原审计的前三层并非在所有背景都属于27–31：M_T为31/30/27，N为31/27/20；因此不把“27–31全注意力”当冻结层组或既定根因。真正应问的是后续计算怎样把已改变的材料变成输出竞争，以及它只是接收上游差异，还是产生新的非线性关系。只有形成区别于一般幅度/几何、继承上游差异的预测，才另写下一轮方案。

暂不做全14层删除，不扫描更多针或剂量，不只因为末端投影大就删末端层。跨层旧四角从14层起入口已不同，不能将其差直接命名“本层新生写入交互”；若以后设计同入口反事实，须另定义和验收。停止词和答案候选两侧持续保留，当前B1不说明整段回答，也不要求为答案侧预设另一套机制。

下一次推进的交付应是一项有现有证据支持、结果能改变判断的计算候选及其反例；若现存轨迹仍不足以区分，就准确列缺测量并暂停该分支。本次仅给方向和更新结果，未设计或运行上述分析/新模型实验。
