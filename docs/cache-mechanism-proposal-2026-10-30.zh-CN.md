## 1. 立项问题与判断

**少数通道的干预，怎样被写入模型的历史状态，并在停止干预之后继续影响回答？** 本线研究这段作用过程中的状态承载、跨层传播和后续读取，区分停止、内容选择、实际任务表现等结果。

研究对象是训练完成、权重冻结的语言模型。当前项目的“插针”是在 MLP 中间激活进入 `down_proj` 之前施加通道加法，不是已经执行了静态权重编辑。对线性投影，单通道加法在注入处等价于沿一列输出权重添加向量；位置少不等于有效扰动小，也不自动证明神经元有单一语义功能。

**立项判断：值得优先推进。** 现有证据已从输出观察推进到指定历史状态的双向替换效应，比稳定副作用控制线更接近其核心问题。优先级来自问题重要性、直接证据和已有工具，而不是已投入成本；不保证最终论文等级或完整机制一定可得。

本线有独立的科学成果标准，不以做出更好的控制算法为必要前提。与此同时，缓存替换是研究手段，不把“恢复得更多”本身当作整个课题的目的。

## 2. 痛点、科学价值与应用价值

| 维度 | 问题 | 本线希望推进什么 |
| --- | --- | --- |
| 科学痛点 | 仅观察到插针后输出变化，无法区分当前写入、此前状态和不同生成文字各自的作用 | 对同一文字历史，解释干预怎样通过可持久读取的状态影响后续计算 |
| 科学痛点 | 状态发生变化、替换状态有效、理解状态里的计算，属于不同证据层次 | 将已有组级因果定位推进为有边界、能提出可检验预期的解释 |
| 工业痛点 | 运行时停用干预后，已有会话状态仍可能携带此前影响；仅检查开关不足以描述实际效果 | 明确撤针与消除历史影响的区别，以及状态依赖的适用范围 |
| 潜在应用价值 | 干预时机、作用持续性和副作用来源难以判断 | 为控制时机、状态管理和副作用诊断提供依据；尚未证明部署收益 |

“历史状态”指本轮实现中的注意力 KV、线性层递推状态与短卷积状态。它不是模型权重中的永久知识，也不是跨会话记忆的同义词。本轮持续性证据限于指定前缀后的续写。

## 3. 已有证据及其来源

### 3.1 实验到底做了什么

在 Qwen3.5-4B 上，同一输入前 n−1 个 token 分别无针和有针处理，形成 C/T 两套历史状态；处理最后一个提示 token 和后续生成时均不插针。按缓存类型或层组混合 C/T，再分别生成和评分。KV 的 K、V 在这轮一起替换；线性层递推状态和短卷积状态分开替换。

全层面板覆盖 L0–L31，每层一个既有固定通道的正负方向，共 64 条件。它不是全模型所有通道的扫描。深度组按四层划分，例如组 4 是 L16–18 的递推及短卷积状态，加 L19 的注意力 KV；“下游层组”指这些具体模型层，不是第四种缓存。

### 3.2 直接结果

| 证据 | 已观察到什么 | 当前支持与限制 |
| --- | --- | --- |
| E1：全层缓存类型差分 | 固定面板上，停止优势异常可由线性层状态替换显著改变；承载事实敏感度变化的缓存类型随插针位置有所不同 | 支持条件相关的状态作用；不能给三类缓存命名天然、互斥的功能 |
| E2：L0/C4146，剂量 −1 | 新题停止优势增加约 20.3；只恢复全局 KV 减少约 0.84，恢复全局递推＋短卷积状态减少约 16.4 | 指定条件下，线性层历史状态对撤针后的停止倾向具有较大因果作用；不是所有通道或模型的规律 |
| E3：同一 L0 条件的局部恢复 | 只恢复组 4 三类状态，停止优势减少约 3.2；事实跟随回答从 0/24 增至 7/24 | 有实际交付改善，但单组只改善约 16% 的停止读数变化，不能认定唯一停止中心 |
| E4：L12/C3621，剂量 −1 | 只恢复 L16–18 递推状态，事实敏感度提高约 5.27；在干净背景仅换入相应受干预状态，下降约 5.75 | 有双向状态效应。单组件分解属于探索性；事实敏感度不等于事实利用能力 |
| E5：行为边界与未检出 | II-B 中晚层角色的全受干预状态下，事实跟随率仍为 96–100%；early:fact 的组级清理未通过多重校正检验 | 内部读数变化不等于可见失效；未检出不能写成零效应或信息永久丢失 |

该报告列出 29,112 次生成、58,224 条候选评分，含审核和预检；这些不是独立问题数。II-B 为 12 基础情景、24 输入，组联合双向主比较共 12 项，11 项检出。单组件分析不冒充全部经过确认性校正。回答阅读及新题构造为模型辅助，未经人工全量审核。本次立项只核对既有报告、合同和锁定记录，没有重新计算或独立复现实验。

### 3.3 测量口径

- 停止优势 D：最大 EOS logit 减最大非 EOS logit；同时看实际首步 EOS、交付、自然停止及长度截断。D 上升不必然导致停止。
- 事实敏感度 S：两种事实输入下，两条固定候选答案的对数似然差之差。它测规定候选对事实变化的响应，不直接读取知识或证明事实利用失败。
- 自由回答的事实跟随、明确错答、矛盾、未交付分别报告。中晚层读数异常不得写成中晚层任务已经失败。

## 4. 已经学到、仍需解释与竞争解释

**已经学到：** 在固定条件下，停止当前注入之后的效应，能被特定历史状态的替换改变；作用位置可以位于插针层之后；某些改变已达到回答交付层面。这比只观察激活差异更接近因果机制。

**尚未解释：** 哪些写入、保持和读取运算产生了这些效应；状态替换改变的是停止竞争、信息读取、答案选择还是其他计算；这种关系能推广到哪些通道、强度、时机和模型。

| 竞争解释或限制 | 为什么仍须保留 |
| --- | --- |
| 有效扰动较大，造成广泛失常 | 少数坐标不等于小能量，当前结果尚未证明所有效应都是特定行为控制 |
| 多处状态冗余承载或交互 | 一处污染有效、清理不足与此相容，但现有不对称不足以唯一确定冗余机制 |
| C/T 混合造成状态组合不一致 | 替换证明指定背景中的因果作用，不自动等于自然运行的唯一中介路径；不同组件的恢复份额不能随意相加 |
| 插针深度与可影响的后续层数量耦合 | 晚层组占比较大可能部分来自结构边界，不能全归因于语义分工 |
| 候选评分变化而实际任务仍正确 | 需要约束结论到测量本身，不能用分数下降替代事实利用受损 |

## 5. 近邻起点与贡献目标

本线直接承接已有缓存交换、混合模型状态分工和递推写入分析。最强机制比较对象为 *What Attention Recalls and Recurrence Controls in Hybrid Language Models* 与 *WriteSAE*；KV Cache Steering 是缓存影响后续行为的应用参照；DSI 是稀疏干预的上游方法参照。逐项覆盖、差异和核查范围见[查重报告](literature/cache-mechanism-prior-art-2026-10-30.zh-CN.md)。

**拟争取的贡献：解释一类重要的稀疏通道干预如何形成持续状态效应，给出可复用的因果关系及适用边界。** 这是贡献目标，不是已有结论。

成果可以体现为对已有解释的验证、具体化、边界修正或更有预测力的解释；不要求先发现一种全新缓存机制。不因近邻存在而退缩到无人关心的特例，也不把“多拆一个组件”单独包装成贡献。

成立的成果应将状态作用与明确行为或可解释的中间读数连接起来，交代竞争解释及推广边界。只有热点图、更多显著读数，或只能事后解释单题的叙述，不足以完成上述目标。即使没有提出新算法，可靠的机制解释仍可独立有价值。

## 6. 尚需补齐的证据与投入判断

## 7. 与另一条线的关系及本次交付边界

缓存机制线与稳定副作用控制线分别立项、分别判断成果。前者解释作用过程，后者改善控制效果与代价；可以共享数据、评价和工具，但不能共享一个含混的“成功”结论。缓存恢复不等于部署可用，控制改善也不自动证明内部机制。
