# 状态形成实验的逻辑审查与设计修订

## Material Passport

2026-10-31；design-audit-r02；academic-research-suite / experiment-agent / plan，当前会话内审查。对象为[上一版实验计划](cache-mechanism-write-update-plan-2026-10-31.zh-CN.md)，不改旧实验及原始数据。依据：固定版本模型源码、原始论文、旧合同与已完成收据。**仅理论、文献与设计工作；没有模型前向、GPU、生成或训练。** 这是设计修订，不是已通过验证的执行合同。

当前具体对照、固定项、结果解释及工作量见[成对实验设计r03](cache-mechanism-write-retention-design-r03-2026-10-31.zh-CN.md)。本审查保留为方法边界；r03不恢复A/B独立交换。

## 1. 审查结论

**用户进一步纠正后的本轮核心问题：干预改变了每一步写进去的信号，还是改变了已有信号被保留、衰减和修正的方式？这两类改变怎样形成历史状态，并分别或共同影响撤针后的回答？** 后续设计必须直接回答这个问题，不能退回宽泛的“研究形成过程”，也不能改为寻找哪个节点干预有效。

上一轮修订把合理干预、真实轨迹与承载桥接放到了中心，却没有逐项说明它们怎样回答上述问题，造成实质性的重心偏移。这里修正的是问这个问题的方法，不撤换问题。总课题仍是暂时通道干预的历史状态机制。

**上一版A/B独立交换不足以承担主要机制证据。** 它可以测量一种明确的人造计算操作的效应，但不能仅凭重建通过、双向有效或同幅度对照无效，归因到原始干预中的“更新机制”或“写入机制”。上一版结果表中“某项作用更强→原始干预主要经该项形成”的推断过强，应撤回。

修订为：**围绕写入改变与已有状态处理改变提出对应预测 → 真实轨迹分析 → 保持共享变量一致的成对过程干预 → 比较状态/读出与回答。** A/B分解可作账本；A/B交叉不再是默认主实验。共享的k、β可能同时改变更新与写入；必须把这部分共同作用纳入原问题的答案，不能用它来回避原问题，也不能强行指定为某一边。

## 2. 漏洞具体在哪里

### 2.1 打断了原规则中的共同变量

沿用本项目key×value记法：

\[
S_t=A_tS_{t-1}+B_t,\quad A_t=\alpha_t(I-\beta_tk_tk_t^\top),\quad B_t=\beta_tk_tv_t^\top.
\]

A与B共享k、β。取A_C、B_T，可能相当于让同一步沿C的key方向修正旧状态，却沿T的另一个key方向写入。它不一定对应任何一组共同的α、β、k、v。

一个无需模型的反例：二维key、标量value，α=0.8、β=0.5，k_C=(1,0)，k_T=(0,1)，v_T=1。则A_C=diag(0.4,0.8)，B_T=(0,0.5)。在原更新式的合法门范围内，A_C的收缩方向要求k沿第一坐标，而B_T沿第二坐标，两者不能由同一个k产生。

这证明的是**该一步的交叉算子不一定符合原更新规则的联合约束**；不证明其最终矩阵在任何其他输入历史下都不可达，也不证明任何人工干预都无效。它是可定义的边操作，但其因果问题是“人为拆开这两条作用路径会怎样”，不是自动等于“原始通道干预通过哪种自然形成过程起作用”。

### 2.2 “写入”边界还依赖代数写法

同一更新也可写为：

\[
S_t=\alpha_tS_{t-1}+\beta_t k_t\left(v_t-\alpha_tS_{t-1}^{\top}k_t\right)^\top.
\]

后一项包含预测误差修正，依赖旧状态与α。若把它叫“写入”，α的作用就同时出现在保留项和写入项中。上一版把B单独叫作“写进去的信号”，容易让读者误以为它就是完整的物理写入操作。

因此A/B分解可精确记账，却没有天然唯一的“机制贡献百分比”。不能用数学可分解代替科学上可独立操纵。

### 2.3 离线固定驱动还遗漏了活模型的反馈

上一版用两条原轨迹的系数离线重建L16–18，再同时替换末状态；没有让中途读出变化影响后续层的输入、门、查询和KV写入。固定系数重放回答的是条件性问题，不是原模型对过程干预的完整响应。尤其不能把三层各自离线重建的状态，称为同一条完整模型轨迹的状态。

### 2.4 结果恢复可能是补偿，不一定阻断原始成因

一个新状态可以通过另一条路径把输出推回正确答案。行为恢复本身不能区分“撤销原成因”与“用另一个效应抵消异常”。同样，在正常背景重现某个异常，说明该操作能够造成此结果，不证明原始插针一定通过该操作造成。

旧四格中的背景依赖、KV单独污染与整组污染的非单调性，正是不能跳过这一步的现成理由。

## 3. 原有对照能回答什么，不能回答什么

| 对照 | 可排查的问题 | 不能据此认证的内容 |
| --- | --- | --- |
| C/C、T/T原样重建 | 公式、头映射、时序和数值实现是否正确 | C/T、T/C的联合计算是否合理 |
| 同幅度方向置换 | 效应是否可由这个特定同幅度扰动复现 | 没有效果不证明主臂在分布内；随机方向可能根本碰不到重要方向 |
| 干净/受干预双背景 | 操作作用的背景依赖、方向不对称 | 两个背景都有效也不能排除二者都产生失配 |
| 状态范数、最近距离 | 明显爆炸或很大的几何偏离 | 近不等于合理；状态方向、查询匹配及跨层一致性仍可能错误 |
| 末状态完整恢复后输出一致 | 确定性重放与管理字段正确 | 不是新机制证据；固定完整状态和输入后输出相同本来就是预期 |
| 生成恢复/恶化 | 操作有可见行为效应 | 不自动说明原始成因、记忆删除或独占中介 |

结论不是再加几个随机对照就能修好旧推断。需要改变主要干预的定义，并让结论受到真实轨迹和过程预测的共同约束。

## 4. 修订后的干预单位

### 4.0 每个比较必须对应回核心问题

| 核心问题的部分 | 直接比较什么 | 能回答到哪里 |
| --- | --- | --- |
| 每步写入信号的改变有没有行为作用？ | 在同一接收条件中纠正v支路，与未纠正及自供体参照比较；反向检验另报 | 固定该步其他变量时，v只直接改变加性项B。可检验value驱动的写入改变，但不是全部B变化 |
| 旧信号的处理改变有没有行为作用？ | 在同一接收条件中纠正α支路，采用同样的参照、时段、状态和行为终点 | 固定该步其他变量时，α直接改变旧状态项A S。可检验衰减驱动的旧状态处理改变，但不是全部定向修正 |
| 两部分是否通过共同变量一起改变？ | 检查k、β的实际变化；必要的干预必须同步作用于A和B | 检验共享地址/更新强度造成的共同改变。该部分不能无约定地分配成纯写入或纯旧状态处理 |
| 哪类改变解释后续回答？ | 将每类过程操作的状态变化、首次读出与同一套停止/S/回答终点对应 | 不能只比较哪个节点效果大；须判断是否符合各自形成过程的预测 |

前两项是本轮需要成对回答的比较，不能看到某一节点有信号，就只留下该节点而省略另一项。共享变量检查是回答完整性的必要部分；是否需要增加其具体干预，由前两项及原始轨迹尚不能解释的部分决定，不作为另一个无关课题。

这里“只直接改变”严格限定于同一步、给定其他变量与旧状态的局部计算。完整运行后，v干预也可能间接改变后续门，α干预也可能间接改变后续写入。必须记录这些间接变化，不能把完整轨迹中的总效果冒充纯B或纯A效果。局部计算对照与完整轨迹检验分别报告，彼此约束。

本轮的答案可以是写入改变具有作用、旧状态处理改变具有作用、两者共同作用，或某部分仍无法区分；必须交代分别覆盖了哪些变量、哪些共同项。不能以测了v和α就声称已经穷尽全部写入与更新，也不能因为不能穷尽而换掉核心问题。

### 4.1 不拆A/B来源；在模型真实存在的变量上操作

在同一题、同一token、同一层/头对齐后，使用原始C/T轨迹的变量作为供体；干预发生在前缀处理期间。接收模型按完整前向运行，后续计算从修改后的结果自然重算。

| 候选过程 | 明确操作 | 保持的联合约束 | 可以怎样命名 |
| --- | --- | --- | --- |
| value支路 | 将当前v替换为同题同位置的供体v，保留接收端当前k、β、α | 同一步A/B仍使用同一个k和β | value支路对状态形成的作用；不是“全部写入机制” |
| 衰减门支路 | 替换当前g（α=exp(g)）并重算原更新 | 原式中的所有α使用同一新值，不能只换某个展开项 | 衰减门支路的作用；不是所有旧状态更新机制 |
| 共同的key/更新强度 | 将(k,β)作为一个候选束替换，重算修正和写入两边 | k、β在全部出现位置同步使用 | 共享地址及更新强度的联合作用；本轮不再拆成A/B二选一 |

(k,β)成束是本轮避免再次割裂共同作用的设计选择，并不声称它们不能分开研究。若以后单独干预k或β，也必须更新其所有下游用途。

v在卷积后的实际value节点操作；g是实际递推接口中的对数衰减；k必须处理归一化与共享头扩展的一致性，不能给同一源key头的多个展开副本注入不同来源。具体位置以固定版本源码为准，执行前再对照实际运行代码。

**这里的“保持一致”仅指局部计算规则一致，不等于全局在分布内。** 用C的v配接收端其他变量，仍可能不是某个自然隐藏向量会共同产生的值。节点干预允许打断变量的上游来源，这是因果测试的定义；它减少了上一版的明确结构问题，但仍需要下面的证据链，不能自行获得“真实机制”标签。

### 4.2 必须采用活模型重算，不能暗中回到固定系数重放

每次干预后，实际状态、读出、残差、下游q/k/v/门、KV及后续状态均由当前接收轨迹重算；只有选定节点按预定时段取供体值。所谓“只改v”，指直接干预节点只有v，不是保证所有后续A都保持原值。若为了隔离而冻结后续系数，那应另命名为“固定驱动诊断”，不能混报。

原插针位置、剂量、校准及相同前缀token不变。所有额外过程干预在撤针边界前结束；最后提示token和生成均无额外过程钩子，才能解释为形成过程留下的历史作用。禁止延续修复钩子到生成期后再称其为历史状态机制。

## 5. 怎样让证据区分原始机制与人工异常

不能用一个通过/不通过标签彻底排除全部分布外解释。可做的是建立以下逐级证据，限定最终能说的话。

### 第一步：在未经额外拼接的C/T轨迹中找到待解释的过程

记录原始轨迹的S、k、v、α、β，以及撤针后首次读取所需的q和门控读出。已有导出缺少这些张量，当前不能假装已经完成分析；将来采集需单独计入预算。

可以在CPU做精确账本：

\[
\Delta S_t=A_t^T\Delta S_{t-1}+\Delta A_t S_{t-1}^C+\Delta B_t,
\]

并同时用等价的C传播写法检查解释是否依赖记账顺序。它帮助定位真实差异出现的时段及变量，但“等式重建成功”只是计算核验；几何项大小不等于行为贡献。不能仅凭某项范数大就选它作为机制。

对更新后原始读出o=Sᵀq，还可分别记录状态差异和查询差异；门控归一化、输出投影及下游变化另列。不得把读出改变全部归于S，也不得把线性读出账本直接当最终logit预测。

**进入过程干预前应写出具体预测**：哪一节点的替换会改变哪一段状态差异、首次读出朝什么方向变化、预期对应哪个行为终点；哪些结果会反驳它。预测在打开新增干预结果之前冻结。若只能写“换了应该有影响”，这轮仍没有准备好。

### 第二步：用一致的节点干预检验，而不是用A/B混合结果自证

对有具体预测的候选过程，做T轨迹中取C供体，以及C轨迹中取T供体。两方向分别解释，不能要求真实机制必然镜像对称；但若只在一个方向有效，必须保留背景依赖或补偿解释。

自供体操作、未操作原轨迹是工程参照；所有状态与操作来源可审计。至少比较过程干预后实际出现的状态变化、首次读出及停止/S/回答，不能只挑其中变好的指标。

若“行为改善，但预期的状态/读出变化没有出现”，这轮不能声称原机制被验证，应优先考虑补偿、错误预测或其他路径。若“状态按预测变了，但行为没变”，只支持形成或局部读取关系，不夸大为整个行为机制。

这一步形成的前缀来自一个可执行的完整受控模型轨迹，避免“各层离线重建后一次塞回”作为唯一依据；但它仍是人工节点干预，不冒充未干预模型的自然历史。

### 第三步：必要时桥接到旧状态替换证据，区分末端承载与前缀期间传播

设X为原接收轨迹，P为经过候选节点干预后完整运行的轨迹。两者在相同撤针边界保存所有状态。G仍指原组4递推，O指其余完整状态。

| 读取条件 | 含义 |
| --- | --- |
| (G_X,O_X) | 原接收参考 |
| (G_P,O_P) | 过程干预实际形成的完整历史；用于主要行为证据 |
| (G_P,O_X) | 仅把过程干预形成的组4递推换回原背景；检验末端G在该背景中的受控充分性 |
| (G_X,O_P) | 从过程干预轨迹撤销末端G改变；检验在O_P条件下对G的依赖 |

这不是把旧C/T四格换名重做：新供体P必须来自明确的节点过程干预，且先有对形成过程的预测。其新增问题是“这个过程形成的作用由撤针时的G承载，还是已在前缀期间传到其他状态”。旧整块C/T交换不能直接回答这一点。

**两个混合臂仍有失配风险。** 它们是定位承载关系的补充，不压过完整P轨迹证据。若只在混合臂有强效果、完整P轨迹没有预期效果，不支持原过程机制；若只有完整P有效，说明G单独承载不足、或存在匹配依赖，不能直接宣布全部由其他状态承载。各臂不能相加为自然中介比例，也不是唯一必要/充分性证明。

不把“让完整状态相同后结果相同”作为第二种独立机制验证；那只是实现恒等检查。

### 对照的优先顺序

1. 先保障联合规则和活模型重算正确、自供体无效应。
2. 再要求真实轨迹中的变化、冻结的过程预测、实际状态/读出变化与行为相互约束。
3. 用必要的双向与承载桥接检查背景和补偿。
4. 同幅度方向对照可保留辅助地位，但不能取代前三项，也不能给全局分布一致性背书。

不因为新增每种对照都有道理，就同时铺开三类变量×全部层/头×时间窗×背景的完整网格。首先围绕写入改变与旧状态处理改变分别形成可证伪预测，并明确共同变量留下的歧义；不能转成“先找一个有效节点再说”。当前缺少原始内部轨迹，不先按旧输出强弱指定v、α或(k,β)为赢家。状态承载桥接服务于解释这些形成过程的行为作用，不取代本轮的成对核心比较。

## 6. 相比WriteSAE新增的认识应在哪里

核对了[WriteSAE v4](https://arxiv.org/html/2605.12770v4)的§2替换协议、§3–4实验、§6.2限制和附录A。作者已做写入替换、删除/随机参照、后续logit及生成干预；因此“写入→传播→读取→行为”以及同幅度对照都不是我们的新意。其传播推导含固定驱动下加性项抵消及进一步近似，且报告了适用边界。不能把作者工作描述成只有表征、没有行为。

本项目拟补的是：**一次上游通道干预，究竟怎样共同改变状态形成所需的变量；哪些改变对撤针后的异常有受控因果作用，以及这种作用留在当前递推中还是已传入其他历史状态。** 这是具体研究对象上的拟新增认识，不是尚未做实验就成立的贡献，也不是对全部文献的排他新颖性认证。

| 比较问题 | 本轮需要跨过的门槛 |
| --- | --- |
| 只证明某个写入/状态替换会影响输出 | 与已有工作高度重叠，不够 |
| 把固定驱动传播公式应用到一组不同输入 | 可能只是应用验证，不能自动称机制突破 |
| 解释实际插针同时造成的更新、写入和读取条件变化 | 须有真实轨迹证据及一致节点干预，不能靠A/B拼接后的效应命名 |
| 解释过程变化与停止/事实响应分离、背景依赖的联系 | 须事前给出可被反驳的预测，并在新增干预上检验；不能事后给每个结果编一套原因 |
| 从过程干预追到撤针时的状态承载或此前向下游传播 | 须比较完整受控轨迹与有限的承载桥接，并保留失配和补偿边界 |

不把论文中的某个4B失败当作我们这条机制已被证实，也不把不训练SAE、换模型、换层、换指标本身作为贡献。

## 7. 旧资产保留什么，上一版撤回什么

保留：L0停止与L12事实响应两个旧锚点；组4作为已有状态效应入口；冻结题目、剂量、来源、候选和回答；D/S与行为分开；已有四格与非单调反例；同一研究主旨及后续保持/读取/范围目标。

撤回：把A/B独立交换作为主要自然机制归因；把随机方向未复现作为合理性认证；把离线形成作用直接等同活模型作用；从单项恢复强弱直接命名主导成因。

上一版192条新回答、276条评分记录、固定数值容差和1 GPU小时提议均依附旧设计。**它们不自动继承为修订设计的执行预算或验收标准。** 新方案若采用完整前缀节点干预，每个条件可能需要新前向，不能沿用“36次来源prefill后全部廉价分叉”的旧账本；也不能凭相同首token和候选分数就保证全部自由生成轨迹完全一致。

本轮已经完成的是逻辑审查、干预定义修正与证据要求。当前仍未取得原始内部轨迹、未确定拥有具体预测的主检验节点、未验收实际实现，因此不把修订框架包装成可直接上卡的冻结合同。

## 8. 最终解释的强度

- 仅代数重建：说明计算账本正确。
- 一致节点干预改变结果：说明该受控操作有因果效应。
- 真实轨迹、事前预测、过程干预及状态/读出/行为相符：支持原现象的一段机制解释，仍有范围与替代解释限制。
- 再有新增输入或条件上的成功预测：才进一步支持可复用的机制关系；不是本轮提前宣称的成果。

研究目标不随层级下降而缩小。证据尚处在哪一级，就按哪一级报告；不会为了给本轮一个“机制结论”而越级。
