# CFM三阶段目标审计：完成实验不等于完成机制识别

## Material Passport

2026-10-31；academic-research-suite / experiment-agent / plan + validate。设计者自审，不是独立评审或模型复现。对照S1原计划、S2 v1/v3、S3 v2及已完成S1/S2证据；没有新模型计算或GPU任务。

## 1. 原目标与实际交付

主线一直是：干预怎样改变每步写入与旧信号的保留、衰减、修正，以及这些变化怎样影响撤针后回答。完整机制解释允许两者共同起作用，不要求硬选唯一赢家；但必须解释具体过程如何推动、抵消或不影响输出，不能止于“都非零”。

| 阶段 | 原本负责什么 | 实际得到什么 | 达成程度 |
| --- | --- | --- | --- |
| S1 | 原C/T中差异的运算来源、时间形成及局部读取；支持选择下一轮 | 有实际逐步轨迹、W/R抵消、撤针后ΔB和读取投影；coupled判据对自然事实差异也常触发 | 过程观测基本达成；机制分支判别未充分达成。不能称零收获，也不能以采集完成代替判别成功 |
| S2 | 用控制前史的操作检验形成解释、判断共同旧来源处理；原v1还含剂量分账稳健性 | 同起点第一步两项变化、H/N形成和读取、仅早针后更新仍变；L0的r10<0.5被反驳；严格相等排除表全部同判 | v3具体过程测量得到交付，形成解释受到实证约束；区分有效机制的能力低于预期。v1剂量稳健性后来移到S3，不能算已完成 |
| 原S3 | 过程分量连接输出，检查其余历史与实际回答 | 尚未执行；自由回答提供时序总效果，统一剂量路径提供限定坐标的归因 | 原设计即使顺利，也不保证独立的过程—行为识别，不能许诺第三阶段自动补齐 |

“前两阶段什么都没有”不符合已有证据；“前两阶段的科学目标全部完成”同样不准确。设计上我把可测量性、严格零差异的排除与真正有区分力的机制检验靠得太近。这是设计判断需要纠正，不是执行者没有认真运行。

## 2. S2对S3提出的具体要求

证据来自[固定S2提交](https://github.com/yuxiexiong/acupuncture/tree/69e140d81dcb101b98dbea43bbc392b9e08b7663/experiments/cache-formation-mechanism-s2-formation-test-v3-2026-10-31)；详见[S2复核](cache-formation-mechanism-s2-result-review-v1-2026-10-31.zh-CN.md)。

- N来源投影占优不能叫纯写入主导，因为N含新写入及后来对这些信号的处理。下一步应把这两部分连到同一个输出Q，而非再比较状态范数。
- H状态投影小不能断言H对Q小；读取方向与下游映射可能不同。必须量化指定输出对该形成向量的响应。
- L0查询项在局部读取分账约占22%–40%，且其他缓存仍可能承载前缀效应。不能只计算目标递推两项然后让未解释量消失。
- L0只有早针时不首步EOS但候选事实敏感度低，尚不知道真实内容是否受损。L12-VAR01也反驳简单的“晚段统一主导”外推；两种反例必须保留。
- 首步EOS及固定候选分数已经可见，不可包装成S3的新盲预测。按现有greedy规则，48个新时序条件中10个首步EOS已确定为空输出；这些没有新的内容证据。

## 3. 原S3不能保证完整回答的原因

1. 时序自由回答同时允许写入、处理、其他历史及生成文字改变，识别的是原操作总效果，不是W/R各自的行为作用。
2. 在τ叶缓存求梯度，得到的是经这些末态坐标进入后续输出的敏感性。目标层在前缀已传到其他缓存的影响计入O，不能用此给全模型W/R总贡献。
3. 分量×梯度及剂量积分有分解、路径和数值近似条件。数值闭合与预测通过，可以支持限定的计算解释，不自动成为两个可独立实施机制的因果证据。
4. 真实回答变化与计算解释并列相符，也没有逻辑上自动消除上述缺口。新剂量点是新操作条件，不是新题泛化。

这不是额外要求必须获得“所有模型唯一因果百分比”才算成功。更基本的缺口是：尚未直接验证某项形成变化的作用是否足以解释所关心的同一输出响应。现有设计不能仅靠增加第三阶段编号解决它。

## 4. 调整决定

[S3 v3修订稿](cache-formation-mechanism-s3-readout-behavior-plan-v3-2026-10-31.zh-CN.md)将过程—输出的定量预测作为主要模块，自由回答作为配套检验；暂不执行原全前缀统一剂量网格。改用与S2共同前史配对一致的后段原针强度路径，分别核对加性写入、对b时旧来源的处理、对b后新来源的处理，以及其余缓存路径。

重点不再是某项是否非零，而是包含/省略该项的预先固定计算式能否预测同一输出变化，符号、大小与误差是否允许区分，及其是否解释已有反例。它仍是有限路径上的计算解释检验，不冒称独立行为中介实验；结果相同或方法不可信，必须结案为仍不可区分。

第三阶段可能取得两类有用认识：形成分量经目标末态如何改变指定输出的可核验解释；以及候选变化是否对应实际回答。**它不能保证完整回答中心问题。** 三阶段结束可以得到有边界的部分机制，也可能得出当前方法无法区分。不能因只规划了三个阶段，就自动追加第四阶段或把“未识别”重命名为“已完成”。

## 5. 对S3调整稿的修改后Review

| 核查 | 结论 |
| --- | --- |
| 是否仍针对中心问题 | 是；同一Q终点分别承接加性写入、对旧来源处理、对新来源处理，行为单列。时段与剂量是操作手段 |
| 是否以N冒充纯写入 | 否；Z_B与Z_N之和才是ΔN；共享变量仍正常共变 |
| 是否只重复非零判决 | 否；检查定量预测与省略项预测的差异，若都能预测就报不可区分 |
| 是否仍遗漏其他历史路径 | 保留O并说明其中可能有目标层前缀传播后果；不宣称全模型过程份额 |
| 新点是否真是未见输出检验 | 只在预测文件先冻结、细化点Q后打开时成立；形成状态已用，所以不是未见输入/状态预测 |
| 是否偷换独立因果识别 | 省略项是预测式检查，不是模型内独立过程干预；即使预测准确，也不承诺独立中介 |
| 是否能在最后强行判成功 | 不能；数值不可信、模型间不区分、行为不对应分别结案，不得以非零或总量闭合替代 |
| 计算是否无限扩展 | 5点固定后段路径，工程先行、上限明列；旧168点包停用，不叠加新旧包 |

反例复审：若Q只依赖O，目标S即使变化大也不能得到过程解释；若Z_B与Z_N很大且反向，省略任一项均预测失败也只说明此计算解释需要抵消，不证明可独立干预的两种因果机制；若状态预测准确而内容正确率不变，结论止于指定分数，不能叫能力损伤。上述情况均有对应失败/限制出口。

审查结论：调整稿是针对当前缺口的有限计算解释方案，不是已经证明能完整回答中心问题的最终实验。工程可行性与实际区分力仍未验证。此次保存审计与调整稿供用户审阅，未修改已冻结S1/S2实验，也未运行第三阶段。
