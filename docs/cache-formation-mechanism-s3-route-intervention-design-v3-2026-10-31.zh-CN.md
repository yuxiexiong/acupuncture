# 缓存形成机制｜CFM-S3 v3 设计草案：缓存写入变量的介入式拆解

> 状态：设计草案，未冻结、未授权运行。拟替代 [CFM-S3 v2](cache-formation-mechanism-s3-readout-behavior-plan-v2-2026-10-31.zh-CN.md)。尚未登记到计划索引（索引由你维护）。新增 GPU 为 0。

## 0. 一句话

不再观察差异，而是在原生前向里**逐组撤掉或单独保留**干预对模型自身"写缓存变量"的影响，直接测量每一组对停嘴和事实使用这两种回答效应是否**必要、充分、可加或必须联合**；同时把撤针后的效应拆成"直接读取遗留内容"和"遗留内容改写后续投影"两条路径。

## 1. 为什么现有设计答不了核心问题

S1、S2 测的都是 T 与 C 两条原生轨迹的差：差异在哪、何时出现、怎样记账。差异记账再细，也只能说明"变了什么"，回答不了"哪个变化造成了回答效应"。要回答后者，必须改变某个中间变量、固定其余，再看回答怎样响应。历史上失败的几种做法（第 9 节逐条对照），问题都出在**改动的变量不是模型自己的变量**：A/B 项、乘积补偿、交换算子，都是在离线记账的坐标里动刀，组合出模型不会产生的状态。

本设计的出发点是：只在**模型源码里真实存在、并且决定缓存内容的那些张量**上做介入，而且要先证明这些张量穷尽了"针位信息到达答案"的全部通道。

## 2. 理论基础：从源码推出的两条事实（推导档，待 P0 的精确检验确认）

**事实 A：针位信息到达答案，只能经过针位上写入的缓存。** 答案位置（末提示 token 与候选）计算时，对之前位置的访问只有三条：

| 通道 | 源码中写入缓存的张量（每层、每个针位） |
|---|---|
| 递推状态 S | 线性层卷积后的 k、v，以及 α（来自 `in_proj_a`）、β（来自 `in_proj_b`） |
| 卷积缓冲 | 线性层 `in_proj_qkv` 的卷积前输出（最后 3 个位置），并经卷积进入后 3 个位置的 q/k/v |
| KV 缓存 | 全注意力层 `k_proj`（经 k_norm、RoPE）与 `v_proj` 的输出 |

MLP、残差、各种 norm 都没有跨位置的状态。线性层的 q、z，全注意力层的查询和输出门，在针位上只影响该位置自己的残差，再经更深层的上述张量间接进入缓存。

**事实 B：把这些张量在针位上全部换回 C 的值，后续计算必然逐位等于参照运行。** 因此"写缓存变量"的分组是**完备**的，任何残余效应都无处藏身。这一点用已有资产即可精确检验：E 段全部换回应逐位重现 S2 的原生 01，L 段全部换回应逐位重现原生 10，两段都换回应重现 00；S2 的 84 份 Mτ 就是标准答案。

## 3. 介入变量：按模型自己的变量分组，不拆共享变量

线性层的写缓存变量在**投影输出**处分组（在卷积之前，这样卷积的时间混合自动随组走，组与组不重叠）：

| 组 | 源码张量 | 在递推更新中的作用 | 对应核心问题中的哪一个 |
|---|---|---|---|
| **V 内容** | `in_proj_qkv` 的 v 通道 | 只进修正量 e = v − m，决定写进什么 | "写进去的信号" |
| **R 保留** | `in_proj_a`（→ α） | 只对旧状态整体衰减 | "已有信号的保留、衰减" |
| **K 寻址与强度** | `in_proj_qkv` 的 k 通道 + `in_proj_b`（→ β） | 同时决定写在哪、写多重、从旧记忆里取什么并擦掉多少 | "已有信号的定向修正"，与写入不可分 |
| **Qc 未来查询** | `in_proj_qkv` 的 q 通道 | 经卷积进入随后 3 个位置的查询 | 读取条件的一部分 |
| **KV** | 全注意力 `k_proj`、`v_proj` | 写入 KV 缓存 | 注意力通道 |

k 与 β 同时进入写入和擦除，这是架构事实，所以**不拆**。K 组的效应就是"写入—擦除耦合"本身，结果按联合机制报告，不再去追求写入与擦除各占多少。v 只影响写入，α 只影响保留，这两组才能单独解释。

**介入方式**：在原生前向里，用钩子把指定组在指定位置的投影输出替换为参照运行（C）同位置的原生值，其余一切照常计算，包括下游各层会对此做出反应。不改内核、不改分块、不拼缓存、不补偿。替换值都是模型真实产生过的值。

## 4. 实验族

记号：在 11 运行（E、L 都开针）上，对**针所在层之后的全部层**做介入。窗口 W ∈ {E, L}，E 为模板开始至事实段末，L 为事实段后至撤针。参照分别为 01（撤掉 E 影响的结果）和 10（撤掉 L 影响的结果）。

### 族 F：形成期写缓存变量的必要性与充分性（核心）

| 格 | 做什么 | 回答什么 |
|---|---|---|
| 完备性（1） | W 内五组全部换回 | 必须逐位等于参照（01 或 10）；不等即停 |
| 单组撤除（5） | 只把组 G 换回 | **必要性**：撤掉 G 的变化，效应还剩多少 |
| 单组保留（5） | 除 G 外全部换回 | **充分性**：只留 G 的变化，效应能复现多少 |
| V/R/K 交互（4） | VR、VK、RK、VRK 换回 | 递推通道内部是否可加、是否需要联合 |
| 受控直接效应（3） | 换回 G，同时把 V/R/K 中另两组钉在 T 值 | G 不经另两组反应的直接作用；与单组撤除之差即经它们的间接作用 |
| 层范围（2） | 五组只在首个受影响层组换回 / 只在其后各层换回 | 撤针后效应来自首受影响层留下的状态，还是更深层的写入 |
| 零对照（10） | 单组撤除与单组保留各配一个反射值 2·G_C − G_T（等幅反向） | 标定"任意同幅改动"会造成多大回答变化（研究准则 6.3） |

首个受影响层组：L0 针为 L1–L3，L12 针为 L13–L15（到下一个全注意力层为止）。

### 族 P：撤针后两条路径（在 11 与 10 运行上，介入撤针之后的位置）

| 格 | 做什么 | 回答什么 |
|---|---|---|
| 内容路径 | 撤针后各层**全部投影**（含查询、门）换成 C 值，缓存保持 T | 遗留内容在干净读取条件下被直接读出时的效应 |
| 只换写入 | 撤针后只换 V、R、K、KV | 遗留内容是否要靠改写后续写入才起作用 |
| 只换读取 | 撤针后只换查询类（q 通道、z、注意力 Q 与门） | 读取条件变化本身的作用 |
| 零对照（1） | 内容路径格的反射值版本 | 同上 |

T 运行的总效应 = 内容路径效应 + 经后续投影的效应；后者再分写入与读取。这正对应核心问题里"延续"与"行为"两环。

### 规模

每个（锚点、输入）：族 F 每窗口 30 格 × 2 窗口 = 60，族 P 8，参照原生运行另需全层投影捕获（00、10、01、11）。开发面板 2 锚点 × 12 输入 → 约 1.7k 条短运行（每条为一次前缀加末提示加两条候选，无自由生成），估计约 1.7 GPU-h，双卡每卡 4 worker 墙钟约 20–30 分钟。确认面板（第 6 节）只跑决定性格，约 0.7k 条。

## 5. 读数与判据（事先写死）

**行为终点**：首步停止优势 D 与首步 EOS；每个输入的事实裕度 m = ll(正确) − ll(错误)，以及情景级 S_fact。候选用 teacher forcing，避免文字分叉引入新路径。只在确认为载体的格上做一次自由生成，作为总效应核对，不作归因。

**恢复比例**：ρ = (Y_格 − Y_T) / (Y_参照 − Y_T)。分母未超过零对照幅度的格，不报比例，只报绝对变化。例如 L0 的停嘴在 E 窗口的分母很小（S2：01 与 11 的 D 都在 0 附近）。

**每组的结论类别**（逐情景报告，必要性 ρ_N 来自单组撤除，充分性 ρ_S 来自单组保留，阈值都相对零对照）：

| 结果 | 结论 |
|---|---|
| ρ_N 与 ρ_S 都高 | 该组单独就是该行为效应的载体 |
| ρ_N 高、ρ_S 低 | 必要但不充分：需要与其他组共同变化（联合机制，看交互格找出伙伴） |
| ρ_S 高、ρ_N 低 | 充分但不必要：存在冗余通道 |
| 都低 | 该组对这一行为没有可测作用 |
| 单组之和 ≈ 总效应、交互项小 | 可加：各组贡献可以分别陈述 |
| 交互项大 | 联合：只能陈述组合起作用的方式，不给单组份额 |

停嘴与事实使用分别判。S2 已显示二者在 L0 上可分离，本族直接检验它们是否由不同的写缓存变量承载。

**路径真实性（排除补偿）**：行为恢复必须伴随内部状态向参照恢复。检查点包括撤针时各层缓存与参照的距离、答案位置各层组之后的残差、L16–18 状态（与 S1/S2 衔接）。若行为恢复 ≥ 0.5，而最终残差的恢复 ≤ 0.2，或其改变方向与（参照 − T）的余弦 < 0.5，就标为"补偿性恢复"，不算找到原路径。

**失配诊断**：每次替换都同时记下"该位置本来会算出的值"。若插入的 C 值与本来值之差，超过 T 与 C 之差，说明这一格已离开原生轨迹太远，结论降档。

**完备性与精度闸门**：完备性格必须逐位等于参照；记录器与钩子先在无替换时逐位惰性；每条运行仍对 II-B / S2 资产做复现核对（同 S1、S2）。任何一道不过即停。

## 6. 阶段与顺序

1. **P0（零 GPU，先做）**
   - 把第 2 节的完备性写成逐行对照源码的证明，列出首受影响层组。
   - 用 S2 的 L16–18 驱动量做离线局部因子分析：上游输入固定，只在该层交换 V/R/K 组，看局部状态与读出怎样变。它只是局部近似，用途是提出可反驳的预测，不当证据。
   - 写死第 5 节阈值与第 7 节预测，提交并记下哈希。
   - 在小模型上做 CPU 测试：替换钩子的惰性、完备性逐位重现、各组互不重叠。
2. **P1（GPU，开发面板）**：族 F 加族 P，两个锚点，现有 6 情景 × 2 事实。
3. **P2（GPU，确认面板）**：validation-r01 里另外 6 个从未用于 CFM 的情景（VAR03/04、VRD03/04、VRL03/04），只跑 P1 中判为载体或联合的组对应的格，加完备性与零对照。用 P1 冻结的预测检验，这是本线第一次真正的样本外检验。
4. 只有在 P1、P2 给出明确载体后，才考虑在载体组内按层定位。那是后续的条件阶段，不在本轮。

## 7. 事先登记的可区分解释与预测（P0 结束时冻结；下面是草案）

| 解释 | 预测 | 反驳它的结果 |
|---|---|---|
| H-内容：效应由写进去的信号承载 | V 组 ρ_N、ρ_S 都高，R、K 低 | V 组单独撤除不恢复，或单独保留不复现 |
| H-保留：效应由旧信号衰减方式改变承载 | R 组主导 | R 组两项都低 |
| H-耦合重写：效应由写入—擦除耦合承载（S1、S2 的反向抵消在同起点就出现，提示这一项） | K 组主导，或 V×K 交互大且 V 单独不足 | K 组两项都低且 V×K 交互小 |
| H-非递推：效应主要走 KV 或卷积 | KV 或 Qc 组主导，V/R/K 合计低 | V/R/K 合计恢复 ≥ 一半 |
| H-分离：停嘴与事实丢失由不同组或不同窗口承载 | 两种行为的载体组不同（S2：停嘴靠 L 段，事实靠 E 段） | 两种行为的载体相同 |
| H-遗留内容直读：撤针后效应主要靠直接读出遗留内容 | 族 P 内容路径格保留大部分 T 效应 | 内容路径格接近 C，而只换写入或只换读取即可恢复 |
| H-起源层：撤针后效应来自首受影响层留下的状态（CPU 分析：该层卷积已一致、递推仍不同） | 层范围格中，只在首组换回即可恢复大部分 | 只在后续层换回恢复更多 |

以上都标为推测档，只有 H-分离有 S2 的直接观察支持（描述档）。每条都可能被反驳；几条同时成立，就作为联合机制报告。

## 8. 这一轮能回答与不能回答的

**能回答的**
- 原干预造成停嘴与事实丢失，是经由写入内容、保留方式、写入—擦除耦合，还是注意力 KV；单独还是联合；可加还是必须组合。对应你列的未解问题 1。
- 撤针后的效应，是直接读出遗留内容，还是经遗留内容改写后续写入或读取条件；来自首受影响层还是更深层。对应问题 2、3。
- 恢复是原路径还是补偿（路径真实性判据加零对照）。对应问题 4。
- 结论直接落在回答终点上，不依赖局部近似。对应问题 5。
- 换一批题是否成立（P2）。对应问题 6 的一部分。

**仍然不能回答的**
- k 内部"写入位置"与"擦除方向"的比例：架构上是同一个向量，本设计把它报告为单一耦合变量，这是结论而不是遗漏。
- 全部是 C/T 混合的反事实，效应是在"把某组固定为 C 值"这一定义下的路径特定效应，不是自然的唯一因果百分比。
- 单层定位、跨模型推广、自由生成里的文本反馈路径，都不在本轮。

## 9. 自审：对照你列出的失败方案与要求

| 你指出的问题 | 本设计怎样处理 |
|---|---|
| 单独交换写入项与处理算子，拆开了共享变量 | 不碰 A/B；k、β 作为一组不拆，耦合作为结论报告 |
| 只换 value 或衰减门，覆盖不全，后续变量混入 | 五组穷尽全部缓存写入（完备性逐位检验）；后续变量的反应用受控直接效应格单独测出，不混在一起 |
| 补偿 value 保持乘积 | 只插入模型原生产生过的值，不构造补偿 |
| 八格加活模型复核，不能排除替换诱发的补偿 | 路径真实性判据、必要性与充分性双向一致、反射零对照、失配诊断 |
| 分账加梯度连接输出 | 不用梯度、不用离线分账，直接测回答 |
| 原针小幅时点微扰，变成局部敏感度 | 全幅原生值替换，终点是原现象（停嘴、事实丢失） |
| "恢复回答"不等于"找到原路径" | 行为恢复必须伴随内部恢复，否则标补偿 |
| 不能凭空构造数学模型 | 分组与完备性直接来自源码；离线局部分析只用来提预测 |
| 区分直接、间接、总作用 | 单组撤除 = 总作用；钉住另两组 = 直接作用；两者之差 = 经另两组的间接作用 |
| 公式闭合、状态差非零不算发现 | 判据全落在回答终点与零对照上；恒等式只作工程验收 |
| 算力节制、先用已有资产 | P0 零 GPU；完备性检验与参照全部复用 S2 的 Mτ 和原生运行；P1 约 1.7 GPU-h |

我自己发现、仍有风险的地方：

1. **反射零对照可能本身离分布太远**，造成很大损伤。若零对照的回答变化接近真实格，相应的充分性结论无法解释，应事先写明这一点，并保留同幅打乱位置作备选零对照。
2. **"全层固定 V"测的是 V 作为最终共同通路的作用，不是 V 作为起因的作用**：上游 K 的变化也可能通过残差改变下游的 v。起因方向只能靠受控直接效应格与层范围格部分回答，不能完全识别。
3. **E 窗口的停嘴效应分母很小**，L0 的停嘴主要只能在 L 窗口检验。
4. 开发面板仍是旧题，P2 才算独立；P2 的情景是模型起草的题，同样需要先做干净审核（沿用阶段二的流程）。

## 10. 借用的工作（本次未重新核对出处，写入正式计划前需要逐条核实）

- 因果中介分析与直接、间接效应的定义：Pearl (2001)；在语言模型上的应用：Vig et al. (2020)。
- 交换介入与因果抽象：Geiger et al.（2021 起）。
- 路径修补：Wang et al. (2022，IOI)、Goldowsky-Dill et al. (2023)。
- Gated DeltaNet 的更新规则（2412.06464）、WriteSAE 的写入—传播—读取框架（2605.12770），以及 transformers 5.20.2 的 Qwen3.5 源码。

我们借用的是"固定中介变量、测路径特定效应"的方法框架。前人没有在混合递推模型的写缓存变量上做过这种完备分组；这一点需要在正式计划前按七步查重核实，目前不作新颖性声明。
