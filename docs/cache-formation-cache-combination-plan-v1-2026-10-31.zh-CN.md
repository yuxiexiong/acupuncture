## 0. 用人话说

上一轮发现：不扎针，只把有针时深层收到的 V 材料送进去，就能产生接近原来的深层分数变化。但是，把一种叫递推状态的记录单独搬过去，常常搬不动多少变化。问题是：效应到底留在了哪种记录里，还是需要几种记录配合才能读出来？

本轮把三种记录——递推状态、短卷积缓冲、注意力 KV——按所有组合交换。材料已经加工完，我们主要复用保存的记录，不重新加工。比较同一批输入、同一根针造成的记录，检验哪些组合在当前读法下足以传递输出变化、哪些必须与其他记录配合。

另有一个单列的补充：给无针运行送入同样大小、方向随机的 V 改变。它问“是不是随便大幅改一下也会这样”。这个补充必须重新形成缓存，不能混称为只做评分。两个随机抽样只能提供有限参照。

## 4. 阶段 A：两对来源的完整组合评分

固定三对 (a,b)：**(C,CT)** 对接无针接收 V_T 的强效应；**(TC,T)** 测"换回干净 V 所消掉的那部分差异"存在哪些缓存组合（"换干净以后还剩什么"对应 C/TC，本轮不另加该对）；**(C,T)（r2 新增）** 是原生扎针形成的深层缓存效应，作为参照，用来检查"V 钉入复现的分数，是否通过相近的缓存组合产生"。仍固定干净浅层，比较的是深层缓存效应，不是完整原生回答机制；组合响应相似会加强 V 与原生效应的连接，但不证明路径相同；不相似说明 CT 不能当 T 的机制替身，CT 的干预证据仍有价值。三对不合并成一个机制百分比。

令 Z_ab(M) 表示：浅层一律 C；M 中的深层组从 b 取，其余从 a 取。M 枚举如下八格：

| M | S 来源 | F 来源 | K 来源 |
|---|---|---|---|
| ∅ | a | a | a |
| S | b | a | a |
| F | a | b | a |
| K | a | a | b |
| SF | b | b | a |
| SK | b | a | b |
| FK | a | b | b |
| SFK | b | b | b |

**去重而不丢方向：** 反向 Z_ba(M)=Z_ab({S,F,K}\M)。相同浅层、相同评分 token、相同完整缓存及管理字段下，两者是同一个计算输入。每对只算八格就能同时报告两个方向。不是每方向再算六格。r2 三对合计每输入 **22 个不同评分**：端点 C、Y_CT、Y_TC、Y_T 共 4 个（C/T 对的两个端点已包含在内），非平凡混合格 6+6+6=18。

端点 ∅/SFK 分别逐位重放上一轮 C/Y_CT、Y_TC/Y_T 的全词表 logits。三类全换等于完整深层移植，是工程恒等核验，不是科学发现。三对共 22 格全部计算，不根据阶段 0 的描述选择。

### 4.1 卷积缓冲的解释纪律

F 保存 V 并不预先决定输出作用大小，更不提供一个可从 D 中直接减去的“V 自动贡献”。卷积核的有限窗口与数值运算决定怎样消费它，其他层/缓存仍可响应。

**r2 槽位说明：** 交换的是完整卷积缓冲（4 个历史槽位全部）；在该单步更新实现下（`causal_conv1d_update`：4 个历史槽拼接当前输入，宽 4 的卷积只取最后一个输出），评分这一步**直接参与计算**的是最近 3 个历史槽加当前输入。具体源码身份在执行中核验。这不等于"只有这三个位置对整个模型有影响"：更早位置的影响仍可能留在递推状态或 KV 中。

本轮先把 F 的 V 段与 q/k 段的来源、逐槽位差、相对于 `v_applied` 的对应关系分别报告，核对实际会被下一步消费的槽位。**这些是张量/源码核对，不是新增切片干预；F 有效时，不能据此分配 q/k 与 V 的因果份额。** 不预设四槽都被使用，也不把 F 大效应称为发现最近材料特别受重视。

若本轮 F 相关效果占优势，留下的具体缺口是“F 中哪一部分、哪个时间范围负责该作用”；本轮不自动追加切片、时间或层扫描。若 F 弱则不为证明近时记忆而另改窗口。

### 4.2 阶段 B：无针背景的随机 V 参照，单列形成成本

为 CT 的方向性主张补两个固定抽样 CR0/CR1。采用与 CT 相同无针 C 背景，在每个 G 层、每个晚段位置，实际 V 钉为 V_C+ξ。ξ 为原 TR 实现同分布的随机单位方向乘 ‖V_T−V_C‖；范数取原实现的整个 value 切片维度，不临时改为逐头。两个种子复用旧 TR 的确定公式 `20261031+1000*k+crc32(input_id)`，k=0,1。**r2 表述：** 每个输入有两个随机抽样，同一输入的有针（TR）与无针（CR）背景共用它们；逐元素一致还须同时核对生成器、调用顺序与形状，执行时以"CR 的 ξ 逐元素等于按旧 TR 算法重算的 ξ"作为工程检查，不只看种子公式。位移为零时 ξ=0。

使用旧冻结 C/T 供体带；仍需 C 的干净前史推进及 CR 的新形成，不能拿 T 中旧 TR 缓存冒充。实际 BF16 加法后的位移范数和方向偏差完整记录，不能把理想同幅等同于机器精确同幅。预检用原 TR 算法重放并检查，若更换随机实现/归一化顺序则须修版。

正式每输入重建 C 一次及 CR0/CR1 两个形成条件，分别评分 C、Y_CR0、Y_CR1；C 完整缓存和输出须与旧 C 逐位一致。预检额外重建 CT 一次、逐位对旧 CT；以此检查冻结供体在无针背景的实际替换。当前不对 CR 再做八格组合，也不生成自由回答。

比较 Y_CT−C 与 Y_CRk−C 的 D、冻结 token 竞争向量、中心化方向距离及赢家身份。随机也引起大 D 变化但方向/词语结构不同，须分别报告；不能把“任何变化”与“同一种效应”混同。两个抽样只支持“相对于这两个抽样”的描述，不建立零分布或显著性，不证明针独有。旧 TR 的弱结果不代替这个参照。

阶段 B 是计划中的独立补充，实施需单独满足形成验收/资源和授权条件；无论阶段 A 阳性或阴性，都不依据 A 挑选随机种子。若只完成 A，仍可报告条件性缓存交换作用，但 CT 超过一般扰动的主张保持未验证。

## 5. 读数、估计对象与可能结果

主读数仍为 D=max(z[两个停止 token])−max(z[非停止 token])。沿用上一轮冻结 token 集，不事后挑成功词；保留每格完整 logits、EOS、两个赢家、熵、最终 r、中心化单位 logits 方向。D/EOS/完整任务正确率互不替代，本轮不测自由回答正确率。

对每对 (a,b)，记 d(M)=D(Z_ab(M))，Δ=d(SFK)−d(∅)。

- 从 a 搬入组 M 的作用：A_M=d(M)−d(∅)。
- 从 b 换回组 M 的削弱：R_M=d(SFK)−d(补集 M)。
- 指定其他组背景 N 下，加入组 i 的作用：d(N∪{i})−d(N)。八格给出全部这些条件差。
- 两组的输出交互：I_ij|N=d(N∪{i,j})−d(N∪{i})−d(N∪{j})+d(N)；分别在第三组来自 a/b 时报告。交互是终点的条件差，不自动是内部协作或自然路径。

所有对比先逐事实，再取情景内两事实均值，保留原值和方向分歧。D 的 max 可制造交互，必须同时对原始 logits 的冻结 token 差计算同一差分；若交互只在 D 明显，报告赢家切换/终点变换，不能命名内部协同。

**r2 完整代数分解：** 浅层固定为 C、只评一步时，S、F、K 覆盖全部深层持久状态，故每对以 a 为基底有恒等式 Δ = Σ_i m_i + Σ_{i<j} I_ij + I_SFK，其中 m_i=d({i})−d(∅)，I_ij=d({i,j})−d({i})−d({j})+d(∅)，I_SFK=d(SFK)−Σ_{i<j}d({i,j})+Σ_i d({i})−d(∅)；以 b 为基底同样分解（等价于反方向）。对 D、各冻结 token 差、固定尺度 D 都报告全部七项并核对恒等式。**这是本实验表的代数分解，不是自然机制分账**：三阶项大也不能区分"三类记录确实需要配合""拼接失配""下游非线性"。

**r2 CT 与 T 的组合图样比较：** 对 (C,CT) 与 (C,T) 两对，逐格报告 (d(M)−d(∅))/Δ 及两对之差、最大绝对差、六个非平凡格的排序是否一致；只作描述，不设"相同/不同"切点。

绝对作用与距目标端点的剩余为主，不设“机制通过”切点。比例 A_M/Δ、R_M/Δ 仅辅助，Δ 绝对值大于数值误差界且 ≥1 logit 才展示，否则标分母不稳定；1 logit 只是预定展示规则，不是科学效应阈值。不按比例给三类缓存分账，不作六情景总体显著性检验。

最终尺度诊断沿用真实 r 和共同 C 分母：z_fix=z*r_X/r_C，离线比较 total/fix/差额。BF16 输出与反事实分开，冻结 token 上的 FP64 误差检查沿用旧实现，配对 2(η_a+η_b) 界内不标方向；全词表 D 另检查其实际赢家是否落在数值验证 token 集中，若出现新赢家，仅为误差核验加入该赢家，不改变科学冻结对比。没有覆盖赢家的误差界不可当全词表 D 的严格界。熵单列有限精度敏感性，不套 token 差的误差界。

| 结果形态 | 新认识与必须保留的边界 |
|---|---|
| 单类在搬入和换回两方向均接近端点差 | 该类缓存在这些背景中具有强条件性传递作用；不证明自然唯一通路。F 强还须保留 §4.1 的输入材料直接存储解释。 |

| D 相近而 token 结构不同 | 只支持停止集合优势相似，不能说同一种输出偏好被搬走。 |
| CR 与 CT 同级 | 不主张 CT 方向超过一般扰动；A 的条件性交换结果仍成立。 |
| CT 明显超过两个 CR 且竞争变化不同 | 增加相对于这两个同幅随机方向的证据；不足以证明针特异或跨针普遍性。 |

## 11. 实质反方检查、修正与最终判定

1. **正反四方向本来就是重复，会浪费预算。** 已按完整缓存来源证明互补格相同，正式由 24 个混合评分改成 12 个，增加明确的 4 个端点重放；CPU manifest 验证等价。C05/C12 重查通过。
2. **F 阳性可能只是搬了尚未消费的 V，并非找到记忆机制。** 已取消“扣除已知贡献”的承诺；按 §4.1 报告切片/槽位与实际消费，不给 V 因果份额。F 的实际输出作用仍是需要测量的增量。C02/C08/C10 重查通过。
3. **单类弱、联合强也可能是失配变小，不能宣布协作。** 明确只说给定来源组合的输出依赖；原始 token 差排除仅 D 的 max 交互，但不排除其他非线性/失配。若所有混合都弱，停止简单模块归因，不把失败包装成成功。C07/C09/C14 通过。
4. **两个随机抽样不足以证明 CT 特异。** 限制主张为两个预定参照；不从旧 TR 迁移，不跑庞大随机分布。A 的问题不依赖针特异性成立。C08/C12/C13 通过。
5. **CT/C 强效应与旧 S 阴性不是同一配对。** 本轮专门在 CT/C 与 T/TC 全组合，纠正外推；旧配对只作阶段 0 描述。C04/C05/C08 通过。
6. **纯评分也要前向与缓存重建，不能叫零 GPU 或免费。** 只本次写作零模型运行；未来 A 216 评分、B 40 前缀/40 评分含验收，耗时待测。资产缺失不自动重建。C11/C12 通过。
7. **只用旧固定 token 的重投影误差不能约束新赢家的 D。** 已加入实际赢家数值验证，科学 token 集不变；熵不套同一误差界。C10/C11 重查通过。
8. **若预期全出现，是否就闭合机制？** 仍可能有混合失配、其他针不同、原生浅层改变读取及后续文字反馈。本轮承诺仅是有源头介入的末态组合约束；不据此宣称完整自然机制。未来是否推广取决于本轮稳定的可失败预测，不自动扩针。
