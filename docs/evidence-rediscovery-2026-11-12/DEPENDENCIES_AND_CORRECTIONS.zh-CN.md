# 证据依赖与口径纠正

2026-11-12。与 [证据卡](EVIDENCE_CARDS.zh-CN.md) 配套。E 编号对应目录账，C 编号对应比较卡。下面区分数据的来源关系与本轮解释，不把不同运行的端点直接拼成唯一自然机制。

## 1. 哪些证据共享什么

| 关系 | 共享或新增对象 | 对独立性与解释的影响 |
|---|---|---|
| E013 → E014/E015 | 扫描点、八题、干净基线；后续增加剂量 | 新操作结果，但不是新任务族确认；从扫描选出的点带有选择历史 |
| E013/E014/E015/E017/E018 → E021/E023/E024 | 18272 条正式回答中的 7632 条被进一步追踪，分批 2152、4560、920 | 轨迹分析是同源深入，不能再算一份独立行为证据；旧停止的 Llama 混合运行另列 |
| E019 → E025及早期机制线 | 针、问题和开发观察被用于后续选择；E025 另有历史确认面板 | 保留当时的确认身份；围绕这些已看结果新提的问题仍是事后探索 |
| E025 → E028 | 已有候选读数／事实变化 | CPU 分析不增加模型样本；低候选敏感性与自由回答低质量是不同读数 |
| 早期状态恢复 → E117 → E118 | WIN-01 桥接旧全窗口结果，WIN-02 使用已见材料、保留针条件与新窗口比较 | 新操作和预先预测仍有信息；不是完全未见数据的外推；天花板格不能充当支持或反证 |
| B2／固定头名单 → FX E073 | 停止相关名单冻结后转向完整交付 | 是可检验的跨终点承诺；失败应结束该名单的既定分支，不自动重筛 |
| LVK、NCC、SPF → DWB → DWR → WSB | 多次使用同六情景、48 输入；供体配对与反事实端点沿用 | 数百配对提高条件测量密度，不创造数百独立场景；HH 与 DWB DO 逐条一致是桥接验收 |
| DWB／DWR → DWC E168 | 新 96 情景、六家族；固定模型与操作，864 接收者扩成很多轨迹 | 有真正的新材料确认价值；不能把 81648 轨迹写成 81648 独立样本或跨模型验证 |
| 幅度分析／NMT → NGC E170 | 用旧幅度线索提出原生背景操作；48 输入仍已见 | NGC 的完整答案阴性直接约束外推；局部预测通过不能替代任务恢复 |
| WSB → CPU pairing | 同 696 差值及其原行为记录的确定性分析 | 增加幅度／方向约束，不增加独立行为证据；哈希不等于张量，无法补出未保存的实际 query |
| WSP v8/v9 → final comparison | 共享评估材料，开发反馈多次可见，空间和约束不完全相同 | 最佳候选是选择后的开发结果；策略间不是随机对照；与 W0 的增益和相对旧补丁的增益分别报告 |
| WSP 140 C 候选＋4 W0 → stable failure／targeting | 144 评估、368640 回答及请求日志 | 稳定失败是对既有开发材料的事后定义；目标覆盖缺口不是未见测试泛化结论 |
| 预检、恢复、冻结、预算、授权目录 → 正式运行 | 工程与治理记录 | 失败预检不算科学阴性；CPU 合成通过不算模型验证；旧授权不能自动延伸到现在 |

这里的箭头表示来源或依赖，不表示中间环节已形成完整因果证明。每次把结果连起来，仍需核对背景、时段、层集合、实际操作和终点；不能仅凭名字都含“write/read”相接。

## 2. 本轮采用的纠正

**R01｜FX：七条宽松正确，零条严格格式正确。** 机器表中固定 45 头四方向 `Y_delivery=0/3/0/4`、`Y_strict=0/0/0/0`。评分源码定义前者为只出现正确的一种编号，允许额外文本或重复；后者必须只输出目标编号。不得把前者当纯“输出了东西”，也不得把后者零写成所有内容都错。先前中途核查时暂称“交付数不能叫正确数”过粗，本轮经评分代码复核后采用上述准确口径。原 P_FIX 判据仍失败，没有改变历史主判定。

**R02｜WIN-02：L2 有六条首停。** 原报告“L2、L3、L5 任何窗口任何任务都不首停”的文句，与机器表 `fact|N_L02_C5251_D-1|W_all|T:first_stop=6,n=48` 冲突。合同“不停”≤2、“停”≥12，六条应为中间不可判。不能用该句推断三根针完全没有停止表现。P5 也须按联合预测看，不能只引用旧自动标签“成立”遗漏停止子条件未兑现。

**R03｜WIN-01：继承原作者已作的窗口、天花板与范围更正。** W_pre 包含模板和记录句；B 块全部 KV 移植不是只换记录位置；L1 的部分跨窗口差异受 T 的原有正确数影响。旧“恢复分工”表只能在这些限定下使用。

**R04｜DWC：D 与 E 的方向不同，不是两个针的 E 互相异号。** 两根针的 E 条件在相关读数上均为负，D 为正；N1210 的 G 区间未达到预设 .25 尺度。保留正向关系与量级失败两件事。

**R05｜WSB：背景身份、字母顺序与净量尺。** H 是受针后恢复指定卷积的混合背景；先接收背景、后差值来源；D_tr=.882 不等于供体命中率 88.2%。HC 的九条自身答案改变不能被接近零的净量尺抹掉。HH 和旧 DWB DO 一致不构成独立再现。

**R06｜WSP：稳定失败审计不能改写原优化任务。** 原流程主要优化平均指标；稳定失败是后续审计对象。六个 v9 构造来源没有覆盖 16 个稳定失败项，不支持“六十轮一直针对它们仍然无解”，也不支持“覆盖后一定有解”。v8/v9 的允许搜索空间不同，不能用单次最佳结果作纯策略归因。

**R07｜NGC：时间与证据等级更新。** 旧设计与撤销队列记录存在，但 11-11 已完成正式运行；当前判断必须用完成报告，不能停留在“仅 CPU 准备”。局部增益预测和原生完整正确数分开。

**R08｜SPF、FBR、NWR：旧解释已被后续限定或更正。** q/k的供体身份不必来自供体，不等于q/k的受针／干净状态无关；两种恢复压住供体作用，不证明两个信息来源；某三层移植足够不证明信息只存三层。FBR的“输入特有”是操作标签，仍有平均失配解释。NWR的共享能量旧估计偏低，后续确认还否证了“额外v分量几乎无效”的猜想。不能只摘原报告开头的强结论，漏掉末尾更正。

**R09｜S1–S3、E2：记账、分差与行为不得混用。** S1的coupled阈值缺少自然对照标定；S2排除严格相等解释的区分力低；S3保留约一半的是停止分差，而相应EOS为0/12；E2深层保留大部分分差也未维持首步停止。这些不使数据无效，但限制标签的解释价值。

**R10｜KVC：按青蒿素原则重评旧查重。** 与已有KV移植同类，不应自动被写成无价值；整缓存成功并不严格蕴含局部切片在指定恢复背景必然成功。本轮保留条件桥接价值，同时承认字段与后续位置未分开，不能独立证明新的形成机制。

## 3. 这些纠正改变什么决策

- 不再用“停止分差已恢复”作为完整任务已恢复的代名词；同时也不否认宽松内容正确的实际七例。
- 不把 KV／递推当按架构永久划分的功能模块，先看形成历史和接收条件。
- 不继续因幅度线索而默认扩展原生增益扫描；NGC 阴性必须改变下一步理由。
- WSB 可支持“实际差值的效果依赖来源与接收运行”，尚不能命名为纯读头机制。
- WSP 的值得解释之处是搜索构造、目标与验收是否对齐，以及空间能力是否足够；不是把未优化的事后指标包装成原系统失约。

纠正以新账形式追加；不改旧原件，不删除失败，不重写冻结预测。新口径在后续问题卡中优先使用。
