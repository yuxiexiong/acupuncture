# 从全量历史材料重新提炼的问题卡

2026-11-12，第一轮。基础是 [171 项目录去向](DIRECTORY_LEDGER.zh-CN.md)、[19 张重要比较证据卡](EVIDENCE_CARDS.zh-CN.md)、[依赖与纠正](DEPENDENCIES_AND_CORRECTIONS.zh-CN.md) 和 [近邻核查](LITERATURE.zh-CN.md)。下面是研究问题与证据缺口，不是既成机制结论、可直接运行的实验合同或论文保证。

本轮建议保留两个彼此有关但不强行合并的机制问题 Q1/Q2，以及一个独立的可靠修补问题 Q5。Q3 作为共同测量问题保留，暂不凭反例集合独立立项。优先级来自现有证据和可获得的认识，不来自“谁最不像别人”。

## Q1｜同一实际写入差值，何时会改变模型的答案选择

### 问题与价值

在一个正常作答的接收运行里，一份来自供体历史的实际写入差值，为什么在某些背景中足以改变答案，在另一些背景中几乎不能？能否用明确的计算关系解释并预测这种可转移性，以及它失败的条件？

这关系到怎样理解稀疏干预：大行为效应到底来自改写了什么、接收计算如何使用它，还是二者结合。若能预测哪种变化真正影响答案，就能减少仅凭向量相似、局部范数或旧成功补丁做无效修复的决策。目标仍覆盖写入、旧状态处理、读取与完整回答；并不把项目缩成某个读头或 EOS。

### 已有支持和最不利证据

1. **最清楚的条件事实是 WSB，而不是唯一机制。** C11 固定每层实际 ΔW 后，CC/CH/HC/HH 的净供体转移约 0/0/.003/.882；各格完整有效编号全部交付，故主要差异不是有无开口。对同一 H 来源差值，换接收背景就改变作用；对同一 H 接收背景，换差值来源也改变作用。
2. **这个现象有连续历史。** C17 的平均缓冲几何上很相似却常不能修好，C14 的状态来源单独充分预测失败；C09/C15 将供体历史作用接到指定写入和同端点后续读取，C09 的 DWC 在新材料上给出支持并保留方向／家族差异。不能把这些当同一批独立复制，但它们逐步排除了不同的粗解释。
3. **最不利证据必须同行。** NWC 的随机对照削弱方向特异性，NGC 没有救回原生完整错误；DWC 第二方向获得量级未达门槛。旧写读链在混合背景成立，不等于原生停答全因该链。SPF 已否证“受针递推来源单独足够”，不能换个名字重新当首选解释。
4. **CPU 几何约束有限。** C11 的范数、余弦和标量残差限制简单统一缩放，却不能凭这些量区分实际读取、竞争 margin 与后续放大。净转移接近零也不代表逐样本没有变化。

### 合理解释及需要区分的观察

| 候选解释，均未证实 | 如果主要是它，应看到的关系 | 什么会削弱它／仍不可判 |
|---|---|---|
| 差值与实际读取方向的对齐不同 | 在同一比较层级，真正进入输出的有效分量，比裸范数更好对应来源选择变化；匹配的差值仍可随接收 query 不同而不同 | 仅有余弦／query范数不够；若局部有效分量相近但答案不同，单独对齐解释不足 |
| 背景的原有选择优势不同，即需跨过的决策余量不同 | 同等有效扰动在弱余量背景较易改变答案；能同时解释不改答和改向其他行的例外 | 仅见正确率天花板不能推出余量；若控制余量后仍有来源特异剩余，阈值解释不足 |
| 差值改变更高层和未来写入，效果由后续演化产生 | 即时局部输出不足以解释最终作用，分歧随层或时步传播后才形成；必须与同一端点连接 | 只看t1/t2哈希不同没有方向与内容；多层操作不能自然拆成可相加份额 |
| 作用是非特异扰动后的默认选项，不是供体相关选择 | 改答集中默认行，控制供体身份后不再有相应关系 | WSB的净供体量尺及SPF非首行供体跟随限制纯固定首行解释；仍需保留混合的默认偏好 |

这些解释可以共同发生，不强迫互斥。线性读出中的 q 与状态差乘积属于公式基础，直接承接，不消耗实验预算重新证明；科学问题是它能否在真实、匹配的条件下预测完整行为。

### 查重后的增量

L01/L03/L04/L12/L13/L15 已覆盖 steering 的计算依据、key／位置区分、来源选择、写入干预与 query 构造。直接借用这些方法。**不能把“背景重要”“递推能影响 query”“存在写读链”作为新总发现。** 可争取的是：把同一实际差值的可转移性连接到一个有预测力的条件关系，解释已出现的成功、失败和异质性。这种增量即使使用全套已有方法，仍可能有用。

### 现有材料能做和不能做的事

- 已能做：固定 ΔW 身份；识别 C/H 真实构造；核对四格完整回答和净供体选择；利用已有 CPU 分析排除某些简单幅度说法；按历史依赖保留开发／新材料身份。
- 当前不能做：从哈希还原 WSB 交叉分支的实际 query、原生状态、t2 margin 或后续传播数值。不能用别的运行的相近张量假装匹配数据，也不能把 DWR/DWC 的用途差当 WSB 四格差异已经被解释。
- 若后续需要新测量，其理由必须是补齐这些具体关系，而非扩大针、模型、层或剂量找更明显的阳性。这里没有规定新臂、运行数或预算，不构成实验授权。

### 放弃或缩小条件

若最后只能重复“混合背景里有相互作用”，没有解释或预测增量，保留为有价值的条件事实，不扩成机制论文。若变化完全由已知的一般竞争余量模型解释，也不必否定研究：可以将贡献改为该解释在实际干预条件中的检验和可用预测，但必须展示其比简单基线多帮助了什么。若关键测量拿不到，当前障碍是不可辨识，不能靠增加修辞补齐。

**当前结论：主候选，证据最连贯；缺关键匹配读取量。优先完成关系定义与资产核对，不默认继续 GPU。**

## Q2｜形成历史何时改变恢复所需的 KV 与递推状态

### 问题与价值

同一个模型、同一项任务中，干预发生在什么历史形成条件下，会决定“只恢复递推”是否足够、是否还要补 KV？这些条件能否解释已有实验和近邻论文看似不同的缓存分工？

回答这个问题可以避免错误的架构功能归因，并帮助判断修复时应该重建哪些历史。它关心已有内容如何形成和在后续使用，不要求重新证明 KV 能存事实或递推能参与检索。

### 证据链与反证

1. C18 早期定位中“主要在递推”的原预测失败，前半段更轻的遗忘预测也失败；中晚层内部读数异常常不对应行为失效。这说明从结构常识直接预测完整损伤并不充分。
2. C06 同任务同针改变形成窗口：L0 全递推在 W_all 只恢复事实10/48、编号6/48，在 W_post 恢复47/48、48/48；同一 W_all 背景补 KV_pre 后恢复到47/48、48/48。
3. C07 在预留条件中，四个有余量的格补 KV 进一步救回11/11、13/13、27/28、38/38；其余天花板不提供同等检验。部分停止预测失败，不能把窗口关系写成全条件规律。
4. C16 显示补入局部 KV 的事实身份能定向改变回答，增加“恢复操作具有答案方向”的约束；但不能区分它只带内容还是同时恢复使用条件。
5. C19 的过程记账与介入说明早期差异可经后续计算继续生成；它不是储存位置到自然因果路径的证明。WIN 的窗口同时改位置数，事实与编号还存在形成路径、校准和生成预算差异。

### 需要区分的解释

| 候选解释 | 有信息的观察 | 现有材料的限制 |
|---|---|---|
| 早段记录及其下游表征受损，需要修复内容相关 KV | 在共同恢复背景中，补入 KV 的事实身份应对应回答选择，且不能完全由一般交付改善解释 | KVC给出相容支持，但字段与后续记录位置一起替换，不能精确定位内容生成阶段 |
| 递推或其他背景决定如何调用仍可用内容 | 相同内容来源在不同恢复背景中作用不同，恢复“调用条件”可改变对既有内容的使用 | 单一失败的移植不证明信息不存在；现有操作同时改变多个可响应计算 |
| 窗口差异主要来自干预量、损伤程度和可救回余量 | 关系应随实际干预位置数或基线余量变化；原有正确数高的格可能只是假天花板 | WIN已有一个明确天花板例，且位置数不等；不能把所有窗口差异都归给语义区段 |
| 两任务的不同来自协议／模型能力而非缓存分工 | 完整对齐后差异缩小，或只在清洁基线不足时出现 | 本轮没有新的对齐运行；不能用原表的跨任务差直接做此归因 |

不要求这些解释互斥；重要的是指出哪一种在什么条件下改变修复需求。只再定位几个层组、但不提高条件判断力，增量有限。

### 查重采用承接而非否定

L02/L13 的分工结果、L03/L15 的 query/key 计算和 L14 的下游缓存内容都可直接作为基础。它们研究的任务、边界和操作不完全相同；不能把差异先包装成矛盾再宣布推翻。KVC 的旧查重降级也不意味着数据无用：它为本项目的条件关系提供桥接，但“也能移植事实”本身不再是中心贡献。

### 可推进范围和退出

现有协议和逐格结果足以建立恢复条件表，纠正窗口含义、天花板、停止阈值及任务不对齐；这一步本轮已完成重要比较核查。现有结果尚不能把内容时段与剂量总量、一般损伤与读取条件完全分开。后续可先对已有逐输入位置数与转移记录核对其解释边界，但新的统计分析需单独固定目标、分母和选择历史；不能临时回归到漂亮关联就称机制。

若所有表面分叉都被评分或协议差异解释，仍应交付可靠的兼容性说明，停止继续寻找缓存分工新故事。若能得到跨条件的修复需求预测，即使承接既有架构解释，也足以保留研究价值；是否独立成稿取决于预测是否有用，不由查重相似度自动决定。

**当前结论：第二主候选，兼容性和适用条件价值明确；内容／位置数／余量尚未分开。不能默认为 Q1 的同一机制。**

## Q5｜搜索提高平均分之后，为何稳定失败仍未被完整修复

### 问题与价值

在 agent 构造权重补丁的流程中，构造依据、反馈目标与最终验收对象是否对齐，怎样影响稳定失败的覆盖和修复？未修好究竟是没真正针对、反馈不足、候选空间不够，还是改善一处会损害别处？

价值是让搜索预算对应实际可靠性需求，避免平均提升被误解成指定失败已经解决。它属于可靠控制／修补线，不强行解释缓存机制。

### 已有事实与不利证据

1. C12 有真实的开发平均提升、修复和改坏数；不能因稳定失败未解决而全盘否认。Qwen v8 B 最佳主指标仍低于旧简单补丁，也不能只挑有利参照。
2. C13 的140候选＋4基线中，没有候选完整修复严格稳定失败源项；但有局部成功。严格顺序与严格模板的分母不同，不能挑某种定义制造更大失败集合。
3. Gemma v9六个方向的构造源项未覆盖16个稳定失败项，诊断接触不等于以原验收提示构造和优化。这个事实提示覆盖缺口，但不证明它造成失败。
4. 已针对的少数锚点仍未修好，反对“只需换目标就成功”的简单解答。v8/v9空间不同、反馈可见历史不同，不能作纯策略因果比较。
5. 诊断数值路径和正式批评估不完全一致，任何机制解释都先受 C12 的工程边界约束。

### 竞争解释与能区分的观察

| 解释 | 需要看到什么，才超出故事 | 什么结果会使其退居次位 |
|---|---|---|
| 目标覆盖缺口 | 同一个失败项在构造、反馈、验收链中的身份可追踪，真正覆盖与名义接触分开；覆盖缺口和未修复有具体联系 | 已被充分覆盖、反馈一致的失败仍普遍无改善，且不是其他约束阻断 |
| 候选表达空间／操作约束不足 | 可针对的对象与允许补丁相容性清楚；不能仅凭没搜到宣布空间里不存在解 | 在相同空间中已有可靠补丁解决同类要求，则不能再泛称表达力不够 |
| 反馈与验收的分布或路径不一致 | 诊断收益不能在冻结正式条件重现，差异能定位到提示、路径或评分 | 在身份完全匹配的条件下仍失败，就需转向其他解释 |
| 修复和其他能力存在真实冲突 | 逐项修复与改坏关系在匹配条件下稳定，不能只看总体净增 | 存在满足同样约束且无相应损害的候选，普遍不可兼得说法被削弱 |

没有把“失败归因给 agent 不够聪明”当解释，也不默认再给更多轮数就会成功。

### 查重与可能贡献

WSP 总路线已有 L08；平均性能和验收要求错位有 L09/L11，开发自适应性有 L10。直接借它们的目标和验证意识。剩余有用问题是本流程的具体断点，以及改进后是否使指定稳定失败真正、可重复地被解决，并保留其他能力。若只是把平均分换成最差组分数，没有新的可靠性收益，贡献有限。另一方面，使用现成目标和现成补丁仍可能解决重要问题，不需为了新颖再造算法。

### 当前可做与不能承诺

本轮已核清140候选、144评估、300主要候选轮次的不同计数身份，以及目标覆盖审计的原结论。现有请求日志和逐项输出可用于后续构造链审计；不得把改过提示的诊断结果当正式修复。现在不能断言改目标即可解决，也没有运行新搜索。若后续进一步离线追踪，需要先固定“完整修复”“稳定”的旧定义与新增定义，并列呈现，避免用事后指标不断移动目标。

若失败集合对微小模板变化不稳定，先缩小“稳定失败”的适用范围；若搜索本来就优化另一目标，交付目标差异而非判系统失约；若匹配目标后仍无可行补丁，允许以可靠失效边界结束，而非无限追加候选。

**当前结论：独立实践候选，现象与过程线索存在，因果归因未成立。暂不与 Q1/Q2 合成一个论文故事。**

## Q3｜代理指标的承诺边界：共同方法问题

从 C02 的候选偏好与自由回答、C18 的阈下内部异常、C19 的停止分差与 EOS、C04 的固定头名单与交付，到 C10 的增益预测与完整答案，反复出现“某个量改善，但目标任务没有按预期改善”。这不是新近才发现的抽象道理，L01/L06/L07已有直接相关基础。

本轮保留的具体问题是：**在这类稀疏干预研究中，哪些读数能承诺哪个终点，在哪些条件下必须拒绝升级解释？** 要同时保留阳性（例如全部V恢复有效）和阴性（固定45头未通过），区分两个本就不同的目标与实际错误承诺。不能因为某指标没有预测它从未承诺预测的完整答案，就说它无效。

目前成果是项目内可执行的证据规则：内部量、首token、宽松交付、严格格式、完整正确、净供体转移分别报告；局部几何不能代替行为；独立材料确认不等于唯一机制。若要独立立项，需要比整理反例更进一步：有明确定义的预测任务、与合理基线比较、能减少错误决策的检验。当前先作为Q1/Q2不可缺少的测量约束，不自动创建新基准或综合分数。

## 暂不推进的方向与原因

| 方向 | 具体原因 | 保留什么 |
|---|---|---|
| 继续扩大随机针／剂量／深度网格 | 目前缺少会被新网格改变的明确判断；已有扫描和负剂量已显示异质性 | 原图谱、反例、选材来源；若未来预测需要，可再讨论所缺条件 |
| 固定45头名单继续重筛 | FX 的冻结出口是结束此分支，事后重筛会回避原失败 | 跨终点预测的失败及全部V阳性 |
| 把原生停答全部归因于一个写入增益 | NGC完整正确阴性，混合修复与原生背景不同 | 幅度是条件因素的证据，不升级为通用修复 |
| 宣称一个专用“选择／安全／道德通道” | 随机对照、其他方向和功能泛化证据不支持该专用身份 | 稀疏干预可产生大效应的真实现象 |
| 把首行偏好单独当新机制 | 默认退化与供体选择需分开，且已有key／位置区分方法 | 并入Q1的替代解释，不丢阴性 |
| 直接以诊断数值近似证明正式路径等价 | 近似局部向量不保证最终贪心输出一致 | 作为数值与工程验收条件 |

## 反方自查与本轮实际改变的判断
