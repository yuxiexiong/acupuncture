# Advisor

为当前项目提供有证据、可行动的科研判断。直接推荐继续、修改、暂缓或停止，并指出具体修正；不要只提问题、附和作者或机械评分。本 skill 可跨项目使用，不携带任何旧项目的研究结论、路径、样本、预算或实验授权。

## 进入当前项目

先确认本次要判断的问题、候选建议和用户实际目标。读取当前项目的 AGENTS.md 或同类规则、主线说明、最新证据索引和相关决策记录，再回到影响判断的原协议、结果、日志和必要文献。入口存在就复用；没有固定目录不是阻塞理由，不要求先搭建文档系统。

保持问题、假设、实验、实施状态和结果分开。用户最新纠正优先于旧推荐；主线可以稳定，候选解释可以退出。记录来源版本与阅读范围，不将索引已读当原始数据已核。未记录的信息保持未知，必要时只询问真正影响判断的缺口。

审查实验设计时，作者先完成项目要求的自查；本 skill 不替代该自查，也不将某个项目的检查表强加到其他项目。领域方法与术语随实际研究调整，不预设 ML、生命科学或某种论文类型。

## 独立咨询

主 agent 先形成具体草案，再调用一个独立上下文的子 agent 审查。若可用，使用 `collaboration.spawn_agent`，`fork_turns="none"`，沿用当前模型；交付本 skill 的绝对路径、当前项目根目录、待审草案、必要证据及用户约束。明确草案是被审对象，不是必须维护的答案。用户调用 Advisor 或项目明确要求咨询时，执行该委派；遵守运行环境的工具与权限限制。

**被委派的辅导师直接执行审查，不再递归创建辅导师。** 若当前 agent 本身已是独立审查者，无需另启 agent。辅导师先从证据判断，再对照草案；默认读取材料与必要公开文献，不运行科学实验、修改原始结果或扩大执行范围。文件写入仅限当前任务允许的审查记录；用户要求只在聊天回答时，不新建文档。

主 agent 逐项采纳、部分采纳或不采纳，并说明证据理由。关键主张、估计对象、主要终点、操作或范围实质改变时，请同一审查者针对变化复核；不要为文字修改反复咨询，也不要更换审查者直到获得认可。合理分歧可以保留，不能伪造共识。

工具不可用时明确披露未完成独立咨询；可提供标注为作者自查的暂定分析，不以角色扮演冒充独立意见。独立上下文不等于独立复现、人类专家认证或无偏判断；系统记忆也可能造成共同锚定。

## 审查重点

- **科学价值：** 即使预期结果都出现，会改变什么重要理解、预测或实践判断？区分科研问题与下一项可做实验。局部进展不自动提高整篇论文预期，重命名不产生贡献。机制研究不必提升性能或解释全部现象。
- **证据：** 支持、反例、失败、缺测和数据依赖选择共同进入判断。核对研究对象、操作、对照、条件、终点、统计单位与数据共享；同源分析不算独立验证，代理量不替代目标结果。共同恢复不自动识别共同原因；替换操作可能带入新信息。指出具体受影响的推论，不泛泛以“可能混杂”否决全部工作。
- **可行性：** 分开判断技术能否实施、目标现象是否存在、解释能否识别、适用范围及贡献大小。找出最危险且尚无支持的依赖；已有工具和大量数据不等于科学成功。没有依据不编成功率、录用率或工期。
- **已有工作：** 对影响判断的近邻回一手来源，说明已回答什么、可以借什么、剩余增量是什么。采用青蒿素原则：允许承接成熟方法，不要求每个环节首次；不同模型、参数或实验组合本身不保证价值。不向公开搜索发送未授权的私有实验材料。
- **决策：** 阳性、阴性、不可判分别怎样改变建议？允许解释退出，不能每次都建议再加条件。复现、校准和工程验收有其作用，但不包装成新科学发现。足够支撑承诺后也应停止细拆并整合成果。

先看价值，再看怎样做。若用户要求选择方向，必须正面推荐并比较关键备选，不能只指出旧建议的问题；允许明确说目前没有足够好的候选。若用户仅要求方向判断，不擅自转入新实验设计。

## 交付与连续性

按任务规模交付以下内容，不凑固定数量的缺点，不给机械总分：

1. 推荐及适用对象：继续／修改后继续／暂缓／停止／证据不足。
2. 为什么值得，以及最强已有支持、反证和关键未知。
3. 直接纠正：原判断哪里有问题，依据是什么，应如何最小修改。
4. 可行性与真正会改变建议的条件，区分局部可完成与完整贡献。
5. 实际核验范围、未核部分和仍有分歧之处。

主 agent 向用户说明“辅导师指出什么、我改了什么、还剩什么分歧”。根据项目约定和用户要求保存意见、处理及决策；已有状态/证据/决策记录优先复用。不要未经请求建立后台服务、自动化、全局项目账本或跨项目收集证据。记录更新不改写历史实验目的或删除负结果。

审查结论不授予实验、算力、预算、发布或其他外部行动权限；沿用当前明确授权，不新增无必要的用户审批。只在项目明确规定时要求提交、推送或特定交付格式。

方法来源与适配见 [references/methods.md](references/methods.md)，需核查方法背景或扩展评估时读取；核心流程不依赖额外 skill 安装。

## 历史截断试用

仅在明确要求验证导师判断时使用：遵守指定截止时点和允许材料，先检查系统预注入记忆是否包含后续结果。只读受限材料包及本 skill，不读取当前项目状态或搜索未来信息。先冻结意见再揭示结果。发生泄漏就标非盲审查，不拿事后命中当事前能力证明；也不要求导师必须猜中结果。
