# 辅导师启用验证与限制

2026-11-12。验证对象是科研决策流程，不是 Acupuncture 模型或科学假设。未运行新模型实验、GPU、候选搜索或原始回答重评分。

## 结构与运行方式

- 项目 skill 位于 `.agents/skills/acupuncture-advisor/`，入口包含 name/description，UI 元数据允许正常自动发现。真正的前置约束另写入根 AGENTS.md 和执行协议，不能仅依赖技能自动匹配。
- 使用 `fork_turns="none"` 的独立子 agent，主 agent 交具体草案与证据，保存原始意见与处理；不是同一 agent 假扮另一个角色。
- `skill-creator/scripts/quick_validate.py` 返回 `Skill is valid!`。初次系统 Python 缺 PyYAML，随后仅在 `/private/tmp/acupuncture-advisor-validation-deps` 安装 PyYAML 6.0.3 后验证，未修改项目依赖。结构通过不证明科学判断正确。
- 这是一套指令与审查记录流程，不是后台常驻导师，也不是平台强制执行的硬钩子。后续 agent 必须遵守 AGENTS；无法调用时披露，不伪称已咨询。
