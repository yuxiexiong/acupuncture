# FX-01 历史截断辅导师意见

审查对象：材料包中的 2026-11-02 实验前 FX-01 v1。身份：独立任务中的 AI 设计意见；不是实验复现、人类专家评议或执行许可。意见仅依据下列三个允许读取文件形成；未执行实验、评分或联网核查。

## 判断：最小澄清后，值得保留这一次有限检验

科学上建议继续准备这份设计，不建议因存在供体信息替代解释就一概否决。已有材料报告全深层卷积恢复能恢复交付，而固定45头只连接过停止侧；检验“冻结的停止侧规则是否也能恢复完整答案”直接检验一条此前未经验证的跨终点连接。FIX、REST、全V及冻结U使成功和失败都有实质含义，不只是再做一遍定位。其价值是裁决这条连接是否值得保留，尚不足以单独支撑“解释了稀疏针如何改写和读取记忆”的论文主张。

这个判断是有条件的：FC、C2和名单的事实目前都是包内作者转述，未独立核验；1 GPU设备小时是否够用也没有实测证据。我建议保留现有矩阵、固定名单、完整回答终点和分母，不追加控制或模型。逻辑准备可以继续；运行仍无授权，不能把这份肯定意见解释成允许预检上卡。

## 必须修正的表述和判读

1. **§1“增量是将停止侧材料规则连接到行为”应改为“检验该规则能否连接到完整交付”。** 原句把待检验的桥接写成已经取得的增量。它尤其危险，因为材料已明确“此前固定名单答案侧并未接通”。同一名单跨背景、跨终点不保证功能迁移，这是本设计最危险的科学依赖，而非工程困难。
2. **把两级结论分开。** 全V成功裁决“V单独恢复是否足够”；FIX成功才裁决“冻结的45头规则是否迁移”。如果全V成功而FIX失败，前一个结果有价值，但不能据此宣布固定规则获得行为解释。反之，FIX成功而全V失败也不是逻辑矛盾：增加恢复分量可以改变下游相互作用。原文没有给这个分支明确出口，应补上“接受非单调结果，保留FIX的条件恢复效应，撤回全V层级递进解释，不把它自动归为工程错误”。这不需要新增实验。
3. **不要将未达整体阈值统一写成“没有接通”。** 5/6情景、3/4方向是实用门槛，不会抹掉部分方向的真实恢复。若未达标，应撤回“整体迁移”主张并停止扩展该名单，同时完整报告局部效应。局部阳性不能触发筛选成功方向后的新一轮追逐，也不应被零效应措辞覆盖。
4. **§3“身份相同而不复现是工程失败”适合作为暂停判读的闸门，尚非故障归因。** 不复现可能来自实现、数值或未完整记录的执行身份；先标“基准重放未通过，本轮科学结论不可判”，定位原因后再命名。不得根据新恢复臂是否符合预测决定重放容差或修改身份。

## 最危险的假设与成功上限

技术上可实施不意味着规则会迁移。包内最不利事实是固定名单的答案侧尚未接通；全卷积成功和V的停止侧变化只能支持尝试，不能提供完整交付阳性的保证。名单冻结排除了本轮按结果重筛，但已见面板及其选择史仍限制外推。

另一个关键限制是同输入正确供体可能把任务信息重新带入受损背景。因此，即使FIX显著恢复完整回答，也只能说明：在这些已见输入、四个方向、指定时点和贪心32-token规则下，一次指定V旧槽位替换及其自然下游反应足以改善正确交付。它不区分“原有信息仍在但读不出”与“供体重建了所需信息”，也不证明原针首先破坏的是这些槽位，更不能给出自然中介比例。

这不使实验失去价值：它能给机制叙事增加真实约束，并使“停止侧名单足以解释行为”的候选连接接受失败风险。但作者必须把这项局部因果操作结果接回总问题时，明确指出写入来源、旧状态处理和后续读取哪些仍未测到。没有必要为消除所有解释缺口而扩建本轮矩阵。

FIX优于所选U，最多说明相对于这一逐输入冻结集合的优势；不能推广成45头选择规则总体优于随机，更不能把“45头”本身当作小扰动证明。这里现有对照足够承担其限定任务，增加随机重复并非本轮必要修改。

## 结果如何改变决定

| 情况 | 保留或撤回的认识 | 行动 |
|---|---|---|
| FIX达标，且优于冻结U | 保留固定规则在所测原生T起点的完整交付迁移；对照优势仅限这个U | 完成来源和完整轨迹报告后转入证据整合，停止继续细拆名单；无自动新实验 |
| FIX与U都成功，或REST也成功 | 保留多个替换集合可分别恢复；撤回FIX特异解释 | 不靠换随机名单、找更差REST或扩大面板追求特异性；结束本轮 |
| 全V达标而FIX未达整体标准 | 保留V恢复连接；撤回固定停止侧规则的整体行为迁移 | 停止固定名单分支，不重筛；部分方向效应如实保留 |
| FIX达标而全V未达标 | 保留非单调的条件恢复结果；全V整体充分性不成立 | 先核验预定来源与重放，若通过就作为科学结果接受；不新增组合扫描 |
| 全V、FIX等均失败，而F重放成功 | 全F效应不能由本轮V单独替换或子集替换重现 | 停止本轮V独立恢复路线；不凭排除法指定Q/K，不自动开启Q/K或SP |
| 基线不足、重放不通过、克隆/映射错误或预算不足 | 对受影响比较不可判；不是规则已被证伪 | 暂停执行、保留失败回执，定位具体闸门；不得调整科学阈值、删臂或自动重跑 |

阴性和阳性都应终结一个明确问题，而不是都成为追加扫描的理由。部分效应与整体阈值未达标可以同时成立。任何后续投入须另有具体认识缺口及有效授权；这份意见不预付下一轮。
