# A002：Acupuncture 原线最值得继续的问题

2026-11-12。已完成辅导师咨询与针对主报告的复核，作者采纳纠正后定稿。用户要求：正面推荐、重要性、可行性和已有支持；不设计新实验。新问题的形成是对已见结果的事后综合，不把旧确认实验改写为针对本问句的预注册验证。见[原始审查及复核](reviews/2026-11-12-02-review.md)、[作者处理](reviews/2026-11-12-02-disposition.md)。

## 推荐什么

**首选：稀疏干预怎样改变模型对历史信息的选择性依赖——什么决定一份历史信息会主导答案、被忽略，或使模型退回默认答案等一般退化？**

这里的“选择性依赖”指来源内容与答案变化之间可被干预检验的关系，不是可加的机制份额，不预设某个语义专用通道，也不预设原生信息完整保存。当前可追溯的证据主要来自 Qwen3.5-4B 的结构化上下文选择任务及明确的反事实状态；不能直接叫一般推理、参数知识、长程规划或真实场景记忆理论。

它延续旧 Q1 与 DWC—WSB 主线，不是凭新标题发现了新方向。重新排序的理由是：在原线候选中，它同时拥有内容定向的答案效应、后续用途的干预证据和新材料预测记录；其他候选在更早的关键环节就缺少支持。推荐继续承担这个问题的科研风险，不等于现稿已经具备强论文贡献。

## 为什么值得回答

稀疏干预造成答案改变，有几种科学含义很不同的可能：干预引入了某种可用内容；改变了模型选择和使用历史的方式；或只是破坏正常作答，使默认输出出现。知道针号、效果大小或能修回来，并不能判断这些情况。

本题要提供的认识，是具体说明**干预怎样改变“历史里的什么被用来作答”及其条件**。有价值的答案应解释一项重要的来源定向关系及其有信息的失败边界，并能约束此前未用于形成解释的材料或条件；一般退化是必须面对的竞争解释，不要求把不同端点所有错误合成统一机制。要求同一个解释承担相关的多个结果，减少为每个条件单独增加故事。

若完成，它对领域的贡献在于让部分稀疏干预从“施加向量后得到某种输出”，推进为可解释的历史信息使用关系；也使干净任务正确率与干预后的信息依赖分开判断。WSB 中两个参照都答对，但对同一外加写入差的响应不同，就是这个目标的具体起点。该差别不是新的普遍定理，也未证明部署风险；它使当前模型中“答得同样对、是否以相同方式抵抗冲突信号”成为可解释的对象。

科学成功不要求发明新模块或新公式。承接已有的查询构造、写入传播和答案竞争解释，只要能说明稀疏干预改变了其中什么、何时有实质答案后果，就可以产生增量。相反，仅说明“背景重要”“状态需要被读取”“非线性产生交互”，不足以成为本题答案。

## 哪些结果真正支持它

| 证据与实际身份 | 已观察到什么 | 对首选问题的支持与限制 |
|---|---|---|
| [DWC 新材料确认](../../experiments/cache-write-read-confirm-v1-2026-11-07/REPORT.zh-CN.md) | 96新情境、固定六结构族。N4146直接读取用途的净获得G=.311、撤回W=.473；冲突配对自身正确比例恢复R=.394。后者95%区间[.374,.414]。同一状态的另一种用途E为负 | 最强科学可行性依据：指定写入的来源作用能够通过后续特定用途改变完整编号答案，关系在未参与开发的新材料上有预测力。R是该供体端点内的比例差，绝非修复39.4%的原生针损伤；81648轨迹不等于81648独立样本 |
| DWC 的方向与材料边界 | N1210的G=.213，95%区间[.192,.234]低于预设.25量级；N4146不同结构族G从.117到.502 | 说明关系不是无条件同强度。边界要求解释，不能挑主方向或把两方向共同称量级确认；也不能因此抹掉第二方向正关系 |
| [WSB 固定实际改动的交叉比较](../../experiments/cache-write-signal-background-v1-2026-11-11/REPORT.zh-CN.md) | C/H自身参照均48/48正确。CC/CH/HC/HH净供体转移为0/0/.003/.882，四格均348/348有效完整编号；同一ΔH在C中不改变答案、在H中显著改变来源跟随 | 接收背景是需要解释的实质因素；不能仅把效力当作写入改动自身的固定属性。H是已修复卷积的混合背景，绝非原生受损T；D_tr不是准确率。HH重放DWB旧端点，新增证据主要在交叉格 |
| [WSB已有CPU诊断](../../experiments/cache-write-signal-background-v1-2026-11-11/analysis/cpu-pairing-r01/REPORT.zh-CN.md) | H/C整包范数比中位.964；固定参考query的局部读出总量没有HH独强；227条HH变答都在第2个生成token首次可见分叉 | 限制“整包更大”和所测参考读出总量解释；不能宣布排除所有幅度因素，更不能据此指定query、margin或某层为真实原因。缺匹配交叉轨迹的真实状态、query及候选分数 |
| [NWC 非特异性反例](../../experiments/cache-native-write-confirm-v1-2026-11-05/REPORT.zh-CN.md) | 同范数随机读取补丁经常造成大量错答，多数退回首列；专用方向的预测失败 | 迫使问题区别内容定向作用与一般退化。随机读取补丁不是随机原始施针；不能拿它直接证明跨针共同致错原因 |
| [NGC 原生阴性](../../experiments/cache-native-gain-v1-2026-11-08/REPORT.zh-CN.md) | 四方向的固定增益配置调整均没有救回此前错误的自然完整答案；反向干净条件仍全对 | 降低“可预测内部增益足以解释原生损伤”的可信度。它不是首选机制的正证据，只是明确的反证边界；不能因此推定另一个解释已经成立 |

DWC 与 WSB 有研究关联，但操作并不相同：DWC含指定写入k去偏移并检验t2用途；WSB固定实际写入差跨背景重放且不添加该去偏移。两者不能相加成自然路径解释率，DWC的新材料确认不能借给WSB的新关系。

更早的随机针与剂量扫描、同文本重建、FX、WIN结果提供选材和约束，不是本轮首选问题的独立确认。它们提示稀疏入口的效应复杂、修复需求依赖形成历史；早期扫描本身不能证明新机制。已复读[全量重审证据卡C01–C11](../evidence-rediscovery-2026-11-12/EVIDENCE_CARDS.zh-CN.md)，避免只以最新WSB大效应决定方向；本轮未重评分这些早期原始回答。

## 与已有工作的实质关系

本轮回原文核对近邻，采用青蒿素原则：继承有效解释，判断剩余认识，既不追求所有环节首次，也不以实验组合不同冒充贡献。

- [Who Asks, Who Answers](https://arxiv.org/html/2611.01909) 已将递推状态、查询构造和定向检索联系起来。若我们只找到“query变了、答案随供体”，重合很大。尚待本项目回答的是稀疏扰动形成的计算背景为什么改变一项具体历史写入的作用，以及该解释能否跨有作用/无作用条件成立。它也可能主要由这项已知机制解释；届时应承接并判断新增边界是否足够重要，不能宣布新查询机制。
- [How Linear Attention Remembers](https://arxiv.org/html/2609.33093) 已研究内容写入、保留、读取和共享记忆的耦合。我们的潜在增量不能只是又画出写读链，而应落在受干预后的信息使用变化及其可预测条件。
- [When Does Activation Steering Change What a Model Computes From?](https://arxiv.org/html/2606.29522) 已区分输出偏置与后续计算实际使用的状态；本项目不能占有这个概念。可承接其证据要求，解释我们预训练混合模型中指定历史写入及背景效应，而非只证明干预有效。
- [WriteSAE](https://arxiv.org/html/2605.12770v4) 已有写入替换与传播到输出的分析。我们没有提出新的写入操作范式；若能在当前干预情形形成更有用的解释或边界，价值来自这些结论，不来自“也能替换写入”。

因此，**问题重要性有根据，具体贡献仍待形成；本轮没有得到独占新颖性认证。** 完整自然回答是本项目的重要证据标准，但换成这个终点本身不保证强论文。详细阅读范围见文末。

## 做出来的可能性

不给没有校准依据的成功率。把所承诺的成果分开判断，以下是研究取舍，不是统计估计：

| 所承诺的成果 | 当前判断与依据 |
|---|---|
| 建立指定条件下历史写入影响答案的真实关系 | 已有相当一部分完成，DWC不只是一条前兆；但范围有限 |
| 找到一种能解释关键条件差异、对新条件有预测力的部分计算机制 | 具有现实可行性，值得列为原线第一优先；风险仍显著。已有可重放操作、内容定向终点与材料外预测，主要风险是解释可能只剩普通脆弱性、答案余量或补丁与混合背景的相容性 |
| 把上述机制连回原始施针，并解释一类实质回答改变 | 尚未闭合。这是Acupuncture机制贡献的重要风险，不能用后续反事实链代替稀疏入口的解释；也不要求解释全部原生停止 |
| 形成完整且有分量的机制论文 | 有条件的希望，当前不能高把握。决定性门槛是解释与预测增量及适用范围，不是再多一张阳性表；现稿状态不因此自动升级 |
| 跨模型通用故障理论、所有原生错误的恢复方法 | 现有证据不足，不作为当前承诺 |

最危险的不是接口做不出来，而是结果正确却科学上不够集中：多种普通机制可能仍解释同一张交互表。仅“接近决策边界更易翻转”是已知事实；即使采用答案余量解释，也须具体说明稀疏干预怎样改变内容竞争、纠正对内容控制的误判并给出有用边界，不能有预测就自动升格。若最终只能得到“不同背景有不同敏感度”，或全部可由常规强扰动退化概括且没有有用的预测边界，这条优先推荐应撤回，不能再换成更小的定位问题无限续命。

## 为什么排在其他原线问题之前

| 候选问题 | 正面价值 | 目前不作为首选的决定性原因 |
|---|---|---|
| 原生错误究竟来自信息丢失还是调用失败，能否恢复 | 高，直接关系模型失败的性质 | 需要证明原生信息的可用性与自身恢复；供体可重新带入信息，原生增益修复为阴性。比首选多承诺了尚无支撑的一环，且丢失/调用不一定互斥 |
| 不同针是否造成共同计算失效 | 潜在解释范围更广 | 共有恢复操作不识别共有原始原因；当前没有具体共同候选能承受已有分叉。保留远期问题，不优先押注 |
| 怎样实现稳定行为控制且保护能力 | 实践价值清楚 | 原线有控制与损伤图谱，但尚无足够的可泛化保护关系。把机制资产直接当实用控制算法可行性会跨越证据；WSP也不恢复推荐 |
| 形成窗口怎样决定KV/递推分工 | 有可靠性和架构解释价值 | 窗口与位置数、基线余量等相伴，且分工已有近邻；尚未显示比首选更直接的认识增量 |

这不是认为其他问题不重要，而是首选在当前资产下离一个可承担检验的科学解释更近。若关键解释风险无法收敛，排序允许改变；不能仅因已经投入很多而保留它。
