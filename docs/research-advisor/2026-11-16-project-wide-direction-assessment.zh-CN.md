# A029：Acupuncture 整个课题的下一阶段判断

日期：2026-11-16。对象是整个课题，不只是最近 H/C 支线。作者：Codex；独立上下文 Advisor：沿用本轮同一审查者。来源基线 `8075c9c4ba0768228ff61c0e587da81eb93efe2d`。本轮只有证据复读、定向一手文献核查和方向判断，没有新统计、实验设计、模型或 GPU 运行。

## 1. 正面回答

**整个 Acupuncture 仍有值得继续的核心问题。下一阶段方向正面选择：稀疏干预的形成历史，怎样改变任务信息的后续利用与恢复需求。** 不再让最近H/C门梯度的局部问题决定整个项目走向。这个选择有项目实证支持，但尚不足以承诺新一轮大投入，也不等于当前已有可推荐执行的具体方案。

最应保留的问题是：**在可见文字相同的条件下，稀疏干预形成的内部历史，为什么会改变任务所需信息的后续利用和完整回答？什么计算关系能解释这种改变的方向、强弱及边界？** 这里不预设信息仍然完整存在，不把所有针归于一个共同故障，也不把撤针作为最终目的。

它比“为什么 H 换 C 门有效”更接近整个机制课题，有早期撤针/重建分离、WIN预留条件的恢复关系、后来的历史用途证据支持。值得争取的认识是：把针×形成历史×任务的恢复分叉组织成有解释力的计算关系，而不只是报告状态可修复。目前最具体的计算结果还不能解释最初自然现象；继续拆H/C不会自动补上这一点。但不能反过来要求先有现成机制，才允许选择这个研究方向。

原课题另一条独立主线——稳定改变指定行为、限制非目标代价——仍有实践价值。本轮单独审查了它；没有因为机制支线收束就连带否定它，也没有把未证实的方法改善写成已具备的突破口。

## 2. 上轮范围错误与本轮覆盖

A028比较的是继续 H/C 细拆、旧 WUS 范围挑战和该链收束，**不足以回答整个项目下一步**。本轮不拿 A028 的结论当全项目停止依据。覆盖如下：

| 原始承诺或证据线 | 已有实质结果 | 对全项目判断的限制 |
|---|---|---|
| 少数通道能否明显改变模型 | 四模型位置/剂量调查；固定双针能力评测；正负方向与剂量非单调的具体反例 | 少数坐标不等于小有效扰动；大变化并非语义特异控制或新机制 |
| 行为变化与任务代价能否分开 | 联合测量有正确事实配异常附语、正常语气配关系错误、未交付等分离 | 未建立稳定目标效果—代价优势；随机针也会退化 |
| 是否能转移特定功能 | 4B→2B/9B 映射及随机流程均有损伤 | 损伤可转移不等于功能可转移；不能据此立功能模块迁移主张 |
| 针效应如何维持 | N5063撤针/同文字干净重建分离；其他点有撤针即恢复、重建无效或反向情况 | 内部历史与生成文字的作用需分开；不能给全部针统一维持方式 |
| 历史形成、写入、用途到答案 | FX/WIN、DWB/DWR/DWC、WSB/RCS/NGU有实际恢复和用途关系 | 共同修复不是共同病因；供体移植/混合状态不是原生路径份额；强、弱、失败结果均保留 |
| 固定结构、系数与数值假设 | A015–A016已比较动力学、归一化几何、压缩；RCS裁决了具体用途竞争 | 不能只因可改一个系数就立项；改后系统行为不自动解释原针机制 |
| 稳定控制及方法迁移 | 独立稳定控制立项和已有问题证据；WSP有历史筛查与修补记录 | WSP按用户纠正不再推荐；稳定控制线本身仍单独判断，不能偷换成WSP续做 |

这里的全项目覆盖复用原171目录账、两轮证据审计及后续A015–A028，不意味着本轮重读所有原始回答或重算所有证据。

## 3. 六个核心问题的竞争，而非六个下一步实验

### P1：定向控制与一般计算损伤，能否有可解释的分界？

价值：能改变对“少数神经元控制某行为”的解释，也能避免把流畅但错答当成成功控制。最强支持是联合行为—能力证据与Llama剂量反例；最强限制是随机通道也损伤、原配方没有认证的跨输入低代价区间，且未给出一个既定目标行为的稳定控制量。

直接近邻不是空白：[Leverage Is Not Reach](https://arxiv.org/html/2606.19831)已研究剂量校准、控制窗口、塌陷与行为时程；[Sparse Neuron Ablation](https://arxiv.org/html/2512.00918)已展示少量消融引起严重退化。后者操作不同，不代表解释了我们的加法干预。我们的非单调个例也不自动推翻前者在指定控制器和任务下的规律。

剩余增量可以是现有窗口/损伤解释之外一个具体且可复用的分界关系，**目前尚未从项目结果提炼出来**。不推荐把“再看更多非单调曲线”作为主线；没有要求先证明新关系为真。

### P2：同文字下，针形成的内部历史怎样改变后续信息利用？

这是本轮最应保留的项目级核心问题。N5063确认材料中，k=4有18/20、k=16有9/9只在干净重建同一可见历史后恢复，简单撤针不足；别的层/点有不同恢复方式。这提供了比单次输出异常更清楚的研究起点。[原报告与后续更正](../../experiments/early-input-control-v1-2026-10-29/REPORT.zh-CN.md)。

Leverage §7.3把其语言路由持续性归于生成文字动量；该结论没有解释本项目的同文字重建分离。反过来，我们的分离也不推翻它，更不能只以“缓存有影响”作为新贡献：撤针不回滚缓存是实现事实；[Aborted but Not Forgotten](https://arxiv.org/abs/2608.15939)与[Tail Replay](https://arxiv.org/abs/2608.30310)也是必须承接的历史状态近邻，本轮对这两项继承旧审计，不冒称重新全文核查。

另外，[WIN-02](../../experiments/window-prediction-win02-v1-2026-11-04/REPORT.zh-CN.md)不是只有事后“共同修复”描述：它在预留条件检验“全前缀干预下，递推恢复仍不足时，补模板/记录位置KV可进一步救回”的关系。在四个可正向检验格，分别救回11/11、13/13、27/28、38/38。必须同时保留：面板已见、其中两格来自同一随机方向、四格天花板、窗口还改变累计干预位置数；早段KV更有效的预测没有在原生事实针上获得支持，停止图样联合预测也未全部兑现。

因此项目已经有一个有限的条件性关系及真实分叉，不是只有重要但空泛的问题。剩余认识增量是解释**为什么某种形成历史下，只恢复一类状态不够，而另外条件足够；这个差别与任务信息的实际利用有什么关系**。不要求唯一自然机制，也不预设递推/KV固定分工。

现有计算切入口在P6；**P2与P6尚未组成同条件的原生解释链**。N5063的同文字分离、WIN的窗口恢复需求、DWC/WSB的反事实供体用途，是三组不同操作下的约束，不能把后两者接成N5063的原生原因。当前选择的是跨这些证据提出的研究问题，没有宣称已贯通同一现象。这限制已获结论和投入强度，不取消方向的正面推荐。当前不推荐任何旧方案自动执行。

### P3：不同针是否通过可复用的共同原因致错？

价值在于跨针预测，而不只是解释某一次修复。FX全部卷积V恢复48/48严格回答，固定45头严格0/48；WIN某些有余量条件补KV可恢复。与此同时，WIN有针×任务分叉，固定名单失败，NWC特异性预测失败，NGC指定策略四方向均没有救回原来错误的完整答案。

这些结果使共同原因成为合理假设，但**共同修复可能覆盖不同损伤，并不能把它排为首要投入方向**。P3从作者初稿与P2/P6并列，改为较弱候选。若未来有能组织这些分叉的计算关系才改变判断；“再增加几根针也能修复”本身不够。这里没有否定所有增益解释，也没有要求一套原因统一所有模型。

### P4：怎样实现可靠、低代价的稀疏行为控制？

这是独立实践问题，允许直接使用成熟选点/优化工具，不要求新理论。[原稳定控制立项](../stable-control-proposal-2026-10-30.zh-CN.md)与3720自由回答的联合测量证明有现实问题，但尚未指定有确认依据的目标—代价改善关系。

[DSI](https://arxiv.org/html/2607.07128v2)已研究跨层稀疏干预与非线性交互，并覆盖短任务及开放概念控制；[COAST](https://arxiv.org/html/2605.01167v1)已针对非目标几何代价改善控制—性能折中。它们不是所有任务的完美解，也不因干预位置与本项目不同就自动留下贡献。

**没有先赢强基线不构成立项否决；真正缺的是项目特有、值得解决的未满足需求和一个有根据的改善切入口。** 现有证据仍主要证明手选配方会损伤。把DSI适配到本模型可有复现/工程价值，但目前不能承诺它将产生新的核心科研贡献。因此暂不推荐将整个项目转成控制算法开发；不把WSP重新包装后恢复。

### P5：稀疏功能能否跨模型迁移？

实践与机制价值都可能很高，但当前可确认的是固定能力面板的损伤迁移，随机源流程也损伤。[迁移原报告](../../experiments/transfer-toy-v1-2026-10-26/RESULTS.zh-CN.md)还明确区分几何映射、实际剂量和主行为终点。没有证实原功能模块被搬运，也没有证实损伤普遍率。

这比P2缺少更关键的项目正向依据。当前不推荐；把规模从4B扩至9B不是功能迁移机制的替代证据。若未来有明确功能保持而非仅能力下降的证据，判断才可能改变。

### P6：针后背景为何改变同一历史写入的用途？

这是现有数据最强的计算切入口。DWC有新情境确认且保留第二方向量级不足；RCS分子用途有完整回答证据，连续用途差排除了规定的“同位移、只有起始余量不同”解释；NGU识别了H方向的条件门用途。梯度解释局部换门响应，不自动解释原用途差。

[A026主干](../cache-mechanism-main-argument-2026-11-16.zh-CN.md)和[A027近邻比较](2026-11-16-contribution-and-gap-assessment.zh-CN.md)保留其真实认识增量。其局限不是“还没找到唯一机制”，而是特定混合状态、供体增量及已见面板的用途关系，还没形成解释更广原针现象的具体关系。近邻已有来源写读、组件交互与状态依赖干预，不能把这些一般性质再作为中心发现。

P6可以成为P2的工具与证据，但目前还不能借P2的重要性替每一项H/C细拆背书。现有案例应保留；不以追加局部链条长度作为投入理由。

## 4. 下一阶段走向与投入判断

不是因为前人相关工作多，也不是因为原目标没有全部完成。已有方法完全可以支撑新的发现；重要部分机制也足以有价值。本轮未采用“全机制闭合”“跨所有模型统一”“先证明效果再允许研究”等门槛。

**方向层面：修改后继续P2，P6作为已有计算证据和工具；P1/P4保留但暂不转入，P3/P5不优先。** 选择P2的依据是已确认的同文字重建分离，以及WIN有限的预留条件预测和分叉；不是“问题还没解决”四个字。它有机会把已有观察推进为有关形成历史与信息用途的解释，哪怕最终只在有意义的有限条件成立，也可以有价值。

**执行与资源层面：暂不推荐大规模投入，也没有本轮可推荐执行的具体科学方案。** 当前计算候选主要针对构造条件的局部响应；它们怎样裁决原始恢复分叉仍未建立。技术上已有撤针、状态替换、来源控制及完整回答读数，但这些不能保证计算解释可识别。该缺口是下一阶段研究要面对的问题，不是要求先解决才能立题。

真正会改变推荐的是：能否由某项关系解释有支持也有失败的恢复条件，并区别于已知内容补入、一般损伤、文字延续或操作补偿。若所有结果仍只能靠逐条件替换重述，或只是近邻已解释关系的另一实例，这条方向可以退出；不会以不断增加层、针、模型维持推进。本轮仅给问题与价值边界，不设计判据、干预或采集矩阵。

若只为完成一个受限案例报告，现有材料可以支持诚实的整合；这不同于认定已具备强论文中心贡献。A026/A027已经完成整合和贡献定位，本轮不再布置一轮无限“继续整理/继续找题”。

本建议不关闭课题、删除资产、停止其他已授权作业或重启任何旧方案。当前没有实验排程，没有默认后备方向，也没有先做P2不行就转P4的队列。下一笔具体投入需要说明如何推进上述关系或解决明确未满足需求，不需要先证实阳性，更不需要保证论文录用。

## 5. Advisor纠正与作者处理

审查原件：[A029独立意见](reviews/2026-11-16-29-review.md)。独立上下文不等于独立复现或人类专家认证。

1. **范围错误：采纳。** A028只回答局部去留，本轮重新覆盖两条原主线、早期调查/迁移和中间负结果。
2. **P2的正向锚点：采纳。** 同文字下的撤针/重建分离应单独保留，不能被“文字动量已有研究”一并消掉；但也不能把它直接称为新计算规律。
3. **P3排序：采纳。** 作者初稿把P2/P3/P6笼统并列为最强家族；修改为P2是项目问题、P6是计算切入口、P3共同病因依据较弱。
4. **稳定控制独立判断：采纳。** 未取得强基线优势不是拒绝研究的充分理由；需要明确缺少的是值得解决的具体需求和有依据的改善关系。
