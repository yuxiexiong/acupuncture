## 1. 本轮最有价值的第一步

优先做现成 JSON 的连续用途桥接。A019 的关键缺口是：大 `delta_e` 属于 11−U，而分子用途证据属于 10−00/11−01；二者尚未在同一连续终点上对齐。现有四臂 logits 足以回答“更大的总响应，是否也出现在指定分子用途的连续条件效应中”，无需新前向。

修订后的两个恒等式正确：

`δe = δC1 + δS0 + δR = δC0 + δS1 + δR`，其中 `R=L00−LU`。

它们提供的是已有端点关系的分账，而不是两个自然路径的因果份额。若两个分子连续对比的背景差都明显，而 δR 较小，会把背景响应差更具体地连接到本次当步用途操作；若主要留在 δR，则不能继续默认整个总响应差都在该分子用途段。两条顺序若给出不同侧重，应保留端点依赖与交互，不挑有利顺序。

R 不能叫已定位的“t1 早期效应”或“其他通路贡献”：00 自己也有改后高层与自然续写响应。修订已删除这种越界命名。没有新增区间或通过标签，所谓较大/较小须通过原始量级、配对与六场景展示来描述，不另造显著性。

## 2. 局部诊断能提供哪些具体区分

### 净读取与更新项

原生 C11/H11 的实际 J、q/k、log_decay/alpha/beta 与 raw0/raw1 足以复算指定 J 的当前净读数。采用正的待减项定义时：

`D=αJᵀq`，`E=αβ(kᵀq)Jᵀk`，`d_raw=D−E`。

同时看 D/E 幅度、有符号内积、夹角及净比，可以区分“直接读取已不同”和“相近读取遭遇不同更新项抵消/增强/转向”这类具体局部模式。只看 q·k、E 大小或一个抵消比不够；`||D−E||²=||D||²+||E||²−2D·E` 是必要分账约束，不是研究发现。

E 是指定 J 的更新项投影到当前读数的影响；小 E 不等于整状态擦除少或历史保留多。实际 J_C/J_H 的差单列，避免把不同实际输入误当纯查询差。q/k 的复算必须沿冻结 FP32 l2norm/epsilon/缩放顺序，再按既有 oracle 的精度定义进入条件代数。通过数值校验仅说明复算对象一致。

### 基底尺度与门转换

真实 d 经过各背景自身 r、γ、SiLU(z) 后的范数比只能叫“该 d 上的有效局部增益”。γ 跨背景固定，其阶段比也可以因 d 方向变；门后比同样混合门变化与输入向量对门的对齐。初稿若直接叫“门放大”会过强。

修订已加入最小的共同向量比较：以 d_C、d_H 分别固定参照，在其自身 r 下比较两背景 gate 算子；另在自身 gate 下比较两背景 r，r0/r1 分开。这能进一步辨别局部算子变化与输入向量方向的适配，不必加载模型或增加回答矩阵。若两种参照给出相反结论，就应报告向量—算子配合，不能挑一个参照宣布“普遍增益”。

这些比较仍止于该层头输出的局部函数。它们不是一次新模型交换的行为结果；原生 11 的高层驱动本身已受上游影响，也不能按某层幅度最大就宣布那里是最初原因。FP64 代数项、实际 dtype 的端点有限差与舍入残差分开是正确要求。

## 3. 采纳的关键修订

| 初审纠正 | 当前处理 |
|---|---|
| 不把总 e 与分子用途缝成自然中介链 | 明列两条端点恒等式，R 保持中性操作身份，不报贡献百分比 |
| 168 任务读数与 348 局部均值不能偷换样本 | 局部诊断同时给固定 168 冲突对、同一接收者等权摘要；348 全表另报，无效应筛选 |
| E 可能抵消、增强或转向；不等于全状态遗忘 | 保存有符号内积、E/D 与方向，并限定为 J 的当前读出更新项 |
| 阶段范数比混合算子与向量变化 | 改称有效增益，并加入两个固定 d 参照的局部 gate/r 比较 |
| 不能在 128 MiB 输出内重存 D/E/J 大向量 | 向量只在逐对内存计算，落盘 4872 条逐层逐对标量与来源 SHA，预计小于 20 MiB；原始大张量保持原位置 |

单个全量 FP64 派生读数向量字段本可超过 300 MiB，所以最后一项是实际预算修复，不是装饰性上限。当前标量方案没有这一缺口。SHA 校验与一次 tensor load 的 I/O 都须计入实际 CPU 进程时长，不能把“每文件一次载入”当作哈希不消耗读取成本。

## 4. 允许的结论与真正的剩余缺测

该卡可以更新具体原因的支持程度，例如“差异在原始净读数阶段已经可见”“当前 J 的更新项改变了读取后果”“共同向量在两背景局部尺度/门算子下有不同输出”。它们比泛称背景重要更具体，也允许出现负面约束。

但局部范数更大、方向不同或算子增益较强，都不能单独解释 D−Y 变化。没有 W_o 矩阵不是唯一缺口；即使得到残差投影，也仍不自动获得其到任务终点的条件影响。若局部量不符合简单幅度故事，不可用排除法宣布下游放大。先完成本轮已有读数，结果不收敛时允许保留不可判并结束。

若数据集中支持一个具体局部关系，最小待辨别的因果问题才会变成：**改变该关系对指定 J 的净读数/局部转换，是否改变同一任务对比的背景响应差，而非仅改变局部幅度。** 现在不预选系数、不展开矩阵。尤其净读取系数为 `α[q−βk(kᵀq)]`，旧 BRC 只换 D 的 αq，不能因名字相近就自动恢复其未运行计划。
