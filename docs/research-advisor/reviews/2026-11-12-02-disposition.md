# A002 作者处理：正面推荐及风险承担

## 决定

首选“稀疏干预怎样改变模型对历史信息的选择性依赖”。明确是原线优先问题，不是全新题目、不代表强论文已经成立。DWC提供最强科学可行性证据，WSB提供条件约束；共同原生病因与原生通用恢复仍不列优先。WSP不恢复推荐，无新实验设计或运行。

## 逐项采纳

| 意见 | 处理与变化 |
|---|---|
| 供体本是受控加入内容，不能推原生正确历史被错误利用 | 采纳；删除原送审稿“正确使用转为错误利用”，不预设原生信息完整保留 |
| 因果权重可能暗示可加份额 | 采纳；使用“选择性依赖”并定义为指定条件下内容改变答案的关系 |
| 不能把新标题当新科研问题，把WSB变成无限续集 | 采纳；报告正面承认继承旧Q1，DWC是最强正证据，WSB关系尚无计算解释；陈述具体剩余贡献 |
| 部分机制与强论文/统一理论应分开评价可行性 | 采纳；保留“现实可行、原线第一优先”的有条件判断，不报告成功率；针入口连接和解释集中性列为实质风险 |
| 近邻已有query、定向检索、写读和实际用途 | 采纳；允许承接，剩余承诺是解释干预造成的内容依赖条件变化，不能仅重现普通关系就称创新 |
| “无方向退化”不准确，NWC通常偏首列 | 采纳第二次复核；改成“退回默认答案等一般退化” |
| 同时解释内容、无效和所有退化可能又强迫统一不同端点 | 采纳第二次复核；要求解释重要定向关系及有信息的边界，一般退化作为竞争解释，不统一所有失败 |
| 普通margin也不能只因有预测就自动算重要贡献 | 采纳第二次复核；必须改变对实际内容竞争的解释或控制判断，并有有用边界；仅接近边界易翻转不够 |

本轮无实质分歧被隐藏。主agent与辅导师一致选择同一问题，但这种一致不是独立科学验证。辅导师没有证明方向一定成功，作者承担推荐及表述责任。

原始意见未改写；第二次复核单独追加§8。最后三处修改直接落实复核意见，无新操作、终点、资源或研究主张，无需为相同内容第三次咨询。对照早期证据卡及五项一手近邻的实际范围均已披露，不声称全量重算或穷尽查重。
