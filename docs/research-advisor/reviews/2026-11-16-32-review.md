# A032｜具体待补连接的比较与首选

2026-11-16。同一独立上下文 Advisor，沿用全局 advisor skill，不递归委派。来源基点由作者指定为 `253171bcc1dd907f61ffa8d53b22d12a86dc7324`。只作具体连接选择，不设计操作、样本、判据或预算，不运行或重算。

## 1. 明确首选

**本轮选择 C：WSB 中，来源写入经过实际净读取后，是否已经产生能解释完整四格来源选择差异的任务方向关系，还是必须依赖额外的背景相关后续转换才能解释。** 其中尚未被近期结果承接的关键对照是：同一 H 接收 ΔC 也弱。

这里选择的是一个有明确对象的待判连接，不是宣布“净读取匹配已是最可能的正确机制”。具体两端是保存的来源写入与 WSB 四格完整来源选择；中间锁定 t2 对实际加入状态增量的净读取及其后任务映射。与仅研究 HH/CH 相比，**HC 是必要的行为解释约束：H 并非对任意这类写入都产生强来源选择。** 但 HC 弱不单独排除“共同 H 增益＋两来源原本不同的任务投影＋行为阈值”；不能据此预先定位来源选择性在哪里产生。

推荐力度是：**它是当前这些候选中最值得优先论证的具体连接；足以选为首选，尚不足以推荐一份执行方案或承诺强中心贡献。** 不要求先有阳性才允许选它，但也不能把这份选择当净读取机制获得了新的支持。

## 2. 两端已有证据，中间究竟缺什么

**来源端已确定。** WSB 对两份实际保存的写入改动进行跨背景重放，原四格均交付有效编号、自然首 token 一致。CPU 原件显示 H/C 整包范数比中位数 .964，合并余弦 .888，最佳单标量后的相对几何残差 .461。这限制“只是同方向更大”的整体描述，却没有证明哪一分量携带供体语义，也没有证明几何残差导致行为差。[WSB CPU 原报告](../../../experiments/cache-write-signal-background-v1-2026-11-11/analysis/cpu-pairing-r01/REPORT.zh-CN.md)

**行为端已确定。** CC/CH/HC/HH 净来源分数约 0/0/.003/.882；RCS/A020 已在 ΔH 列把指定新增分子用途连到完整答案，并确认同用途的连续任务作用 C/H 为 .481/5.911。NGU 对该用途的门操作只解释部分条件作用，TGA 则校准了另一对象——换门响应。这些结果使 C 有明确的行为承接点，而不是从一张张量图猜题。

**四格行为排序不等于四格连续任务响应已有相同排序。** 现有连续用途差及“同位移、只因起始余量不同”的排除只针对 ΔH 列，不能移借给 ΔC。尤其不能把“HC 的 D_tr 小”直接说成“HC 净读取或任务位移小”。A020 已有 ΔH 列真实 D−E 和驱动诊断，并已有部分层 H 净幅度反而小的反例；本次不是“终于测实际 q／E”，只能以尚未承接的来源对比及任务解释作为增量。

**缺的连接不是再算一次矩阵乘法。** 要理解的是：两种来源写入经过各自实际接收过程后，是否形成能解释完整来源选择差异的任务相关净读数关系；还是解释必须包含额外的背景相关后续转换。串联环节可以共同决定结果，不要求二选一，不把选择性划成互斥的“出生位置”或自然机制百分比。

最有价值的增量，是把现有“只 HH 强”的配合事实推进为**具体、可失败的来源选择关系**，能够同时约束为何强端强、两个交叉端弱。若最后只得到 HH 的某个范数较大、存在读写交互，或又一项系数操作能改变分数，尚未兑现这个增量。

**最强反对意见：** 这仍可能只是把一个已知的双线性读取与非线性后续系统逐段分解、拟合现有四格；“完整解释四格”的愿望不能自行证明认识增量。当前没有新证据提高净读取候选为真的信心，也没有提高论文成功预期。我仍作有限首选，是因为对象、两端和未承接的弱对照比其他候选更明确，而非认定它已经有更高的阳性概率。若后续具体化只剩增加四格向量记录或重复一个系数有效，这个首选理由就不成立。

## 3. 必须纠正的数学与解释边界

设 \(b\) 为接收背景、\(s\) 为写入来源，当前层的实际加入量为 \(J_{b,s}\)。在固定本次调用驱动的局部比较中，实数形式的净增量读取为

\[
d_{b,s}=J_{b,s}^{\top}w_{b,s},\qquad
w_{b,s}=\alpha_{b,s}\big[q_{b,s}-\beta_{b,s}k_{b,s}(k_{b,s}^{\top}q_{b,s})\big],
\]

其中 q 应包含所用内核的实际缩放，有限精度与实际状态加法另有身份。这个式子是已知函数关系，不是待发现的机制。

三项边界不可省略：

1. **高层 w 同时依赖背景和写入来源。** 前面层的写入已经改变后续层输入，不能把四格简化为一份独立固定的 \(J_s\) 乘一个独立固定的 \(w_b\)。旧来源 q 代理也不能替代真实交叉轨迹。
2. **局部 J 用途不是整个写入效应。** t1 的其他后果、基底状态、各层当前驱动以及后续状态仍可不同。固定驱动下的局部恒等式，不自动分配整个有限轨迹的来源作用。
3. **没有证据预先指定擦除项抹掉 ΔC。** 旧 NVW 已显示擦除项变化量不小而行为作用可弱；NQK 又表明受针 q/k 在干净背景单独不致错。不能因公式里有负项，就将 HC 弱归因于负项；范数相近也不等于任务方向等价。[NVW](../../../experiments/cache-native-v-write-interaction-v1-2026-11-03/REPORT.zh-CN.md)；[NQK](../../../experiments/cache-native-qk-history-v1-2026-11-03/REPORT.zh-CN.md)

“保留、削弱、改向”必须相对明确的同空间比较，并最终承接任务作用；不能把状态矩阵到读出向量的维度变化本身叫方向改变。四格终点的强弱也不自动要求每层、每头的局部幅度有相同排序。

## 5. 与旧 BRC、A027/A028 的关系

**C 有旧 BRC 的直接血缘，不能包装成全新想法。** BRC v2 围绕 CH/HH 的 ΔH 列，操纵 J 的直接读取 D 系数 \(\alpha q\)，保留 E、当前写入与真实状态更新；虽然重放四格，核心因果判断并未解释 ΔC 列。它至今只是未运行方案，不是失败实验。[BRC v2](../../../experiments/cache-background-read-coefficient-v1-2026-11-13/PLAN.zh-CN.md)

本次首选与它的有意义区别只能是：完整承接写入来源选择的约束，研究实际净读取与后续任务使用的连接，而非只做 ΔH 的一个 D 系数交换。**加上 E、补一列或更换公式本身均不是科学增量。** 若最终仍只得到“某读取系数在 CH/HH 有作用”，应如实承认回到了 BRC 的局部问题，不能宣称解释了 WSB 完整配合。

A027 的近邻审查已经说明：来源写读、背景交互、归一化／门作用都有直接前人。C 可能增加的是本案例为何具有这种来源选择性的具体认识，不是发现矩阵记忆需要匹配查询。当前没有新的首次性判断，也不保证这种案例解释足够成为强论文中心。

A028 暂缓的是当时可指明的门—梯度—末端 seed 继续细拆与旧范围挑战，并未实证否定 C。此次排序变化来自重新比较未承接的 HC 约束与整个机制地图，**不是获得了新的阳性数据，也不是因用户要求首选而撤销旧反证**。当前可推荐 C 的相对优先，不必把 A028 的局部暂缓翻译成永久禁止再审 H/C 问题。

## 6. 什么失败仍能增加认识，以及何时不值得继续

若任务相关的实际净读取差异不能承担来源选择排序，或同等可信的后续映射解释始终无法区分，应撤回／暂缓“净读取配合解释了 HH 独强”的主张。它不会自动证明后续放大，更不能转而宣布一般非线性就是答案。

这样的阴性在明确约束某一读取解释时有价值；但“没有测清”“只有范数关联”或“又找到一个有效操作”不能都算成功。若 C 只能产出这些结果，就不足以兑现本次首选的理由，应允许收束，不默认接着拆层头、补全部生成过程或转大模型。

**最终建议：首选 C，F 为最接近但未超出的备选；不启动任何方案。** 当前选择已经具体到原 WSB 两份实际写入、真实 t2 净读取和四格完整来源选择之间的缺口，不再把整个历史机制总问题冒称为下一题。下一步是否能成为有效设计是另一个尚未完成的判断，本轮不预先给它通过。
