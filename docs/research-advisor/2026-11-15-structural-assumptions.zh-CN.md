# A012：哪些默认固定的计算规则值得重新审视

2026-11-15。来源基点 `067534ee1fd233bb980e62b6508f87d6788721ae`。用户提出：改变通常默认不动的模型结构，是否可能帮助Acupuncture突破当前卡点，或产生独立价值？

**交付身份：候选筛选与研究价值判断，不是新实验设计或运行方案。** 没有加载模型、生成回答、训练、修改模型源码或使用GPU；未改变BRC/WUS方案及其未运行身份。使用 Scientific Brainstorming 独立生成流程和独立上下文 Advisor；候选不等于发现，审查不等于独立复现。

## 1. 正面判断

存在值得审视的默认规则。按与本项目证据的距离，优先保留 **B：短卷积的历史混合规则**，再保留 **A：中间归一化的共享尺度规则**。这只是前期核查顺序，不是机制真实性排序，也不构成直接实施结构手术的推荐。**C：擦除与写入的绑定**有直接架构先例，但简单版本已与本项目旧操作重叠，目前不优先。

这里的“默认固定”指本项目目前沿用预训练模型的计算规则，不是宣称学界从来没人动过。已有方法可以承接，是否值得做取决于它能增加什么认识或实际能力，而不是每个部件是否首次。

主问题保持：针如何改变历史形成、写入、旧状态处理与后续读取，并造成完整回答变化。新切口是让某条计算规则本身成为解释对象。结构改动不会自动获得更强因果识别；有解释力的条件patch可以比大改架构更有价值。

## 2. 候选B：历史混合规则——项目证据最近

**默认规则。** 当前Qwen3.5 GDN将最近的投影输入通过训练后固定的短卷积生成q/k/v，再执行读写计算。源码为逐通道卷积，各通道系数独立；不是q、k、v共用同一个滤波器。相关定义见[固定版本源码](https://github.com/huggingface/transformers/blob/v5.20.2/src/transformers/models/qwen3_5/modeling_qwen3_5.py)。

**可以重新审视什么。** 历史应以怎样的时间权重参与当前读写，是否必须一直沿用原来的固定混合规则？这与之前换入一份干净缓存不同：前者改生成当前信号的规则，后者改规则所处理的内容。此处没有选定新核、窗口、层、时段或算法。

**项目支持与反证。** [FX](../../experiments/cache-fixed-v-delivery-v1-2026-11-02/REPORT.zh-CN.md)在旧P面板中恢复全部卷积V后严格交付48/48，而固定45头严格0/48；它证明特定历史内容操作的条件作用，不证明原卷积规则有缺陷，更不证明删卷积可以恢复。DWC/WSB进一步支持来源写入与答案的条件关系，但不能与FX拼成已识别链。[NQK](../../experiments/cache-native-qk-history-v1-2026-11-03/REPORT.zh-CN.md)中受损q/k历史单独移入干净背景没有致错，不能把此候选缩成“query就是病根”。

**值得回答的问题（假设）。** 针的后果是否依赖某种具体的时间混合方式，使先前受扰动输入持续参与后续来源选择？若能解释一种有效/失效条件，就可能接上针入口与后续历史用途。并非仅发现卷积会混合时间，也不预设改变规则一定减轻损伤。

**近邻。** [Dynamic Short Convolutions Improve Transformers](https://arxiv.org/html/2606.03825)将静态卷积改为输入依赖滤波器，并在训练所得的Transformer、Gated DeltaNet和Mamba-2变体中检验效果；相关训练对比见§3.2。这说明规则可改、有可借用方法，不能推出冻结Qwen直接替换会有效。本轮不建议另起大规模训练来复制该架构结果。

**价值与退出边界。** 若变化只让干净和受针运行一起退化、只带来任意答案翻转，不能解释针机制；若只能靠对每题重新挑滤波器保持效果，不能称可复用规则。现有证据不足以预判新规则成功，保留理由是与已知效应对象接近。

## 3. 候选A：中间归一化共享尺度——数学入口清楚，项目支持更弱

**默认规则。** RMSNorm按向量总体能量生成分母，再缩放各坐标。某些分量的变化会改变其他分量的输出尺度；这可以继续影响非线性门与残差支路的相对作用。它可能压低、稳定或改变后续响应，不能未经测量称为“放大器”。

**必须先纠正的直觉。** 针加在MLP中间通道，经down projection后已是残差空间中的稠密方向。不能把它说成“一个hidden坐标异常，所以从分母里删掉那个坐标”。共享分母也不是针影响变得稠密的必要起点。它是否在当前针效应中具有行为意义仍未知。

**可以重新审视什么。** 计算尺度是否必须由当前所有分量共同决定，以及怎样区分针带来的方向变化与共享尺度变化。单次换用干净分母是诊断patch；采用不同尺度估计规则才是函数变更。两者都可能有用，不能因名称叫结构变更就提升价值。本轮不选归一化替代算法，也不推荐直接删除归一化。

**项目支持与反证。** 早层研究已经讨论过归一化几何；[BRIDGE方案§5.1](../cache-formation-readout-bridge-plan-v1-2026-10-31.zh-CN.md)和[输出路径CPU报告](../../experiments/cache-output-path-audit-v1-2026-11-01/REPORT.zh-CN.md)已处理最终归一化尺度。不能当成从未考虑过的新机制。仅改无偏置输出头前的最终正标量尺度，在实数算术下不改argmax，不能用它承诺修复greedy答案。这里留下的是**中间计算**中尺度与后续非线性响应的关系，现有材料未证明其主导针效应。

**近邻。** [RMSNorm原文§5](https://arxiv.org/html/1910.07467)已有用部分坐标估计尺度的pRMSNorm；[Massive Activations原文附录B.2](https://arxiv.org/html/2402.17762)讨论某些模型中少数巨大激活支配归一化分母。这些是方法与可能机制的先例，不是我们Qwen针存在同一现象的证据。

**价值与退出边界。** 有价值的是说明一个已知计算规则在什么针/输入条件下改变了历史用途和完整答案，而不是再发现“分母会变”。若现有轨迹和计算约束不支持这条关系，不应仅因换norm容易实现而升级模型实验；即使尺度规律存在，NGC已提醒内部规律不自动解释行为。

## 4. 候选C及不优先事项

| 候选 | 确实能动什么 | 本轮取舍及理由 |
|---|---|---|
| 擦除/写入绑定 | 原GDN同一β参与旧状态定向擦除和新值写入，同一key参与两者 | [Gated DeltaNet-2](https://arxiv.org/html/2605.22791v2)已用独立通道级擦写门并训练模型。可承接，非新点子否决；但[NGC源码](../../experiments/cache-native-gain-v1-2026-11-08/ngc_core.py)已在指定t1保留原生E、单独改变W，且新修复为零。简单拆β不是未试过的突破；更高维规则尚缺项目依据。暂不优先。 |
| 先更新后读取 | 原生输出使用更新后的状态；可以改变本步可见的状态时点 | 真正规则变化，但单步去掉当前写入容易退化为旧用途patch；原任务可能依赖即时写入。未看到它比已有D/E用途问题提供更强的项目增量，保留为独立生成者的次选，不升级。 |
| q/k在value heads间共享 | 固定源码使用repeat_interleave；可解除绑定 | 结构可改，但没有项目证据指向共享导致当前难点，不能只因是“隐藏的默认”而优先。 |
| 改坐标基、旋转再反旋转 | 在合法位置成对变换可保持原函数；插针方向若同时变化则是新的干预 | [QuaRot](https://proceedings.neurips.cc/paper_files/paper/2024/hash/b5b939436789f76f08b9d0da5e81af7c-Abstract-Conference.html)已利用计算不变性。仅证明稀疏依赖坐标系是代数结果，不会自行解释现有针；非线性前后不能随意交换旋转。 |
| 换层顺序、attention比例、扩大状态容量 | 改宏观结构和容量 | 当前没有相应瓶颈证据，冻结权重直接改容易失配，需要适配训练时应按独立架构课题判断价值，不作为本轮默认解卡方法。 |
| 屏蔽EOS、再扫针/层/剂量 | 改输出约束或扩大搜索 | 不回答用户提出的结构切口，也不作为当前课题主目标。 |

## 5. 什么样的结果才可能帮助解卡

诊断价值：改变一条计算关系后，能够解释针效应为何改变，约束来源选择的成功与失败，并与原模型证据相连；无需解释所有原生错误。反之，换了模型之后出现新行为，并不能自动回推原来的病因。

独立方法价值：即使尚未解释原机制，若一种改动能在适用范围内改善干预的可控性或降低能力代价，仍可能属于稳定副作用控制线的成果。但必须分别证明效果、能力代价与范围；本轮没有这项结果，不提前承诺。

因此推荐是B/A前期核查，而不是选择“更大胆”代替证据。现行BRC/WUS不被本轮自动取消、替换或执行。

## 6. 生成过程、筛选与反方核对

先定评判维度：与主问题的联系、项目证据/反证、相对旧操作的认识增量、改动可判读性、失败能否结束分支。采用理由判断，不给成功率或综合分。

查文献前作者独立初轮：P1擦写key/β解绑；P2短卷积时间规则；P3共享归一化尺度；P4 q/k头共享；P5坐标基；P6更新/读取时序；P7宏观层序/比例/容量。另一独立上下文agent `structural_candidates` 未见作者候选，生成SC01共享归一化、SC02写后读取时序、SC03擦写解绑；其排序是SC01优先、SC02次之、SC03暂不优先。它未独立提出B，不能声称多人一致发现B。

查证后重新开放筛选：保留P2/P3；P1由文献取得可实现性依据，但被本项目NGC重叠限制，不当新发现；P4缺项目锚点；P5的等价性本身非实证增量；P6与用途操作过近；P7缺瓶颈证据。已有工作不因“已有人做”被淘汰，淘汰/降级理由是本项目增量或识别价值不足。

最强反方：①改结构产生训练失配，不说明原针机制；②只把内部变化换一个位置，没有增加解释；③模型普遍退化/答案阈值变化制造假象；④把熟悉公式当发现；⑤把阴性都解释成需要更大改动。处理：限定当前为候选，不冻结手术；保留基线能力与完整答案问题；必须有针相关、可失败的解释增量；没有依据时结束候选，不能自动加训练、模型、层或预算。

## 7. Advisor审查与处理

同一独立上下文审查者 `bottleneck_advisor` 对本轮具体草案重新审查。结论：保留A/B为前期可行性核查候选，不称最可能突破方向；按项目证据距离B先于A。结构改动不天然比patch更有解释力；C暂不优先；独立方法价值必须另证。无模型/GPU授权。

作者处理：

1. 采纳B先于A的证据距离排序，明确与生成者SC01优先的不同；不虚构共识或机制胜算。
2. 采纳归一化不叫放大器、针down projection后已稠密的纠正；A仅为项目支持较弱的结构假设。
3. 采纳结构改动不优于patch的原则，不以“改函数”本身作为新颖性和识别优势。
4. 采纳C训练架构先例不能证明冻结手术有效，NGC旧操作重叠必须披露。
5. 采纳独立方法贡献需要能力代价与范围证据，不提前许诺。
6. 审查者初次将NBR与NVB混淆，否定作者使用“固定梯度只换q/α的投影较小”的依据。作者提供准确[NBR原报告顶部更正](../../experiments/cache-native-bridge-record-v1-2026-11-03/REPORT.zh-CN.md)后，同一审查者复核并撤回该条否定。其原句：

> 已核对，确实是我把NBR与NVB来源混淆；撤回上一意见第2点对你引用依据的否定。NBR更正支持“固定梯度、仅换q/α时，所测一阶目标投影变化很小”，但不支持query对完整行为普遍作用弱；你现在保留这一特定投影边界的表述，我无异议。

本报告不依靠NBR宣称query普遍弱。未解决未知：A/B是否有实际针相关行为作用、结构变更能否维持基线能力，以及能否形成有分量的部分机制或方法贡献。
