# DWC之后的下一阶段：先检验关系能否跨模型，再扩大任务范围

2026-11-08。状态：方向建议与概念自查；不是可执行合同，未实现、未冻结、未运行。依据为论文v1.6及DWC正式交付提交`7f3d1ce20`。采用Academic Research Suite实验规划流程及项目实验设计自查v1；作者自查不称独立评审。

**同日复用审计更正：** 先前仅引用9B预检metadata，低估了已有跨模型积累。现已核对四模型18,272份唯一单针回答、其中7,632份内部轨迹，以及4B→9B/2B迁移与每个目标模型1,400道能力测评题的已交付记录。下一步先复用这些结果；不重跑全层扫描、剂量面板或能力测评。G4需要补的是同一写入—读取关系的跨模型检验，不是从零证明其他模型会受干预影响。9B是候选，具体对象与新增测量须经既有资产比较确定，不能因本方向文档而默认重新开展大规模多模型采集。详见[复用审计](cross-model-reuse-audit-2026-11-08.zh-CN.md)。

## 1. 明确建议及优先级

总问题不变：稀疏干预怎样通过历史信号、写入、旧状态处理和后续读取造成大幅回答变化。

**下一优先补G4，首选Qwen3.5-9B上的同族规模迁移：检验4B中得到的历史来源—指定写入—直接读取—完整答案关系能否预测第二个模型的行为。** 同架构族跨规模是第一步，不等于跨架构普遍性；不能仅多列一个模型的答对率就宣称机制推广。

DWC已在96新情境上确认主方向双向量级；N1210获得区间上界低于M，保留为范围边界。当前不优先追加相同材料、放宽门槛或继续扫描4B层/头。下一轮需要改变解释覆盖的轴。

| 次序 | 要补的证据 | 对论文的增量 |
|---|---|---|
| 1 | 同族第二模型的同关系预测，首选9B | 检验结论是否依赖4B特定权重实例；迁移或分叉都能约束解释 |
| 2 | 非编号的内容选择/事实回答，先固定模型 | 检验是否局限列表行号与短编号输出；换真实内容判据，不能只改编号外观 |
| 3 | 入口如何形成关键写入/读取条件，围绕具体分叉 | 增强为什么会出现效应的解释；不开展无目标缓存扫描 |
| 4 | 真实转向中的非目标损伤与修复收益 | 提供应用价值；目前不能替代机制覆盖证据 |

跨模型和换任务不在第一轮同时改变，以免阴性无法区分模型、材料与操作不兼容。异架构模型的算子不一定有相同D/E分解，不能生搬硬套；它是后续广度轴，不借9B阳性提前计分。

## 2. 下一实验应保留的科学问题与比较

本轮问题：在9B的可比稀疏干预背景中，供体历史引起的指定写入差异，能否经后续直接读取产生定向获得、撤回和自身答案恢复？D用途是否仍区别于E？

建议保留的比较职责：

- 干净及原生受针运行：任务可答性、实际损伤、自然停止/截断分账。
- 自身来源O与供体来源F的局部写入端点：同一接收者、同一干预背景，只改变指定写入的历史来源；不是从4B复制缓存张量到9B。
- O读取F与F读取O的D用途：双向净转移及冲突配对自身恢复，不能只报告“换状态后输出变了”。
- E用途作为既有竞争比较：防止把任意状态替换都称为直接读取解释。工程零用途检查不当科学阴性对照。

估计对象沿用完整回答上的供体相关净转移及配对G/W/R，按独立基础情境统计。工程上仅在相应输出用途读替代状态，当前层持久更新不被替换，高层及后续自然响应；这是条件总效果，不宣称唯一原生中介。具体模型revision、方向选择、剂量标定、层集合、生成终点和样本量尚须定为合同；不能照搬N4146编号或4B向量。量级判据与不确定性规则应在正式输出前固定，关系同向与达到关注量级分别报告。

## 3. 最重要的前提：不能把“调到有效”当迁移

第一步先做旧资产、配置和实现的CPU审计。仓库已有9B历史预检metadata，记录revision `c202236235762e1c871ad0ccb60c8ee5ba337b9a`及当时模型路径；这证明历史运行身份，不证明服务器当前权重完整或新算子已就绪。当前官方config有交替linear/full attention及卷积配置，可作为接口审计入口，不能覆盖历史固定revision。

方向、剂量和局部写入适配只能按明确规则在分离的开发材料上建立，并记录全部候选与成本；正式材料不用于筛选。若要新拟合9B的去偏移量，须明确它是目标模型校准，不能叫4B参数零样本直迁。适配规模必须有上限，不以G/W阳性为挑选依据，也不反复换针救结果。没有可比损伤或无法形成可交付端点时，应报告迁移前提不满足；不能当作读取关系已被否证，也不能无限寻找例外。

DWC的96情境可以用来对照或开发，但其结果已见。需要独立确认的9B材料必须另行划分/生成并事先冻结；如果沿用DWC材料只做模型迁移，应准确标为“已见材料上的跨模型检验”，不能再叫新材料确认。

## 4. 成功、失败、部分结果各说明什么

| 观察 | 允许的认识增量 | 不允许的推论 |
|---|---|---|
| 可比端点成立，D双向关系及自身恢复确认 | 同族第二模型支持历史—写入—读取的预测关系；若量级门槛亦过，再声明量级确认 | 所有混合模型、所有任务、自然唯一通路成立 |
| F有转移，D获得/撤回为正但较弱 | 来源写入可迁移，读取作用强度有边界 | 无作用，或隐去强量级失败 |
| F有转移，D关系无支持/异号且工程与精度足够 | 写入到该读取用途的迁移预测受限；定位到接口分叉 | 供体历史不含信息，或立即全层搜一个阳性 |
| E也有效、D不再相对更强 | 传递关系与用途优势分开；4B的用途排序未迁移 | 只保留D阳性而隐藏E |
| 干净不答、没有可比损伤、端点无法交付、预算截断过多 | 前提或测量范围不满足，不能裁决核心读取迁移 | 当作机制科学阴性；通过调输出筛掉困难样本 |
| 区间太宽 | 结果不可判，报告估计和设计精度 | “不显著所以没有效应”或自动扩样 |

任何结局都保留4B独立确认；它检验解释范围，不重写已发生的结果。不因阴性自动增加模型、方向、剂量或层。

## 5. 成本与当前缺失信息

可复用DWC材料生成/供体配对/完整回答判读/分层统计，以及LVK/SRU算子定义。必须新增的是9B的实际端点、读取反事实和数值验收；旧多模型行为记录不能提供这些测量。

目前不能给可靠GPU预算：尚缺固定revision的算子兼容性、目标方向选择规则与成本、9B端点可达率、每种场景实际吞吐/峰值显存及所需独立场景精度。DWC的17.46 GPU进程小时包含共卡竞争，既不能直接乘9/4，也不能作为本轮上限。预算应计入适配、失败尝试、预检、正式、加载与共享负载；先完成CPU资产审计，再给可验收合同和预算，不能现在称可上卡。

## 6. 设计自查与历史错误

本次是方向取舍，不伪装成完整执行设计。相比DWC：保留来源、写入、读取和完整答案关系；新增模型轴；不再以扩4B材料填G1，不同时新增任务轴。最强反方意见是“9B阳性可能只是为9B重新调出了类似现象”；处理是预先固定适配规则、分开开发/正式、不按读取效应筛方向，并如实区分算子关系迁移与零样本参数迁移。

| 项 | 判定与理由 |
|---|---|
| C01 | 通过：总问题与来源—写入—读取—完整回答主线保持 |
| C02 | 通过：新增第二模型上的可预测关系，不重复缓存影响输出 |
| C03 | 通过：DWC正式回执、旧9Bmetadata、基础审计；历史资产非当前就绪 |
| C04 | 通过：保留N1210低于M、E异号及跨结构异质性，不预设强度相同 |
| C05 | 未完成：目标revision/针/剂量/层集合待CPU资产审计与明确适配规则，不可执行 |
| C06 | 概念通过：当前层输出用途和持久状态区分，下游响应允许；实现待验收 |
| C07 | 概念通过：不额外独立拼换共享门控，不跨模型复制状态；具体算子待兼容核对 |
| C08 | 通过：条件作用、跨规模与跨架构边界分开，不称自然唯一路径 |
| C09 | 通过：F转移与D/E读取结果有不同结局，前提失败与关系失败分离 |
| C10 | 通过：完整答案、净转移、自身恢复为终点，停止/截断保留 |
| C11 | 通过：阴性、异号、弱效应和不可判分别解释；工程失败不算科学失败 |
| C12 | 未完成：已识别新增测量，但样本精度与全包预算未确定 |
| C13 | 未完成：开发/确认边界已规定，具体材料、版本、冻结与数值验收未完成 |
| C14 | 通过：迁移或边界均形成稳定认识，无自动扩扫描 |

相关历史错误E01/E24：不缩目标、不要求一轮完整机制；E02/E04/E19：架构定义是审计前提；E03/E12：坐标少不等于小扰动，净转移非万能消混杂；E05–E09/E13–E18/E26：只主张明确来源与用途的条件总效果，不命名唯一自然路径；E10/E11：完整回答不由EOS/logit/信息存量代理；E20：模型适配失败与读取分叉不假装互斥机制；E21：不凭换模型宣布首次；E22/E23：已见材料及作者自查准确标识；E25：不同时扩所有轴。

**结论：优先级判断成立；可执行设计尚未通过，具体阻塞为C05/C12/C13。** 当前可以明确建议先补跨模型关系，不能把本文作为冻结合同或GPU放行。新实验调用0，无队列或预算变更。
