# 下一阶段候选 B（状态滞留）与 S（sink / L3 边界）：七步查重报告

2026-10-29。用户指令：“跑查重，一次查明白”。三路模型辅助检索并行（B 线第 1–4 步、S 线第 1–4 步、两线共用第 5–6 步），汇总与第 7 步由主会话完成。本报告只写文献覆盖，不写 novelty 段、不给等级。原始笔记、逐步查询表与原文引文在 [`next-stage-state-sink-audit-2026-10-29/`](next-stage-state-sink-audit-2026-10-29/)。

## 0. 先说坏消息

1. **B 线的现象已发表。** Prefix Steering（2610.04967）只在一小段 token 上转向、之后不再干预，效应延续到转向结束后很久；机制被作者列为开放：“our behavioral experiments do not distinguish between these mechanisms”（OLMo 3、Qwen3，纯 Transformer）。
2. **B 线的方法在同一模型上已有。** 2609.04434 在 **Qwen3.5-4B** 上做 split-prefill（只留 KV 或只留递推状态）与 state-swap，并给出类比档预言：语言/人设/语气类效应走递推状态。
3. **B 线的痛点被反转。** Prefix Steering、PrOSV、KV Cache Steering、ReFT 都把“撤掉后仍有效”当作优点；“转向经前缀缓存污染下一个请求”没有找到任何报告。唯一的正面证据（2605.10664 GCAD，多轮 CAA 的“KV 污染”）没有撤除臂，作者只写“likely mechanism”。
4. **S 线前一半已被占。** “干预使上下文不可用而参数知识保留”在概念层被 Jin 2502.01563（ICML 2025，破坏 Q/K massive values 后 passkey 100%→0–2%）占据；方法 S4（配对事实候选 logit 差）被 Ortu 2402.11655、Du 2404.04633 覆盖，且 Hagström 2412.17031 公开批评此类 logit 差未归一化。
5. **对前一轮审计（2026-10-28 晚）的两处更正。** ①2608.12149 的删 PAS 实验只在 M-A-P GDN 检查点（340M、1.3B）上做，Qwen3.5 只有观测图；全文无 EOS 读数——“sink 破坏导致停止”在 Qwen3.5 上无直接证据，C5 降为两步类比。②2603.16335（Yap）不只是 C4 零结果：其表 5（decode_only 转向 p=0.36–0.67 无效，prefill_only p=0.0007）被作者写成“behavioral commitments are computed during prefill in GatedDeltaNet”，在结论层断言了 B3 的一部分（未排除全注意力 KV，属推断）。另，2606.11375 是探针层面、各向同性、不传播的结果，不是输出层面的反证（见 `experiments/early-stop-knowledge-readout-v1-2026-10-29/PROTOCOL-CHECK-2606.11375.zh-CN.md`）。

## 3. 本轮的零 GPU 蕴含检验

2602.02712 命题 4.1：所有位置加常向量 v、剂量趋大时，logits 收敛到 LN(v)·Wᵀ。若其 argmax 恰为 EOS，则“首步 EOS”为推论。用 Qwen3.5-4B 权重（tied embedding，最终 RMSNorm 为 x/rms·(1+w)）在 CPU 上计算各条件写入方向 ±W_down[:,c] 与两条随机方向 ±v：

- 早层 16 个原生条件与 4 个方向条件：argmax 无一为 EOS（248044/248046）；EOS 排名 2,499–245,820。
- 中后层同样无一为 EOS。
- 读法（推导档）：各早层写入方向“指向”的 token 彼此完全不同，而干预后输出一致为首步 EOS；EOS 不是写入方向的直接投影，更接近读不到上下文时的默认输出。这支持 S3、并排除 S1 被命题 4.1 直接蕴含。
