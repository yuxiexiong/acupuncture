# 缓存机制线：架构可迁移性与检查点

日期：2026-11-01。性质：研究定位与检查点建议，不是可执行实验合同，不新增模型/GPU运行授权。核对材料：当前对话的 B2/C1-P/C2/B3/B3-P0 报告截图、仓库文献合并表、架构先验审计，以及官方模型配置/论文。截图中的实测数字按报告证据使用，本轮未复算原始张量。交付期间远端更新至 4f617bb；已读取该提交的 B3-P1 报告：按出口 (2) 结束记录分析，没有可区分计算预测。报告的有符号对齐能量主要来自同一步增量，跨步项总体为负；这仍不等于独立写入或共享下游响应已被证实。

## 1. 核心定位

总问题保持为：稀疏激活干预如何改变写入、历史状态处理和后续读取，进而改变回答。跨针眼、跨规模、跨架构是解释的适用边界检查，不是三个独立的新主线。

目前不能给“多少百分比跨架构”的统计。文献合并表有 124 个去重 arXiv 条目，其中包含核心研究、相邻方法和检索线索；这不是 124 篇全部精读并确认的机制论文，也没有逐篇编码架构覆盖。我们的当前缓存机制链尚没有跨架构确认；项目历史上的其他模型行为实验不能替代这项确认。

| 层级 | 可以迁移的内容 | 不随之成立的内容 |
|---|---|---|
| 数学恒等式 | 向量内积、四格交互、残差加法、平方范数分解 | 实际效应大小、方向、集中层和行为意义 |
| 有组件前提的推导 | RMSNorm 的分母效应；线性 down_proj 的单坐标写入；固定系数状态递推 | 所有模型都有同一组件，或真实运行始终满足固定系数条件 |
| 可迁移的研究操作 | 构造两个组的四格、比较分子/分母、冻结预测再检验 | 不同模型的状态变量、头数、注入位置天然一一对应 |
| 本项目实测关系 | 固定 45 头在已测输入/四方向的停止侧效果；本模型的对齐与交互账目 | 相同 45 头、13–18 层、0.7 余弦或特定门控关系在别处也成立 |

## 2. Related Work 已经跨到了哪里

- [Confidence Regulation Neurons](https://arxiv.org/abs/2406.16254) 在多种模型中研究经归一化/输出读出影响置信度的神经元。归一化影响 logits 不是本项目首次发现，更不是 Qwen 独有；但它不自动解释当前历史干预的形成过程。
- [WriteSAE](https://arxiv.org/abs/2605.12770) 研究递归写入表征，覆盖/讨论 Gated DeltaNet、Mamba-2、RWKV-7 等写入形式。跨递归架构的写入研究已有基础；不同更新算子的因果操作仍需分别定义。
- [What Attention Recalls and Recurrence Controls](https://arxiv.org/abs/2609.04434) 在 Qwen3.5 和 Falcon-H1 等混合架构上研究 KV/递归状态作用。其跨模型证据不等于对纯 Transformer 成立，因为后者没有同样的递归支路。
- [KV Cache Steering](https://arxiv.org/abs/2507.08799) 已研究 KV 干预及后续影响。其具体实验不是本项目冻结条件的复现，也不能直接改名为递归状态编辑。

我们的增量应定位为：在明确的干预/读取背景下，解释哪些历史变化通过哪些计算产生所测回答效应，提出能预测强弱或失败条件的关系，并检验这些关系的边界。不能写成“前人只观察现象，我们第一次解释内部机制”。

## 3. 比较具体版本，而不是品牌

架构有至少两个正交维度：序列混合器（全/局部注意力、递归、混合）与前馈模块（dense、MoE）。MoE 不是注意力的替代名。

| 具体模型 | 关键结构 | 对本项目的影响 |
|---|---|---|
| Qwen3.5-4B，当前固定 revision | 32 层文本骨干，3 层 Gated DeltaNet/线性注意力接 1 层全注意力；dense MLP | 同时存在短卷积、递归状态、注意力 KV；当前逐头 V 历史实验主要依赖这套实现 |
| Qwen3-8B | dense Transformer，GQA，RMSNorm | 同为 Qwen 却没有本研究的 Gated DeltaNet 状态；适合拆开品牌和混合器差异 |
| Llama 3.1-8B | dense decoder Transformer，GQA，RMSNorm | 可迁移残差/读出/历史影响问题；递归状态拆解不能照搬 |
| Mistral-7B-Instruct-v0.3 | dense Transformer，GQA；该配置 sliding_window=null | 不把初代 Mistral 的滑窗配置套到所有版本 |
| Gemma 3（如 4B） | 局部与全局注意力交替，配套归一化结构 | 历史可达范围受局部窗口约束；不是 Qwen3.5 那种注意力/递归混合 |
| DeepSeek-V3 | MLA 潜在注意力 + MoE | 压缩 KV 和专家路由改变可操作变量与耦合；需新适配 |
| 纯 Mamba-2 模型 | 选择性状态空间/递归混合器 | 没有普通逐 token 注意力 KV；需研究状态更新/读取，不存在同义的 KV 槽编辑 |

原始来源：[Qwen3.5 固定配置](https://huggingface.co/Qwen/Qwen3.5-4B/blob/851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a/config.json)、[Qwen3-8B 配置](https://huggingface.co/Qwen/Qwen3-8B/blob/main/config.json)、[Llama 3 报告](https://arxiv.org/abs/2407.21783)、[Mistral v0.3 配置](https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.3/blob/1e5c12c6a4a2a40ef8d566695d7a8496fcff8929/config.json)、[Gemma 3 官方结构说明](https://developers.googleblog.com/gemma-explained-whats-new-in-gemma-3/)、[DeepSeek-V3](https://arxiv.org/abs/2412.19437)、[Mamba-2](https://arxiv.org/abs/2405.21060)。家族内模型也有例外，例如 DeepSeek 的蒸馏 Qwen 模型不能按 V3 的 MLA/MoE 处理。

## 4. 数学上到底什么不能直接迁移

### 通用几何与条件读出

令 h10=c+a，h01=c+b，h11=c+a+b+d，则：

K(||h||²)=2<a,b>+2<c+a+b,d>+||d||²。

这对任意同维实向量成立；本模型实测“第一项为正且大，含 d 的合计为负”不是恒等式保证的。去掉沿 c 的共同收缩后仍对齐，也是条件性实测结果，不能从公式推出。

RMSNorm 后线性读出可写 z_i=p_i/r+b_i，p_i 吸收可学习归一化增益，r=sqrt(mean(h²)+epsilon)。有此结构时，分母解释可迁移；LayerNorm 还含中心化，其他读出变换要重新推导。[RMSNorm 原论文](https://arxiv.org/abs/1910.07467)。

特别注意：无偏置线性读出、固定 h 的方向时，所有 logits 除以同一正 r 不改变 argmax。它能改变概率/置信度，却不能单凭这一点解释贪心 EOS 翻转。与“停止读出方向”正交只针对一个线性读数，不等于对所有词的 logits 都无作用。当前平方范数账目不能替代最终行为因果解释。

### 历史计算的结构差异

普通注意力示意为 o_t=softmax(q_t K^T/sqrt(d))V，读取逐位置历史；当前 Qwen3.5 G 层可以用 S_t=A_t S_(t-1)+B_t 表示更新，再从 S_t 读取。Gated DeltaNet 的 A/B 由遗忘、key 和纠错写入共同决定，并伴有短卷积等计算。两者都能承载干预后的历史效应，但不是同一个状态更新问题。

不能原样迁移的对象：

1. Llama/Qwen3 无 Gated DeltaNet 的矩阵状态、beta 纠错门和对应短卷积缓存，故“恢复这些变量”没有同义操作。Mamba-2 也不能直接套 Gated DeltaNet 的更新系数公式。
2. GQA 的多个 query 头共享 K/V；本项目 448 个值头块的分组不是所有模型的 448 个独立注意力头。头数和共享关系必须从目标实现定义。
3. MLA 原生压缩缓存常耦合 K/V 来源，不能假定编辑一个缓存坐标只改变 V；可在解压后设计 V 干预，但那是重新定义的操作。
4. MoE 的坐标写入会涉及具体专家与路由权重。固定路由条件下的线性关系可以使用，输入变化导致的路由变化不能忽略。
5. 神经元编号、头名单、绝对层号、原始激活/状态张量不能跨模型直接拷贝；即使维度相同，也没有天然语义坐标对应。这不禁止迁移选点规则或机制假说。

因此，结构上没有同一对象、需要工程适配、机制尚未验证，是三个不同结论。不能把前者说成“其他架构不会有这个行为”。

## 5. 什么时候设检查点

| 检查点 | 时机 | 应检验什么；何时停止 |
|---|---|---|
| 跨针眼/方向的内部一致性 | 现在，每次新解释提出时 | 用已有 N4146/N1210/R0/R1 检查同一解释是否容纳强弱及反例；已有面板是开发数据，不能重新称留出 |
| 新针眼的确认 | 有一条可写成预测的计算关系、准备深挖该关系之前 | 冻结选针规则和幅度定义，在未参与机制选择的通道/输入上测试；主效应太弱、机制关系失败、工程失败分别报告。跨深度另算时序/层位迁移 |
| 第一次跨架构检查 | B3-P1 已于 4f617bb 按出口结束，现在即到检查点 | 先审计已有其他模型资产；再决定是否另立小规模合同。先问对应状态操作是否保留主要现象及分子/分母关系。有候选才测候选机制；没有候选只能做现象边界检查 |
| 跨规模检查 | 同家族机制操作和读数稳定之后；若主张涉及规模，则必须在该主张前 | 同家族不同大小优先，并核对层布局/头共享/MoE是否也变了。两个规模只能说明有限迁移，不能宣布 scaling law |
| 论文确认 | 主机制与适用范围冻结后 | 独立输入/针眼，按主张补必要架构或规模；不自动展开模型×尺度×针眼大网格 |

最新 P1 的“共享下游响应”只是新假说，不自动授权新一轮分析。随机扰动是否同向依赖扰动分布、主导方向、符号及局部线性近似，不能单凭“有主导奇异方向”就保证任意两次响应正余弦。

跨架构不应无限等到 Qwen 全机制闭合才开始，也不应在没有对应操作时复制全部实验。优先选择一个没有递归层、但保留残差和 RMSNorm 的 dense Transformer（现有 Llama 资产优先审计；Qwen3 是另一选项），最能检验当前解释是否依赖递归混合器。单一 Qwen/Llama 对比同时改变权重、训练数据和 tokenizer，差异不能直接归因于架构。若进一步要声称“递归结构导致差异”，还需更有针对性的多模型或结构干预证据。

对齐应采用功能定义：注入发生在什么计算边界、历史形成与评分背景、供体/接收者、当前查询是否变化、相对残差的实际写入量。相同层号、相同数值剂量或相同参数量均不保证可比。不能按测试输出效果调剂量再宣称无偏匹配；起点写入匹配也不保证深层扰动匹配，后者应测量并明确是响应变量。

## 6. 自查与交付边界

这是范围定位，不是新增实验设计；因此不以 C01–C14 的运行设计通过替代尚未给出的具体合同。已按规范核对 C01/C02/C03/C08/C10/C12/C13/C14：主线未改、文献增量未夸大、公式和观测分离、EOS与logit分离、优先资产审计、已见数据不冒充留出、允许失败和停止。C04–C07/C09/C11 的具体假说、操作、竞争预测和工程闸门必须在各独立实验合同中完成，此处不宣称已完成。

最强反例：若另一模型也出现范数增长，仍可能来自不同历史计算。处理：只承认现象迁移，要求同一计算预测在对应操作下成立才提高机制主张。若另一模型没有效应，可能是剂量、基线或实现不可比，不能直接宣布架构特有。若相同架构不同规模失败，也不能自动命名为规模定律。

本轮不修改 B3-P1 v2，不执行模型/模块前向，不新增 GPU 预算。跨架构与跨规模的新运行仍需各自有用途、预算、工程验收与有效授权。
