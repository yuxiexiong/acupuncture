# Acupuncture 两针能力损伤的因果定位方案

更新：2026-10-26 12:20，北京时间。版本：v1，整合此前讨论与原帖第二轮核查。

**状态：讨论稿，根因实验继续暂停。本次只更新方案，不启动模型、不改变正在执行的迁移实验。** 本文是根因研究的当前讨论入口；历史方案及实验记录保留。

## 1 要回答的问题

我们已经观察到，两处动态激活干预会使模型的任务表现严重下降。接下来要回答：**两针改变了哪段计算，这段计算正常做什么，修复或重现其中的有限变化能解释多少损伤。** 由此再预测其他模型中应查找什么位置。

最直接的证据链是：

> 两针各自与共同的作用 → 受影响的具体计算 → 保留两针而局部修复 → 不扎两针而重现中间变化 → 无针时检验正常功能 → 冻结解释并跨模型检验。

“前额叶”保留为研究问题的类比，不作为已发现的结构。需要分别回答三个不同的大小问题：

| 对象 | 实际测量什么 |
|---|---|
| 干预入口 | 已知两点，以及有限候选中还有多少入口能影响同一计算；本轮不穷举全模型 |
| 下游计算系统 | 经验证的组件集合、所在层、作用位置、状态和子空间；可能跨层分布 |
| 功能影响范围 | 哪些任务要求受到影响，哪些仍可完成；不能用组件数量代替 |

核心目标是解释能力损伤。内容偏移、敌意措辞、主动有害建议、重复与结束异常分别记录，不合成一个含义不清的“变坏分数”，也不要求一定找到无损的行为控制方法。

## 2 已知起点与新增线索

### 已知起点

源模型是固定 revision 的 Qwen3.5-4B。两针位于门控 MLP 的 `SiLU(gate) * up` 之后、`down_proj` 之前：B 为零起始索引 L13/N7956，负向、先执行；A 为 L14/N8949，正向、后执行。模型权重冻结。

自然激活为 a、输出权重列为 w，通道加法为 a←a+c。理想实数计算中的额外写入是 c·w；当前配方 c=sign×dose×m/‖w‖，m 来自原版提示的参考残差尺度。因此 dose=1 的单针写入约为一个参考残差范数。“只有两针”表示入口少，不表示幅度小。实际 BF16 写入和逐位置相对尺度另行记录。

4B 的正式固定子集已出现明确能力下降，见[能力面板结果](../experiments/capability-screen-v3-2026-10-26/RESULTS.zh-CN.md)。迁移实验的进展另见[运行入口](../experiments/transfer-toy-v1-2026-10-26/active_run.json)。其他模型也下降，只增加了共同机制的可检验性，尚未证明原因相同。

### 第二轮材料改变了哪些设计

完整来源与证据分级见[第二轮核查报告](literature/lyra-x-thread-round2-2026-10-26.zh-CN.md)。以下把可借鉴的方法与未验证的线索分开。

| 新材料 | 纳入方案的变化 | 不能据此认定 |
|---|---|---|
| 评论者称单独 L14 已能改变内容，L13 作用较弱 | 提高 A/B 分解优先级；分别看能力、内容与结束 | L14 单独解释能力损伤，或 L13 无作用 |
| 强推城市概念后算术回答出现城市名的自述 | 加入“任务计算受损”和“无关内容压过答案”的竞争解释 | 模型其实算对了，只是故意不说 |
| 单神经元论文比较固定与输入依赖的抑制，并报告不同能力代价 | 记录实际幅度、位置和作用次数；强制驱动与正常活动分开 | 差异一定来自某个特定机制，或我们的加法也有相同结果 |
| Sauers 模型卡报告原始模型中的定向消融及同层随机对照 | 候选路径还要接受无针状态下的正常功能检验 | 训练后的身份表述证明天然人格中心 |
| 情绪回路研究改变神经元／头的数量并设置随机对照 | 增加“集合大小—效应”曲线，并在独立材料确认 | 曲线给出天然脑区边界或全局最小回路 |
| 第三方以临时输出偏置实现双点干预 | 对照校准及写入定义，优先复用已有数值桥接记录 | 两种实现有限精度下逐位一致，或第三方50题已证明机制 |

这里借鉴的是[单神经元论文的方法比较](https://arxiv.org/pdf/2605.08513#page=6)、[Sauers 模型卡的原模型检验](https://huggingface.co/Sauers/Qwen3-8B-tawny-owl-128-neurons)和[情绪回路的消融与随机对照](https://arxiv.org/html/2510.11328v1#S6.SS3)。它们都没有验证我们的两个坐标的损伤机制。27B 抵抗、反向变善良等设置不完整的自述不作为本轮扩展模型或命名功能的依据。

## 3 第一步具体做什么

**第一步要交付一张可复核的分解表：是谁造成哪种变化、变化最早在哪些位置可观测，以及哪些候选值得进入因果验证。它本身不宣布已经找到功能区。**

### 输入与条件

先在 4B 上进行，沿用固定模型版本和评分规则。每题参考尺度只由原版提示计算一次，跨条件和回答位置固定；B开启后不重新校准A。既有 Q01–Q24 及已查看过的基准题只作开发材料；不恢复 Q25–Q40。

| 项目 | 本轮讨论提案 |
|---|---|
| 能力开发集 | 固定64道选择题，MMLU与ARC-C各32；使用完整选项评分，同时记录正确率 |
| 行为与生成位置 | 重放既有24题的原版和AB主回答，两族前缀在全部条件下分别比较；不把结束后的续写当主回答 |
| 主条件 | 原版、A、B、AB；剂量固定比较1和0.5，原版只算一次 |
| 方向对照 | 两针同时反向，逐层幅度保持相同；不预设其含义是“善良” |
| 随机对照 | 预先固定20组同层随机通道对；按列范数与自然激活尺度分层抽样，匹配实际逐层写入范数、符号数量及位置规则 |
| 联合作用对照 | 使用同一批随机列比较 A+随机B、随机A+B、随机A+随机B；先做内部读数 |

这些数量是成本受控的提案，不是已经执行或冻结的合同。第一步不对全部条件生成长回答，也不运行大 Benchmark。随机组完整保留，不挑“最像”或“最不像”两针的组。20组用于估计本批对照的范围，不能宣称精确测得极小尾部概率。

低剂量用于减少地板／天花板遮蔽。若1与0.5仍无法分辨，不事后逐档寻找好结果；在执行前可选择是否预登记一次0.25补充，写清触发规则和预算。没有预登记则本轮记为该剂量范围内难以分辨。

### 每个条件记录什么

1. **实际写入。** 提示和回答位置都记录 a、c、BF16相加前后差值、c·w 的理想范数及实际局部增量，以及相对于该位置原残差的尺度。局部增量在同一模块输入状态下，通过开启／关闭本针的配对计算测量；跨条件模块输出差分另外记录为传播效应，避免将B引起的输入变化计作A的写入。复用[已有数值桥接收据](../experiments/transfer-toy-v1-2026-10-26/validation-r01/bridge/receipt.json)覆盖的检查；新增条件才做必要补充。
2. **能力。** 记录正确选项相对错误选项的连续得分优势，并保留每个选项原始分数。沿用对应基准的长度处理与提示格式，不暗中换评分规则。连续分数仍可能饱和，不能单靠它认定交互。
3. **内容与结束。** 在相同前缀上读冻结的配对续写得分和结束概率，作为辅助定位；不把词汇出现当作恶意行为，也不把更早停止当作能力恢复。
4. **传播。** 记录注入后各模块对上述读数的差分和梯度归因，用于候选排序。自然激活大、残差差分大或词表投影显眼均不能单独定功能。

主比较始终使用完全相同的文字前缀，每个条件从头重算 KV 和递归状态。原版回答族和 AB 回答族分别统计，不跨族直接相减。特别保留第一次输出分叉前的共同前缀；分叉后的固定前缀检验是条件反事实，不能冒充两条自由生成轨迹的同状态比较。EOS读数在各自有效主回答的结束位置测量；未自然结束的记录保留截断状态，不把最后一个预算位置当作正常结束位置。

能力交互记为 `I = R_AB − R_A − R_B + R_0`，同一题、同一剂量、同一读数尺度计算。它只表示该读数上的非加性；不直接说明 B 经 A 传播，也不证明两个点属于同一回路。正确率、标签率和连续分数均保留，解释以校准结果为准。

### 第一步结束时回答五个问题

- A、B、AB 分别改变能力、内容和结束的程度如何？A单独是否接近AB，还是联合效应需要继续追踪？
- 与匹配随机干预相比，哪些变化具有位置／方向特异性，哪些像一般强扰动？
- 在提示末尾、首个答案选择及回答延续的哪些位置，能力相关读数已出现偏离？最早可观测位置不等于致损阶段；阶段归因需另行限定注入窗口，并控制作用次数与幅度。
- 有多少自然通道信号在当前注入下仍数值可辨？B是否改变A的自然激活，且这种差异是否值得检验？
- 哪些下游组件的有限贡献有望解释任务得分变化，哪些只是产生无关主题或停止异常？

若仍需区分自然激活与强制写入，预登记少量 a←c 的钳位诊断，与 a←a+c 比较。钳位是另一种干预，不是迁移的前提；相近输出只支持所测条件下近似等效，不能推出输入侧在所有任务中无用。加法与直接向量写入的数值校验也不能替代这项解释性检验。

## 4 从候选变成因果解释

### 用便宜读数定位少量候选

搜索两个入口后的传播计算；B还包括L14的线性注意力，不能只从L15开始。首轮按完整注意力头、可独立干预的线性注意力贡献、MLP模块排序；线性注意力的头和递归状态先核对实现，不能把隐藏坐标任意切片当作独立功能。只在入选模块内细化通道或子空间，不遍历全部神经元。

梯度归因用于缩小搜索，不承担结论。它在低剂量及少数真实替换上检查误差；原剂量预测失准时，只能缩小其用途，不能据此排除非线性路径。[Attribution Patching](https://arxiv.org/html/2310.10348v2)提供这种近似筛选思路。

本轮提议最多10个候选进入真实验证：8个按预定规则排名，2个从其余范围随机审计，检查漏检。若不同读数或前缀产生不同榜单，先按冻结的合并规则压到总预算内。候选统一写成：**组件集合、贡献子空间、作用位置／状态、所测任务**，不能只写“第几层第几个头”。

### 对候选做四种对照

| 操作 | 直接检验什么 |
|---|---|
| AB保持开启，仅把候选的有限贡献恢复为同前缀原版值 | 这部分变化是否参与损伤的形成或维持 |
| 原版无针，仅重放候选在AB下的中间变化 | 这部分变化是否足以重现相应损伤 |
| 同类型、同位置数、同维数及相近幅度的无关替换 | 恢复是否只来自任意改动或一般再平衡 |
| A、B、AB下分别检验候选与固定小集合 | 两针是否通过共同计算、不同计算或交互共同起作用 |

整层残差换回原版、直接消除 c·w 或关闭针，不作为找到传播机制的证据。模块整体替换可以作为粗定位诊断，最终解释必须尽量缩到有限贡献。位置局部恢复与全前缀恢复分开报告；后者可能同时清洗大量历史状态。

修复与重现都可能产生混合状态。需要核对替换位置与幅度，保留异常结果；修复有效但重现无效时，只能得到较弱的干预证据。恢复效应大于直接词分数变化，不自动说明补偿。若怀疑补偿，需测其他组件如何反向响应，并在有限的再干预中检查它是否抵消原效应；不把整批下游恢复当作恢复率的理论上限。

核心读数报告有符号的原始变化与区间；总效应接近零时不计算“解释百分比”。多个候选联合效应不等于单个效应之和，允许冗余、抵消和超过100%的相对恢复，不强行拼出可相加的贡献图。

分别修复两个组件有效，还不能证明二者之间的连接。若最终解释依赖某条具体传播路径，只对入选解释的关键连接补有限验证：在其他输入保持同一基线时，单独改变发送端传给指定接收端的贡献，检查接收计算与最终读数是否按预测变化。没有连接干预证据的连线保留为候选，不扩展成全模型逐边搜索。

### 用最小鉴别区分两类损伤

对入选路径补一个受控任务对：相同信息下，一题需要完成计算／比较，另一题直接给出答案而只需正确报告。两者与原版、AB及局部恢复一起测量，并配词汇和格式匹配对照。

- 若计算要求增加时损伤明显加重，且恢复任务相关中间贡献能改善独立解题，支持计算过程受影响。
- 若已给答案仍难以正确报告，说明给定信息的读取／保持／报告链路也受影响；只有对候选输出贡献的局部修复与重现进一步支持时，才归入输出竞争，不能仅凭任务对把内部计算与输出端彻底分开。
- 两种情况都可能存在；答案给出后的题目改变了任务难度，因此任务对本身只用于鉴别，仍需上述局部因果验证。

从隐藏状态解码到正确答案、压低几个城市词或恶意词，都不足以证明能力保存。结束恢复也须分别检查完成、正确、重复和截断。

## 5 它平时做什么 以及范围有多大

### 正常功能需要在无针模型中检验

先在候选确认输出打开前写好有限的任务族，例如：跨位置保留／读取给定信息、比较两个候选答案、把已给答案按要求输出。每个任务对只改变主要计算要求，并匹配长度、词汇、答案格式与无关对照。不能看到某组词后临时命名为“善恶”“前额叶”或“人格”。

在无针模型中对候选的有限贡献做消融或任务匹配的替换，再恢复；与同层同大小随机操作比较。零值消融可能产生分布外损伤，因此不能仅凭一次置零掉分命名功能。若候选只在强制注入后起作用而未见正常功能证据，应称为**强制扰动的传播通路**。若自然条件也支持特定计算作用，才进一步描述其正常功能。

这部分沿用 Sauers 原模型检验的思路，不复制其稀疏训练目标。自然消融无效也可能来自冗余；结论限定为当前任务和干预范围，没有可检出的正常功能贡献。

### 用集合大小与效应的关系描述范围

对入选组件按开发集固定次序形成1、2、4、8个组件的嵌套集合，最大不超过已验证预算。比较逐步加入后的恢复和重现，另对最终小集合做逐个移除；所有集合在确认前冻结，并配匹配随机集合。

同时报告层跨度、组件类型、作用的token位置、贡献维数或子空间秩，避免把一个整层MLP与一个注意力头简单算成等大的“一个点”。曲线分别画能力、内容和结束，不以其中一项代替另一项。

输出是“**本轮搜索范围内，达到预定恢复标准的最小已测试集合**”，不是全模型最小集合，更不是解剖边界。如果10个候选内无稳定解释，报告本轮未定位；不能直接断言不存在局部机制，也不能自动扩大搜索。

## 6 如何确认而不每次跑大 Benchmark

| 层级 | 材料与成本安排 | 决策作用 |
|---|---|---|
| 开发快测 | 上述64题连续能力读数、固定前缀的辅助读数；全条件使用相同材料 | 分解效应、候选排序、检验近似 |
| 小型真实验证 | 对最多10个候选做局部修复／重现；对少数代表条件做完整生成 | 排除代理误导、检验因果效果 |
| 独立机制确认 | 最多1—2个冻结解释，用未参与选择的题目及任务对确认 | 判断解释能否在新材料成立 |
| 正式能力面板 | 最终解释的关键修复、重现和必要对照进入现有四项面板 | 量化影响范围，不替代机制证据 |

小型完整生成沿用数学16题、代码16题、普通场景16题的讨论预算；正式执行前核验样本来源和重叠。先对原版、AB、预定随机条件及局部恢复条件校准代理，按干预类别分别比较。固定抽查被代理判为无效的条件；数学解答概率提高不等于能独立算对，代码概率提高不等于通过测试。

内容代理如需使用，采用立场与措辞交叉配对，避免把粗鲁词识别成行为变化；自然回答对与人工配对分别报告。完整回答按预先写好的判定规则盲评，普通正确性优先使用可复核规则。

历史看过或用于筛选的题不能再称独立确认。现有大面板可复用完全一致的原版／AB基线，明确它属于已见固定面板；新候选的独立机制确认使用另行冻结的材料。不能把大量同一题token当作大量独立样本。

统计以题目／场景为配对单位，报告效应和区间；多个随机通道组的差异另外保留。需要声称“另一项基本不变”时采用事前约定的等价范围，不能以不显著代替等价。确定性推理重跑的零波动不是统计误差。

历史的秒级诊断耗时不含加载、反向传播、校准、真实替换、生成及归档。本轮不承诺十分钟定位；获准运行后先用代表性工作量测量端到端成本，再按冻结预算执行。

## 7 如何把解释带到9B和2B

既有迁移实验保持原协议。根因方案先解释4B；只有源端候选通过独立确认，才把解释写成目标端预测。目标是预测对应的**计算关系**，不要求同编号或相邻通道构成功能区。

例如，若4B证据支持两针干扰跨位置的信息读取，迁移预测应包括：目标模型何种任务更受损、哪些候选读取计算应改变、局部恢复应改善什么，以及哪种结果会推翻预测。不能只预测“模型也会掉分”。

在查看目标端的新机制实验输出前，冻结功能定位规则、候选预算、作用位置、剂量规则、对照和失败标准。可用目标模型的正常任务活动定位，但必须记录用过哪些目标信息；使用目标损伤结果再调位置属于目标端开发，不能称零反馈预测。

分别记录：现象迁移、源定位规则有增益、对应计算得到双向因果支持。前两项都不自动等于机制迁移。若9B、2B最终解释不同，也保留这一结果，不以“都有严重损伤”强行合并。

## 8 竞争解释与本轮裁决

| 待检验解释 | 支持它需要的主要证据 | 不支持时如何表述 |
|---|---|---|
| A主要造成能力损伤，B贡献很小 | 低剂量与原剂量的能力读数、真实解题及预定等价比较一致 | 内容上的A主导不能推广到能力；本轮不作单针归因 |
| 损伤主要是一般大幅扰动 | 匹配随机通道产生相近损伤，特定路径证据不优于随机 | 两点的特殊性需具体到某项结果，不以少量入口本身证明 |
| 某段任务计算承载损伤 | 局部修复、反向重现、正常功能任务对及无关对照共同支持 | 只有相关性、只修好或只置零掉分，证据均不足 |
| 输出／内容竞争是重要因素 | 正确报告任务和有限输出贡献的因果检验支持，并与计算任务区分 | 正确答案可解码或主题词减少只能作线索 |
| 内容与能力在本轮可分离 | 存在预定干预使一项变化超过阈值，另一项落在等价范围，独立确认支持 | 写“所测干预内未分离”，不写“必然同源” |
| 一小组组件能解释多数损伤 | 冻结集合在确认题的修复与重现达到预定标准并优于匹配对照 | 本轮预算内未定位，不无限加候选 |
| 机制可迁移 | 源端冻结预测在目标模型中获得对应因果支持，且定位优于同预算基线 | 区分规则失效、证据不足和只有现象相似 |

假设可以同时成立。区间过宽或代理失准时记为证据不足；没有达到支持标准不自动等于已证明反面。各项最低效应、等价范围和统计处理须在确认集打开前确定，不能依据确认结果补阈值。

## 9 预期交付和恢复执行前需冻结的事项

本阶段争取交付四件东西：

1. 两针单独与联合的分解表，附实际幅度、随机对照及全部失败条件。
2. 一张组件级因果定位图：节点标明已验证贡献，连线区分直接检验过的连接与仅由结构、差分或归因提出的候选连接，保留补偿可能和未定位部分。
3. 正常功能的任务对照，以及集合大小—能力恢复／重现曲线。
4. 一组在9B、2B上尚未看结果的机制预测。

恢复运行前，另行冻结题目及哈希、主读数与等价范围、随机种子、低剂量补充是否允许、候选合并和最多10个的预算、完整生成抽查规则、确认题、软件与模型版本及端到端成本上限。本文先把因果问题和证据要求确定下来，具体确认阈值尚未定，不能称为可直接启动的冻结协议。

这沿用用户提供的[HanLab总结](HanLab经验总结.md)中“竞争解释配反事实、修复回到同一个被解释量、匹配对照、独立确认”的原则。新材料提高了鉴别力；研究主线仍是解释两针造成的损伤、识别对应计算及其范围，并检验该解释能否预测其他模型。
