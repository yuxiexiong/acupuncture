共同设置：
- 干预点是门控 MLP 中间通道，加在 `down_proj` 之前。偏移 c = d·m/‖W_down[:,n]‖，m 是该层干净提示上逐 token 残差范数的中位数，按题计算。
- **因此写入残差的向量范数恒为 d·m，与通道无关**（推导）。同一层、同一剂量下，各通道只差写入方向。
- 所有提示位置和解码步都注入；greedy、BF16、最多 128 token；8 道中文短答题 Q01–Q08。原版回答在同一文件（`layer=None`）。
- 通道是随机抽的，种子写在合同里，不是按激活大小挑的。

可以从已存字段准确导出的读数（不需要标注）：
- 首步 EOS（`generated_token_count==1` 且 `end_reason=='eos_token'`）；
- 首 token 是否与原版不同；
- 8 题中不同首 token 数（问题依赖度）；
- 长度、是否撞 128 上限、token 编辑距离、4-gram 重复。

**没有的**：正确性标签（8 题中只有 Q01/Q02/Q08 有可核对答案，部分原版本身答错）、logit 或 margin。

## 4. 对检验设计的含义

1. **结局大多已经见过。** 现有数据只能做"盲算候选量"的回顾性检验：先冻结候选量的定义和计算代码，再计算，最后才和结局连接。这比前瞻检验弱，必须照实标注。
2. **真正的前瞻检验需要新数据**：在层内差异大的层上新抽随机通道，先登记预测再生成（需要 GPU，放在后续阶段）。
3. **层内差异是最有判别力的地方。** 同层同剂量时写入幅度相同，所以层内差异只能来自方向。幅度类解释在这里预测"没有差异"，方向类解释必须说明哪些通道会停、哪些不会。
4. **剂量数据每层只有 1 个通道**，层与通道混在一起；剂量类问题只能做描述，或者只在这些点上比较符号不对称。
5. **范围边界**：中层的"换事实"类错误没有数值标签，本轮不纳入；首步停止与问题依赖度崩溃是本轮的因变量。
