## 1. 本阶段的问题及顺序调整

中心仍是写入与旧状态处理怎样形成撤针后的行为效应。S2给出形成来源与时序操作证据，S3回答：**这些形成解释能否预测撤针后具体输出；哪部分已经接到行为，哪部分仍只解释了目标组内部变化？**

S1显示两针都有明显的L16–18状态/读出变化，只有L0首步停止。因此S3不再默认“状态差异大→行为效应大”，也不把负R当保护项。分两步：先检验原生时序操作的连续输出和自由回答；再在确有可分辨输出且数值方法可用时，做原生剂量路径归因。第二步不是第一步自动触发的GPU队列。

研究范围不改变：目标是机制解释，不是修EOS、找更强攻击或重新挑针。能完成的是有边界的局部过程解释＋原生操作的行为因果检验；不能保证给出全模型、与路径约定无关的W/R独立贡献比例。

## 2. 输入与预先冻结的读数

连续读数直接复用S2，避免无意义重复评分：

1. 原首步停止优势D及EOS；另按输入/锚点冻结token e=原S1针条件首步最高EOS、c=原S1干净条件最高非EOS，记录 `L=z_e−z_c`。不能每格重新取e/c，L也不等于所有停止行为。
2. 每事实的正确候选总loglikelihood减另一候选Q，并保留历史S_fact定义、逐token分数、长度与候选共同前缀。Q的后缀评分包含后续更新，不称为纯τ读取。

## 3. S3-A：先检验机制预测能否落到真实回答

### 3.1 在看新增回答前冻结交接表

S2的形成结果和连续L/Q已经可见，因而此时对这些量的解释是拟合/解释证据，不能再称盲预测。**尚未打开的10/01自由回答**才是本模块前瞻检验。交接表每个锚点/情景/时序条件写明：

- S2哪项具体形成/读取证据支持预期，方向是什么，是否跨背景稳健；未分辨或失败直接写明。
- 已观测的首步停止、Q/S_fact，不再包装成S3的新预测。
- 对正确核心、忠实题面、矛盾、未交付的预期及反例条件；不能推出就写“未预测”。不得从Q下降直接推出任务失败。
- 对10/00、01/00、11/10分别作解释；不得只报告有利于原假设的一对。

若完全不能对内容提出预测，仍可报告操作对真实回答的总效果，但必须将“形成到行为的预测解释”标为未建立，不事后补写预测。阶段二结果可以推翻旧读法，不以“非线性”保持原假设永远正确。

### 3.2 实际比较和判读

84个原生状态对应回答：12个共享00，以及两锚点各12×3个10/01/11。旧00/11的36份生成仅在输入、校准、精度、路径、策略/上限及可验证输出身份一致时复用；旧首步/候选相等不是完整生成相等的证明，仍须有对应生成记录与设置。默认新增48份10/01回答。

匿名判读隐藏针位置、时序和机制预测，保留原文、标注身份和分歧；同文本复用标签不算独立重复。6情景逐一列两事实、所有条件与反例，不以token/头/多条同题输出制造样本数。固定候选与自由生成在文字分叉后不继续做同token状态配对；本模块检验的是时序操作总效果。

| 结果 | 机制理解推进到哪一步 |
| --- | --- |
| 10保留后段W/R变化，且预注册内容效应也保留 | 早段操作通过后续持续形成差异并伴随行为效应获得跨层级证据；仍非目标组唯一中介，也非局部自反馈证明 |
| 10形成差异减弱、01近似原11，内容预测也符合 | 当前输入中晚段操作足以重现相关效应，支持近期在场解释；E/L不同针次数不允许推广到语义时段优劣 |
| 同起点ΔH可分辨并进入读取，但回答不变 | 已证明旧来源处理与局部读取变化；尚未证明这部分改变任务表现，保留阈值/天花板等候选解释但不当既定结论 |
| L/Q改变，核心作答不改变或与预测相反 | 指定评分解释与任务机制分离；内容预测失败，不称能力损伤/恢复 |
| 状态变化不大但行为变化大，或两针方向不同 | 范数代理不足；方向、查询/门和其他历史路径仍需解释，不能直接指定某条就是原因 |
| S2局部解释失败而全模型行为效应仍在 | 原生操作有效，但本局部机制链条未闭合。可以形成负面结论，不自动扩层找一个新的热点 |

## 4. S3-B：有条件的过程到输出归因，保留具体设计但不默认执行

### 4.1 进入条件和不会回答的问题

仅在S2完成身份/误差核验、原00/11的L或Q有可分辨差异、且有明确需连接的形成向量时提出运行本模块；是否支持原假设不作为选择条件。所有6情景继续保留，无输出差异者记未分辨而非删掉。若梯度不可信或背景账不稳定，不强行给W/R定量份额。

本模块回答**原00→11效应沿指定剂量路径如何经τ处各缓存进入输出**。它不识别10→11的专属中介，不替代S3-A的时序操作检验，不声称原针整个前缀的W/R自然独立因果效应。若未来要解释另一条时序路径，须单独冻结路径与预算，不能运行后悄悄改称同一个归因。

### 4.2 路径、分组与计算

保留v1的原针全前缀统一强度路径：λ=0、0.25、0.5、0.75、1；用λ乘原固定校准加法，每点从原输入完整前向，τ后撤针。端点用S2同身份完整Mτ；中点不插值缓存。若进行定量归因，固定增加0.125、0.375、0.625、0.875作为4/8小段稳定性检查，不按结果选点、不无限细化。

完整Mτ分为互不重叠的S=L16–18递推、O_KV=全部全注意力K/V、O_conv=全部卷积、O_R=其余递推；审计额外可变状态O_extra及张量别名，固定位置/mask/长度/初始化标记。同一逻辑张量只算一次。离散管理字段不一致或状态覆盖不全则停止。

对相邻真实剂量轨迹，沿整个前缀按S2/S1对称账得 `ΔS_j=Z^W_j+Z^R_j`（从零初态分账，不把S2在τ后重置的W/R拿来混用）。共享β/k同步进入两项，C/T背景账另报。取实际完整缓存作叶节点，权重冻结，仅对τ后的正常读取函数F求各组梯度G；F分别为固定L、Q。

```
C_W = Σ_j <(G_S,j + G_S,j+1)/2, Z^W_j>
C_R = Σ_j <(G_S,j + G_S,j+1)/2, Z^R_j>
C_Og = Σ_j <(G_Og,j + G_Og,j+1)/2, ΔO_g,j>
ΔF_hat = C_W + C_R + Σ_g C_Og
```

必须和真实F逐段变化及总变化比较。这是指定路径的局部线性近似，不是精确恒等式；梯度是在真实状态处求取，但梯度方向本身可离开自然状态集合，不声称消除了反事实假设。沿用v1的Integrated Gradients方法归属，未主张新归因定理。

C_W/C_R仅指**经τ目标递推坐标进入未来输出**的形成分量。目标层在前缀已经影响其他KV/conv/递推的后果会计入O，不能称O与写入/处理无关，也不能把各时间各层的全导数再加一遍。后续更新在F内，因此梯度含该末态对后续计算的直接和间接作用；没有分离成两种独立因果效应。

### 4.3 有界工程门槛与失败出口

先固定VAR01-f0的C、两针λ=0.5/1共5个状态，检查功能化缓存读取与原实现的输出、状态无副作用、固定方向的中心差分和自动微分。BF16的阶梯和cast导数不等于数学真导数；如需FP32代理，另标模型读取近似，须先过原终点/中点误差验收，不通过就停止。方向、步长、同单位误差界须在工程结果打开前写入实施合同；此计划没有伪称它们已验收。

- 每个相邻段的残差均展示；小段残差绝对值之和须≤`max(10×工程误差界, 0.05×真实小段变化绝对值之和)`，要解释的效应须高于误差。
- 4/8小段各分组归因变化≤分组绝对量总和的5%；分项符号/背景依赖完整报告。不靠不同小段正负抵消让总和“过关”。
- 通过总量闭合仍不证明各分项具有唯一自然因果意义；还需要梯度验收、完整状态覆盖、分项稳定性。
- 不稳定、梯度不可信或原/代理输出不符：结果写“此方法在当前实现下不能可靠连接过程与输出”。保留S3-A的行为证据，不自动改精度、加剂量、换窗口。
