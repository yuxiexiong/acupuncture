# 本轮官方依据

使用 [ICML 2026 主会审稿规则](https://icml.cc/Conferences/2026/ReviewerInstructions)，与前次采用的规则一致；本轮重新下载，抽取文本哈希与前次相同。官网文本给三人各一份，完整原文不转载入Git。来源、下载时间和哈希见 [sources.json](sources.json)。

[ICML 2026 LLM policy](https://icml.cc/Conferences/2026/LLM-Policy)用于区分作者侧AI模拟与正式会议审稿身份。此处没有受会议指派，不能代填正式履职合规声明。四项质量1–4，总推荐1–6，信心1–5；各人按官网锚点评分。
