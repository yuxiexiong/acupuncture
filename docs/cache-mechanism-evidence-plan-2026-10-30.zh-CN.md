## 1. 核心判断与排序

**最缺的不是再证明缓存有影响，而是把“少数通道干预→具体状态写入→撤针后读取→可解释终点”接成能被反驳、能预测新条件的因果链。**

采用两个锚点，避免把所有现象强行解释成一件事：

- **行为锚点：L0/C4146，−1。** 新题全受干预状态下 24/24 未交付；全局递推＋短卷积恢复使停止优势 D 减少约 16.4，但最佳单组只减少约 3.2，并将事实跟随从 0/24 提至 7/24。需要解释真实停止及其分布式承载。
- **计算锚点：L12/C3621，−1。** L16–18 递推状态单独替换对事实敏感度 S 有约 +5.27/−5.75 的双向作用，但中晚层角色在新题上仍有 96–100% 事实跟随。适合解释候选偏好的计算变化，不能冒称已经定位事实作答失败。该单组件结果仍属探索性。

上述数字来自[固定提交结果报告](https://github.com/yuxiexiong/acupuncture/blob/73185a40de0c779d55beac204c7d46683736b5ef/experiments/early-state-localization-stage2-v2-2026-10-30/REPORT.zh-CN.md)，不是本轮重算。

| 优先级 | 独立计划 | 要补的决定性证据 | 为什么排这里 |
| --- | --- | --- | --- |
| P0 | A：行为与读数对账 | 停止阻断、生成异常、明确错答与阈下分数变化的区别 | 决定机制究竟要解释什么，防止把 S 当能力 |
| P1 | B：替换效应的可信性 | 排除操作错误，检验混合状态不一致、一般扰动与补偿解释 | 决定现有恢复/污染能支撑多强的中介主张 |
| P2 | C：写入—保持—读取计算链 | 找到可被局部干预、可预测读数变化的运算 | 科学贡献核心；不能停在定位图 |
| P3 | D：撤针后的持续与消退 | 在相同文字下测出写入窗口、状态寿命与再次读取 | 将单个提示边界效应推进成时间机制 |
| P4 | E：留出条件上的机制预测 | 对新题、通道、剂量作预先预测，报告失败边界 | 区分可复用解释与两个热点的事后故事 |

这里排序是证据依赖，不是把科学价值最高的 C 拖到最后。A 离线对账时即可准备 B/C 的实现审计和近邻计算映射；正式推理各有独立合同和授权，不自动串联。

## 2. 计划 A（P0）：先确定真实行为问题

**问题：L0 是主要被首步停止挡住，还是即使开口仍不能正确完成任务？L12 的 S 下降对应哪种答案偏好变化？**

### 最小工作与对照

1. 承接既有 [E00 方案](../experiments/cache-behavior-validation-v1-2026-10-30/e00-existing-evidence/PLAN.zh-CN.md)，先用已有四个入选条件的全部相关臂做逐条来源对账：题目、D/S、候选排序、生成 token、结束原因和全文标签。不新增被测模型生成；缺原始记录先取回并核验来源，不能由报告均值倒推逐题结果。
2. 分开列出未交付、交付后错误、循环/截断、正确核心但附错、正确完成；同时展示分数变坏而回答仍正确的案例。保留原标签，修订另存，不能覆盖旧阅读。
3. 新推理优先承接 [E01 首步 EOS 解除](../experiments/cache-behavior-validation-v1-2026-10-30/e01-eos-only/CONTRACT.zh-CN.md)：干净/受干预状态 × 原始解码/仅首步屏蔽 EOS，四臂均保留。只屏蔽首步，第二步起恢复原规则；D 取屏蔽前数值。
4. 需要区分首步阻断之外的状态作用时，分别承接 E02 递推、E03 短卷积、E04 KV；E05 联合清理只回答组合是否有额外价值。它们是独立问题，不要求五项全部跑完才推进计算分析。

### 主要终点与判读

主要终点沿用已有合同：一对相反事实版本均正确完成的情景比例 P；另报交付、交付后正确、第二步停止、矛盾、重复、截断和候选排序。D/S 只辅助。

- 仅解除首步 EOS 就恢复正确完成，并通过干净对照的保留检验：支持停止阻断有主要解释力，但没有说明停止倾向如何写入状态。
- 能开口但仍反复停止、循环或答错：还有未解释环节；一次 EOS 屏蔽失败不能证明信息已丢失。
- 缓存清理在同样屏蔽首步 EOS 后仍提高 P：支持超出首步阻断的作用；须进一步区分少循环与明确错答转正确。
- L12 只有 S 改变而 P 保持：将其正式作为阈下候选响应机制，不追求把题目或剂量改到必然失败。

### 验收、成本与依赖

交付逐条对账表、类别转移表、候选与自由输出的不一致表和主张降级表。完成应以分类和证据完整为准，不要求得到“能力受损”。新题阅读执行既有人工审核要求；无人审时只能交付模型辅助暂定结论。

E01 既有草案为 96 基础情景/192 输入、四臂共 768 生成；原车队预留 11 个优效比较的校正额度不因优先只做部分项目而回收。本文不修改其题量、门槛或功效主张；若决定换设计，另版合同，不能静默改旧版。E00 零新增被测模型推理，不等于零分析人力。

## 3. 计划 B（P1）：替换恢复是否反映原运行中的作用路径

**问题：观察到的效果有多少是目标状态差异，有多少可能来自不一致状态组合、任意大扰动或干净供体的补偿？**

### 最小工作与对照

1. 先核验旧实现与来源，不重跑全层扫描。取回冻结清单与验收收据，核对模型、hook 时序、缓存管理字段、深拷贝以及 C/C、T/T 恒等对照。旧记录足够则复用；仅缺失项进入有界预检。
2. 固定两个锚点，各比较完整 C、完整 T、原位同来源替换、目标组件清理及反向污染。供体始终来自同一输入、同一事实版本、同一 token 位置，不能用不同自由回答的缓存拼接。
3. 增加“沿计算过程重新生成”的对照：在选定写入位置纠正更新，再让下游状态按模型原运算生成，与直接换入最终缓存比较。它不能保证完全消除分布外问题，但能检验结论是否仅依赖一次不一致的终态拼接。
4. 一般扰动控制在**MLP 投影后的实际向量空间**匹配范数、位置和 token 支持；并测方向差异。不能仅匹配通道数或标量剂量。另设状态空间随机差分对照时，应匹配组件和差分范数，明确其仍可能分布外，不作为唯一裁决。
5. 固定弱剂量梯度检查自然形成的 T 状态与恢复效果是否一致变化。新梯度另行冻结；原 −1 锚点保留，不因新结果弱而改强度。

### 验收与结论边界

报告真实状态差分、匹配对照、直接替换与顺序重算的 D/S 和行为效应及不确定性。若同来源替换不恒等，先解决工程问题；若工程正确但两种干预路径明显不一致，保留差异，暂时收窄为“指定混合背景下的因果效应”。

如果匹配随机方向也产生相似现象，优先解释为较一般的扰动/状态传播规律，不再声称通道具有特殊语义。即使所有控制通过，也不证明唯一中介或没有补偿；只能提高该路径解释的可信度。

交付一份竞争解释对照报告；不以恢复率越高越成功。B 的原始/清理/污染参照与 A 身份完全一致时才复用，引用均值不算复用。新臂数量在实现审计后有界冻结。

## 4. 计划 C（P2，科学核心）：从状态位置推进到具体计算

**问题：干预改变了哪些 token 的写入，哪些变化被保留，又通过哪些查询、门控和下游路径影响输出？**

### 近邻起点

[What Attention Recalls and Recurrence Controls](https://arxiv.org/html/2609.04434) 已做缓存类型与功能对照，适合当粗粒度解释参照；[WriteSAE](https://arxiv.org/html/2605.12770v4) 已分析递推写入及其对输出的影响。本计划借用其可适用计算关系，先核对冻结模型的实际递推公式、归一化、门控和执行顺序；不默认其他设置的公式或拟合精度可以直接迁移，也不以训练 SAE 为前置要求。

### 最小工作与对照

1. 首先研究 L12→L16–18 的递推路径，因其组级效应集中、终点明确。逐 token 保存进入递推更新的量、更新前后状态、查询/读取输出和门控；只在锚定层与必要的下游读出采集，避免再次全模型全通道穷举。
2. 在旧开发题上区分“写入变化”“保留/衰减变化”“读取变化”。比较干净和受干预运算，将具体因素作单独和必要的联合替换；替换后重新向前计算，不拿隐藏态距离直接当作用大小。
3. 对开发阶段选定的 token 窗口与层，做阻断目标写入差异、反向引入该差异、以及恢复原路径的对照。先验证状态更新重建和局部输出，再检验最终候选 logit/对数似然变化。状态差异最大的位置不自动等于最有因果作用的位置。
4. 分解预测先在固定前缀、固定候选上验证。多 token 候选按真实 teacher-forcing 序列逐项计算，不把一步 logit 近似直接当整条 S。若依赖固定门控、固定读者或局部线性近似，明确条件并单独测近似误差。
5. 锁定计算关系、参数、所选窗口及预测方向后，在未用于选点的新题上检验；预测误差、符号准确性和校准同时报告。与“只看状态差分范数”和“只看插针深度”的简单预测比较，防止复杂解释只拟合幅度。
6. 再将同一分析思路用于 L0 停止：区分 EOS logit 增加和非 EOS 竞争项下降，检查跨层共同承载。不能因组 4 排名第一就预设单一停止中心；仅在单组解释不足时增加预先指定的多组联合对照。

### 验收与失败分支

最低有意义产出是：一段明确写入—保持—读取关系，局部干预对该关系的支持，以及独立题上的方向/幅度预测和失败范围。可报告“近邻公式在本条件有效”或“某项近似在强干预下失效”，不要求创造新公式。

只有相关性、热点或事后拟合不能完成 C。阻断和反向引入只支持指定背景下的条件性作用，不包装成全局必要/充分性。若 S 可预测而真实行为不可预测，应分开报告；L0 不成立不抹除 L12 的有限计算结果。

每个锚点单独交付分析与合同；L12 的计算探索无需等所有行为车队结束，确认性新题必须在开发选点后隔离。细粒度记录的显存/磁盘和逐 token 前向成本应先小规模测速，不能套用旧批次的 GPU 小时。

## 5. 计划 D（P3）：什么时候写入，撤针后保持多久

**问题：当前证据限于整个 prompt[:-1] 受干预后的一个边界，尚不能回答短暂写入的时间窗、寿命与消退机制。**

### 最小工作与对照

1. 在固定锚点上比较相同长度的早/中/晚写入窗口，撤针后馈入相同的固定 token 序列；另保留原全前缀干预作为历史锚点。写入窗口长度匹配，不能把“更早”与“累计更多次注入”混为一谈。
2. 在预先固定的若干间隔读取三类状态差分、C 预测的机制量及 D/S，再分别自由续写。给定文字的对齐路径回答状态持续性；自由续写回答自然行为，两种证据分开。
3. 用冻结实现的短卷积窗口长度确定至少一个超过该窗口的测量点，检验短卷积槽被覆盖后递推/KV 中是否仍有作用。不预设卷积槽消退就等于整体效应消失。
4. 在相同 token 历史与相同位置比较“继续干预”和“停止干预”；分开估计历史状态效应和新增干预效应。对不同自由生成文本不能直接交换缓存并归因于撤针。

### 验收与失败分支

交付按 token 间隔的状态/读数/行为曲线、窗口匹配对照以及来自 C 的事前预测误差。持续性不必单调，不强拟合单指数或宣称统一半衰期。强制续写的结果不能直接外推成自然对话中的同等持续时间。

若效应只在临近提示末尾的短窗口出现，收窄为边界局部效应；若长期存在，须确认仍由已识别状态路径解释，不能仅凭输出持续异常下结论。D 可独立结题，但复用 C 的机制量才更有解释价值。

## 6. 计划 E（P4）：用留出条件检验机制是否可复用

**问题：获得的解释能否事先判断其他干预何时产生状态效应，而不只解释两个选中的极值？**

### 最小工作与对照

1. 先在 Qwen3.5-4B 内验证：未用于选点的新题、按事先规则抽取的额外通道、固定正负方向与剂量。通道抽样保留无效点和反例，不只增加强效点。
2. 冻结 C/D 给出的可计算预测：例如哪些写入差异被保留、哪些会被查询读出、效应方向与相对幅度。预测使用的信息必须先界定；允许读取干预的中间量，但不能偷用待预测的最终 logits/答案。
3. 与简单幅度/深度基线作同样留出比较，按基础情景及通道分组汇总，不能把共享题面的 token 当独立样本。开发与确认的数据、调参预算和失败点完整保留。
4. 仅在模型内关系成立后，选一个第二模型检验相同计算关系；对齐架构、状态类型与有效扰动，不迁移通道编号或直接照搬剂量。跨架构属于进一步扩展，无需一次覆盖全部模型。

### 验收与结论边界

交付冻结预测清单、留出预测结果、简单基线差异、反例和适用范围。若只在原两个点成立，就报告两个有边界的机制案例；若模型内成立而跨模型失败，就限定模型/架构，不换模型直到成功。

本计划是贡献范围的检验，不是“多做模型就更强”。精确题量、通道数和最低有意义预测改善应根据开发方差与预算，在接触确认输出之前冻结；当前不编造功效或总卡时保证。

## 7. 共同冻结要求与推进关口

- **研究单元：** A–E 是五个独立问题，A 下已有 E00–E05 各自身份保留。不会把一项成功补成另一项成功，不建立自动总队列。
- **来源：** 沿用模型 revision、校准和 hook 的确切身份；新采集需独立版本目录、代码/题目/条件哈希、退出和成本收据。历史权重、题面、剂量与原始回答不覆盖。
- **统计：** 历史确认性比较与探索性组件结果分开。新实验按基础情景配对，事实变体在情景内；共享面板的检验家族提前定义，不因拆合同回收多重比较额度。报告绝对效应与区间，避免小总损伤分母的“恢复比例”。
- **测量：** D=max EOS logit−max 非 EOS logit；S 保持原候选差之差；不把 D、S、P 合成一个模糊成功分数。未显著不是零效应，未下降不是等效无损。
- **选择：** 旧数据只作开发和历史复核；候选锁定后才开放新题结果。任何结果驱动的额外层/窗口/公式作为探索，独立确认另列，不事后改冻结规则。
- **资源：** 每项先明确有界臂数、生成/评分/内部前向与状态快照规模，再根据新实现预检估墙钟、GPU 占用及磁盘。旧批次 5.19 小时墙钟不能外推细粒度机制研究；当前没有新运行预算承诺。

建议推进关口：**先完成 A 的旧证据对账；优先冻结 E01 与 B 的最小对照；同步准备 C 的 L12 计算分析；待路径解释有支撑后做 D；最后以 E 判断可复用程度。** 如果 A 表明主要是停止门控，C 仍须解释为何历史状态改变停止竞争；如果 L12 始终没有行为失效，其阈下计算机制仍可研究。
