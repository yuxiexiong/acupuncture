编号：CFM-FORM-AB-v1-20261031。日期：2026-10-31。

状态：**设计逻辑自查通过；实现与数值验收未完成；未冻结运行合同，未执行模型或 GPU。** 本文是依据[自查规范 v1](experiment-design-self-check.zh-CN.md)对对话中 A/B 建议的修正，不替换历史冻结协议。自查及反方检查均由同一设计者完成，不称独立审查。

**推进判断：值得进入代码实现与工程验收，尚不能直接开始正式采集。** 价值在于从 E2 的末端承载定位推进到深层效应的形成条件；不以本轮识别完整原生机制为前提。进入实现前将继承参数、hook 时刻、读数与成本上限逐项写入运行合同；正式采集前通过第 8 节验收并具备运行授权。无需为进入编码继续扩大科学矩阵。文档推送不等于代码完成或开跑授权。

## 1. 本轮仍回答什么

总问题仍是：针如何改变模型内部计算，经过写入、旧状态处理与读取，造成显著回答变化？

本轮问：**针经过浅层后形成的深层缓存效应，对两种操作分别有多敏感：抵消进入深层的原始加法增量，以及让浅层每一步读到的过去缓存保持干净？**

这是对深层效应形成条件的干预检验。它从 E2 的“深层缓存能承载多大停止分数偏移”推进到“哪些形成过程的改变会改变这份效应”。本轮不承诺把原生作用唯一拆成直接传递、浅层记忆和非线性放大三份，也不把停止分数作为课题总目标。

## 2. 依据、未知及新颖性边界

- E2 固定来源：提交 `b28fb8300adf9289514caddd9331676da261863c`，目录 `experiments/cache-formation-mechanism-e2-depth-transplant-v1-2026-10-31/` 的 CONTRACT、REPORT、judgments 与 verification。该版本只完成 E2，E1 未运行。
- E2 在干净浅层背景中保留 L0 晚段针形成的深层缓存，保留约 75%–94% 的停止分数偏移；这些混合运行的首步 EOS 为 0/12。原生 L0·01 为 8/12。因此本轮最直接追踪的是连续分数效应，不能宣称正在解释一个混合背景中已经出现的停嘴行为。
- S2/S3 提供过程变化和卷积前 V 的条件性输出证据，但不能直接证明本轮两种操作沿原生 V 路径起作用。S2/S3 的变量、层范围与背景不同，不能拼成已闭合的中介链。
- 加法残差允许定位原始增量的显式加法项；浅层分支已经对受扰输入作出的响应不会因末端减法自动撤回。共享变量的作用不靠分别拼接或补偿拆开。
- “L0 注入绝对范数更小、效应更大”可提出选择性处理假说，不能证明增益放大：注入层、方向、后续处理和读出敏感性都不同。
- 缓存交换、写入干预、写入/保留/读取分解已有近邻工作；本轮不主张方法首次。增量仅是对本项目特定针效应形成条件的约束。论文层面的新颖性需另按最终发现与直接近邻比较，不由本次设计审查授予。

已有末端缓存不能重建所有逐位置干净浅层状态和实际注入差分，故旧数据能支撑问题及参照，不能替代这次尚未授权的新运行。缺失记录应先核查归档；可复用则不重跑。

## 3. 保留 A/B 四格，修正实际操作

沿用 E2 的模型修订、针坐标与剂量、输入、分词、事实对、晚段 01 时窗、层编号及首步评分边界；执行前从固定合同逐项展开到新合同，不能凭本段简称猜参数。使用已见过的六情景及各两个事实版本，标为探索性复用；两个事实不是两个独立情景。

记干净运行为 C，L0 晚段针运行为 T，最后一个已处理前缀位置为 τ。全文“第 13 层入口”使用 E2 的实际代码层索引；不是自然语言层号加减一。评分处理的下一个共同输入 token、位置和掩码亦沿用 E2。

| 运行 | 形成期 A | 形成期 B |
|---|---|---|
| X_none | 无 | 无 |
| X_A | 有 | 无 |
| X_B | 无 | 有 |
| X_AB | 有 | 有 |

另有 C 作干净参照。不用 00/01 命名这四格，以免与原早段/晚段时窗混淆。

### A：抵消进入深层的显式增量

在每个晚段前缀位置 t，记录 T 与 C 在第 0 层干预后的残差输出差 δ₀(t)。须先验证这两条运行在该层针前输入相同，且差值对应实际针及其当步舍入，不拿全局校准范数或近似权重向量代替。

在第 13 层归一化之前，从当前残差中减去 δ₀(t)。其他浅层响应已经发生，深层随后正常计算并写入缓存。固定前缀 token 下，A 在深层、B 在第 1–12 层，均不反馈改变第 0 层当前输入；该前提须由实现确认。

它问的是“在已发生浅层响应的背景下，抵消这项增量会怎样改变深层形成”。它不是重新运行一个从未受针的浅层，也不定义原生直接效应份额。减法和舍入规则须在工程验收前确定，不宣称有限精度下口头上的精确抵消。

### B：固定浅层每一步读到的过去状态

在每个晚段位置 t、浅层第 1–12 层处理当前 token **之前**，把该层过去的递推状态、短卷积缓冲或注意力过去 K/V 换为 C 在同一位置边界的对应状态。每种层仅替换其实际拥有的缓存；长度、位置索引、掩码保持对齐。

当前 token 的 q/k/v、门、输出及 MLP 由接收运行正常计算，不换成供体的当前投影。当前更新正常发生；到下一个位置，再把浅层过去状态固定到该位置的 C 参照。深层过去状态不替换。

因此 B 阻断的是**受扰浅层过去状态值在后续位置被读取**。它仍允许当前受扰残差与干净过去状态相互作用，也允许深层积累自己的受扰历史。B 不等于“所有记忆都干净”，不等于只换写入变量；它也不是原生轨迹。

不独立交换 k/β 在更新公式中的不同用途，不为保持 βv 而补偿 v。由当前输入得到的共享变量在各用途上保持一致。缓存和当前输入仍可能不匹配，这限定结论为受控背景依赖；不据此声称恢复了自然机制。

### 评分背景：四格统一

到 τ 后，所有格均使用 **C 的第 0–12 层缓存 + 本格形成的第 13–31 层缓存**。随后关闭 A/B 和针 hook，处理同一个评分输入，读首步 logits。

这一步沿用 E2 的深层缓存比较背景，避免把 B 对最终浅层读取的直接影响误判为深层内容形成效应。X_none 应复现 E2 对应混合格，而非原生 T；不得用原生 T 的分母冒充本轮参照。

共同的是浅层缓存和外部输入，不是所有深层查询及读出变量。深层允许正常响应；本轮测的是不同形成过程得到的深层缓存，在统一浅层背景中的条件性输出效果。它不是“仅写入不改变读取”的纯效应，也不能自动解释完整自由回答。

## 4. 读数与结果解释

主读数沿用 E2 的停止分数 D 原定义；首步 EOS 单独报告。按每条输入列原始 D，汇总以六情景为单位，事实对保持配对。不进行自由生成，不把本轮称为完整行为验证。

可辅助报告 R_X = (D_none − D_X) / (D_none − D_C)。分母为零时标不可定义；分母小、异号、超出 0–1 均显式保留，主要判断回到原始差值。恢复比例不是自然机制占比。0.3/0.7 若沿用只作描述分段，不作显著性或唯一机制判据。

| 结果 | 有效认识 | 不允许推出 |
|---|---|---|
| A 明显改变效应，B 很小 | 在已形成浅层响应背景下，入口增量抵消能改变深层所承载的效应 | 原始针直接传递是唯一原因；浅层处理没有作用 |
| B 明显改变效应，A 很小 | 固定浅层过去状态改变了深层效应形成，提供跨位置浅层历史参与的受控证据 | 原生效应必然沿同一条历史路径；全部来自旧状态处理 |
| A/B 都有作用 | 深层形成对两种操作均敏感；比较各自另一条件下的效应 | 把恢复量分成两份可相加的自然贡献 |
| 单独弱、联合强，或异号 | 存在背景依赖或联合敏感性；保留四格及交互 | 交互就是某条特定递推计算机制 |
| A/B 及联合都弱 | 这两种操作未明显削弱该背景中的深层效应；原三分解释不能由本实验建立 | 剩余一定是浅层同位置放大 |
| 各情景不一致或读数接近误差 | 本轮证据有限或不可判，报告完整分布 | 改题、换剂量或筛掉不利情景来救假说 |

改变方向可以是削弱、增强或反转；反向结果同样更新认识。没有结果会自动触发全层扫描或另一实验包。若两项均弱或不稳定，本轮结束，不把未解释部分改名为发现。

## 6. 反方检查及处理

**即使 B 有效，会不会只是缓存与当前输入拼接失配？** 会存在这种替代解释。因此只能声称该受控过去状态操作改变了深层形成，不声称发现原生唯一通路。该结果仍比 E2 的末端承载定位多一条形成条件约束；若研究承诺升级为原生中介归因，当前设计不通过，不能只改标题。

**A 有效会不会是深层读出对新方向的响应，而不是阻断原直接路径？** 可以。本轮不把数值抵消当路径删除；它检验该精确定义入口操作对后续深层形成的效果。

**A/B 都弱是否其实说明残差分支完成了放大？** 不足。补偿、深层历史、相互作用和剩余方向均未被排除，已删除该判据。

**统一评分背景会不会又变成只研究混合模型？** 是明确的条件性比较，目的为接续 E2 的已知深层效应。不能把结果无条件推广到原生行为，但没有因此改变总课题。若这个边界不满足后续原生机制主张，应另补证据，不假称本轮全部完成。

**是不是降低结论就让任何实验过关？** 不是。本轮仍作出可失败的实质承诺：在相同评分背景下，测出两种不同形成操作是否、怎样改变深层效应；若操作不能隔离其命名的对象、共同背景不能实现或参照不能复现，设计/实现必须停下，不靠限定词通过。

## 8. 执行边界与成本

科学比较为每个输入 C + 四格，共 12 × 5 = 60 个前缀运行条件及对应首步评分。先复用有效归档；干净逐位置参照和实际 δ₀ 捕获计入这五种条件，不另隐匿捕获成本。该数字不是 GPU 耗时估计，逐步缓存固定可能改变吞吐。

工程验收尚未实施，不能因设计通过而跳过：

- 原生 C/T 及 X_none 在选定执行路径上复现 E2 对应参照；分块与逐步执行、dtype 或算子差异不能静默混用。严格一致与数值容差的项目、依据在看到科学效应前固定；失败先处理实现，不解释机制。
- 检查 A 的针前相同输入、δ₀ 记录位置、实际减法与舍入；检查 B 替换的是 t 前缓存，未误植当前 token 投影、长度或索引。
- 检查当前共享变量各用途一致、无别名污染供体；评分时浅层缓存逐项来自 C，所有干预 hook 均关闭，深层取自本格。
- 无操作重放须一致；可选 L12 抵消只作为有明确定义与数值误差要求的工程校验，不加入科学机制判读。

工程重放/失败重跑的数量和耗时尚未核定，正式执行合同须另外列上限并计入总预算，不把“60”当全部成本。无需为此现在启动任何模型。当前用户要求仅文档与设计审查，不授权 GPU、自由生成或新增模型运行。
