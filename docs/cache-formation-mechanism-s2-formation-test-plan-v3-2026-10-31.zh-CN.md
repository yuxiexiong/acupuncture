## 1. 主线核对：本轮仍在回答什么

**中心问题不变：暂时的稀疏激活干预，怎样改变每步写入的信号，以及已有信号的保留、衰减和修正；这些变化怎样形成撤针后的状态与回答效应？**

## 4. 主要分析一：共同起点后的第一步与旧来源轨迹

采用S1的key×value方向：`S_t=A_t S_(t−1)+B_t`，`A=α(I−βkkᵀ)`，`B=βkvᵀ`。B称**加性写入项**，不是语义上“新增知识”的净量。共享β/k同时改变写入与扣除旧预测；两项抵消可能只是同一次delta更新的两个部分。

### 4.1 第一更新步，不混入先前状态分离

对01/00、11/10，预先固定报告t=b+1，不按最大效应或首次显著位置选择。理想共同状态S_b下：

`ΔS_(b+1)=ΔA_(b+1) S_b+ΔB_(b+1)`。

分别测量B的变化、A对**这同一份S_b**的作用变化，以及它们的方向/抵消。实际核验始终用完整式 `ΔS=ĀΔS_b+ΔA S̄_b+ΔB`，把可分辨的起点差异与重建误差列出；不能直接丢掉残差来制造同起点结果。

- `ΔA S_b`非零：处理算子变化确实作用到了这个共同旧状态；不是仅因两条轨迹此前状态不同。
- ΔB非零：该步加性写入项不同；不代表产生了独立的新语义内容。
- 两项都变：共同起点这一更新同时包含两类变化，不能按较大项判独立主因。
- ΔA非零但`ΔA S_b`不可分辨：算子变了，但没有在这份旧状态上分辨到作用；不得等同“旧信息已被改变”。

这比不同历史末态比较更严格，但仍是自然共变下的过程拆解，不是只改A或只改B的反事实实验；同token的跨层传播也包含在真实A/B中。第一步无可分辨效应就如实记录，不把后面最大效应步骤改称第一步。

### 4.2 逐步追踪同一份旧来源，而不是只看终点

各实际轨迹从b设 `H_b=S_b,N_b=0`，递推 `H_t=A_t H_(t−1)`、`N_t=A_t N_(t−1)+B_t`，逐步核验`S=H+N`。H标记b时已有来源；N标记b后写入来源。两者只做离线分析，不喂回模型；H不等于事实知识，N也不等于新知识。

对两种同起点配对，每一步报告：

```
u_B,t   = ΔB_t
u_H,t   = ΔA_t H̄_(t−1)
u_N,t   = ΔA_t N̄_(t−1)
ΔH_t    = Ā_t ΔH_(t−1) + u_H,t
ΔN_t    = Ā_t ΔN_(t−1) + u_N,t + u_B,t
```

由此分清：当步改变加性写入，处理变化作用于b时旧来源，还是作用于后来写入的来源。各步u及ΔH/ΔN全保留，报告范数、有符号读取投影、起止位置和抵消；不以整个窗口只剩一个总值替代。

H变化说明共同旧来源沿实际算子序列受到了不同处理；它不证明处理变化是原针的独立原发机制。早先写入变化可能通过后续计算影响A，H分解仍条件于各自真实驱动。H末态相等不能排除途中不同；逐步H相等也不证明A完全相同或对其他信号没有影响。

## 5. 主要分析二：早段撤针后的逐步变化

对10/00从b后起，逐步记录 `ΔB_t`、`ΔA_t`及其实际作用 `ΔA_t S̄_(t−1)`，直到τ、t_L及各固定候选位置。10/00在b不共享状态，不能套用4.1，也不能把它的ΔH全称为处理变化。

若10撤针后仍有ΔB，则说明**早段操作足以在该条件、该位置造成后续加性写入项差异**，排除“形成这种差异必须有后段针在场”。逐步处理源项同理报告。它不识别源头究竟是哪类上游缓存、不证明目标层局部自反馈，也不证明这些变化对回答必要。单个位置非零不命名为整个后续阶段“持续重写”；必须给出覆盖位置及衰减/间断情况。

三项累计账降为辅助摘要。对指定边界c（b或τ）设：

```
D_c = ΔS_c, W_c = R_c = 0
D_t = Ā_t D_(t−1)
W_t = Ā_t W_(t−1) + ΔB_t
R_t = Ā_t R_(t−1) + ΔA_t S̄_(t−1)
ΔS_t = D_t + W_t + R_t
```

- D是平均算子下传递的边界差异，不是“干净规则下的纯被动遗留”。
- W也经过后续算子处理，不能称纯写入独立效应。
- R作用于每步当时的全部状态，包含b后新写入的内容；它不是专门处理原始旧记忆的账。共同起点的旧来源应看第4节H/u_H。
- W或R末态小，可能来自时间抵消或衰减，**不能判途中没有该过程**。两项合计小也不说明各项小。
- 不以累计W/R或D接近总差异认证“被动延续”。只有逐步源项均未分辨，且原始算子/写入检查与整段差异传递相容，才可说“在所测轨迹、时窗与精度下，未发现偏离共同算子传递的证据”；不能证明精确为零。算子不同但作用落在零空间时，还须区分算子不变与对当前状态作用未分辨。

保留S1的C背景、T背景及对称账作为敏感性报告。改变背景改变份额时，直接记录约定依赖；即使三种账结论一致，也不自动升级成独立因果贡献。α衰减与β/k定向修正细分仅是可选离线附表，不扩展门控实验，也不替代主要的共同旧来源检验。

## 6. 结果—解释排除表：按实际轨迹、时窗和精度结案

下表所有“非零/改变”均要求通过第8节同单位误差核验。排除的是具体计算解释，不是其更宽泛的因果版本。

| 待检验解释 | 足以反驳它的结果 | 不能据此声称 |
| --- | --- | --- |
| 共同起点后的第一步仅加性写入项不同，旧来源处理作用相同 | 同起点认证后，`ΔA_(b+1) S_b`可分辨 | A独立导致最终回答，或A变化不是同一共享变量变化的结果 |
| 在观察窗口内，b时那份共同旧来源始终受到相同处理 | 任一实际位置ΔH可分辨；同时给出u_H及完整轨迹 | 事实记忆被删除；若仅最终ΔH为零则不能支持此解释 |
| 当前窗口的差异只涉及处理变化，B始终相同 | 任一实际位置ΔB可分辨 | B是原发原因、具有独立行为效应，或排除“处理变化先引发后续B变化” |
| 后段的加性写入项差异必须依赖后段针在场 | 10/00在b后某位置ΔB可分辨 | 已证明整个11效应不需要后段针，或已找到维持差异的缓存路径 |
| 当前窗口只有相同A/B下的旧差异传递 | 逐步A或B本身有可分辨差异，反驳严格算子不变；逐步作用源项可分辨，显示当前状态上的过程变化 | 这些源项不可抵消，或最终状态/行为的变化必须依赖它们 |
| 没有发生写入/处理变化，因为末态W/R或ΔH很小 | 中途源项或ΔH可分辨，即使后来抵消 | 小末态能证明过程缺席；不得再采用v2的这一判据 |

若逐步ΔB未分辨而u_H/ΔH可分辨，可支持“本窗口分辨到了旧来源处理变化，未分辨到加性写入变化”，不能说全模型只有处理机制。若ΔB可分辨而u_H/ΔH全程未分辨，可说“本窗口共同旧来源上未分辨到不同处理”；还须检查u_N，不能据此排除对新写入信号的处理变化。

无论结果如何，以下问题仍不由本轮识别：共享β/k的独立W/R贡献；写入改变和处理改变中谁是原发原因；所有跨层直接/间接路径；L16–18对回答的必要性/充分性；整个模型的唯一机制。部分计算解释被排除后，可以保留多个未区分解释，不硬判主因。

## 7. 局部读取与既有时序预测的地位

每一步按实际q报告 `Δo=ΔSᵀq̄+S̄ᵀΔq`。状态项继续用H/N或D/W/R拆分，但须并列查询项；gated norm、out_proj及边界隐藏输出另作实际观测。raw读取项可以精确记账，不等于对后续非线性层和回答的归因；负R不能命名为保护/修复。

v2事前登记的时序预测全部保留为次要预测，不改阈值、不替代第4—6节的过程目标：

- 在t_L报告`r10=||S10−S00||/||S11−S00||`；S1预测r10<0.5。≥0.5只反驳这一数量预测，不能单独判定哪一过程造成它。
- 报告`a01=<ΔS01,ΔS11>/||ΔS11||²`、`e01=||ΔS01−ΔS11||/||ΔS11||`；v2约定a01≥0.5且e01≤0.5称目标状态近似重现。范数相近但方向不同不算重现；近似重现不是行为充分性。
- 保留L0的r10高于L12的逐情景预测；失败或异质性照实报告，不改写为普遍自维持机制。

所有比值给原值及误差；分母不可分辨不算比例。合并层/事实时用等权堆叠向量求范数与内积，防止先平均向量把反向差异抵掉；同时报告分层、分事实结果。六基础情景逐一列出，不用头/token当独立样本，不设“多数通过即机制成立”。

## 8. 误差、记录与科学验收

沿用S1状态/原生raw读取重建相对容限1e−3/1e−2，作为工程上限，不当作所有分项统一的检测阈值。对ΔB、ΔA作用、H/N及读取分别记录同单位绝对误差；根据记录精度、b态重建误差和递推误差传播建立分项界，并用固定重复路径校验。仅有末态重建误差小，不足以证明每一过程项精确。
