# 下一阶段建议：全深度剂量单位、输入依赖崩溃判据与安全剂量上限表

日期：2026-10-28（北京时间）。状态：**建议稿，未冻结合同，未授权运行。** 依据为本仓库既有 18,272 份单针回答、7,632 条内部轨迹的零 GPU 再分析（脚本与输出见 [experiments/early-layer-question-dependence-v1-2026-10-28/](../experiments/early-layer-question-dependence-v1-2026-10-28/)）与 [七步查重报告](literature/dose-calibration-related-work-audit-2026-10-28.zh-CN.md)。

全文按三档标注：**推导**（有论证链）、**类比**（有邻域证据，跨域未验证）、**推测**（需独立验证）。

## 0. 一句话

早层扎针后的空答与循环不是"语言组织区"受损，而是现行剂量单位在早层把上下文抹平；下一阶段要造三样东西：**覆盖全深度与注入位置的剂量单位、看得见"输入失明"的崩溃判据、四模型全层的安全剂量上限表**。这是对 Liu（[2606.19831](https://arxiv.org/abs/2606.19831)）控制窗定律的补全，不是证伪：新单位必须同时拟合他的中后层数据和本项目的早层数据。

## 1. 为什么换方向：早层现象的再解读

### 1.1 现有数据说了什么

对每个（模型，层，通道，+1）条件，数八道题干预后回答的**不同首 token 数**。原版八题首 token 各不相同（8 种）。若只剩 1 种，说明输出已不依赖题目。

| 层 | 2B：八题同首 token 的通道数 /10 | 4B | 9B | Llama-3.1-8B |
|---|---:|---:|---:|---:|
| L0 | 5 | 9 | 9 | 2 |
| L1 | 1 | 7 | 5 | 0 |
| L2 | 3 | 3 | 6 | 0 |
| L3 | 1 | 0 | 6 | 0 |
| L4–L7 | 0–1 | 0–1 | 3–4 | 0 |
| L11 以后 | 0 | 0 | 0 | 0 |

9B 的 L0 有 4 个通道八题完整输出逐字相同且不是空答（整篇"托托托"、"StackStack"、"映映映"、纯换行）；换通道换一个固定词，换题目不变。4B L0 十个随机通道九个 8/8 首步 EOS。剂量阶梯上，4B L0 N4146 与 9B L0 N978 在 |d|≤0.5 时八题首 token 仍有 7–8 种，到 ±1 只剩 1 种，正负对称。深层相反：L20 以后 ±1 仍保持 8 种，回答坏在内容而不是坏在"不看题"。

Llama 早层没有首步 EOS，但 L0–L1 八题首 token 中位数只剩 3 种（基线 7 种），内容是模板回声、系统日期、"答案："、编号列表：句子组织完好，丢的是输入。

### 1.2 读法

- **推导：早层 dose=1 等价于抹平上下文。** 剂量按该层残差范数中位数标定。4B 在 L0–L2 的 attention 与 MLP 输出范数只有 0.5–1.2，残差 2.1–2.3，残差几乎就是 token embedding。往每个位置加同一个与残差等长的常向量，所有位置被同一方向主导，题目信息对下游基本不可见。通道无关、符号无关、阈值陡（0.5 到 1 之间）、输出变成通道决定的常数，四条都是抹平的指纹。
- **类比：空答是 Qwen 模板下"没有内容时的默认输出"。** Qwen 提示以空 think 块结尾，抹平后首选变成 `<|im_end|>` 或重开 `<think>`；Llama 没有这个结构，吐出的是模板回声。两个模型差的是默认输出，不是脆弱性。
- **推测：抹平持续到哪一层由残差里 embedding 以外成分的占比决定。** 2B/4B 在 L3（第一层全注意力）骤停，9B 延续到 L7–L10，"第一层全注意力之前"的规律在 9B 不成立，不采用。

### 1.3 与已发表结果的关系

Liu 用同一单位 B = ‖r_L‖/‖v‖ 报告崩溃在 1.37–1.65 B，其中 Qwen3.5-4B 为 1.65；本项目在同一模型 L0 测到 ≤1.0 B。两处口径差异：Liu 的 ‖r_L‖ 取生成位置、通用文本；本项目取各题提示位置中位数并在全部提示位置注入。Yap（[2603.16335](https://arxiv.org/abs/2603.16335)）在 Qwen3.5-35B 混合架构上证明只在解码期注入零效应、承诺在 prefill 形成。因此差异最可能来自注入位置，这正是 Liu 自列为未测的"剂量 × 注入时长"面。

## 2. 主体贡献：造出来的三样东西

1. **一个仪器：输入依赖崩溃判据。** 对任意干预（原生神经元、SAE 特征、均值差向量），在固定题池上测干预后输出对输入的依赖度，给出崩溃剂量。替代 distinct-bigram 比值与 LLM 评委，能抓住空答和"流畅但对输入失明"两类现有判据看不见的崩溃。独立发布，别人直接调用。
2. **一个单位：让崩溃阈值在全部层与注入位置上成为常数的剂量标定 B'(L, 注入位置)。** 三个预注册候选：去掉 embedding 分量后的残差范数；下一层 attention 输入的范数；按注入位置数加权的残差范数。由数据选，选出后一个剂量数字在 L0 与 L20、在 Qwen 与 Llama 之间才真正可比。
3. **一张表：四模型全层安全剂量上限，以及按它重评的 22 个公开配方**（lyra 与 Abhinav 的坐标）。这是给工具使用者直接拿去用的。

Liu 的 1.65 对本项目的 ≤1.0 只作为第 2 项的动机与验收：新单位必须让他的中后层数据和本项目的早层数据落在同一常数上。揭示的缺口只出现在动机段，主体是仪器、单位与表。

## 3. 三条主张与现状

| 主张 | 档位 | 现有证据 | 杀死它的观测 |
|---|---|---|---|
| A. 崩溃系数在早层远低于 1.4–1.65 B，且存在一种单位使其跨深度恒定 | 推导（前半）/ 推测（后半） | §1.1 表；深层 ±1 保持题目依赖 | 口径摊平后早层也回到 1.5 B；或三个候选单位都不能压平曲线 |
| B. 输入依赖判据比相干性判据更早触发，并覆盖空答与模板回声 | 推导 | 问题依赖度全层剖面；Llama 早层流畅回声 | 两判据在全部层给出相同上限 |
| C. 早层崩溃是 prefill 位置现象 | 类比 | Yap 表 5；本项目全提示位置注入 | 只解码注入在早层仍 ≤1.0 B 崩溃 |

## 4. 三个合同（建议顺序）

### 合同 1：摊口径与位置轴，约 2 GPU 小时，双卡并行

- 对象：4B 与 9B 的 L0–L5 原十通道（既有身份），剂量阶梯 0.25、0.5、0.75、1.0、1.25、1.5、2.0（以 Liu 的 B 为单位重算，‖r_L‖ 按生成位置、通用文本测一次）。
- 三种注入范围：全部位置；只最后一个提示位置加解码；只解码。
- 两种判据并行：Liu 的 distinct-bigram 比值；本项目的问题依赖判据（题池扩到 ≥30 道新题）。
- **对照臂排队首**：随机高斯方向、同范数、同三种注入范围。
- 预注册预测：只解码注入时早层崩溃回到 1.4–1.65 B；全部位置注入时 ≤1.0 B；问题依赖判据给出的上限在早层低于 bigram 判据。
- 停止条件：三条预测有一条不成立，相应主张降级（见 §3 最后一列）；若全部位置也回到 1.5 B，主张 A 死，只剩 B。
- 注册的结果不是"Liu 对不对"，而是"三个候选单位中哪一个让早层与中后层重合"。

### 合同 2：深度分辨的崩溃律，约 6 GPU 小时

- 四模型全部 32（24）层、每层十通道，剂量阶梯在 0.5–2.0 B 之间加密，得到 m*(L)。
- 同时计算每层残差的参与比 PR(r_L)，检验 Liu 的解释能否预测早层的低 m*。
- 预测：早层 m* 随深度单调上升至 L3 附近饱和；新单位下 m*(L) 平坦。平坦则定律成立；不平坦则交付单模型标定表，论文卖点改为判据。

### 合同 3：判据对比与处方，0–1 GPU 小时

- 用合同 2 数据比较两种判据的上限差；产出每模型每层的安全剂量上限表；按它重评 22 个公开坐标；给出崩溃类型列（首步 EOS / 常数 token 循环 / 特殊标记循环 / 模板回声 / 流畅离题）。

所有合同按 6.1–6.7 执行：冻结前离线预演两种判据能通过也能不通过（4B L0 N4146 的 +0.5 与 +1 是现成的一正一反）；零假设用随机方向臂标定；预测先写后看；偏离记账；失败分型。

## 5. 零 GPU 先做

- 读 Liu 的代码与附录，确认其随机神经元的层分布与注入位置；能复用其代码就不自写。
- 把问题依赖指标正式化：题池换成未读过的新题，报告跨题 KL 与首 token 多样性两种读数。
- 从归档轨迹算早层逐位置 cosine 塌陷比例（引擎已保存 step 0 全部提示位置），作为主张 B 的内部证据。
- 用 Liu 的范数口径重算现有剂量阶梯的 B 值，看 1.0 对 1.65 的差异有多少可由口径解释。

## 6. 停掉、降级、搁置

- 脑区作为论文主张：停。可留在动机段。
- 三维图作为证据：停。保留为浏览工具。
- 两类循环（针推动 / 历史支撑）：不单独立项，并入上限表的崩溃类型列；撤针与历史动量已被 Liu §7.3 与 Xu 等 2022 覆盖。
- 跨家族迁移第二阶段、十个修复候选：搁置，待上限表出来后决定是否在正确剂量下重做。

## 7. 风险与退路

- 最大风险：Liu 附录或代码已覆盖早层且口径一致。此时主张 A 降为复现，退路不是缩题，而是主张 B 与 C 单独成立：输入依赖判据和位置轴在其论文中确实没有。
- 次要风险：四模型 m*(L) 互不相似。此时交付单模型标定表与判据。
- 口径风险：在摊平前，"1.0 对 1.65"只登记为待核对差异，不写成矛盾。

## 8. 改做法的人

- 用 Liu 配方做可控性审计的人：早层要换上限。
- 在 Qwen3.5 上用 lyra、mfstuff 工具找针的人：剂量按注入位置与层深分开定；解码期注入可能是空操作。
- 做强度理论的人：第一份跨题目、逐层的输入依赖实测。
