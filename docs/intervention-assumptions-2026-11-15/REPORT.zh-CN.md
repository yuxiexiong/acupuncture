# 哪些固定模型条件可能决定扎针效果？

2026-11-15；研究探索与文献核查。**最终资料报告；已完成两支线独立Advisor审查及综合同人复核。** 无新模型、GPU、训练、权重编辑或参数扫描。

## 1. 目前最重要的回答

**这个设想有科学依据，但“改变固定结构/系数会影响内部干预”已经有直接先例；我们尚未找到一个可以诚实地称作新发现、或已经值得立即立项的强候选。** 本轮不是只查到“相关工作”，而是找到多个直接动过这些条件、足以推翻宽泛空白说法的研究。

更值得保留的问题是：**改变模型的一条明确计算关系，能否帮助我们辨别原来的针怎样改变历史形成、旧信息的处理与后续读取，进而影响完整回答？** 增强、减弱、翻转或保持都可能提供认识；模型改善不是必要条件。改变后的响应不能仅凭“无法换算成剂量”就回推原模型机制，还要说明改动针对哪项依赖，以及工作点、旁路和背景变化造成的替代解释。它仍须落到具体计算对象，不能凭宽标题绕过查重。

我们没有查到“大家公认这些东西不能改”的共识。冻结模型通常是实验设定；改结构/权重、改运行时gate和换干预算子都已有研究，只是它们回答的问题不同。也不能把Acupuncture这个项目名的较新，等同整个activation intervention领域从零开始。

## 2. 已经被前人做过、不能直接当新题的东西

| 原始直觉 | 一手近邻实际覆盖什么 | 对本轮的影响 |
|---|---|---|
| 归一化可能决定单针控制上限 | [Leverage Is Not Reach](https://arxiv.org/html/2606.19831) 已讨论单通道写入、残差预算及Gemma post-FFN RMSNorm的可达范围；[Angle–Norm Decomposition](https://arxiv.org/html/2606.06735v2) 分离径向/角向作用 | 不能把“norm重要”“保范数更好”当空白；严格保范数也非普遍最优 |
| 改模型天然归一化增益γ，会改变对针的反应 | [DDO附录D.2](https://arxiv.org/html/2609.16204) 确实改过RMSNorm gain以影响方向消除响应，并报告不稳定 | 不同于本项目加法针，但足够否定“没人动过γ”的说法 |
| 改写入/擦除的共同系数可能释放控制自由度 | [Gated DeltaNet-2](https://arxiv.org/html/2605.22791v2) 已解耦erase/write并训练比较 | “发明两扇门”不是增量；它对稀疏针响应的具体约束仍不能从训练收益推出 |
| 改注意力温度或QK归一化会显著改输出 | [Thermometer of Thoughts](https://aclanthology.org/2026.acl-long.200.pdf)、[LLMs without QK-Normalization](https://arxiv.org/html/2611.10560v1) 已研究这些计算条件 | 需要针响应的解释，单独温度扫分或换norm不够 |
| 模型量化后，扎针会不会不同 | [Steering Under Compression](https://arxiv.org/html/2609.06473v1) 已比较权重量化下的等行为效果能力代价和无针基线 | 泛化量化×steering题已有人直接做；剩余问题不能靠换bit数制造 |
| 递推记忆精度/遗忘会改变扰动的长期影响 | [LoReS](https://arxiv.org/html/2611.01864v1)、[Low-Bit GDN](https://arxiv.org/html/2610.39931v1) 已研究误差传播、未来敏感性与状态维护 | 遗忘噪声/保护新写入都不是新原理；不能把误差公式换名为针理论 |
| MoE路由是dense针失效的隐藏结构条件 | [RARE](https://arxiv.org/html/2608.21236v1) 已把表示干预与路由漂移区分并干预 | 有直接架构先例，但本项目不靠扩MoE重新发现 |
| 针会污染缓存、影响后续回答 | [Prompt-Activation Duality v3](https://arxiv.org/html/2605.10664v3) 已做缓存反事实并研究多轮连贯性 | 当前混合递推模型仍有特定未知，但“有缓存累积”不是新贡献 |

以上是作者论文结果或方法，未在本轮独立复现。近邻身份不等于全部结论可靠，也不意味着所有相关新问题无价值。我们采用青蒿素原则：承接现成公式与方法，判断剩余认识是否有用，不要求所有环节首次。

## 3. 两个待落实的机制问题与一个独立实践备选

### 候选A：固定记忆系数能否帮助辨别针改变历史用途的哪一环？

这一路对应时间尺度的训练后参数，以及擦除/写入是否共用门。**它与机制主旨相关，但目前没有证据支持它优先于B；简单写入解绑还与本项目NGC重叠，不能作为新切口升级。**

理论来源明确：GDN的一步更新同时保留旧状态、沿key擦除旧关联、写入当前value。同一门参与多个用途，所以调一个“写入强度”并不等于只增加新内容；而延长记忆同时可能延长有用信号和干扰。这给了值得问的结构性问题，却没有直接给出哪个效应在真实模型占主导。

真正有价值的答案会是：借某个具体更新条件，区分“旧信息持续存在”与“后续实际使用旧信息”的关系，并解释针为何改变完整回答。仅看到状态残留变长、读数变大，或者按每个任务重新拟合一个时间常数，不足以支持它。时间尺度改动也会改变模型工作点，不是一个只改变记忆寿命的纯旋钮。已有[Mamba长记忆与转换瓶颈研究](https://aclanthology.org/2026.findings-emnlp.1944/)还直接干预长记忆子空间并报告QA/摘要迁移，不能把“长记忆通道重要”当空白。

**对乐观捷径最直接的项目反例来自NGC。** [NGC原报告](https://github.com/yuxiexiong/acupuncture/blob/86bfe25ac83bd043cc7dccaa0d63b8483b926bd9/experiments/cache-native-gain-v1-2026-11-08/REPORT.zh-CN.md) 中，针相关增益具有可预测性，但预定调整在四方向均未救回原先错误的完整答案。它提醒我们不能从增益预测直接跳到答案机制；它并未直接检验固定时间尺度参数，不能算A的直接反证，更不能把答案修复当机制成功必要条件。

**尚缺的是具体关系及认识联系，而不只是一个未做的实验。** 当前资产没有直接回答固定参数改变如何辨别原针机制；不同checkpoint又混入训练差别。GDN-2已经占据解耦结构本身。只改写已有公式没有增量，但用现成理论解释此前未解释的重要行为条件，仍可有贡献，不必发明新的传播数学。详见[dynamics](dynamics.md)。

### 候选B：改变归一化／残差系数，能否改变原来调针剂量无法得到的响应？

这是对用户“改一点模型自身系数可能很关键”的最直接回应，但**几何支线和其独立Advisor均不推荐当前独立立项**。

理论依据是：残差流与归一化后的新模块输出共同决定后续计算；缩放不一定被下一层norm完全抹掉，非均匀gain还会改变方向。但这些是已知数学。要留下研究价值，需要确定某个实际组合映射如何改变输入信息相对针信号的使用，而不是仅把同一剂量曲线左右平移。

最危险近邻不仅有角度—范数研究，还有DDO真正的γ修改。也不能把γ的参数名字当功能单位：在适用路径上，它可吸收进相邻投影矩阵；如果作等价补偿，函数与同语义干预不会凭参数名变化。当前针在同层非线性之后，同层SiLU也不会重新门控已经加上的那一项。

剩余问题可以包括方向翻转、选择性消失等负面机制，不要求一定改进性能；但“出现了更差结果”也须有解释增量。即使不是剂量换算，也不能由改后系统直接推断原系统依赖同一机制；需说清被改动的计算关系如何约束原针解释。只重复已知几何配方没有增量；用这些理论解释一个有分量、此前未解释的现象则可以有价值。详见[geometry](geometry.md)及[Advisor](reviews/geometry-review.md)。

### 候选C：部署压缩保住了正常能力，是否也保住了扎针这个控制接口？

**这是独立的部署可靠性备选，不能作为解决原针机制卡点的答案。** 普通权重量化下的steering已有直接论文；值得辨别的较具体问题是：持续更新的递推状态在量化写回后，是否仍保留同一针的目标作用与完整回答代价。

理论起点不是“低精度必然更差”。量化后的有针/无针差不等于原扰动，两条轨迹的舍入误差也不自动相消；选择性的变化、相反变化以及稳定保持都有可能。但这些算术性质不能证明实际存在大效应。LoReS、Low-Bit GDN与[STEPQuant](https://arxiv.org/html/2609.38169)已深入研究状态量化；[When Quantization Breaks Memory](https://arxiv.org/html/2609.04490)还直接研究GRU/LSTM状态写回吞掉连续小更新，不能把“小针被量化阈值吞掉”当新原理。后者不是LLM扎针证据。

有价值的产物应是可用的响应保持/失效边界或预测，而非一个新量化网格。如果只是改了输入处剂量、压缩基线已崩溃，或重述已有误差累积，停止独立机制主张。当前没有同一针跨状态精度的项目证据，不能说已观察到这类现象。详见[numerics-and-equivalence](numerics-and-equivalence.md)。

## 4. 什么可能是盲区，什么还不能叫误解

目前可以有依据地纠正四种推理，而不能断言整个领域都相信它们：

1. **少坐标不等于小扰动，也不等于高语义特异性。** 本项目列范数校准已处理一部分，实际浮点偏移、背景和后续计算仍须分开。
2. **同一名义剂量不等于同一干预；同一局部写入也不等于同一完整行为作用。** 等价重参数化可制造前者的伪差异，计算背景可造成后者的真实差异。
3. **保住无针能力，不自动保住针响应；针有效，也不自动保住能力。** 两者是不同评价对象，已有量化/干预近邻已开始直接讨论，不能称本轮首次提出。
4. **动态gate不是固定模型系数。** 修改A_log/dt_bias与钳制输入依赖α/β不同；改变参数的总效果不能被某一条固定轨迹公式替代。

值得继续关注的“盲区候选”是**针与接收它的计算条件之间的关系是否被评价得足够明确**。本轮没有通过文献数量统计证明领域普遍忽视它，也没有确认某一系数就是关键原因。

## 5. 我们怎样排除“瞎想”

各候选至少有具体公式、原始论文或项目观察作为起点，同时保留相反证据；有出处不等于假说为真。对参数条件p，必须区分无针基线Y(p,0)与针响应Y(p,a)−Y(p,0)，再比较响应如何随p改变。准确率地板/天花板可以制造交互，内部张量或一个分数也不能替代完整回答。

剂量重标定是有竞争力的解释，但不能每题、每终点事后任意拟合使它永远成立；也不能用一个故意太弱的全局倍数制造“非等价”。如果得到可跨条件使用的校准规律，仍可能有实践价值，只是不能冒称新内部机制。控制改进需要效果与代价证据；机制贡献允许有用的阴性和失败边界。

这轮没有提交可执行方案，因此未把C01–C14打成“通过”。没有用未验证想法建立GPU队列，也没有恢复旧计划。具体操作、样本、评价与资源应在确有值得做的问题后另行设计，不能用更多实验格子替代价值判断。

## 6. 独立探索与Advisor的实际作用

两个独立探索sub-agent分别完成几何、动力学支线，主作者完成数值/等价与MoE补查。每支线各自委派独立上下文Advisor并处理纠正，主作者另作综合审查；完整记录保存在[reviews](reviews/)。这不是人类专家共识或独立复现。

几何审查要求撤回“强候选”，补上DDO与单针norm上限近邻，避免过度配平抹掉研究对象，区分控制改进与机制价值，并排除代数等价参数名解释。动力学审查撤回“接口容易改所以优先”，澄清同编号针与同实际注入不等价。综合初审进一步纠正：回到A014的机制认识目标；撤回A/B确定排序；C仅作独立实践备选；NGC不是时间尺度的直接反证；采用已有理论也可有实质增量。全部纠正已采纳；[综合同人复核](reviews/synthesis-recheck.md)确认可按资料探索结论交付，无未解决的交付范围分歧。这不表示候选已获科学确认或实验设计通过。[逐项处理](reviews/synthesis-disposition.md)保留修改理由。支线文件保留候选演变，最终项目目的与排序以本报告及末次审查为准。
