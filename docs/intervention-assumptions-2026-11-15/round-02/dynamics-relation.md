# GDN 擦写关系：query–key 对齐究竟改变什么

2026-11-15；第二轮定向资料与理论核查。作者稿，供本轮综合 Advisor 审查；未另唤醒动力学 Advisor。没有模型调用、统计重算、科学实验、实现方案、运行矩阵或预算。

**结论：否决“query 越对齐当前 key，就越强化新写入、越抑制旧关联读取”作为当前机制解释。** 它混淆了相对直接读取的擦除量与擦除后的旧关联读数。较准确、有解释内容的关系是：**一份来源写入能否在下一步产生读数，取决于来源写入轴、当前擦除 key、当前 query 三者的有符号关系；写入范数或 β 单独不足以决定它。** 这仍是已知 delta rule 的应用，现有证据没有证明它解释 WSB 背景差；NBR 的小 E 读数反而限制优先级。本轮不据此另立实验或主推结构改造。

## 2. 先核矩阵方向、归一化与门控身份

以单头、单步为单位，采用列向量记号：`S∈R^(dk×dv)`，`q,k∈R^dk`，`v,o∈R^dv`。与项目 [NBR reader/dew 实现](../../../experiments/cache-native-bridge-record-v1-2026-11-03/nbr_core.py) 一致：

\[
S'=\alpha(I-\beta kk^\top)S+\beta kv^\top,\qquad
 o=S'^\top q=\underbrace{\alpha S^\top q}_{D}
 -\underbrace{\alpha\beta(q^\top k)S^\top k}_{-E}
 +\underbrace{\beta(q^\top k)v}_{W}.
\]

此处 D/E/W 是核输出的计算分账，不是完整答案的可加机制份额。把 q 写成行向量时就是问题中的 `qS'` 形式，不能同时沿用列向量转置。

- 本模型 GDN 在 causal convolution 与 SiLU 后得到原始 q/k。核内 FP32 `x·rsqrt(sum(x²)+1e−6)`，q 再乘 `dk^(-1/2)`；因此 k 不严格是单位向量，q 也不是未经缩放的单位向量。`qᵀk` 有符号，不是 softmax 概率。
- β 是每输入/头计算的 `sigmoid(b)`；α=`exp(−exp(A_log)·softplus(a+dt_bias))`。它们是输入依赖激活；固定的是门控参数化、训练后的投影参数、共享同一 β 擦写的规则等。修改 β 读数、修改固定参数、修改共享规则是不同研究对象。
- 上述归一化属于 GDN；full attention 中另有 q/k RMSNorm，不能混称。核输出随后还经过每头 RMSNorm、SiLU 输出门和投影，因此本节等式只到归一化前核输出。

上游交叉核验：[Transformers v5.20.2 Qwen3.5 源码](https://github.com/huggingface/transformers/blob/v5.20.2/src/transformers/models/qwen3_5/modeling_qwen3_5.py)，`l2norm`、`torch_recurrent_gated_delta_rule` 及 GDN forward；两种核调用均显式启用 q/k 归一化。此版本用于公开源码交叉核查，不冒充所有历史运行的环境版本证明；历史操作解释以各包原实现与回执为准。

## 3. 原说法哪里失败

令 `ρ=kᵀk>0`、`c=qᵀk`、`m=Sᵀk`，且 `q⊥=q−(c/ρ)k`。直接重排得

\[
o=\alpha S^\top q_\perp+\alpha c(\rho^{-1}-\beta)m+\beta cv.
\]

固定其他量时，沿 key 的旧读数与新写入读数都含 c。旧平行分量相对于未经擦除的直接读数，只衰减了 `1−βρ`，**该相对衰减因子不由 query 的对齐度决定**。在自然 β∈(0,1)、实数归一化 ρ<1 的条件下，它非负。增大正 c 通常使残余旧读数也增大；若固定 query 范数做旋转，还同时改变垂直分量。因此“E 的绝对幅度变大”不能直接说成“旧信息读得更少”。k=0 时擦除与写入均为零，本推导无需除以零延伸。

另一个等价式是

\[
o=\alpha S^\top q+\beta c\,[v-\alpha S^\top k].
\]

大 βc 放大的是“新 value 与衰减后旧预测之差”。若 `v=αSᵀk`，该更新对输出恰好为零；若二者反向，更新可很大。以上均是条件数学恒等式，不是本项目新发现。只有 β 改变、其他量固定时，才同时降低旧平行系数并提高新写入系数；真实针会联动改变 q/k/v/门/背景，不能套用该偏导作为总效应。

## 4. 修订后的具体关系：来源写入轴与当前擦除轴必须分开

设上一时刻的一份局部状态增量为 `J=κabᵀ`。a 是该份写入的 key 方向，b 是其 value 差方向；**a 不是默认等于下一时刻的 k**。在同一个当前局部驱动 `(α,β,q,k,v)` 下比较 `S+J` 与 S：

\[
\delta o=\alpha J^\top[q-\beta k(k^\top q)]
 =\kappa\{\underbrace{\alpha q^\top a}_{d}
 -\underbrace{\alpha\beta(q^\top k)(k^\top a)}_{-e}\}b.
\]

这把“写得多”与“写入在当前读取中起多大作用”分开：κ 控制给定方向的幅度；d+e 控制该来源方向在当前核中的有符号使用。β_source 可以主导 κ，β_current 却与三个方向的几何关系共同决定 e；两个 β 位于不同时间，不应混为同一个效力开关。

几个有辨别含义的边界由等式直接确定：

- `kᵀa=0` 或 `qᵀk=0` 时，这份 J 的当前 E 贡献为零；仅有“大 β”不构成抹除它的证据。
- d、e 异号时可以抵消，同号时会加强；不能把所有 E 命名为任务信息的负向作用。即使状态变换在欧氏范数下收缩，也不保证任意 query 投影幅度下降。
- `qᵀa=0` 而 `(qᵀk)(kᵀa)≠0` 时，D 读数为零但 E 可非零；故 `e/d` 在此无意义，不能靠比例爆炸声称强擦除机制。
- 若来源轴恰与当前 key 相同，才回到第 3 节的 `1−βρ` 衰减；“source/current key 相似”仍不足以判断答案，需要 query 及 b 的下游任务作用。

这些边界不会自动预测完整答案。J 是固定局部增量时才有上述精确差分；稀疏 MLP 针造成的全轨迹差不是处处秩一，也不保持驱动不变。多层同时加 J 后，上层实际 q/k 会响应；必须使用实际接收轨迹，不能拿源轨迹 query 代替。

## 5. 通常冻结的规则如何进入这个问题

为澄清关系，形式上把原规则中的擦除项乘固定系数 p，写入项不变：`S'_p=α(I−pβkkᵀ)S+βkvᵀ`，原模型为 p=1。这是**结构规则的数学反事实**，不是自然 β 调节，也不是本文建议执行的操作。固定同一局部驱动和 J 时：

\[
[o_p(S+J)-o_p(S)]-[o_1(S+J)-o_1(S)]
=-(p-1)\alpha\beta(q^\top k)J^\top k.
\]

因此规则确实可以改变“增量响应”，不能把 p 改后无针基线变化视作自动否定；但仅比较 `o_p(S+J)` 与 `o_1(S+J)` 又会混入基线变化。真正的机制余量是：原针是否把来源写入送到一个在自然 p=1 下被抵消、加强或转向的条件中，且这项变化对原答案有实质作用。

这个局部交互本身由公式决定，不值得另花科学预算验证。若改 p 后答案改变，仍可能来自其他历史、当前 W、跨层响应或归一化竞争；不能反推自然 p=1 的错误由该份 J 的 E 抵消造成。结构工具只有在原轨迹的来源关系与相应任务读数接上时，才会改变对原针的判断。本文不提供该连接已经成立的证据。

## 7. 实质查重与可能增量

**项目内最近邻是既有 NBR/DWC 分账及尚未运行的 [BRC](../../../experiments/cache-background-read-coefficient-v1-2026-11-13/PLAN.zh-CN.md)。** BRC 已问固定 J 在背景间的 D 读取系数 `αq` 是否有条件任务作用，保持 E/current W/S2 原生。本节把当前 k/β 纳入 J 的净 D+E 作用，并没有建立新机制；只有出现“D 单独不足、三方向有符号关系对失效/异号具有实质预测力”才可能超过已有问题。不能因为可以多拆一项就自动建议加实验。

**外部最接近的是 [Muir v1](https://arxiv.org/html/2611.08376v1)。** 它研究通道门控、擦除与读取的替代关系；§6/附录 I.3 已做训练后 readout 替换及 erase-logit 干预，§6 追踪来源写入在后续回答中的读取贡献，表 3 包括相邻 key 自擦除。因此不能声称训练后干预、写入贡献追踪或擦读权衡首次。其主要理论涉及通道统计与记忆时距；这里剩余问题是原稀疏针是否改变特定来源内容的任务用途，而非重复架构优化。（已读 §2–3 相关公式、§6、附录 D.5/I.3 相关段落；不是独立复现。）

相应的有价值结果必须更具体：例如，原针使某类来源内容的直接读数仍大，但在原规则下净读数反向或接近零；该有符号变化对原答案具有条件作用，并能解释为什么增大写入幅度无效。反之，若净核读数仍相似而行为差大，就应降低这一分支、转向已明确的下游关系，而不是说“还有别的层/时刻可能擦掉”。这是假设之间的含义区分，不是已有发现或新实验承诺。

## 8. 最危险未知、停止条件与自查

最危险未知不是能否写出公式，而是 **该关系在原针相关轨迹是否足够大、任务相关、且超出 D 系数和下游读出变换已有解释**。我们目前不能由 NMT/NGC/DWC 拼出这条链；WSB 缺实际 t2 驱动，NBR 又不支持一般化的大 E。只看到结构改动减轻针效应、同基线正确率、或局部读数改变，都不解决它。

当前处理：原两项对齐口号退出；三方向关系保留为精确竞争解释和判读边界，不列为强候选或新运行方向。若后续只得到已知公式数值成立、与 NBR 一样 E 很弱、或无法超过 BRC 的 D 解释，应停止这个分支；不得自动扩层/换针/换背景。若它对局部核作用成立但任务作用不成立，应记录局部机制边界，不改称完整答案机制。
