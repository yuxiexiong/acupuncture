# 综合 Advisor 初审：固定规则与原针机制的认识联系

2026-11-15。独立上下文 AI 审查；未递归委派、未运行模型/GPU/科学实验，只写本记录。被审稿为本目录 REPORT、SCOPE 与三支线草案。本审查不等于独立复现、人类专家认证或设计验收。

## 结论

**修改后交付研究探索报告；目前不推荐把 A/B/C 任一项提升为新的主实验或强论文题目。** 这不是说结构规则不可研究，或前人一旦研究过某部件就没有价值。真正值得保留的是：能否借改变一条明确计算关系，识别原模型中针怎样改变历史内容的实际用途，并获得有意义的解释或边界。

初读主工作树入口时，我暂时认可 A 最贴近主线。父作者随后发现固定来源分支已有 A011–A014；补读后必须纠正这一初步认可：**最新用户卡点是解释不足，不是模型尚未修好。** 主稿以“可控性来自哪里”“有用作用与干扰能否分开”为中心，仍可能重复 A014 刚纠正的偏移。A 的时间尺度部分可以保留为资料问题，简单擦写解绑不可凭改名重新升格；B 可以保留，但尚没有实际关系足以优先于 A；C 有独立部署价值，不能称解决原针机制卡点。当前无证据给 A/B 作确定优先级。

## 必须修改的判断

1. **将机制认识放在控制改善之前。** 总问题应先回答“改哪条关系、何种观测会改变对原针现象的哪项解释”。增强、减弱、翻转和保持都可能有价值。效能—代价曲线是稳定控制线的评价工具，不能成为当前机制线的必要终点。也无需把所有问题强制写成两假设对决。
2. **非剂量等价不是原机制归因。** 即使改 p 后响应无法用剂量重标定，也只先得到改后系统的条件关系。解释原模型还要说明改动所针对的计算依赖，以及工作点变化、旁路与背景变化可能造成的替代解释。基线正确率相近不能补足这座桥。草案已注意基线和剂量，但缺少这个最终连接。
3. **不要把青蒿素原则再收紧为新理论门槛。** “超出已知规律”若指必须发明新的传播理论，过严。承接已有遗忘/读取或归一化理论，解释训练后模型此前未解释的重要完整行为条件、排除一个有分量的错误解释，也可以有贡献；不必每项都产生新机制。相反，仅验证代数恒等式、换模型或多扫参数，没有自动增量。
4. **NGC 不是 A 的直接最强反证。** 我回读固定来源的报告、合同和正式回执：原操作在指定 t1 单独调整写入用途，擦除用途保持该分支原生值；四方向未新增完整答案修复。它是“内部增益可预测就接近行为解释”这条乐观捷径的项目反例，也是简单解绑写入操作的历史重叠；它并未直接检验固定 A_log/dt_bias 改动。不得据此否定所有门控，亦不得再以完整答案修复为机制成功必要条件。
5. **说明与 A012/A013 的连续性。** 原 A012 已讨论共享归一化、擦写绑定、短卷积；A013 的去共同时间分量规则已退出。新 A/B 并非首次提出这些轴，应明确本轮文献补查使哪些判断改变。不得把 A013 改成另一滤波器继续，也不能因它退出就让所有结构候选永久退出。
6. **不要用“本项目未做 p×针”作为循环否决。** 探索阶段当然允许未知现象。当前不足在于具体关系、可判读认识增量及与原针的连接尚未落实，而不只是缺一个已完成实验。若能够用现成理论提出有内容、能失败的预测，并说明它的重要性，就可能值得未来设计；不要求先证明答案才准研究。

## 三候选应如何保留

| 候选 | 应保留的问题身份 | 价值与真实风险 | 本轮决定 |
|---|---|---|---|
| A 记忆时间尺度及擦写关系 | 原针改变历史用途，是因为旧信息存续、定向覆盖或后续读取发生何种具体变化？改变相关固定系数能否辨别其中一条关系？ | 与项目主旨近；但把固定轨迹传播式搬到完整模型无效，简单写入解绑又与 NGC 重叠；时间尺度并非一个随手可调而不影响其他计算的纯旋钮 | 保留时间尺度的资料问题；擦写解绑不升级；不称首选强题 |
| B 中间归一化与残差组合映射 | 某个具体重缩放依赖是否让原针改变信息用途，而不仅移动名义剂量？ | 用户所问固定系数的直接对象；已有直接 γ 干预、角度/范数与残差预算近邻。参数名不是功能单位，非等价结果还要连接回原模型 | 保留较具体的机制问题；无依据排在 A 之前或之后 |
| C 状态压缩与干预接口 | 保持无针能力的状态部署表示是否保持已定义的干预响应，何时失效？ | 实践目标清楚，可有校准/可靠性贡献；权重量化 steering 与状态压缩近邻已密集，不可把交叉标题当新意 | 仅独立部署价值备选；不能充当主线解卡答案 |

不是必须凑出三个活跃候选。若最终只能给出 A/B 的候选关系和未解决缺口，应直接告诉用户目前未筛出值得立即立项的强题。这个结论与继续承认结构切口有合理科学基础并不冲突。当前也没有足以支持“优秀论文很有把握”的证据。

## P1 与其他理论核验

我读了当前 `control_engine.py` 的 native hook 与审计字段。正数 c 缩放 up 第 j 行、down 第 j 列除 c 的推导正确：门支路不变，无针函数实数等价；以重参数化后列范数重新校准，且参考残差尺度保持相同，则注入坐标幅度乘 c，残差写向量不变。因此不需假设 SiLU 齐次。必须保留“校准量按新权重更新”的条件：复用旧 cached column_norms 并不是推导中的操作。

有限精度破坏此恒等先提示数值路径/实际注入不同，不能直接解释为神经元功能变化。但也不能逻辑上规定所有数值差异都只能是工程小事：若数值接口产生稳定而有实践意义的行为边界，可形成 C 类问题，仍需相应证据。任意旋转一般不保逐元素门控结构的边界正确。

固定驱动下 GDN 旧状态差收缩、量化双轨迹误差不自动抵消、RMSNorm 径向/切向差异，这些条件推导未见硬伤。它们不能自动判定原针经验效应的主因；也无需为了研究实证适用边界再发明新数学。

## 独立补查的一手近邻

本节仅记影响裁决的窄事实，不把搜索未命中当空白证明。

- [Gated DeltaNet-2](https://arxiv.org/html/2605.22791v2)：读摘要、§2–3 与相关结论。已解耦通道级 erase/write 并训练比较；这直接覆盖架构想法，不能据其训练收益推出固定 Qwen 手术有效。它不回答本项目原针的具体历史用途机制。
- [Sparse Long Memory and Transition Bottlenecks](https://aclanthology.org/2026.findings-emnlp.1944.pdf)：核正式 PDF 摘要、引言与贡献定位。其长记忆子空间干预、短长记忆转换及输入依赖离散化已经比“门影响记忆”更具体，并报告 QA/摘要迁移。建议用正式新版补充旧 Primacy/Recency 引文；此处未全文复核因果证据，也不借其机制到 Qwen。
- [Steering Under Compression](https://arxiv.org/html/2609.06473v1)：核摘要、导言与方法定位。其权重量化下等行为效果比较直接重合 C 的宽泛实践动机；不是只擦边提到量化。仍不等于重复状态写回的干预响应已被解决。
- [LoReS](https://arxiv.org/html/2611.01864v1)：核摘要、状态量化入口及附录 D.2/Table 11。除误差维护外，它还比较不同 mixer 架构中 dominant-channel 删除/均值替换的 PPL 影响。因此“结构条件能改变稀疏内部干预后果”的宽说法已有更直接例证；PPL 消融不等于本项目加法针完整回答机制。
- [STEPQuant](https://arxiv.org/html/2609.38169)：补读摘要及方法目录/入口。已将误差寿命与 key-row 读出影响用于递推状态压缩。只提出“慢遗忘头更敏感”“读方向决定误差影响”不能充当新贡献；其读过部分并未给出本项目所问 p×针的回答。
- [When Quantization Breaks Memory](https://arxiv.org/html/2609.04490)：读摘要和引言。其 GRU/LSTM 研究直接讨论确定性状态写回吞掉连续小更新与补偿。不是 LLM steering 证据，但 C 若以“小针被量化阈值吞掉”为机制卖点，必须承接它，不能当新原理。
- [Residual Streams Read, Recurrent States Remember](https://arxiv.org/abs/2609.32102)：只核摘要。作者已区分概念可读、状态 steering 与关系回答，后者未一致改善。这是外部方法警示，不是本项目反证；不需为收集更多标题扩大本轮。
