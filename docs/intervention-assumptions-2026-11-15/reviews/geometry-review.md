# 冻结几何路线：独立 Advisor 初审

2026-11-15。审查者为独立上下文 AI 子 agent；按全局 advisor skill 执行，不递归委派。不构成人类专家意见、独立复现或运行授权。被审稿为 `../geometry.md` 的五项登记及 G3-R 草案。仅写本审查文件；未运行模型、GPU或科学实验，未修改模型、原证据或 Git 状态。

## 直接决定

**暂缓把原 G3-R 当作独立推荐方向；允许一次更准确的问题重写，但不保送该分支进入实验。** G1/G2 的宽泛新颖性主张应取消，G4 当前缺少与实际 hook 对应的直接逻辑，G5 由父路线统一处理。当前证据不足以推荐其中任何一项为强主线。

原 G3-R 不只是数学恒等式，因为完整回答是否丢失输入约束确属经验问题；但“归一化/残差重缩放决定这个边界”尚没有比已知角度—范数、更新比例和一般扰动更明确的未知。**问题可以不是恒等式，却仍然太宽，缺少值得独立投入的剩余认识增量。** 从残差恒等式到完整回答之间存在证据缺口；不能把存在缺口本身当成贡献。

## 最危险近邻如何改变裁决

- [Angle–Norm Decomposition，§3及结果段](https://arxiv.org/html/2606.06735v2)已经将固定角度与径向缩放分离，比较控制和能力。换成“相同局部作用、不同输入约束保持”未必越过此工作；必须表明所解释的是模型固有系数的响应机制，而非另一种径向 steering 配方。
- [Leverage Is Not Reach，§2–3、附录 A.3](https://arxiv.org/html/2606.19831)比草案实际阅读范围更危险：A.3 明确讨论 Gemma 的 post-FFN RMSNorm 对单通道可达范围的限制，并与直接 residual 注入区分。因此“归一化位置决定单针控制上限”本身已有近邻，不能只将此归为一般剂量工作。其阈值/控制窗口仍为有条件作者结果，不能覆盖本项目全部非单调任务，更不能当普适定理。
- [Unified View，§3](https://arxiv.org/html/2601.22966)已经将归一化、outlier、显式门控及参数吸收联系起来。它主要比较训练和架构配置，不等于证明在本项目冻结模型修改系数后的针响应；但“重缩放是功能因素”不是剩余问题。
- [DIAL，§3.3 式4与附录 D.3](https://arxiv.org/html/2610.31438)的 norm weight 是 adapter 输出的几何插值系数，**不是 base RMSNorm γ**。文中匹配 persona 效果后比较 coherence 的结果也提示：同名控制强度改善不等于效能—代价前沿改善。不能借它直接否定 base γ 问题，也不能再次提出相同的几何调剂方法。
- 作者在审查中补充的[DDO，附录 C、D.2](https://arxiv.org/html/2609.16204)已由我独立打开核对。其 RMSNorm Gain Control 确实修改 refusal-aligned 维度的 γ，且报告生成不稳定；同附录还有多种权重/路由改动。**“改冻结γ会改变对干预的反应”不是无人涉足的空白。** DDO 主要抵御估计式方向消除，仍不能直接回答原生单通道加法的固定针响应，更不能把一种负面配置视为全部 γ 干预无效。原稿必须纳入这项直接近邻，不宜只补文献名。

这些是实际阅读的一手作者陈述，没有独立复现。新颖性结论限于上述具体重合，不声称完成穷尽检索。

## 建议的最小、实质性改写

可将剩余问题写为：

> **模型的归一化或残差系数改变后，同一稀疏针的行为响应是否只相当于在原模型上重新标定剂量，还是会改变原模型调剂量无法到达的效应方向、任务选择性或效能—代价关系；若存在这种改变，哪一项输入依赖计算解释它？**

这是一个较准确的研究问题，不是已支持的假说、方法提案或实验设计。比原稿强之处是给出了有竞争力的“剂量重标定”解释，并要求参数改变带来可识别的响应差异，而非观察到参数有效就结束。最后一句防止把一个参数扫描包装成机制论文。**“改变响应形状/前沿”本身也不是创新充分条件；若没有具体计算关系和有意义边界，只会得到现象学扫描。** 不推荐因为改写后更可证伪就立刻试跑。

“只相当于重标定”不能允许针对每道题、每项终点事后单独寻找任意映射，否则任何有限数据几乎都能被解释；也不能强求全输入只有同一个倍数，制造过弱对手。应在未来问题具体化时采用由实际局部几何支持、复杂度受限且先于目标结果确定的剂量等价解释。本轮无需写矩阵、预算或拟合器。

## 必须纠正的逻辑

1. **移除“相同注入处有效扰动”作为不加定义的入口门槛。** 若它指实际写入向量，适合区分名义剂量与实际作用；若指 γ 作用后的完整向量，则可能把待研究的中介路径主动配平掉。总响应问题和某条路径被配平后的条件问题不同。不要以“控制更严格”掩盖估计对象改变，也不要把相同范数/角度当完整向量等价。
2. **主效应与效应修饰要分开，但基线改变不是自动淘汰条件。** 对同一参数设置分别看有针相对无针的行为变化，再问该变化如何随参数改变；不能只比较两种有针输出。反之，无针表现不同不妨碍研究结构对针响应的作用，只会限制“能力完全不变”的方法主张。离散准确率的地板/天花板也可能制造表观交互，不能单凭交互项命名机制。
3. **不要混淆三个 γ。** 学到的 RMSNorm γ、参考模型的残差/写向量标度以及 DIAL 的 norm interpolation weight 是不同对象。原生参数位置还决定它在针之前还是之后。当前 post-activation / pre-down-proj 加法不经过同层 SiLU，G4 不能靠“改 SiLU 会改变针的门控”直接成立。
4. **参数名不是独立机制。** 在简单 RMSNorm 后线性投影的路径，γ 与下一线性矩阵列可相互吸收；若所有相关消费者作精确补偿且针所在中间表征也保持一致，函数及针响应不会凭参数名改变。这是代数筛除，不用模型实验验证。若没有补偿而修改 γ，则改变的是组合映射，应以实际计算对象描述。此点与 G5 相接，不要求额外开一个坐标研究支线。
5. **目标效果保持是方法价值标准之一，不是全部机制价值的通行证。** 如果参数导致针方向翻转或选择性消失，即使没有性能改善，也可能提供机制认识。当前草案“无保留目标作用则停止”应限于稳定控制改善主张，不应连研究方向/边界的解释价值一起抹掉。
6. **不得借 NGC 阴性保住或否定本假说。** 我核过固定提交的原报告、实施合同和回执相关字段：其操作是 t1 指定层头写入用途的增益调整，非 RMSNorm γ；完整答案修复为零仅约束该配置。它提醒内部可预测量未必解释完整回答，不为新的 γ 假说提供正支持。

## 是否值得继续、何时停止

眼下只建议将上述问题作为**低信心、待辨别候选**交给总路线比较，不推荐独立立项或模型试跑。最有利的证据是已知结构确实可能改变针的可达范围，项目剂量观察又不支持简单普遍单阈值；两者均不证明尚有超越近邻的剩余贡献。

真正会提高推荐的是：能够在一个具体且非代数等价的固有参数对象上，说明它为何改变某类输入信息相对针信号的使用，而已知剂量/范数解释不能回答这一关系；并能说明这种认识为何比已有“normalization cap”或方向隐藏多一步。这里只要求问题论证，不要求当前凑出阳性结果。

若资料核查后只能提出“γ会影响输出”“较小扰动更稳定”“范数改变更新比例”或另造 steering adapter，停止本支线。若只剩为寻找改善而扫描参数，也停止机制主线推荐。若最终发现全部相关变化由有预测力的剂量标定解释，可保留有边界的校准结论，但不自动延长项目追求新机制。允许本轮所有几何候选均不进入下一阶段。

另外独立读 [How Far Can You Steer?，摘要、引言及§3入口](https://arxiv.org/html/2611.06001v1)：行为—能力 frontier 已有明确先例，且已讨论留出与开放生成边界。因此沿用前沿是评价语言，不是 R2 的新颖性。R2 所剩的认识增量只能是具体固有参数改变导致非剂量等价的针响应，且有可反驳计算解释；当前未证明这一现象存在。不能因为近邻不完全同题就推断值得立项。

作者交付前还需三处小而有实质意义的澄清，不需要再次扩查或新增设计：

1. 将 R2 的“哪个训练形成的重缩放关系决定了这一变化”改为“这种变化是否由某个具体重缩放关系解释，而非一般基线改变或损伤”。只研究训练后系数修改，不能认定已识别该关系在训练中如何形成；“决定”也提前假设了候选机制成立。
2. 明确 R2 覆盖并取代原 G3-R 的退出措辞：未保持目标效果，只排除控制改善主张，不自动否定方向翻转/选择性消失的机制认识。原段可以保留为历史，但须注明已被这项纠正覆盖。
3. 在参数对象处补一句：先筛除 γ 与相邻权重的代数等价重参数化；实际研究对象是未被补偿的组合映射及其针响应，不能把参数名当独立功能单位。这是理论边界，不是追加实验。
