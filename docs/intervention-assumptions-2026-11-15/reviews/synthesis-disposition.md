# 综合审查逐项处理

2026-11-15。作者处理独立上下文Advisor的初审，并由同一审查者复核。初审与末次复核分别保留，不改写旧意见；无新模型、GPU或科学实验。

| 意见 | 处理与理由 |
|---|---|
| 1. 原机制认识优先 | 采纳。REPORT总问题改成改变计算关系怎样影响对原针的解释；作用增强/减弱不是成功本身。SCOPE与数值路线同步，C独立实践价值不替代主线。 |
| 2. 非剂量等价不足以回推原模型 | 采纳。明确改后结果先属于改后系统，仍要处理工作点、旁路和背景替代；基线正确率相近不足以建立解释连接。当前并未解决该缺口。 |
| 3. 不要求新数学 | 采纳。删去必须“超出已知规律”的表述；已知理论能解释重要未解释行为也可能有增量，换名重写恒等式则没有。 |
| 4. NGC的反证身份 | 采纳。改作内部增益预测不等于答案机制的乐观捷径反例，不能作为固定时间尺度直接反证；简单写入解绑与NGC重叠，且答案修复非机制成功必要条件。 |
| 5. A012–A014连续性 | 采纳。记录初轮工作树入口滞后及补读纠正，承认归一化/擦写轴并非本轮首次提出；去共同时间分量规则继续退出，不用另一滤波器自动替代。 |
| 6. 不以没有现成实验循环否决 | 采纳。尚缺具体关系、可判读认识及原系统联系，不要求先有阳性才许研究；A/B均暂缓，不确定排序。 |
| P1校准条件 | 采纳。正数重参数化证明要求新列范数与同参考残差尺度，旧缓存不属此设定；有限精度差异先查实际路径，但有用数值边界仍可能有实践贡献。 |
| 新近邻 | 采纳。主作者补核正式Mamba摘要/元数据、STEPQuant与write-back摘要/引言；LoReS附录消融明确为Advisor核验，不冒充作者再次独立核验。 |

最终没有可立即立项的强候选，不选“最不弱的一张”充当赢家。几何、动力学均保留自身初审、纠正与同人复核；主作者数值路线纳入综合Advisor。三位Advisor与探索者分工独立，但共享后续反证且属于AI审查，不是人类专家共识或独立复现。
