## 1. 决策目标与交付物

本方案要回答：对一个成品模型施加某种干预后，它在相同任务上少做对了多少题；损伤如何随剂量和位置变化；换成另一个模型后，这种下降是否仍出现。

主结果沿用已有研究的可解释单位：**正确率或 pass@1 下降多少个百分点**。每项任务分别报告原版、干预版、差值与配对置信区间。不建立“总损伤百分比”，不把知识、数学、代码、语言损失和有害性混成一个总分。

完成一批实验后，必须能交付：

1. 逐模型、逐条件、逐任务的完整前后对照表。
2. 每项任务的剂量—损伤曲线，显示全部预注册剂量和对照。
3. 固定语料上的语言建模损失表，以及截断、无效输出、重复等诊断表。
4. 每题原始输出或选项似然、判分记录、失败记录和可复算的汇总。
5. 真实时间、GPU 占用与校准成本；未完成项目明确标记。

这些结果量化的是指定条件下的可测任务表现，不自动等于全部知识被删除、某个脑区受损，或已找到“道德神经元”。

## 4. 干预定义与比较单位

记 A 为零起始 L14/N8949，B 为零起始 L13/N7956。位置是 MLP 的 `down_proj` 输入，即门控乘积后的中间通道激活。

设通道激活为 `a_n`，对应投影列为 `w_n`，则本方案的动态干预为：

```text
c_L,n(x) = dose_L,n × m_L(x) / ||w_n||₂
a'_n = a_n + c_L,n(x)
局部额外写入 Δh_L = c_L,n(x) × w_n
```

`m_L(x)` 沿用历史实现：用未干预模型处理完整输入提示，计算该层输出残差各有效 token 的 L2 范数，排除首 token 后取中位数。每题只校准一次，所有剂量共用该题原版尺度；prefill 和 decode 沿用固定偏移。校准输入是所有候选共享的完整上下文：保留题干已展示的选项和 few-shot 示例答案，排除本题待评分的候选续写、本题目标答案与 padding。

联合条件使用 `dose_A=+λ，dose_B=−λ`。λ=1 是历史设置；理想实数运算下，每点注入范数等于相应参考残差范数。它不是 1% 微扰，也不是只修改两个标量权重。

每次记录名义剂量、`m_L`、列范数、偏移值及数值精度。另在固定诊断样本上记录实际写入范数和相对原版残差尺度。不能将两层的注入范数简单相加，当作最终输出空间的总扰动。

未来换模型或位置时：仍计算该模型、该层自身的尺度；相同 λ 仅表示同一归一化规则，不保证相同生理意义、有效强度或行为效应。固定参考尺度、逐题尺度、乘法消融和永久权重修改应使用不同 `intervention_id`，不能混在同一曲线上。

## 5. 主能力面板与评分合同

以下四项均为英文、文本任务；本版不据此声称中文、多模态、长上下文或工具调用能力保持。未来增加领域时单列新面板，保持本版分数可追溯。

| 基准 | 全量测试题数 | 主指标 | 本版拟固定设置 |
| --- | ---: | --- | --- |
| MMLU | 14,042 | 选项正确率 `acc` | 5-shot，按固定任务定义计算 A/B/C/D 续写似然；报告 harness 聚合方式和学科明细 |
| ARC-Challenge | 1,172 | 长度归一化选项正确率 `acc_norm` | 25-shot，按固定任务定义计算完整选项似然；`acc` 同时附报，不事后择优 |
| GSM8K | 1,319 | 严格最终数值 exact match | harness `gsm8k` 的 5-shot，贪心生成，固定严格提取规则；上限 2,048 新 token |
| HumanEval | 164 | greedy pass@1 | 官方函数补全提示、0-shot，每题生成一份代码，最多 1,024 新 token，按固定测试环境运行 |

题数依据 CircuitBreak 的面板及上游任务；shot、ARC 的主指标和预算是本项目的明确选择，不宣称逐项复刻 CircuitBreak 的未充分披露设置。[R2, R6–R9]

### 5.1 采用现成实现，冻结实际配置

- MMLU、ARC-C、GSM8K 优先使用 LM Evaluation Harness 的固定 commit、任务 YAML 和 scorer；HumanEval 使用固定版本的官方数据和执行器。实施时记录准确 commit 与依赖版本，不能只写 `latest`。[R6–R9]
- 主能力面板采用标准文本补全提示，不额外套模型聊天模板，不人为加人格/安全 system prompt。所有模型使用相同任务文本、few-shot 示例和选项顺序；BOS 等 tokenizer 必需处理记录在案。
- 这是对文本任务能力的共同测量，不能把补全成绩称为聊天体验完全保持。本版不执行 Persona 性格评测或聊天行为评分；若需行为—能力双曲线，须另行冻结聊天题集、行为维度、评分器、盲化与预算后注册，不能仅凭本版能力曲线声称完成该目标。
- MMLU 字母似然和 ARC 完整选项似然严格沿用各任务定义。历史“首 token 限定四个字母”的诊断不能冒充整套标准评测。
- 每道选择题所有候选共用由完整公共上下文计算的原版校准尺度；上下文中已展示的选项属于合法输入。不得分别把每个候选续写拼入后重新校准，从而使不同候选使用不同干预强度。
- GSM8K 主分数固定为 `strict-match`。上游 `flexible-extract` 仅作预先指定的辅助分数，所有臂同时计算，明确其可能误取叙述中数字的限制。不得看完某臂回答再发明解析器。[R6]
- HumanEval 报告每题测试通过/失败、语法错误、超时及提取结果。采用函数补全原始 completion，不人工修复、拼接候选或提取“最好”的代码块；执行超时固定为官方默认的每题 3 秒，`k=[1]`，记录 Python 与隔离环境版本。生成代码在禁网、无凭据、有资源限制的隔离环境执行。[R7]

### 5.2 统一预算与结束条件

同一模型的两臂使用相同精度、后端、batch 策略、提示与结束条件。源模型优先 BF16、eager、贪心；不得只对干预版增加重复惩罚、强制答案或额外重试。

为源模型核验 248044 与 248046 的映射；其他模型从其固定 tokenizer/config 获取结束标记，不能复制 Qwen 的数值 ID。任务约定的停止字符串同样冻结。统计回答长度时去掉生成结束后的 padding，原始 token 仍保留。

2,048/1,024 是本版共同生成预算，不代表所有 tokenizer 提供相同文字空间。跨模型另报 token 数、UTF-8 字节数、截断率和耗时；结果应解释为此预算下的任务表现。

预算只可在正式测试前通过独立开发材料修订。正式运行发现截断率高时，保留本版结果；若开展更长预算实验，建立新版本、对比较的所有臂使用同一新规则，不只续写失败题。

## 6. 语言建模损失与生成诊断

### 6.1 三种固定参考分布

借鉴 Refusal Direction 的三种参考分布，采用 teacher forcing：原版与干预版对**相同的固定 token 序列**计分，而不是各自生成一句再比较各自概率。[R1]

| 分布 | 本方案样本规则 | 衡量对象与限制 |
| --- | --- | --- |
| 普通文本 | The Pile 官方可获取验证资源中至少 512 Unicode 字符的 100 个不同文档；固定种子按文档抽取，每段取前 2,048 Unicode 字符 | 对一般文本的预测损失；不是事实正确率 |
| 指令—参考回答 | Alpaca 中固定 100 条记录；用各模型原生聊天模板，只计参考回答正文 | 对相同指令回答分布的拟合；参考答案不保证完全正确 |
| 指令—原版回答 | 同一批 100 条指令；每个模型的原版贪心生成一次，最多 1,024 token，随后冻结 | 保留该模型原始输出分布的程度；不能作为跨模型同文本比较 |

以上数量、长度和抽样方式是本方案选择。原始资源 revision、文档 ID、文本及选择清单哈希在正式运行前固定。若 The Pile 指定资源无法获取，记录阻塞并修订方案；不能无记录地换成另一语料后仍称相同实验。无需下载完整预训练语料库。

普通文本使用首 256 字符作为条件前缀，剩余正文为评分目标；指令样本以实际提示为前缀。校准只读取此前缀，不读取目标答案。窗口策略、最大上下文、BOS/EOS 和跨边界 token 处理必须固定；无法精确分离目标 token 时修复实现，不能静默计入提示损失。

交叉熵主汇总固定为同一分布中全部目标 token 的总负对数概率除以总目标 token 数，单位 nats/token；不是逐样本 CE 的等权平均。报告原版 `CE₀`、干预版 `CE₁`、`ΔCE=CE₁−CE₀`，正值表示预测损失增加，另保存逐样本 NLL 和 token 数以供复算。bootstrap 每次按文档/指令重采样后重新求这个比值。三种分布分别报告，不能平均成能力总分。

不同 tokenizer 的 nats/token 不直接横比。如需共同普通文本/参考回答的跨 tokenizer 辅助对照，额外计算 `BPB=−Σ log p(target token)/(ln 2 × 目标 UTF-8 字节数)`；明确模板与特殊 token 的记账。BPB 仍是预测分布指标，且只有目标文本与条件文本一致时才有共同文本比较意义。各模型自行生成的参考答案不满足这一条件。

### 6.2 不改变主分数的诊断项

- 终止原因：EOS、任务停止串、长度上限、基础设施失败，分别计数。
- 输出有效性：答案解析失败、代码编译/测试失败；保留在相应任务分母中。
- 重复率：借鉴 CNA 的思路，本版明确使用模型 token 的 4-gram，定义 `1−不同4-gram数量/总4-gram数量`。少于 4 token 记 NA 并报告数量，不记作完美质量。报告逐回答分布和均值；不同 tokenizer 下不直接当作同尺度指标。[R4]
- 如需跨 tokenizer 的重复检查，另报固定 Unicode 字符 4-gram，同样不解释为语义能力。代码天然重复等题型差异应分任务呈现。
- 聊天连贯性或有害性可以另行标注，但不是本版主能力判分器；不以含粗口、拒答减少、评分器认为“连贯”来替代任务正确率。

## 7. 数据隔离与防止按结果选设置

所有抽样种子以 `20261026` 为默认值，生成后的 ID 清单与内容哈希才是最终身份依据。种子不是数据版本。

1. **技术开发集**：从非测试划分取固定小样本，用于检查 hook、解析、终止、吞吐和预算；不能进入确认分母。HumanEval 的执行器检查使用合成代码，不提前查看测试输出。
2. **选择材料**：如将来搜索位置或为跨模型匹配剂量，应另设不与主面板测试题重叠的选择集。所有候选、预算和选择规则事前记录，不能用正式测试分数来反复挑点。
3. **正式面板**：四项固定完整测试集，所有注册条件都报告。其用途是标准化任务比较，不能被当作后续无限调参的开发集。
4. **独立确认标记**：历史 GSM8K 100 题已暴露。全量 1,319 题仍报告以便标准化，但同时在去掉历史题后单列未暴露集合；若 ID 一一对应且没有额外重叠，应为 1,219 题。实际确认数量以内容去重清单为准。不能宣称全量结果完全盲测。
5. **已有 24 题**：只用作探索性行为材料，不当作新机制或迁移主张的独立确认集。

本版固定剂量网格完整呈现，不按最终分数挑一个最好剂量。未来任何根据本版结果提出的新候选，应在新注册的确认材料上测试。预训练污染无法仅靠本次隔离排除，报告中应区分“本研究未用于调参”与“模型预训练从未见过”。

## 8. 源模型条件矩阵与执行顺序

### 8.1 最小主矩阵：六个条件

| 条件 ID | A 剂量 | B 剂量 | 目的 |
| --- | ---: | ---: | --- |
| O | 0，未挂干预 hook | 0 | 原版基线 |
| A1 | +1 | 0 | A 单点影响 |
| B1 | 0 | −1 | B 单点影响 |
| AB025 | +0.25 | −0.25 | 联合低剂量 |
| AB050 | +0.5 | −0.5 | 联合中剂量 |
| AB100 | +1 | −1 | 历史联合剂量的标准面板测量 |

O、AB025、AB050、AB100 构成预注册剂量曲线；O、A1、B1、AB100 构成 λ=1 的单点/联合对照。只有 λ=1 有完整单点分解，不能推断所有剂量下的交互。这里的“最小”是本项目控制成本的选择，不是文献规定的标准样本量。

零剂量 hook 和卸载后恢复是技术验收条件，不作为额外独立模型或独立重复计数。

### 8.2 若要判断位置特殊性，增加四个对照条件

- `REV100`：A=−1、B=+1，检查方向反转。
- `R1/R2/R3`：事前随机抽取三组 L13、L14 通道对，排除原目标；沿用相同层、通道数、正负号、逐层参考注入范数与注入时机，λ=1。保存抽样全集与权重列范数，不依据输出重抽。

这四臂在主张“目标位置具有特殊性”时是必要对照。三组随机对照仅能提供有限的扰动参照，不能可靠估计全部通道中的罕见性，也不能据此宣布已定位唯一功能区。若需要全分布显著性，必须另行设计更大的随机样本预算，而不是假装三组足够。

随机对照匹配的是各层的局部归一化写入幅度；它没有匹配下游总变化或最终损伤，这些应作为结果测量。

### 8.3 分阶段推进

| 阶段 | 工作 | 完成标准 |
| --- | --- | --- |
| 0 | 固定资产、评分、技术开发集、实现与预算；完成验收 | 无未解释的零剂量差异；冻结清单齐全，吞吐实测完成 |
| 1 | O 与 AB100 的四项全量面板及语言损失 | 两臂所有条目均有成功或明确失败记录，获得标准剂量损伤基线 |
| 2 | A1、B1、AB025、AB050 | 六条件全部配对，获得单点分解和剂量曲线 |
| 3 | 若要解释位置特殊性，运行 REV100 与三组随机对照 | 全部对照保留，不只展示弱于目标的随机组 |
| 4 | 将同一指标接入源模型路径替换/恢复实验 | 修复的对象是原先下降的同一指标；机制方案单独注册 |
| 5 | 源机制与对应规则明确后，再做同家族、跨家族迁移 | 目标模型、候选规则、选择预算与确认集提前固定 |

阶段 1 的好坏不能成为删去既定负结果或重写阶段 2 剂量的理由。运行因资源限制分批时，列出已完成与待完成矩阵，不把中途结果包装为全部完成。

## 9. 换位置、模型大小、家族及干预方法时如何比较

| 改变因素 | 固定内容 | 必须额外记录 | 能支持的结论 |
| --- | --- | --- | --- |
| 剂量 | 模型、位置、归一化、输入、评分 | 名义剂量与实际局部写入 | 同一干预的剂量响应 |
| 位置 | 模型、局部范数规则、时机、候选预算 | 层类型、模块、通道、候选来源 | 指定位置之间的表现差异 |
| 模型大小 | 相同任务和判分，每个模型有自身原版 | 模型/权重/tokenizer revision、上下文预算 | 有限模型面板中的差异 |
| 模型家族或类型 | 相同题目和输出指标；明确任务模式 | Base/Instruct、Dense/MoE、模块映射、原生模板 | 指定模型的可比任务结果，不证明共有功能区 |
| 动态/静态/乘法等方法 | 同一模型、题集与评测协议 | 实际操作、校准、权重差分与加载方式 | 方法间损伤差异；不能默认数学等价 |
| 精度或推理后端 | 每个后端单独设未干预基线 | dtype、量化方案、内核、硬件 | 分离数值执行变化与干预变化 |

跨模型先列 `原版分数、干预分数、下降百分点`。原版 90% 降到 80%，与原版 50% 降到 40%，均为下降 10 个百分点，但不等于剩余能力相同。参数量不作为分数的除数。

同编号、相邻编号或相同相对层深不是功能对应规则。换模型时必须先明确待检验的对应关系；本协议只负责测量该候选的代价，不负责替它证明机制。

若将来要比较“同一能力损伤约束下谁的行为变化更大”，应事前在独立选择集给四项任务分别设损伤上限，选定满足全部约束的剂量，再到确认集报告；不能在测试集插值挑最好点。满足同一个上限不等于损伤相同。若要严格做等损伤比较，还须预定四项差值的逐项匹配容差，并在确认集核验；找不到匹配点就报告无法匹配，不假定剂量单调或强行插值。单个 CE 或某一任务相同，不代表四项能力同时相同。

跨模型具体名单、revision 和候选定位办法尚未冻结，当前迁移阶段暂缓。这不妨碍在源模型建立可复用的损伤测量协议，也不构成本次自动下载或运行其他模型的授权。

## 10. 统计分析、判据与地板效应

### 10.1 主效应

对于同一任务和同一批题，记原版得分 `S₀`、干预版得分 `S₁`，均以百分数表示：

```text
D = S₀ − S₁    （单位：百分点）
```

`D>0` 表示任务表现下降，`D<0` 表示改善，负值不截为零。沿用各 benchmark 的原始聚合权重；MMLU 另提供学科明细，不能在看到结果后更换宏/微平均。

每项再保存原对→新错、原错→新对、两者都对、两者都错的计数，防止净分掩盖题目交换。它们是本项目补充诊断，不是新造的主损伤总分。

### 10.2 区间与比较范围

- 每项采用 10,000 次配对 bootstrap，随机种子固定；同一次抽样同时取原版与全部条件的对应题目。MMLU 在学科内配对重采样并保留既定权重；存在共用上下文的任务按上下文聚类。HumanEval 按编程题抽样，不能把同题测试用例当成独立样本；CE 按文档或指令配对重采样。
- 报告 95% 配对区间。它描述测试题抽样的不确定性，不代表模型训练种子、全部模型家族或所有解码策略的不确定性。
- 若原版/干预版正确性不一致的题数不超过 5，额外给出保守范围：以不一致率的单侧 95% Clopper–Pearson 上界 `q_U` 构造 `[-100q_U,+100q_U]` 个百分点。对按学科加权的 MMLU，逐科分配显著水平使各上界联合覆盖至少 95%，再按冻结权重合并。此范围不替换点估计；尤其不能拿完全一致时 bootstrap 产生的 `[0,0]` 来证明不存在稀有损伤，后续非劣声明不得只依赖这种退化区间。
- 本版 greedy 每题一次。重复运行相同确定性生成不是新的独立样本；技术复跑只用于数值一致性，不虚增样本量。
- 四项主任务与各条件均报告效应，不用“某一项 p<0.05”代替全貌。若正式进行多条件显著性声明，对事前列出的任务×条件检验族做 Holm 校正，公开完整族和校正结果。
- 单点交互可补充计算 `I=S_AB−S_A−S_B+S_O`，仅在同任务相同 λ 的条件下解释为得分层面的交互；它不证明 B→A 的传播路径。

### 10.3 如何表述“无损”

本版默认交付连续分数与区间，不强迫给“无损/有损”的总标签。“差异不显著”不等于“没有损伤”。

若后续论文需要“损伤不超过可接受范围”的声明，须在看确认结果前为四项分别指定容忍界值 `δ_j`，并使用单侧非劣检验；每项损伤上界都小于对应界值才可声称在这四项上满足该约束。对一个预注册条件的“四项全部通过”是交并式判定；若跨多个条件挑通过者，还须处理选择和多重比较。当前没有用户认可的实际容忍界值，因此不擅自把 1 或 2 个百分点写成领域公认标准。

HumanEval 仅 164 题，一题约 0.61 个百分点；不能承诺用这个面板辨别任意小差异。资源与精度预算须参考开发集的配对不一致率估计，不能仅因为总题数大就宣称所有任务都有足够统计功效。

### 10.4 地板与混合结果

若某任务全部剂量接近零分或选择题机会水平，报告读数分辨率不足。CE、重复率可以说明其他变化，但不能据此给“负能力”排序。

若知识改善但数学下降，分别报告，不用平均抵消；若格式失败和任务答错并存，主分母保留所有输出，辅助诊断解释失败类型；若需增加更低剂量或更简单任务，作为新版本提出，保留本版全部结果。

## 11. 技术验收与异常处理

正式测试前应完成以下有限验收，不提前跑完整测试集来调实现：

1. 模型、tokenizer、数据、评测任务、干预代码身份和哈希可追溯。
2. 零剂量与无 hook 在固定开发样本上的 logits 与生成一致；卸载后恢复一致。记录容差及差异，不用宽松容差掩盖实现错误。
3. 确认 hook 位置是目标通道，偏移符号、范数、prefill/decode 覆盖和 padding mask 正确；同题所有选项共用校准值。
4. 同一套 baseline 权重与相同题目可顺序运行；不要求同时驻留多个 4B 实例。每题清空 KV/递归状态，禁止把前一条件的缓存带到后一条件。权重前后摘要一致。
5. batch 与单题的固定开发样本对照通过；若批量改变排序或输出，先解决或固定 batch=1。不能让两臂使用未经对照的不同 batch 策略。
6. 终止标记、答案提取、HumanEval 执行器和 CE 目标掩码通过合成或非测试样本检查。

异常分类必须区分：

| 情况 | 记录与判分 |
| --- | --- |
| 正常生成但答案错误、拒答、无可解析答案 | 任务失败，保留在分母 |
| 达到生成上限 | 标记截断，仍按固定 scorer 判分；若已存在合法正确答案不强制改判错 |
| 生成代码语法错误、执行超时、测试不通过 | 按 HumanEval 执行合同记失败，同时保留错误类别 |
| OOM、网络断开、输入文件损坏、进程崩溃 | 基础设施失败，不能冒充模型答错；整项标记未完成，并保留计划总数、完成数与缺失数 |
| NaN/Inf、hook 失效、零剂量不一致 | 测量有效性失败，停止依赖该实现的后续收集，保存证据并修复后另建运行版本 |

故障恢复仅补未完成单元，已产生的完整输出不覆盖；重复尝试全保留并按事前规则确定计分记录。禁止为更好内容重抽、重试或挑选种子。保持每 30 分钟技术检查的既有偏好，异常及时报告；不把固定检查间隔误当实际 ETA。

## 12. 样本量、成本和 ETA 合同

四项全量每个条件合计 `14,042+1,172+1,319+164=16,697` 个题目—条件单元：

| 套餐 | 条件数 | 总题目—条件单元 | 说明 |
| --- | ---: | ---: | --- |
| 阶段 1 | 2 | 33,394 | O、AB100 |
| 最小主矩阵完成 | 6 | 100,182 | 包含阶段 1，不重复计算 O |
| 加方向与三组随机对照 | 10 | 166,970 | 包含前六条件 |

该计数不是 forward 次数或生成数：选择题可能有多个候选续写，GSM8K/HumanEval 有可变长度生成；另有校准、300 条参考序列的语言损失、每模型 100 条原版参考回答生成及技术验收成本。

先在非测试材料按任务、长度和条件测量吞吐。尤其测 AB100 的长输出成本，不能只用原版短回答速度外推。记录冷启动、加载、校准、评分、生成、代码执行、结果校验与导出各自耗时。

```text
总计算成本 = 加载与验收 + 原版校准 + 各任务各条件推理
           + 语言损失与参考回答生成 + 代码测试 + 汇总导出 + 失败尝试
墙钟 ETA = 按真实并行/串行依赖与实测吞吐排程的剩余时间区间
```

每项报告设备、batch、有效 token/秒或题/秒、峰值显存、GPU 小时与墙钟区间。进程时间可重叠，不能直接相加称墙钟；校准缓存只在模型、提示、尺度定义和精度均相同时复用。

历史 100 题快速测试的时间不直接外推到本方案。**当前尚无该评测栈的实测吞吐，因此不给虚构小时数。** 正式执行前以实测填入成本表、设置任务超时与总预算；超过预算时保留状态并报告，不能为了赶进度删题或缩短某一臂。

## 14. 本版结论与实施前待补字段

本版确定的是一套可重复使用的量化协议：**四项标准任务测实际表现，三类参考语料测预测损失，配对对照与剂量曲线测变化规律，生成诊断解释失败形式。** 它能支持不同条件的具体比较，但不单凭一张损伤表证明自然功能区或跨模型共同机制。

以下属于实施时必须填写的资产/预算信息，不是允许事后自由选择的科学参数：评测 harness 与执行器 commit、数据 revision 与冻结 ID、实际上下文适配检查、硬件和 batch 验收结果、实测 ETA/资源上限、固定随机通道清单。若这些条件迫使修改 shot、预算、尺度或评分，应更新协议版本再开始正式收集。

本次仅提交方案。新模型运行、静态修改或迁移实验仍须依据后续明确执行指令；不会因文档合入自动启动。
