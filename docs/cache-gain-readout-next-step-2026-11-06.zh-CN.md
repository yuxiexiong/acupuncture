# NWC之后的下一步：优先补获得侧的完整回答与随机比较

2026-11-06；建议设计 r01；证据截点 `8a2ae4e69`。依据用户本轮两张截图及“下一实验建议怎么做、补什么”的问题。采用 academic-research-suite 的证据核对原则，按[设计自查 v1](experiment-design-self-check.zh-CN.md)记录作者自查。**这是可讨论的逻辑设计，不是冻结运行合同；未实施、未运行，无新GPU授权。**

## 1. 建议与优先级

先将NWC已经完成的结果纳入论文现行正文与缺口表。若随后只选一个补充实验，建议检验：**L10接收者通过一次直接读取使用L11的状态，能否恢复正确记录选择和完整回答，且净恢复超过预先固定的同范数随机补丁平均？**

选择获得侧并非为了把表格补成对称。NWC已表明，许多随机扰动也能使回答退回首列；因此，继续观察“换状态使回答坏掉”对识别解释的增量有限。获得侧已有SRU开发证据，但没有NWC面板上的结果，也没有本设计要求的获得侧随机比较。补它可判断写入端点与读取的连接，是否有超出一般扰动的**正向恢复作用**。

这属于现稿的优先补强，不是提升论文等级的独立大贡献。“破坏容易、恢复困难”不能当作未测即真的原理，也不作为本项目的新颖性声明。若本轮为阴性，接受获得侧不稳定／不优于所测随机平均，结束这一补证分支。

| 选项 | 本次取舍 | 理由 |
|---|---|---|
| 获得侧＋同范数随机比较 | 若继续补实验，第一优先 | 同时触及主链缺失方向和NWC暴露的一般扰动解释；正反结果都改变中心句 |
| 继续扩大撤回侧随机数或换针寻找特异性 | 不优先 | 已有明确负面结果；不为修复一个失败卖点继续寻找阳性 |
| 改排列、提示或默认答案以解释首列落点 | 保留为另一问题，不与本轮合并 | 可以检验默认策略，但“跟着第一条走”仍不自动识别内部计算；不能仅因新现象有趣就替换原主线 |
| 跨任务／模型 | 更宽主张需要，但当前不铺矩阵 | 先确定值得推广的具体关系；补齐获得侧也不自动授权跨模型运行 |
| 原生停止形成、实际转向／修复 | 分别保留G3、G5身份 | 本轮仍不解释这些问题，不靠获得侧成功借用其贡献 |

## 2. 已有证据与真正缺的量

- [NWC合同](../experiments/cache-native-write-confirm-v1-2026-11-05/CONTRACT.zh-CN.md)、[报告](../experiments/cache-native-write-confirm-v1-2026-11-05/REPORT.zh-CN.md)、[结果JSON](../experiments/cache-native-write-confirm-v1-2026-11-05/analysis/nwc-readouts-r01.json)：非首列48条上L10为1、26、30，L11为41、47、46，D10撤回后为5、28、32；没有L10读取L11状态的获得臂。NWC冻结中心门槛确认的是原生来源读取，不是整个LVK→SRU双向链。
- NWC的P3是端点差效应大小预测，P4M/P4Y才是随机族稀有性预测；不要把三条统一改述为同一种方向特异性检验。主臂强于随机平均和不少随机方向也致错可以同时成立。
- [基础知识审计](cache-mechanism-known-basics-audit-2026-10-31.zh-CN.md)：读取公式、状态差的代数分解和恢复／污染的不对称并非本轮待发现的知识。实际完整回答是否恢复以及与参照的差异不能由公式推出。
- 旧数据可核对端点、可达性、错误类型和实施接口；**不能从撤回臂取负号算出获得臂的自由回答**。获得侧接收者、q和后续轨迹不同。
- 本轮尝试重新打开既有activation-patching近邻网页时连接失败。因此不新增文献优先权断言；文献定位沿用仓库已核查材料，正式投稿前的查重另做。

## 3. 设计卡

**主线。** 稀疏干预怎样改变历史、当步写入、后续读取和完整回答。本轮检验其中“写入端点差经读取恢复答案”的关系，不将课题改成一般噪声鲁棒性。

**新增认识。** 在第二块、现在已见的面板上，旧SRU获得关系是否仍有效；其完整回答恢复是否超过同一接收者中的固定随机参照。成功支持有条件的正向恢复，失败限制双向链的可复用范围。

**模型／输入。** 继承NWC的Qwen3.5-4B固定revision、L0施针、剂量、校准、布局及形成窗口。复用72输入：六结构族×四基础情境×三个版本；非首列N为48条、首列F为24条。N4146、N1210为主要方向，R0只作诊断。输入全保留，不按L10是否答错或是否到达t2筛选。

**数据身份。** NWC面板和基线结果已公开给设计者。本轮是在已见面板上、预先规定新增操作的补充检验，**不是新的独立留出确认，也不使整条双向链获得完全开发外确认身份**。若目标必须是独立确认，需另立未见材料合同，不能把本轮悄悄改名。

**操作范围。** 继承SRU的14个G层与t1写入构造。每输入重建同源L10/L11：L10只改t1局部v，L11同时改局部v与写入项k。供体为同输入L11的S1，接收者为L10。只在自然t2修改输出用途；供体只读，不将供体状态写入持久缓存。接收者的q/k/v/门控按本分支当前计算产生，高层响应较低层补丁，S2按该分支自然更新，t3起无钩子。不强制首token，不屏蔽EOS。

| 臂 | 内容 | 用途 |
|---|---|---|
| L10、L11重放 | 无t2操作，完整自由生成 | 同输入基线、写入端点差与桥接；L11不是读取恢复的理论上限 |
| 获得D | 在t2输出加α(S1[L11]−S_r)ᵀq | 检验直接读取的正向恢复 |
| 获得E | 在t2输出加−αβ(kᵀq)(S1[L11]−S_r)ᵀk | 同一状态差的用途比较；不是等范数对照 |
| 随机R1–R20 | 同接收者、同层头、同t2时刻加随机输出向量 | 比较同幅度配置的一般扰动能恢复多少 |

**随机族定义。** 新种子固定为2026110701–2026110720，正式冻结前检查与已有种子不重合；不按NWC的强弱排名选方向，不补抽。单位向量沿用NWC的采样空间与实现，按种子／层固定并跨输入复用。先保存该输入、该方向获得D自然轨迹上每层每头的实际补丁范数，20臂均匹配这份参考范数配置；不是在各随机分支中重算一套不同参考范数。零范数处零补丁。后续q及传播仍允许变化。**这项范数参照与NWC的具体实现必须分别标明，不能直接比较两轮“随机概率”。**

不增加D+E、跨输入移植、半幅度、层头搜索或新针；它们不回答本轮主要缺口。若L10在t1停止，D/E/随机臂无t2可操作，结果按停止保留；不能事后删除。首token不同于共享编号首token时仍保留完整回答读数，但不称t2为记录选择步。

**估计对象与主要终点。** 在N层、各干预方向内，使用冻结解析器的自然完整正确Y，报告每臂Y、正确→错误和错误→正确、首列错号、停止、其他。令g=Y(L11)−Y(L10)，δ_D=Y(D)−Y(L10)，δ_E同理，δ_R为20个预定随机方向的平均净变化。比较δ_D、δ_D−0.5g、δ_D−δ_E、δ_D−δ_R；全部为操作总效果，不是自然中介比例。F层另报原本答对输入的改坏及全部72条合并计数，不能拿F层饱和稀释N层失败。t2正确选择为辅助读数，不以logit增益代替Y，也不新增共同强制首token评分路线。

**建议判据。** 每方向g≥0.25才有足够端点缺口；L10未到t2比例≥25%则读取关系记不可判，但所有回答仍报告。按24个基础情境在族内重抽、三个版本一起走，10000次；95%百分位下界分别计算，不将72条当独立样本。δ_D−0.5g、δ_D−δ_E、δ_D−δ_R三个下界均>0，才称“有实质恢复且超过指定用途／有限随机平均”。半缺口沿用NWC的实质效应标准，不是通用机制阈值；不满足不能写“毫无作用”。两个主要方向分别判读，同时满足才称两方向支持；R0不替代主要方向。区间只对输入变化、条件于这20个方向，不宣称已估计全部随机方向总体。保留每个随机方向的完整分布及超过D的个数，不以随机平均掩盖强对照。正式合同需固定重抽种子、实现和判读顺序，不能看新增结果后调整。

**范围与成本。** 复用输入、校准、解析器、来源manifest、SRU读取公式与NWC桥接证据。张量文件存在不代表保存了可直接续写的全部缓存；此前2.1GB张量留服务器，本轮未访问或验其可复用性。保守按全部端点重建计：正式自然轨迹72×3×(2+1+1+20)=5184；32-token生成上限下，t2及后续至多160704次token前向，另计形成／预填、432个来源t1、影子计算、零钩子及FP64核验、旧结果桥接、预检与允许的失败尝试。NWC实耗约1.15GPUh只能作工程参照，不能按轨迹数线性承诺本轮GPUh；未测吞吐前不填一个虚假的卡时上限。实施合同必须补全端到端上限，超限停，不削对照或挑题救预算。

## 4. 结果如何改变论文

| 结果 | 可以增加或保留的认识 | 必须停止的推断／行动 |
|---|---|---|
| D实质恢复，且超过E与固定随机平均 | 同一写入端点差在第二块面板的获得侧有正向作用；与撤回侧共同约束解释 | 不称首列语义内容、天然读取路径、唯一通路或任意随机都无效 |
| D恢复，但与随机平均差异不清 | 保留恢复效应，明确无法分开一般扰动的帮助；报告区间 | 不因“获得方向补齐”就提升解释强度 |
| D不恢复或异号，L11端点仍明显更好 | 写入改善可复现，但一次D用途替换不足以在此面板带回收益；双向链只能保留旧面板范围 | 不按排除法归因于KV、q或多步状态；不自动续t3、扫层或加剂量 |
| E同样有效或更强 | 修正“直接读取主导”的范围 | 不重新挑指标或删E |
| 端点差不足／t2不可达 | 当前接收条件不支持本轮比较，结果不可判 | 不换针、强制开口或增幅直到可判 |
| 工程桥接或数值验收失败 | 没有有效新增科学结果 | 实施阶段按合同处理；不能当作科学阴性 |

所有结果收尾后整稿；成功不自动解锁G3–G5，失败也不生成下一组局部卡。下一次争取更宽贡献时，必须明确需要推广的关系或可检验的形成解释，再决定独立的任务／模型或形成研究。

## 6. 历史错误、与NWC的差别及反方自查

相关历史错误：E01/E24/E25——保持主问题与有界增量，不把填满矩阵当必要；E04——不把读取公式当发现；E07/E08/E14/E15——写清端点与用途，双向也不等于自然路径；E09/E10——不把分数／张量交互当回答解释；E12——匹配范数不排除所有非特异影响，逐个展示随机收益；E13——L11供体可能提供有用信息，只称供体状态恢复，不称接收者原记忆恢复；E16/E18——阴性不自动归因到剩余部件；E19/E22/E23——桥接是工程、已见面板不是留出、自查不是独立评审；E26——t1端点来源与t2输出操作分开，未隔离天然形成中介。E02/E03/E05/E06/E11/E17/E20/E21在本轮没有新增相应操作或主张：不赋予层号特权、不以稀疏等于小、不独立拼换共享变量、不声称穷尽更新、不估语义存量、不直接抵消残差、不设假互斥、不宣称首创。

与NWC相比：模型、面板、端点、用途公式和解析规则保留；接收者从L11换为L10，供体改为L11；检验收益而非损失；加入获得侧新随机族和固定参考范数匹配；不重做NWC的DV、DX、半幅度、40方向分数或原生来源中心预测。NWC的新输入身份不能继承给本轮。

反方一：**“阳性只是供体重新带入答案。”** 这足以限制语义／天然中介结论，但不推翻同输入写入端点差经指定读取带来恢复这一承诺；§3/§4禁止扩大解释。

反方二：**“破坏非特异，恢复特异也不能证明一条特殊天然线路。”** 接受。仅与固定随机族平均比较，保留个别随机强恢复；不宣称恢复／破坏有通用不对称定律。

反方三：**“旧面板看过了，再跑只是追认。”** 因此命名为预先规定新增臂的补充检验；不能补成完全独立确认。若文章不再把双向链当中心贡献，此轮优先级应下降，不为自洽强行跑。

反方四：**“这个小补丁仍然不能把论文抬到strong accept。”** 同意。本轮解决当前中心句的具体证据责任，不保证贡献的重要性或广度。后续要提高上限需另有可复用关系或形成解释，不能靠不断补同类格子累加。

反方五：**“随机范数匹配是否偷偷沿用各分支不同q的范数？”** 已在§3修正为获得D实际参考轨迹的逐层逐头固定范数；随机臂自由响应，解释限定于这一控制族。不能只改标题不改实现。

**结论：逻辑设计通过，作为下一实验的建议供讨论；工程、冻结、端到端预算及运行授权均未完成。** 本轮仅记录建议与自查，未改实验代码、未连接服务器、未加载模型或运行GPU；同一助手完成，不是独立审查。
