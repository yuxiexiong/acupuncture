## 1. 本阶段要解决的问题

主线保持不变：**暂时的稀疏激活干预，怎样改变每步写入与旧信号的保留、衰减和修正，并形成撤针后的行为效应？**

S1已看到：目标组中写入账与处理账反向，撤针后仍有新写入差异。未知的是：晚出现的差异是否必须由当时仍在场的针维持，还是前段针留下的历史会在后面继续生成差异；从同一旧状态出发，后段针究竟改变了多少旧状态处理，而非仅增加不同的新信号。

本轮用真实时序操作提供因果比较，用该操作产生的真实计算分账定位写入/处理。**不是以时序四格代替W/R问题，也不是把W/R两项人为独立开关。** 新增认识须来自具体过程和可被否定的预测；公式恒等式、架构允许传播和“有交互”不算发现。

## 2. 固定资产、范围和时间边界

冻结继承S1的模型revision、tokenizer、transformers 5.20.2实际torch路径、精度、校准和输入身份。两针为L0/C4146/−1、L12/C3621/−1；VAR01、VAR02、VRD01、VRD02、VRL01、VRL02各两个事实，共12输入；L16–18所有递推头，不按结果选头。L12是已有行为不同的经验锚点，不是代表所有层或所有模型。

- b：原分段文件中事实陈述最后一个token更新后。E=模板起点至b；L=b之后至τ。
- τ：`prompt[:-1]`更新后，原针最后允许作用的前缀边界。
- t_L：最后一个提示token更新后；此token及所有候选/生成token均无针。
- 候选：沿用原两条固定后缀；分别报告相同候选、相同位置的条件比较。只处理为评分确实送入模型的token，不能把最后一个已评分但未喂入的token算作更新。

S1主要汇总在t_L；新计划分别报告b、τ、t_L、候选各位置，不能把t_L的投影份额当τ缓存的份额。b处状态可按原驱动离线重建并标识误差；不为取得b而改动prefill分块路径。

## 3. 只增加两个时序条件，保持所有变量自然共变

| 条件 | E开针 | L开针 | 目的 |
| --- | --- | --- | --- |
| 00 | 否 | 否 | 干净基线，两锚点共享 |

主要操作对比为10−00、01−00、11−10；对预定量Z另报 `I=(Z11−Z10)−(Z01−Z00)`。这些是原针时段操作的总效果/交互，包含所有真实下游路径；I不命名为W/R独立交互。E/L长度不同，10与01的大小不能解释成“事实语义比模板更重要”。

## 4. 三本相互校验的账：具体拆解什么

采用与S1一致的key×value方向：`S_t=A_t S_(t−1)+B_t`，`A=α(I−βkkᵀ)`，`B=βkvᵀ`。以下都是**离线分析真实轨迹**，任何分量均不送回模型。

### 4.1 同一起点的旧来源处理：直接回答“旧的那份信号有没有被不同处理”

在每条轨迹上设 `H_b=S_b,N_b=0`，后续 `H_t=A_t H_(t−1)`、`N_t=A_t N_(t−1)+B_t`，核验 `S=H+N`。

- 01/00在b的S及完整前史相同；11/10也相同。各对的ΔH只能来自b后实际A序列不同，不能由纯加性B直接产生。ΔH高于误差即排除“相同旧来源状态受到完全相同处理”的解释。
- ΔN包含新写入和之后对这些新信号的处理，不能改名为纯写入效应；须继续看4.2的逐步账。
- H是计算来源，不等于事实知识。相同前史配对的ΔH可以是间接影响后的算子变化：这不识别A的上游独立因果来源。
- 10/00的b起点不同，不能将它的ΔH全部说成处理改变。对此主要用4.2。

### 4.2 在撤针边界区分旧差异传递、新写入差异、处理差异

对每一预定成对轨迹，记Δ为第一条件减第二条件、横线为两者平均。在边界c设：

```
D_c = ΔS_c,  W_c = 0,  R_c = 0
D_t = Ā_t D_(t−1)
W_t = Ā_t W_(t−1) + ΔB_t
R_t = Ā_t R_(t−1) + ΔA_t S̄_(t−1)
ΔS_t = D_t + W_t + R_t
```

对10/00从c=b开始，回答早针撤除后的形成；对所有三种主要比较再从c=τ开始，回答末提示及固定候选阶段的形成。01/00、11/10从b开始也分账，此时D_b=0，与4.1交叉核对。

- D：边界已有差异按平均算子传递的账；W：边界后新产生的加性写入差异；R：边界后处理算子变化产生的差异。三者合计重建实际ΔS，实测舍入误差另列。
- 10在后段已无针，若W仍可分辨，说明早段操作的历史后果会在该目标组继续形成写入差异；不能说这些差异必由“晚段仍开针”产生。它不证明目标组自身反馈，来源可能在上游历史。
- 若D足以近似实际向量、W/R都在误差内，支持当前窗口的被动延续。若W/R各自大而相互抵消，即使净和小也不能称“没有持续重写”。若R显著而W不可分辨，支持处理变化主导当前新增账，而非新B变化。
- β/k同时进入A/B，变化同步计入；W/R是指定分解的计算来源，不是独立因果效应。须复算S1的C背景、T背景账；若符号或大小排序依赖背景，明确不可给稳定主因。不能为得到稳定结论改账。
- 如需细分R，令 `P=I−βkkᵀ`，用 `ΔA=Δα·P̄+ᾱ·ΔP` 分别递推衰减和定向修正账，仍是共享变量下的指定分解，不是新增门控实验。正负方向均记录，不沿用只检查正R的late_processing分支。

### 4.3 同一时刻的真实读取：防止只看状态大小

对更新后状态和实际q，用 `Δo=(ΔS)ᵀq̄+S̄ᵀΔq`，将D/W/R分别投影到q̄；另列查询项、gated norm和out_proj后的实测差异。H/N也做同样的读取分账。跨条件q允许改变，因此只投影状态而不列查询项不算闭合。

这在raw读取层面是精确账目；非线性门、残差和后续层至答案仍需S3检验。R在状态投影为负，并不意味着改善事实回答。不得仅用范数为过程排重要性。

## 5. 事前预测、反例与报告方法

下表在新条件结果打开前固定。S1报告提出的预测保留为待检验推测，不把它们称为已有发现；无理论依据的方向不填“预期支持”。

| 问题/预测 | 必须报告的量 | 什么结果改变解释 |
| --- | --- | --- |
| S1近期在场解释预测：10在t_L的差异范数不足11的一半 | `r10=||S10−S00||/||S11−S00||`，分层及全目标组；两事实先等权合并每个情景 | r10≥0.5是该情景的预注册反例；若伴随后段W/R可分辨，早段历史持续生成差异成为实际证据。r10<0.5不单独证明晚针必要 |
| “01重现大部分11”的补充可检验定义 | `a01=<ΔS01,ΔS11>/||ΔS11||²`、`e01=||ΔS01−ΔS11||/||ΔS11||`，读取向量同报 | 本版在新结果前约定a01≥0.5且e01≤0.5才称目标状态近似重现；这是操作阈值非显著性。范数相似但方向不合不算重现；不自动推到答案 |
| S1预测L0的r10高于L12 | 每个基础情景的两锚点配对差；逐层/两事实完整展示 | 反向、近零或跨情景不一致分别保留，不改称普遍自我维持机制 |
| 纯新增信号解释是否足够 | 同起点01/00、11/10的ΔH、其实际读取分量，以及W/R | ΔH可分辨排除该时窗“旧来源处理完全没变”；ΔH未分辨不排除新写入后又受不同处理 |
| 早段针是否仅留下被动残留 | 10/00在b后、τ后的D/W/R及读取方向 | 新W/R可分辨则纯被动延续不足；D大、W/R小支持当前窗口的被动部分；结果混合就逐项报告 |

r10的0.5来自S1报告，a01/e01是本版对“大部分”的事前操作定义，不能冒充原冻结指标。所有阈值的连续原值均提供；分母低于数值界时不计算比例。全部6个情景报告支持/反例/未分辨，不用“多数投票”遮住反例，不把层、头、token当独立样本；不承诺统计泛化。

误差标准沿用S1状态重建1e−3、raw读出1e−2的相对上限，并同时记录绝对残差。成对效应及分项以实际重建/重放残差的10倍为保守可分辨界，明确每个指标的同单位界；低于界只记未分辨。恒等式重建过关是工程条件，不说明机制正确。01/00、11/10在b必须核验相同；若实际调用导致不相同，停止这一同起点解释并修正实现，不硬作ΔH结论。

## 6. 保存什么，哪些已有数据仍不够

继承S1记录器：全部目标层的逐token q/k/v/α/β、实际状态/读取验收、分段与注入审计、边界隐藏输出、原首步logits、候选逐token分数、原针校准/权重/清理检查。保存每个条件的完整Mτ及管理字段、张量别名清单、全部张量hash；大文件按现有归档方式，不进Git。末提示后的完整状态可由Mτ重放，不要求额外存第二份全模型缓存。

S1已足够复核旧00/11的W/R、背景敏感性、晚期账和端点；没有10/01就不能回答时序因果问题。它的目标层状态和全缓存哈希也不能代替可续跑的完整Mτ。因此本轮端点重建有具体资产目的，不是又跑一次以增加样本数。

## 8. 自审与贡献边界

本轮没有异源状态、βv补偿或冻结后续变量。能区分的是操作时段的总因果效应、共同旧来源的处理改变、撤针后实际差异的三类计算来源；不能把后两者说成彼此独立的自然因果效应。若W/R共变且背景依赖，结案为“指定账目可解释、独立贡献未识别”，不能硬选一个主因。

沿用[先验审计](cache-mechanism-known-basics-audit-2026-10-31.zh-CN.md)与其中核对的Gated DeltaNet、WriteSAE及固定源码：更新恒等式、写入—传播—读取框架都不是本项目新贡献。增量在于这些原上游稀疏针在真实轨迹中如何形成撤针后的差异，及该解释能否预测新的时序条件；此次未新增文献优先权主张或独立复现声明。
